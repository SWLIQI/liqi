# 分镜配额：11 项区间 + S 码

> 同步来源：`liqi-video-forge v6.19.8` → `references/分镜配额与机检规范.md`
> 本包把能由镜头表 JSON 判断的项做成机检；不能判断的明确标「需人工」。

## 一、景别九档

`大远景 → 远景 → 全景 → 中全景 → 中景 → 中近景 → 近景 → 特写 → 大特写`，对应 1–9 档。完整视觉结果见 `02-optics.md`。

## 二、11 项区间配额

| # | 配额 | 区间 | 例外 |
|---|---|---|---|
| Q1 | 人物特写占比（8–9 档，物件不计分子；分母 = 全部镜头） | 25%~40% | 物件特写只不进分子，仍计入分母；定场镜禁特写 |
| Q2 | 常规机位占比（平视 + 正面/过肩 + 平稳运镜） | ≤30% | 文戏重场可声明「常规机位主导」 |
| Q3 | 侧 45° 机位占比 | 30%~40% | — |
| Q4 | 侧面机位占比 | ≤15% | — |
| Q5 | 大仰角次数 | ≤3 次/集 | — |
| Q6 | 大俯角次数 | ≤3 次/集 | — |
| Q7 | 荷兰角次数 | ≤1 次/集，或不用 | — |
| Q8 | 全片焦段种数 | ≥4 种 | — |
| Q9 | 全片运镜种数 | **≥4 种（本包适配）** | 含「固定」为一种；主包口径是 ≥8，但骨架库只有 7 个合法词，详见本节末 |
| Q10 | 连续同运镜 | 禁止第 3 镜（≤2 镜） | 剧烈晃动短链可连续；固定不计入连续链 |
| Q11 | 重技法全片上限 | 滑动变焦 ≤1、环绕 ≤3、Snorricam ≤1、鱼眼 ≤2、升降 ≤2、摇臂 ≤2、POV ≤3 | 单场各 ≤1 |

**构成要求 C1**：每组（段）至少 1 大景别（1–3）+ 1 特写（8–9）+ 1 中景（5）。不算占比，算必有项。

> **Q9 为什么是 4 而不是主包的 8**：主包 Q9 要求全片 ≥8 种运镜，但本包骨架库实际只有 7 个合法运镜词（固定 / 横移 / 缓推 / 后拉 / 跟拍 / 缓降 / 微推）。若沿用 8，任何 ≥8 镜的镜头表都会必挂且无法通过合法输入消除。本包把**种数门槛降为 4**（与 Q8 焦段种数同量级），`minShotsForMove` 仍为 8（不足 8 镜不统计）。这是对 7 词表上限的适配，不是降低质量要求；主包若补到 8 词，本包应同步恢复 8。

## 三、越界分级

- **ERROR**：Q7 荷兰角超配、Q10 连续第 3 镜同运镜、Q11 重技法超全片上限。这三项没有合法创作理由。
- **WARN**：Q1~Q6、Q8、Q9 越界，提示调整但不阻断。
- **S21**：相邻景别差 ≥3 档，WARN；声明「极限景别跳跃」即豁免。跳级本身不非法，缺过渡素材才非法。
- **S22**：统计失效元检查——没有镜块 / 都不含时长 / 统计不到景别或运镜，报 ERROR，并明说「本门没有真正查过，不算通过」。

## 四、最小样本量（别把短包判死）

| 配额 | 门槛 |
|---|---|
| Q1~Q4 | ≥3 镜 |
| Q8 | ≥4 镜 |
| Q9 | ≥8 镜（种数门槛 ≥4） |

不到门槛时输出「本门未查（镜数 N < 门槛）」，**不报合格，也不报不合格**——未查 ≠ 通过。

## 五、本包机检边界

| 项 | 本包 |
|---|---|
| Q1 特写占比 | ✅ 机检（WARN） |
| Q2 常规机位 | **需人工**：数据模型没有「正面 / 过肩」这个字段，不硬算 |
| Q3 侧 45° | ✅ 机检（WARN） |
| Q4 侧面 | ✅ 机检（WARN） |
| Q5/Q6 大仰/大俯 | ✅ 机检（WARN） |
| Q7 荷兰角 | ✅ 机检（ERROR） |
| Q8 焦段种数 | ✅ 机检（WARN，≥4 镜才查） |
| Q9 运镜种数 | ✅ 机检（WARN，≥8 镜才查；种数门槛 4） |
| Q10 连续同运镜 | ✅ 机检（ERROR，固定不计） |
| Q11 重技法 | ✅ 机检（ERROR，按 `technique` 字段计数） |
| C1 每组三件套 | ✅ 机检（WARN，按 `segment` 分组） |
| S21 跳级 | ✅ 机检（WARN，`jump_declared=true` 豁免） |
| S22 统计失效 | ✅ 机检（ERROR） |

## 六、声明式例外

镜头表里用 `jump_declared: true` 声明该镜允许极限景别跳跃（本包简化写法；主包是段首 `【配额声明】`）。声明只豁免统计，不免内容质量：仍要补过渡素材或前一镜尾帧。

## 七、交付前自检

- 景别按 9 档写，没有自造档位名
- Q1 25%~40%、Q3 30%~40%、Q4 ≤15%
- 大仰/大俯各 ≤3；荷兰角 ≤1
- 焦段 ≥4 种、运镜 ≥4 种（本包 7 词表上限 7；短包看「未查」提示）
- 无连续第 3 镜同运镜（固定除外）
- 重技法在上限内，单场各 ≤1
- 每组有 ≥1 大景别 + ≥1 特写 + ≥1 中景
- 多人镜有轴线声明；跨轴有合法过渡
- 机检跑过，没有 S22
