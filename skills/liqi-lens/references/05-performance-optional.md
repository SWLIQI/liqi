# 表演模块（可选）

> 同步来源：`liqi-video-forge v6.19.8` → `references/情绪表演层.md`
> 只在**本镜含台词**或**情绪爆发镜**时加载；其余镜不展开。需要脸上具体怎么动（FACS 动作单元）时，回主包 `references/表演层_FACS微表情.md`；本包不复制 29 个 AU。

## 一、三态写法

| 态 | 写什么 | 占本镜时长 |
|---|---|---|
| 说前 | 吸气或停顿、视线落点、身体预备姿态 | 20%~25% |
| 说时 | 口型与台词同步、身体动作减弱、呼吸让位于发声 | 50%~60% |
| 说后 | 停在某个状态、呼吸回常态、等待回应 | 20%~25% |

三态缺一，台词像贴上去的；尤其「说前」没有吸气与视线，角色会一开口就说话。

## 二、呼吸

| 状态 | 写法 |
|---|---|
| 说前 | 一次缓慢吸气，肩线微抬 |
| 紧张 | 呼吸浅而短，肩线几乎不动 |
| 说后 | 一次长呼气，肩线回落 |
| 哭腔 | 呼吸断续，吸气带气声 |
| 隐忍 | 屏住呼吸，只有喉结一次滑动 |

呼吸写进声音设计的呼吸层，与时间线对应段逐字一致。

## 三、视线

一镜内只选一个落点，中途换落点要拆拍：

- 看向对话对象（关系建立）
- 看向画外某处（悬念与留白）
- 避开对视（心虚与逃避）

反打匹配：A 看向画面右，B 在下一镜必须看向画面左。

## 四、一镜只给一处微变化

情绪爆发最容易翻车的是同时写皱眉、咬唇、握拳——模型随机挑一个，剩下变抽搐。

从下面选**一处**写透，其余部位明确写「保持不动」：

- 眼部：眼睑下垂 / 瞳孔收缩 / 目光失焦
- 口部：唇线抿紧 / 下唇微颤 / 嘴角一侧下拉
- 呼吸：见上表
- 手部：握紧 / 松开 / 指节发白

## 五、与保真预算的关系

情绪表演是保真预算的主花费。如果本镜预算主项已经押在材质或群像上，表演降级：只留呼吸与视线，去掉微表情，靠声音设计承载情绪。先定预算，再定表演层级。
