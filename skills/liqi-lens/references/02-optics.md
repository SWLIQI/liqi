# 光学：景别、透视、景深与焦段

> 同步来源：`liqi-video-forge v6.19.8` → `references/光学与空间语言块.md`（一~九节）
> 原则：**写可见结果，不写镜头参数**。不写 f 值、不写焦段毫米数、不写 ISO、不写镜头型号；模型对参数响应不稳定，对「背景熔成什么色块」稳定。

## 一、景别九档（与配额同源）

| 档 | 名称 | 取景 | 可复制视觉结果 |
|---|---|---|---|
| 1 | 大远景 | 环境主体，人物仅为点景 | 主体仅为比例参照，环境占满画面，可辨认的是体积与位置，不是细节 |
| 2 | 远景 | 全身 + 大量环境 | 主体全身可见但小，姿态与动势可辨认，五官不可辨 |
| 3 | 全景 | 全身 + 周边环境 | 主体全身入画，头顶与脚下留有余量，环境交代所处空间 |
| 4 | 中全景 | 膝盖以上 | 取景到膝盖，人物全身入画但下缘切在膝上，环境仍在交代所处空间 |
| 5 | 中景 | 腰以上 | 取景到腰腹，背景保留形状与色块关系，细节纹理让位给主体 |
| 6 | 中近景 | 胸口以上 | 取景到胸口，面部占画面六分之一以上，背景化开但能读出明暗结构 |
| 7 | 近景 | 肩以上 | 取景到肩部，面部占画面四分之一以上，背景化开但能读出明暗结构 |
| 8 | 特写 | 头部/局部 | 主体占画面六成以上，背景只剩色块与光斑，不参与叙事 |
| 9 | 大特写 | 极微距 | 只有局部占满画面，其余全部融化，可辨的只有材质与微动 |

档位必须在时间轴段头写清；不许只写「镜头对准 XX」。

## 二、透视三类（每类至少选 3 条叠加）

- **广角空间扩张**（机位贴近，约一米）：前景身体存在感大于自然比例；环境延伸到画面边缘；边缘到边缘清晰；直线不弯；机位物理贴近；无长焦压缩与奶油散景。
- **标准自然人眼**（距主体三到五米）：透视接近人眼；无可见畸变；景深舒适；画面沉稳中性。
- **长焦压缩**（六到八米或更远）：背景压成平面、紧贴主体；只有主体锐利；近景靠焦段拉近；前景暗散景框住主体；主体在融化背景前跳出；镜头与主体之间有大气薄雾。

同一段内**不得同时出现广角与长焦的行为句**，否则模型随机选一个。

## 三、景深三档

| 档 | 视觉结果 |
|---|---|
| 浅 | 只有主体与关键物件在焦点内，背景熔成 X 色块，前景边缘同样化开 |
| 中 | 主体清晰，背景保留形状与色块，失去细节纹理 |
| 深 | 前景到远景全程清晰，纹理可读，纵深靠线条与明暗交代 |

景深写视觉结果，不写 f 值；f 值只进参数行。

## 四、焦段：按内容选视角（不按数值写正文）

| 内容类型 | 对角线 FOV | 写法 |
|---|---|---|
| 面部肖像 · 带环境的亲密特写 | 84° | 亲密广角 |
| 面部肖像 · 中景肖像 | 29° | 短焦长焦肖像 |
| 面部肖像 · 紧凑情感特写 | 18° | 经典长焦 |
| 面部肖像 · 远距隐藏观察 | 8° | 超长焦 + 前景遮挡 |
| 环境动作 · 纪录片式 | 47° | 标准镜头 |
| 环境动作 · 宽广 | 84° | 经典广角 |
| 环境动作 · 大尺度地理 | 107° | 广角直线镜头 |
| 环境动作 · 极端沉浸 | 135° | 仅整拍都是环境动作时 |
| 细节/微距 · 标准 | 29° 或 18° | — |
| 远距观察 · 体育/野生动物 | 8° | 超长焦 |
| 远距观察 · 压缩监视肖像 | 18° 或 8° | 长焦 + 前景遮挡 + 大气雾霾 |

**一个节拍内禁混两类内容**（面部肖像 + 环境地理 + 微距细节同拍 = 镜头漂移）。度数只作选型依据，正文写视觉结果。

## 五、防漂移句（长焦/广角必加）

- 长焦：本镜任何部分都不变为广角覆盖，背景全程保持压缩与融化，更宽的取景靠机位拉远实现而不是换透视。
- 广角：本镜任何部分都不变成长焦肖像，环境在主体周围保持可见，机位保持物理贴近。
- 标准：无极端广角畸变，无长焦压缩，画面保持自然中性。

`shot_list.mjs` 会按 `fov_deg` 自动补对应防漂移句，不需要手写。

## 六、空间弱词替换

| 禁用 | 替换 |
|---|---|
| 附近 / 不远处 / 周围 | 紧贴 X / 手搭在 X 上 |
| 旁边 / 一侧 | 在 X 的画面左侧 / 位于画面左三分之一 |
| 某处 / 在该区域内 | 正站在 X 正下方 / 在 X 门前 |
| 靠着 | 背靠 X / 手搭在 X 上 |
| 大概在 / 差不多 | 与 X 齐平 / 高出 X 半个头 |

物理锚定句式：`主体 + 接触动词 + 参照物 + 画面位置`。**禁写「距 X 一米」**——米/厘米在画面里没有落点；用接触、画框分数、已知尺寸参照物三种写法。

## 七、朝向与视线分离

三个变量分别写：

- 躯干朝向：正对 X / 侧身朝画面左 / 背对镜头
- 视线目标：锁定 Y / 越过镜头看 Y / 眼睑下垂不看任何目标
- 头部动作：转向 Z / 保持不动 / 微微低头

对白场景：说话者嘴唇只为当段台词而动；其他角色静默聆听；不说话时嘴唇静止；无明确要求不出现画外音。

## 八、真假运镜

- **真推进 Dolly In**：机位真实向主体移动，透视改变，前景/背景遮挡关系同步变。
- **假推进 Zoom In**：机位不动，只放大画面，前景/背景关系不变，无透视变化。
- **真后退 Dolly Out**：机位真实远离，空间打开，环境逐步入画。
- **Dolly Zoom**：机位靠近 + 取景收窄，背景伸缩而主体比例稳定。

三条纪律：①「摄影机真实移动」必须显式写；②同一镜不得先写真推进又写只放大；③ mm / T 值 / F 值不进正文。
