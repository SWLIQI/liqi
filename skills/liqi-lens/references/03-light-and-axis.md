# 光位与轴线

> 同步来源：`liqi-video-forge v6.19.8` → `references/视听层_镜头文法与光色.md`（七节）、`references/轴线与反打规则.md`
> 光管「真不真」，轴管「左不左」。

## 一、光：必须有物理来源

**严禁无来源的情绪假光与廉价棚拍白光。** 每一镜的光都要能指出发光物：

- 日景白天：侧面窗棂天光、林间丁达尔斑驳阳光、天空自然散射光
- 夜景室内：暖黄钨丝灯、破败日光灯管频闪、蜡烛烛火、霓虹灯管反射
- 阴影：自然的青灰 / 暗棕环境漫反射色阶，**严禁死黑或全脸漂浮发白**

镜头表的 `light_source` 必填；写「氛围光」「电影光」等于没写。

## 二、日景防冷光

日景 / 白天**严禁直接使用「冷白光、冰冷蓝光、刺眼冷光」**。需要肃杀、凄清、冷酷时，转译为：

> 低饱和度影调，青灰色自然漫射阴影，背光面与高光处形成自然明暗阶梯，逆光边缘光勾勒轮廓

原因：「白天 + 冷蓝光」是棚拍打光的特征，是「假」的第一识别信号。

## 三、光比与光位

镜头表用 `light` 记方向（顺光 / 侧光 / 侧逆光 / 逆光 / 顶光 / 底光），`light_ratio` 记光比（如 `1:4`），`light_source` 记物理光源。光位方向必须能落到具体发光物上；只写「45° 主光」而没有光源，仍不合格。

**冲突三问**：① 这两个词能否同时为真（光源方向 × 天气遮蔽）？② 时段是否打架（正午顶光 × 黄昏长影）？③ 光源句是否互相作废（前句「唯一实用光源」后句「霓虹满街」）？撞一条就保叙事需要的那半边。

## 四、轴线：三条铁律

| 类型 | 定义 | 适用 |
|---|---|---|
| 视线轴 | 对视角色之间的连线 | 对话、对峙 |
| 运动轴 | 主体运动方向的延长线 | 行走、追逐 |
| 关系轴 | 三个以上同框对象的关系线 | 群戏（取最主要两人） |

1. **建立镜定轴**：一场第一个双人镜建立轴线，写明谁在画面左、谁在右。
2. **同侧原则**：后续机位全部保持在轴线同一侧（180° 工作区）。
3. **跨轴必须过渡**：换边必须经过中性镜、运动镜、插入特写，或明确重新建轴。**裸跨轴是硬错误，没有例外。**

一场戏只用一条主轴线。三个人的戏每镜换关系线，等于没有轴线。

## 五、跨轴四种合法过渡

| 方式 | 写法 | 注意 |
|---|---|---|
| 中性镜 | 机位正对轴线拍单人，画面无左右信息 | 主体居中且无侧向参照 |
| 运动镜 | 机位在画面内绕过主体，跨轴过程被完整记录 | 同一段内连续，不能切 |
| 插入特写 | 插入与轴线无关的物件/局部，切断空间连续性 | 特写本身不能含左右信息 |
| 重新建轴 | 新场景/新人物关系的第一个镜，明确声明新轴 | 换了戏就重新建 |

## 六、反打匹配

| 上一镜 | 下一镜（反打） |
|---|---|
| A 看向画面右 | B 看向画面左 |
| A 位于画面左三分之一 | B 位于画面右三分之一 |
| 过肩：A 的肩在画面左侧 | 反打：B 的肩仍在画面左侧 |
| 主体自左向右运动 | 下一镜仍自左向右，不得反向 |

第四条最常被忽略：运动轴反向会让观众觉得主体在折返。

## 七、轴线声明字段

多人物镜在「场景与人物」之后另起一行，正文只写地理事实：

```
轴线：柱—隔断墙连线，旅客甲在画面左三分之一（西侧），查验员乙在右三分之一（东侧），隔查验台相望
```

**状态词（建立 / 保持 / 跨越）不进正文**——逐镜单独投喂，模型看不到上一镜；状态词记进连续性台账。

本包 `check_lens` 实际会查：多人镜有没有 `axis`、`axis` 是否写清左/右、有没有 `axis_side`、同场景上一个多人镜跨轴有没有 `cross_axis`（`轴上` 视为中性态，前后任一侧都合法）。主包的 `W-AXIS-NO-GEO` / `W-AXIS-STATE-IN-BODY` 不在本包实现。

## 八、自检五问

1. 这场戏的轴是谁与谁的连线？
2. 第一个镜定的左右是什么？
3. 本镜机位在轴的哪一侧？
4. 要跨轴，用了哪一种合法过渡？
5. 反打镜的视线方向反过来了吗？

**本包 `check_lens.mjs` 能查**：多人镜有没有轴线/左右/机位侧；同场景 `axis_side` 变化有没有 `cross_axis`。**语义对不对**（是否真的同侧、视线是否匹配）仍需人看台账。
