# 镜头文法：这一镜该不该存在

> 同步来源：`liqi-video-forge v6.19.8` → `references/视听层_镜头文法与光色.md`（一、二、三、四、五节）
> 口径以主包为准；本文件是操作化压缩。

## 一、镜头三任务（写镜前第一问）

每个镜头至少承担一个明确任务，三项皆无的镜头一律剔除：

| 任务 | 含义 | 例 |
|---|---|---|
| 改变人物情绪 | 自信→慌乱、伪装→破防 | 听到名字的瞬间，握杯的手停住 |
| 实质推进动作 | 物理位移、攻防、传递道具 | 他把刀放下，推过桌面 |
| 施加戏剧压力 | 缩短距离、缩紧时间、逼入死角 | 门在身后关上，脚步声逼近 |

自检：删掉这一镜，观众会漏掉什么？答不上来就删。

## 二、三大调度法则

1. **芬奇法则**：摄影机默认静止沉稳；只有主体发生状态改变时才跟随运镜，速度与主体运动 1:1。无状态改变不要运镜。
2. **斯皮尔伯格空间法则**：任何一秒，观众都要清楚「主角在哪、威胁在哪、出口在哪」。氛围镜头也要留一个空间参照物。
3. **黑泽明环境压力法则**：全场只用**一种**主导的物理环境压力（暴雨 / 狂风 / 水雾 / 碎石 / 频闪日光）贯穿。

## 三、剪辑六律与节奏

切镜优先级：**情感真实 51% > 剧情推进 23% > 节奏节拍 10% > 视线引导 7% > 二维构图 5% > 三维空间 4%**。

- **Eye-Trace**：上一镜观众视线落在哪，下一镜切入瞬间的核心信息点要在同一位置或顺势滑动；不要让观众满屏找焦点。
- **景别阶梯**：严禁连续两个镜头使用相同景别 + 相同机位；高潮前插极微距特写，大招用宏观全景，收尾用鸟瞰/过肩定格。
- **极限景别跳跃**：ECU ↔ EWS 对跳合法，但要有过渡素材或声明；不是默认手法。
- **四阶呼吸律**（长段 ≥15s）：静 → 极动 → 慢/滞（1–2 个紧凑镜头）→ 绝杀定格。升格慢镜默认禁用。

## 四、反形容词转译

**严禁空洞形容词，强制转译为摄影机可记录的物理事实。**

| 空词 | 转译 |
|---|---|
| 他很愤怒 | 咬紧后槽牙，咬肌隆起，下颌紧绷，指节发白 |
| 激烈的打斗 | 后脚蹬碎青砖，腰胯猛拧，拳峰重击下颚 |
| 极具压迫感的光线 | 左上窗棂透入窄条天光，半边脸颊隐入青灰暗部 |
| 速度极快 | 身形化作残影，出招瞬间空气被击穿出细长气穴 |
| 氛围感布光 | 45° 主光从机位左打来，右侧柔光补面，顶部逆光勾发丝 |

精度梯度：Level 0 空泛 → Level 1 类型 → Level 2 布光 → **Level 3 角度（至少到这里）** → Level 4 数值（只有极高一致性要求才上，数值不进正文）。

用户口语先翻译再写：炫酷→轨迹/动作链/距离/速度曲线；电影感→焦段/景深/物距/轨迹/光影；震撼→先扩空间尺度再加环境反馈；丝滑→连续轨迹/惯性/跟随；真实→重量/惯性/重心/受击反馈；快→缩短准备+跟拍+更紧景别，不是疯狂切镜；慢→延长准备与结果确认，不是整段慢动作。

## 五、美学构图四件套（锦上添花，不是基础层）

1. **开场 ECU 两极对冲**：极微距双眼特写，左右对称，一帧立住级别。
2. **中心对称 · 天地立极**：单人蓄力/对峙，中心对称 + 极低角度仰拍；必须边动边蓄，禁悬空静止。天地异象要具象化，禁写「光柱直插云霄」。
3. **剪影 / 轮廓光 / 负空间**：只用于动作瞬间（跃起/挥斩中），禁静止剪影。**人物承担表演时禁用剪影**——模型会把人渲染成黑块或直接不出场；只作环境元素或动作瞬间抓拍。
4. **极端体量对比**：渺小人物 vs 通天巨物，人物放画面一角/底部；体量差本身就是奇观。

节奏优先：美学镜头每个 ≤1–2s，不拖节奏。

## 六、受击工具箱（挨打方怎么拍）

短促径向震动（1–2 帧）· 轻微轴向受力偏转 · 瞬时焦点转移 · 径向动态模糊（方向与位移匹配，禁全屏均匀模糊）· Time Ramp 仅限命中帧前后 0.2s，禁整段升格。
