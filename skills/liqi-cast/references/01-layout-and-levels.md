# 依赖分级与 4 View 版式

> 同步来源：`liqi-video-forge v6.19.8` → `references/资产层_锁定与一致性.md`（一、二节）、`references/4View资产板_模板.md`（一、二节）
> 口径以主包为准；本文件只做操作化压缩。

## 一、先分级，再决定建不建资产链

| 级别 | 判据 | 要不要建 4 View |
|---|---|---|
| A0 | 单张图 / 单人单镜 / 不要求跨镜一致 | **不建**，直接写提示词 |
| A1 | 同一角色 ≤2 个镜头，且都是远景 | 可以不建，用文字锁凑合 |
| A2 | 同角色 ≥3 镜，或有一个近景/特写 | **建** |
| A3 | 跨集、换装、变年龄、多角色对手戏 | **必须建**，并且要版本互锁 |

判据的核心不是「角色重要不重要」，是**镜头里脸有多大、出现几次**。

## 二、版式：一次出图，左 25% + 右 75%

```
┌────────────┬──────────────────────────────┐
│            │   Front（正面全身，保头无脸）   │
│  左区 25%  │   Side（90° 侧面，保头无脸）    │
│  头部近景   │   Rear（背面，保头无脸）        │
│  五官可辨   │                              │
├────────────┴──────────────────────────────┤
│  图底横纹条 12%（音色速览标签 / 版本号占位）  │
└───────────────────────────────────────────┘
```

硬约束（写错一条就裁不出来）：

1. 左区 **25%**、右区 **75%**，右区三格**三等分**，顺序固定：正面 → 90° 侧面 → 背面。
2. 左区取景**上下双锁**：上沿＝发顶上方 5% 空隙；下沿＝主视图区下沿横切于锁骨下方约两指宽处，下巴位于左侧区域上沿下方 85%–90% 处。
3. 左区必须写「肩部有与右侧三格完全相同的外套衣料覆盖，衣领清晰入镜，肩颈不裸露」——只写「头部近景」会出成医学式头肩解剖图。
4. 右区三格必须写「头部完整入画 + 面部不刻画五官」，且必须**保头无脸**——不是无头，也不是模糊脸；英文兜底 `featureless face, no facial features`。
5. 全身三格要**完整到鞋**；鞋只有全身格一个去处。
6. 排版段必须声明「主视图区 88% + 图底细节条 12%」，图底条与三格之间要有分隔声明。
7. 零引线、零标注线、零箭头。卡面文字只允许三处：身高线数值、色板色名、图底音色速览标签（≤8 词英文）；未启用音色时回到两处。
8. 表情中性：基准卡带情绪会污染下游所有镜头。
9. 画面零道具（需要道具另出单卡）。
10. 背景默认亮灰影棚；同项目内必须统一，不要一半纯白一半影棚灰。

## 三、像素账（决定「哪一区能当身份锚」）

在 3840×2160 原生分辨率下实测：

| 裁片 | 脸高 | 判定 |
|---|---|---|
| 左区头部近景 `face_hd` | 约 **1922 px**（预留图底条后约 1710 px） | 远超 900 px「优秀」线 |
| 右区全身格 | 约 **285–320 px** | 250–500 px「勉强/偏小」 |

**差 6 倍。** 所以：

- **全身图不能当身份锚。** 单独投喂右区全身格，模型读不清五官，只能现编——脸必漂。
- 报数字时要说清是哪一档口径（1922 与 1710 不要混用，那本身就是版本漂移）。

## 四、出图顺序（图生图链）
