# 文字锁 16 项

> 同步来源：`liqi-video-forge v6.19.8` → `references/资产层_锁定与一致性.md`（第三节）
> 16 项是**外观锁**：五官 10 + 服装 6。音色不在这 16 项里，是另一条正交的交接链。

## 为什么必须逐项写满

写「严格沿用参考图的五官」等于没写——模型没有「参考图」这个概念，它只有你写下的词。
16 项写满，才有可复现的余地；缺项就是给模型留了自由发挥的口子。

## 五官 10 项（杜绝脸部漂移）

| # | 字段 | 写法要求 | 反例 |
|---|---|---|---|
| 1 | 脸型骨相 | 方圆脸 / 冷艳瓜子脸 / 重颌方脸 | 「好看的脸」 |
| 2 | 眉形细节 | 平直剑眉 / 微挑柳叶眉 / 断眉 | 「细眉」 |
| 3 | 眼型与眼窝 | 狭长丹凤眼 / 深邃眼窝杏眼 | 「大眼睛」 |
| 4 | 瞳色与反光 | 深褐琉璃瞳 / 赤金锐利高光 | 「棕色眼睛」 |
| 5 | 鼻梁山根 | 高挺直鼻 / 小巧微翘驼峰鼻 | 「高鼻梁」 |
| 6 | 唇形与唇色 | 薄唇微抿 / 朱红饱满唇峰 | 「红唇」 |
| 7 | 下颌线条与折角 | 下颌线清晰锐利 / 方正刚硬 | 「尖下巴」 |
| 8 | 耳廓耳型 | 贴脑耳 / 白净分明耳廓 | 「耳朵正常」 |
| 9 | 标志性特征 | 眼角泪痣 / 眉心浅疤 / 断鼻骨 | 留空 |

## 性别锚点（必写，最容易被忽略）

面部特写句必须以 **`X~Y岁男性/女性（身份代称）`** 收尾。

- 只写「老将」「文士」「武将」，或只写年龄段，模型会自行推断性别 → 漂移。
- 正确：`55~60岁老年男性（老将）`；错误：`老将`、`55~60岁`。
- 生成器会把锚点放在 LEFT 段的最后一个子句。

## 身高（height_cm，必填）

- 50–250 的整数，单位 cm；生成器把它写进 `HEIGHT LINE` 段与卡面数值。
- 身高线必须与脚底地面基准线零刻度对齐，且与人物身体留出空隙；穿模是常见崩法。
- 没有身高的角色先定身高再出卡——基准卡缺了这一项，跨镜身形就没有可比性。

## 色板（HEX + 中文色名）

- 至少 3 项，推荐对象写法：`{"name":"青灰","hex":"#3A4E48","part":"外衫"}`。
- `hex` 必须带 `#`，从风格注册表取，不要现编；缺 `#` 的裸 hex 会被机检判错。
- `name` 会印在卡面；只写字符串 `"#3A4E48"` 也能跑，但会 WARN 缺色名，卡面只有 HEX。
- 三色必须与服装、道具、场景共用同一套注册表，改色全卡同步。

## 负向词纪律

- 负向词里**不要放裸的 `text` / `letters` / `words`**：会把卡面上的身高数值和色名一起压掉。要禁就按类点名（`view name text` / `character name text` / `panel number text` / `caption`）。
- 需要压制乱码时，用「unintelligible scribbles / watermark」这类具体词，不要用泛词。
- 版本的互锁负面词只进 `NEGATIVE (per version)`，不要写进 `VERSIONS` 正向段。
