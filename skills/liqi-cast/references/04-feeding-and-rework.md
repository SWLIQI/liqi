# 投喂与返修

> 同步来源：`liqi-video-forge v6.19.8` → `references/资产层_锁定与一致性.md`（第二节投喂铁律）、`references/4View资产板_模板.md`（四、五节）

## 一、三条投喂铁律

1. **任何镜头都要带一张 `face_hd`（左区头部近景）。**
   全身图单独喂，脸一定漂——285–320 px 的脸，模型读不清五官，只能现编。
2. **侧面和背面镜头必须额外带对应的高清头部图。**
   右区三联是**保头无脸**的，只给正面清晰脸，侧面结构（鼻梁、下颌、耳廓、发髻）没人告诉它。
3. **Hero Image 锁定，中途不换参考集。**
   4 View 板裁完后选一张最优做全项目主参考。中途更换，等于换了个人。

## 二、分层投喂（省钱且防漂）

| 镜头类型 | 投喂方式 | 理由 |
|---|---|---|
| 特写 / 近景 | 图生视频 + 参考图；**提示词只写动作与运镜，不重复描述长相** | 参考图已锁长相，文字再描述会互相打架 |
| 远景 / 切出 | 文生视频 + 提示词锚，不投参考图 | 脸小，观众不敏感；服装与体型由提示词管 |
| 群戏 | 从已确立的角色图逐一出 | 多主体纯文本直出是重灾区 |

## 三、两个物理限制

- **转头 60° 禁区**：侧脸超过约 60°，五官开始靠先验编。分镜设计上避开大角度转头，或补一张该角度的头部图。
- **转身镜头**：首帧给背身、尾帧给正脸，让模型在两个锚之间维持同一个人。

## 四、出图前九问

1. 左区 25%、右区 75% 三等分、顺序正面 → 90° 侧面 → 背面？
2. 右区三格写了「头部完整入画 + 面部不刻画五官」+ `featureless face`？**有没有误写成「无头」？**
3. 16 项文字锁写满了？性别锚点收尾了？
4. 表情是中性？
5. 画面零道具（或已明确声明为单卡）？
6. 三个 HEX 带 `#`、带中文色名、从注册表取？
7. 右区是「保头无脸」而不是「无头」？
8. 三格全身完整到鞋，不裁头不裁脚？
9. 排版写了「88% + 12%」？身高线数值写了吗？音色标签 ≤8 词？负向词里没有裸的 `text`/`letters`/`words`？零引线？

## 五、常见崩法与补救

| 症状 | 先查什么 | 补救 |
|---|---|---|
| 三视图脸不一样 | 是不是把全身格当参考喂了 | 补喂 `face_hd`，提示词删掉长相描述 |
| 右区画出清晰五官 | 提示词是否漏了「面部不刻画五官」 | 补英文强制串，重出；不要试图后期修 |
| 身高线穿模 / 压在身上 | 站位与身高线是否贴边 | 留出安全距离，重出 |
| 年龄忽大忽小 | 16 项里「面部肌肉与肤色」是否写了 | 补写肤色与体块描述 |
| 塑料感 | 服装 6 项缺纹理/垂坠/扣具 | 补齐 12/13/15 项 |
| 换装后认不出是同一个人 | 版本互锁词有没有进负向段 | 每版补 `interlock`，出图只取对应版本那一行 |
| 卡面文字乱码 | 负向词是否放了裸 `text` | 换成点名式（`view name text` / `caption`） |

**原则**：4 View 是基准，基准错了不要在下游修——回退重出比修十张便宜。
