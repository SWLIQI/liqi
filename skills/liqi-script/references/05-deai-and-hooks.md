# 去AI味、尾钩与筹码账

> 同步来源：`liqi-video-forge v6.19.8` → `references/去AI味对照清单.md`、`references/尾钩与筹码账.md`、`references/叙事层_剧本门控与台词.md`（五·补、七节）

## 一、书面腔 → 自然口语

| AI 腔 | 自然说法 | 说明 |
|---|---|---|
| 你的肢体状态十分可疑 | 你的动作不太对劲 | 去医学/书面词 |
| 他的神情透露出深深的犹豫 | 他犹豫了一下 | 删空泛修饰 |
| 内心感到无比挣扎 | 他攥了攥拳，又松开 | 心理转可见动作 |
| 这一刻，他终于幡然醒悟 | 他垂下头，没说话 | 觉悟用行为表现 |
| 情绪递进层次分明 | 瞳孔涣散定焦→嘴唇抿成死线→下颌微颤 | 递进写成动作序列 |

**规则**：抽象意境可以保留，但必须紧跟一句可执行的画面支撑；纯形容词（绝美/逼真/张力/电影感）一律删。

## 二、slop 词计数

| slop 词数量 | 处置 |
|---|---|
| 0 | 提交 |
| 1–2 | 删除并收紧 |
| 3–5 | 从主体重新往下写 |
| 5+ | 推倒重来 |

常见 slop：电影感、高级感、氛围感、大片感、质感拉满、细节丰富、极其、非常、十分、惊心动魄、引人深思、深刻揭露、耐人寻味、震撼、完美呈现、精妙绝伦、栩栩如生、超高、极致、顶级、一流、卓越、绝佳、cinematic masterpiece、stunning、breathtaking、hyper-detailed、ultra-realistic、award-winning、best quality。

**本包只把文学型 slop 做成机检**（电影感/高级感/氛围感/大片感/质感拉满/细节丰富/惊心动魄/引人深思/深刻揭露/耐人寻味/完美呈现/精妙绝伦/栩栩如生/顶级/一流/卓越/绝佳/震撼），避免把对话里的「非常」误报；动作/环境描述与台词都会扫。

精度梯度：Level 0 空泛 → 1 类型 → 2 布光 → **3 角度（至少到这里）** → 4 数值（只有极高一致性要求才用，数值不进正文）。

## 三、台词 AI 腔六模式

| 模式 | 病例 | 修法 |
|---|---|---|
| 排比三连 | 「我恨这一行，恨这条街，恨这该死的天。」 | 砍到一恨，恨最具体的 |
| 开头重复 | 连续三句都以「我以为」起头 | 只留情绪最重的一句 |
| 「不是…而是…」腔 | 「我要的不是钱，而是个说法。」 | 一场戏最多一次 |
| 金句收尾 | 每场最后一句都是格言腔 | 删掉，用动作或半句话收 |
| 升华腔 | 「这一夜，所有人都长大了。」 | 旁白不许替观众总结 |
| 伪格言 | 「老话说，人心隔肚皮。」 | 除非角色真爱引老话，否则删 |

自检：任意一场台词行命中 ≥2 种 → 回改。**不建机检门**（台词以剧本原文为准，机检无原文可对）。

## 四、尾钩四型（多集项目）

| 型 | 定义 | 判据 | 例 |
|---|---|---|---|
| 信息钩 | 抛出此前不知道的事实/身份/线索 | 观众收到新事实 | 「你弟弟的单子，不是意外」 |
| 危机钩 | 把主角架到新的危险/压迫 | 下集处境更差或被追击 | 「同一张重单，砸给全站」 |
| 选择钩 | 两难摆到主角/观众面前 | 下集必须回应选哪边 | 「U 盘悬在两人之间——拿，还是不拿？」 |
| 态度钩 | 主角对世界亮出态度宣言 | 下集围绕态度付代价/收回报 | 「明天发布会，我自己说」 |

三条铁律：① 每集必须有尾钩（季终集除外）；② 尾钩必须携带新信息（复用旧钩 = 第三集疲劳）；③ **下集前 30 秒必须回收**，回收写进分集结构表「下集回收」列，格式 `E5 0:10 接 28 斤单全景`。

## 五、筹码变化账

四类：**信息 / 关系 / 资源 / 力量**。

- 每集至少一类非空；四条都没变 = 水集。
- 类型必须在四类枚举内（写飞了账就废）。
- 「只压必给」：憋屈集的下一集必须给痛快/暖的回报（语义项，人工）。

与伏笔表分工：筹码账记主角状态增减；伏笔表记具体物/信息的埋设—回收。软肋物破损同时记两表，各记各的字段。

## 六、分集结构表（7 列，opt-in）

```markdown
| 集 | 核心事件 | 筹码类型 | 筹码内容 | 尾钩类型 | 尾钩内容 | 下集回收 |
|---|---|---|---|---|---|---|
| 1 | 地铁送单被系统判超速，当众反杀 | 信息 | 申诉方法论＋线索 | 信息钩 | 匿名短信「你弟弟的单子，不是意外」 | E2 0:08 回拨顾客电话 |
```

N5/N6：筹码类型/尾钩类型枚举外 = ERROR；内容为空 = WARN；回收为空或不含集号 = WARN；表解析 0 行 = ERROR。**未传表 = 跳过，跳过不是通过。**

## 七、三视角审稿（自检）

观众视角（没看懂/想划走/记不住人）· 类型视角（这个类型期待什么）· 类型反例视角（最烂的片子会怎么拍这一场）。
每视角至少 2 个真问题；三视角全好评 → 可疑，回类型反例视角重审；作者自评至少一处不满意。
**等级只代表剧本层潜力，不预测成片质量，不作交付硬门。**

## 八、本包机检范围

尾钩类型/内容/回收集号、筹码类型/内容 → 机检；「新不新」「还得好不好」「只压必给」→ 人工。
本包不做分集结构表解析（那是多集台账层）；JSON 里可写 `tail_hook` / `chips` 先查枚举与空值。
