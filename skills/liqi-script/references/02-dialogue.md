# 台词：去机械感与七维诊断

> 同步来源：`liqi-video-forge v6.19.8` → `references/叙事层_剧本门控与台词.md`（二、三节）
> 本层是台词的**唯一可改阶段**；定稿即冻结，进 Step 2 之后一字不差。

## 一、去 AI 机械感三大法则

1. **角色压力与筹码追踪**：对话不是客气问答，是权力/信息/立场的隐秘博弈。每句必须有一方施压、另一方掩饰或反击；杜绝无立场的解释性闲聊。
2. **承重场景识别**：承重戏（生死抉择、秘密揭穿、师徒死斗）投入最高视听与微表情密度；过场戏果断省略。不要在过场戏上花承重戏的预算。
3. **冰山对白（反解释性）**：严禁角色向已经知情的同伴解释世界观设定。双方已知信息一律转入潜台词、眼神与道具动作。

## 二、台词七维诊断

每句全量过一遍；命中致命病灶必须重写。

| 维度 | 致命病灶 | 重构方向 |
|---|---|---|
| 1 角色辨识度 | 全员同一种文绉绉/书面化语调 | 语言指纹：粗人短句、书生引典留白、杀手惜字如金 |
| 2 潜台词层级 | 0 层直白陈述（「我很愤怒，我要杀了你」） | 1~3 层潜台词（「茶凉了，换杯热的再上路吧」） |
| 3 冲突推进力 | 礼貌寒暄、无意义重复、被动附和 | 每句产生信息/立场/情绪/行动**变动** |
| 4 类型语感 | 古装戏冒出「经济损失/逻辑漏洞」 | 古风简炼、港派生猛、市井接地气 |
| 5 信息效率 | 自报家门向观众交代背景 | 双方已知信息删去，转动作与微表情 |
| 6 节奏与音乐性 | 连续 30 字以上无气口大长句 | 单句 6~18 字；金句预留 0.5s 停顿 |
| 7 金句潜力 | 通篇大白话，无记忆点 | 提炼哲理/反常识/极度反差的高光句 |

**语言三件套**（主要角色每人三件，缺一件辨识度不达标）：口癖句（全集 ≤1 句，出现 ≤2 次）、句长档（短/中/长，不漂移）、对主角称呼（称呼变化 = 关系状态信号，要登记）。

## 三、三段式重构契约

改写建议必须给**不少于 3 条具体维度依据**：

```text
原台词：「…」
改写建议：「…」
为什么这么改：
  1. 【维度X 辨识度/语感】：…
  2. 【维度Y 潜台词/信息效率】：…
  3. 【维度Z 节奏与视听留白】：…
```

不给依据的改写是感觉，会被打回。

## 四、长度与节奏

- 单句基准 **6~18 字**；关键金句前留 0.5s 停顿发酵。
- **>24 字**：建议拆镜（正反打/过肩/反应镜头拆 2~3 镜，每镜 ≤18 字）。
- **>30 字**：必须拆镜（本包直接 ERROR）。
- 一句话一个意思；对白别写长从句，像真人说话，短句为主。
- 情绪用动作呈现：紧张=步伐僵硬/攥拳/低头；心动=瞳孔微睁/嘴角微扬；不直接写「他很紧张」。

## 五、本包怎么用七维

- 每句在 JSON 里写 `functions` 数组，枚举：角色辨识度 / 潜台词层级 / 冲突推进力 / 类型语感 / 信息效率 / 节奏与音乐性 / 金句潜力。
- 标了「潜台词层级」就必须写 `subtext`；不写直接 ERROR。
- 一句承担 >3 个功能会报警——不是越多越好，是可能过载。
- 六模式（排比三连、「不是…而是…」腔、金句收尾、升华腔、伪格言、开头重复）见 `05-deai-and-hooks.md`；命中 ≥2 回改，不建机检门。

**本包不替你改台词。** 只诊断结构/时长/用词；改字是作者的事，冻结后一字不差。
