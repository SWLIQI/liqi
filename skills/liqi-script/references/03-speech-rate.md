# 语速与排期

> 同步来源：`liqi-video-forge v6.19.8` → `references/叙事层_剧本门控与台词.md`（第四节）
> 这一节只解决一件事：这句台词念不念得完、这样排挤不挤。

## 一、理论档（配音员能做到的范围）

| 档位 | 语速 | 适用 |
|---|---|---|
| 标准语速 | 3.5 ~ 5 字/秒 | 普通对白、文戏推进、信息交代 |
| 慢速重音 | < 3.5 字/秒 | 金句宣言、临终遗言、情绪顶点、威慑（一字一顿） |
| 快速爆发 | > 5 字/秒 | 情绪失控、争吵、逼问（连续 >5 字/秒不得超过 3 秒） |
| 物理红线 | > 6.5 字/秒 | 物理不可实现，必须拆句 |

## 二、实测校准（排期用这一张）

主包实测基准：**96 条中文配音，1305 字 / 503.8 秒**。原始记录在主包 `叙事层_剧本门控与台词.md` §四，不随本包；本文件只带结论口径。

- 全片均值 **2.59 字/秒**，最快 **3.79 字/秒**，**4.0 以上 0 句**。

| 类型 | 实测语速 | 说明 |
|---|---|---|
| 说书人 / 旁白（慢板） | 3.6 ~ 3.8 | 字头重、句尾拖腔 |
| 普通对白 | 3.4 ~ 3.6 | 文戏推进 |
| 情绪重拍 | 2.6 ~ 3.0 | 临终、威慑、哭腔、停顿多 |
| 校验上限 | **3.2** | 排期超过这个数要警惕 |

**关系**：理论档回答「念不念得完」，实测表回答「这样排好不好听、挤不挤」。
排期用实测表，物理红线仍用 6.5。某片按 3.5~5 排完，32 句超标、9 句 >6 字/秒，整片听感是赶；按均值 2.59、上限 3.2 重排后余裕正常。

## 三、速算

```
口播时长 = 可发音字符数 ÷ 语速
对白总时长 = 口播时长 + 标点停顿 + 情绪停顿 + 金句余韵
最短有效 = 字数 ÷ 5      最长有效 = 字数 ÷ 3.5
```

**字数口径**：只数可发音字符（汉字、数字、外文字母）；标点不计入语速公式，另按停顿预算：
顿号/逗号 ≈ 0.1–0.3s，句号/感叹/问号 ≈ 0.3–0.6s。

## 四、六步自检

拆句（逗号/句号/感叹/问号）→ 计数（只数可发音字符）→ 停顿预算 → 套档 → 速算 → 判定。

## 五、判定五档

| 判定 | 条件 | 处置 |
|---|---|---|
| ✅ 合规 | 3.5~5 字/秒，且单句 ≤24 字 | 通过 |
| ✅ 排期舒适（推荐） | 2.6~3.6 字/秒（实测校准） | 通过，听感有余裕 |
| ⚠️ 超长句（P1） | 单句 >24 字 | **建议**拆镜：正反打/过肩/反应镜头拆 2~3 镜，每镜 ≤18 字（>30 字才 ERROR） |
| ⚠️ 金句缺发酵（P2） | 金句后无 0.3~0.8s 反应镜头 | 补微表情或旁观者反应 |
| 🔴 超时（P0） | 台词所需时长超该镜预算 | 重构台词或调整镜次，**严禁超镜时长** |

## 六、字数速查

| 字数 | 所需时长 | 判定 |
|---|---|---|
| ≤8 | 1.6–2.3s | ✅ 短句，适合金句/威慑 |
| 10 | 2.0–2.9s | ✅ 标准句 |
| 14 | 2.8–4.0s | ✅ 标准句 |
| 18 | 3.6–5.1s | ✅ 上限附近（建议拆） |
| 24 | 4.8–6.9s | ⚠️ 触发拆镜阈值 |
| 30 | 6.0–8.6s | 🔴 必须拆 2–3 镜 |

## 七、拆镜示范

```text
原台词（33 字）：「三年前你杀我师父灭我师门占我武馆今日我陈烬归来倒要看看谁该灭门偿命」

镜1（近景·正面）：「三年前，你杀我师父，灭我师门，占我武馆。」16字 ≈3.2–4.6s + 4处停顿≈0.6s
镜2（特写·眼神）：「今日我陈烬归来。」7字 ≈1.4–2.0s，金句前预留 0.3s
镜3（近景·步步逼近）：「我倒要看看——谁，该灭门偿命！」11字 ≈2.2–3.1s，结尾预留 0.5s 发酵
```

自检卡是内部 QC 附件，不写进提示词正文。

## 八、本包怎么实现

- 单句 `rate`：`slow` 2.8 / `normal` 3.5 / `fast` 5.0，或填 1–6.5 的数字（数字字符串如 `"3.5"` 也接受）。
- 硬闸：>6.5 直接 ERROR；`fast` 且单句 >3 秒 WARN。
- 全剧口播均值 **>3.2 字/秒** WARN（实测排期上限）。
- 单句 >24 字 WARN；>30 字 ERROR。
- 标点停顿：逗号/顿号 0.2s，句末 0.4s；可用 `pause_after` 追加金句余韵。
- 场景预算 = 台词总时长 + `action_time`；超出 `duration` 直接 ERROR。
