# VO / OS 与方言标注

> 同步来源：`liqi-video-forge v6.19.8` → `references/方言与旁白规程.md`
> 方言是参考表，不设门禁；VO/OS 是规则，交付前必过。

## 一、三个概念先分清

| 记号 | 是什么 | 说话者在画面里 | 锁口型 |
|---|---|---|---|
| 对白 | 角色当场开口 | 在 | **锁** |
| VO（画外旁白/心声） | 角色内心独白，或第三方讲述 | 可能在（心声） | **不锁** |
| OS（画外音） | 说话者在别处/未入画 | **不在** | **不锁** |

剧本 JSON 里用 `type: "对白" | "VO" | "OS"` 标；`旁白` 只能用于 VO/OS。

## 二、容量红线（赛道①/②/④）

| 项 | 上限 | 为什么 |
|---|---|---|
| VO + OS 镜数占比 | ≤30% | 画外声是结构件，占比一高观众从「看」变成「听」 |
| VO 口播量 | 60~80 字/分钟 | 超过就从点睛变念稿 |

赛道③解说叙事类豁免容量口径（全片旁白），改用解说语速档 3.8~5.0（金句 3~3.6），仍守 6.5 物理硬闸。
本包先按**行占比**报警（镜头级占比需在分镜层复核），VO 口播量按场景时长折算。

## 三、OS 不复述画面

> 画外声讲因果/规律/内心；画面给证据/场景/过程。

判据：删掉画外声，画面信息量不减少；删掉画面，画外声信息量不减少。两边都要独立成立，且不互相复述。

| 违规 | 例 |
|---|---|
| 复述字幕 | 画面打大字「康熙二十三年」，旁白也说「康熙二十三年……」 |
| 复述动作 | 画面正在篙点船帮，旁白说「他把篙点向船帮」 |
| 正确 | 画面给磨白的黄铜扣特写，旁白说「这箱子，她抱了十二年」 |

## 四、三条硬线（违反即阻断）

1. **标了画外音/心声/旁白的行，不得同时要求该角色口型动作。** 一边说不锁、一边写「嘴型同步」= 自相矛盾。
2. **画外声必须写进「对白：」行并带括注标记，不得塞进声音设计四层混音。** 四层混音是氛围层，不是台词层。
3. **`<>` 音效 / `{}` 台词 / `()` 音乐 / `【】` 字幕 只能出现在声音段与台词位，不得混进画面描述。**

## 五、方言标注（参考，不设门禁）

- 方言是**语气位的音质维**，不新增 `方言：` 字段、不写进画面描述。
- 强度：轻（默认，带点 XX 味）/ 中（XX 话口音，尾音上扬）/ 纯方言（用户明确指定才用）。
- **只改听感，不改一个字**；不得为「更像方言」改台词用字。
- 禁混相邻地区（西安≠兰州、成都≠重庆、广州≠香港）；禁播音腔、相声腔、导游播报腔。
- 方言总控 12 条以当地年轻人真实日常口语为基准，优先地域听感、其次清晰度；不做夸张模仿。

## 六、本包机检

- `type` 枚举；`旁白` 只能 VO/OS。
- VO/OS 且 `lipsync=true` → ERROR；对白 `lipsync=false` → WARN。
- VO/OS 行占比 >30% → WARN（行占比，非镜数）。
- VO 口播 >80 字/分钟 → WARN。
- 声画信息差、方言听感、口型同步质量：**需人工**。
