# 风格锚 · 皮影 2D（L1 · 十节）

风格 id：shadow-puppet-2d　｜　轨道：平面工艺轨　｜　维度：2D　｜　status：已落值

## 零、文件头

一句话定位：本文件是 liqi Step 2「全片统一风格锚（九段）」在**单层半透明皮料皮影**这套风格上的落值。数值事实源是项目级 style-registry.json 的同名条目，本文件不另立数值。

适用判定：画面主体是牛皮雕镂的半透明皮影人形，靠单一背光透出暖黄；人物按肩 / 肘 / 腕 / 髋 / 膝 / 颈分件连接，动效是关节摆动不是肌肉收缩；画面被一块素色幕布限定，上下左右都是幕布。用户给了皮影设定图、或明确要求皮影 / 驴皮影 / 非遗皮影戏风格时选本风格。

边界声明：与剪纸的边界在「透光」——剪纸是不透光实体色块，皮影是半透明皮料对背光有反应，出现不透光红纸即串轨。与写实轨的边界在「层与关节」——写实轨要皮肤与体积，皮影是单层皮料加分件关节，侧看成绝对纸片。与定格木偶轨的边界在「厚度」——定格是黏土实体有微缩景深，皮影是皮料平面贴幕，禁止任何厚度词。与水墨的边界在「光」——水墨是均匀平光无光源逻辑，皮影的全部质感来自背光，无背光不成影。

### 措辞纪律表

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 皮影很立体 | 单层皮料贴幕，无厚度 | 立体与厚度把皮影变成纸雕或定格 |
| 灵动的眼神 | 雕线眉眼随头件摆动 | 眼神与表情肌肉是真人词汇，皮影脸是雕的 |
| 人物走向深处 | 平行于幕布进退 | 纵深运动会破坏幕布平面，皮影没有第三维 |
| 温暖的灯光照亮 | 唯一幕后背光，透光处最亮 | 方向光让皮影失去全部质感来源 |
| 塑料片 / 亚克力 / 玻璃 | 牛皮雕镂，哑光皮料 | 工业材料的透光是均匀冷白，与牛皮的暖黄透光完全两套逻辑，一换就成灯箱广告 |
| 幕布上的影子 / 手影 | 皮料本身贴在幕布上，是有颜色的透光彩绘 | 影子是黑的，皮影是彩绘皮料透光；写成影子模型会把人形压成纯黑剪影，雕纹全丢 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。只写一句会导致色域漂移——尤其朱砂那一处重音色，漏写配色句时模型会把它撒到每个冠珠与令旗上。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 95 词（按校验器空白分词口径实测），在全库锚中排第 3（按词数降序），偏长——**加词前必须先想清楚删哪一句**。

## 三、色值表

| 用途 | HEX | 说明 |
|---|---|---|
| 皮料透光部 | #E8C97A | 牛皮透背光的暖黄，主色 |
| 幕布基底 | #F0E6CF | 素色幕布，画面未被人形占据的部分 |
| 皮料实部 | #2B2118 | 未雕镂的牛皮本色，近黑的深褐 |
| 重音色 / 朱砂 | #A63A2E | 唇、冠珠、令旗，一镜只许一处 |
| 雕纹透光 | #F6E3B8 | 密雕处的亮黄，比皮料主色亮一档 |

色彩预算纪律：每镜只声明一个唯一重音色（朱砂 #A63A2E），其余压进暖黄色阶（#E8C97A 与 #F6E3B8）加深褐实部。不声明色彩预算，模型会自发补饱和度，冷色与杂色立刻进场。

**本表无「肤色」项（不是漏项）**：皮影人物的「皮肤」就是皮料本身，透光即亮、实部即暗，`#F6E3B8` 的雕纹透光已经承担了这一格。另立一格肤色等于给皮料加一层不透明涂层，一加就不透光，皮影的本体失效。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定正面（正对幕布）、缓慢推近（保持画面平行幕布）、垂直升降取景 |
| 少量 | 换景重取景（等同皮影戏的「换布景」，全片不超过三次） |
| 避免 | 横移、环绕、荷兰角、任何让摄影机斜对幕布的运镜 |

每段只锁一个主运镜。皮影的镜头语法是「正面看戏」——摄影机永远正对（或等比推近）幕布，斜一秒，皮影的平面本体就暴露成贴片。

## 五、材质与可见性预算

| 项 | 落值 |
|---|---|
| 主花费 | 雕镂纹样的透光对比（密雕亮、素处暗）与关节分件的清晰度 |
| 次花费 | 幕布织物的均匀质感与构件剪影 |
| 省 | 群像（压成深褐剪影群，只以轮廓与冠饰区分）、幕布后的空间（完全不可见） |
| 可见性 | 群像只写数量与轮廓动态；一镜同框人形不超过三个（超过则分件重叠读不出） |
| 禁 | 体积光、渐变、3D、景深、真实皮肤、布料垂坠、方向光、任何厚度词 |

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| 变纸雕或定格木偶 | 写了厚度、立体、微缩；或给了带侧面的参考图 | 压句第一句钉死 single-layer translucent shadow puppet；参考图必须正面贴幕 |
| 关节处断裂错位 | 分件连接没写；或一镜给了超过两个关节的大幅摆动 | 六处关节逐一点名；一镜只动一个主关节 |
| 皮料变不透光红纸（串剪纸） | 用了红纸词汇或高饱和红色 | 主色锁牛皮透光暖黄；皮影的红只能是朱砂点缀 |
| 背光丢失变顶光 | 写了舞台灯、顶光、照亮 | 唯一合法光是幕后背光，写进压句 |
| 人物斜对幕布出现透视 | 运镜写了环绕斜移；或人物写了走向深处 | 运镜只用固定与推近；位移一律平行于幕布 |
| 变成真人侧脸 | 脸写了五官细节与表情肌肉 | 脸是侧面镂空雕，眉眼是雕线；表情靠头件角度与冠饰摆动 |
| 一镜塞进多个人形 | 群像没管 | 同框人形上限三个，其余写成幕侧剪影或画外声 |
| 幕布长出褶皱与投影 | 写了幕布纹理、布面不平、幕布被风吹 | 幕布是**均匀素色的发光面**，不是织物；有褶皱就有明暗，有明暗就有体积 |
| 透光对比消失，整片变均匀色块 | 没写密雕与素处的对比，只给了主色 | 雕纹透光 #F6E3B8 与实部 #2B2118 **必须同框出现**；只有主色没有对比，皮影就退化成一块黄纸 |
| 皮料漂成塑料冷白 | 写了塑料、亚克力、灯箱、玻璃 | 牛皮是暖黄哑光，透光带琥珀色；工业材料的透光是冷白均匀，两者一眼可辨 |

## 七、声音签名（中英双轨）

投中文面（Seedance 2.5 / 国内面）直接取中文版，不要拿英文版现场翻译。

**中文版（2.5 面 / 国内面用）**：

```text
整体声音签名：环境层——幕布后的锣鼓架子与市井远声；
动作层——皮影关节的木头磕碰、皮料抖动的脆响、签杆点的轻击；
呼吸层——默认无（平面人形无胸腔起伏，不许补呼吸）；
配乐层——默认有：戏曲性锣鼓点加一件主奏乐器，速度与编制写死，全片不换。
```

**英文版（H3 面用）**：

```text
overall_soundscape:
Backstage gong-and-drum frame and a distant market murmur in the ambient bed; the dry wooden knock of jointed limbs, the crisp flutter of hide and the light tap of control rods on every movement. No breathing layer — flat hide figures have no chest rise.

non_diegetic_music:
Folk-opera percussion plus one lead instrument (banhu or suona), fixed tempo and fixed instrumentation, unchanged for the whole film.
```

配乐中文写法（本风格默认有配乐，别写成 N/A）：`一段戏曲锣鼓点，板胡主奏，速度中板，全片不换编制。`

**配乐纪律（本风格与多数风格相反）**：皮影的锣鼓不是气氛选项，是**这门艺术的本体**——皮影戏本来就靠后台锣鼓与唱腔推叙事。所以配乐层默认**有**，且乐器与速度要在全片第一镜就写死；中途换编制等于换了一台戏，观众会读成两条片子。

**呼吸层纪律**：平面工艺人形没有胸腔起伏，**呼吸层默认写「无」，不是留空**——留空会被补呼吸，呼吸又会诱导模型给皮影加体积。

**动作层是本风格的辨识度所在**：木头磕碰声只在**关节动作镜**写（行走、作揖、打斗）；人形静止或纯对话镜不要堆满磕碰声，会像木偶戏而不是皮影。

## 八、参考图集与角色锁定

本风格无专属参考图集，角色锁定走 `<Subject N>` 通用写法。出角色资产图时的版式按 liqi 非写实适配：视图改侧影 / 正面 / 关节分解三视图（分解视图把六处关节的分件画开，这是皮影资产的核心），材质写半透光皮料，相机写平面化，头身比落 4 到 4.5，身高线改工艺尺寸线。投喂铁律照旧：任何镜头都要带一张头部裁片作身份锚。

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

| 污染词 | 替换词 | 为什么 |
|---|---|---|
| 立体 / 有厚度 | 单层皮料贴幕，无厚度 | 厚度词把皮影推出平面 |
| 灵动的眼神 / 表情 | 雕线眉眼随头件摆动 | 表情肌肉是真人词汇 |
| 走向深处 / 纵深感 | 平行于幕布进退 | 纵深破坏幕布平面 |
| 舞台灯光照亮 | 唯一幕后背光 | 方向光让皮影失去质感来源 |
| 红红火火一片红 | 牛皮透光暖黄为底，朱砂只一处 | 满红直接串去剪纸 |
| 幕布纹理 / 布料褶皱 | 均匀素色发光面 | 幕布一旦有纹理就有明暗，明暗即体积，皮影的平面本体当场失效 |
| 投影 / 影子投射在幕上 | 皮料本身贴在幕上透光 | 皮影是**透光**的彩绘皮料，不是**挡光**的影子；写成投影，人形会被压成纯黑剪影 |
| 丝滑 / 流畅 / 运动模糊 | 关节摆动，一拍一个姿态 | 连续插值会让分件之间出现拉伸与变形，关节分件是皮影的结构本体 |

### 9.2 互斥风格

与以下 id 互斥（与 L0 excludes 双向一致）：photoreal-pbr、documentary-live-action、guofeng-cine-3d、urban-folk-filmstill、gothic-puppet、ink-wash-2d、npr-celshaded-3d、stylized-pixar-3d、celshade-guoman-2d、anime-2d、webtoon-2d，以及同轨的 papercut-2d、guochao-2d、nianhua-2d。

- 混剪纸：红纸不透光与皮影透光直接矛盾，两个主色互相污染；
- 混定格木偶：黏土厚度与微缩景深让皮料平面变成实体摄影；
- 混写实轨：皮肤毛孔与体积光把暖黄透光变成棚拍人像；
- 混水墨：均匀平光无光源逻辑，皮影的透光对比全部作废。
