# 汉画像石·拓片剪影 风格锚（平面工艺轨 × 汉代石刻专项）

本文件是 Step 2「全片统一风格锚（九段）」在**汉画像石（石刻拓片）美学**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字不要改**。

**适用判定**：汉代画像石的拓片质感——石面为底、车马出行/宴饮/狩猎/神话（朱雀青龙）的**剪影平涂**、
减地平钡的分层轮廓、拓片的黑白反转关系与石纹肌理、带状横卷构图。用户给的是汉代 /
石刻 / 拓片 / 古拙神话叙事参照时，锁③ 风格轨道选**平面工艺轨**，风格 id 取 `han-relief-rubbing`。

**边界声明**：

- 与剪纸（`papercut-2d`）：同为剪影平涂，**载体与反转关系不同**——剪纸是红纸正形负地（镂空）；
  拓片是墨色正形石底白纹（或反转），带石纹颗粒与捶拓的晕边。
- 与皮影（`shadow-puppet-2d`）：皮影有**透光与关节分件**；画像石是凿刻的实体剪影，无透光、
  部件连体不分件。
- 与民俗年画（`nianhua-2d`）：年画是多色套版带线版；画像石是单色拓印、无线版、以形轮廓叙事。
- 与水墨淡彩（`ink-wash-2d`）：水墨有笔触浓淡；拓片是均匀的拓墨与石面肌理，无笔性。

> **竖屏适配（C26）**：汉画像石的带状横卷构图依赖横幅——**签名依赖横幅构图，须附竖幅改写行**。
> 竖幅改写：带状横卷改「上下两层分栏」（上栏羽人神兽、下栏车马主叙事），石纹底纵向贯通——
> 是改写不是放弃。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|

| ② 配色与色域 | 拓片两值＋一色限额：墨黑剪影＋纸白（或石灰）底，朱砂作为唯一限额重音（印鉴位/主神兽）；禁彩色、禁渐变、禁金 |
| ③ 运动签名 | 24fps，**石刻的静与带的行进**：人物车马按横卷带状行进（车轮转、马蹄扬、旌旗猎），姿态是凿刻的定格程式；运镜以横向平移为主；禁快切、禁环绕 |
| ④ 角色锁定 | 走 `<Subject N>`：头身比 5.5-6.5（汉代程式化比例，古拙取势）；人物是剪影侧脸正身（正侧面复合视角），衣冠带籍贯程式（进贤冠、帻）；跨镜冠式不变 |

| ⑥ 道具锁定 | 走 `<Subject N>`：车马形制（轺车/轩车）、弩机、酒樽写死，皆为剪影程式 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Han-dynasty stone-relief rubbing: solid ink silhouette figures carved in flat layered profile, the stone grain showing through, chisel marks, mica flecks and fine cracks, rubbed-ink halos at contour edges. Processions of carriages and horses, winged immortals and guardian beasts in archaic Han formulas, banded frieze composition. Two values only, rubbed black and paper white, with cinnabar reserved for one seal-red accent. No perspective depth, no lighting, no color.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
two-value rubbing — ink black on paper white, cinnabar seal-red as the single accent
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `papercut silhouette / 红纸` | `stone-relief rubbing` | 载体与反转关系不同 |
| `3D relief carving / 立体浮雕` | `flat layered profile` | 立体化是本锚反面（拓片是平面拓印） |
| `colorful fresco / 彩绘` | `two values only` | 画像石的本体是拓片两值 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 69 词，全库最长档——预算紧先删第三句（Processions 一句，叙事程式由正文逐镜写），删后约 57 词；再紧可删第二句的石纹列举（保留 chisel marks 一项），约 50 词。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅汉画像石拓片质感的画面：均匀拓墨的剪影正形，石面肌理透出——凿痕、云母星点与细裂纹，轮廓边缘有捶拓晕。车马出行、羽人与四神都是汉代凿刻的古拙程式，带状横卷构图。只有拓墨与纸白两值，朱砂只做唯一限额重音。没有透视景深，没有光照，没有彩色。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：拓墨黑与纸白两值，朱砂只做每镜唯一重音（印鉴位或主神兽）。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「剪纸」「红纸镂空」 | 删，写「石刻拓片」 | 反串剪纸档 |
| 「立体浮雕」「石雕特写」 | 删，写「平面拓印」 | 拓片是平面不是器物 |
| 「彩色壁画」「汉墓彩绘」 | 删，写「拓片两值」 | 彩绘不是拓片 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（拓片两值、剪影程式、石纹肌理、带状构图）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把剪影推成照片级石雕特写**，所以「平面拓印」与「石纹肌理」在国内面**不许省略**。

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 跑成剪纸 | 写了红纸、镂空、窗花 | 锁「石刻拓片」「石纹肌理」；负面词带剪纸红纸 |
| 立体浮雕化 | 写了 3D、深度凿刻特写 | 「平面拓印」锁死；负面词带立体浮雕 |
| 彩色混入 | 写了彩绘、壁画 | 两值锁死；朱砂全片限一处 |
| 透视景深出现 | 写了远近层次 | 带状分层构图锁死；拓片没有透视 |
| 石纹变噪点 | 肌理写成颗粒噪点 | 「凿痕、云母星点、裂纹」三项具名 |
| 姿态过于灵活 | 写了大幅肢体动作 | 凿刻定格程式——动在车马旌旗不在人 |
| H3 正文混中文 | 压句或叙事段夹中文 | 压句纯英文；跑 `check_prompt_h3.mjs` |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「立体化」与「彩色化」两侧的词**，保留拓片两值与凿刻程式。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 3D relief / 立体石雕 | flat layered profile rubbing | 拓片是平面 |
| papercut / 红纸镂空 | stone-grain rubbing | 反串剪纸档 |
| colorful mural / 彩绘壁画 | two values only | 彩绘不是拓片 |
| depth / 透视远近 | banded frieze layers | 带状分层不是透视 |
| noise grain / 噪点 | chisel marks, mica flecks, cracks | 肌理要具名不抽象 |

### 9.2 互斥风格

`papercut-2d`（红纸镂空 vs 石拓剪影，载体与反转关系互斥）、`shadow-puppet-2d`（透光分件 vs 实体连体）、
`nianhua-2d`（多色套版 vs 单色拓印）、`ink-wash-2d`（笔性 vs 凿性）。
