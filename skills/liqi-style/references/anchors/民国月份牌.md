# 民国月份牌画报 风格锚（手绘轨 × 民国题材专项）

本文件是 Step 2「全片统一风格锚（九段）」在**民国月份牌广告画（calendar poster）质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：月份牌广告画的擦笔水彩质感——炭精擦笔打底的柔和明暗、半透明水彩罩色、
旗袍女性的程式化甜美、商业海报式的构图（人物大半身 + 边框 + 品名牌）、做旧的纸面与轻微泛黄。
用户给的是民国题材 / 画报感 / 老上海参照时，锁③ 风格轨道选**手绘轨**，风格 id 取 `republic-calendar-poster`。

**边界声明**：

- 与民俗年画（`nianhua-2d`）：年画是**木版套色**（平面色块、无明暗、粗犷边线）；月份牌是**擦笔水彩**
  （柔和明暗、透明罩色、细笔）。工艺层完全不同。
- 与水墨淡彩（`ink-wash-2d`）：水墨是宣纸笔墨与留白；月份牌是机制纸擦笔 + 水彩满色。
- 与绘本水粉（`gouache-2d`）：绘本是现代童书水粉质感；月份牌是商业海报程式（人物类型化、边框、品名牌）。
- 与写实实拍各档（`documentary-live-action` 等）：本锚是**绘画**不是照片——擦笔的柔和过渡是手绘本体。

> **竖屏适配（C26）**：月份牌海报原生就是竖构图（人物大半身 + 上端横匾 + 下端品名牌），**竖屏是本锚的主场**。
> 横屏写法：边框改上下横条，品名牌移右下。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Republic-era Chinese calendar-poster painting: soft charcoal-and-gauze shading under translucent watercolor washes, no visible brush strokes, gently aged cream paper with yellowed edges. Stylized sweet figures in qipao robes, poster composition with decorative border. Muted bean-red and lake-green on warm cream, gold pattern accents. Almost still, only silk and gaze gently moving.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
bean-red and lake-green on aged cream paper, gold pattern accents, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `photorealistic vintage photo` | `painting ... charcoal-and-gauze shading` | 本锚是绘画不是老照片 |
| `bold woodblock outlines` | `no visible brush strokes, soft shading` | 反串年画档 |
| `vivid saturated colors` | `muted ... on aged cream paper` | 数码高饱和破坏做旧纸感 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 52 词，偏长档——预算紧可先删末句（Almost still 一句，静中有动由正文逐镜写），删后约 55 词。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅民国月份牌广告画质感的画面：炭精擦笔打底的柔和灰面，水彩薄罩两三层，过渡朦胧不见笔触，机制纸面轻微泛黄带岁月痕迹。程式化甜美的旗袍人物，海报式构图带装饰边框。泛黄纸底上的豆沙红与湖绿，金黄纹样做重音。画面静中有动，只有衣纹纱帘缓动与眼神微动。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：泛黄纸底，豆沙红或湖绿做每镜唯一重音，金黄只给纹样。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「老照片」「纪实影像」 | 删，写「月份牌广告画」 | 本锚是绘画，照片感是反面 |
| 「鲜艳」「浓郁」 | 删，写「泛黄纸底上的豆沙红」 | 高饱和破坏做旧感 |
| 「品名牌上写着…」 | 「画边框不写字」 | 可读文字铁律 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（擦笔水彩、泛黄纸面、程式化人物、静中有动）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把擦笔推成照片老滤镜**，所以「不见笔触的擦笔水彩」与「海报程式」在国内面**不许省略**。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 极缓推近、轻微缩放（海报呼吸感）、固定正观（海报正视角） |
| 少量 | 缓慢横移（边框扫过）、淡入淡出（画报翻页感） |
| 避免 | 快切、环绕、甩镜、手持、大角度俯仰 |

**每段只锁一个主运镜**；本锚的动在画面内（衣纹、纱帘、眼神），不在镜头。

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 跑成老照片滤镜 | 写了「老照片」「纪实」 | 锁「绘画」「擦笔水彩」；负面词带照片写实感 |
| 跑成年画木版感 | 写了粗边线、套色平涂 | 「不见笔触的柔和过渡」锁死；负面词带木版套色 |
| 色彩变数码鲜艳 | 写抽象的「鲜艳」 | 用具体色名（豆沙红 #B86A5A）锁；纸底泛黄不许省 |
| 人物动起来失真 | 写了大动作 | 「静中有动」锁死——动只给衣纹纱帘眼神 |
| 品名牌出现可读字 | 写了牌上的字 | 只画框不写字；可读文字铁律 |
| 纸面变干净数码 | 岁月痕没写 | 「轻微泛黄 + 边缘岁月痕」不许省 |
| H3 正文混中文 | 压句或服饰段夹中文 | 压句纯英文；跑 `check_prompt_h3.mjs` |

## 八、参考图集与角色锁定

本风格无专属参考图集，角色锁定走 `<Subject N>` 通用写法。角色条目必须写头身比（7-7.5），
并写死**旗袍纹样、盘发形制、眉眼程式**——月份牌的人物辨识度集中在这三处。
人物程式化程度写「像同一张海报里走出来的人」，跨集同一人物纹样不变。

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「照片化」与「木版化」两侧的词**，保留擦笔水彩与海报程式。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| vintage photo / 老照片 | painting, charcoal shading | 照片感是本锚反面 |
| bold outline / 套色平涂 | soft shading, no visible strokes | 反串年画档 |
| vivid saturated / 浓墨重彩 | muted on aged cream paper | 数码鲜艳破坏做旧 |
| ink splashes / 大写意 | delicate brush transition | 反串水墨档 |
| readable brand text | border frame only | 可读文字铁律 |

### 9.2 互斥风格

`nianhua-2d`（木版套色 vs 擦笔水彩，工艺层互斥）、`ink-wash-2d`（宣纸写意 vs 机制纸擦笔）、
`gouache-2d`（现代绘本水粉 vs 商业海报程式）、`documentary-live-action`（实拍 vs 绘画，负面词完全相反）。
