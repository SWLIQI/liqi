# Low-poly / 等距 3D 风格锚（三渲二轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**低多边形 / 等距 3D**这套具体风格上的落值（v5.42.0 批 3 首个），
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

**适用判定**：面块分明的低多边形几何、flat shading 无平滑法线、纯色面块无纹理贴图、
块状/体块化的人与物剪影、等距或弱透视的舞台感构图、干净的环境光。科幻太空、游戏化叙事、
科普演示、轻松几何感的 MG 3D 都吃这套。用户给的设定图是这类低面数质感时，锁③ 选**三渲二轨**，
风格 id 取 `lowpoly-iso-3d`。

**边界声明**：

- 与写实轨（`photoreal-pbr`）：写实轨要 PBR 材质、高精度皮肤布料与真实光影；本风格要**面块与纯色**——
  「细节少」是本体不是偷工。纹理词、材质细节词一律不写。
- 与三渲二同轨（`npr-celshaded-3d`）：三渲二是 3D 模型套卡通着色，允许多层次渐变与描边；
  本风格是**低面数硬边面块、无描边**。判据是面块密度：面少而硬 = low-poly，面平滑带描边 = 三渲二。
- 与风格化 3D（`stylized-pixar-3d`）：皮克斯式走多层软过渡与次表面质感；本风格禁平滑过渡，
  一切明暗按面块跳变。
- 与平面工艺轨（`papercut-2d` 等）：平面工艺是物理层叠的平面，本风格是 3D 空间里的立体渲染。
  「像剪纸的 3D」不是本风格，是串轨。

> ⚠️ **版权规避**：投喂词内不点名任何具体作品或游戏名（哪怕用户拿某款游戏当参照系）。
> 只写风格特征——低多边形、面块、等距。作品名只出现在本文档的说明层与对话里。

## 一、九段锚（中文，给 liqi 上游用）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 低多边形 3D 渲染风格：几何体由少量大面块拼成，每块纯色平涂，块与块之间是清晰的硬边折面；无平滑法线过渡、无纹理贴图、无噪点颗粒；人与物都是简化体块，剪影优先于细节 |
| ② 配色与色域 | 低饱和冷调为底（钢蓝、雾青、夜蓝），暖橙作全片唯一重音色；色块间明度差明显，靠色相区分而不是靠渐变；禁用真实材质色（金属拉丝、木纹）、禁荧光 |
| ③ 运动签名 | 24fps；运动干脆、路径清晰，允许 3D 环绕与转面（本风格是 3D，转面不崩）；无运动模糊——低面数渲染没有；无手持抖动 |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 5–6（块状人体档，肩臀做成几何体块）**；发型是几片体块、五官极简（点状眼或简单面片）、服装按大色块分区；跨镜体块数量与配色不变 |
| ⑤ 场景锁定 | 走 `<Subject N>`：建筑是几何体组合、地面是大色块面片、植被是锥体或球体的抽象形；**同场景跨镜地标的体块形状、颜色与相对位置必须一致** |
| ⑥ 道具锁定 | 走 `<Subject N>`：道具都是几何体拼装（箱体、圆柱、棱锥），入画方式必须写（手持 / 悬挂 / 置地）；不写材质纹理，只写形状与颜色 |
| ⑦ 光色基调 | 全局均匀环境光为主 + 一个方向光投柔和阴影；阴影是面块整块变深，不是渐变；不写体积光、辉光、反射 |
| ⑧ 声音签名 | 环境层：干净的低频空间底噪或按场景的极简环境声；动作层：轻快的点状音效（弹跳、滑动、放置）；呼吸层：不做拟真呼吸；配乐：轻电子或极简氛围，节奏点干净 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅生图模型与其他有 negative 字段的面可用：照片写实、PBR 材质、纹理细节、平滑曲面高模、毛发毛发细节、渐变过渡、景深虚化、可读文字、水印 logo |

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A low-poly 3D render with faceted flat-shaded geometry and crisp hard edges between polygons, matte solid colour surfaces without texture maps, simplified blocky silhouettes, soft uniform ambient light with one gentle shadow direction, clean isometric-leaning staging.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
muted cool-toned low-poly palette of ice white, steel blue and misty cyan, with warm orange as the single accent hue per frame
```

**三条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `detailed 3D render` / `high detail` | `low-poly ... faceted flat-shaded geometry` | 细节词把面块密度顶上去，直接变高模渲染；本风格的可辨识度就是面少 |
| `smooth shading` / `soft surface` | `crisp hard edges between polygons` | 平滑着色消灭面块边界，是本风格的第一崩点 |
| `realistic material` / `textured` | `matte solid colour surfaces without texture maps` | 纹理词把画面推向 PBR，方向整个反掉 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。
改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 36 词（按校验器空白分词口径实测），偏短，加词空间充足，但别堆否定串（扩散模型对否定基本不生效）。

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅低多边形 3D 渲染画面：几何体由少量大面块拼成，每块纯色平涂，块与块之间是清晰的硬边折面，无平滑过渡、无纹理贴图。造型是简化的块状剪影，环境光均匀柔和，只有一个方向的柔和阴影，构图带等距舞台感。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
低饱和冷调低多边形配色：冰白、钢蓝与雾青为主，暖橙作每帧唯一重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「精致的 3D」「高精度建模」 | 「低多边形」「面块简洁」 | 精度词与面块数成正比，是本风格头号崩点 |
| 「圆滑的表面」「柔和过渡」 | 「硬边折面」「无平滑过渡」 | 平滑词消灭面块边界 |
| 「不要纹理、不要细节」 | 删否定句，正面写「纯色平涂、剪影优先」 | 扩散模型对否定基本不生效 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（低多边形、硬边折面、纯色平涂）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台自带美化倾向会自动补细节**——它会把低面数渲成高模。
所以 2.2 那句「少量大面块」「无平滑过渡」在国内面**不许省略**。

## 三、色值表（风格级起点，项目级以 asset-registry 为准）

| 用途 | 色值 | 说明 |
|---|---|---|
| 冰白（底色） | #E8ECF2 | 亮部面块与背景基色，不纯白 |
| 钢蓝（主色） | #3E5C76 | 主体衣物与大型结构面块 |
| 暖橙（重音色） | #F2A65A | 全片唯一重音色：关键道具、信号灯、标识面块 |
| 雾青 | #A8C3D9 | 远景面块与中间层次 |
| 苔绿 | #6A8E7F | 植被与地面色块 |
| 夜蓝 | #22303F | 暗部面块与夜场基调，不是纯黑 |
| 亮面白 | #F7FAFC | 顶面高光面块 |
| 沙金 | #D9B779 | 地面、沙漠与暖调场景面块 |

**色彩预算纪律照旧**：每镜只声明一个唯一重音色，其余压成同色系。
低多边形对色彩预算更敏感——面块越少，每个颜色的权重越大，多一个重音就乱。

**暗部纪律**：暗部 = 面块整块换深色（夜蓝系），不是渐变、不是黑。
面块之间靠明度与色相跳变区分，一旦出现渐变过渡，面块感立刻消失。

**同步纪律**：本表与 L0 注册表的 `palette` 必须一致，改一处要同步另一处。
项目级具体角色的色值另存 `asset-registry.json`，不抄进本文件。

## 四、运镜池

| 类别 | 镜头 | 用法 |
|---|---|---|
| 主力 | 等距固定机位、缓慢环绕（本风格是 3D，环绕是签名运镜）、垂直升降、横向平移、缓慢推近 | 环绕时保持等距或弱透视，面块随视角翻转是本体特征 |
| 少量 | 俯冲入场、大范围拉升、穿越式镜头 | 段落转折点，一部片两三次 |
| 避免 | 手持晃动、甩镜、浅景深虚化、强透视广角 | 低面数几何吃不住真实摄影机的抖动与景深，一加就变「渲染故障」 |

**每段只锁一个主运镜**，与 liqi 的原语群纪律一致。
需要手持纪实感时换 `documentary-live-action`，不要在本轨硬写。

## 五、材质与可见性预算（低多边形版）

| 项 | 落值 |
|---|---|
| 主花费 | 体块剪影与面块折边——这套风格的辨识度全在「几笔几何就认得出是什么」 |
| 次花费 | 色块分区与方向光投影——用整块阴影交代体积 |
| 省 | 表面细节、纹理、边缘倒角、远景群像——全部压成纯色面块 |

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **变高模写实渲染** | 写了「精致、高精度、细节丰富」等词 | 压句钉死 `low-poly` 与 `faceted`；负面词带「高模、纹理细节」 |
| **面块边界消失，变平滑卡通 3D** | 写了「圆润、柔和过渡、smooth」 | 钉死 `crisp hard edges between polygons`；禁写平滑法线 |
| **变体素 / 像素 3D** | 写了「方块、体素、像素」 | 体块≠体素：写「几何体块拼装」，不写方块化 |
| **变 2.5D 剪纸贴片** | 等距构图写过头，模型放弃纵深 | 保留「3D 空间」「环绕运镜」词；等距只是倾向（`isometric-leaning`），不是锁死轴测 |
| **颜色发脏** | 重音色超过一个、或加了环境遮蔽 | 每镜只声明暖橙一个重音；阴影是整块换色，不叠 AO |
| **角色跨镜体块数量变化** | 没走 `<Subject N>` 锁体块 | 每镜内联锁定体块构成；首帧必带身份锚图 |
| **道具飘在半空** | 入画方式没写 | 道具入画方式必须写（手持 / 悬挂 / 置地） |

## 八、参考图集与角色锁定

本风格**无专属参考图集**。角色锁定走 `<Subject N>` 通用写法（见第一节第④段，头身比 5–6）。

投喂纪律照旧：**任何镜头都带一张左区头部近景当身份锚**；4 View 板只当 `<Subject N>` 定义，绝不当首帧。

**本风格特有的出图纪律**：

1. 4 View 板同样按低面数出图——参考图一旦是高模质感，后续所有镜都会被拉向写实。
2. 出图顺序照旧：4 View 锁定 → 专属道具表 → 人物使用道具图，跳序会串体块构成。
3. 等距构图的项目可在 4 View 补一张 45° 俯视全身图当构图锚。

## 九、去立体化与串轨防护

本风格**不需要去立体化**——它是 3D 轨，立体是本体。要防的是反向污染：**被写实化**。
不要跑任何为手绘轨写的 `dedupe_style.py` 词表（会误删构成风格本体的 3D 词），按 §9.1 手工清。

### 9.1 污染词与替换对（低多边形方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 精致渲染、高精度建模、细节丰富 | 低多边形、面块简洁 | 精度词顶高面块密度，头号崩点 |
| 圆滑表面、柔和过渡、smooth shading | 硬边折面、无平滑过渡 | 平滑词消灭面块边界 |
| 真实材质、木纹、金属拉丝、PBR | 纯色面块 | 纹理词把画面推向写实渲染 |
| 景深虚化、浅景深 | 全画面清晰 | 虚化要求真实光学，低面数几何配不上，一加就假 |
| 辉光、泛光、体积光 | 删除 | 光效词把渲染器推向写实管线 |
| 体素、像素、马赛克 | 几何体块拼装 | 体素是另一档粒度，混写变游戏素材 |

**保留不动的词**（这些在别的轨要删，在本轨是本体）：`3D`、`render`、`环绕`、`阴影`、`几何`。
