# 像素艺术·复古游戏 风格锚（卡通轨 × 像素专项 · 条件准入转正）

本文件是 Step 2「全片统一风格锚（九段）」在**像素艺术（pixel art）复古游戏质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。
本锚由路由表「条件准入」转正（v6.11.0 · C32 批 5），**稳定性维持「险（动态）」**——见约束清单。

**适用判定**：十六位机时代的像素游戏画面——写死的像素网格尺寸、有限的调色板、
抖动（dithering）过渡、帧动画的有限张数感、CRT 显示器的扫描线可选。用户给的是像素游戏 /
复古游戏 / 8-bit 叙事参照时，锁③ 风格轨道选**卡通轨**，风格 id 取 `pixel-2d`。

**转正评估（v6.11.0 · N19 批 5，用户方案既定槽位）**：像素风在 AI 视频生成的最大风险是
**动态帧间网格漂移**（模型把像素边画糊）。转正前提是把风险写成可执行的约束清单（下），
并把稳定性如实标「险（动态）」——**逐段渲染后必须过拉片复盘**，网格糊即返修，连续 3 段糊即停用本锚回退条件准入。

**边界声明**：

- 与极简几何扁平（`flat-minimal-2d`）：扁平是矢量无限分辨率；像素是**有限网格**（色块由可见方格构成）。
- 与合成器波（`synthwave-retro-2d`）：合成器波的 CRT 扫描线是叠加效果；像素的网格是画面本体。
- 与美式漫画（`us-comic-ink-2d`）：美漫是印刷排线；像素是栅格色块。
- 与所有手绘/工艺/实拍档：像素是数字栅格本体，与笔触、布纹、实拍全部互斥。

> **竖屏适配（C26）**：像素网格画幅无关——竖屏写法：游戏界面纵向分带（上 HUD、中画面、下状态栏）。
> **竖屏友好，无需改写行**。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 十六位机像素艺术：写死的像素网格（声明网格档：16×16 / 32×32 sprite），有限调色板（16-32 色），色块间用抖动（dithering）过渡，轮廓是阶梯状的硬像素边；可选 CRT 扫描线叠加（包首声明） |
| ② 配色与色域 | 有限调色板（声明色数）：复古游戏机的色域感（偏饱和但色数少），**每镜只声明一个唯一重音色**；禁渐变（渐变用抖动实现）、禁照片色、禁荧光 |
| ③ 运动签名 | 24fps，**帧动画的有限感**：动作按 8-12 帧/秒的游戏动画节奏（不是全平滑），角色移动是格子级位移；运镜只许整像素移动（滚动）与静止；禁平滑运镜、禁景深虚化 |
| ④ 角色锁定 | 走 `<Subject N>`：头身比不适用（sprite 档——声明 sprite 高度档 16/32/64px）；像素人物的发色、服装色、轮廓形写死到色板号；跨镜调色板不变 |
| ⑤ 场景锁定 | 走 `<Subject N>`：地牢、城镇、野外、飞船内景四类；场景由 tile 拼贴程式构成，同场景跨镜 tile 一致 |
| ⑥ 道具锁定 | 走 `<Subject N>`：剑、药水、钥匙，皆为 sprite 程式，形制写死 |
| ⑦ 光色基调 | 调色板分档明暗：亮暗靠色板档位切换（不是渐变光），发光件（火把/魔法）用闪烁帧表达；**禁渐变光、禁写实光影、禁环境光晕** |
| ⑧ 声音签名 | 环境层：芯片音乐底（chiptune pad）、CRT 哼鸣；动作层：8-bit 音效化的脚步、拾取、剑击（声音本身就是复古游戏的）；呼吸层：情绪点才写；配乐：chiptune，方波与噪声通道，循环乐句 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。其他面：平滑渐变、照片质感、高分辨率细节、写实光影、柔边抗锯齿、3D 渲染、可读文字（像素字也算可读文字，禁）、水印、多余人物、分身 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A 16-bit pixel-art game frame: a locked pixel grid with hard staircase edges, a limited 16-colour palette, dithering for all transitions, sprite-based characters moving in stepped game-animation frames. Palette-swatch lighting instead of gradients, torch and magic glows flickering frame by frame. Optional CRT scanline overlay. Crisp pixels everywhere, never smooth, never anti-aliased, never photoreal.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
limited retro palette, dithered transitions, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `smooth shading / 渐变` | `dithering for all transitions` | 渐变毁像素栅格 |
| `anti-aliased / 平滑` | `hard staircase edges ... crisp pixels` | 抗锯齿是本锚反面 |
| `photoreal detail` | `limited 16-colour palette` | 细节是反面 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 54 词，偏长档——预算紧先删末句（Crisp pixels 一句，由负面词锁）。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅十六位机像素艺术的画面：写死的像素网格带阶梯状硬边，十六色有限调色板，所有过渡用抖动（dithering）实现，角色按游戏帧动画的步进节奏移动。明暗靠色板档位切换而不是渐变，火把与魔法的发光用逐帧闪烁表达。可选 CRT 扫描线叠加。处处是锐利像素，没有平滑，没有抗锯齿，没有照片感。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：复古有限调色板，抖动过渡，每镜只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「平滑过渡」「柔边」 | 删，写「抖动过渡」「硬像素边」 | 平滑是本锚反面 |
| 「光影氛围」 | 删，写「色板档位明暗」 | 渐变光毁栅格 |
| 「高清」「细节丰富」 | 删，写「十六色调色板」 | 分辨率感是本体 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（像素网格、有限调色板、抖动过渡、步进帧动画）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台自动平滑与抗锯齿**，所以「硬像素边」与「抖动过渡」在国内面**不许省略**。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 静止、整像素滚动（横版卷轴） |

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 网格糊掉（最大风险） | 模型把像素边画糊 | 逐段拉片查网格；糊即返修；连续 3 段糊停用回退条件准入 |
| 平滑抗锯齿混入 | 写了柔边、渐变 | 「硬阶梯边＋抖动」锁死；负面词带平滑抗锯齿 |
| 渐变光照混入 | 写了光晕、氛围光 | 色板档位明暗锁死；负面词带渐变光 |
| 调色板漂移 | 跨段色数变多 | 调色板色数包首声明；跨镜不变 |
| 分辨率感丢失 | 细节写多 | 「sprite 高度档」声明（16/32/64px）锁死 |
| 帧动画变全平滑 | 动作写流畅 | 8-12 帧/秒步进节奏锁死 |
| H3 正文混中文 | 压句或色板段夹中文 | 压句纯英文；跑 `check_prompt_h3.mjs` |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「平滑化」与「细节化」两侧的词**，保留有限栅格与抖动程式。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| smooth / anti-aliased | hard staircase edges | 平滑是最大崩点 |
| gradient light / 光晕 | palette-swatch lighting | 渐变光毁栅格 |
| photoreal / 高清细节 | limited 16-colour palette | 分辨率感是本体 |
| cel shading / 赛璐璐 | dithered sprite shading | 反串动画档 |
| 3D render | flat pixel grid | 立体渲染反面 |

### 9.2 互斥风格

`flat-minimal-2d`（矢量无限分辨率 vs 有限栅格）、`synthwave-retro-2d`（扫描线叠加 vs 像素本体）、
`us-comic-ink-2d`（印刷排线 vs 栅格色块）、`shonen-hotblood-2d`（全平滑动画帧 vs 步进帧）。
