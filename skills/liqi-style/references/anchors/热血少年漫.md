# 热血少年漫 2D 风格锚（卡通轨 × 热血男频专项）

本文件是 Step 2「全片统一风格锚（九段）」在**热血少年漫画（shonen）2D 动画质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：少年漫动画的热血档——高饱和色块、硬边两段式阴影、速度线与集中线、
爆发帧与冲击波光效、夸张的透视（广角拳头冲镜头）、汗与伤痕的干净画法。
用户给的是男频打斗 / 热血逆袭题材参照时，锁③ 风格轨道选**卡通轨**，风格 id 取 `shonen-hotblood-2d`。

**边界声明**：

- 与日系 anime 通用档（`anime-2d`）：同一族但**情绪强度不同**——anime 是通用叙事档（薄色、克制）；
  热血档是**高饱和 + 速度线 + 爆发帧**的强化档，两档负面词方向不同（热血禁「素朴淡雅」）。
- 与暗黑二次元（`dark-anime-2d`）：暗黑是低照度悬疑向；热血是高调爆发向。明暗逻辑相反。
- 与美漫波普（`comic-popart-2d`）：波普是印刷网点与平涂图形化；热血是动画赛璐璐 + 光效。
- 与国漫赛璐璐（`celshade-guoman-2d`）：国漫美型档偏偶像叙事；热血档偏战斗演出，速度线与变形透视是本体。

> **竖屏适配（C26）**：热血签名里的「广角拳头冲镜头」天然偏竖向出拳，竖屏适配良好。
> 竖幅写法：速度线沿纵向收束（四角向中心），爆发帧的光从画面下方涌上。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 少年漫动画质感：干净数码勾线，硬边两段式赛璐璐阴影，高饱和平涂色块；速度线与集中线作为画面元素；爆发帧允许夸张变形透视（广角拳头冲、仰角咆哮） |
| ② 配色与色域 | 高饱和对战色：橙红与钴蓝的主角配色对撞，黄白高光；**每镜只声明一个唯一重音色**；禁灰暗低饱和、禁粉调、禁柔和过渡 |
| ③ 运动签名 | 24fps 战斗节奏：静止蓄力帧与爆发帧交替，速度线帧内表达而非运镜表达；每段只锁一个主运镜（冲镜头 / 环绕二选一）；禁连续甩镜 |
| ④ 角色锁定 | 走 `<Subject N>`：头身比 6.5-7（少年主力档）；发型写死（刺猬头 / 束发 / 发色即身份）；服装写战斗形制；伤痕与汗巾是角色记忆点，跨镜保留 |
| ⑤ 场景锁定 | 走 `<Subject N>`：道场、废墟、天台、竞技场四类；同场景跨镜地标一致；战斗破坏（裂地、扬尘）写「本段新增」，不回退 |
| ⑥ 道具锁定 | 走 `<Subject N>`：武器与护具形制写死；发光武器写「自体光 + 蓄力增亮」的明暗规则 |
| ⑦ 光色基调 | 高调爆发光：逆光轮廓 + 蓄力期压暗、爆发期过曝；光效是演出节拍不是常驻；**禁低照度悬疑光、禁写实全局光照** |
| ⑧ 声音签名 | 环境层：风、场地回声、人群声浪；动作层：破风、冲击、落地震；呼吸层：蓄力时的屏息；配乐：摇滚 / 电子战斗曲，中快板，鼓点驱动 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。其他面：低饱和、灰暗悬疑、柔光朦胧、写实照片感、厚涂笔触、Q 版二头身（除非声明搞笑段）、可读文字、水印、多余人物、分身 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A shonen action anime frame: clean digital lineart, hard-edged two-tone cel shading, high-saturation flat colors, speed lines and focus lines as picture elements, exaggerated wide-angle action perspective with impact frames. Orange-red versus cobalt-blue character colors with yellow-white highlights. Brave and energetic, never muted or desaturated.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
high-saturation orange-red and cobalt-blue scheme, yellow-white highlights, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `muted desaturated serious` | `high-saturation ... never muted` | 反串暗黑悬疑档 |
| `soft gradient shading` | `hard-edged two-tone cel shading` | 柔边是条漫/国漫档的词 |
| `photorealistic muscles` | `exaggerated wide-angle action perspective` | 写实词会把动画拉向照片 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 45 词，中等——战斗段的招式名与蓄力描述耗词快，预算紧先删末句（never muted 一句，靠正文正面词锁饱和度）。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅热血少年漫画风格的动画画面：干净的数码勾线，硬边两段式赛璐璐阴影，高饱和平涂色块，速度线与集中线作为画面元素，广角冲击透视与爆发帧。橙红对钴蓝的主角配色，黄白高光。蓄力帧压暗、爆发帧过曝，战斗的光效跟着节拍走。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：高饱和橙红对钴蓝，黄白高光，每镜只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「暗黑」「阴沉」「肃杀」 | 删，写「热血」「高饱和」 | 反串暗黑档 |
| 「柔和」「唯美」「朦胧」 | 删，写「硬边」「高饱和」 | 反串柔光系 |
| 「慢节奏」「文戏」 | 文戏段另锁，战斗段写「蓄力-爆发」节拍 | 强度节奏是本锚本体 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（硬边两段式、高饱和、速度线、一段一主运镜）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把高饱和推成荧光辣眼**，所以「高饱和平涂」与「禁荧光」的界限在国内面靠配色句的「橙红对钴蓝」**具体色名**锁住，不写抽象的「鲜艳」。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 广角冲镜头（拳头/踢击向镜头）、急推急拉（爆发帧）、固定蓄力帧 |
| 少量 | 环绕（对决对峙，每段 ≤1 处）、低速升格（决胜一击）、纵向拉升 |
| 避免 | 连续甩镜、手持晃动、慢速横移（黏滞感）、写实跟拍 |

**每段只锁一个主运镜**；速度线是画面元素不是运镜，写在帧内不写在镜头动词里。

| 项 | 落值 |

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 跑成写实格斗 | 出现真实肌肉、汗珠特写照片感 | 锁「动画质感」，负面词带写实照片感 |
| 强度不足像日常番 | 没写速度线与爆发帧 | 「速度线与集中线作为画面元素」不许省 |
| 高饱和变荧光辣眼 | 写抽象的「鲜艳」 | 用具体色名（橙红 #E85428 对钴蓝）锁 |
| 暗黑化 | 蓄力期压暗写过头 | 蓄力压暗只到「可辨轮廓」，爆发帧必须回高调 |
| 连续运镜眩晕 | 甩镜连用 | 一段一主运镜；速度线在帧内表达 |
| 伤痕穿帮消失 | 前段受伤后段干净 | 伤痕是角色记忆点，登记进连续性台账 |
| H3 正文混中文 | 压句或招式段夹中文 | 招式名用英文意译；跑 `check_prompt_h3.mjs` |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「写实化」与「灰暗化」两侧的词**，保留高饱和爆发与速度线演出。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| photoreal muscle / real sweat | 动画质感、变形透视 | 反串写实格斗 |
| muted grey serious / 阴郁 | high-saturation 爆发光 | 反串暗黑档 |
| soft gradient / 柔边 | hard-edged two-tone | 柔边是条漫/国漫档的词 |
| oil brush / 厚涂 | clean digital lineart | 反串厚涂档 |
| halftone dots / 网点 | speed lines 速度线 | 反串美漫波普 |

### 9.2 互斥风格

`anime-2d`（通用叙事档 vs 热血强化档，强度档位不同）、`dark-anime-2d`（低照度悬疑 vs 高调爆发）、
`comic-popart-2d`（印刷网点 vs 动画赛璐璐）、`photoreal-pbr`（写实 vs 动画变形）。
