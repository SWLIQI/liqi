# 风格锚 · 民俗年画 2D（L1 · 十节）

风格 id：nianhua-2d　｜　轨道：平面工艺轨　｜　维度：2D　｜　status：已落值

## 零、文件头

一句话定位：本文件是 liqi Step 2「全片统一风格锚（九段）」在**木版套色年画**这套风格上的落值。数值事实源是项目级 style-registry.json 的同名条目，本文件不另立数值。

适用判定：画面是木版套色年画：色块边界硬、无光影无投影，形象饱满（娃娃、门神、鲤鱼、花卉），构图对称热闹但不杂乱。用户给了年画设定图、或明确要求年画 / 木版年画 / 桃花坞 / 杨柳青 / 绵竹年画风格时选本风格。

边界声明：与国漫赛璐璐的边界在「影」——赛璐璐有两段式阴影逻辑，年画完全没有影，只有线加色块；出现暗部与固有色加影即串轨。与剪纸的边界在「色数」——剪纸是红纸单色负形，年画是多色套印。与国潮新中式的边界在「装饰语法」——国潮是现代插画加几何纹样讲留白，年画是满构图加传统母题讲热闹。与写实轨的边界在「光」——年画无光，写实轨一切质感来自光。

### 措辞纪律表

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 鲜艳的颜色铺满 | 受控套色五色，槐黄只作一个重音 | 满饱和是廉价年货风，不是木版年画 |
| 有光影更立体 | 无光无影，墨线加色块即全部层次 | 一个投影就把年画串去写实轨 |
| 灵动的飞舞 | 默认静态，局部单动一拍一 | 连续飞舞触发插值与模糊，年画没有连续运动 |
| 精致的五官 | 程式化眉眼，墨线勾勒 | 五官细节是真人轨词汇 |
| 做旧泛黄 / 老纸质感 / 岁月痕迹 | 均匀宣纸底 #F2E8D5，无做旧无污渍 | 做旧是复古摄影词汇，会顺势带进污渍、光斑与真实纸纤维，把印刷品变成文物实拍 |
| 热闹喜庆的氛围 | 满构图吉祥母题 + 纸底留白至少两成 | 「氛围」是抽象词，模型的落地方式只有加饱和度和加光，两头都串轨 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。只写一句会导致色域漂移——尤其槐黄那个唯一重音色，漏写配色句时模型会把它撒到每一处衣饰镶边上。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 86 词（按校验器空白分词口径实测），在全库锚中排第 7（按词数降序），中等，留有两三个词的余量。

## 三、色值表

| 用途 | HEX | 说明 |
|---|---|---|
| 主色 A / 年画红 | #D33A2C | 大面积衣饰与主体 |
| 主色 B / 槐黄 | #E8B04B | 大面积衣饰与主体，一镜只许一个主体 |
| 辅色 / 翠绿 | #2E7D5B | 叶片、衣饰镶边 |
| 辅色 / 紫绛 | #7A4A6B | 衣饰与器物的次辅色 |
| 勾形墨线 | #1F1A17 | 所有色块的边界 |
| 纸底 | #F2E8D5 | 未上色部分 |

色彩预算纪律：每镜只声明一个唯一重音色（槐黄 #E8B04B 的一个主体），其余锁进五色套印体系（红黄对为主，绿紫为辅）。不声明色彩预算，模型会自发补饱和度，套色体系立刻散掉。

**本表无「肤色」项（不是漏项）**：木版套色只印五色，娃娃的脸就是留白的纸底 `#F2E8D5`，最多再压一版淡赭——那是「第五版套印」，不是皮肤。单列一格肤色等于承认画面里有皮肤塑造，套印逻辑当场散架。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定正面、缓慢推近（保持平面不变形）、垂直升降取景 |
| 少量 | 切换机位重取景（等同换一张画，全片不超过三次） |
| 避免 | 横移、环绕、荷兰角、任何透视变形与视差运镜 |

每段只锁一个主运镜。年画是「画」不是「空间」——摄影机正对画面或等比推近，斜一秒，木版套色的平面本体就暴露成贴片。

## 五、材质与可见性预算

| 项 | 落值 |
|---|---|
| 主花费 | 色块边界的硬边精度与套色对位（墨线不越界、色块不糊） |
| 次花费 | 吉祥母题的识别度（蝠、鱼、莲、牡丹一眼可辨） |

| 禁 | 体积光、渐变、3D、景深、真实皮肤、布料垂坠、投影、阴影、辉光 |

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| 出现投影或明暗（最致命） | 写了光照、逆光、立体；或给了带投影的参考图 | 压句第二句钉死 no light and no shadow；参考图必须是无影年画 |
| 色块间出现过渡渐变 | 写了柔和、晕染、水彩 | 色块边界一律硬边，写进压句 |
| 变成国漫赛璐璐 | 写了暗部、固有色加影、两段式阴影 | 年画无影；层次只靠套色对比，不靠明暗 |
| 变成廉价年货风 | 满饱和无控；母题堆砌 | 五色受控加唯一重音色；母题一镜不超过四种 |
| 满构图变杂乱 | 每个空处都填了纹样 | 纸底留白至少占画面两成；母题分区不越界 |
| 动效滑行 | 写了飞舞流动 | 默认静态；局部单动一拍一写进压句 |
| 变成剪纸单色 | 只给了红纸色 | 套印五色体系，红黄对为主 |
| 画面做旧（泛黄、污渍、纸纤维实拍） | 写了做旧、复古、岁月痕迹；或参考图是老照片扫描件 | 纸底锁 #F2E8D5 均匀无污渍；参考图取新印年画，不取馆藏扫描件 |
| 套色错位（色块越出墨线、两版叠脏） | 压句没写墨线勾形与硬边 | 写死「色块之间是墨线分隔、不越界」；套色对位随资产图一并锁定 |
| 母题跨镜对不上（蝠/鱼/莲的形变样） | 只写了母题种类，没写程式化形 | 母题按第一段⑥的定式写死：蝠 = 展翼弧、鱼 = 涡身月牙尾、莲 = 俯视团花；换镜不动形 |

## 七、声音签名（中英双轨）

投中文面（Seedance 2.5 / 国内面）直接取中文版，不要拿英文版现场翻译。

**中文版（2.5 面 / 国内面用）**：

```text
整体声音签名：环境层——市集的远闹与爆竹的零响；
动作层——木版磕碰的钝响、纸张翻动的脆响、拓印刷子的扫过声；
呼吸层——默认无（平面人物无胸腔起伏，不许补呼吸）；
配乐层——默认无配乐；节庆段落需唢呐锣鼓时显式声明乐器与速度。
```

**英文版（H3 面用）**：

```text
overall_soundscape:
Distant fairground murmur and scattered firecracker pops in the ambient bed; the dull knock of woodblocks, the crisp turn of paper pages and the dry sweep of a printing brush on every movement. No breathing layer — flat printed figures have no chest rise.

non_diegetic_music:
N/A by default. For festival passages, declare suona and gong-drum with an explicit tempo rather than letting the model supply a bed.
```

配乐中文写法（节庆段落需要时）：`一段唢呐加锣鼓，速度欢快，只铺节庆镜，不铺全片。`

**呼吸层纪律**：平面印刷人物没有胸腔起伏，**呼吸层默认写「无」，不是留空**——留空会被补呼吸，呼吸会诱导模型给色块人物加体积，而年画一旦有体积就串去写实轨。

**爆竹声的用法**：零响的爆竹是本风格最强的年节信号，但只写**零星的远响**（两三声、有间隔）；写成连续的鞭炮串会被平台当成噪音类素材，且会盖掉动作层的木版声——年画的辨识度在木版，不在鞭炮。

**静态默认纪律**：年画默认是**静帧画面**，多数镜不写动作层。只有在「局部单动」的镜（风车转、鱼摆尾）才填动作声；给静帧硬配动作声，模型会顺势把画面也动起来，与第九段的「默认静态」自相矛盾。

## 八、参考图集与角色锁定

本风格无专属参考图集，角色锁定走 `<Subject N>` 通用写法。出角色资产图时的版式按 liqi 非写实适配：视图用正面 / 侧面 / 背面三视图（套色纹样必须三面对得上），材质写平涂不透光，相机写平面化，头身比落 5 到 5.5，身高线改工艺尺寸线。投喂铁律照旧：任何镜头带一张头部裁片作身份锚；套色分布图随资产图一并锁定。

## 九、去立体化与串轨防护

### 9.2 互斥风格

与以下 id 互斥（与 L0 excludes 双向一致）：photoreal-pbr、documentary-live-action、guofeng-cine-3d、urban-folk-filmstill、gothic-puppet、ink-wash-2d、npr-celskaded-3d、stylized-pixar-3d、celshade-guoman-2d、anime-2d、webtoon-2d，以及同轨的 papercut-2d、shadow-puppet-2d、guochao-2d。

- 混国漫赛璐璐：两段式阴影逻辑把无影年画变成动画着色，木版感当场作废；
- 混剪纸：红纸单色负形把五色套印压成单色，母题识别度崩塌；
- 混国潮：几何纹样与留白语法把满构图的热闹变成冷淡插画；
- 混写实轨：皮肤与投影把宣纸底变成真人电影的抠像。
