# 暗黑二次元 2D 风格锚（卡通轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**暗黑二次元**这套具体风格上的落值（v5.42.0 批 3 第二个），
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

**适用判定**：高对比低照度、浓重的冷灰两段式阴影、锐利细线、去饱和冷调（蓝绿底色）、
窄眼型小高光、剪影感强的构图。恐怖志怪、黑深残悬疑、都市怪谈、暗黑奇幻的 2D 日常戏都吃这套。
用户给的设定图是这类低明度锐线质感时，锁③ 选**卡通轨**，风格 id 取 `dark-anime-2d`。

**边界声明**：

- 与日系动画（`anime-2d`）：那是本风格的**高明度母系**——同样的赛璐璐逻辑，但整体明亮、
  阴影轻。判据是画面平均亮度与阴影浓度：暗部占比过半、阴影浓黑 = 本风格。
- 与暗黑哥特 2D（`gothic-2d`）：哥特是**西式符号系**（教堂尖拱、维多利亚裙装、铁艺花纹、
  湿冷雾都）；本风格是**日式暗黑系**（现代或和风场景、锐利细线、浓阴影、冷青调）。
  判据是符号词汇：出现尖拱与花窗就是哥特，出现都市夜景与制服就是本风格。
- 与写实轨：写实轨要真实材质与摄影机光学；本风格是画——两段式阴影与色块就是本体。

> ⚠️ **版权规避**：投喂词内不点名任何具体作品名（哪怕用户拿某部暗黑番当参照系）。
> 只写风格特征——暗黑二次元、浓阴影、冷调。作品名只出现在本文档的说明层与对话里。
>
> 🔴 **过审红线（恐怖志怪题材专属，投国内面前必读）**：血腥与恐怖元素**只走事后状态与光影**——
> 暗红渍痕、拖拽痕迹、空荡的椅子、骤暗的灯；**不写血溅、断肢、内脏、身体穿破等正在进行的过程**。
> 这与 `urban-folk-filmstill` 的志怪口径同源（禁血禁用血浆，代价只走光影与事后状态）。
> 投国内面另跑 `audit_risk.py` 过审预检，高敏感词先过 §6.3 五手法。

## 一、九段锚（中文，给 liqi 上游用）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 暗黑系日式 2D 动画赛璐璐风格：锐利细线勾边，色块平涂，阴影为浓重的两段式（深冷灰而非纯黑），画面暗部占比过半；高对比低照度，无噪点颗粒 |

| ③ 运动签名 | 24fps；动作克制但关键帧锐利，起手与收势清晰；阴影随动作整体跳变（赛璐璐逻辑）；无运动模糊、无镜头抖动；节奏留白多——静比动多 |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 6–7（写实系 anime 档）**；窄眼型小高光、锐利下颌线、发型轮廓硬朗；服装形制与配色、鞋袜；转面不换形，跨镜不换装 |
| ⑤ 场景锁定 | 走 `<Subject N>`：建筑形制与配色、光源位置（本风格的光位是叙事的一部分）、门窗开合状态；**同场景跨镜地标与光位必须一致**——光位变了恐怖感就散 |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、入画方式必须写（手持 / 悬挂 / 置地）；恐怖向道具（旧照、绳结、镜面）写形状与摆放，不写血迹过程 |

| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅生图模型与其他有 negative 字段的面可用：明亮日常光、高饱和暖色、Q 版二头身、厚涂油画笔触、噪点颗粒、血溅与断肢（过审红线）、可读文字、水印 logo |

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A dark Japanese-style 2D anime frame with sharp thin linework, heavy two-tone shadows in deep cool grey, desaturated palette with cold blue-green undertones, high-contrast low-key lighting, narrow sharp eyes with small highlights, no gradient, no grain.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
desaturated dark palette of ink-night blue-black and cold grey-blue with one dark crimson accent per frame, shadows staying cool grey rather than pure black
```

**三条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `anime style` / `2D anime`（单独用） | `dark Japanese-style 2D anime` | 不带 dark 定语会路由到明亮日常番的通道，阴影浓度整个掉下去 |
| `blood splatter` / `gore` | 删除，改写事后状态（`dark stains` / `drag marks`） | 过审红线：过程性血腥是拦截项，事后状态只走光影 |
| `soft shading` / `painterly` | `two-tone shadows` / `sharp thin linework` | 软过渡把本风格推向厚涂，浓阴影变灰雾 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。
改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 36 词（按校验器空白分词口径实测），偏短，加词空间充足，但别堆否定串。

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅暗黑系日式 2D 动画画面：锐利细线勾边，色块平涂，浓重的两段式阴影用深冷灰而非纯黑，画面暗部占比过半。高对比低照度，窄眼型带细小高光，无渐变，无噪点颗粒。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
去饱和暗调配色：墨夜蓝黑与冷灰蓝为主，燐青做环境冷光，每帧只保留一个暗血红重音；阴影是冷灰不是黑。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「恐怖血腥」「血浆四溅」 | 「暗调悬疑氛围」，血只写事后状态 | 国内面过审红线，过程性血腥是拦截项 |
| 「暖暖的灯光」「温馨氛围」 | 「低照度冷光源」 | 暖光词直接瓦解色域，本风格禁暖底 |
| 「不要太亮」 | 删否定句，正面写「画面暗部占比过半」 | 扩散模型对否定基本不生效 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（锐利细线、浓重两段式阴影、暗部占比过半）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台自带美化倾向会把阴影提亮、把冷调校暖**——
所以 2.2 那句「画面暗部占比过半」「深冷灰而非纯黑」在国内面**不许省略**。

## 三、色值表（风格级起点，项目级以 asset-registry 为准）

| 用途 | 色值 | 说明 |
|---|---|---|
| 墨夜蓝黑（底色） | #1A1D24 | 画面最底层与夜空，不是纯黑 |
| 冷灰蓝（主色） | #3E4A5C | 服装主体与建筑暗面 |
| 暗血红（重音色） | #8E2F3C | 全片唯一重音色：关键物、警示光、事后状态的渍痕 |
| 骨白 | #D8D5CC | 高光面、纸张、面具，不是纯白 |
| 灰青 | #5C6B73 | 中间调过渡面块 |
| 燐青 | #2E4A4D | 环境冷光与屏幕光 |
| 铁灰 | #4A4E54 | 金属道具与结构 |
| 暗调肤色 | #C9A38A | 肤色亮部，平涂；暗部 #9E7B62 加深一档 |

**色彩预算纪律照旧**：每镜只声明一个唯一重音色（默认暗血红），其余压成冷调同色系。
恐怖感靠「克制的重音」撑——重音一多，惊悚变猎奇。

**暗部纪律（本风格的命门）**：阴影 = 深冷灰蓝的两段式，**不是纯黑**。
纯黑阴影会把画面压成剪影贴纸，丢掉赛璐璐的层次；冷灰才能保留「看得见的暗」。

**同步纪律**：本表与 L0 注册表的 `palette` 必须一致，改一处要同步另一处。
项目级具体角色的色值另存 `asset-registry.json`，不抄进本文件。

## 四、运镜池

| 类别 | 镜头 | 用法 |
|---|---|---|
| 主力 | 缓慢推近、固定机位长镜、微俯、缓慢横移、背后跟随 | 克制是本风格的运镜气质——镜头在「偷看」，不在「表演」 |
| 少量 | 急推（惊吓点专用）、倾斜地平线、入眼 | 一部片两三次；急推后必须接静止长镜恢复呼吸 |
| 避免 | 360 环绕、航拍大俯仰、手持晃动、荷兰角连用 | 2D 资产做不了环绕；手持晃动与倾斜角是恐慌语法，连用就疲劳失效 |

**每段只锁一个主运镜**，与 liqi 的原语群纪律一致。

## 五、材质与可见性预算（暗黑二次元版）

| 项 | 落值 |
|---|---|
| 主花费 | 光位与剪影——这套风格的辨识度全在「谁被照亮、谁藏在暗里」 |
| 次花费 | 眼型高光与轮廓线的锐度——恐惧与警惕都写在眼睛里 |

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **变明亮日常番** | 光位写暖、暗部占比没声明 | 压句钉死 `low-key lighting` 与「暗部占比过半」；每镜写明光源 |
| **阴影变纯黑，成剪影贴纸** | 暗部写黑或阴影过重 | 钉死「深冷灰而非纯黑」；剪影只给一两个角色用 |
| **变西式哥特** | 场景词带教堂、古堡、维多利亚 | 场景词走现代都市或和风；符号系冲突查 `gothic-2d` 边界声明 |
| **变厚涂插画风** | 写了软过渡、笔触、环境光遮蔽 | 压句带 `two-tone shadows`；负面词带厚涂 |
| **血腥词触发平台拦截** | 写了血溅、断肢等过程性血腥 | 过审红线：只写事后状态（渍痕、拖痕、空位）；投国内面先跑 `audit_risk.py` |
| **色域漂移变蓝黑滤镜大片** | 冷调写过头、丢重音 | 每镜保留暗血红唯一重音；无重音的镜也要在色彩预算里声明「本镜无重音色」 |
| **角色跨镜换脸** | 没走 `<Subject N>` | 每镜内联锁定；首帧必带身份锚图 |

## 九、去立体化与串轨防护

本风格是 2D 赛璐璐系，**不要跑手绘轨或定格轨的 `dedupe_style.py` 词表**（方向都不对），按 §9.1 手工清。

### 9.1 污染词与替换对（暗黑二次元方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 温馨、暖光、夕阳治愈 | 低照度冷光源、单光源 | 暖光词直接瓦解色域 |
| 血浆、血溅、断肢、gore | 事后状态：渍痕、拖痕、空位 | 过审红线：过程性血腥是拦截项 |
| 软过渡、厚涂笔触、柔和阴影 | 两段式阴影、锐利细线 | 软化把本风格推向厚涂 |
| 教堂、尖拱、维多利亚、哥特教堂 | 现代都市夜景 / 和风旧宅 | 西式符号系是 `gothic-2d` 的领地，混符号即串轨 |
| 亮色大底、高饱和霓虹 | 去饱和冷调 | 高饱和把低照度悬疑变霓虹都市 |
| 纯黑阴影、剪影贴纸 | 深冷灰蓝两段式 | 纯黑丢层次，冷灰保「看得见的暗」 |
| 噪点、颗粒、胶片感 | 删除 | 本风格要干净的赛璐璐面 |

**保留不动的词**（这些在别的轨要删，在本轨是本体）：`shadow`、`silhouette`、`low-key`、`dark`、`outline`。

### 9.2 互斥风格

重点对子（写具体因）：

| 互斥 id | 混了会怎样 |
|---|---|
| `anime-2d`（日系动画 2D） | 同一赛璐璐母系的高明度版：亮度与阴影浓度相反，同包混写明暗逻辑断裂 |
| `gothic-2d`（暗黑哥特 2D） | 同是暗调但符号系相反：西式教堂符号 vs 日式都市锐线，符号混装两边都不像 |
| `celshade-guoman-2d`（国漫赛璐璐） | 明快美型色块 vs 低照度浓阴影，色域无法共存 |
| `urban-folk-filmstill`（市井写实志怪） | 同题材但媒介相反：实拍电影感 vs 2D 赛璐璐，负面词方向完全相反 |

**以下补登自 L0 excludes 全量对齐（v5.42.0）**——其余互斥 id 保证锚文件与 L0 无漏：

| 互斥 id | 混了会怎样 |
|---|---|
| `webtoon-2d`（韩漫条漫） | 低照度悬疑 vs 条漫明亮分格，明暗逻辑相反 |
| `thickpaint-2d`（厚涂二次元） | 浓阴影两段式 vs 软过渡厚涂，明暗逻辑相反 |
| `comic-popart-2d`（美漫波普） | 冷调悬疑 vs 高饱和波普撞色，色域无法共存 |
