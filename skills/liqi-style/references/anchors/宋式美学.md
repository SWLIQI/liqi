# 宋式美学·院体绢本 风格锚（手绘轨 × 宋画专项）

本文件是 Step 2「全片统一风格锚（九段）」在**宋代院体画美学**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：宋代院体画（含花鸟、山水小景、人物纨扇）的绢本质感——绢本米黄细底、
矿物色的淡雅设色（天青、赭石、汁绿）、大量留白、工笔勾线但墨色极淡、
构图疏朗取一角半边（马一角夏半边）。用户给的是宋画 / 极简国风 / 禅意东方参照时，
锁③ 风格轨道选**手绘轨**，风格 id 取 `song-aesthetic-2d`。

**边界声明**：

- 与水墨淡彩（`ink-wash-2d`）：水墨是**写意**（泼墨笔触、浓淡干湿、大片留白是笔墨本身）；
  宋式是**院体工笔**（细勾线、矿物色薄染、留白是构图不是笔法）。笔性相反。
- 与敦煌工笔重彩（`dunhuang-gongbi-2d`）：敦煌是**满构图重彩**（矿色叠染到覆盖、人物满壁）；
  宋式是**疏朗淡设色**（绢底透出来、色只染两三成）。浓度与构图密度相反。
- 与绘本水粉（`gouache-2d`）：绘本是现代童书的颗粒干笔触；宋式是绢本薄染无颗粒。
- 与写实实拍各档：本锚是**绘画**——勾线与绢纹是本体，照片质感即跑偏。

> **竖屏适配（C26）**：宋画纨扇与立轴天然接近方形/竖向——竖屏写法：取「一角式」构图
> （主体占一角、余下留白），远山做上段薄染。**竖屏友好，无需改写行**。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Song-dynasty court painting on silk: fine silk weave showing through thin mineral pigment, pale ink outlines (gossamer-thin), generous empty space left as the bare silk ground. Ru-ware celadon blues with ochre and sap-green accents, rouge reserved for petals. Corner composition, the subject occupies one corner, distance fades in a thin wash above. No cast shadows, no volumetric light.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
ru-ware celadon base with ochre and sap-green, rouge as the single accent, bare silk as negative space
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `splash ink / expressive brush` | `pale ink outlines (gossamer-thin)` | 写意笔墨是水墨档的本体，反串 |
| `rich saturated mineral pigment` | `thin mineral pigment` | 满壁重彩是敦煌档的方向 |
| `photorealistic texture` | `silk weave showing through` | 照片感是本锚反面 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 59 词，属于长档——预算紧先删末句（Corner composition 一句，构图由正文逐镜写），删后约 52 词。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅宋代院体绢本画的画面：细绢经纬纹理透出薄薄的矿物色层，墨线极淡如游丝描，大片留白露出绢的米黄本色。汝窑天青为底，赭石与汁绿染枝叶，胭脂只点花瓣。一角式构图——主体居一角，远山在上段薄染。没有投影，没有体积光，是画不是照片。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：天青打底，赭石汁绿染枝叶，胭脂只做每镜唯一重音。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「水墨」「泼墨」「写意」 | 删，写「院体工笔」「游丝描」 | 笔性相反，反串水墨档 |
| 「浓墨重彩」「满壁」 | 删，写「薄染两三成」 | 反串敦煌重彩档 |
| 「真实质感」「光影氛围」 | 删，写「绢纹」「无影平光」 | 光影是本锚反面 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（绢本薄染、留白、无影平光、一角式构图）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把淡雅推成灰暗或加出立体阴影**，所以「薄染两三成」与「无影平光」在国内面**不许省略**。

## 三、色值表

| 用途 | 色值 | 说明 |
|---|---|---|
| 绢本米黄（底） | #E3D8C0 | 留白处的本色，全画面最亮 |
| 汝窑天青（主色） | #A8C2C2 | 底层淡染与器物 |
| 赭石 | #B08A62 | 枝干与山石 |
| 汁绿 | #9AAE8A | 叶色，薄染 |

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 跑成水墨写意 | 写了泼墨、笔触、浓淡干湿 | 锁「院体工笔」「游丝描」；负面词带写意泼墨 |
| 跑成敦煌重彩 | 色层写满、矿色叠染 | 「薄染两三成」锁死；负面词带满壁重彩 |
| 加出立体阴影 | 平台或措辞带光影 | 「无影平光」不许省；负面词带投影 |
| 色彩变鲜艳 | 写抽象的「清新明快」 | 用具体色名（天青 #A8C2C2）锁 |
| 留白被填满 | 场景写太满 | 一角式构图锁死；留白是构图不是空缺 |
| 跑成照片 | 出现景深、摄影词 | 「是画不是照片」；绢纹不许省 |
| H3 正文混中文 | 压句或服饰段夹中文 | 压句纯英文；跑 `check_prompt_h3.mjs` |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「写意化」与「重彩化」两侧的词**，保留院体工笔与绢本薄染。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| splash ink / expressive brushwork | pale gossamer-thin outlines | 反串水墨档 |
| rich layered mineral pigment | thin mineral wash | 反串敦煌重彩档 |
| cast shadow / volumetric light | 无影平光 | 光影是本锚反面 |
| vivid colors / 明快 | muted on bare silk | 鲜艳破坏淡雅 |
| photorealistic / 景深 | silk weave showing through | 照片感反面 |

### 9.2 互斥风格

`ink-wash-2d`（写意笔墨 vs 院体工笔，笔性相反）、`dunhuang-gongbi-2d`（满壁重彩 vs 疏朗薄染）、
`documentary-live-action`（实拍 vs 绘画）、`photoreal-pbr`（写实渲染 vs 平面绢本）。
