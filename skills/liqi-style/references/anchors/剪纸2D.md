# 风格锚 · 剪纸 2D（L1 · 十节）

风格 id：papercut-2d　｜　轨道：平面工艺轨　｜　维度：2D　｜　status：已落值

## 零、文件头

一句话定位：本文件是 liqi Step 2「全片统一风格锚（九段）」在**单层平面剪纸**这套风格上的落值。数值事实源是项目级 style-registry.json 的同名条目，本文件不另立数值。

适用判定：画面为单层红纸本体，主体由负形镂空界定，边缘是刀刻般的硬边，无抗锯齿、无过渡；构图讲对称与满而不乱；动效是跳切式的换位，不是连续的走。用户给了红纸质感设定图、或明确要求剪纸 / 窗花 / 非遗剪纸风格时选本风格。

边界声明：与写实轨的边界在「体积」——写实轨要皮肤毛孔与光影体积，本风格连投影都是画上去的镂空形状，禁止一切体积词。与定格木偶轨的边界在「层数」——定格是实体微缩有厚度，剪纸是单层，侧看成绝对纸片。与水墨手绘轨的边界在「边缘」——水墨是晕染与墨线的柔，剪纸是刀刻的硬，出现晕染即串轨。与皮影的边界在「透光」——皮影的皮料半透明对背光有反应，剪纸是不透光实体色块。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 媒介声明放第一句：这是一幅单层平面剪纸作品，红纸本体，刀刻边缘。纸面是均匀的哑光纸纤维，无光泽、无纹理起伏、无体积；所有形状由负形镂空界定，镂空处直接透出纸底，不出现任何材质的物理细节 |

### 措辞纪律表

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 立体感、有层次 | 色块分层（红与暗红区分前后景） | 立体与层次会把单层纸推出体积，剪纸的本体就是平 |
| 细腻的纸张纹理 | 哑光纸纤维，均匀无起伏 | 真实材质纹理是写实轨的词汇，会让红纸变成折纸摄影 |
| 灵动的飘落 | 分两拍位移，每拍一个静止姿态 | 连续飘落会触发运动模糊与插值，剪纸没有连续运动 |
| 金光闪闪 | 一处金箔点缀，哑光金 | 闪闪会触发高光辉光，把金箔变成金属 3D |
| 窗花摆件 / 立体剪纸 / 纸雕 | 单层平面剪纸作品，从一整张纸上剪出 | 摆件与纸雕是有厚度的实物摄影，一出现就串去定格实拍轨，单层平面当场失效 |
| 渐变的红 / 深浅过渡的红色 | 红与暗红两层色块，硬边分界 | 渐变是体积渲染的入口词，单层平涂一旦出现过渡，纸就不再是纸 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。只写一句会导致色域漂移——尤其金箔那一处重音色，漏写配色句时模型会把它撒到每个装饰点上。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 92 词（按校验器空白分词口径实测），在全库锚中排第 4（按词数降序），偏长——**加词前必须先想清楚删哪一句**。

## 三、色值表

| 用途 | HEX | 说明 |
|---|---|---|
| 主色 / 纸体 | #C0362C | 中国红，占画面七成 |
| 纸底 / 镂空透出 | #F2E8D5 | 暖白，只从镂空处露出 |
| 勾边黑 | #1A1A1A | 仅最内层轮廓，一线即可 |
| 重音色 / 金箔 | #E8B04B | 哑光金，一镜只许一处 |
| 暗部 / 后层 | #8C1F1A | 暗红，用于后景色块分层，不是阴影 |

色彩预算纪律：每镜只声明一个唯一重音色（金箔 #E8B04B），其余全部压进红纸色阶（#C0362C 与 #8C1F1A 两层）。不声明色彩预算，模型会自发补饱和度，年画式的杂色立刻进场。

**本表无「肤色」项（不是漏项）**：剪纸人物就是红纸本身，纸底下没有皮肤这一层，`#F2E8D5` 的镂空透出同时承担亮部与留白。硬凑一格肤色会在平涂纸面上开出一块异色，单层平面当场破功——这是本体决定的，不是偷懒。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定正面、固定微俯、缓慢推近（保持平面不变形）、垂直升降取景 |
| 少量 | 切换机位重取景（等同剪纸的「换一刀」，全片不超过三次） |
| 避免 | 横移、环绕、荷兰角、任何会产生视差与透视变形的运镜 |

每段只锁一个主运镜。平面工艺的镜头语法是「取景框在纸上移动」，不是「摄影机在空间里移动」——推近可以（等比放大），横移不行（破坏单层平面）。

## 五、材质与可见性预算

| 项 | 落值 |
|---|---|
| 主花费 | 负形镂空的轮廓精确度与红纸色块的均匀度 |
| 次花费 | 纹样的细密程度（团花、涡形、月牙的装饰密度） |
| 省 | 群像（压成同一红色块的剪影群，只以轮廓区分）、远景 |
| 可见性 | 群像只写数量与轮廓动态；道具纹样一镜不超过三种 |
| 禁 | 体积光、渐变、3D、景深、真实材质纹理、抗锯齿、任何方向的投影 |

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| 变立体折纸或纸雕 | 写了折、叠、层、立体构成；或给了带侧面的参考图 | 压句第一句钉死 single-layer flat papercut；参考图必须是正面单层 |
| 镂空处糊死或长出杂质 | 镂空形状太小太密；模型自行补细节 | 单个镂空不小于画布的百分之五；负形用团块不用细丝 |
| 边缘出现抗锯齿与毛边 | 写了毛边、做旧、手撕 | 边缘写刀刻硬边；做旧只能写在纸底（#F2E8D5 的旧黄），不写在轮廓 |
| 动效滑行丢失剪纸感 | 写了飘、飞、流畅移动 | 动效一律跳切式换位；确需移动时分拍静止 |
| 整体变年画或国漫 | 加了套色多色、五官细节、赛璐璐阴影 | 色数锁死在红与暗红两层加一线黑；脸是团块不是五官 |
| 投影出现 | 写了灯光、投影、逆光 | 均匀平光；投影是画上去的镂空形状（只用于幕布戏中戏，且必须是平面形状） |
| 金箔滥用 | 每个装饰点都描金 | 重音色一镜只许一处，写进本镜色彩预算 |
| 长出第三层纸 | 写了前后景、景深分层、多层叠压 | 层数锁死在「主体红 + 后景暗红」两层；出现第三层就是纸雕，不是剪纸 |
| 红纸色号漂成朱红 / 橘红 / 粉红 | 只写「红色」不钉 HEX，模型按自己的先验补 | 主色钉死 #C0362C、暗部钉死 #8C1F1A，压句与配色句两处都带 HEX |
| 人物长出五官与关节细节 | 写了眉眼细节、手指、腕关节、衣褶垂坠 | 脸是团块、眉眼是镂空线条、四肢是整体分件；细节一律改成纹样（团花 / 涡形 / 月牙） |

## 七、声音签名（中英双轨）

投中文面（Seedance 2.5 / 国内面）直接取中文版，不要拿英文版现场翻译。

**中文版（2.5 面 / 国内面用）**：

```text
整体声音签名：环境层——纸的摩擦声与市集的远闹；
动作层——剪纸撕拉的脆响、红纸对折的闷响、剪刀开合的金属声；
呼吸层——默认无（平面人物无胸腔起伏，不许补呼吸）；
配乐层——默认无配乐；民俗段落需锣鼓点时显式声明乐器与速度。
```

**英文版（H3 面用）**：

```text
overall_soundscape:
Dry paper friction and a distant market murmur in the ambient bed; the crisp tear of paper being cut, the soft thud of a folded sheet and the metallic snip of scissors on every movement. No breathing layer — flat paper figures have no chest rise.

non_diegetic_music:
N/A by default. When a folk passage needs percussion, declare the instrument and tempo explicitly rather than letting the model supply a bed.
```

配乐中文写法（需要时）：`一段锣鼓点，鼓点颗粒清晰、唢呐进一句即收，不铺满全段。`

**呼吸层纪律（本风格特有）**：平面工艺人物没有胸腔起伏，**呼吸层默认写「无」，不是留空**——留空会让模型自行补呼吸，而呼吸会诱导它给纸人加胸腔体积，直接把单层纸推出 2.5D。这条与第七节同步写进正文，不是只写在文档里。

**撕拉声的用法**：剪纸的「撕拉脆响」是本风格最有辨识度的一层，只在**有剪纸动作**（剪、撕、对折）的镜写；人物走位与对话镜不写——平面人物换位本就是跳切，没有摩擦过程可配音。

## 八、参考图集与角色锁定

本风格无专属参考图集，角色锁定走 `<Subject N>` 通用写法。出角色资产图时的版式按 liqi 非写实适配：视图改侧影 / 正面 / 关节分解三视图（剪纸人物四肢仍是分件的），材质写平面不透光，相机写平面化，头身比落 4 到 4.5，身高线改工艺尺寸线（以「头宽的倍数」标注，不用真人厘米）。

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

| 污染词 | 替换词 | 为什么 |
|---|---|---|
| 立体感 / 有层次 | 色块分层，红与暗红区分前后景 | 立体词把单层纸推出体积 |
| 纸张纹理细腻 | 哑光纸纤维，均匀无起伏 | 真实材质纹理是写实词汇 |
| 灵动飘落 / 流畅 | 分拍静止，跳切换位 | 连续运动触发插值与运动模糊 |
| 金光闪闪 | 一处哑光金箔 | 辉光词把金箔变金属 3D |
| 逼真五官 | 团块脸，镂空眉眼线条 | 五官细节直接串去真人轨 |
| 渐变 / 柔和过渡 / 晕染 | 硬边一刀切，无过渡 | 渐变与晕染是体积渲染与手绘水墨的入口词，单层平涂沾上就软 |
| 逆光 / 透光 / 半透明 | 不透光实体色块 | 透光是皮影的皮料属性，红纸不透光；写了透光模型会去补背光 |
| 摆件 / 摆拍 / 微缩景深 | 平面作品，画在纸上 | 摆件与景深是定格实拍轨词汇，把纸片变成有厚度的实物 |

### 9.2 互斥风格

与以下 id 互斥（与 L0 excludes 双向一致）：photoreal-pbr、documentary-live-action、guofeng-cine-3d、urban-folk-filmstill、gothic-puppet、ink-wash-2d、npr-celshaded-3d、stylized-pixar-3d、celshade-guoman-2d、anime-2d、webtoon-2d，以及同轨的 shadow-puppet-2d、guochao-2d、nianhua-2d。

- 混写实轨：皮肤毛孔与体积光把红纸变成红背景的真人电影，平面本体当场废掉；
- 混定格木偶：黏土厚度与微缩景深让剪纸变成纸雕摄影；
- 混皮影：半透明皮料与背光逻辑让不透光红纸出现透光矛盾；
- 混年画：多色套印与无影色块把单色负形变成套色版画，红纸色域失控。
