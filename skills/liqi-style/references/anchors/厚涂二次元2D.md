# 厚涂二次元 2D 风格锚（卡通轨 × 笔触档）

本文件是 Step 2「全片统一风格锚（九段）」在**厚涂二次元（thick-paint anime）**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：数字绘制的厚涂质感——明暗是**一层层罩染出来的软过渡，找不到硬边分界线**；
笔触在暗部与轮廓边缘可见、在受光面收住；皮肤有厚度与血色，暗部偏暖褐而不是灰黑；
画面带绘画的体积感，但本体是一张画。用户给的设定图是这类质感时（甜宠 / 都市言情 / 霸总这类最常见），
锁③ 风格轨道选**卡通轨**，风格 id 取 `thickpaint-2d`。

**边界声明**：

- 与国漫赛璐璐（`celshade-guoman-2d`）：**明暗逻辑正相反**——国漫是硬边界两段式，本风格是软过渡无硬边。混写出杂烩。
- 与日系 anime（`anime-2d`）：日系是薄色 + 两段式硬分界 + 6.5–7 头身；本风格是厚堆色 + 软过渡 + 暗部带环境反光。
- 与韩漫条漫（`webtoon-2d`）：条漫是柔边赛璐璐 + 7.5–8 修长头身 + 屏幕亮感；本风格有笔触厚度，且**条漫锚把「thick paint / oil brush」列为污染词**，两者互斥。
- 与韩系插画（`korean-illust-2d`，待建备选）：**边界按维度切，不按好坏切**——本 id 管**笔触与明暗逻辑**（软过渡、无硬边、暗部暖褐带反光）；
  韩系插画管**题材与光色**（水光肌、低饱和、纯色渐变背景）。两者可以叠着说，但**同一包里只取一个 id**；
  边界没定死之前韩系插画维持待建，不现场落值。
- 与写实 PBR（`photoreal-pbr`）：厚涂的皮肤有厚度，但仍然是画的笔触，不是毛孔与摄影镜头发。写了 photorealistic 就跑偏。
- 与古典油画（本库尚未建 id）：厚涂是**数字笔触**，不是画布油画。写了 canvas texture / oil on canvas 会被推到油画那一档。

> **本风格是「笔触档」不是「比例档」**：它改的是明暗怎么过渡，不是人物长几头身。
> 比例按题材在 6.5–7.5 里取一个值后全片写死，别拿厚涂去解释比例变化。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A painterly digital painting in a thick-paint anime style: light and shadow built up in soft blended layers with no hard edge boundary, brushwork visible in the shadows and along contour edges but held back on the lit planes of the face. Skin reads with thickness and blood colour, shadow areas stay warm brown with a touch of ambient bounce and are never crushed to black. It is a painting, not a photograph and not a 3D render.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
thick-paint palette with ivory highlights, warm brown shadows and a single ochre-red accent, desaturated backgrounds
```

**五条措辞纪律**：

| 写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `two-tone shading` / `crisp shadow` / `hard edge` | `soft blended shading with no hard edge boundary` | 硬边两段式是赛璐璐轨的本体，写了就回退成国漫或日系 |
| `photorealistic` / `skin pores` / `DSLR` | `painterly digital painting` | 写实词把厚涂拉向照片，笔触层直接消失 |
| `3D render` / `CGI` / `octane` / `subsurface scattering` | `painted brushwork` | 渲染词会让模型出 3D 皮，体积逻辑从「堆色」变成「打光」 |
| `canvas texture` / `oil on canvas` / `impasto everywhere` | `painterly digital painting` | 画布纹理是古典油画那一档的词，不是数字厚涂 |
| `black shadow` / 只写「暗」不写暗部色 | `warm brown shadows with ambient bounce, never crushed to black` | 暗部死黑是厚涂第二常见的崩法，一黑就没有厚涂味 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头，配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移——这一条在本风格上格外明显，因为厚涂的暖褐暗部全靠配色句钉住。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 78 词（按校验器空白分词口径实测），在全库锚中排第 10（按词数降序），中上，已靠近本库偏长的一侧——**加词前必须先想清楚删哪一句**。真要压减，先砍「Skin reads with thickness and blood colour」整句，**但 `no hard edge boundary` 与 `not a photograph and not a 3D render` 两处不许删**，那是本风格仅有的三道边界声明。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅厚涂数字绘画质感的二次元画面：明暗是多层罩染出来的软过渡，没有硬边分界线；笔触在暗部与轮廓边缘可见，在面部受光面收住。皮肤有厚度与血色，暗部偏暖褐并带一点环境反光，绝不压成纯黑。整体是画，不是照片，也不是 3D 渲染。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
厚涂配色：暖象牙白亮部、暖褐暗部、赭红唯一重音色，背景与陈设压低饱和。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「厚涂」单写 | 「厚涂数字绘画质感的二次元画面」 | 单写「厚涂」会被油画化 |
| 「不要硬边阴影」 | 删否定句，正面写「软过渡、没有硬边分界线」 | 否定在扩散模型上基本不生效 |
| 「不要照片感」 | 正面写「是画，不是照片，也不是 3D 渲染」 | 同上，且要一次挡住照片与 3D 两个方向 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次（软过渡、无硬边、暖褐暗部、唯一重音色）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台会把软过渡压成硬边两段式**（回退成赛璐璐），
所以「软过渡、没有硬边分界线」这句在国内面**不许省略**。

## 三、色值表

| 用途 | 色值 | 说明 |
|---|---|---|
| 亮部 / 受光面（primary） | #E8DCCB | 暖象牙白，厚堆色，不纯白 |
| 暗部主色（secondary） | #6B5A4E | 暖褐，不是死黑 |
| 重音色（accent） | #B4483C | 赭红，全片唯一重音色：唇、发饰、花、灯 |
| 中间调暖灰 | #A99687 | 亮暗之间的过渡层，厚涂的体积靠它堆出来 |
| 皮肤亮部 | #F6DCC8 | 受光面厚堆，带血色，不做瓷白 |
| 皮肤暗部 | #C9947F | 暗部偏暖红，不许压成灰黑 |
| 环境反光冷灰 | #7E93A6 | 暗部边缘的环境反光，厚涂区别于赛璐璐的标志；只走边缘不成块 |
| 发色深棕 | #3B2B26 | 发丝主色，暗部带反光 |
| 背景低饱和 | #8C8779 | 场景与陈设压低饱和，让角色笔触跳出来 |
| 软勾线 | #4A3B36 | 只用于需要强调的轮廓，软而细，不是黑描边 |

**色彩预算纪律**：每镜只声明一个唯一重音色（默认赭红），其余压成同色系；背景与陈设一律低饱和。
不声明色彩预算，厚涂会自发加饱和——笔触越厚，溢色越明显。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定中景、缓慢推近、轻微横移、正反打、局部特写（眼 / 手 / 物件） |
| 少量 | 慢速环绕（全片不超过两次）、轻微俯仰、过肩带前景遮挡 |
| 避免 | **360 环绕、甩镜、快速变焦、连续长镜跟拍、手持晃动** |

**每段只锁一个主运镜**。厚涂的笔触在快速运动里会糊成一团，所以本风格对运动幅度比同轨其他 id 更保守；
需要情绪强度时用局部特写代替运镜强度。

## 六、崩点清单与反制（9 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 回退成赛璐璐（**本风格头号崩点**） | 写了 two-tone / crisp shadow / hard edge 这类硬边词 | 压句与正文都写 `soft blended shading with no hard edge boundary`，硬边词全部删除 |
| 变写实照片 | 写了 photorealistic、skin pores、DSLR、摄影镜头发 | 写 `painterly digital painting`，删写实词 |
| 变 3D 渲染 | 写了 3D render、CGI、Octane、subsurface scattering | 写 `painted brushwork`，删渲染与次表面词 |
| 面部糊成一团，笔触盖住五官 | 笔触没限定范围，全画面铺笔触 | 笔触只许在暗部与轮廓边缘；面部受光面写 `smooth blended skin` |
| 暗部死黑 | 写了 black shadow，或只写「暗」不写暗部色 | 暗部写 `warm brown with ambient bounce`，明写不死黑 |
| 跑成古典油画 | 写了 canvas texture、oil on canvas、impasto everywhere | 厚涂是数字笔触不是画布油画，删画布纹理词 |
| 跨镜笔触密度与肤色不一致 | 每镜笔触词写法不同，没走 `<Subject N>` | 每镜内联锁定；压句逐字复用；必带资产图走 I2V/Ref2VA |
| 色彩溢出，自发加饱和 | 没写色彩预算 | 每镜声明唯一重音色与低饱和背景 |
| 国内面把软过渡压成硬边两段式 | 国内面压句省了「无硬边」这句 | 国内面「软过渡、没有硬边分界线」一句不许省略 |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**两侧都删**——删「硬边化」（会把软过渡压回赛璐璐），也删「写实化与渲染化」（会把笔触抹平）。
这与赛璐璐轨相反（赛璐璐轨只删厚涂词），**不要把别轨的污染词表抄过来**。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| two-tone / crisp shadow / hard edge | soft blended shading with no hard edge boundary | 硬边是赛璐璐轨本体 |
| photorealistic / skin pores / DSLR | painterly digital painting | 写实词抹掉笔触层 |
| 3D render / CGI / octane / subsurface scattering | painted brushwork | 渲染词把「堆色」改成「打光」 |
| canvas texture / oil on canvas / impasto everywhere | painterly digital painting | 会把画面推到古典油画那一档（本库尚未建 id） |
| glossy / plastic highlight | skin with thickness and blood colour | 塑料高光是厚涂皮肤最常见的崩法 |
| black shadow / 只写「暗」 | warm brown shadows with ambient bounce | 暗部死黑就没有厚涂味 |
| 中文词混入英文压句 | 全部改英文 | H3 面英文纯度门禁 |

### 9.2 互斥风格（重点对因）

`celshade-guoman-2d`（国漫，明暗逻辑正相反：硬边界 vs 软过渡）、`anime-2d`（日系，薄色硬分界 vs 厚堆软过渡）、
`webtoon-2d`（条漫，柔边赛璐璐与屏幕亮感；条漫锚已把「thick paint」列为污染词）、
`photoreal-pbr`（写实，画的笔触 vs 真实材质）、`ink-wash-2d`（手绘平面，水色渗化 vs 厚堆笔触）、
`gothic-puppet`（定格，黏土实体 vs 绘画体积）。
