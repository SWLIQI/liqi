# 美漫波普 2D 风格锚（卡通轨 × 印刷档）

本文件是 Step 2「全片统一风格锚（九段）」在**美漫波普（comic pop-art）**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：印刷出来的漫画页质感——**粗而实的黑墨线勾形**，内部是干净的高饱和平涂色块，
明暗只有两段、边界硬，没有渐变也没有柔焦；背景铺 **halftone 网点**；
人物是英雄壮硕体块（肩宽腰窄、体块夸张），常见速度线与倾斜构图。
用户给的设定图是这类质感时，锁③ 风格轨道选**卡通轨**，风格 id 取 `comic-popart-2d`。

**边界声明**：

- 与厚涂（`thickpaint-2d`）：**明暗逻辑正相反**——本风格是平涂两段式硬边，厚涂是多层罩染的软过渡无硬边。混写出杂烩。
- 与国漫赛璐璐（`celshade-guoman-2d`）：同为硬边上色，但国漫走美型大眼与干净厚亮色块、头身 6–6.5；
  本风格走**粗黑墨线 + 波普撞色 + 网点印刷感 + 7–8 英雄体块**。
- 与日系 anime（`anime-2d`）：日系是细线薄色；本风格是**粗墨线 + 高饱和印刷色 + 网点**，气质是印刷品不是电视动画。
- 与吉卜力系（`ghibli-2d`）：吉卜力是手绘水彩背景与柔和自然光；本风格是印刷平涂与波普撞色，水彩与网点互斥。
- 与写实轨任一：平涂色块与网点 vs 真实材质，负面词方向完全相反。

> **一条必须先说清的纪律（本风格头号风险）**：
> **波普的「网点与撞色」是图形，不是文字**，与 liqi 的「禁可读文字」铁律**不冲突**，可以放心建。
> 但波普**自带的对话框与 BANG / POW 拟声词就是可读文字**，照样被禁——一律改成**纯图形符号**。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
An American comic book pop-art frame: bold solid black ink outlines, clean high-saturation flat colour blocking inside, shading in two hard-edged steps with no gradients and no soft focus. The background carries halftone dot screening as a graphic layer, not noise. Pop colour contrast comes from yellow, deep blue and magenta, with a single accent hue for the whole film. No readable text anywhere: speech balloons and onomatopoeia become pure graphic symbols. It is a printed comic page, not a photograph and not a 3D render.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
pop-art clash palette of flat yellow over deep blue with a single magenta accent and cyan halftone screening
```

**五条措辞纪律**：

| 写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `soft blended shading` / `painterly` / `gradient` | `flat colour blocking`、`two hard-edged steps` | 软过渡与渐变是厚涂与柔化的入口，写了硬边当场消失 |
| `noise` / `grain` / `texture` | `halftone dot screening` | 网点必须是图形层；写成噪点会被渲染成脏噪点与摩尔纹 |
| `speech balloon` / `BANG` / `POW` | 删掉，改「纯图形符号」或不写 | 拟声词是可读文字，撞禁可读文字铁律；出片会被文字门禁拦 |
| `thin lineart` / `delicate lines` | `bold solid black ink outlines` | 细线会把风格拉向日系或水墨 |
| `photorealistic` / `3D render` / `skin pores` | `printed comic page` | 写实词把印刷品拉向照片与 3D |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头，配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致撞色失控——波普的黄蓝二元全靠配色句钉住面积比。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，
改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 86 词（按校验器空白分词口径实测），在全库锚中排第 5（按词数降序，与 `claymation-3d` 并列），偏长——**加词前必须先想清楚删哪一句**。真要压减，先砍「Pop colour contrast comes from…」整句，
**但 `bold solid black ink outlines` 与 `no readable text` 两处不许删**——前者是墨线本体，后者是过审闸门。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅美漫波普风格的漫画画面：粗而实的黑墨线勾形，内部是干净的高饱和平涂色块，明暗只有两段、边界硬，不用渐变也不用柔焦。背景铺 halftone 网点，是图形不是噪点。波普撞色靠黄、深蓝与洋红三色完成，全片只有一个重音色。画面里不出现任何可读文字——对话框与拟声词一律改成纯图形符号。整体是印刷出来的漫画页，不是照片也不是 3D 渲染。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
波普撞色配色：波普黄大面积平涂，深蓝压暗部，洋红唯一重音色，网点青只走网点层。
```

**中文面四条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「漫画风」单写 | 「美漫波普风格的漫画画面」 | 单写「漫画风」会被引向黑白线稿或日系 |
| 「柔和过渡」「渐变」 | 「明暗只有两段、边界硬」 | 渐变与柔化是本风格的第一崩点 |
| 「不要文字」 | 正面写「对话框与拟声词一律改成纯图形符号」 | 否定不生效，要给出替代形态 |
| 「噪点」「颗粒」 | 「halftone 网点，是图形不是噪点」 | 噪点会被渲染成脏颗粒 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次（粗黑墨线、平涂硬边、halftone 网点、无任何可读文字）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台默认降饱和，还会自发补对话框**，
所以「高饱和平涂色块」与「不出现任何可读文字」两处在国内面**都不许省略**。

## 三、色值表

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 / 大面积平涂（primary） | #F5D13B | 波普黄，画面主色，不成点缀 |
| 暗部与深色块（secondary） | #1B3A6B | 深蓝，代替纯黑墨块压暗部 |
| 重音色（accent） | #E03050 | 洋红，全片唯一重音色，与黄构成撞色 |
| 网点青 | #2FA8B8 | halftone 网点层与次要色块，只走网点不成大面积 |
| 黑墨线 | #14161C | 勾线色，粗而实，不是细线 |
| 纸白 | #F7F3E8 | 网点底与留白，代替纯白 |
| 皮肤亮部 | #F6C9A0 | 平涂，无渐变 |
| 皮肤暗部 | #C98A63 | 硬边阴影，两段式，不柔化 |
| 撞橙 | #EE7A2E | 次要撞色，少量使用，破黄蓝二元 |

**色彩预算纪律**：每镜只声明一个唯一重音色（默认洋红）；**黄为主、深蓝为辅、洋红点缀**，
撞色面积不许五五开。不声明色彩预算，波普撞色会立刻变脏。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定中景、硬切、快速推近、倾斜构图、局部特写 |
| 少量 | 慢速环绕（全片不超过两次）、横移、变焦冲击 |
| 避免 | **连续长镜跟拍、运动模糊、柔焦虚化、慢速溶解转场** |

**每段只锁一个主运镜**。倾斜构图是美漫的冲击力来源，主力用；
连续跟拍与运动模糊会破坏印刷品的「一帧一格」感。

## 六、崩点清单与反制（8 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| **出现可读文字（本风格头号崩点）** | 波普自带对话框与 BANG / POW 拟声词，写进正文就成了可读文字 | 对话框与拟声词一律改纯图形符号；负面词保留可读文字；出片必跑 `check_prompt` 的文字门禁 |
| 变厚涂，软过渡抹掉硬边 | 写了 soft blended / painterly / gradient | 写 `flat colour blocking` 与 `two hard-edged steps`，删软过渡词 |
| 变写实或 3D | 写了 photorealistic、3D render、真实皮肤纹理 | 媒介声明放首句（comic book pop-art frame），删写实词 |
| 网点变成噪点或摩尔纹 | 写了 noise / grain / texture 而不是 halftone screening | 网点只写 `halftone dot screening`，并写明它是图形层 |
| 撞色失控变脏 | 重音色多于一个，或撞色面积五五开 | 每镜声明唯一重音色；黄为主、深蓝为辅、洋红点缀 |
| 墨线消失，变无描边平涂 | 压句没写 bold ink outlines | 压句与正文都写 `bold solid black ink outlines` |
| 跨镜网点密度与色块不一致 | 每镜网点词写法不同 | 每镜内联锁定；压句逐字复用；必带资产图走 I2V/Ref2VA |
| 国内面把高饱和压灰 | 国内平台默认降饱和 | 国内面「高饱和平涂色块」一句不许省，并声明唯一重音色 |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「柔化」与「写实化」两侧的词**，保留硬边、平涂与印刷感。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| soft blended shading / gradient / 渐变 | flat colour blocking、two hard-edged steps | 软过渡是厚涂的入口，一进来硬边就没了 |
| noise / grain / texture / 噪点颗粒 | halftone dot screening | 网点必须是图形层，噪点会被渲染成脏颗粒与摩尔纹 |
| speech balloon / BANG / POW / 拟声词 | 纯图形符号 | 拟声词是可读文字，撞禁可读文字铁律 |
| thin lineart / delicate lines / 细线 | bold solid black ink outlines | 细线把风格拉向日系或水墨 |
| photorealistic / 3D render / skin pores | printed comic page | 写实词把印刷品拉向照片与 3D |
| glossy / plastic highlight | flat matte colour block | 塑料高光是平涂色块最常见的崩法 |
| 灰暗 / 低饱和 | 高饱和平涂 | 波普的本体就是撞色，压灰就不是波普 |
