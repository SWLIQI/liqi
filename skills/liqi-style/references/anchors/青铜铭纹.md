# 青铜铭纹·吉金纹样 风格锚（平面工艺轨 × 青铜专项）

本文件是 Step 2「全片统一风格锚（九段）」在**商周青铜器纹样美学**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：青铜器的吉金世界观——深色铜底上的饕餮兽面与夔龙纹样、云雷纹地纹满铺、
金文铭文的行列排布、铜绿锈色的点缀、错金银的线迹。画面像「器物纹样展开成世界」，
不是器物摄影。用户给的是青铜 / 上古神话 / 吉金铭文参照时，
锁③ 风格轨道选**平面工艺轨**，风格 id 取 `bronze-motif-2d`。

**边界声明**：

- 与汉画像石（`han-relief-rubbing`）：同为古拙程式，**载体与色系不同**——画像石是拓片两值剪影带状叙事；
  青铜是器型纹样带（兽面对称、地纹满铺）＋铜绿与错金的多层次色。本锚**不用「拓片」一词**。
- 与青花瓷韵（`qinghua-porcelain-2d`）：青花是白底蓝绘的绘画性；青铜是深底浮雕感的纹样性，
  且有铜绿与错金两路限定色。底色与色系互斥。
- 与国潮新中式（`guochao-2d`）：国潮是现代设计感的靛青金线；青铜的纹样全是商周凿铸程式，
  无现代设计变形。
- 与金碧山水（`jinbi-landscape-2d`）：金碧是山水画程式（绢本设色）；青铜是器物纹样程式
  （铸造肌理），无山水皴染。

> **竖屏适配（C26）**：青铜器型纹样带天然横向环带——竖屏写法：取器型一段纵览
> （口沿纹带→腹部兽面→圈足铭文），纵贯如立轴。**竖屏可用，无需改写行**。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Shang-Zhou bronze-vessel motif world: deep patinated bronze ground with relief taotie masks and coiling-dragon bands, thunder-pattern grounds filling every gap like woven texture, bronze-script inscriptions in ranked rows. Verdigris flecks and gold-and-silver inlay lines as the age layer; texture is casting grain, never brushwork. Everything unfolds on the vessel, never photographed.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
dark bronze ground, verdigris accents, gold-inlay lines as the single accent per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `stone rubbing / 拓片` | `bronze ground with relief bands` | 反串汉画像石档 |
| `photoreal artifact macro` | `unfolds on the vessel` | 器物摄影是本锚反面 |
| `colorful / 珍宝色` | `verdigris ... gold-and-silver inlay` | 三色限额是本锚的命 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 52 词，偏长档——预算紧先删末句（Everything unfolds 一句），删后约 51 词。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅商周青铜器纹样质感的画面：深褐铜底上浮雕感的饕餮兽面与夔龙纹带，云雷纹地纹如织物般铺满每个空隙，金文铭文成行排布。铜绿锈斑与错金银线迹是岁月层；肌理是铸造铸痕，不是笔触。一切在器物上展开，不是器物摄影。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：深铜为底，铜绿点缀，错金线只做每镜唯一重音。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「拓片」「剪影」 | 删，写「浮雕感纹样」「铸痕」 | 反串汉画像石档 |
| 「明亮」「崭新铜器」 | 删，写「深褐铜底」「锈色岁月层」 | 新铜是本锚反面 |
| 「铭文写着…」 | 「铭文是纹样，禁可读化」 | 可读文字铁律 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（深铜底、云雷地纹、错金重音、铸痕肌理）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把纹样推成照片级文物特写**，所以「在器物上展开」与「铸痕肌理」在国内面**不许省略**。

## 三、色值表

| 用途 | 色值 | 说明 |
|---|---|---|
| 深铜褐（底） | #4A3828 | 全画面底色，铸痕深浅分层 |
| 铜绿（限额） | #5A8A6E | 锈斑与岁月层，点缀不铺面 |
| 错金线（重音） | #C8A050 | 目纹与勾廓，唯一情绪重音 |
| 错银线 | #B8B4AC | 与错金二选一做重音 |
| 地纹褐 | #5A4632 | 云雷纹的次级色 |
| 铸痕深影 | #2E2318 | 纹样凹处的最深档 |
| 铜面哑光 | #7A6248 | 凸起处的微亮 |
| 铭文褐金 | #9A7E48 | 金文行迹 |

**色彩预算纪律**：每镜只声明一个唯一重音色（错金或错银二选一）；铜绿是点缀不铺面；朱砂默认禁用。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 极缓推近、横向扫过（纹带展开） |
| 少量 | 缓慢环绕（器型专用，每段 ≤1 处） |
| 避免 | 快切、甩镜、手持、俯仰、无人机拉升 |

**每段只锁一个主运镜**；铭文浮现与地纹涌动是画面内动效。

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「摄影化」与「鲜亮化」两侧的词**，保留吉金三色与铸痕肌理。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| artifact macro / 文物特写 | unfolds on the vessel | 器物摄影是反面 |
| rubbing / 拓片剪影 | relief bands on bronze ground | 反串汉画像石档 |
| bright new bronze / 崭新铜器 | patinated deep bronze | 新铜是反面 |
| colorful gems / 珠宝色 | verdigris + gold-and-silver inlay | 三色限额 |
| modern design / 几何变形 | Shang-Zhou casting formulas | 商周程式锁死 |

### 9.2 互斥风格

`han-relief-rubbing`（拓片两值 vs 青铜三色纹样，载体与色系互斥）、`qinghua-porcelain-2d`（白底蓝绘 vs 深底浮雕）、
`guochao-2d`（现代设计 vs 商周程式）、`jinbi-landscape-2d`（绢本山水 vs 器物纹样）。
