# 绘本水粉 2D 风格锚（卡通轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**儿童绘本水粉**这套具体风格上的落值
（v5.42.0 备选批第二个），同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——
改一个词，不同镜头质感就会漂移。

**适用判定**：粉质笔触的水粉色块、纸面肌理可见、圆润简单的造型、柔和的漫射光、
无硬轮廓或极淡轮廓、温暖友好的低对比色域。童书绘本、温情治愈、亲子内容、
睡前故事、低幼科普都吃这套。用户给的设定图是这类粉质纸面质感时，锁③ 选**卡通轨**，
风格 id 取 `gouache-2d`。

**边界声明**：

- 与吉卜力系（`ghibli-2d`）：吉卜力是西式透明水彩——颜色透亮、有远近空气感、
  自然光戏剧性；本风格是**不透明水粉**——粉质覆盖、色块厚实、纸面肌理是本体。
  判据是透明度：透亮 = 水彩，粉质覆盖 = 水粉。
- 与水墨淡彩（`ink-wash-2d`）：水墨的淡彩是晕染在宣纸上的薄色；本风格是覆盖性颜料
  的厚涂薄涂并用，色块边缘是笔触形状不是水痕。判据是边缘：水痕 = 水墨，笔触 = 水粉。
- 与 Q 版超变形（`chibi-qban-2d`）：同为幼态受众，但头身档不同（本风格 4–5 头身，
  Q 版 2–3），且本风格角色有正常五官比例的简化，不是超变形。

> ⚠️ **版权规避**：投喂词内不点名任何绘本作品或插画家名（哪怕用户拿某本绘本当参照系）。
> 只写风格特征——水粉、粉质笔触、纸面肌理。作品名只出现在本文档的说明层与对话里。

## 一、九段锚（中文，给 liqi 上游用）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 儿童绘本水粉插画：不透明粉质色块，笔触可见但边缘柔和，纸面肌理透出；造型圆润简单，无硬黑轮廓线（用色块边缘色收形）；无噪点颗粒（纸纹不是颗粒） |

| ③ 运动签名 | 24fps；动作缓慢圆润、路径柔和（物体像在水里移动的温和版）；无急停急转；无运动模糊；转场多用翻页式或淡入淡出 |

| ⑤ 场景锁定 | 走 `<Subject N>`：场景是纸面舞台——家、森林、小镇用大色块与简单形制搭出；**同场景跨镜地标与光位必须一致**；场景里手绘肌理方向统一（横向纸纹或竖向，不混） |
| ⑥ 道具锁定 | 走 `<Subject N>`：道具圆润简化（茶杯是半圆、树是三团圆），入画方式必须写（手持 / 悬挂 / 置地 / 抱）；不写真实材质细节 |
| ⑦ 光色基调 | 均匀漫射光（阴天的柔和感），物体亮面与暗面对比温和，暗部是固有色加深一档的水粉色；不写投影硬边、不写逆光强剪影、不写体积光 |

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A children's picture-book illustration in gouache, soft chalky flat colour areas with gentle visible brush texture, rounded simple shapes, warm friendly palette on a paper-toned ground, soft diffused lighting, hand-painted feel without hard outlines, no gradient, no grain.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
warm friendly gouache palette of rice-paper white and pea green with one terracotta orange accent per frame, neighbouring hues blended by analogous transitions
```

**三条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `watercolour wash` / `transparent` | `gouache` / `chalky flat colour areas` | 透明水彩词把画面推向吉卜力系；水粉的不透明粉质是本体 |
| `bold black outlines` / `comic lines` | `hand-painted feel without hard outlines` | 硬黑轮廓把画面推向赛璐璐；本风格用色块边缘收形 |
| `digital clean render` | `paper-toned ground ... brush texture` | 数字干净感抹掉纸面肌理，绘本感全失 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。
改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 38 词（按校验器空白分词口径实测），偏短，加词空间充足，但别堆否定串。

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅儿童绘本水粉插画：不透明的粉质色块，笔触柔和可见，纸面肌理透出，造型圆润简单，无硬黑轮廓线（以色块边缘色收形）。温暖友好的低对比色域，漫射柔光。无渐变，无噪点颗粒。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
温暖友好的水粉配色：米纸白与豆绿为主，每帧只保留一个陶土橙重音；相邻色同类过渡。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「水彩画」「透亮」 | 「水粉」「粉质色块」 | 透明水彩词推向吉卜力系，不透明粉质是本体 |
| 「鲜艳夺目」「高饱和」 | 「温暖友好」「中低饱和」 | 高饱和把绘本推向商业插画风 |
| 「精致细节」 | 「圆润简单」「大色块」 | 细节词把绘本推向写实插画，简是本体 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（粉质色块、纸面肌理、无硬轮廓）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台自带锐化与美化倾向会把粉质边缘变脆、把纸纹磨平**——
所以 2.2 那句「笔触柔和可见」「纸面肌理透出」在国内面**不许省略**。

## 三、色值表（风格级起点，项目级以 asset-registry 为准）

| 用途 | 色值 | 说明 |
|---|---|---|
| 米纸白（底色） | #FBF3E4 | 纸面基色与亮部，透纸纹 |
| 豆绿（主色） | #A3C9A8 | 植被、服装主色与大色块 |
| 陶土橙（重音色） | #E8875B | 全片唯一重音色：主角服装点缀、关键道具 |
| 雾蓝 | #9DBBD0 | 天空与冷调色块 |
| 奶黄 | #F5DEA3 | 暖调亮面与灯光 |
| 灰粉 | #E8B4B8 | 腮红、花瓣与点缀 |
| 深褐 | #7A5C43 | 最深固有色与树干，不是纯黑 |
| 苔点绿 | #6E8B5E | 植被暗部层次 |

**色彩预算纪律照旧**：每镜只声明一个唯一重音色，其余压成同类色过渡。
绘本色的辨识度在「温和」——对比色一多，睡前故事变广告。

**暗部纪律**：暗部 = 固有色加深一档的水粉色（豆绿加深是苔点绿），**不是灰、不是黑**。
深褐只给轮廓收形与树干，不做大面积暗部。

**同步纪律**：本表与 L0 注册表的 `palette` 必须一致，改一处要同步另一处。
项目级具体角色的色值另存 `asset-registry.json`，不抄进本文件。

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **变透明水彩（滑向吉卜力）** | 写了透亮、晕染、水痕 | 钉死 `gouache` 与 `chalky`（不透明粉质）；色块覆盖不透明 |
| **变数字插画（丢纸纹）** | 写了数字感、干净渲染 | 钉死 `paper-toned ground` 与 `brush texture`；纸纹透出是本体 |
| **变赛璐璐卡通（硬轮廓出现）** | 写了描边、勾线 | 「无硬黑轮廓、以色块边缘色收形」写死 |
| **变成人向插画风** | 高饱和、锐利构图、时尚感词汇混入 | 「温暖友好、中低饱和、圆润简单」写死 |
| **暗部变灰变脏** | 用灰调阴影 | 暗部=固有色加深一档；深褐只收形 |
| **角色跨镜变形** | 没走 `<Subject N>` | 每镜内联锁定；首帧必带身份锚图 |
| **场景比角色细** | 背景堆细节 | 场景是纸面舞台：主花费永远在角色与笔触上 |

## 九、去立体化与串轨防护

本风格是 2D 手绘质感的卡通轨，**不要跑手绘轨（水墨）的 `dedupe_style.py` 词表**——
水墨词表删「笔触」类词，而**可见笔触正是本风格的本体**。按 §9.1 手工清。

### 9.1 污染词与替换对（绘本水粉方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 水彩、透亮、氤氲 | 水粉、粉质、不透明色块 | 透明度是分水岭，透明词推向吉卜力系 |
| 描边、勾线、黑色轮廓 | 色块边缘色收形 | 硬轮廓把画面推向赛璐璐 |
| 鲜艳、高饱和、炫彩 | 温暖友好、中低饱和 | 高饱和把绘本推向商业插画 |
| 立体感、光影纵深 | 漫射柔光、温和明暗 | 立体光把画面推向 3D |
| 恐怖、暗黑、悬疑 | 温暖、安心、柔和 | 题材词跨类型，受众完全不同 |
| 噪点、颗粒 | 删除（纸纹不是颗粒） | 颗粒是摄影概念，纸纹是介质肌理 |

**保留不动的词**（这些在别的轨要删，在本轨是本体）：`brush texture`、`chalky`、`paper`、`soft`、`rounded`。
