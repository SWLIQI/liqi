# 黄金样例 A2《夜巡》—— liqi 端到端可跑基准

> **用途**：全库唯一的 **A2 级完整链路**样例。10 镜、2 场景、2 角色、1 关键道具，
> 资产层 / 风格锚 / 剧本层 / 台账 / 伏笔 / 分集结构 / 改编表**全部齐备**，
> 目的是给「整条链路到底长什么样、每一门到底要什么输入」提供一份**可复跑的证据**。

### 曾经的三处 warning 与它们的去处（v5.29.0 全部清零）

| 曾经 | 原因 | v5.29.0 处置 |
|---|---|---|
| S21 ×6：相邻景别跨度 ≥3 档 | Q1（特写 25~40%）+ Q3（侧45° 30~40%）+ C1（每组三种景别）三条配额**强迫**跨档；逐段声明要 9 处 ×14 字，吃穿 800 额度 | 新增**包级**声明 `【配额声明】全片采用极限景别跳跃`（写包首、不进正文）→ 一次豁免全片 |
| B 门 ×1：全部块未指定首帧参考 | M1 形态正文只写 `锚「…」图`，没有 `@图片N` | 正文内联 `@图片N`（M1 本来就该这么写）→ B 门识别，同时接线单 6 行全部被引用 |

**结论：本样例现在是全库第一份「六门全绿 + 门覆盖 18/18」的端到端证据。**
