## 完整示例（海捕文书）

生成图片：专业3D道具展示设定表，16:9画幅，浅灰白色影棚背景，画面填满无大面积空白，蓝图辅助网格，纤细手绘辅助引导线，全部引线注释使用中文。
整体风格：写实PBR材质渲染，古装志怪电影道具质感，低饱和青灰调，做旧年代感（纸缘泛黄、墨色沉着、印泥氧化），胶片颗粒，与全片风格锚一致。
道具：清代缉捕文书，黄麻纸竖幅（约4:3），纸面顶部竖排大字标题「缉捕文书」，标题下数行竖排正文墨迹（内容示意：查得妖物假托人形剥皮害命、悬赏缉拿、知情报官者赏银五十两——文字须清晰可辨，若生成变形则以留白处理、后期合成），中央印一个无五官的人影图形（墨色人形剪影，脸部空白），下方落款行（衙门名与日期），右上角一方朱红官印（印痕图形），纸面四沿暗纹边框（回纹/云纹），纸缘泛黄卷边、有虫蛀孔与褶皱。
状态弧：本卡只承担「展开可读态」；剧情另有「卷起封存态」时另出一张（编号 18B），两张走版本互锁（本卡禁卷起轴装形态，B 卡禁展开平铺）。
画面中心并排展示2个视图：平铺态、半卷态。
核心强制约束：两个视图使用完全一致的纸张长宽比，标题、正文行、人影图形与落款的位置、大小统一；两个视图的纸边贴合同一条水平基准线。
尺度短语：摊开后约两个手掌大小、可单手托起的竖幅文书；另在比例尺左侧标注数值“约 40 cm”。
细节面板：① 麻纸纤维纹理放大，引线标注：麻纸纹理；② 标题「缉捕文书」字迹；③ 正文竖排文字行；④ 无五官人影图形；⑤ 官印朱砂色块。
画面角落放置色板，圆形色票，每项色票旁标注中文色名与色值：麻黄 #D9C89A（纸）、灰黑 #3A3A38（墨迹）、朱红 #C1382E（印泥）、棕 #8B5E3C（轴木）。
禁止内容：现代纸张、打印感、卡通化、乱码错字（文字变形则以留白处理、后期合成，禁止乱码字符）。
写实PBR材质渲染，细节锐利清晰，整张画面光照统一，无透视畸变，全部视图采用严格正交相机，不篡改参考道具形态比例，16:9

## 常用道具视图 / 尺度短语 / 状态弧速查

| 道具类型 | 推荐展示视图 | 尺度短语（必带，另标数值核对） | 状态弧（哪些态要另出一张卡） |
|---|---|---|---|
| 文书/纸张 | 平铺态、半卷态 | 摊开约两个手掌大小、可单手托起的竖幅（约 40cm） | 展开可读态与卷起封存态影响交接与文字识别 → 各出一张（18A/18B） |
| 容器（盆/碗） | 俯视（水面/内腔）、侧视（器型） | 双手合抱大小的浅盆（盆口约 35cm） | 空置态与盛水态若跨镜复用 → 各出一张 |
| 工具（剪/镊） | 闭合态、微开态 | 单手持握、一掌可握的小工具（全长约 18cm） | 闭合 / 微开差异小，同卡并排即可，不另出卡 |
| 衣物（完好） | 叠放态、挂放态（配手掌参照） | 可折叠成一摞的上衣（衣长约 45cm） | 完好态与烧焦态**必须分卡**（8A/8B），走版本互锁 |
| 衣物（烧焦） | 蜷缩残骸俯视、残骸侧视 | 巴掌大的一团焦骸（烧前约 45cm → 烧后约 25cm） | 同上，与完好态双向互锁 |
| 动物（乌鸦） | 停枝态、展翅态 | 比手掌略大、单手可托的鸟（体长约 45cm） | 停枝 / 展翅并排即可；剧情需要「受伤垂翅态」则另出一张 |

**展示视图与状态弧的分工**：同卡并排的两个视图是**同一态的两个观察角度**（或差异极小的两种摆放）；
差异大到影响识别或交接的态 → **各出一张独立的道具展示表**，按 18A/18B 编号走版本互锁
（判据见 `资产层_锁定与一致性.md` 第八节道具状态弧原则）。

## 字段注释

| 字段 | 写法要点 |
|---|---|
| 整体风格 | **必填**：注入项目风格锚（渲染方式+色调倾向+材质做旧特征+胶片颗粒+与全片一致），避免道具与影片风格脱节 |
| 道具 | 材质+品类+颜色/做旧/状态，一句到两句 |
| 状态弧 | **必填**：先声明本卡承担哪个态，再说明哪个态要另出一张卡。判据：该态是否跨镜复用、是否影响识别或交接。（v5.6.8：场景的结构性破损同样建态，走 `scenes.*.damage_states`；"场景没有状态弧"已作废，见 `资产层_锁定与一致性.md` 第八节） |
| 展示视图 | 道具双视图并排，按上表选型。**两视图是同一态的两个角度**；两个差异态不要塞进同一张卡（见上表状态弧列） |
| 核心强制约束 | 比例维度随道具变（长宽比/盆形/刃长/衣型/体长） |
| 尺度短语 | **必带**：数值必须与用途匹配，并写成可念的尺度短语（手掌大小 / 齐腰高 / 单手持握 / 桌面摆件）。AI 默认把手持道具画成家具尺寸，没有尺度短语的设定图十有八九超标；烧焦等状态变化写"烧前→烧后"。可念尺度与数值都要写进正文（数值供人工校色核对，不是元指令） |
| 细节面板 | 2-4 项，材质/结构/状态放大，引线中文 |
| 禁止内容 | 现代材质、状态恢复等必写；**文字类道具例外**：文书/匾额类设定图允许可读文字（标题+正文示意），但必须带"乱码错字"防线（生成变形→留白后期合成）；非文字类道具仍禁可读文字 |
| 技术收尾 | "不篡改参考道具形态比例"（与角色条目的"人物面部"区分） |
