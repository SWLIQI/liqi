## 完整示例（海捕文书）

生成图片：专业3D道具展示设定表，16:9画幅，浅灰白色影棚背景，画面填满无大面积空白，蓝图辅助网格，纤细手绘辅助引导线，全部引线注释使用中文。
整体风格：写实PBR材质渲染，古装志怪电影道具质感，低饱和青灰调，做旧年代感（纸缘泛黄、墨色沉着、印泥氧化），胶片颗粒，与全片风格锚一致。
道具：清代缉捕文书，黄麻纸竖幅（约4:3），纸面顶部竖排大字标题「缉捕文书」，标题下数行竖排正文墨迹（内容示意：查得妖物假托人形剥皮害命、悬赏缉拿、知情报官者赏银五十两——文字须清晰可辨，若生成变形则以留白处理、后期合成），中央印一个无五官的人影图形（墨色人形剪影，脸部空白），下方落款行（衙门名与日期），右上角一方朱红官印（印痕图形），纸面四沿暗纹边框（回纹/云纹），纸缘泛黄卷边、有虫蛀孔与褶皱。
画面中心排布2个展示视图：平铺态、半卷态（并排展示）。
核心强制约束：两个视图使用完全一致的纸张长宽比，标题、正文行、人影图形与落款的位置、大小统一；两个视图的纸边贴合同一条水平基准线。
三视图左侧放置垂直比例尺，零刻度对齐基准线，线条向上延伸至纸顶，带有简短刻度标记，线旁标注文字“约 40 cm”。
细节面板：① 麻纸纤维纹理放大，引线标注：麻纸纹理；② 标题「缉捕文书」字迹；③ 正文竖排文字行；④ 无五官人影图形；⑤ 官印朱砂色块。
画面角落放置色板，圆形色票，每项色票旁标注中文色名与色值：麻黄 #D9C89A（纸）、灰黑 #3A3A38（墨迹）、朱红 #C1382E（印泥）、棕 #8B5E3C（轴木）。
禁止内容：现代纸张、打印感、卡通化、乱码错字（文字变形则以留白处理、后期合成，禁止乱码字符）。
写实PBR材质渲染，细节锐利清晰，整张画面光照统一，无透视畸变，全部视图采用严格正交相机，不篡改参考道具形态比例，16:9

## 常用道具视图与比例尺速查

| 道具类型 | 推荐展示视图 | 比例尺 |
|---|---|---|
| 文书/纸张 | 平铺态、半卷态 | 纸高约40cm |
| 容器（盆/碗） | 俯视（水面/内腔）、侧视（器型） | 盆口直径约35cm |
| 工具（剪/镊） | 闭合态、微开态 | 全长约18cm |
| 衣物（完好） | 叠放态、挂放态（配手掌参照） | 衣长约45cm |
| 衣物（烧焦） | 蜷缩残骸俯视、残骸侧视 | 烧前45cm→烧后25cm |
| 动物（乌鸦） | 停枝态、展翅态 | 体长约45cm |

## 字段注释

| 字段 | 写法要点 |
|---|---|
| 整体风格 | **必填**：注入项目风格锚（渲染方式+色调倾向+材质做旧特征+胶片颗粒+与全片一致），避免道具与影片风格脱节 |
| 道具 | 材质+品类+颜色/做旧/状态，一句到两句 |
| 展示视图 | 道具双视图并排，按上表选型 |
| 核心强制约束 | 比例维度随道具变（长宽比/盆形/刃长/衣型/体长） |
| 比例尺 | 数值必须与用途匹配；烧焦等状态变化写"烧前→烧后" |
| 细节面板 | 2-4 项，材质/结构/状态放大，引线中文 |
| 禁止内容 | 现代材质、状态恢复等必写；**文字类道具例外**：文书/匾额类设定图允许可读文字（标题+正文示意），但必须带"乱码错字"防线（生成变形→留白后期合成）；非文字类道具仍禁可读文字 |
| 技术收尾 | "不篡改参考道具形态比例"（与角色条目的"人物面部"区分） |
