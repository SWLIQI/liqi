# 风格锚 · 国风电影级 3D（guofeng-cine-3d）

## 零、文件头

**一句话定位**：本文件是 liqi Step 2「全片统一风格锚（九段）」在**国风电影级 3D（国产院线三维动画质感，唐代古风应用为主）**这套风格上的落值。设计参照国产院线国风三维动画的视觉管线（介于写实与写意之间、PBR 材质、次表面皮肤、电影级全局光照、体积光与大气透视），**投喂词内不点名任何具体作品**（ip 纪律同 celshade-guoman-2d）。

**适用判定**（全部满足才选本风格）：
1. 三维渲染，画面带体积光、大气透视与景深——近景饱和、中景清晰、远景蓝灰朦胧三层可辨；
2. 唐代或古风服饰形制（幞头、束发、圆领袍、宽袖交领长袍、戎装、竹编斗笠），建筑为唐式（歇山、斗拱、坊墙、城郭）；
3. 低饱和高级灰调：青绿、靛蓝、赭石、墨色打底，单一暖金（或朱砂、灯笼橙黄）重音；
4. 人物写实骨相但经动画美化，皮肤次表面透光不发蜡，发丝有丝缕光泽。
用户说「国漫 3D」「动画电影质感」「院线动画」「长安风」，或参考图是院线 3D 古风剧照时选本风格。

**边界声明**：
- 与写实轨 photoreal-pbr 的界线：photoreal 要真人毛孔、细纹与实拍感；本风格要动画美化与次表面透光。皮肤词汇互斥，混写出恐怖谷夹生脸。
- 与三渲二 stylized-pixar-3d 的界线：Pixar 档 6-6.5 头身、明亮饱和、圆润简化；本档 7-7.5 头身、低饱和高级灰。头身档与饱和方向互斥。
- 与 2D 各轨（celshade / ink-wash 等）的界线：本风格的体积、景深、大气透视是本体，一切平面化、描边、平涂词汇一律禁。

**措辞纪律表**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 点名《长安三万里》等作品名 | "Chinese 3D animated feature film look / 国产院线 3D 动画电影" | 投喂词禁点名具体作品：模型对片名响应不可控，且有 ip 风险；只写可观测特征 |
| "很写实 / 超写实" | "stylized realism between real and painterly / 介于写实与写意之间" | 写实程度必须钉在中间态，防两头滑：滑向实拍真人 or 滑向卡通 |
| "8K超高清 / 无噪点 / 柔和抗锯齿" | 删除，分辨率帧率走参数行 | 遗产画质词占字数额度且无增量效果 |

| "远山偏蓝灰" 顺手写 | 必写，且与"近景饱和"成对出现 | 大气透视是本风格空间层次的唯一来源，只写一半等于没写 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 76 词（按校验器空白分词口径实测），在全库锚中排第 11（按词数降序），中等，留有两三个词的余量。

## 五、材质与可见性预算

- **主**：面部骨相与皮肤次表面透光、发丝丝缕光泽——本风格的辨识度押在这里
- **次**：布料双材质对比（丝绸柔光 vs 棉麻织纹）、金属配饰锐利但不过曝的高光
- **省**：远景城郭山峦（压成蓝灰层次）、群像（只写数量与动势）、背景植被细节
- **可见性**：雾中人物写「仅剪影与轮廓光」；远景人物只写数量与动势不写五官
- **禁**：皮肤毛孔与真人皮肤纹理、平涂色块、描边、塑料高光、游戏实时渲染感、美颜磨皮

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| 变写实真人 / 恐怖谷（本锚头号崩点） | 写了 photoreal、毛孔、真实皮肤纹理、真实五官比例 | 压句第一句锁 "Chinese 3D animated feature film look"；皮肤只写次表面透光；删一切真人词 |
| 变卡通赛璐璐 / 三渲二 | 出现描边、两段式硬边阴影、平涂色块 | 删描边词；写多层软过渡与电影级全局光照 |
| 变游戏 CG / 实时渲染质感 | 出现 game engine、实时渲染、多边形、贴图感 | 压句写 animated feature film；材质写织纹、磨损与包浆，不写引擎词 |
| 浓雾灾难 | 大气雾效 + 丁达尔 + 体积雾在同一段三连发 | 单镜雾效词只留一种；雾只负责近中远三层透视 |
| 饱和度失控、强调色泛滥 | 没写色彩预算，暖金朱砂橙黄同时上 | 每镜唯一重音色三选一；基底压回青灰调；配色句与压句同时出现 |
| 唐代形制穿帮（服饰混搭 / 建筑西化） | 多套发型服装并存、建筑词含糊 | 单图锁死一套形制；建筑写唐式歇山斗拱坊墙，禁西式塔楼圆窗 |
| 暗部死黑或发灰 | 平台默认管线把阴影压成中灰或纯黑 | 写暗部吃环境色（冷场偏蓝紫、暖场偏暖棕）且保留细节 |
| 空间层次丢失、远景糊成一片 | 没写大气透视三段式 | 必写「近景饱和、中景清晰、远景蓝灰朦胧」三层 |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对（对应 L0 `dedupe_pairs`）

| 污染词 | 替换词 | 为什么 |
|---|---|---|
| 皮肤毛孔 / skin pores | 皮肤次表面透光 / soft subsurface skin | 毛孔是 photoreal-pbr 的词，会拉向真人恐怖谷 |
| photorealistic | stylized 3D animated | 写实度钉回风格化动画 |
| cel-shaded / 赛璐璐 | soft multi-tone shading / 多层软过渡渲染 | 两段式硬边是三渲二的词，会毁掉软过渡 |
| 两段式硬边阴影 | 多层软过渡阴影 | 同上 |
| 平涂色块 | 带体积的渲染材质 | 平涂是 2D 轨的词 |
| game CG / 游戏实时渲染 | 3D animated feature film / 院线动画渲染质感 | 引擎词会把画面推向游戏过场而非电影 |
| 浓雾弥漫 | 远景蓝灰朦胧，近景清晰饱和 | 雾效过量反杀空间层次 |
| 8K超高清 / 柔和抗锯齿 | （删除） | 遗产画质词占额度无效果 |
| 高饱和撞色 | 低饱和高级灰，单一重音色 | 色彩方向钉死 |
