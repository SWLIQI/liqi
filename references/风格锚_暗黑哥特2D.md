# 风格锚 · 暗黑哥特 2D（`gothic-2d`）

## 零、文件头

**一句话定位**：本文件是 liqi Step 2「全片统一风格锚（九段）」在 **暗黑哥特 2D** 这套风格上的落值。
L0 数值事实源为 `style-registry.seed.json` 的 `styles["gothic-2d"]`，本文件是它的散文展开。

**适用判定**（看到这些特征才选本风格，不看题材名）：

- 用户点名「暗黑哥特 / 哥特 2D / 维多利亚暗黑童话 / Tim Burton 式 2D / Edward Gorey 式 」；
- 设定图是**平面手绘**质感：单色墨线勾边、平涂色块、硬边剪影阴影，无渐变无高光；
- 配色被压在冷月雾蓝与墨黑紫之间，明暗对比拉到剪影级，暖色只由烛火 / 提灯 / 月光一处承担；
- 人物瘦长脆弱：四肢与指节拉长、肩窄、头略大、眼大而深陷、眼窝一片阴影、肤色苍白灰调；
- 题材落在：哥特庄园与古堡、维多利亚孤儿与钟楼、乌鸦与鸟笼、八音盒与怀表、雾街与铁艺墓园。

**与相邻风格的边界**（混了会怎样）：

| 相邻风格 | 边界 | 混轨后果 |
|---|---|---|
| `gothic-puppet`（哥特定格木偶） | 那条轨要「假」——黏土、布偶、微缩实拍，有真实体积与景深；本风格要**平面**，色块平涂、硬边剪影、无体积无景深 | 一面出现黏土皮肤或微缩布景，画面会在「平面动画」与「实物拍摄」之间夹生，两边都不成立 |
| `anime-2d`（日系动画 2D） | 日系靠彩色描边 + 高饱和 + 明亮肤色；本风格是墨线单色勾边 + 冷灰同色系 + 苍白灰肤 | 出现「动漫感 / 大眼睛 / 彩色描边」，本风格的剪影压迫感立刻被稀释成普通日系番剧 |
| `ink-wash-2d`（水墨淡彩） | 水墨要晕染、纸纹、留白与墨色浓淡；本风格要平涂、均匀墨线、不留湿痕 | 出现「晕染 / 水彩 / 纸纹」，画面转成东方手绘，哥特的铁与石全部失去硬度 |
| `photoreal-pbr` / `documentary-live-action`（写实轨） | 写实轨要真实皮肤毛孔与 PBR 材质；本风格连皮肤纹理都不要 | 出现毛孔、皮肤次表面、真实景深，平面本体被推翻，且与「恐怖谷」叠加成审核高危 |
| 平面工艺四风格（`papercut-2d` / `shadow-puppet-2d` / `guochao-2d` / `nianhua-2d`） | 那四套的物理本体是「材料」（红纸 / 皮料 / 靛青金线 / 套色无影）；本风格的本体是「画」——墨线加平涂 | 出现剪纸刀口、皮料透光或金线，画面从「画」掉进「工艺实物」，色域也被拉去高饱和 |

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | **平面 2D 动画画面**（媒介声明放第一句，不许挪到后面）。手绘墨线勾边，线条细而匀、带轻微手抖；色块平涂，硬边剪影式阴影；全画面无渐变、无体积光、无高光、无景深虚化。暗部始终留得住形，绝不死黑。 |
| ② 配色与色域 | 冷月雾蓝（`#7E8A9B`）为底，墨黑紫（`#241F2E`）压暗部与轮廓；**唯一重音色只由暗绯红（`#9C2B36`）承担，且只由画面里的一处红色物件承担（缎带 / 领结 / 内衬）**。其余全部压进同色系冷灰。禁高饱和、禁霓虹色、禁粉彩。 |
| ③ 运动签名 | 24fps 平缓节奏。动作幅度小、**起收各留半拍静止**；人物移动带轻微顿挫，不做丝滑过渡。镜头以固定为主，缓推与缓摇为辅。禁甩镜、禁 360 度环绕、禁多层视差横移（平面会露馅）、禁快速变焦。 |
| ④ 角色锁定 | 走 `<Subject N>`：**6–6.5 头身**（头身比必写），瘦长脆弱体型，肩窄，四肢与指节明显拉长；头略大，眼大而深陷，眼窝一片阴影，下颌线清瘦；肤色苍白灰调（`#D9CFC6`）不带红晕；服装走维多利亚形制——高领、长袖、束腰、裙撑或燕尾、成排纽扣、深色厚料。 |
| ⑤ 场景锁定 | 维多利亚形制建筑：尖拱窗、陡坡屋顶、铁艺栅栏与尖顶、煤气灯、砖石墙面、雾街。室内深色木作、壁炉、厚帷幔、螺旋楼梯、钟摆与长走廊。**同场景跨镜的地标与光位必须一致**，地标写进连续性台账的空间行。 |
| ⑥ 道具锁定 | 乌鸦、鸟笼、怀表、提灯、烛台、黄铜钥匙、旧书、剪刀、八音盒、棺形木盒。**入画方式必写**（手持 / 悬挂 / 置地 / 笼中），不写入画方式的道具会飘在半空。 |
| ⑦ 光色基调 | 主光只有一个，且必须有画面内依据：烛火、提灯、壁炉或冷月光。入射角写低（侧下或侧上），衰减快，**影子是硬边剪影并被拉长**。禁全局均匀打光、禁顶光平打、禁霓虹与屏幕光。 |
| ⑧ 声音签名 | 环境层：远处教堂钟声、木地板吱呀、排水管滴水、风穿过铁栅栏的低鸣。动作层：布料摩擦、门轴长吟、金属轻碰、烛火轻爆。呼吸层：浅而慢，几乎不闻（紧张段可反向做强）。配乐：八音盒 / 单簧管 / 大提琴，小调、慢速、稀疏单音，**默认稀疏到接近静默**。 |
| ⑨ 排除项 | H3 面丢弃（无 negative 字段，靠正面陈述锁定）；Seedance 2.5 与国内面把负面压缩成 **Must not 一行**附于正文末。本风格负面词方向见第九节 9.1，不与手绘轨 / 定格轨共用。 |

### 措辞纪律表（防回退）

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 哥特风、暗黑系、氛围感 | 平面 2D 动画 + 维多利亚暗黑童话 + 具体材质词 | 铭牌词没有唯一解，模型会自己挑一种，多半挑成写实恐怖片或 3D 暗黑风 |
| 诡异的氛围、阴森 | 冷月雾蓝与墨黑紫、硬边剪影阴影、唯一烛光 | 情绪标签模型演不出来，只会补饱和 + 高斯模糊 + 暗角，画风立刻散 |
| 唯美、精致、高级感 | 苍白灰调肤色、细匀抖动墨线、平涂色块 | 唯美词把画面推向日系精修插画，与本锚粗粝的剪影压迫感相反 |
| 大眼睛动漫人物 | 眼大而深陷、眼窝重阴影、瘦长脆弱体型、6–6.5 头身 | 「动漫」触发日系彩色描边与高饱和，直接串到 `anime-2d` |
| 电影感、影视级、有质感 | 平面动画、无景深虚化、无体积光 | 「电影感」把平面上色推成电影 CGI，平面本体被推翻 |
| 恐怖、惊悚 | 剪影与留白承担不安；绯红只作为一处重音 | 恐怖片词汇引来脏器特写与畸形肢体，本风格的不安来自形与光，且过审风险高 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 144 词（按校验器空白分词口径实测），在全库锚中排第 1（按词数降序），偏长——**加词前必须先想清楚删哪一句**。

## 三、色值表

| 用途 | HEX | 说明 |
|---|---|---|
| 画面底色 | `#7E8A9B` | 月雾灰蓝：雾、砖石墙、夜空基底（L0 `palette.primary`） |
| 暗部与轮廓 | `#241F2E` | 墨黑紫：勾边、暗部、帷幔与木作（L0 `palette.secondary`） |
| 唯一重音色 | `#9C2B36` | 暗绯红：只由画面里的一处红色物件承担，与光源色分开计算（L0 `palette.accent`） |
| 亮部 | `#E8E4DC` | 冷月光白：受光面与雾的边缘，不许扩成大面 |
| 肤色 | `#D9CFC6` | 苍白灰调，无红晕、无红晕、无鼻尖高光 |
| 夜间基线 | `#14101A` | 最深暗部，仍保留色块边界，不许糊成纯黑 |

**色彩预算纪律**：每镜只声明一个唯一重音色，其余全部压进冷灰同色系。不声明色彩预算，模型会自发补饱和度，全片色调立刻散掉——这是平面风格里最快的一类崩塌。

**同步纪律**：本表前三行与 L0 `palette` 逐项一致，改一处必须同步另一处。

## 六、崩点清单与反制

按「最容易变成什么 → 什么词触发它 → 怎么正面钉死」写。

| 崩点 | 成因 | 反制 |
|---|---|---|
| 变 3D 渲染 / 皮克斯立体感 | 材质词没配平面词；正文出现立体、体积、建模、次表面、渲染 | 压句逐字复用；每个材质词后跟「平涂」与「无体积」；媒介声明放第一句 |
| 变日系动漫赛璐璐 | 出现动漫感、大眼睛、彩色描边；肤色写明亮 | 写「墨线单色勾边」「冷灰同色系」「眼窝重阴影」「肤色苍白灰调」；头身比压到 6–6.5 |
| 变写实恐怖片 / 恐怖片 | 出现恐怖、惊悚、惊悚、腐烂；皮肤写毛孔 | 不安由剪影与留白承担；暗红只作一处重音，不成块不流动；皮肤写苍白灰调无纹理 |
| 比例滑向可爱 Q 版 / chibi | 头身比没写死，或写了「可爱」「萌」 | 压句固定 6–6.5 头身 + 瘦长四肢 + 肩窄；禁写任何可爱向词 |
| 变水彩绘本 / 手绘淡彩 | 出现晕染、水彩、纸纹、柔和过渡 | 写「平涂」「硬边」「均匀墨线」「无晕染无湿痕」 |
| 串到 `gothic-puppet` 定格轨 | 出现黏土、木偶、微缩布景、定格、实拍布景 | 写「平面 2D 动画」「一张平面的画」；禁写任何实物材料名 |
| 画面糊成纯黑，形全丢 | 暗部压太死，或写了「纯黑」「死黑」 | 写「暗部始终留得住形」「最深暗部仍保留色块边界」 |
| 饱和度自己涨回来 | 没声明唯一重音色 | 每镜写色彩预算一行，点名重音色及其画面内依据 |
| 雾气糊成一片灰 | 雾没写层次与边缘 | 雾写「分层且边缘清晰」，第 2 层以后不交代细节 |
| 铁艺与砖石写成实拍质感 | 用了「锈迹斑斑」「岁月痕迹」这类真实材质词 | 改成线描密度词：铁艺写「线条细密均匀」，砖石写「以墨线勾出砖缝」 |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删立体词与写实词**（与定格木偶轨相反——那条轨删的是丝滑词）。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 哥特风 | 平面 2D 动画 + 维多利亚暗黑童话 | 铭牌词没有唯一解，模型自选多半选成 3D 或写实 |
| 氛围感、诡异感 | 冷月雾蓝与墨黑紫、硬边剪影阴影、唯一烛光 | 情绪标签只会换来饱和 + 高斯模糊 + 暗角 |
| 唯美、精致 | 苍白灰调、细匀抖动墨线、平涂色块 | 唯美词推向日系精修插画 |
