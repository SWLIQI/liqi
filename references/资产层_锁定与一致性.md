# 资产层：锁定与一致性

> 🔗 流程位置：**Step 2.5**（A1 以上必做）。上游＝Step 0 资产依赖分级；下游＝Step 3 逐镜的 `@锚点` 引用。
>
> 本层分工：**出图版式统一为 4 View 角色资产板**（一卡同时给身份锚与三向身体参考），**像素账铁律、注册表、光照锚点**来自本 skill 的资产链，**文字锁、门禁、亲缘推导**为在此基础上补齐的规则。
>
> ⚠️ **2026-09-15 修订**：本层原先保留「A2/A3 走 liqi 九视图三卡、A1 退化为 4 View」的分歧版式，现已撤销——**版式全部统一为 4 View 资产板**。原 liqi 三卡体系退为「按需补出」的两类单卡，默认不出。版式分歧已按本节结论统一，不再保留分歧记录。

## 一、 依赖分级（先分级，再决定要不要建资产链）

不分级会让单镜小活被整套资产流程拖死。

| 级别 | 条件 | 资产动作 |
|---|---|---|
| **A0** | 纯文字 / 单镜 / 无一致性要求 | 不强制资产链，文字描述可直投，禁用 `@锚点` 即不受门禁约束 |
| **A1** | 单角色单镜 | 资产可选（有参考图更稳）。出 4 View 板即可，不补任何额外卡 |
| **A2** | 跨镜角色 / 场景一致性 | 启用相关角色与场景资产出图，角色走完整 4 View 板 |
| **A3** | 多人 / 多场景 / 连续剧集 / 高一致性 | 完整执行本层（默认档）：4 View 板 + 按需补卡 + 注册表全量维护 |

**判定不清按高一级处理。**

> 两边的分级原意不同：liqi 默认所有角色都出三张卡——对 A0/A1 是纯浪费；分级是老李补进来的。
> 本层现在**版式只有一种（4 View）**，分级只决定「要不要建资产链、要不要按需补卡」，不再决定用哪套版式。

## 二、 角色资产板：统一的 4 View 版式

**本 skill 只用一种角色资产版式——4 View 资产板。**不分 A 级、不分题材、不设第二套。

### 出图顺序（图生图链，前一张没锁定不进下一张）

```
4 View 角色资产板（文生图，全链唯一身份锚）
  ↓
专属道具表（独立文生图）
  ↓
人物使用道具图（图生图，参考 4 View 裁片 + 道具表）
```

**前一张没锁定（脸稳、色准）不进下一张。**

### 4 View 资产板的构成

| 区 | 内容 | 作用 |
|---|---|---|
| **左区** | Face Close-up 头部近景 / 面部特写 | **身份锚**——五官骨相、眉眼间距、瞳孔色泽、皮肤肌理 |
| **右区** | 无头 Front View 正面全身 | 服装正面廓形、配色、结构 |
| **右区** | 无头 Side View 90° 侧面全身 | 侧身厚度、服装侧面结构（**纯侧，不露正面五官**） |
| **右区** | 无头 Rear View 背面全身 | 背面结构、后颈发际线以下的发尾走向、衣背纹样 |
| **附** | 全身比例尺（身高如 180cm / 168cm；头身比按 `扩展面板与比例色彩速查.md` 第四节档位表选定——写实 7–7.5／国产 3D 与美型 7–8／日式 3D 动漫 6–6.5／日式 2D 5.5–6.5／卡通 4–5／Q版 2–3，**不只 6.5~8 这一段**） | 跨镜身形一致 |
| **附** | 细节材质三联（布料微距肌理 / 发型流向与碎发高光 / 纽扣袖口配饰） | 防「塑料感」 |
| **附** | HEX 三色（Primary / Secondary / Accent） | 跨批次色偏的唯一锚 |

### 🔴 右区「无头」的措辞纪律（2026-09-16 实测补入）

**不要只写「无头」。** 右区三格实测仍会画出一个头，三层原因叠加：

1. **「无头」是否定式约束**，人物立绘的先验太强，模型多半照画一个头。
   改成**构图式指令**——「从颈根以下取景，头部完全落在画框之外」。
   模型对「画框外 / 裁掉」的遵循度远高于对「不存在」的遵循度。
2. **提示词里带头部特征等于点名让它画**：发髻、发冠、发带、须发、刘海、麻花辫，
   这些词一出现，右区就会多一个头。角色描述里的头部项**只作用于左区**，
   抄进右区描述前必须先删干净。
3. **一次出三格注意力分散**，漏一格整板就废。

**右区取景强制串（逐字照抄，中英文都要）**

```
中文：右区三格一律从颈根以下取景，头部完全落在画框之外，画面上沿在颈根处平切；
三格内不出现头颅、面部、头发、发髻与任何头部轮廓。
英文：The three right panels are cropped at the base of the neck with the head
entirely out of frame; only the shoulders, collar and torso are visible —
no head, no face, no hair, no topknot in any of the three right panels.
```

Negative 追加：`head, face, hair, topknot, skull, ear, second head, extra head,
floating head, three heads, head above the collar`。
⚠️ **不要写 severed / decapitation / blood**——那会激活切面与血肉语义，
撞本 skill 的血肉 / 切面类安全边界。

**图生图补板时尤其危险**：投喂的参考图（双视图）里本身有大头 + 有头全身，
模型会直接把「有头」抄进右区。走三步法：
① 先把参考图的头部整块裁掉得到无头正面全身；
② 以它为参考**分格**出侧面与背面，每次只出一格；
③ 左区头部近景 + 三格 + 三样附加项拼版，拼版用外部工具，不要让模型重画。

**仍出头时的兜底**：右区改写成服装展示语义
「这套服装穿在无头人台上展示（garment on a headless mannequin）」。
人台会带一点塑料与接缝感，只当兜底，不作默认版式。

💡 **为什么只用一卡**：4 View 板在同一张图上同时给出**身份锚 + 三个方向的身体参考**。原 liqi 三卡体系需要分别出「双视图人设卡 + 侧背补锚卡 + 九视图人设卡」三张，其中侧背补锚卡要做的事（侧面 / 背面头部）与九视图要做的事（表情 / 机位）**在短片工况下大部分用不上**——多出的两张卡是纯成本。

💡 **90° 侧面与 C10 的取景禁令不冲突**：本表里的 90° 是**设定图的画法角度**（人物在纸面上被转过来），C10 禁的是**中景/全景镜头的机位角度**（防街机横板感）。两回事，不要互相套用。

### 🔴 像素账（liqi 的实测结论，升级为独立铁律保留）

在 3840×2160 原生分辨率下实测：**4 View 板左区头部近景裁开后，脸约 1922 px；右区全身格裁开后，脸仅约 320 px。**

两者的差距是 6 倍。这直接定死了一件事：

> **全身图不能当身份锚。**把右区的全身格单独投喂，模型读不清五官，只能现编——脸必漂。

由此定死投喂分工：

| 用途 | 用哪一区 | 理由 |
|---|---|---|
| **身份锚（正面五官）** | 左区头部近景 `face_hd` | 唯一像素足够的（约 1922 px） |
| **侧脸轮廓 / 后脑发型** | 右区 Side / Rear View | 正面脸给不了鼻梁、下颌线、耳朵、发髻结构 |
| 服装款式 / 配色 | 右区 Front View | 锁廓形与配色 |
| 机位 / 体型参考 | 右区全身三格 | **别指望它锁脸** |

### 按需补出的两类单卡（默认不出）

4 View 板覆盖不了以下两件事，**只有剧本确实用得上时才补单卡**，不列入默认流程：

| 补卡 | 触发条件 | 说明 |
|---|---|---|
| **侧 / 背头部特写卡** | 片中有侧脸或背身**特写**（不是中远景） | 右区三联是**无头**的，给不了侧面/背面头部的五官与发型细节。用图生图从 4 View 裁片出，要求「纯侧面 / 纯背面，不露出任何正面五官」 |
| **表情参考卡** | 剧本需要 ≥4 种差异较大的表情，且这些镜要走全量 FACS | 出**纯表情网格**（不要连全身三视图一起出）。注意 liqi 的像素账：表情格约 600 px，**够看表情怎么摆，不够锁五官**——它只当参考，不能当锚 |

⚠️ **本 skill 默认不出 liqi 的「九视图人设卡」**（左 2/3 全身三视图 + 右 1/3 六表情那版）。理由：它的全身三视图部分与 4 View 右区重复，表情部分精度不够锁五官，而它要多占一张卡的生成成本与投喂位。**真需要表情参考就出纯表情网格，不要九视图。**

### 🔴 三条投喂铁律

1. **任何镜头都要带一张 `face_hd`（左区头部近景）。** 全身图单独喂，脸一定漂——320 px 的脸模型仍读不清五官，只能现编。
2. **侧面和背面镜头必须额外带对应的高清头部图。** 4 View 右区三联是**无头**的，只给正面脸，模型不知道这人侧脸什么样、后脑勺什么样，转过去就换了张脸。**片中有侧/背特写就补侧背头部特写卡**（见上）。
3. **Hero Image 锁定，中途不换参考集。** 4 View 板裁完后选定一张最优图做全项目主参考。**中途更换参考集是重新引入漂移最快的路**——哪怕新参考「看起来更像」。要改，回板上改。

**分层投喂（省钱且防漂）**：

| 镜头类型 | 投喂方式 | 理由 |
|---|---|---|
| 特写 / 近景（脸是重点） | I2V + 参考图；**prompt 只写动作运镜，不重复描述长相** | 参考图已锁长相，重复描述反而干扰 |
| 远景 / 切出镜头（脸小） | **文生视频 + 提示词锚**，不投参考图 | 观众对小脸不敏感；服装+体型描述足够维持错觉 |
| 群戏 | 从已确立的角色图 I2V 出 | 多主体从文本直出是重灾区 |

**转身镜头技巧**：首帧给背身、尾帧给正脸，模型必须在两个锚之间保持同一个人——**用动作本身强制身份一致**，比「喂一张背面图求它别漂」稳得多。

**转头 60° 禁区**：跨模型实测的共同弱点——侧脸超过约 60°，五官就开始靠先验编。**分镜设计时侧脸镜头角度尽量 ≤60°；必须大转头的戏用转身首尾帧法拆解。**

## 三、 文字锁：16 项必写

**4 View 资产板上必须写满。**这 16 项取自老李——liqi 原来只要求「严格沿用参考图片全部五官样貌」，**那是笼统指令，不是清单**。

### 五官 10 项（杜绝脸部漂移）

1. **脸型骨相**（方圆脸 / 冷艳瓜子脸 / 重颌方脸）
2. **眉形细节**（平直剑眉 / 微挑柳叶眉 / 断眉）
3. **眼型与眼窝**（狭长丹凤眼 / 深邃眼窝杏眼）
4. **瞳色与反光**（深褐琉璃瞳 / 赤金锐利高光）
5. **鼻梁山根**（高挺直鼻 / 小巧微翘驼峰鼻）
6. **唇形与唇色**（薄唇微抿 / 朱红饱满唇峰）
7. **下颌线条与折角**（下颌线清晰锐利 / 方正刚硬）
8. **耳廓耳型**（贴脑耳 / 白净分明耳廓）
9. **标志性特征**（眼角泪痣 / 眉心浅疤 / 断鼻骨）
10. **面部肌肉与肤色**（冷白无暇 / 古铜粗糙 / 刀削般体块）

### 服装 6 项（杜绝塑料感）

1. **面料类别**（重磅斜纹棉麻 / 做旧哑光皮革 / 高密生丝）
2. **编织与表面纹理**（粗糙麻织肌理 / 皮革龟裂细纹）
3. **垂坠受力与硬挺度**（厚重硬挺垂坠 / 贴身流线）
4. **战损污损与做旧细节**（袖口磨损起毛 / 衣角泥水浸润 / 领口汗渍）
5. **金属与扣具光泽**（哑光拉丝古铜扣 / 冷银拉链反光）
6. **缝纫与剪裁工艺**（双排工整明线 / 暗青色提花刺绣）

### 🔴 性别锚点（必写）

**面部特写句必须以 `X~Y岁男性/女性（身份代称）` 收尾**（如 `24~26岁青年女性`、`55~60岁老年男性（老将）`）。

**为什么**：只写「老将 / 文士 / 武将」等身份代称，或只写年龄段，**模型会自行推断性别导致漂移**。所有下游投喂词（人物入场句）提及该角色时，性别指向必须与资产板一致——女文士不能写成「青衫文士」。

## 四、 亲缘推导（家族 / 师徒戏必做）

liqi 完全没有这一层。**禁止孤立生成配角。**

### 梯队划分

- **T1 核心基准**：男一号、女一号。率先锁定脸模与核心画风
- **T2 亲缘 / 亲密**：父母、子女、兄弟姐妹、情侣、核心反派
- **T3 功能配角**：同门、手下、管家、路人

### 推导参数（推导后**直接出图**，不是文字推导）

- **骨相继承**：继承 T1 角色 **40%~60%** 的下颌骨轮廓或眼眶深浅
- **五官关联**：如母亲与女儿共享相同鼻型与眉形弧度，**仅在眼尾纹理与面部胶原蛋白丰满度上作年龄化差异**
- **色彩呼应**：家族成员在服装 HEX 调色板中**共享至少 1 个** Secondary / Accent 色值
- **出图方式**：复用 T1 的底色 / 材质描述 + 差异化参数，直接生成 T2 的资产卡

## 六、 注册表：跨批次一致性的唯一保障

会话记忆会丢，**注册表不会**。

### 定位顺序

**以 `资产注册表_asset-registry.md`「落盘位置」一节为唯一依据**（用户指定目录 → 项目内已有资产目录 → 参考图同目录 → 项目根；三处都没有则先声明再新建）。本文件不另立顺序——历史上两处顺序不同、兜底行为一个问用户一个静默建，那是缺陷，已统一。

### 动手前先扫已有资产

- 列一遍注册表中已存在的**角色 / 道具 / 场景**条目
- **复用既有条目编号、身高、色值与互锁词**；场景条目还要复用 `lighting_anchors`、`light_port`、`permanent_marks`
- **禁止为已注册资产另起一套数值**——这是跨批次穿帮的头号来源

### 主动检索参考图

不要假设用户会主动给图。主动扫项目内已有资产图（`characters/`、`assets/`、`storyboard/`、`*.png`），存在相关图就作为图生图参考并记入 `reference_files`。

### 回写

本轮产出的每个条目结束后必须写回注册表——编号、身高、色值 HEX、互锁词、参考图路径、`durable` 标志物清单。

**`durable` 不掺情绪**：里面只有**跨场次成立**的事实（长在身上的标志物、义肢、发簪、痣）。表情、姿态、伤口、湿衣、持物等**瞬时状态不许混进去**——它们会污染后续所有场次。

schema 见 `资产注册表_asset-registry.md`。

## 七、 版本拆分与互锁

任何资产需要多版本时，**单独成条目、独立生成**。

| 版本触发条件 | 示例 | 处理 |
|---|---|---|
| 服装阶段切换 | 前期素白中衣 → 中秋后藕荷衣裙 | 拆 A/B 条目，各自独立出图 |
| 体态状态切换 | 正常版 → 瘦脱形版 | 拆两条目，正常版负面词禁瘦脱形 |
| 道具阶段切换 | 小衣完好态 → 烧焦态 | 拆两条目（18A/18B），各配互锁负面词 |
| **场景时间线切换** | 停尸房在正午 / 黄昏 / 深夜各一次 | 拆三条目，各配光照互锁词 |
| 单一版本 | 全片一套服装的角色 | 一条目即可 |

### 🔴 版本互锁负面词（硬规则）

拆出的每个版本，**禁止内容里必须写入「禁用另一版本的特征」**（A 版禁藕荷色、B 版禁素白中衣、完好态禁焦黑、烧焦态禁恢复完好），防止生图工具混入其他版本特征。

**场景时段版本要从三个维度同时下刀**——色温、光质、影子形态。只禁一个维度挡不住串版（夜版要同时禁「日光」「天光」「均匀照明」「暖黄烛光晕」）。

**先定 `baseline_time`（基准时段）再出变体**：基准版锁死空间结构、陈设布局、色板；其余时段变体**只改光照字段**，陈设与空间一律复用。否则同一场景的不同时段会被画成两个不同的地方。

### 换装走图生图编辑，不重出全卡

```
以这张图片为参考（角色全身正面站姿）。
保持人物面部五官、发型、头饰、姿势、构图与背景完全不变，
仅将服装{旧描述}替换为{新描述：颜色+材质+款式+结构}。
Negative Prompt: 面部改变，发型改变，姿势改变，背景改变，{旧服装特征}，{版本互锁词}。
```

**脸和发型被锁住** → 新卡天然继承锚定能力，不会出现「换了衣服换了个人」。

## 八、 光照锚点

**四值只从 `lighting_anchors` 取，禁止现场编**：色温、入射角、影子形态、人工光状态。

| 时段 | 色温 K | 入射角 | 影子 | 人工光 |
|---|---|---|---|---|
| 拂晓 | 6500–8000 | 无明确方向 | 几乎无、极柔 | 烛火将熄 |
| 晨 | 5000–5600 | 15–30° | 长、较清晰 | 灭 |
| 正午 | 5500–6500 | 60–90° | 最短、锐利 | 灭 |
| 午后 | 4500–5000 | 30–45° | 中长 | 灭 |
| 黄昏 | 2000–3500 | 5–15° | 极长、拉伸 | 将燃 |
| 入夜 | 2000–2700 | 点光源 | 短、围绕光源 | **点亮** |
| 深夜 | 7000–10000 | 单一 | 浓黑、对比极强 | 残烛 / 无 |

⚠️ **黄昏与入夜最容易混**：都是暖色，但黄昏是低角度日光（有明确方向、投长影），入夜是点光源（无方向性、光域小、衰减快）。**互锁词必须能区分这两者。**

**两条铁律**：

1. **同一场景 × 不同时间 → 必须可区分**：色温、光斑位置、影子长度、人工光、曝光，**五项至少变三项**
2. **不同场景 × 同一时间 → 必须一致**：色温、光位、光质、粒子、曝光，**五项全部对齐**

**进光口登记为固定项**（`light_port.fixed = true`）：进光口是建筑结构，跨时段不变——变的只是太阳角度决定光斑落在哪里、影子多长。这是「同一场景跨时间既有变化又可辨认」的几何基础。

## 九、 色值双轨

**中文色名 + HEX，缺 HEX 视为不合格。**

「藕荷色」「瓷白」这类中文色名在不同生图模型里解释漂移极大，是跨批次色偏的主因；HEX 给出确定锚点。

- 色值**只从注册表取**，已注册角色的色值禁止重新编造
- 4 View 板与所有下游卡共用同一套色板 HEX，**改色必须全卡同步**
- 生图模型对色板上的 HEX 字符渲染不稳时，允许弱化 HEX（保留中文色名），但**落盘 `.md` 里 HEX 必须完整保留**，作为人工校色依据
- 场景条目**不画色卡**，色值只落盘注册表与 `.md`

## 十、 非写实风格适配（皮影 / 剪纸 / 水墨 / 版画）

本层模板默认**写实 PBR 3D**。遇到平面侧影风格时，六处必须改：

| 原模板 | 非写实适配 | 理由 |
|---|---|---|
| 三视图（正/侧/背） | **侧影 / 正面 / 关节分解** | 皮影角色本身就是侧影，正背视图无意义；关节分解才是工艺核心 |
| 写实 PBR 材质渲染 | **平面材质 + 透光**（牛皮雕刻 / 宣纸晕染 / 水墨渗化） | 光是背后透射，不是正面布光 |
| 严格正交相机 | **平面化构图，无透视** | 无纵深 |
| 头身比 7（写实档） | 皮影 **5 头身**；剪纸 **4–5**；水墨按题材定 | 民间造型的夸张比例，写实档会失去味道 |
| 身高参照线 | **影人 / 画面实体尺寸线** | 皮影影人约 30–45cm，用工艺尺寸更有依据 |
| 场景 2×2 四视角 | **全景 / 前景层 / 陈设特写 / 空镜无特效版** | 平面背景板没有仰视俯视；改出「分层」与「可合成的空镜」 |

**保留不动**：六层结构 → prompt 双输出、色板中文色名 + HEX、场景禁止出现人物、面板 ≤4、版本互锁、全部引线中文。

### 两条非写实专属纪律

1. **特效层是独立物理层，不是后期效果**。皮影的雾、光柱，剪纸的衬底，水墨的留白——都要在提示词里写成**独立的半透明皮料层 / 独立的宣纸层**，否则后期无法分层合成。
2. **暗部必须提亮一档**。写实里的暗部在平面化后会变成死黑一片，镂空花纹全丢。换算规律：**提亮一档 + 降饱和一档**，再把色值归到该风格的限定色板内。

## 十一、 面板密度与字数

- **面板密度预算**：单张设定图的独立面板（局部放大、独立道具、细节面板）**不超过 4 个**。面板过多时生图模型会丢元素或互相污染，宁可拆成两张图
- **正文字数按面板数分档**：面板 3–4（完整档）约 **650–900 字**；面板 ≤2（精简档）**200–320 字**。判据是**面板数**，不是字数
- **服饰 / 布料条目必须写出织法、厚度、缝线、袖口、褶皱、垂坠、光泽、做旧中的至少 4 项**，禁止只有「布料垂坠」一句带过

## 十二、 生成后诊断

### 每张卡必做的六项漂移检查

出图 ≠ 完成。拿到手先过一遍，**检查基准＝注册表 `durable` + 卡面提示词逐项比对**，不凭印象。

| # | 检查项 | 对照什么 |
|---|---|---|
| 1 | 脸：脸型 / 五官 / 年龄感与锚点卡一致 | 4 View 左区头部近景 vs 下游卡、左右脸互检 |
| 2 | 剪影：整体轮廓（发型外轮廓、身形）没变形 | 与 4 View 右区三联比对 |
| 3 | 服装：款式 / 结构 / 配色与卡面描述一致 | 提示词外貌段逐项 |
| 4 | 色板：画面实际用色 vs 注册表 HEX | 抽 2–3 个主色目测 |
| 5 | 标志物：`durable` 清单里的东西都在且形制正确 | 提示词里写死的形制细节 |
| 6 | 风格：渲染方式 / 背景体系与全包统一 | 总起句背景 vs 实际背景 |

**任何一项不过 → 先修，不要带着瑕疵进图生图链**（瑕疵会被下游全部继承）。

### 🔴 Fix at the sheet, not the shot

某个分镜里角色细节错了，**不要反复重抽那个镜头**——回设定卡定位错误面板，修正卡片，之后所有镜头继承修复，只重抽受影响的镜头。

反复重抽同一镜头会引入新的随机漂移，且每次重抽都在消耗「这张卡还是对的」的信心基准。

### 高频故障速查

| 症状 | 优先怀疑 | 修法 |
|---|---|---|
| 左右两张脸不一样 | 一致性约束太弱或太靠后 | 把「必须保障左右两侧角色长相特征完全一致」提到排版段末尾强调位；仍不行则拆成两张独立图各出一次，取各自最优再人工拼 |
| 一张图里两个人 / 人脸重影 | `@` 标签缺失，模型猜错了 | 补 `@ImageN is …` 用途声明 |
| 脸漂（每个镜头长得不一样） | 没带 `face_hd` | 加 4 View 左区头部近景图 |
| 侧脸轮廓不对 | 只有正面锚，侧脸靠脑补 | 补侧背头部特写卡的 `face_side` |
| 后脑发型不对 | 只有正面锚 | 补侧背头部特写卡的 `face_back`；或改用转身首尾帧法 |
| 该纯侧不纯（混进 3/4 侧脸） | 侧背头部特写卡没锁死角度 | 卡上补「纯侧面」「不露出任何正面五官」重出 |
| 服装款式对但布料像塑料 | 只有款式锚没有材质锚 | prompt 补面料词 ≥4 项；服装大特写镜头按需出服装局部特写 |
| 换装后「换了个人」 | 换装时整卡重出，脸跟着漂 | 别重出——用图生图换装编辑，面部发型姿势构图全部锁死只改衣 |
| 不同场景里衣服颜色跳 | 把光照偏色误当成服装问题 | 服装色锚 = 注册表 HEX；场景内偏色由光照锚点管，**禁止改服装卡** |
| 跨批次色偏 | 只有中文色名无 HEX | 补 HEX，并从注册表取色而非重编 |
| 动漫角色显得成人化 | 头身档位错（用了写实 7–7.5） | 按目标观感重选：日式 3D 动漫 6–6.5、日式 2D 5.5–6.5 |
| 面板被吞（少画了） | 密度超预算 | 拆成两张图，或砍到 ≤3 个面板 |
| 混入另一版本特征 | 互锁词缺失或太弱 | 强化互锁负面词，并把另一版本特征写进禁止内容的**最前面** |
| 角色卡里冒出道具 | 缺道具分离约束 | 角色卡加「空手站立，不持任何道具」硬约束 + 负向词「角色手持或佩戴任何道具」 |
| 持物图道具形制漂移 | 双锚定失效 | 核心强制约束点名道具表条目并写「禁止重新设计道具」，道具表 HEX 直接列进提示词；负向词加「道具融进身体或衣料」 |
| 场景里冒出人 | 无角色约束不够靠前 | 把「出现任何角色或人物」提到禁止内容**第一项**，并追加「人物剪影、人影」 |
| 四面板环境不一致 | 缺环境同一性约束 | 加「四个面板展示完全相同的环境与陈设布局」 |
| 四面板视角雷同 | 角度描述太软 | 写死角度数值（「向上倾斜 60 度」而非「仰视」） |
| 分隔线变粗黑框 | 没写全限定词 | 加「内部边缘线，1pt，不要双重加粗，不要外框」 |
| 跨场景色温打架 | 没用光照锚点 | 全场景从 `lighting_anchors` 取值，禁止现场编 |
| 同一场景晨昏没差别 | 只改了色温 | 按五项（色温/光斑/影子/人工光/曝光）至少变三项 |
| 白天场景点了灯 | 没声明人工光状态 | 时间线锚点显式写「烛火熄灭」 |

**诊断后需要修订的，只改受影响字段，不要整条重写**（整条重写会引入新的漂移）。修订记录写入 `.md` 的「修订日志」小节。

## 十三、 双输出（硬规则）

每个资产条目都按 **(A) 结构层 → (B) 生成 prompt** 两段给。

- **A 结构层**用六层结构（环境气候 / 主体构成 / 外观造型 / 状态版本 / 质感细节 / 氛围终层）——给人看，用于定位迭代
- **B 生成 prompt** 是可直接复制的提示词正文

**迭代时先判断哪一层出问题，只改那一层再重压 B，禁止整条重写。**

**第 6 层氛围终层不能是前五层的复述**——把它删掉，如果画面描述完全不变，说明它是复述，重写。
