# 持物设定图模板（人物 × 道具联动）

> ⚠️ 版式更新（2026-09-15）：本 skill 的角色资产版式已统一为 4 View 资产板，不再以 liqi 的三卡体系为主导。
> 本文件内出现的「双视图人设卡 / 九视图人设卡 / 侧背补锚卡」一律按按需补出的单卡理解；凡与本 skill 主文件冲突的生成顺序，以 资产层_锁定与一致性.md 第二节为准。

## 定位

角色使用道具的参考图，**单独成图**。不从角色卡抠、不从道具卡抠——角色卡是空的（零道具），道具卡里没有人，"人和物如何互动"这条信息只存在于持物图。

**生成顺序（硬规则）**：4 View 角色资产板（文生图，全链唯一身份锚）→ 专属道具表（文生图）→ 持物图（图生图，参考 4 View 裁片 ＋ 道具表）。前一张没锁定（脸稳、色准）不进下一张。完整链见 `资产层_锁定与一致性.md` 第二节。

## 道具分离三条铁律（与 4 View 角色资产板配套）

1. **角色卡零道具**：三视图/人设卡一律空手自然站立，任何道具（专属/通用）不进角色卡。提示词显式写"不持任何道具，不背负装备，身上无任何挂载物"，负向词写"角色手持或佩戴任何道具"。
2. **道具全部独立成条目**：每个道具单独一张道具展示表。人物专属道具条目名 = 道具名·角色名（如：保温杯·角色甲），slug 加角色名后缀（示例文件名，如 cup-char-a.md）——同名道具在多角色手中时分条目注册，色值形制互不污染；通用道具不加人名。
3. **持物互动单独出图**：双锚定——人物特征只从角色卡取，道具特征只从道具表取，**持物图本身不发明任何新特征**。

## 模板（按序输出，可直接复制）

```
生成图片：角色持物设定图，16:9横版，纯白背景，画面填满无大面积空白，纤细蓝图辅助网格，整卡无任何标注线、引线与箭头，禁止英文单词与乱码字符。
参考角色：【人名】，严格沿用参考图片（4 View 资产板左区头部近景裁片 `face_hd` 为身份锚）的全部五官样貌、发型发色、服饰细节与色值，外貌完全锁定，头身比与人物卡完全一致（【X头身】）。
画面中心为单一全身视图：【3/4侧面】站立，【持物动作描述：双手捧起/单手提握/背负/怀抱】，【道具名】位于【位置：胸前/右手侧/背后】，道具完整可见，不被身体遮挡，不被衣袖遮盖。
核心强制约束：道具形制、比例、色值与《【道具名】·【人名】》独立道具展示表完全一致，禁止重新设计道具；握持部位正确自然，手指与道具接触关系清晰，手部结构完整五指分明。
标准平视，无透视畸变，光影统一，均匀漫射平光，无强烈投影。
握持方式与道具相对位置写进画面描述正文（零引线零标注）。
画面角落放置色板，圆形色票，色值与人物卡、道具表完全相同。
正向：8K超清，极致细节，精致材质渲染。
负向：脸型变化，服饰变化，发色变化，道具形制变化，道具消失，道具融进身体或衣料，手脚畸形（手部重点加权），多指缺指，透视畸变，头身失调，塑料CG感，背景杂物，英文文字，乱码字符，水印。
【渲染风格同人物卡】，游戏角色设定图风格，不篡改参考图人物面部五官结构，16:9
```

## 字段注释

| 字段 | 写法要点 |
|---|---|
| 参考角色 | 必须点名角色卡（"严格沿用其 4 View 资产板"），不能只写人名——只写人名时模型没有锚，脸会漂 |
| 持物动作 | 从"双手捧起/单手提握/背负/怀抱"里选或具体描述，禁止只写"拿着"——动作模糊是握持关系崩坏的主因 |
| 道具锚定 | 核心强制约束里点名道具表条目名（《道具名·人名》）并写"禁止重新设计道具"；必要时把道具表色值 HEX 直接列进提示词 |
| 背景体系 | 默认纯白背景（与 4 View 资产板同体系）；项目若用浅灰白影棚体系则跟着项目走，同包统一 |
| 色板 | 与角色卡、道具表完全同值，改色三处同步 |

## 高频故障（Step 4 补充）

| 症状 | 优先怀疑 | 修法 |
|---|---|---|
| 道具形制和道具表对不上 | 双锚定失效 | 核心强制约束点名道具表条目并写"禁止重新设计道具"；把道具表 HEX 直接列进提示词 |
| 手握道具五指糊成一团 | 手部权重不够 | "多指缺指"移到负向词最前面，加"手指与道具接触关系清晰，手部结构完整五指分明" |
| 道具被衣袖/身体吃掉一半 | 可见性约束丢失 | "道具完整可见，不被身体遮挡，不被衣袖遮盖"必须保留，不能省 |
| 道具融进身体或衣料 | 道具与人物关系描述太软 | 负向词加"道具融进身体或衣料"，正文写清"道具与身体相对位置" |
| 人物脸和角色卡对不上 | 参考锚太弱 | 参考角色行点名角色卡全句（含头身比数字），不要只写人名 |
