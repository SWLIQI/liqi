## 二、逐条论证

### C01 景别档位：五档 vs 九档

- 外部写法（W2）：远、全、中、近、特五档，15 个组合全部按五档设计。
- liqi 写法：九档（大远景 → 大特写，v5.7.0 扩档、v5.22.0 补可复制句），配额与景别表演耦合都按九档。
- 裁决：**liqi 主导**。外部的五档只作换算源：中→中景或中全景（看取景范围）、特写→特写或大特写（看占比）。
- 事故依据：外部五档防的是「初学者不知道景别要分级」；liqi 九档防的是「中全景、中近景无法表达，
  景别与表演耦合规则（`视听层` §七之二）失去刻度」。按五档写镜，耦合规则里的「头占 1/7 改 1/3」没有落点。
- 落地：术语表 §十六换算表 + `镜头骨架库.md` §九 引用处均带换算注。

### C02 光圈记号：T 值 / F 值 vs f/ 值

- 外部写法：W4 用 T1.2~T16；W5 用 F1.2~F11 并给出焦距×光圈×物距组合矩阵。
- liqi 写法：f/ 值只写进行数行「景深注记」，正文一律视觉结果句（光学块开头铁律：不写 f 值、不写焦段毫米数）。
- 裁决：**liqi 主导**。T 值与 F 值都是摄影工程同义记号，登记进术语表作换算，不进任何规则层。
- 事故依据：外部整套参数矩阵防的是「用户说不出专业参数」；liqi 的铁律防的是「模型不执行数值、
  数值还占正文额度」（Level 4 纪律）。把矩阵搬进本库 = 把 Level 4 塞进正文，正面撞 `E-PARAM-IN-BODY`
  之外的权重稀释——两害相权，收因果层不收数值层。
- 落地：术语表 §十六；`光学与空间语言块.md` §九 纪律三。

### C03 真运镜假运镜：参数矩阵 vs 视觉结果

- 外部写法（W4）：摄影机推进 + 焦距固定＝真 Dolly In；摄影机不动 + 焦距增加＝Zoom In；
  提示词必须写「摄影机真实移动」。W5 同款：默认动作主力 35mm、景深动态表。
- liqi 写法（光学块）：只写视觉结果，不写参数；透视三类（广角扩张 / 标准人眼 / 长焦压缩）＋ 防漂移句。
- 裁决：**互补融合**。吸收「机位因果」层写成视觉结果句（真推进 / 假推进 / 真后退 / Dolly Zoom 四类），
  不收 mm、T 值、F 值矩阵；W5 的「默认 35mm 主力」作参考区间，**不作默认值**（会击穿焦段 ≥4 种配额）。
- 事故依据：外部的真假运镜防「把 Zoom 写成推进」——因果写错，透视不变，观众看到画面被放大；
  liqi 的视觉结果铁律防「参数不被模型执行」。两件事不同源，都留。
- 落地：`光学与空间语言块.md` §九（新增）+ §八 接入位置加一句入口。

### C04 方言控制：否定式词库 vs 不内置

- 外部写法（W1）：34 城市 × 八字段，每城市「必须像 X + 禁止 Y」双锚，加一条全国总控。
- liqi 写法（`方言与旁白规程.md`）：完整词典**不内置**（v5.9.0 既定裁决）；12 条总控 + 六大区速查 +
  强度三档 + 「只改听感不改台词用字」+ 语气位叠加、不立 `方言：` 字段、不写进画面描述。
- 裁决：**liqi 主导**。词条不搬；登记两版外挂词典（含 W1 的八字段名目），吸收的「双锚」写法
  liqi 速查表本已同构，登记即闭环。
- 事故依据：外部词库防「方言感做成腔调表演」；liqi 的不内置 + 不进画面正文防两件更硬的事——
  ① 整包否定式词条进正文会批量撞 `W-NEGATION-IN-BODY`（v5.44.0 由 P0 降为建议级——官方支持负向控制，只是不保证生效）与「Naming a flaw plants it」铁律；
  ② 内置 34 城词条的维护负担与重复造轮（v5.9.0 裁决原文）。
- 落地：`方言与旁白规程.md` §2.1 挂两版词典名目 + 否定式边界；待办路线图第五节登记。

### C05 转场分类：六类 vs 段缝四选一

- 外部写法（W3）：图形匹配 / 相似构图 / 相似颜色 / 动作匹配 / 视线衔接 / 甩镜 / 声音（J-cut、L-cut）/
  前景遮挡 / 黑场，六类不扩类，附平台适配与教程写作规则。
- liqi 写法：段缝方式四选一，其中④技巧型转场列五手法 + J-cut；骨架库第七类三骨架（视线匹配 /
  遮挡物过渡 / 光色匹配）；转场注记总表要求镜号锚定 + 状态交接。
- 裁决：**liqi 主导**。外部六类按本库手法名一一映射登记（术语表 §十六），外部 Skill 登记为
  「转场设计时的外查执行手册」，本库不并列第二套分类。
- 事故依据：外部六类防「转场做法散在各处查不到」；liqi 的段缝四选一防「声明段缝时用错名字、
  机检认不出的写法静默缺席」（`E-SEAM-UNDECLARED` 认 `【段缝声明】①~④`）。两套分类并列的代价是
  声明①却写「J-cut」这类串味——所以只留映射，不并行。
- 落地：术语表 §十六；术语表 §六 转场条目交汇处不再新增（本轮不加，避免第二节 K 模式扫到重复定义）。

### C06 验证措辞：四态 vs 二元

- 外部写法（W3）：区分提示词方案 / 已检查静态素材 / 已检查动态片段 / 已验证剪辑衔接四态；
  静帧不能证明动作接顺，没听过不能声称已验证。
- liqi 写法（`质控层` §三之二 + Step 4 ⑩）：断言纪律二元——没观察过不声称观察过；
  机检 `E-UNVERIFIED-CLAIM` 抓「有断言无痕迹」。
- 裁决：**互补融合**。二元口径不动（它抓「有没有声称」），补四态词表（它抓「声称到哪一级」）。
