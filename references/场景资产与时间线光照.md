# 场景资产与时间线光照

场景是分镜的背景板。角色资产解决"人长什么样"，场景资产解决"人在哪儿、什么时候、什么光下"。

## 一、场景资产与角色资产的四个根本差异

照搬角色模板会出错。差异在：

| 维度 | 角色/道具资产 | 场景资产 |
|---|---|---|
| 主体 | 有主体（角色/道具） | **无角色**（背景板），出现人物即失败 |
| 文字策略 | **要中文引线注释** | **默认无文字**（画面纯净） |
| 视角组织 | 三视图（正/侧/背） | **2×2 四视角网格**（平视/仰视/特写/俯视） |
| 版本维度 | 服装阶段 / 状态 | **时间线**（同一场景的晨/午/昏/夜） |

**文字策略的取舍**：场景图是给分镜当背景用的，画面上带文字会污染画面。所以场景资产默认走"纯图无字"——注释全部落盘 `.md` 承载（沿用 SKILL.md Step 3 降级预案的第 3 档逻辑）。需要给美术评审看的场景设计稿，才切到「标注模式」加中文引线。

## 二、场景环境设定表模板（2×2 四视角）

### 纯场景模式（默认，无文字）

```
生成图片：专业3D场景环境设定表，16:9画幅，{空间类型}，画面填满无大面积空白，蓝图辅助网格。
场景：{空间定位}。{空间结构与尺度}。{核心陈设}。{次要陈设}。{材质与磨损状态}。
光源：{光源类型与位置}。{光的性质与强度}。{光作用于何处、产生什么结果}。{阴影特征}。
氛围：{情绪基调}。{空气感与粒子}。{色温倾向}。
时间线锚点：{时段}，{该时段唯一光照特征}，{人工光是否点亮}。
画面排布2×2网格共4个视角面板，第一行从左到右：① 正面平视（直接面向场景的平视视角）；② 仰视（相机从水平面向上倾斜60度）。第二行从左到右：③ 特写（聚焦环境关键陈设的紧凑视角，填满大部分画面）；④ 俯视广角（从高处俯瞰，视野开阔）。
核心强制约束：四个面板展示完全相同的环境与陈设布局，摄像机位置、高度、方向明显不同，透视变化强烈且明确；四个面板的光照方向、色温、强度完全一致；面板之间添加干净纤细的1pt白色网格线分隔（内部边缘线，不要双重加粗，不要外框）。
禁止内容：出现任何角色或人物、画面上出现任何可读文字、{时间线互锁词}、{安全约束}、{风格约束}。
{项目风格锚}。
```

### 标注模式（给美术评审用，带中文引线）

在纯场景模式基础上，把「禁止内容」里的"画面上出现任何可读文字"换成"文字仅限中文引线注释，禁止英文与乱码"，并在核心强制约束后追加：

```
细节面板：{陈设特写}、{材质特写}、{光影特写}，引线标注中文。
```

### 字段注释

| 字段 | 写法要点 |
|---|---|
| 场景 | 按「定位 → 结构尺度 → 核心陈设 → 次要陈设 → 材质磨损」五段写。陈设要**列全**，分镜里要用到的每件道具都得在场景里能找到 |
| 光源 | 必须写出**光源在哪、光是什么性质、照到什么上、产生什么结果**四件事。只写"昏暗"不够，生图模型不知道光从哪来 |
| 时间线锚点 | **本 skill 的核心字段**。写时段 + 该时段唯一特征 + 人工光状态。见下节光照锚点表，数值只从注册表取 |
| 四视角网格 | ①平视 ②仰视60° ③特写 ④俯视广角。顺序固定，便于跨场景比对 |
| 1pt 网格线 | 明确写"内部边缘线，不要双重加粗，不要外框"——AI 生图常把分隔线画成粗黑框或双线 |
| 色板 | **无——场景不画色卡**（色板上的色名与色值属于可读文字，与"场景默认无文字"冲突）。色值只落盘注册表 `palette` 与 `.md`，人工校色时查文档；图上的色彩一致性由光照锚点（色温/光位）与基准调色板逐字复用保证 |
| 禁止内容 | **"出现任何角色或人物"是场景资产的第一硬约束**，必须写 |

## 三、时间线光照系统（核心）

### 为什么必须有

没有光照锚点时，每次生成场景都在随机采样色温和光位。结果是：同一场戏的甲场景是暖黄夕照、乙场景是冷白正午，剪在一起直接穿帮；同一场景的清晨和正午又长得一模一样，时间流逝感消失。

两条铁律：
- **同一场景 × 不同时间 → 光影必须可区分**
- **不同场景 × 同一时间 → 光影必须一致**

### 项目级光照锚点表（一次定义，全场景共用）

写进 `asset-registry.json` 的 `lighting_anchors`。**这是全项目唯一光源事实源**，任何场景的任一时段都必须从这里取值，禁止现场编。

| 时段 | 色温 (K) | 光质 | 入射角 | 影子 | 人工光 | 关键特征 |
|---|---|---|---|---|---|---|
| **拂晓** dawn | 6500–8000 | 极弱、全漫射 | 无明确方向 | 几乎无、极柔 | 烛火将熄 | 冷蓝灰主导，尘埃悬浮，冷暖交界 |
| **晨** morning | 5000–5600 | 中、斜射 | 15–30° | 长、较清晰 | 灭 | 晨雾，光束斜长，冷白偏暖 |
| **正午** noon | 5500–6500 | 最强、硬 | 60–90°（近垂直） | 最短、边缘锐利 | 灭 | 高对比，垂直光柱，暗部浓重 |
| **午后** afternoon | 4500–5000 | 强、略软 | 30–45° | 中长 | 灭 | 光斑偏移，暖意初现 |
| **黄昏** dusk | 2000–3500 | 中、水平穿透 | 5–15°（极低） | 极长、拉伸变形 | 将燃 | 强暖橙，长投影横贯画面 |
| **入夜** evening | 2000–2700 | 弱、点光源 | 不适用（多点） | 短、围绕光源 | **点亮** | 烛火光晕，衰减快，光域小 |
| **深夜** night | 7000–10000 | 极弱、单光源 | 单一（月/残烛） | 浓黑、对比极强 | 残烛/无 | 大面积暗部，仅轮廓微光 |

注意：**黄昏和入夜都是暖色，但性质完全不同**——黄昏是低角度日光（有明确方向、投长影），入夜是点光源（无方向性、光域小、衰减快）。这是最容易搞混的一对，互锁词必须能区分。

### 天气-光照耦合表（时段之外的第二个光照维度）

**时段决定色温与入射角，天气决定光被怎么改造。** 只锚定时段不锚定天气，同一时段的两个场景照样会打架。

| 天气 | 高光 | 阴影 | 色温偏移 | 粒子 / 空气 | 曝光 | 提示词写法 |
|---|---|---|---|---|---|---|
| 晴 | 明亮、边界清晰 | 硬、边缘锐利 | 无偏移 | 无 | 高 | 硬边阴影，高光锐利 |
| 薄云 / 散射 | 柔化，有方向无锐边 | 软，方向仍可辨 | 微冷 +300K | 无 | 中高 | 柔化定向光，阴影有方向但边缘松散 |
| 阴 | 几乎无高光 | 极软，近乎消失 | 冷 +800–1500K | 无 | 中 | 无可见阴影，均匀顶光，色温偏冷 |
| 雨 | **高光被散射成片** | **阴影软化，对比下降** | **冷蓝偏移** | 雨丝、湿地面镜面反射 | 中低 | 散射高光，软化阴影，冷蓝偏移，湿地面镜面反射 |
| 雾 / 霾 | 光域扩大，光柱可见 | 阴影几乎消失 | 冷灰偏移 | **体积雾、丁达尔光柱** | 低对比 | 体积雾中可见光柱，低对比，远景衰减 |
| 雪 | 高光增强（雪面二次反光） | 阴影偏蓝（天空反射） | 冷 +1000K，高光仍暖 | 雪粒、白雾呼吸感 | 高（易过曝） | 雪面二次反光，阴影偏蓝，高光保留细节 |
| 风沙 / 扬尘 | 高光浑浊 | 阴影被尘土冲淡 | 暖黄偏移 | **浓密悬浮颗粒，光柱明显** | 中低 | 浓密悬浮尘土，浑浊光柱，暖黄偏移，远景低可见度 |

⚠️ **最常见的翻车**：提示词写了"雨天"，画面却是晴天的锐利硬阴影。天气对光的**物理后果**必须显式写出，只给天气名词没用。

### 大气元素锚点（跨场景一致）

大气元素最容易忽有忽无——一个场景有尘埃、另一个没有，剪在一起立刻穿帮。登记为项目级锚点：

```
atmosphere: { particles: "悬浮尘埃", fog: "无", rain: "无", rule: "尘埃是逆光产物：只有存在逆光或光柱的场景才可见，漫射场景不出现" }
```

**规则必须写成条件句，不是绝对值。** "所有场景都有尘埃"是错的——漫射光下看不见尘埃；"逆光场景才有"才对。

### 物体恒存锚点（场景痕迹跨场次保留）

场景的"伤疤"要跨场次保留：墙上的裂缝、门板的破损、地面的污渍、道具的缺口。这些是场景的指纹。

```
permanent_marks: ["东墙第三块砖有斜裂纹", "停尸台西北角有缺口", "排水口附近有深色污渍"]
```

出图时写进提示词的"场景"行，并在禁止内容加"改变既有痕迹"约束。不登记的话，同一面墙第一场有裂缝、第三场消失，观众说不出哪里怪但会觉得假。

### 色彩节奏设计（什么时候该"破"一致性）

**一致性不是目的，一致性是为了让刻意的破有意义。**

> 观众把有意的色彩转变读作叙事，把随机的转变读作失误。

规划方法：
1. 全片定一个基准调色板，逐字复用于所有场景。
2. **只在情绪转折点留一处刻意对比**（如：全片冷青灰，唯独真相揭晓那场转暖）。
3. 要破就**破得彻底且持续整场**——半吊子的偏移最难看。

```
color_rhythm: { baseline: "低饱和青灰调", turning_point: "第7场真相揭晓，转暖橙", rule: "除第7场外全部锁定基准调" }
```

### 场景级光照锚点

光锚定在时间上，还要锚定在空间上。每个场景必须登记**进光口**：

```
light_port: { desc: "高处带木栅栏的小窗", wall: "东墙高处", fixed: true, note: "进光口位置全时段固定，变的只有太阳角度" }
```

**`fixed: true` 是关键**。进光口位置是建筑结构，跨时段不变——变的只是太阳角度决定了光斑落在地面哪里、影子多长。这条保证了"同一场景不同时间"既有变化又可辨认是同一个地方。

### 时段版本的互锁词

场景的时段版本，本质就是**多版本**，沿用 liqi 的版本互锁机制：

| 版本 | 禁止内容必写 |
|---|---|
| 停尸房·正午 | 暖橙夕照、烛火光晕、长投影 |
| 停尸房·黄昏 | 正午顶光、冷白天光、短锐阴影 |
| 停尸房·深夜 | 日光、天光、均匀照明、暖黄烛光晕 |

互锁词要从**色温、光质、影子形态**三个维度同时下刀，只禁一个维度挡不住串版。

### 人工光规则

一条容易忘的纪律：**白天不点烛，入夜必点烛**。写时段锚点时必须显式声明人工光状态（"烛火熄灭"／"烛火点亮"），否则生图模型会在正午场景里给你点上灯笼。

## 四、一致性自检矩阵

出图后按这个矩阵验，两个方向都不能漏：

**纵向（同场景 × 跨时间）——查"有没有区分开"**

| 检查项 | 不合格表现 | 修法 |
|---|---|---|
| 色温差异 | 晨昏夜长得一样 | 强制按锚点表拉大色温差，写进提示词 |
| 光斑位置 | 光斑钉在同一处不动 | 写明"随太阳角度移动，光斑落在{具体位置}" |
| 阴影长度 | 影子长度没变 | 按锚点表写明影子长度与拉伸程度 |
| 人工光 | 白天也点着灯 | 显式写"烛火熄灭" |
| 曝光水平 | 深夜和正午一样亮 | 写明整体曝光档位 |

**横向（同时段 × 跨场景）——查"有没有统一"**

| 检查项 | 不合格表现 | 修法 |
|---|---|---|
| 色温一致 | 同一场戏冷暖打架 | 所有场景从同一 `lighting_anchors` 取值 |
| 光位一致 | A 场景光从左、B 从右 | 登记各场景进光口朝向，跨场景对齐 |
| 对比度一致 | 有的硬光有的软光 | 同时段光质写死同一档 |
| 粒子/空气感 | 有的有尘埃有的没有 | 尘埃是**逆光产物**，同时段要么都有要么都没有 |
| 曝光一致 | 明暗跳变 | 统一写曝光档位 |

## 五、场景资产专用负面词

每次都必带的：

```
出现任何角色或人物、人物剪影、人影
画面上出现任何可读文字（纯场景模式）
面板分隔线双重加粗、黑色粗边框
不同面板出现不同陈设或不同环境
不同面板光照方向不一致
```

按场景类型追加：

| 场景类型 | 追加禁止 |
|---|---|
| 内景·白日 | 烛火光晕、暖黄点光源、均匀无方向照明 |
| 内景·夜晚 | 日光、天光、冷白顶光 |
| 外景·白日 | 人工暖光、光域过小 |
| 外景·夜晚 | 均匀天光、日照暖橙 |
| 古装/东方题材 | 现代建材、混凝土、金属反光、玻璃幕墙、电线 |

## 六、场景资产失败模式

| 症状 | 优先怀疑 | 修法 |
|---|---|---|
| 画面里冒出人 | "无角色"约束不够靠前 | 把"出现任何角色或人物"提到禁止内容**第一项** |
| 四面板环境不一致 | 缺"完全相同的环境"约束 | 加"四个面板展示完全相同的环境与陈设布局" |
| 四面板视角雷同 | 角度描述太软 | 写死角度数值（"向上倾斜60度"而非"仰视"） |
| 分隔线变粗黑框 | 没写"不要双重加粗" | 加"内部边缘线，1pt，不要双重加粗，不要外框" |
| 画面出现乱码文字 | 模型自作主张加标注 | 禁止内容加"画面上出现任何可读文字" |
| 跨场景色温打架 | 没用光照锚点表 | 全场景从 `lighting_anchors` 取值 |
| 同一场景晨昏无差别 | 没写时段唯一特征 | 按锚点表写明该时段色温+入射角+影子三件套 |
| 正午场景点了灯 | 没声明人工光状态 | 显式写"烛火熄灭" |
| 光斑位置不动 | 没写光随太阳移动 | 写明光斑落点随太阳角度变化 |
| 场景缺关键陈设 | 陈设列得太粗 | 把分镜需要的道具全部写进"次要陈设" |
| **写了雨天却是晴天的硬阴影** | 只给了天气名词 | 查天气耦合表，写出物理后果（散射高光／软化阴影／冷蓝偏移／湿反射） |
| **尘埃忽有忽无** | 大气规则写成绝对值 | 改成条件句："尘埃是逆光产物，只有逆光或光柱场景才可见" |
| **墙上的裂缝场次间消失** | 没登记 `permanent_marks` | 登记场景痕迹，出图写进"场景"行，`lock_out` 加"改变既有痕迹" |
| **全片一个色调太平** | 缺色彩节奏设计 | 规划一处情绪转折点的刻意偏移，且持续整场 |
| **同一场景两个镜头镜头语言打架** | 没定相机语言锚点 | 登记 `camera_language`（焦段／运动／景深／机位高度） |

**字段含义**：
- `weather` 挂在**变体**上，不挂在场景上——同一个场景不同时段可以有不同的天气。取值后必须去天气耦合表查它对该时段光的具体改造，写进提示词。
- `permanent_marks` 挂在**场景**上，跨时段复用，出图时写进"场景"行，并在 `lock_out` 加"改变既有痕迹"。
- `camera_language` / `atmosphere` / `color_rhythm` / `forbidden_elements` / `generation` 是**项目级**字段，定义在 `资产注册表_asset-registry.md`，与本文档的 `lighting_anchors` / `scenes` 同属一个 JSON 文件。

**`baseline_time` 的用法**：先定一个基准时段（通常是该场景第一次出现的时段），把它的光照、色板、陈设全部锁死；其余时段变体**只改光照相关字段，陈设与空间结构一律复用基准版**。这样既保证跨时间可区分，又保证跨变体不会把场景画成两个地方。
