# 三渲二 NPR 风格锚（三渲二轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**三渲二 NPR（3D 建模 + 卡通着色）**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

**适用判定**：角色有明确的 3D 体积与转面一致性，但明暗是 2D 的——两段式硬边阴影、明确描边、
平涂色块。镜头敢做环绕、敢推轨、敢做长镜头跟拍。用户给的设定图是这类质感时，
锁③ 风格轨道选**三渲二轨**，风格 id 取 `npr-celshaded-3d`。

**边界声明**：

- 与纯 2D 赛璐璐（`celshade-guoman-2d`）：两者画面很像，**区别在资产是几维**。
  三渲二的资产是 3D 模型，转面由模型保证，可以环绕；2D 的资产是画，转面要重新画，环绕会崩。
  **选定后中途不得换**——这决定投喂方式与运镜池，换一次全片重来。
- 与写实 PBR（`photoreal-pbr`）：同为 3D，但着色逻辑相反。写实轨要真实材质与全局光照；
  本轨要**卡通着色**：阴影是两段式的，材质是平涂色块，不要 PBR。
- 与手绘轨 / 定格轨：一个要平面无体积，一个要手作痕迹与实体微缩；本轨要干净 CG + 卡通明暗。

> **本轨的核心优势是长片一致性**：资产是模型，转面不崩、跨镜不走形，是 30 镜以上长片的首选。
> 代价是建模与绑定成本高、纯文生视频的还原率不如 2D。**有资产图或走 I2V/Ref2VA 时再选本轨。**

## 一、九段锚（中文，给 liqi 上游用）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 3D 模型的卡通着色（NPR / cel-shading），角色是有体积的三维实体，转面由模型保证；明暗是两段式的，亮部一个色、暗部一个色，分界硬；轮廓描边清晰均匀；材质用平涂色块表达，不做 PBR；允许浅景深，但不做写实景深虚化 |
| ② 配色与色域 | 干净明快的中高饱和：暗部用固有色加深一档，绝不用灰或黑；**每镜只声明一个唯一重音色**；禁用荧光、霓虹、脏灰混色、胶片颗粒 |
| ③ 运动签名 | 24fps 或 30fps，运动连续（CG 插值），可以做长镜头跟拍与环绕；**禁用运动模糊**（运动模糊会把画面推向写实 CG）；相机可以实拍感轻微手持，但不要手持抖动 |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 6.5–7（美型成人档；孩童取 5–5.5）**；脸型骨相、发型、眉眼、服装形制与配色；**转面由模型保证，跨镜不换装、不换形**；同一角色不同镜必须可辨认是同一个模型 |
| ⑤ 场景锁定 | 走 `<Subject N>`：建筑与道具是 3D 建模的，有真实体积与透视；同场景跨镜地标与光位一致；场景允许有纵深与层次 |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、持握方式；道具入画方式必须写（手持 / 悬挂 / 置地）；金属与木料用色块 + 形状化高光，不写反射细节 |
| ⑦ 光色基调 | 单主光 + 可选的补光；阴影是两段式硬边，随曲面走但分界不软；**禁用全局光照、环境光遮蔽、软阴影**；可以写逆光轮廓边，画成一条明确亮边 |
| ⑧ 声音签名 | 环境层：按场景走，允许有空间感与远近层次；动作层：脚步、衣料、道具碰撞，节拍清晰；呼吸层：克制但可闻；配乐：明快或有史诗感均可，按题材定 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅生图模型与其他有 negative 字段的面可用：写实 PBR 材质、真实皮肤毛孔、次表面散射、全局光照、软阴影、镜面反射、厚涂笔触、噪点颗粒、Q 版二头身、可读文字、水印 |

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A cel-shaded 3D render: solid three-dimensional characters with real volume that stay consistent from every angle, shaded in two flat tones with a hard edge between them. Even outlines, flat colour areas, no gradient, no grain, no motion blur. One key light, unified lighting across the frame.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
clean cel-shaded palette where shadow is the local colour one step darker, never grey or black, with a single accent hue per frame
```

**三条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `3D render` / `CGI` 单写 | `cel-shaded 3D render` | 只写 `3D render` 会被路由到写实 PBR 通道，材质与光照整套走偏 |
| `soft shadow` / `ambient occlusion` / `global illumination` | `two flat tones with a hard edge` | 写实渲染管线的默认光照是本轨头号崩点，一开就变写实 CG |
| `subsurface scattering` / `skin pores` | 删除 | 写实皮肤词会把卡通着色顶掉 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅三渲二卡通着色的 3D 画面：角色是有体积的三维实体，任意角度转面都保持一致，明暗是两段式的平涂色，中间分界硬。轮廓线均匀，色块干净，无渐变，无噪点颗粒，无运动模糊。单一主光，整张画面光照统一。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
干净的三渲二配色：阴影是固有色加深一档，不是灰也不是黑，每帧只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「3D 渲染」「CG 动画」 | 「三渲二卡通着色」「3D 模型的卡通着色」 | 中文面「3D 渲染 / CG」直连写实 PBR，不写「卡通着色」必滑走 |
| 「柔和的光影」「真实的光照」 | 「两段式平涂，分界硬」「单一主光」 | 写实光照词会触发全局光照，明暗立刻变软 |
| 「不要写实材质、不要 PBR」 | 删否定句，正面写「色块平涂、描边均匀、光照统一」 | 否定不生效，`不要 PBR` 反而容易被读成「有 PBR」 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（三渲二、两段式阴影、均匀描边、无运动模糊）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台默认渲染管线会开全局光照与软阴影**。
所以 2.2 那句「明暗是两段式的平涂色，中间分界硬」在国内面**不许省略**。

## 四、运镜池

| 类别 | 镜头 | 用法 |
|---|---|---|
| 主力 | 固定中景、缓慢推近、横向平移、跟拍、环绕、摇臂升起、航拍拉远 | **本轨的卖点**：3D 资产扛得住环绕与长跟拍，2D 轨做不了的这里都能做 |
| 少量 | 斯坦尼康跟拍、入眼、变焦对焦、低角度仰拍 | 段落转折与情绪高点 |

需要环绕与转面时**就用本轨**——这正是选 `npr-celshaded-3d` 而不是纯 2D 赛璐璐的理由。

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **变写实 PBR / CG 电影感** | 压句只写 `3D render` 没写 cel-shaded；正文出现 PBR、SSS、AO、GI | 压句第一词就是 `cel-shaded`；写实渲染管线词全部删除 |
| **阴影变软，掉进写实光照** | 写了柔和阴影、环境光遮蔽、全局光照 | 钉死 `two flat tones with a hard edge`；只写单一主光 |
| **变纯 2D 平涂，体积丢失** | 压句没提 3D 体积；运镜不敢动 | 压句带 `solid three-dimensional characters with real volume`；本轨敢写环绕，写了才像 3D |
| **描边丢失，变无描边 CG** | 风格压句没提描边 | 压句带 `even outlines`；出图提示词同样带上 |
| **材质变塑料 / 光滑玩具感** | 写了 glossy、specular、次表面散射 | 每个材质词后跟「平涂 / 无高光反射」；金属只给形状化高光 |
| **转面崩形 / 跨镜换脸** | 走了纯文生没给资产图；或参考图不是同一套模型 | **必走 I2V/Ref2VA 并带资产图**；每镜内联锁定同一 `<Subject N>` |
| **贴图拉伸 / UV 错误** | 3D 生成常见问题，靠提示词只能缓解 | 服装写「色块平涂，无复杂贴图花纹」；复杂花纹交给后期 |
| **运动模糊出现，画面变实拍** | 正文写了运动模糊或快门拖影 | 压句带 `no motion blur`；动作写清楚起收 |
| **角色变 Q 版** | 头身比没写 | 钉死 6.5–7 |

## 八、参考图集与角色锁定

本风格**无专属参考图集**。角色锁定走 `<Subject N>` 通用写法（见第一节第④段，头身比 6.5–7）。

**本轨的资产纪律（与 2D 轨不同，别照抄）**：

1. **必带资产图走 I2V / Ref2VA**。纯文生视频对三渲二的还原率明显低于 2D，**不带图时别选本轨**。
2. 资产图按**正交相机、无透视畸变**出多视图——与 2D 轨一致，但这里是为了让模型还原出同一个 3D 形态。
3. 同一角色跨镜必须可辨认是**同一个模型**：脸型骨相、发色、服装配色三样不许变。
4. 需要 360 环绕时，先确认资产图里有多角度视图；只有正面的图撑不起环绕。

## 九、去立体化与串轨防护

**本轨不要跑 `scripts/dedupe_style.py --style ink-wash-2d`**——那份删词表是为手绘平面轨写的，
会删 `shadow`、`glow`、视差位移，而**两段式阴影与 3D 位移正是本轨的风格本体**。
用它等于把三渲二删成 2D。本轨只按 §9.1 的表手工清。

### 9.1 污染词与替换对（三渲二方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| PBR、physically based、真实材质 | cel-shaded、平涂色块 | 写实材质词会把卡通着色顶掉 |
| 次表面散射、subsurface scattering、皮肤毛孔 | 平涂肤色 + 一处高光 | 写实皮肤管线词 |
| 全局光照、环境光遮蔽、AO、光线追踪 | 单一主光、光照统一 | 写实渲染管线的默认光照，一开阴影就软 |
| 柔和阴影、soft shadow、渐变过渡 | 两段式平涂，分界硬 | 本轨头号崩点 |
| 镜面反射、specular、glossy | 形状化高光 | 高光反射会带出塑料感 |
| 运动模糊、快门拖影 | 删除 | 一有运动模糊就像实拍 CG 而不是动画 |
| 厚涂、油画笔触 | 平涂色块 | 明暗逻辑相反 |
| 噪点、颗粒、胶片感 | 删除 | 本轨要干净 |
| 复杂贴图花纹、印花图案 | 纯色块或简单条纹 | 3D 生成的贴图最容易拉伸穿帮 |

**保留不动的词**：`shadow`、`outline`、`flat`、`volume`、`three-dimensional`、`depth`（浅景深可接受）。
这些在手绘轨要删，在本轨是本体。

### 9.2 互斥风格

与本风格互斥的 id（与 L0 `style-registry.json` 的 `excludes` 一致，**双向登记**；数值有出入时以 L0 为准）：

| 互斥 id | 混了会怎样 |
|---|---|
| `celshade-guoman-2d`（纯 2D 赛璐璐） | 决定资产是 2D 还是 3D，进而决定能不能写环绕与转面。**选定后中途不得换** |
| `photoreal-pbr`（写实 PBR） | 同为 3D 但着色逻辑相反：写实轨要真实材质与全局光照，本轨要平涂与硬边 |
| `ink-wash-2d`（水墨淡彩） | 一个要平面无体积，一个要 3D 体积，方向相反 |
| `gothic-puppet`（哥特定格木偶） | 定格轨要手作痕迹与实体微缩实拍，本轨要干净 CG；材质词汇互斥 |
| `stylized-pixar-3d`（风格化 3D） | 两者都是 3D，但一个软过渡真实光影、一个两段式硬边平涂；混了会同时出现描边与软过渡 |
| `anime-2d`（日系动画 2D） | 纯 2D 与 3D 建模资产互斥，投喂方式与转面写法都不一样 |
| `documentary-live-action`（纪实实拍） | 实拍没有着色器，与本轨的 NPR 卡通着色完全对立 |

**串轨怎么认**：看阴影边界与光照词。本轨正文里出现「柔和阴影 / 全局光照 / 次表面散射 / PBR」，
或写实轨正文里出现「两段式 / 描边 / 平涂色块」，就是串了。
