# 表演层：FACS 微表情引擎

> 🔗 流程位置：**Step 3 表演位写法**。上游＝叙事层的情绪节拍；下游＝`check_prompt.mjs` 出稿质检。
>
> 核心信念（Ekman FACS）：**人脸表情由彼此独立的动作单元 AU 组成。不写「开心 / 难过 / 凶狠」这种结果词，而是写哪块肌肉、做出什么肉眼可见的动作、多大幅度、持续多久。**
>
> AI 对「颧大肌把一侧嘴角向斜上拉起 20%」的执行，远比对「邪魅一笑」稳定。

---

## 〇、 触发分级（关键：FACS 是增强模块，不是所有任务的固定表单）

原 liqi 的表演写法停留在「三态结构 + 呼吸与视线」，落到「脸上到底怎么动」时只能写「隐忍」——**那不是可执行的**。FACS 补的正是这一层。但**不能所有镜都全量跑**，否则会撑爆单镜 800 字符的预算。

| 档 | 条件 | 做法 |
|---|---|---|
| **默认档** | 简单文戏、过场戏 | 用正常影视表演语言（动作 + 神态 + 可见生理反应）。**不展开 AU 配方、不产出 cue 表**。但**空泛结果词禁令全局有效**——禁「开心 / 难过 / 邪魅 / 愤怒」 |
| **全量档** | 满足其一：① 特写 / 大特写；② 微表情、口是心非、隐忍克制类表演；③ 情绪转折关键拍（台词重音 / 金句发酵）；④ 该角色历史表情易崩 | 走下面的五步工作流，四区拆解 + 强度档 + 时序 |

**判定不清按全量档处理。**

---

## 一、 五步工作流

1. **定情绪与潜台词**：这一拍角色真正想表达 / 想隐藏什么（说出口的话 vs 真实情绪，常用微表情制造「口是心非」）
2. **选 AU 配方**：查本文 §四 速查表；真笑 / 假笑、惊讶 / 恐惧这类易混组合**必须查，不要凭印象**
3. **逐区拆解**：按「**眉区 → 眼区 → 颧颊 → 嘴/下颌**」四区写全——**缺区会导致表情发空或模型自由发挥崩脸**
4. **定强度与时序**：套〔痕 / 显 / 强〕三档和「起—hold—落」时间，让峰值对齐台词重音字
5. **分层产出并自检**：投喂正文只写肌肉动作的**画面语言**；AU 编号、强度标记、English kernel 一律只进内部 cue 表

---

## 二、 铁律（高频翻车点）

### 🔴 分层铁律（最高优先级，违反即返工）

**AU 编号、`〔痕/显/强〕`、English kernel 是给创作者看的内部标注，不是视频模型的词汇，禁止出现在投喂正文。**

正文只写画面语言：**哪块肌肉 + 做什么可见动作 + 幅度 + 持续秒数**。

**为什么禁**：

1. 模型不识别 FACS 编码，`AU23` 会被当无意义 token 忽略；**更糟的是被当字面字符串渲染成画面上可读的文字**，与「禁止任何可读文字 / UI / 水印 / 字幕」正面冲突
2. 中文稿里插一整句英文 kernel 会造成语义重复、token 浪费，中英各执行一半导致动作加倍或打架
3. 这几项本就在吃紧的字数预算里，删掉不损失任何画面信息

**强度档怎么翻译进正文**：

| 内部档 | 正文用词 |
|---|---|
| 〔痕〕 | 轻微地 / 极浅地 / 一丝 / 几乎看不出地 |
| 〔显〕 | 明显地 / 清晰地 |
| 〔强〕 | 大幅度 / 剧烈地 |

**English kernel 的唯一正当用法**：整条提示词本来就写成**全英文**时。中英混排一律禁止。

### 其余铁律

- **真笑 vs 假笑**：杜乡真笑＝**AU6（眼轮匝肌外圈：眼尾眯、眼下隆起）＋ AU12（嘴角上提）**，**眼一定参与**；只动 AU12、眼睛不眯＝社交假笑。要「皮笑肉不笑」时**恰恰只给 AU12**。
- **情绪靠组合，不靠单点**：AU1+2+5 是惊讶（抬眉 + 瞪眼）；**再叠 AU4（眉心拧住）才是恐惧**。单一 AU 常含义中性。
- **AU10 ≠ AU15**：AU10 提上唇＝轻蔑 / 厌恶 / 嫌；AU15 降口角＝难过 / 委屈的嘴角下撇。**写反情绪就错。**
- **强度宁小勿大**：默认〔痕〕；〔强〕只给爆点，且**不超过 80%**，满格易成鬼脸 / 崩脸。
- **表情不能比台词先结束**：峰值对齐重音字，句尾留半拍余韵——防止「话没说完脸先松＝台词被吞」。
- **左右要指定、不中途换边**：单侧 AU（玩味笑、挑眉、wink）必须写明哪一侧，并与镜头 / 站位轴线一致。
- **不叠互相矛盾的 AU**：如同侧嘴角同时上扬 AU12 和下压 AU15。
- **遮挡就写看得见的部分**：戴墨镜 / 侧脸 / 背对 / 阴影遮眼时，眼区 AU 拍不出来——改写镜上缘露出的眉（AU2/AU4）与下半张脸（AU12/AU24/AU10/AU20）、下颌、头部角度。**只在眼睛真正露出时才写眼区 AU。** 背影、纯物体、字幕卡可豁免。

## 三、 强度三档与时序

| 档 | 肌肉幅度 | 时长 | 用于 |
|---|---|---|---|
| 〔痕〕trace | 10–25%，仅特写可读 | 起 0.2–0.3s，hold 0.3–0.8s | 藏情绪、日常、克制型角色、微表情 |
| 〔显〕clear | 30–55%，中景可读 | 1–2s | 主要情绪、态度转折 |
| 〔强〕strong | 60–80%，远景可感 | 爆发后 0.5–1.5s 回落 | 爆点、群像、惊恐 / 大笑 |

- 任何表情都要有「**起—hold—落**」，不全程绷在峰值
- 真笑可让**嘴角先动、延迟约 0.3s 笑意才到眼睛**（更真实）
- **与语速自检联动**：表情 hold 时长不得侵吞台词预算；金句后的 0.3~0.8s 发酵气口正好承载余韵微表情

## 四、 AU 速查

**上半脸**

| AU | 肌肉 | 可见形态 |
|---|---|---|
| AU1 | 内眉抬 | 眉内侧上提，眉间出现竖纹 |
| AU2 | 外眉抬 | 眉外侧上提 / 挑眉 |
| AU4 | 皱眉压眉 | 眉心拧紧下压，眉间深竖纹 |
| AU5 | 上眼睑提 | 睁大眼，露出上方眼白 |
| AU6 | 脸颊提（真笑之眼） | 眼尾眯、眼下隆起，眼周出现细纹 |
| AU7 | 眼睑收紧 | 目光变锐，眼裂变窄 |

**下半脸**

| AU | 肌肉 | 可见形态 |
|---|---|---|
| AU10 | 提上唇 | 鼻翼上提、上唇抬起——嫌 / 轻蔑 |
| AU12 | 嘴角上提 | 笑 |
| AU14 | 嘴角绷紧 | 单侧讥笑 |
| AU15 | 嘴角下垂 | 难过 / 委屈 |
| AU20 | 嘴角横拉 | 隐忍 |
| AU24 | 抿唇 | 克制 / 决心 |
| AU25/26 | 嘴微张 / 下颌松 | 愣住、惊讶 |

**其他**：AU45 自然眨眼、AU46 单眼 wink。
**非 AU 的自主神经信号**（耳尖泛红、喉结吞咽、出汗、呼吸、瞳孔）**极适合做「藏不住的真实」**——它们不受意志控制，写出来比任何 AU 都可信。

## 五、 交付物形态

- **单镜**：分镜表演位内嵌**四区肌肉动作的画面描述（可见动作 + 幅度 + 起落秒数）**；AU 编号与强度档另列在内部 cue 表备查
- **整项目**：可额外产出**角色情绪库 / FACS cue 表**（角色 × 情绪 × AU 配方 × 强度），保证同一角色全片表情一致、不漂移——与《资产图册》同源锁定
- **只审查不改写**：逐条标出「空泛情绪词 / 假笑风险 / 矛盾 AU / 左右未指定 / 遮挡误写眼区 / 表情吞台词」并给替换 AU

## 六、 与 liqi 情绪表演层的叠加方式

原 liqi 的 `references/情绪表演层.md`（说前 / 说中 / 说后三态 + 呼吸与视线）**保留为默认档的写法骨架**，FACS 在其上叠加：

| 层 | 管什么 | 来自 |
|---|---|---|
| 情绪弧线 | 这一拍情绪走到哪一阶段 | 叙事层情绪节拍 |
| 三态结构 | 说前（蓄）→ 说中（发）→ 说后（余）的节奏分配 | liqi 情绪表演层 |
| **肌肉动作** | 脸上具体哪块肌肉怎么动、多大幅度、多久 | **本引擎** |
| 呼吸与视线 | 鼻息节奏、视线落点与转移 | liqi 情绪表演层（FACS 遮挡改写与它联动） |

**顺序**：先用三态定结构，再用 FACS 填肌肉，最后用呼吸与视线收口。

## 七、 输出前自检清单

- [ ] 每个正脸 / 有台词的镜头都用了具体肌肉动作，没有残留「开心 / 难过 / 邪魅」等空泛词
- [ ] 眉 / 眼 / 颧颊 / 嘴四区写全，或明确说明某区被遮挡及其替代信号
- [ ] 真笑带 AU6；假笑刻意只给 AU12；惊讶与恐惧区分（有无 AU4）
- [ ] AU10 与 AU15 未用反；无相互矛盾的 AU 叠加
- [ ] 单侧动作指定了左右且不换边、与轴线一致；wink 轻柔不抽搐
- [ ] 标了强度与起落时间，峰值对齐台词重音、句尾有余韵，未侵吞台词预算
- [ ] 幅度未拉满成鬼脸；遮挡镜头没写拍不到的眼区
- [ ] **投喂正文零 FACS 标注**：无 AU 编号、无强度标记、无 English kernel（除非全英文稿）——表演已全部翻译成肌肉动作的画面语言
- [ ] 解剖合理，负面项含多肢 / 脸崩 / 磨皮塑料感
