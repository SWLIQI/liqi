# 扩展面板与比例色彩速查

> ⚠️ 版式更新（2026-09-15）：本 skill 的角色资产版式已统一为 4 View 资产板，不再以 liqi 的三卡体系为主导。
> 本文件内出现的「双视图人设卡 / 九视图人设卡 / 侧背补锚卡」一律按按需补出的单卡理解；凡与本 skill 主文件冲突的生成顺序，以 资产层_锁定与一致性.md 第二节为准。

标准转面表/道具表之外的可选扩展产出，以及生成时的速查数值。需要时读，不必每次加载。

## 一、表情表（Expression Sheet）

标准转面表只解决"静态长相"，解决不了"这角色会做什么表情"。**触发条件以 `资产层_锁定与一致性.md` 第二节为唯一依据**：剧本需要 **≥4 种差异较大的表情、且这些镜要走全量 FACS** 时才补出一张表情表。「60 秒以上 / 有大量情绪戏」只是提示信号，**本身不构成触发条件**。不满足就别出——表情格约 600 px，够看表情怎么摆、不够锁五官，它只能当参考不能当锚。

模板：

```
生成图片：专业3D角色表情设定表，16:9画幅，浅灰白色影棚背景，画面填满无大面积空白，极淡蓝图辅助网格，整卡无任何标注线、引线、箭头与圈注，图注文字仅限中文。
参考角色：{年龄}{身份}，严格沿用参考图片全部五官样貌，{发型发色}，{面部/皮肤特征}。
画面中心排布2行×3列共6个头部特写面板：{平静}、{喜悦}、{愤怒}、{悲伤}、{惊讶}、{思索}。
核心强制约束：六个面板使用完全一致的{头身档位}头部比例与{脸型}结构，五官位置、发型走向、光影方向全部统一；每个面板只改变表情肌运动，不改脸型、不改发色、不改瞳色。
细节约束：{该角色专属表情特征，如：无眼白角色不做"眼白增多"的惊讶表现，改用眉弓抬升+瞳孔收缩}。
画面角落放置色板，圆形色票，附带中文色名与色值：{色名} #{HEX}（{部位}）。
禁止内容：{版本互锁词}、脸型变化、发色变化、瞳色变化、出现可读文字、背景非影棚灰。
写实PBR材质渲染，细节锐利清晰，整张画面光照统一，无透视畸变，全部视图采用严格正交相机，不篡改参考图人物面部五官结构，16:9
```

**六个基础表情是下限**：平静、喜悦、愤怒、悲伤、惊讶、思索。角色有特殊设定时替换其中 1–2 个（如妖化、黑化、失神）。

**注意**：表情表是**独立一张图**，不要塞进转面表（会突破密度预算）。

### 按需补卡：九视图人设卡（表情 + 转面合一 · 非默认）

⚠️ **本 skill 默认不出这张卡。**触发条件与「为什么不用它」的像素账依据，见 `资产层_锁定与一致性.md` 第二节「按需补出的两类单卡」。**只有剧本确实需要 ≥4 种差异较大的表情、且这些镜要走全量 FACS 时**才考虑；即便如此也优先出**纯表情网格**，而不是这张九视图卡。

下列内容作为**兼容保留**：用户明确要"一张图承载角色出厂基准"（游戏人设卡风格、视频图生图基准卡）时可用。

**2026-09-06 用户改版**（替代旧"上表情下全身"版式）：
- **版式**：16:9 横版，**左 2/3 为正/侧/背三个全身站立视图**（最左身高线），**右 1/3 为六表情头部特写**（3行×2列竖排）。理由：旧版全身格被压到头高 159 px 且比例失真；新版全身格头高约 320 px、表情格头高约 600 px（实测，见 `资产层_锁定与一致性.md` 第二节 · 像素账）。
- **表情来源**：**不再指定标准六种表情**。六个表情**从剧本里提取人物实际出现过的情绪节点**（逐场场记：情节→表情名），幅度自然克制、贴合日常情绪强度；负向词禁浮夸戏剧化表情。无剧本时向用户要，不自行编造。
- **生成方式**：**必须以 4 View 角色资产板（裁片 `face_hd` 为身份锚）为参考图图生图**，禁止文生图独立出——4 View 板是全链唯一身份锚，九视图是它的展开。

```
生成图片：角色九视图人设卡，16:9横版，浅灰白色影棚背景（与 4 View 角色资产板同背景体系），画面填满无大面积空白，纤细蓝图辅助网格，仅六个表情面板与身高线数值保留文字标注（表情名与身高值），其余画面区域无任何文字与引线标注，禁止出现英文单词与乱码字符。
参考角色：【角色描述】，严格沿用参考图片中人物的全部五官样貌、发型发色、服饰细节与色值，外貌完全锁定。
画面左侧占画面三分之二，排布3个全身站立视图：正面、侧面、背面（从左到右）；最左侧放置垂直身高参照线，零刻度精准对齐脚底地面基准线，从脚底向上延伸至头顶，带简短刻度标记，旁标文字"【X】cm"；身高线与人物身体留出空隙，绝对不能遮挡、穿插躯体。
画面右侧占画面三分之一，排布3行×2列共6个头部特写面板，按剧情出现顺序排列：【表情1（情节语境＋幅度上限）】【表情2（情节语境＋幅度上限）】【表情3（情节语境＋幅度上限）】【表情4（情节语境＋幅度上限）】【表情5（情节语境＋幅度上限）】【表情6（情节语境＋幅度上限）】。每个表情名后必须跟一句情节语境与幅度上限（如"轻微担忧：仅眉头轻蹙，眼神不安，不流泪"）——实测只给表情名时，模型会把多种负面情绪统一塌成哭泣。
核心强制约束：六个表情面板与三个全身视图使用完全一致的【X头身】头部与人体比例，五官位置、脸型结构、发型走向、服饰细节、色值全部统一；表情面板只改变表情肌运动，不改脸型、不改发色、不改瞳色；三个全身视图肩宽、躯干、四肢、衣摆长度全部统一，脚底严格贴合同一条水平地面基准线。
表情幅度约束：所有表情自然克制，符合日常情绪强度，肌肉运动细微真实；禁止浮夸戏剧化表情，禁止瞪眼、夸张张嘴、漫画式五官变形。
三个全身视图为空手自然站立姿态，双手垂放身体两侧，不持任何道具，不背负任何装备，身上无任何挂载物，画面中不出现任何道具。
标准平视，无透视畸变，光影统一，均匀漫射平光，无影棚戏剧布光，无方向性硬光，无强烈投影。
画面角落放置色板，圆形色票，每项标注中文色名与色值：【色名 #HEX（部位）】。
整体风格：【项目风格锚（与 4 View 角色资产板逐字相同）】。
游戏角色设定图风格，全部视图采用严格正交相机，不篡改参考图人物面部五官结构，16:9

Negative Prompt: 透视畸变，视图不一致，头身失调，五官不对称，阴阳脸，表情串脸，表情浮夸，五官夸张变形，手脚畸形，塑料CG感，塑料感皮肤，背景杂物，角色手持任何道具，服装跨视图不一致，发型跨视图不一致，英文文字，乱码字符，水印logo。
```

九视图卡专属纪律（仅在这张按需卡确实要出时适用）：

- **零道具是硬约束**（道具分离铁律一）：三视图空手，道具走道具展示表独立生成，专属道具条目名 = 道具名·人名；同框需求走持物设定图（`references/持物设定图_模板.md`）。
- **背景体系**：与 4 View 资产板二选一统一（亮灰影棚默认推荐），同一项目内背景体系必须统一，禁止一半纯白一半影棚灰。
- **密度口径**：左 2/3 三视图 + 右 1/3 六表情是主画布内容，不算独立面板；此卡上**不再叠加任何独立细节小面板**（局部放大/道具/状态对比），叠加即超预算。
- **表情自然纪律**：表情名来自剧本场记（如"平静专注""轻微担忧"），**每个表情名后必须跟一句情节语境＋幅度上限**（如"释然：长呼一口气，眉眼舒展，带浅淡笑意"）——2026-09-06 实测：只给表情名，疲惫/释然/焦急全部塌成哭泣脸，笑意格变成闭眼大笑。负面词必须带"哭泣与流泪"。六个表情的情绪强度要有梯度但都不越界到浮夸。
- **全身区零文字（2026-09-06 用户定稿）**：三个全身视图上**禁止任何引线与服饰标注**（"后背中缝车线""深棕色毛领"这类全部去掉）——它们是噪声且 Seedream 中文渲染不稳。全卡仅允许三处文字：表情面板的表情名、身高线数值、色板色名。服饰结构描述写在提示词正文里，不画到图上。
- **互染拆分预案**：出图出现表情串脸、全身视图被表情特征污染时，拆回"表情表 + 转面表"两张标准图，两图共用同一参考角色行与色板，互锁词不变。

**变体历史**：2026-09 初版为"上半 2行×3列 六表情（温柔/惊讶/坚定/悲伤/冷傲/微笑）+ 下半全身三视图"上下结构；2026-09-06 用户实测后改版为左右结构并确立"剧本取表情"与"图生图链"两条规则。旧版式不要再用于新项目。

完整模板在项目内单独落盘（项目级路径，不随 skill 分发）。

### 按需补卡：双视图人设图（图生图基准卡 · 非默认）

用途是**给后续所有图生图 / 视频首帧当身份锚**，不是给人看的设定表。⚠️ **本 skill 默认不出这张卡**——身份锚这个职责已由 4 View 资产板的左区头部近景承担；只有需要一张更「干净」的单角色图时才按需补出。

完整模板、排版段逐句拆解、专属纪律、故障表见 **SKILL.md Step 2.5**。此处只存格式锚原文与适配示例——**本节的排版段 10 个约束点仍然有效**，因为 4 View 板的左区头部近景就是照这套排版做的。

| 位置 | 矛盾 | 处理 |
|---|---|---|
| 总起句 `纯白背景` vs 排版段 `亮灰色影棚背景` | 同一个画面两个背景 | 二者必须统一；新模板用 `{背景体系}` 占位符，二选一后两处同写 |

| 外貌描述 | 参考角色行 | ② 外貌段 | ② 外貌段 | **逐字相同** |
| 头身比 | 核心强制约束写出数字 | 头部特写不体现 | 不体现 | 由 4 View 板定档 |
| 色板 HEX | 画面角落 HEX 三色 | 无（落盘 `.md`） | 无（落盘 `.md`） | 值取自注册表 |
| 背景 | 亮灰影棚（默认） | 与 4 View 板一致 | 与 4 View 板一致 | **二选一统一** |
| 表情 | **中性（expressionless）** | **中性** | 按剧本场记提取，自然克制 | 资产板与特写卡一律中性 |
| 道具 | 零道具硬约束 | 头饰保留、其余不出现 | 不出现 | 手持类一律走 Step 2.5 持物设定图 |
| 文字 | 仅身高线 / 色板带字 | **零文字** | 仅表情名带字 | 除色板与身高线外零文字 |
| 生成依赖 | **可独立（文生图，全链第一张）** | **必须以 4 View 裁片为参考图**（图生图） | **必须以 4 View 裁片为参考图** | 顺序：4 View 板 → 补卡 → 道具表 → 持物图 |
| 裁切布局 | `--layout 4view` | `--layout sideback` | `--layout 9view` | 见 `scripts/slice_reference.py` |
| 裁出产物 | `face_hd`（约 1922px，身份锚）+ front/side/rear（无头） | `face_side` / `face_back`（各约 1922px） | `face_×6`（约 600px，**锁不住五官**） | 像素为 3840×2160 实测估算 |

## 二、面料细节词库

PBR 渲染目标下，只写"布料垂坠"一句是不够的。**服饰条目至少命中其中 4 项**：

| 维度 | 可选词 |
|---|---|
| 织法 | 平纹、斜纹、缎纹、麻纤维粗糙、提花暗纹、纱罗、针织罗纹 |
| 厚度 | 轻薄透光、中层挺括、厚实硬挺、多层衬里 |
| 缝线 | 明线走边、暗线收口、手工针脚不均、包边 |
| 袖口/边 | 收口窄袖、敞口广袖、卷边、毛边、磨损起毛 |
| 褶皱 | 静态自然垂坠、肘部堆积褶、腰间束褶、久坐压褶 |
| 垂坠 | 硬挺不贴身、柔软贴体、下摆外扩、垂至脚踝 |
| 光泽 | 哑光、微弱丝光、缎面反光、蜡质光泽 |
| 做旧 | 洗白褪色、磨破、补丁、污渍、虫蛀、焦痕、水渍 |

示例（古装中衣）：`素白丝质中衣，平纹丝绸带微弱丝光，中层挺括不贴身，交领暗线收口，敞口窄袖口沿磨损起毛，静态自然垂坠至脚踝，下摆久坐压褶，无纹样无腰带。`

## 三、面板密度预算

生图模型的注意力是稀缺资源。面板越多，每个面板被正确渲染的概率越低。

| 指标 | 上限 | 超了怎么办 |
|---|---|---|
| 单图独立面板数（含局部放大/独立道具/细节面板） | **4 个** | 拆成两张图，或砍到 3 个 |
| 提示词正文字数 | **按面板数分档**：面板 3–4（完整档）**650–900 字**；面板 ≤2（精简档）**200–320 字**。判据是面板数不是字数；额度以 `资产层_锁定与一致性.md` 第十一节为准 | 删形容词，保留硬约束；说明性内容移到 `.md` |
| 色板色票数 | 5 个 | 合并近似色 |
| 禁止内容项数 | 8 项 | 只保留最关键的，其余移到 `.md` 备注 |

**优先级（预算不够时按此顺序砍）**：核心强制约束 > 参考角色行 > 身高/比例尺线 > 版本互锁词 > 独立道具面板 > 局部放大面板 > 色板 > 装饰性细节。

## 四、头身档位速查

**「3D」是渲染介质，不决定头身比**——决定头身比的是目标观感，两者正交。按下表按观感选：

| 目标观感 | 头身比 | 3D 实现 | 2D 实现 |
|---|---|---|---|
| 写实真人 | 7–7.5 | 虚拟人、UE 写实渲染 | — |
| 国产 3D 动画 | 7–8 | 玄机/原力风、修仙玄幻、虚拟偶像 | — |
| 日式 3D 动漫 | 6–6.5 | 3D 渲染 + 二次元头身（多数 3D 动漫短片落这档） | — |
| 日式 2D 动漫 | 5.5–6.5 | — | 赛璐璐、二次元手绘 |
| 少年/成年美型 | 7–8 | 热血漫 3D、美型主角 | 热血漫、少女漫成年角 |
| 卡通 / 吉祥物 | 4–5 | 欧美 3D 动画 | 欧美 2D |
| Q版 / 二头身 | 2–3 | 3D Q版 | 2D Q版 |
| 孩童 | 该档位 −1.5~2 | 成人档 7 → 孩童 5–5.5 | 同左 |

**同一资产包内禁止混档。**

**选型捷径**：拿不准就先出 6 头身和 7 头身两张测试图对比，选定后写进资产注册表锁死。

**AI 生图实操坑**：提示词里光写「3D动漫」，模型大概率给成写实虚拟人（"3D" 有强烈写实现验）。必须显式写头身比数字锚定，如 `3D动漫渲染，日式二次元角色比例，6头身`。

### 人物（成人通用值，无设定时可用并标注"待确认"）

| 类型 | 身高 |
|---|---|
| 成年男性 | 170–175 cm |
| 成年女性 | 158–165 cm |

### 道具

| 道具类型 | 推荐展示视图 | 比例尺 |
|---|---|---|
| 文书/纸张 | 平铺态、半卷态 | 纸高约 40 cm |
| 容器（盆/碗） | 俯视（内腔）、侧视（器型） | 盆口直径约 35 cm |

## 七、IP / 版权安全

生成前先判断素材是否涉及既有 IP（知名角色、明星脸、品牌、在世人物）：

- **涉及 IP**：提示词改用**无 IP 描述**（"金发高个战士、红披风、北欧板甲"而非角色名），保留视觉特征但去掉专有名词。大部分生图模型对专有名词会拒答或产生侵权产出。
- **原创设定**：可正常使用，但仍建议避免直接复制特定商业角色的可识别组合特征。
- 目标平台审核严格时（国内平台尤甚），默认走**无 IP 描述**路径。

## 八、表情幅度基线（2026-09-07 实测补丁）

情绪标签词（心虚/认命/自厌/怜惜这类）会召唤训练集里的「哭脸原型」，
把角色自己的五官盖掉——六个格子全生成含泪皱眉脸。解法三层：

1. 每格写具体肌肉微动作，不写戏剧词：视线偏向侧下方、眼睑略压低、
   双唇轻抿、下颌线微紧、眼睑半垂、嘴角平直。删舞台化描述——恐惧眼底、
   喉结动作、紧锁眉头、咧嘴、手捂嘴（脸部特写格里不出现手，不出现
   身体动作如后退）。
2. 六格后追加统一基线句：六格共用完全一致的同一张脸，均为低幅度微表情：
   头部姿态统一正视镜头，不歪头不低头；双眼清澈有神，无泪光，眼眶不红
   不湿润；嘴唇自然闭合不露齿；眉头基线放松，每格仅允许眉、眼、唇之一
   的细微变化，五官结构与脸型不变，情绪细腻克制。
3. 负面词补：含泪、泪光、眼眶湿润泛红、痛苦扭曲、张嘴嚎哭。
   剧情需要落泪的例外格在基线句里单独注明；此时负面词只禁大哭、
   泪流满面、嚎啕——禁「哭泣流泪」会跟落泪格自相矛盾，模型反而
   全卡靠含泪半途状态摆烂。
