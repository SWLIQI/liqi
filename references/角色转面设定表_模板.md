## 完整示例（角色A A 版 · 素白中衣）

> **关于头身**：本节示例的目标观感是**写实真人档（7–7.5 头身）**，所以下面写 7 头身。换档时这一处必须跟着改——日式 3D 动漫档写 6–6.5，日式 2D 动漫档写 5.5–6.5，孩童再 −1.5~2。示例中的 7 头身**不是默认值**，别照抄。

生成图片：专业3D角色转面设定表，16:9画幅，浅灰白色影棚背景，画面填满无大面积空白，蓝图辅助网格，整卡无任何标注线、引线与箭头，图注文字仅限中文。
参考角色：外表20岁画皮妖，严格沿用参考图片全部五官样貌，乌黑柔顺长直发，几缕发丝半遮挡面部，皮肤苍白半透明，带有微弱蜡质光泽。
局部放大面板：眼部特写，全黑瞳孔，无眼白，引线标注：无眼白，唇色极淡近乎无色。
画面中心排布3个站立角色视图：正面、侧面、背面。
核心强制约束：正面、侧面、背面三套视图使用完全一致的7头身人体比例，肩宽、躯干长度、四肢长度、衣摆长度全部统一；三个角色的脚底严格贴合同一条水平地面基准线。

服饰：素白丝质中衣，衣身无任何纹样，不配置腰带，简洁干净的交领剪裁，布料静态自然垂坠，衣摆无飘动效果。

## 字段注释

| 字段 | 写法要点 |
|---|---|
| 参考角色 | 有主图必写"严格沿用参考图片全部五官样貌"；无主图改"参考设定"并给足文字描述 |
| 局部放大面板 | 选最标志性特写，1 个即可；引线必须中文 |
| 核心强制约束 | 按 `扩展面板与比例色彩速查.md` 第四节「头身档位速查」**按目标观感**选头身（写实真人 7–7.5／国产 3D 动画 7–8／日式 3D 动漫 6–6.5／日式 2D 动漫 5.5–6.5／Q版 2–3；孩童在该档位 −1.5~2），同包禁止混档；脚底同一基准线 |
| 身高参照线 | 数值 = 角色设定身高；孩童 vs 成人差可加括号注释（构图关键差） |
| 服饰 | 版本专属，写颜色+结构+布料+垂坠；不同版本必须可区分 |
| 背面视图 | 写背面独有细节（发髻/脊缝/头巾结/背负物），不是简单重复正面 |
| 独立道具面板 | 道具必须完整呈现，禁止藏于角色身上；带"禁止..."约束 |
| 色板 | 中文色名 + HEX（部位）双轨格式，圆形色票；色值从资产注册表取 |
| 禁止内容 | 版本互锁词必写（禁另一版本特征）+ 安全 + 风格 |
| 技术收尾 | 原样保留；无主图条目保留即可（生图按"保持设定五官一致"理解） |

## 非站立角色的适配

| 类型 | 视图改写 | 比例/基线改写 |
|---|---|---|
| 尸体躺姿 | 俯视、左侧躺姿、右侧躺姿 | 身长参照线 172cm；人体贴地面基准线 |
| 动物局部 | 头部正面、头部侧面、头肩3/4侧 | 肩高参照线（约40cm）；爪底贴基准线 |
| 群体剪影 | 并排正面剪影全景 + 代表者侧/背 | 按档位表统一头身；脚底贴基准线；不露正脸 |
