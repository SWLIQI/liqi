## 字段注释

| 字段 | 写法要点 |
|---|---|
| 参考角色 | 有主图必写"严格沿用参考图片全部五官样貌"；无主图改"参考设定"并给足文字描述。**必须带性别锚点**（`X~Y岁男性/女性（身份代称）`），只写身份代称会让模型自行推断性别导致漂移 |
| 核心强制约束 | 按 `扩展面板与比例色彩速查.md` 头身档位速查**按目标观感**选头身（写实真人 7–7.5／国产 3D 动画 7–8／日式 3D 动漫 6–6.5／日式 2D 动漫 5.5–6.5／Q版 2–3；孩童在该档位 −1.5~2），同包禁止混档；脚底同一基准线；**零道具硬约束**必写 |
| 身高参照线 | 数值 = 角色设定身高；孩童 vs 成人差可加括号注释（构图关键差） |
| 服饰 | 版本专属，写颜色+结构+布料+垂坠；不同版本必须可区分 |
| 背面视图 | 写背面独有细节（发髻/脊缝/头巾结），不是简单重复正面。**零引线**——细节写进正文不画标注线 |
| 细节小面板 | 3 个以内，走材质 / 肌理 / 缝纫扣具，**不出现道具**（道具走 `道具展示表_模板.md` 独立成条目，同框走 `持物设定图_模板.md`）。密度上限见 `扩展面板与比例色彩速查.md` 第三节 |
| 文字纪律 | 全卡仅两处带字：身高线数值、色板色名。**零引线、零标注线、零箭头**（与本文件骨架第 1 行的约束一致） |
| 色板 | 中文色名 + HEX（部位）双轨格式，圆形色票；色值从资产注册表取，**缺 HEX 视为不合格** |
| 禁止内容 | 版本互锁词必写（禁另一版本特征）+ 安全 + 风格 + **角色手持或佩戴任何道具** |
| 技术收尾 | 原样保留；无主图条目保留即可（生图按"保持设定五官一致"理解） |

## 非站立角色的适配

| 类型 | 视图改写 | 比例/基线改写 |
|---|---|---|
| 尸体躺姿 | 俯视、左侧躺姿、右侧躺姿 | 身长参照线 172cm；人体贴地面基准线 |
| 动物局部 | 头部正面、头部侧面、头肩3/4侧 | 肩高参照线（约40cm）；爪底贴基准线 |
| 群体剪影 | 并排正面剪影全景 + 代表者侧/背 | 按档位表统一头身；脚底贴基准线；不露正脸 |
