## 〇、 立条目背景

### 现象

提示词正文写「一只靴抬起、停住、踏下」「一只手举着一张纸」「落在一个跪着的人身上」——
**画面里有这个部件，但没说是谁的**。模型照样出片，不报错，看起来也完全合理。

### 复现场景（最小复现）

```
段 1｜靴底碾下（15s）
画面（事件序）：一只靴抬起、停住、踏下；木牌从中段崩开……
```

出片症状（三条，按暴露顺序）：

1. **款式对不上**——靴是模型从「古装街景」先验里取的中位数样本，与该角色已出图的资产不是同一双。
2. **位置凭空**——手从画面边缘长出来，不属于画面里任何一个人。
3. **接戏断在同一帧**（最致命）——同一只手在段 2、段 3 里换了肤色与袖口，
   因为**每段的「一只手」都是模型重新抽的一次样**，没有任何东西保证它们是同一只。

### 根本原因

| 层 | 原因 |
|---|---|
| 表层 | 作者省略归属——写作者脑子里「那是马六的靴」是已知的，笔上就省了 |
| 中层 | 🔴 **归属是上下文，而逐镜单独投喂把上下文切断了**。作者脑子里的「上一句」对模型不存在 |
| 深层 | 🔴 **模型不会追问，只会填空**。缺的信息它按先验分布补一个最像的，且补得**视觉上完全成立**——所以不报错，只悄悄错 |
| 机制层 | 这是**不可见缺陷**：单看一帧看不出问题，跨镜接戏时才暴露。人工复核也容易漏——人复核时会自己把归属补上 |

一句话：**写作者省掉的那几个字，模型会用「最像的陌生人」填上。**

### 为什么既有四道门全没拦住

| 门 | 管什么 | 为什么拦不住 |
|---|---|---|
| `check_prompt.mjs` | 格式与可执行性（站位 / 景别 / 时长 / 动作密度） | 不管**语义指代**——「一只靴」在格式上完全合法 |
| `audit_literal.py` | 抽象、不可演的表述 | 「一只靴抬起」**可演**，它不是抽象表述 |
| `audit_risk.py` | 平台合规 | 与合规无关 |
| `check_style.mjs` | 风格串与色板 | 与风格无关 |

**真正的缺口是一个维度：指代完整性。** 四门覆盖的是「格式 / 可演 / 合规 / 风格」，
没有一门管「这句话里的每个实体，模型能不能找到它的主人」。故立本专项并补两码。

**实战代价**：改完 43 处以为收工，复检又补 7 处（因为第一轮只扫了「画面（事件序）」行），
再上机检又抓出 3 处人工扫漏的。**三轮才收敛**——这就是没有机械门的成本。

## 一、 定义

**局部入画**＝画面里只出现某人的一部分（不是完整的人）：

- 肢端：手 / 掌 / 指 / 拳 / 臂 / 肘 / 脚 / 腿 / 膝
- 鞋履：靴 / 鞋 / 履
- 躯干与头颈：肩 / 背 / 颈 / 下颌 / 额头 / 辫 / 发髻
- 衣饰局部：袖口 / 衣摆 / 下摆 / 裙摆 / 帽檐 / 头巾

**归属**＝这个部件属于画面里的哪一个具名对象（人物名 / 身份名 / 已定名的临时角色）。

**判定口径（一句话）**：把这句话单独抽出来给一个没看过前后文的人读，
他能不能说出这个部件是谁的？说不出 = 缺归属。

## 二、 必写归属的四族词表

| 族 | 词 | 典型坏写法 |
|---|---|---|
| 肢端 | 手 / 掌 / 指 / 拳 / 臂 / 肘 / 脚 / 腿 / 膝 | 一只手举着一张纸 |
| 鞋履 | 靴 / 鞋 / 履 | 一只靴抬起 |
| 躯干与头颈 | 肩 / 背 / 颈 / 下颌 / 额头 / 辫 / 发髻 | 一个跪着的人（整体） |
| 衣饰局部 | 袖口 / 衣摆 / 下摆 / 裙摆 / 帽檐 / 头巾 | 两只袖口从画面两侧进来 |

**豁免（本来就不需要归属的）**：

1. **非身体名词**——「一只纸马」「一只鸟」「一盏灯」「一只碗」，部件词表不含它们，机检不响。
2. **非人的「人」**——纸人 / 泥人 / 木人 / 铜人 / 雪人 / 冰雕 / 画中人，不是人，ANON 码已排除。
3. **无人镜**——空镜、纯群像远景、不露脸 POV。走 §五的声明式豁免。

## 三、 写法三式（照抄即可）

| 式 | 写法 | 用在什么时候 | 例 |
|---|---|---|---|
| **式一**（首选） | 人物名 + 的 + 部件 | 默认 | 「陈砚的手按在册页上」「陈砚的两只手分别拾起两半木牌」 |
| **式二** | 人物名 + 指代 + 部件 | 需要区分「哪一只 / 哪一个」时 | 「马六那只深褐短打的靴抬起」「陈砚那只垂着的袖口不动」 |
| **式三** | 身份名 + 部件 | 临时角色没有名字时 | 「门房的手从缝的内侧横出来」「管家的两只手把木箱盖掀开」「第一名打手转头看第二名」 |

**反例三式（一律禁）**

| 坏写法 | 问题 | 改法 |
|---|---|---|
| 一只靴抬起 | 裸量词，句首无人接 | 马六那只深褐短打的靴抬起 |
| 一个跪着的人 | 无名无身份，模型造脸 | 跪着的陈砚 |
| 第一个人转头看第二个人 | 裸序数 | 第一名打手转头看第二名 |

**临时角色定名纪律（★ 关键，最容易被跳过）**：
打手、门房、管家、路人这类人往往**跨段复现**——段 1 是「一个人」，段 4 是「第一个人」，
模型给出的是两张脸。改法不是写「四个人」，而是**先定名再写**：

```
四名打手从画面左缘挤进来 → 第一名打手转头看第二名 / 打手甲 / 打手乙
```

定名后**必须登记进人物账**（`连续性台账.md` 人物账），否则下集换个名字，等于没定。

## 四、 六个漏点位置（★ 画面行只是第一个）

实战里第一轮只改了「画面（事件序）」行，以为收工，复检又补 7 处——全在下面后五个位置。
**改归属时，六个位置全扫一遍。**

| # | 位置 | 实战漏例 |
|---|---|---|
| 1 | 画面（事件序）行 | 「一只靴抬起」→「马六那只深褐短打的靴抬起」 |
| 2 | **场景行** | 「雪地上已跪着一个人」→「陈砚已跪在雪地上」 |
| 3 | **站位行** | 「管家：只给两只手与袖口」（这个有归属，合格） |
| 4 | **硬性约束行** | 「两只手全程不接触」→「陈砚的手与赵全的手全程不接触」 |
| 5 | **Must not 行** | 「两只手相碰」→「陈砚的手与赵全的手相碰」 |
| 6 | **段名 / 接戏表 / 纪律段** | 段名「一只手扑了空」→「赵全的手扑了空」；「第一个人转头看第二个人」→「第一名打手…」 |

⚠️ 机检只扫 **1、2、3**（正文层：段头 → `Must not` 之前）。**4、5、6 靠人工**——
`Must not` 与表格行走 liqi 的文档层定义（不进正文），做成判据会破坏「正文边界」这条更大的规矩。
所以 §六自检清单里第 5 问专门查这三处。

## 五、 机检两码（`W-BODY-PART-NO-OWNER` / `W-ANON-FIGURE-NO-OWNER`，check_prompt.mjs §22E）

| 码 | 触发 | 级别 |
|---|---|---|
| `W-BODY-PART-NO-OWNER` | 量词 / 指示词（一只 / 另一只 / 两只 / 三双 / 这只 / 那只…）**停在小句开头**，后面紧跟部件词 | WARN |
| `W-ANON-FIGURE-NO-OWNER` | 「一个 / 一名 / 第一个…」+ 人（男人 / 女人 / 汉子 / 身影），且前 8 字内无「的」也无代词 | WARN |

### 判据为什么是「量词停在小句开头」（🔴 第一轮写坏过）

第一版判据是「量词前 8 字内有没有『的』」，结果：

- 「陈砚那只垂着的袖口不动」→ 判**无归属**（错）——它明明写了陈砚，只是没用「的」。
- 这是把**写法偏好**当成了**语义缺陷**。

正确判据：**量词前是标点 / 行首 = 这半句里没有任何人接住它 → 缺归属**；
量词前紧贴着字（「马六那只…」「陈砚那只…」）= 归属已给 → 放行。

### 三条设计限定（与 v5.8.0「完播自评只作自评」、v5.12.0「只查写没写」同一取舍）

1. **只查「带没带归属」，不查归属写得对不对**——谁叫陈砚、马六穿什么，脚本量不出来。
2. **两条都是 WARN，不是 ERROR**——空镜 / 群像远景 / 不露脸 POV 里匿名局部是有意为之，
   做成 ERROR 会逼出「为过门硬塞人名」的假合规。
3. **未触发 = 本段不适用，不是通过**——本段没有局部入画就不会收到警告，那不代表它合格了。

### 声明式豁免（★ 一开始就建，不要等撞了再补）

段头写一行即整段豁免两条：

```
【局部入画豁免】：本段为无人物空镜
【局部入画豁免】：群像远景，无单人局部
```

### 误报源四件套（已实测排除）

1. 非身体名词（一只纸马 / 一盏灯）——部件词表不含。
2. 纸人 / 雪人 / 画中人——ANON 码用 lookbehind 挂在「人」字上排除。
   ⚠️ 挂错位置的教训：第一版把 lookbehind 挂在量词上，「第一个纸人」里量词前是「第」，等于没挂。
3. 台词与声音层——`bodyNoDialogue` 已剥离。
4. 文档层（`>` 引用行、`|` 表格行、`#` 参数行）——不进正文，不扫。

## 六、 自检清单（交付前七问）

1. 这一镜有没有**只露一部分**的身体部件？有 → 第 2 问。
2. 每个部件前面，有没有**人物名 / 身份名**？（不是「他」，是名字；同段两个同性人物时「他」不算）
3. 画面里有**没名字的人**吗？有 → 按 §三的临时角色定名纪律定名，并登记人物账。
4. **六个位置全扫了吗**（§四：画面 / 场景 / 站位 / 硬性约束 / Must not / 段名与接戏表）？
5. 跨段复现的临时角色，**名字前后一致吗**（查人物账）？
6. 确为无人镜 → 段头写了「【局部入画豁免】」吗？
7. 跑完 `check_prompt.mjs` 是 0 error / 0 warning 吗（含本两码）？

## 七、 失败模式（现象 → 原因 → 第一改项）

| 现象 | 原因 | 第一改项 |
|---|---|---|
| 靴 / 鞋款式与人物资产对不上 | 裸量词，模型从先验里抽了一双 | 式二：人名 + 指代 + 部件 |
| 手从画面边缘凭空长出来 | 部件不属于画面里任何人 | 式一：人名 + 的 + 部件 |
| 同一只手跨段换了肤色与袖口 | 每段的「一只手」是独立抽样 | 三段统一定名，登记人物账 |
| 群演 / 打手下一场换了一批脸 | 用「四个人」「第一个人」写群演 | 打手甲 / 乙 / 丙，或第一名打手…第四名 |
| 改完 43 处还有漏 | 只扫了「画面（事件序）」行 | 按 §四六位置全扫 |
| 改完报「写法没问题却还告警」 | 判据把「没用『的』」当成「没归属」 | 量词紧贴人名即视为已归属（式二合法） |

## 八、 与既有规则的边界（不重叠）

| 规则 | 管什么 | 本条管什么 |
|---|---|---|
| `专项_打斗编排.md` §二第 3 段 接触点 | 打斗里**谁击中对方哪个部位**（动力链） | 非打戏镜里**这个部件属于谁**（指代） |
| `专项_打斗编排.md` §二第 4 段 武器锁 | 武器形制与持握 | 不涉及 |
| `check_prompt.mjs` §21d 持物分左右手 | 物件在哪只手 | 手是谁的 |
| `连续性台账.md` 人物账 | 跨段状态（站位 / 朝向 / 服装 / 持物） | 跨段**名字一致性**（定名后必须入账） |
| `表演层_FACS微表情.md` | 脸部肌肉动作 | 不涉及（本条只在部件与整体人的层面） |
| `抽象表述判定口径.md` | 抽象、不可演 | 「一只靴」可演，不在其射程内——**这次补的就是这个盲区** |

一句话分工：**那些门管「写得对不对、演不演得出来」，本条管「每个实体找不找得到主人」。**
