# 去AI味对照清单（对白/旁白/心声专用）

生成对白与旁白时逐条核对，避免机器腔。以下为实际项目制作中积累的对照案例与通用规则。

## 一、书面腔 → 自然口语对照

| 常见 AI 腔（避免） | 自然说法（推荐） | 说明 |
|---|---|---|
| 你的肢体状态十分可疑 | 你的动作不太对劲 | 去掉医学/书面词"肢体状态"，换成口语判断 |
| 请配合前往人身查验室 | （保持不变） | 执法用语本身该正式，保留即可 |
| 他的神情透露出深深的犹豫 | 他犹豫了一下 | 删掉"深深的""透露出"空泛修饰 |
| 内心感到无比挣扎 | 他攥了攥拳，又松开 | 心理活动转成可见动作 |
| 这一刻，他终于幡然醒悟 | 他垂下头，没说话 | 觉悟用行为表现，不喊口号 |
| 所谓"高薪带货兼职"，多是走私陷阱 | （保留） | 普法字幕/配音可适度书面，但别堆形容词 |

## 二、画面描述的 AI 腔 → 可执行描述对照

对白之外，画面描述同样是 AI 味重灾区。判据只有一条：**这句话能不能直接变成画面？不能就删或补支撑。**

| 常见 AI 腔（避免） | 可执行写法（推荐） | 说明 |
|---|---|---|
| 电影感十足的构图 | 中景｜沿土路水平缓推 | 用"景别｜机位｜运动"三元组替掉 |
| 极具张力的氛围 | 角色甲脊背僵硬如泥塑，与那具起伏的粉红躯体对峙 | 张力落到对比关系 |
| 高精度细节丰富 | 粗布补丁，经纬粗粝起毛，补丁针脚外露 | 材质必须可观测 |
| 死寂而诡谲 | 死寂——胸腔以极缓频率起伏，狗身被晨雾吞没只留剪影 | 抽象意境后必须紧跟画面支撑 |
| 光影效果绝美 | 火把光晕在青灰雾墙中炸开成暖橙色团块 | 写清光源、介质、色块 |
| 质感逼真令人不适 | 褪色旧绢/泡胀雨衣质感，轻薄半透，破损边缘 | 用交叉引用锚定已知资产 |
| 情绪递进层次分明 | 瞳孔涣散定焦→嘴唇抿成死线→下颌微颤 | 递进写成五官动作序列 |
| 充满压抑的氛围 | 无泪，嘴唇抿成一道苍白的死线，下颌微颤但强行克制 | 压抑由克制动作呈现 |

**规则**：抽象意境（死寂、诡谲、压抑）允许保留，但必须紧跟一句可执行的画面支撑；
纯形容词（绝美、逼真、张力、电影感）一律删除。

## 三、slop 词计数门禁与精度梯度

画面描述里的空泛词是可以**机械计数**的，比"删掉空泛修饰词"这种定性要求可执行得多。

**计数门禁**（统计整条提示词正文）：

| slop 词数量 | 处置 | 规则码 |
|---|---|---|
| 0 | 提交 | — |
| 1-2 | 删除并收紧 | `W-SLOP-COUNT` |
| 3-4 | 从主体重新往下写 | `W-SLOP-COUNT` |
| ≥5 | 推倒重来，按五层结构重写 | `E-SLOP-OVERLOAD`（P0 阻断，不许交付） |

四档互斥、无缝覆盖：3–4 归 warning，≥5 一律升为阻断级，不存在「5 既算重写又算推倒」的两属情况。

**常见 slop 词**：电影感、高级感、氛围感、大片感、质感拉满、细节丰富、极其、非常、十分、
惊心动魄、引人深思、深刻揭露、耐人寻味、震撼、完美呈现、精妙绝伦、栩栩如生、超高、极致、
顶级、一流、卓越、绝佳、cinematic masterpiece、stunning、breathtaking、hyper-detailed、
ultra-realistic、award-winning、best quality

**精度梯度**（同一概念从弱到强，描述布光的例子）：

| 层级 | 写法 |
|---|---|
| Level 0（slop） | 氛围感布光 |
| Level 1（类型） | 戏剧肖像光 |
| Level 2（布光） | 三点布光 |
| Level 3（角度） | 45° 主光，右侧柔补，顶逆发丝光 |
| Level 4（数值） | 主光 45° 机位左，3200K |

**至少做到 Level 3**。Level 4 只在一致性要求极高时使用，且**数值类表述不进正文**（写入参数行）。

## 四、去AI味通用规则

1. **删空泛修饰**：惊心动魄、引人深思、深刻揭露、耐人寻味、无不体现——一律不写。
2. **删三段式排比**："不仅…更…还…""从…到…再到…"拆成平实一句。
3. **删标题腔**：不加"警示！""触目惊心！"式感叹号堆砌。
4. **心理活动改心声**：角色内心戏优先用"心声（V.O.，画外音，音色压轻、带轻微混响）"，不要让他开口说出来——开口说话要符合剧情逻辑（对面有人才说话）。
5. **判断要有依据**：执法/结论性台词必须保留因果（"箱子没问题，动作不太对劲"→ 才引出人身查验）；删掉依据会让逻辑断掉。
6. **一句话一个意思**：对白别写长从句，像真人说话，短句为主。
7. **情绪用动作呈现**：紧张=步伐僵硬/攥拳/低头，心动=瞳孔微睁/嘴角微扬，不直接写"他很紧张"。

## 五、写入提示词时的格式要求

- 对白/旁白/心声一律用「」包住原文，标注形式（画外音/对白/心声/电话滤波/电流质感）与语气/语速。
- 台词以剧本原文为准、一字不差，禁止让 AI 自行生成或改写台词；"一字不差，后期配音/合成"仅在全局制作纪律声明一次，逐镜不重复标注。
- 若台词有引号（如法条引用），内外引号分清。
