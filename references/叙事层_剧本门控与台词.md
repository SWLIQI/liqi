> 🔗 流程位置：**Step -1（可选前置层）**。触发条件——原料不是合格剧本（只有梗概 / 小说 / 一句创意），或用户明确要求审剧本。原料已是合格剧本时**整层跳过**。
>
> 本层吸收自一套上游短剧工程方法论的四个模块（剧本门控引擎 / 台词七维诊断 / 语速校验 / 情绪节拍曲线），
> 这些模块**未随本仓库分发**，其结论已并入下文各节。
> **已按文艺短片 / 公益片 / 毕设的适用性裁剪**——裁掉了抖音短剧专用的爽点铁律。

## 一、 五阶门控（Gate 1~5）

禁止跳过结构直接写大段台词。

### Gate 1 · Premise（核心前提）

**30 字前提公式**：`[主角] + [核心欲望] + [不可抗力阻碍] + [失败的致命代价]`

四项缺一，后续所有节拍都会漂。写完逐项打勾。

**开场钩子类型**（必须选定其一，但不强制必须是「极端」型）：

1. 极端悬念——把刀尖对准主角咽喉，生死悬于一瞬
2. 认知反差——最弱的人展现出颠覆常理的能力
3. 情绪爆发——至亲受辱 / 婚约撕毁 / 绝境背叛
4. 视觉奇观——异象、法相、天雷裂空

> ⚠️ **裁剪说明**：常见模板要求钩子必须「黄金 3 秒」且「拒绝无事件铺垫」——那是对信息流平台的适配。文艺短片可以慢开场，**但第一拍必须在 3 秒内给出一个「值得看下去」的信息**（一个动作、一个反常、一个视线），不能是空镜。

### Gate 2 · Structure（结构）

**三幕时间比例**：铺垫建立 **30%** → 核心冲突危机 **50%** → 转折爆发与卡点 **20%**。

> ⚠️ **裁剪说明**：100 秒单集类模板给的是具体秒数（0~30s / 30~80s / 80~100s）。**只吸收比例，不吸收秒数**——比例可以套到任意时长。

**结尾卡点**：必须停在决策关头、身份暴露瞬间或攻击命中的**前一帧**。

### Gate 3 · Beat Sheet（场景因果节拍表）

**场次存在性法则**：一场戏如果删掉后**不影响后续剧情**，则该场戏必须立即删除。

这条是全层最硬的一条，直接砍水。创作时不舍得删的过场戏，删掉几乎总是让片子更好。

**每场戏必须包含完整因果链**：

```
场景目标 → 遭遇阻碍 → 升级行动 → 意外转折 → 产生不可逆新局面
```

五段缺一，这场戏就是「发生了点什么」，而不是「推进了什么」。

#### 反派阶梯两检（v5.20.0 · 多集/长篇必查）

逆袭类叙事的高频死法是**反派原地踏步**——第 2 集和第 8 集在跟同一种坏蛋斗同一种坏。两检（语义项，人工）：

1. **阶梯检**：反派按「权力源」分级爬坡——**职权（站长）→ 金钱（白嫖团伙）→ 合同（车行陷阱）→ 权力（总部高管）→ 名望（公关话语权）**。同级反派不得连续 ≥3 集（范本：外部《单王》五级五源，L1→L5 每 2-3 集升一级）。
2. **打脸升级检**：主角的反击方式必须逐级升级——**现场（当众）→ 证据（留痕）→ 规则（用对方的规则）→ 真相（揭穿）→ 舆论（公开）**。打脸方式降级回退 = 爽感断电。

### Gate 4 · Worldview & Entity Bounds（世界观与实体边界）

- **时代法则**：明确时代背景（古代 / 民国 / 现代 / 赛博未来），锁定**法律、战力天花板、技术极限**
- **人际关系网络**：明确上下级、仇恨、盟友关系，**杜绝无动机叛变**

战力天花板尤其重要——它决定冲突怎么解决。天花板没锁，第三幕就会出现「主角忽然会飞」这类崩坏。

#### 软肋锚点＝物（v5.20.0 · 人物设定必答）

**每个主要角色的软肋必须挂在一个「物」上**，并在资产清单登记（`category: softspot`，与关键道具同权不同类）：

- 为什么：AI 视频跨镜一致性靠**同一物件反复出现**来锚——角色的脆弱性写在台词里，模型记不住；挂在裂头盔/绘本/旧工牌上，观众每看一次就记一次。
- 判据：主要角色（有名字且戏份 ≥2 场）人人有软肋物；该物必须进 `asset-registry.json` 的 props 桶（`W-ASSET-SOFTSPOT-DANGLING` 机检挂靠反向；空物 = 分类手滑，`W-ASSET-SOFTSPOT-ORPHAN`）。
- 范本（外部《单王》）：周野＝弟弟的裂头盔（裂纹随剧情加深＝软肋的视觉进度条）；小满＝女儿贴画的保温箱；大鹏＝母亲的透析单据。
- **软肋物的裂痕/破损是状态弧**：随剧情恶化的破损走 `props.*.state_arc`（或场景的 `damage_states`）登记，不新建卡。

### Gate 5 · Script Page（标准排版）

```
[场景序号] [内景/外景] · [具体地点] - [日景/夜景]
出场人物：@角色A、@角色B        ← 脚本页只列名；**提示词包的「出场人物」行还带身份描述**（Step 3 第 5 小节）
环境氛围：[空间构图、天气、主导光源与声音质感]

[动作描述]（遵循反形容词法则，只写摄像机能拍到的物理动作与空间位移）

@角色A（微动作指示：咬紧后槽牙，指节因用力而泛白）
"（台词内容，遵循冰山法则与潜台词）"
```

**反形容词法则**：只写摄像机能记录的东西。「他很愤怒」不写，写「咬紧后槽牙，咬肌隆起」。

## 二、 去 AI 机械感三大法则

1. **角色压力与筹码追踪**：角色对话不是客气的问答，而是**权力、信息与立场的隐秘博弈**。每句对话必须有一方施压、另一方掩饰或反击。**杜绝毫无立场的解释性闲聊。**

2. **承重场景识别**：区分**承重戏**（生死抉择、秘密揭穿、师徒死斗——投入最高视听与微表情密度）与**过场戏**（果断视听省略，一镜带过）。**不要在过场戏上花承重戏的预算。**

3. **冰山对白（反解释性）**：**严禁角色向已经知情的同伴解释世界观设定**（「你明知道这本秘籍是天下第一……」）。双方已知信息一律转入潜台词、眼神与道具动作。

## 三、 台词七维诊断

每句台词全量过一遍七维，命中致命病灶的必须重写。

| 维度 | 致命病灶（必须切除） | 重构方向 |
|---|---|---|
| **1 角色辨识度** | 全员同一种文绉绉或书面化语调 | 建立角色语言指纹：粗人糙话短句，书生引典留白，杀手惜字如金 |
| **2 潜台词层级** | 0 层直白陈述（「我很愤怒，我要杀了你」） | 1~3 层潜台词（「茶凉了，换杯热的再上路吧」） |
| **3 冲突推进力** | 礼貌寒暄、无意义重复、被动附和 | 每句必须产生信息 / 立场 / 情绪 / 行动**变动** |
| **4 类型语感** | 古装戏冒出「经济损失 / 逻辑漏洞」等现代词 | 严格匹配题材语感：古风简炼，港派生猛，市井接地气 |
| **5 信息效率** | 自报家门向观众交代背景（「我是你师兄……」） | 双方已知信息一律删去，转为动作与微表情 |
| **6 节奏与音乐性** | 连续 30 字以上无气口大长句 | 单句 6~18 字，关键金句预留 0.5s 停顿发酵 |
| **7 金句潜力** | 通篇大白话，无任何记忆点 | 提炼蕴含哲理、反常识或极度反差的高光句 |

#### 语言三件套（v5.20.0 · 辨识度维的工具）

七维诊断的「角色辨识度」维从感觉变工具——**每个主要角色落三件，缺一件即辨识度不达标**：

| 件 | 内容 | 判据 | 范本（外部爆款管线《单王》） |
|---|---|---|---|
| **口癖句** | 一句只在危机/动情时蹦出来的短句 | 全集 ≤1 句，出现 ≤2 次 | 「先拍照，再说话」／「讲不讲理啊」 |
| **句长档** | 该角色的基准句长（短/中/长） | 同角色不得跨档漂移（情绪爆发可临时升一档，须回落） | 周野短句｜苏芮中句｜赵德柱官腔长句 |
| **对主角称呼** | 该角色怎么叫主角 | **称呼变化 = 关系状态信号**，变化必须登记进关系图事件行 | 大鹏：野哥 → E10 起「周顾问」（叛徒归位的观众通知） |

**为什么值得抄**：AI 视频一镜一投，观众认人靠声音和称呼——三件套是「闭眼听也能分出谁在说」的最低配置。机检不做（语义项），进 CT 契约人工勾选。

### 三段式重构输出契约

改写建议必须给出**不少于 3 条具体维度依据**——不给依据的改写是感觉，会被打回。

```
原台词：「[原剧本台词]」
改写建议：「[重构后的台词]」
为什么这么改：
  1. 【维度X 辨识度/语感】：…
  2. 【维度Y 潜台词/信息效率】：…
  3. 【维度Z 节奏与视听留白】：…
```

**🔴 定稿即冻结**：本层是台词的**唯一**可改阶段。进了 Step 2 之后一字不差，由 `audit_project.py` 的 A 项守着。

## 四、 语速三档与自检

> ⚠️ **本节是「赛道① 国内剧」的对白口径。** 赛道②（海外剧）按目标语言重算
> （英文 ≈ 2.2~3.0 词/秒，**禁用字/秒**）；赛道③（解说叙事类）走**解说专用档**
> （排期 3.8~5.0 字/秒、金句 3~3.6、硬闸 6.5）。见 `赛道分流.md` 第五节。

| 档位 | 语速 | 适用 |
|---|---|---|
| **标准语速** | **3.5 ~ 5 字/秒** | 普通对白、文戏推进、信息交代 |
| **慢速重音** | < 3.5 字/秒 | 金句宣言、临终遗言、情绪顶点、威慑台词（一字一顿） |
| **快速爆发** | > 5 字/秒 | 情绪失控、争吵、紧张逼问（⚠️ 连续 >5 字/秒 不得超过 3 秒） |
| **物理红线**<br>（不是档，是硬闸） | > 6.5 字/秒 | 物理不可实现——排到这个速度的台词必须拆句（与 `SKILL.md` 单句语速行同值） |

### 🔴 实测校准（排期请用这一张，不要用上面的理论档）

上面那张是**理论可行区间**（配音员能做到的范围），不是**排期舒适区**。
按它排期会全线偏紧——实测中文叙事短片的实际语速远低于其下限。

**实测基准**（96 条中文配音，1305 字 / 503.8 秒）：

- **全片均值 2.59 字/秒**，最快 3.79 字/秒，**4.0 以上 0 句**

| 类型 | 实测语速 | 说明 |
|---|---|---|
| 说书人 / 旁白（慢板） | **3.6 ~ 3.8** | 字头重、句尾拖腔，看似慢但单位字数多 |
| 普通对白 | **3.4 ~ 3.6** | 文戏推进 |
| 情绪重拍 | **2.6 ~ 3.0** | 临终、威慑、哭腔、停顿多的句子 |
| **校验上限** | **3.2** | 排期时超过这个数就要警惕 |

**用法**：排期用实测表，**红线仍用原表**（>6.5 物理不可实现那条不变）。
两者的关系是——原表回答"这句话念不念得完"，实测表回答"这样排好不好听、挤不挤"。

**排期后果警示**：某片按理论档（3.5-5）排完，32 句超标、9 句 >6 字/秒，
整片听感是赶。同样内容按实测档（均值 2.59、上限 3.2）重排后余裕正常。

**速算**：

```
口播时长 = 可发音字符数 ÷ 语速
对白总时长 = 口播时长 + 标点停顿 + 情绪停顿 + 金句余韵
最短有效 = 字数 ÷ 5      最长有效 = 字数 ÷ 3.5
```

**字数口径**：只数**可发音字符**（汉字、数字、外文字母），**标点不计入语速公式**，另按停顿预算独立处理（顿号逗号 ≈0.1–0.3s，句号感叹问号 ≈0.3–0.6s）。

### 六步自检流程

拆句（按逗号/句号/感叹/问号）→ 计数（只数可发音字符）→ 停顿预算 → 套档 → 速算 → 判定。

### 判定五档

| 判定 | 条件 | 处置 |
|---|---|---|
| ✅ 合规 | 语速 3.5~5 字/秒，且单句 ≤24 字 | 通过 |
| ✅ 排期舒适（推荐） | 语速 2.6~3.6 字/秒（见实测校准表） | 通过，且听感有余裕 |
| ⚠️ 超长句（P1） | 单句 >24 字 | **强制拆镜**：正反打 / 过肩 / 反应镜头拆 2~3 镜，每镜 ≤18 字 |
| ⚠️ 金句缺发酵（P2） | 关键台词 / 高潮金句后无 0.3~0.8s 反应镜头 | 补微表情或旁观者反应（瞳孔骤缩 / 倒吸凉气 / 静场） |
| 🔴 超时（P0） | 台词所需时长超该镜预算，或为塞时长强行放慢/加速 | 重构台词或调整镜次分配，**严禁超镜时长** |

### 字数速查表

| 字数 | 所需时长 | 判定 |
|---|---|---|
| ≤8 字 | 1.6–2.3 s | ✅ 短句，适合金句/威慑 |
| 10 字 | 2.0–2.9 s | ✅ 标准句 |
| 14 字 | 2.8–4.0 s | ✅ 标准句 |
| 18 字 | 3.6–5.1 s | ✅ 上限附近（建议拆分） |
| 24 字 | 4.8–6.9 s | ⚠️ 触发拆镜阈值 |
| 30 字 | 6.0–8.6 s | 🔴 必须拆 2–3 镜 |

### 拆镜示范

```
原台词（33 字）：「三年前你杀我师父灭我师门占我武馆今日我陈烬归来倒要看看谁该灭门偿命」

镜1（近景·正面）：「三年前，你杀我师父，灭我师门，占我武馆。」16字 ≈3.2–4.6s + 4处停顿≈0.6s
镜2（特写·眼神）：「今日我陈烬归来。」7字 ≈1.4–2.0s，金句前预留 0.3s
镜3（近景·步步逼近）：「我倒要看看——谁，该灭门偿命！」11字 ≈2.2–3.1s，结尾预留 0.5s 发酵
```

**自检卡是内部 QC 附件，不写入提示词正文。**

```
台词：「…」  字数：N  语速档：标准/慢速/快速  所需时长：约 X~Y 秒
判定：✅ / ⚠️ / 🔴    建议：…
```

## 五、 情绪张力曲线

量化全片节拍点的情绪张力（0~10 分），画成曲线，直观评估节奏。

### 只吸收四条法则

1. **波峰波谷法则**：全片波峰（≥9.0）**不少于 2 次**，且高潮之间**必须有适度回落**。**严禁持续平庸（全片 5~6 分平铺）或持续高压无喘息。**
2. **开局冲突**：第 1 个节拍点必须在 3.0 分以上且伴随即时冲突，**拒绝无事件铺垫**。

### 不吸收的部分（以及为什么）

面向信息流短剧的 12 节拍表，节拍名与目标分值**不可移植**：

| 原规则 | 不吸收的原因 |
|---|---|
| 「第 9 节拍必须达到全片最高峰值 9.5+，实现戏剧张力的绝对释放」 | 这是爽点铁律。它默认观众在刷信息流、需要每 10 秒喂一次爽点。文艺短片、毕设、公益片照做会毁掉节奏——这类片子的张力可以整体偏低、波峰更少 |
| 「悬疑·起势 3.0~4.0 / 危机·陷阱 8.0~8.5 / 反击·反杀 9.5~9.8」这套固定分值 | 短剧专用剧本结构（反派底牌 → 绝境 → 反杀）。题材不匹配时，硬套会让节奏变得机械 |
| 「终局清算 / 余波震荡 / 尾钩」 | 「尾钩」是连续剧概念，单片不需要 |

### 可移植的输出形式

1. 逐节拍列出「情节 + 张力分值（0~10）」
2. 判定波峰数量是否 ≥2、高潮间是否有回落
3. 可选：用 `scripts/generate_emotion_curve.py` 画折线图（PNG）标注高潮区

**判定口诀**：不看绝对值，看**形状**——有没有起伏、有没有回落、有没有一段长到让人走神的高原。

## 五·补、筹码变化账与尾钩链（v5.20.0 · 多集项目）

> **完整规程（四类筹码 / 尾钩四型 / 三条铁律 / 分集结构表格式 / 机检）唯一权威 = `references/尾钩与筹码账.md`。** 本节只立两条纪律，防与既有规则混淆：

1. **筹码账（集间）≠ 台词章筹码（句间）**：第二节「角色压力与筹码追踪」管**每一句对话**里的权力博弈；本节的筹码账管**每一集**主角的得失——每集至少一类非空（信息 / 关系 / 资源 / 力量）。一集下来四条都没变 = 水集（`W-EPSTRUCT-STAKES-EMPTY`）。
2. **尾钩（集尾）≠ 钩子门（开场）**：钩子门管开场 3 秒让人点进来；尾钩管集尾 15 秒让人点下一集，且**下集前 30 秒必须回收**（`W-EPSTRUCT-RECALL-EMPTY`）。多集项目每集都要，季终集除外（季终钩归第二季，见 `连载记忆与多集一致性.md`）。

**驱动输入**：《分集结构表》（`audit_project.py --epstruct`，七列：集 / 核心事件 / 筹码类型 / 筹码内容 / 尾钩类型 / 尾钩内容 / 下集回收）。

## 六、 分阶段量化门禁（v5.8.1 新增）

> 上游来源：漫剧老李 V7.4.20 `sd-script-engine`（六阶段管线的阶段门禁 + 锁稿二十五项质量门
> + 情节点密度下限 + 事实权威链）。**只吸收可量化的部分**，五席圆桌见下一节的轻量替代。

旧版五阶门控是**描述性**的（Gate 1~5 各有进入条件与产出），但没有数值——
于是「这场戏够不够」「这一集跳不跳」全凭感觉，且**每份文档无法复核**。
本节把能变成数值的变成数值，不能变的明写「人工核对」，不冒充机检。

### 6.1 门禁总表

| 门 | 量化判据 | 核对方式 |
|---|---|---|
| **Gate 1 Premise** | 30 字前提四要素齐全；开场钩子类型已选定（四选一） | 人工打勾 |
| **Gate 2 Structure** | 三幕比例 **30% / 50% / 20%** 可核算；结尾卡点停在决策关头 / 身份暴露 / 攻击命中的**前一帧** | 人工核算 |
| **Gate 3 情节点密度** | **单集 ≥5 个；15s 投喂段 ≥1 个**；相邻情节点之间**不得跨过一场戏** | **机检 N2** |
| **Gate 3 因果链完整度** | 每场五段齐全：场景目标 → 遭遇阻碍 → 升级行动 → 意外转折 → 不可逆新局面 | 人工清单 |
| **Gate 4 实体编号唯一性** | 同一实体不得两个编号；编号跨集连续 | **机检 N1** |
| **Gate 5 锁稿门** | 对白零擅删 / 场景编号连续 / 角色出场可追溯 | **A 门 + N1** |
| **改编类任务** | 事实权威链五级标注必做（FACT / INFERENCE / ASSUMPTION / USER_OVERRIDE / OPEN_ITEM） | **机检 N3** |

### 6.2 情节点：定义、标注与两条下限

**定义**：一次**意图变化 / 关系变化 / 信息翻转**，任一即算一个情节点。
不是「发生了一件事」——一件事没改变任何人的意图、关系或信息量，它就不算情节点。

**标注方式**（机检靠这个统计，不标就查不了）：

```
情节点：桃木剑被认出是长风师父的旧物（信息翻转 · 清羽立场动摇）
```

或用括号注记 `（情节点：…）`。**一个剧本不标注任何情节点，机检不会替你猜**——
报「未标注，无法核对」，这不是通过（见 6.5）。

**两条下限**：

- **单集 ≥5 个**：低于 5 个，一集里观众能记住的转折不足，节奏必然发闷。
- **15s 投喂段 ≥1 个**：AI 视频每一段是独立生成的，一个 15 秒段里没有任何情节点，
  这段出片就是「一段好看的空镜」——观众会划走。

**相邻情节点不得跨过一场戏**：这一场的后果必须在下一场被看见。
跳过了，观众自行脑补的那一段就是剧情「跳太快」的来源（该条来自上游实测反馈：
「段一是两人对话，段二一下变成四个人，它得有个过渡吧」——过渡是**剧本层的戏点**，
不是分镜层的技术补丁，分镜只能补交代、补不出戏）。

### 6.3 实体编号唯一性（Gate 4）

- **同一实体不得两个编号**：同一个人在第 3 场叫 `@长风`、第 7 场叫 `@长风道长`，
  下游资产层就会当两个人建两套资产（这是 liqi 资产层最贵的一类返工）。
- **编号跨集连续**：跨集项目按集连续编号，不每集从 1 重排——重排等于每集一套实体，
  连续性台账与资产注册表会在集边界整片失效。
- 编号与 `asset-registry.json` 的 slug 对齐（小写连字符），**禁止中文文件名与空格**。

### 6.4 事实权威链五级（改编类任务必做）

改编项目里每一处「这不是原作写明的」都必须标注等级，五选一：

| 级别 | 含义 | 处理 |
|---|---|---|
| **FACT** | 原作明文 | 直接可用 |
| **INFERENCE** | 由原作两条以上事实推得 | 可用，但要在审稿层写明推导链 |
| **ASSUMPTION** | 原作无据，为连贯而设 | 必须过用户确认才能进正文 |
| **USER_OVERRIDE** | 用户明确要求改写 | 记录原作原文 + 用户原话 |
| **OPEN_ITEM** | 尚未确定 | 挂起，禁止静默按默认处理 |

**为什么必须分级**：不分级时，模型推断会被当成原作事实写进正文，
到第三集就出现「原作里没有的设定被当成铁律」——而且没人知道是哪一句开始跑偏的。
权威顺序固定：`用户提供的小说事实 > 锁定剧本 > 分集规划 > 当前稿 > 审稿意见`。

### 6.4b 改编转换表（v5.20.0 · 真实事件改编类任务）

N3 管「事实不许漂」，本节管**「不爽点 → 合规爽点」的转换登记**——真实事件改编（〇·1 锁②改编的常见形态）每集填一行：

```markdown
| 集 | 真实原型 | 不爽点 | 爽改编 | 爽点配方 | 合规处理 |
| 1 | 深圳骑手坐地铁送单被判超速 | 人不在车上也算超速，申诉无用 | 闸机记录+时刻表当众反杀 | S05 | 维权走平台申诉，不教唆违规 |
```

**合规处理列不许空**（`W-ADAPT-COMPLIANCE`）：写清取证路径 / 执法主体 / 去性化处理 / 不教唆违规。audit_risk 只查词，查不了这一层——**过审风险要在剧本层就拆弹，不能等提示词层**。
驱动：`audit_project.py --adapttable <改编转换表.md>`（N3b 门；`--adapt` 时建议同给）。

### 6.5 机检 N1~N7 + N3b（`audit_project.py`，v5.20.0 扩）

| 码 | 判据 | 级别 |
|---|---|---|
| **N1 场序号** | 重复编号 = **ERROR**；缺号 / 乱序 = WARN | ERROR / WARN |
| **N2 情节点密度** | 全剧 0 处标注 → WARN「未标注，无法核对」（**不是通过**）；单集 <5 → WARN；折算每 15s <1 → WARN | WARN |
| **N3 事实权威链** | `--adapt` 时全剧 0 处五级标注 → WARN「改编任务未做标注，无法核对」 | WARN |
| **N3b 改编转换表** | `--adapttable`：每集合规处理列为空 → `W-ADAPT-COMPLIANCE`；爽点配方编号 ∉ S01~S07 → `W-ADAPT-SDCODE`；表解析 0 行 → `E-ADAPTTABLE-EMPTY` | WARN / ERROR |
| **N4 伏笔生命周期** | `--foreshadow`：ID 重复 / 状态枚举 / 回收集空 / 回收早于埋设 = ERROR；埋后 <2 集回收 = WARN | ERROR / WARN |
| **N4b 反转分级（v5.20.0）** | 伏笔表 7 列扩展格式：级别 ∉ L1/L2/L3 → `E-FORESHADOW-LEVEL`；L2 锚点 <3 / L3 <4 → `W-FORESHADOW-ANCHOR`；相邻 L2+ 埋设集间隔 >4 → `W-FORESHADOW-GAP`。**5 列旧表照常解析**（级默认 L1、不查锚点） | ERROR / WARN |

| **F8 软肋物挂靠（v5.20.0）** | `--registry`：角色 softspot 指向的 prop 不存在 → `W-ASSET-SOFTSPOT-DANGLING`；已登记但 category ≠ softspot → `W-ASSET-SOFTSPOT-CATEGORY`；标了 softspot 无人引用 → `W-ASSET-SOFTSPOT-ORPHAN` | WARN |

### 6.6 爽点配方门（`check_prompt.mjs --beats`，v5.20.0）

见 §乜。三码：`W-SHUANGDIAN-NONE`（声明了但 0 个 S 编号）/ `W-SHUANGDIAN-SPARSE`（密度 <1 个/15s）/ `W-SHUANGDIAN-MONOTYPE`（只用一种配方），包首声明 `〚爽点门〛查` 才启用，**全 WARN**。

**三条都是「没标就不算通过」口径**——与 liqi 一贯的假绿防护一致：
没输入就报跳过，绝不把「没查」显示成「通过」。

## 七、 三视角审稿（轻量版，v5.8.1 新增）

> **不搬五席圆桌 full 版**：上游是「两名主编 + 三类观众」五席独立审读 + 加权算 S/A/B/NOT_READY，
> 那是为**长剧多批次**设计的。liqi 的用户做的是单集短片 / 毕设 / 公益片，
> 五席会把它变成一场流程表演。**改为三视角轻量版**，保留它的两个内核：
> **独立视角**与**反捧杀**。

### 7.1 三视角与各自只问什么

| 视角 | 只问什么 | 不许问 |
|---|---|---|
| **观众视角** | 哪里没看懂、哪里想划走、哪个人记不住 | 不许评价文笔 |
| **类型视角** | 这个类型的观众在这里期待什么、剧本给没给 | 不许按别的类型要求 |
| **类型反例视角** | 如果这个类型最烂的那批片子会怎么拍这一场——本稿有没有踩 | 不许给改进方案（只指病灶） |

**每视角至少 2 个真实问题。** 「整体节奏不错，建议加强人物塑造」这类空话**不算**——
写不出 2 个真问题，说明这个视角没审，重审。

### 7.2 反捧杀两条

1. **创作笔记自评不满意点 ≥1 条**：作者本人必须写出至少一处自己不满意的地方。
   「全都满意」的稿子不存在，写不出 = 没真读自己的稿。
2. **会诊一致度过高警报**：三个视角**全部给好评**时，判为可疑——
   强制回到「类型反例视角」再审一轮。全票通过通常是没审，不是真好。

### 7.3 输出格式

```
观众视角：
  1. …
  2. …
类型视角：
  1. …
  2. …
类型反例视角：
  1. …
  2. …
创作笔记·自评不满意点：
  1. …
判定：通过 / 回炉（写明回炉到哪个 Gate）
```

**等级只代表剧本层潜力，不预测成片质量**，也不作为交付硬门——
它是自检工具，不是门禁（与 §五情绪曲线、§四语速自检同一性质）。

## 九、 爽点配方（v5.20.0 · 只对赛道①国内剧 · 声明式 opt-in）

> **来源**：外部爆款管线《单王》爽点编号系统 S01~S07（2026-10-17 检索吸收）。
> **🔴 吸收必须带枷锁**——liqi 在 §五明写拒绝过信息流爽点铁律（「第 9 节拍必须 9.5+ 反杀」），
> 那条裁决对文艺短片/毕设/公益片依然有效，本节不推翻它。四条枷锁：
> ① **只对赛道①国内剧**（信息流短剧形态）适用；② 包首声明 `【爽点门】查` 才启用，
> 不声明 = 本门不适用（**不是通过**）；③ **只登记不设 ERROR**（密度/多样性全 WARN）——
> 语义参量阻断会把爽点逼成注水；④ **配方是工具箱，节拍表是模板，都不是铁律**。

### 9.1 七种爽点配方

| 编号 | 配方 | 一句话判据 | 《单王》范本 |
|---|---|---|---|
| S01 | 证据翻案 | 弱势方用完整证据链当场翻盘 | 三千张同框照 |
| S02 | 以退为进 | 受害者替施害者说话，反获更大胜利 | 骑手劝网友别网暴店员 |
| S03 | 规则反杀 | 用对方定的规则击倒对方 | 出餐超时上报让门店整改 |
| S04 | 温暖回报 | 善意得到具体回报（反向也可：背叛者的痛） | 哑叔的豆浆 |
| S05 | 认知反杀 | 观众以为的优势当场被反转 | 地铁送单反证「系统误判」 |
| S06 | 代价陈述 | 用一句代价代替宣言 | 「不好意思，刚刚在救人」 |
| S07 | 系统升级 | 个人的较真变成规则的改变 | 平台上线超范围服务提示 |

### 9.2 标注与两条纪律

**标注**：在节拍清单（beats）的拍描述里写配方编号，如 `P01｜场次1｜甲推门反杀（S05）｜动作`。
`check_prompt.mjs --beats` 随带统计（`W-SHUANGDIAN-NONE` / `W-SHUANGDIAN-SPARSE` / `W-SHUANGDIAN-MONOTYPE`）：

1. **密度纪律**：爽点数 / (总秒/15s) <1 → WARN——一个 15s 段没有任何爽点，出片就是空镜。
2. **多样性纪律**：只用一种配方 → WARN——同一配方用三集，观众第三集起疲劳。

**补爽点只走四正路**：补兑现 / 补反转 / 补代价 / 补关系变化——禁拉长文采凑字（同 N2 情节点口径）。
