# 国漫赛璐璐 2D 风格锚（卡通轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**国漫 2D 赛璐璐**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

**适用判定**：美型人物设计、赛璐璐两段式上色、线条流畅清晰、色块干净饱和、大眼高光瞳、
明确的轮廓线。现代都市 / 古风 / 仙侠 / 奇幻题材的日常戏与轻喜剧气质都吃这套。
用户给的设定图是这类质感时，锁③ 风格轨道选**卡通轨**，风格 id 取 `celshade-guoman-2d`。

**边界声明**：

- 与写实轨：写实轨要 PBR 真实皮肤与高精度材质；本轨要「画出来的」——色块与描边就是风格本体。
  **皮肤毛孔、次表面散射、镜面反射一律不写**，写了就滑向 3D。
- 与手绘轨（水墨）：水墨要细匀墨线与边缘晕染、要平面无体积；本轨要**明确轮廓线与硬边阴影**。
  两者最像也最容易混，判据是**阴影边界**：硬边 = 赛璐璐，晕开 = 水墨。
- 与三渲二轨：三渲二（npr-celshaded-3d）是 3D 模型套卡通着色，可以做 360 环绕与转面；
  本轨是 2D，环绕与强透视会崩。**选了本轨就不写环绕运镜**。

> ⚠️ **版权规避**：投喂词内**不点名任何具体作品名**（哪怕用户拿某部番剧当参照系）。
> 只写风格特征——赛璐璐、美型、国漫 2D。作品名只出现在本文档的说明层与对话里。
> 平台对作品名有过滤，点名有概率触发拦截或串到别的画风。

## 一、九段锚（中文，给 liqi 上游用）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 国漫 2D 动画赛璐璐上色风格，美型人物设计；线条清晰流畅，色块干净，阴影为边缘分明的两段式阴影（亮部一个色、暗部一个色，中间不做过渡），整张画面光照统一；轮廓线明确但不粗黑；无噪点颗粒 |
| ② 配色与色域 | 明快干净的中高饱和：主色按角色固有色走，暗部用固有色加深一档而非加黑；**每镜只声明一个唯一重音色**；禁用荧光、霓虹、脏灰混色、胶片颗粒感 |
| ③ 运动签名 | 24fps，动作起收干净、关键帧明确；不做运动模糊（赛璐璐动画没有）；无镜头抖动、无抽帧卡顿；幅度可以大——本轨不吃「克制」，吃「清楚」 |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 6–6.5（美型成人档；孩童取 4.5–5，Q 版 2–3 是另一条轨，本轨禁）**；脸型、发型与发饰、眉眼特征（大眼高光瞳）、服装形制与配色、鞋袜；转面不换形，跨镜不换装 |
| ⑤ 场景锁定 | 走 `<Subject N>`：建筑形制与配色、地面质地、植被种类与位置；背景允许压成干净色块与简单透视，但**同场景跨镜地标与光位必须一致** |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、持握方式；道具入画方式必须写（手持 / 悬挂 / 置地）；木质与金属一律用形状化色块 + 明确高光形状表达，不写反射细节 |
| ⑦ 光色基调 | 单光源为主；亮部一个色、暗部一个色，分界硬；阴影是**固有色暗部**，不是灰、不是黑；不写渐变、体积光、环境光遮蔽；逆光可以写，但轮廓光要画成一条明确的亮边而不是渐变 |
| ⑧ 声音签名 | 环境层：按场景走（都市车流底噪 / 古风风声虫鸣）；动作层：衣料摩擦、脚步、道具碰撞，节拍清晰；呼吸层：动画式夸张呼吸，可闻可见；配乐：明快，可带轻喜剧气质 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅生图模型与其他有 negative 字段的面可用：写实照片、3D 渲染、CG 质感、真人皮肤质感与毛孔、厚涂油画笔触、噪点颗粒、Q 版二头身、儿童化、可读文字、水印 logo |

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Chinese 2D animation frame in clean cel-shading, with smooth confident linework, flat colour areas and two-tone shading split by a hard edge. Large eyes with a single crisp catchlight, even outlines, no gradient, no grain. One light source, unified lighting across the whole frame.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
clean saturated cel-shading palette where shadow is the local colour one step darker, never grey or black, with a single accent hue per frame
```

**三处措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `2D anime` / `anime style` | `Chinese 2D animation` | 本轨是国漫不是日系；写 `anime` 会被路由到日式赛璐璐通道，眼型与头身比整套偏过去 |
| `soft shadow` / `gradient shading` | `two-tone shading split by a hard edge` | 渐变是本轨第一崩点——一软就变厚涂二次元，明暗逻辑整个反过来 |
| `realistic skin` / `skin texture` | 删除 | 写实皮肤词是滑向 3D 的入口 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅国漫 2D 动画赛璐璐上色的画面，线条流畅清晰，色块干净，阴影是边缘分明的两段式阴影，亮部与暗部之间不做过渡。大眼带一处清晰高光，轮廓线均匀，无渐变，无噪点颗粒。单一光源，整张画面光照统一。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
干净明快的赛璐璐配色：阴影是固有色加深一档，不是灰也不是黑，每帧只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「日系动漫」「二次元番剧」 | 「国漫 2D 动画」 | 中文面同样有语种风格路由，「番剧」「日系」会把眼型与头身比带偏 |
| 「柔和的阴影过渡」 | 「边缘分明的两段式阴影，不做过渡」 | 中文「柔和过渡」直接触发厚涂/半立体 |
| 「不要写实、不要 3D」 | 删否定句，正面写「色块干净、线条清晰、光照统一」 | 扩散模型对否定基本不生效，`不要 3D` 极易被读成「有 3D」 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（赛璐璐、两段式阴影、均匀轮廓线）。
2.5 面没有 negative 字段，正向句是唯一的钉子。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台自带美化倾向会磨平色块边界**——它会把两段式阴影渲成软过渡。
所以 2.2 那句「亮部与暗部之间不做过渡」在国内面**不许省略**。

## 三、色值表（风格级起点，项目级以 asset-registry 为准）

| 用途 | 色值 | 说明 |
|---|---|---|
| 亮部底 / 纸白 | #EDE8DB | 高光面与内衬，不纯白 |
| 主色（黛蓝系） | #3A4E66 | 道袍、制服类主体衣物 |
| 主色（玄青系） | #2F3A45 | 深色调主体衣物 |
| 皂黑 | #26282A | 最暗的固有色，不是纯黑 |
| 朱砂红（重音色） | #A63A2B | 全片唯一重音色：绳结、符绳、印记 |
| 黄铜 / 暗金 | #B08D42 | 金属道具，用色块 + 高光形状表达 |
| 墨玉绿 | #1F4A3D | 陈设与植被暗部 |
| 皮肤亮部 | #F2D9C4 | 美型肤色，平涂 |
| 皮肤暗部 | #D9A98C | 同色系加深一档，不是灰 |

**色彩预算纪律照旧**：每镜只声明一个唯一重音色，其余压成同色系。
不声明色彩预算，模型会自发补饱和度，这套风格立刻变脏。

**暗部纪律（本轨的命门）**：暗部 = 固有色加深一档。
**绝不允许**用灰色或黑色当阴影——一用灰黑，画面立刻从赛璐璐掉到厚涂插画。

**同步纪律**：本表与 L0 `style-registry.json` 的 `palette` 必须一致，改一处要同步另一处。
项目级具体角色的色值另存 `asset-registry.json`，不抄进本文件。

## 四、运镜池

| 类别 | 镜头 | 用法 |
|---|---|---|
| 主力 | 固定中景、缓慢推近、横向平移、微俯、跟拍、轻摇 | 与 2D 分层背景的常规做法一致，平移不产生视差问题 |
| 少量 | 摇臂升起、航拍拉远、入眼、变焦对焦、快速推拉（演出用） | 段落转折点，一部片两三次；本轨允许比水墨更强的运镜 |

需要环绕与转面时，**换 `npr-celshaded-3d`，不要在本轨硬写**。

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **阴影变渐变，滑向厚涂二次元** | 写了「柔和过渡」「渐变」「环境光遮蔽」 | 钉死 `two-tone shading split by a hard edge`；暗部写「固有色加深一档」 |
| **变 3D 渲染 / CG 质感** | 写了 PBR、皮肤毛孔、次表面散射、镜面反射 | 压句逐字复用；材质词一律改用「色块 + 高光形状」 |
| **变成日系而不是国漫** | 压句写了 `anime`；眼型写了日系大眼占比过大 | 写 `Chinese 2D animation`；美型大眼要配明确的中式服化道锚 |
| **变 Q 版 / 儿童化** | 头身比没写或写了 Q 版参考 | 钉死 6–6.5；负面词保留「Q 版二头身、儿童化」 |
| **色块变脏、发灰** | 加了噪点颗粒 / 胶片颗粒 / 脏灰混色 | 压句带 `flat colour areas` 与 `no grain`；每镜声明色彩预算 |
| **轮廓线丢失，变无描边平涂** | 风格压句没提线条；或写了 `no outline` | 压句带 `smooth confident linework` 与 `even outlines` |
| **角色跨镜换脸 / 换装** | 没走 `<Subject N>`；参考图不是同一套 | 每镜内联锁定；首帧必带身份锚图 |
| **转面崩形** | 直接要求 360 度转面或强透视 | 本轨不写环绕；需要转面换 `npr-celshaded-3d` |
| **道具材质写实化（木纹、金属反射全出来了）** | 道具写了真实材质词 | 道具一律「形状化色块 + 明确高光形状」，不写反射细节 |

## 八、参考图集与角色锁定

本风格**无专属参考图集**。角色锁定走 `<Subject N>` 通用写法（见第一节第④段，头身比 6–6.5）。

投喂纪律照旧：**任何镜头都带一张左区头部近景当身份锚**；4 View 板只当 `<Subject N>` 定义，绝不当首帧。

**本轨特有的出图纪律**（资产链踩过的坑，别跳）：

1. 多视图一律写**严格正交相机、无透视畸变**——不写这条，4 View 板会出现远近大小不一，转面直接废。

3. 出图顺序：**P1 锁定（脸稳色准）才出 P2，P2 锁定才出 P3**。跳序会导致师门/家族角色骨相互相污染。
4. 换装走图生图编辑：保持面部、发型、姿势、构图完全不变，只改服装描述。

## 九、去立体化与串轨防护

**本轨不要跑 `scripts/dedupe_style.py --style ink-wash-2d`**——那份词表是为手绘平面轨写的，
会删 `shadow` 与 `glow`，而**两段式阴影与形状化高光正是本轨的风格本体**。
用它等于把自己的画风删掉。本轨只按 §9.1 的表手工清。

### 9.1 污染词与替换对（赛璐璐方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 柔和阴影、渐变过渡、soft shadow | 边缘分明的两段式阴影 / two-tone shading with a hard edge | 一软就变厚涂，明暗逻辑整个反过来 |
| 厚涂、油画笔触、厚重的笔触 | 平涂色块 / flat colour areas | 厚涂是本轨的头号邻居崩点 |
| 皮肤毛孔、皮肤纹理、次表面散射 | 平涂肤色 + 一处高光 | 写实皮肤词是滑向 3D 的入口 |
| 镜面反射、金属反射、环境反射 | 形状化高光 | 反射细节会带出 3D 渲染感 |
| 体积光、光柱、丁达尔 | 删除，或写成「一条明确的亮边」 | 体积光要 3D 空间才成立，本轨写了即出 2.5D |
| 环境光遮蔽、全局光照、AO | 删除 | 写实渲染管线词，会把两段式阴影渲成软过渡 |
| 噪点、颗粒、胶片感 | 删除 | 本轨要干净，颗粒一加就脏 |
| 2D anime（英文）/ 日系动漫（中文） | Chinese 2D animation / 国漫 2D 动画 | 语种风格路由，写错整套眼型与头身比偏走 |
| Q 版、二头身、儿童化 | 删除 | 跨档，同包禁混 |

**保留不动的词**（这些在别的轨要删，在本轨是本体）：`shadow`、`highlight`、`outline`、`flat`、`glow`（写成形状化高光时）。

### 9.2 互斥风格

与本风格互斥的 id（与 L0 `style-registry.json` 的 `excludes` 一致，**双向登记**；数值有出入时以 L0 为准）：

| 互斥 id | 混了会怎样 |
|---|---|
| `photoreal-pbr`（写实 PBR） | 负面词方向完全相反：写实轨禁的就是「平涂 / 描边 / 色块」，本轨靠的正是这三样 |
| `ink-wash-2d`（水墨淡彩） | 水墨要细匀墨线与边缘晕染、要平面无体积；本轨要硬边阴影与明确轮廓线，写反全片质感废掉 |
| `gothic-puppet`（哥特定格木偶） | 定格轨要体积与纵深，本轨要平；且定格轨的「哑光不反光」会把赛璐璐的高光形状全部抹掉 |
| `npr-celshaded-3d`（三渲二） | 决定资产是 2D 还是 3D，进而决定能不能写环绕与转面。**选定后中途不得换** |
| `anime-2d`（日系动画 2D） | 同为 2D 赛璐璐但线条气质与配色体系不同（本轨朱砂红重音色 vs 日系影色带），同包混写会两套压句并存 → P0 |
| `webtoon-2d`（韩漫条漫） | 条漫是竖屏专项、干净线稿重色块；与本轨的横屏国漫配色和轻喜剧演出冲突，同包禁混 |
| `documentary-live-action`（纪实实拍） | 实拍无描边无平涂，方向完全相反 |

**串轨怎么认**：看阴影边界与材质词。本轨正文里出现「渐变 / 体积光 / 次表面散射 / 毛孔」，
或水墨正文里出现「粗黑轮廓 / 硬边阴影 / 高光瞳」，就是串了。
