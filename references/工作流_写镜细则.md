### Step 1：时长带宽、字数额度与台词红线

**时长**（两条线必须分清：官方硬上限 vs 放行线）：

| 单条时长 | 处理 |
|---|---|
| ≤15s | **推荐值**（质量实践：单段高动态直出最稳） |
| 15–20s | 放行条件：`[起-止秒]` 时间戳分段 + 一镜连贯运镜过渡（模型不支持组内硬切）。**满足即放行**——「需写明理由」的模糊门槛已废止（v5.19.0），理由只挂在「偏离密度匹配时长」上 |
| 20–25s | **三条件放行**（v5.19.0 起替代平铺红线）：段头 `【长段声明】Ns · 节拍 N · 收束：末1s定格` + 时间轴段数 ≥4 + 末拍收束结构（收束窗措辞 + 定格措辞 + 景别装下全员）。三条件齐 → 免 `W-OVER-20S`；缺任一 → 报（消息点名缺哪条） |
| 25–30s | 三条件放行 + **收束结构强制** + 建议配首帧参考（I2V 长段比 T2V 稳） |

> **本表口径三态（v5.22.0 补齐 · 与「投放面参数总表」同一纪律）**：
> `≤15s 推荐值` 与 `15–20s 放行条件` = **③ 社区实测**（经验值，不是官方承诺；来源：20s 阈值实测口径=《长段放行与段缝成本对账.md》§四，≤15s/15–20s 原始出处未存档、待复访补证）；
> `20–25s / 25–30s 三条件` = **① 官方 30s 硬上限** + **③ 收束体例**（【长段声明】三条件是本库实测归纳）。
> 写进提示词前先看这一行——③ 类不是承诺，是「跑通过的做法」。

⚠️ **投 MiniMax H3 面时这张表整体作废**：H3 单条硬上限 **15 秒**，4–15 秒之外根本跑不动，滑窗阈值按 **15 秒**算。数值以「投放面参数总表」为准，适配细节见 `references/MiniMaxH3适配.md`。
⚠️ **投 Seedance 2.0 面时这张表的上半段作废**：2.0 官方单条 **4–15s 或 auto**（ByteDance 发布资料与 Runway API 均为 15s 封顶），15s 以上时长在 2.0 surface 根本不存在——长内容用 `Shot 1:/2:/3:` 标签在一个调用内分镜（每镜一动作一运镜，约 4–6s/镜），不走滑窗。表中的「15–20s / 20–25s / 25–30s / >30s」四行只对 2.5 面成立。
⚠️ **2.0 面的段头结构同步切换**：火山引擎 2.0 提示词指南（82379/2222480）明示 2.0 按事件序响应 镜头1/镜头2/镜头3，**不响应时间戳**，对 0-3 秒这类精确范围的支持不稳定、强制时长可能产生异常输出；字节 2.5 指南（82379/2607689）明列两条线差异——2.0 响应镜头编号，整秒时间戳是新线（2.5）能力。故 2.0 面包的段头用镜头编号骨架，秒级时间轴禁用（秒只作内部预算，写进行为描述如「停一拍的工夫」，不写「0-3s」）；国内面【时间轴】骨架仅对 2.5 面成立。Ark 另推荐 prompt 首尾可选回声「时长：X秒」（中文「秒」）作强化，非控制。

**2.0 面单镜块模板（v6.9.1 · 16x9_15s_2x0 实战事故反哺）**：2.0 面适配规范见 `Seedance2.0适配.md`（v6.12.0 新增），历史上生成时套用了 2.5 模板导致三类事故（元块进正文 / 即兴注记 / 台词声音被清空）——本模板定死 2.0 面包的正文边界：

1. **【参考素材职责】2.0 面不进正文**。它只定义于 2.5 适配（2.5 官方要求 prompt 内指代素材）；2.0 挂图顺序改参数行——`# 投喂图序（按顺序挂 N 张）：图1=路径（职责）｜图2=…`，放「—— 以下不进正文 ——」之后。
2. **段头只写「时间线分镜（镜头编号事件序）：」**，禁止把规则理由写成括号注记进正文（如「（按事件先后执行，无时间戳）」——那是写给人看的规则依据，塞进正文就是 `W-CONTEXT-LEAK` 该抓的操作者语境）。
3. **台词按三写进正文**（时间线段内 + 镜行尾 + 声音设计对白行），官方台词符号 `{}`（①），对白文本建议置「」内；**声音设计行音效用 `<>`**——2.0 原生支持音视频联合生成（① 1587797），不存在「本面无同期声」。
4. **交付指针（配音对齐单/音效单）只进包首或附文区**，不进正文；引用的交付物必须真实存在（《后期音效单》从未定义过，指针指向它=指向虚空）。
| >30s（2.5 面） | **强制滑窗拆分**（官方硬上限，`E-OVER-30S`；30s→2 窗，45s→3 窗）。**该码的阈值随锁①型号走**：2.0 / H3 / H3 Max 面的硬上限是 15s，超 15s 同样报此码——一套判据四个型号，数字唯一事实源见 `references/model-limits.json` |

**为什么改（v5.19.0）**：旧规则「>20s 不拆，模型只稳出约 20 秒、剩余靠循环播放凑」治的病是真的，但平铺红线把三个问题混成一条——**时长长 ≠ 会循环**，循环的病根是节拍供给不足 + 没有停止语义；且「建议拆」从不对账拆分的代价（段缝跳切 + 多一次生成 + 末帧锚定工作流）。**完整规程（三条件判据 / 段缝成本对账表 / 20s 阈值实测口径 / 循环判定指纹 / 返修顺序）唯一权威 = `references/长段放行与段缝成本对账.md`，写长段前必读。**
**对账摘要**（60s 内容）：4×15s＝4 段 3 缝、零循环风险；3×20s＝3 段 2 缝、低循环风险（**默认推荐区间**）；2×30s＝2 段 1 缝、循环风险最高——**除非三条件全齐**。段数越少段缝越少一致性越好，**不要为「保险」把 30s 拆成两个 15s**（多一个段缝 = 多一次跳切风险）。
**口径标注**：官方口径只有「2.5 单条 ≤30s」；「20s 之后只稳出约 20 秒」是**本库社区实测**（非官方），测法与循环指纹见该文件 §四——样本攒够前，20s 不放也不动。
**返修顺序**（治「后半段重复」）：先查密度 → 再查收束 → **最后才拆段**。尾段减速收势、有新信息的长段是合格长段，别误判去拆。

滑窗规则：每个窗口独立自洽，角色重新用外观识别，**禁写「接上/继续/仍穿着」**，窗间靠视觉重叠衔接。

**段缝衔接方式（多段任务强制 · v5.16.0）**：总时长超单条硬上限（2.5=30s / H3=15s，必须拆分）时，动笔拆段前先锁**段缝方式四选一**，并在包首写 `【段缝声明】①/②/③/④`——机检 `E-SEAM-UNDECLARED`（audit_project.py V 门）未声明即 FAIL：

| # | 方式 | 做法 | 适用 |
|---|---|---|---|
| ① | **实际尾帧承接（需要跨段继承时推荐）** | 段末需要清晰出口时，可用定格收束，或按档差选择缓拉 / 快速后拉 / 固定机位全景；两种写法只选一种，不要求“边定格边拉镜”。取帧首选 API 原生 `return_last_frame: true`，失败再手动截图。**实际尾帧先验收**人物数量、位置、朝向、关键持物和固定锚物；合格后在下一段界面 / API 硬绑定 `first_frame`，参数区记录来源与绑定，首拍先保持再动作，并复核实际首帧。普通参考图不等于锁定，不承诺 100% 一致。施工注记与剪辑决定放正文外 | 下一段需要继承本段空间状态；尾帧不合格就重出或改出口机位，不把计划帧当实际帧 |
| ② | **换机位硬切** | 段缝两侧直接换机位/视角硬切，做成两个镜头的剪辑关系 | 动作戏、多机位快切段缝 |
| ③ | **空镜过渡** | 段缝处插 1~2s 带戏剧任务的空镜（情绪/音效桥/时空转场），单集 ≤3 处 | 情绪段、转场段 |
| ④ | **技巧型转场** | 相似动作/形状匹配/前景遮挡/甩镜/闪白/画中画/J-cut，单集 ≤3 处、同段不连用；**每个必须能说出叙事意图，禁「为转而转」**；术语只标在分镜层，投喂稿写「画面怎么接」 | 叙事/情绪的关键咬合点 |

⚠️ 2.0 面**不适用本机制**（长内容用 `Shot N` 标签单次调用内切分，无生成单元间段缝，见「投放面参数总表」滑窗阈值行）。

**集级时长预算（v5.18.0）**：D 门只管**段级硬上限**（4–15s / ≤30s）——「一集 120 秒写成 95 秒或 180 秒」没有任何门能响。多集项目或有目标时长的单集，**包首写一条声明**：

```
【集级预算】目标 120s ±15%
```

声明后 `audit_project.py` 的 **D3 门**按叶子镜块求和核对（± 可省，默认 15%，可配）。口径三条：
① **严重度是 WARN 不是 ERROR**——liqi 的时长是「下给模型的生成时长」，该拆的段拆了就必然超目标，集级偏差可能是有意取舍，阻断不合理；
② 写欠**补戏不注水**（加冲突不加寒暄），写超**先砍无戏节拍再压台词**（同 `叙事层` 的裁剪顺序），确认是刻意分段取舍的**更新声明**，不改门；
③ 不声明 = **本门不适用**，不是通过。

**整片结构速配（总时长 → 推荐结构 · v5.38.0 吸收 ACTION V6.0 时长算法）**：集级预算定了总秒数后按下表配结构——D3 门管「写没写超」，本表管「怎么写才不超」：

| 目标总时长 | 推荐结构 |
|---|---|
| 3 秒 | 动作 → 结果 |
| 5 秒 | 冲突 → 攻击 → 防守或反应 → 结果 |
| 10 秒 | 冲突 → 动作链 → 反击 → 小高潮 |
| 15 秒 | 立即冲突 → 第一轮交锋 → 连续动作 → 战术变化 → 升级 → 高潮 → CUT |
| 30 秒 | 冲突 → 第一轮 → 连续攻防 → 距离或战术变化 → 反转 → 第二阶段 → 终极能力 → 最终碰撞 → 结果 |
| 60 秒以上 | 按阶段拆成多个 15~20 秒动作段，每段必须有自己的小高潮 |

口径三态：**③ 社区实测**（外部经验值，本库未逐条回归；来源：W5《AI_ACTION_SCALE V6.0》时长结构算法，v5.38.0 吸收，裁决记录《外部Skill吸收裁决总表》W5 行 / C10 节）；**只对 2.5 面成立**——2.0 面单条 15s 封顶、走 `Shot N` 单次调用内分镜，H3 面单条 15s 硬上限，两面不套本表。表中「CUT」是剪辑语义，不是让模型自己切镜头。

**写超裁剪的排序依据——默奇六律（v5.54.0 · C19，权重配方源自 smixs/visual-skills · CC BY 4.0，落法本库自定）**：「先砍无戏节拍再压台词」升级为完整排序，按剪切价值从低往高砍：

| 砍序 | 维度 | 权重口径 | 砍它之前先想 |
|---|---|---|---|
| ⑥（最先砍） | 空间连续 | 4% | 换机位能不能替代交代 |
| ⑤ | 平面轴线 | 5% | 越轴是不是真的伤戏 |
| ④ | 眼动迹 | 7% | 观众要不要跨屏找主体 |
| ③ | 节奏 | 10% | 慢一拍是不是气口（气口不砍） |
| ② | 故事推进 | 23% | 砍了因果链断不断 |
| ①（最后砍） | 情绪 | 51% | 情绪是这段存在的理由 |

旧口语序 = ⑥⑤④→③→②→① 的速记版；权重是默奇经验值（③ 口径），作用是**排序不是配额**——不要求按 51:23 做算术分配。

**镜职务自查（三职务 · v5.54.0 · C19，同上来源）**：每镜动笔前问一句——本镜**变情绪 / 推进动作 / 加压力**三选一占了几条？零条 = 废镜候选，删或并。与既有两层的粒度不同：承重戏分级管**戏级**配额，节拍认领行管**对账**，这条管**单镜有没有存在的理由**，互不替代。WARN 级自查不进机检——职务是语义判断，机器判不了；逐镜自问的结论写进《改动复验报告》。

**字数额度**（分场景，硬上限）：
| 场景 | 上限 |
|---|---|
| 整合镜 | 4800 字符 |
| 单镜 · I2V（有参考图） | 800 字符 |
| 单镜 · T2V（无参考图） | 1000 字符 |

> 🔴 **上表是「单镜」额度，按 15 秒定，且是社区实测经验值，不是平台限制**（v5.41.1 补注）。
> **超过 15 秒的长段按时长线性放大**：`额度 × 时长/15`，如 30 秒 T2V = 2000 字符、30 秒 I2V = 1600 字符。
> 理由：25–30s 长段（2.5 面三条件放行档）信息量约为 15 秒段两倍，沿用单镜额度必报 `W-LENGTH-CAP` 且删无可删——
> 脚本注释里作者自己写过「零冗余的 T2V 单镜为 899 字符，按旧的统一 800 卡会误报且删无可删」。
> **15 秒及以下仍取原值**，不放松既有标准。上表与线性放大值只是**防爆硬上限，不是推荐写满**；日常生成以官方中文 ≤500 字质量建议为默认目标，超出先删重复和元信息。

计数含标点、空格、换行。超限**必须删到达标**（脚本报的是 `W-LENGTH-CAP`，默认跑法 exit 0，要把它卡成失败须加 `--strict`）；禁止把一个镜拆成两段规避上限，真要拆走滑窗规则。

**投官方 API 时另压一道**：官方口径是中文 ≤500 字（英文 ≤1000 词）——✅ **v5.45.0 已取到官方原文**：火山方舟《创建视频生成任务》（docs.volcengine.com/docs/82379/1520757，2026-10-20 更新，2026-10-28 复核）原文为「**提示词字数建议：中文提示词不超过 500 字，英文提示词不超过 1000 词。字数过多易导致信息分散，模型可能忽略细节、仅关注重点，进而造成视频缺失部分元素。**」——措辞是「**建议**」而非硬限制，理由是质量衰减而非 API 拒收，口径三态归 **①官方（建议级）**。代码侧 `W-OFFICIAL-500` / `W-OFFICIAL-1000W` 为**默认关闭的 opt-in 质量提醒**（v6.4.2 实测裁决改回：`--official` 显式开启，WARN 不是 API 硬限制；500 字口径不适用 30s 长段六段式）；`--no-official` 保留为兼容 no-op——**阈值唯一事实源 = `references/model-limits.json` 的 `prompt_length`**（v5.49.0 起 check_prompt 从它读取）。同「投放面参数总表」的「官方 API 附加门禁」行。字符额度与官方字数口径**量级接近但不相同**（后者含标点，前者只数汉字），交付给官方 API 前按 500 字复核一遍。超了就按此序删：重复风格形容词 → 通用质量词 → 参考图里已有的背景 → 次要运镜 → 次要动作 → 推测性情绪标签。**保留**：保真约束、动作时序、角色映射、台词。

**组级字数预算与删除优先序（v6.13.0 · C33-A2，来源 script-writing-studio-v2 单组预算制——机制参考零拷贝）**：镜块级额度之上还有**组级**——一次生成的整段投喂词建议 ≤1900 字、**2000 字硬上限**，输出前先估组内纯净投喂词总字数。超限按序删：① 低收益后缀与重复修饰 → ② 管理话术（`W-META-IN-BODY` 词表同款）→ ③ 重复字段与可并入项——**不压每镜必填字段**。仍超限：按**镜头边界**拆成连续单元（2.0 面 4-15s；2.5 面单条上限内），用上一单元的段末可见状态承接下一单元首拍——不在单个镜头内部硬拆。组级是镜块额度的上游闸，两级各自对账。

**功能标签反模板（v6.13.0 · C33-A3，同源）**：段名、转场注记、钩子描述里的功能词（钩子 / 反转 / 证据 / 误导 / 情绪反咬一类）必须**从本镜内容提炼**；同一功能词在全包不得机械复用——「每段都写钩子」等于没有钩子。人工自查不进机检（加门三问：模板感是跨段分布特征，单包门只会误伤正常复现）。

**节奏档位（v6.14.0 · C33-B，来源 script-writing-studio-v2 节奏档位——机制参考零拷贝；liqi 化=显式声明制）**：包首 opt-in 一行 `【节奏档位】四档之一`，全包默认档（单段覆盖暂不做，攒到首个真实混档需求再议）。四档与节拍预算：

| 档位 | 节拍预算（15s 段） | 景别纪律 | 判档信号（自动判参考，用户可覆盖） |
|---|---|---|---|
| 电影感中速 | 3-4 拍 | 常规配额 | 文戏、对话推进、情绪铺陈 |
| 短视频中高密度 | 4-5 拍 | 常规配额 | 短剧默认档、信息推进段 |
| 高密度动作或强钩子 | 5-6 拍 | 允许极限景别跳跃（仍须一镜一景别） | 打斗、追逐、开场钩子、爆点 |
| 慢节奏但高信息 | 2-3 拍 | 常规配额 | 旁白信息段、蒙太奇、解说 |

**三条纪律**：① 档位**不改任何机检阈值**——21e 三档景别判据有生成物理依据，高密度档的正解是**多拆镜号**（每镜一景别），不是把三档并进一镜；② 出枚举报 `W-PACE-TIER`（机检已接）；③ 复盘与噪声分类按档位归因（N20）。口径标注：四档划分与节拍预算为**③ 本库参考骨架**（来源 skill 未经实测验证），首项目拉片后按实测量修订（N16 同款纪律）。

**台词密度红线**（写台词进时间轴前必查）：

| 指标 | 算法 | 红线 |
|---|---|---|
| 单段密度 | 该段台词发声字数 ÷ 段长 | ≤4.0 字/秒（慢板·旁白）／≤5.0（对白）——**4.0 档无机械兜底**（脚本分不出旁白与对白，只校 >5.0 / >6.5 两档），人工判。**赛道③ 两档全豁免**：改用解说语速档 3.8~5.0（金句 3~3.6），仅保留 6.5 物理硬闸（权威见 `赛道分流.md` 三维表，v5.43.0 就地补注） |
| 单句语速 | 发声字数 ÷（下一落点 − 本落点） | 自然 3.5–5.0；>6.5 物理不可实现 |
| 单句长度 | 可发音字符数 | >24 字强制拆镜，每镜 ≤18 字 |
| 语速档 | — | 标准 3.5–5 字/秒；慢速重音 <3.5（金句/临终/威慑）；快速爆发 >5 且连续 ≤3 秒 |

字数口径：只数可发音字符（汉字、数字、外文字母），**标点不计入语速公式**，另按停顿预算处理（顿号逗号 0.1–0.3s，句号感叹问号 0.3–0.6s）。
**金句后必须留 0.3–0.8s 发酵空间**（无对白反应镜头），这段气口正好承载余韵微表情。

**文戏节奏阶梯四型（v5.54.0 · C19，配方源自 smixs/visual-skills · CC BY 4.0；数字为社区经验值，③ 口径）**：打戏有「镜内速度四拍」（`专项_打斗编排.md`），一般文戏此前没有段内时长模板、全靠手感匀速。时间轴段时长序列按类型选起手阶梯：

| 类型 | 段内时长序列（秒） | 效果 |
|---|---|---|
| 慢燃 | 4-4-3-2-1-停-2 | 观众先于人物知道，压迫感层层收拢 |
| 商业弧 | 3-2-1.5-1-0.5-2 | 信息密度递增，末拍反弹收住 |
| 焦虑递进 | 2-1-1-0.5-0.5-0.3-停-1 | 触觉式不安，越切越快直到气口 |
| 冲击场 | 停-0.2闪-2静 | 静止—炸点—余震三段式 |

通则一条：**最大的那次剪切之前，必须留一次停顿**（不限本型；金句气口是它在台词维度的对应物）。阶梯是起手配重不是硬门——2.0 / H3 面 15s 封顶的段按比例截取前几级；与「首拍不短于 3s、末拍 3–8s」的拍长纪律冲突时，**拍长纪律优先**（慢燃末级 2s 即此让位）。

⚠️ **排期用实测档，不用上面的理论档**：理论档是"念不念得完"的红线区间（3.5–5），
实测中文叙事短片**均值只有 2.59 字/秒、最快 3.79**（96 条样本）。按理论档排期会全线偏紧。
排期基准：说书人/旁白 3.6–3.8｜对白 3.4–3.6｜情绪重拍 2.6–3.0｜**校验上限 3.2**。
详见 `references/叙事层_剧本门控与台词.md` 第四节「实测校准」。

**拍长纪律**：首拍不短于 3s；末拍（转场拍）3–8s。

**单拍动作密度**：动作分句数 ÷ 拍秒数 >0.5＝一镜多动作，>0.8＝物理不可执行。注意区分**真动作数**与**并列修饰**：「幕布亮起，织纹、竹竿压边、角花依次浮现」是 1 个动作 + 材质描述，不是 4 个动作。

### Step 2：全片统一风格锚（九段，总纲）

任何多镜 / 整合镜任务**必须先**产出风格锚。九段固定，与 `references/风格锚_<style_id>.md` 第一节「九段锚」**逐段同序同构**——锚文件就是本步的落值格式，写完即存档：

1. **画风与材质质感**：媒介声明放**第一句**（是画、是模型、是渲染、是实拍），再写画风一句话（含渲染倾向与精度基准），已上传参考图集则用「」锁定图集名。
   *选项库*：六大电影级美学预设——诗意 / 纪实 / 港派 / 赛博 / 水墨 / 国漫。
   **材质与质感清单**（同段附加）：按材质类别逐条写，每条锚定一张资产图。标准四类——布料（纤维粗细/织纹/磨损/补丁/垂坠）、皮肤（血色/干湿/皮下透色/纹理强度——**不写光泽**）、地面与环境面（潮湿/反光/颗粒/风化）、关键道具（材质本体/反光率/新旧）。写法＝**名词 + 可观测特征**。
   **质感交叉引用技法**：图集里没有的新材质，禁止凭空造形容词，改用已有资产夹逼定位——`质感介于「修皮骨簪」的惨白与「瓷盒」的温润之间`。格式固定为 **"X 的（属性）+ 与/但 + Y 的（属性）"**。
2. **配色与色域**：色名 + HEX 倾向 + **唯一重音色是谁** + 禁用哪些。配色补充句**逐字复用**锚文件**对应投放面**的配色句（H3 面 §2.1 ／ Seedance 2.5 面 §2.2 ／ 国内面 §2.3；`S8-PALETTE-MISSING` 查它）——压句与配色句必须同时出现，只写一句会色域漂移。
3. **运动签名**（分两层）：生成期写节奏与质感词汇（**进正文**）；后期写剪辑操作（抽帧/速度曲线，**不进正文**，写进参数行）。**禁什么也要写**——定格要禁丝滑，手绘要禁视差。
4. **角色锁定**：每角色 2–3 句可复现描述，**头身比必写**（漏了跨镜身形立刻散）。
   **I2V 服装名词禁令**：有参考图时只写颜色 + 轮廓 + 可辨识特征，**禁止重复服装名词**（会让模型用该词的通用概念替换参考图里的实际服装，是 I2V 漂移头号原因）。服装只在明确换装时才写。无参考图（T2V）时必须写全。
5. **场景锁定**：每场景 2–3 句（空间结构、主色/辅色/跳色、光线来源与质感、标志性陈设），并声明**同场景跨镜地标与光位一致**。
6. **关键道具锁定**：贯穿全片、承担叙事功能的物件一句锁定，声明唯一性或出现镜次，**入画方式必须写**（手持 / 悬挂 / 置地）——漏了道具会飘在半空。
7. **光色基调**：主光是什么、入射角、影子形态、禁哪种光。只写「昏暗」不写光从哪来，等于没写。
8. **声音签名**：四层——环境 / 动作 / 呼吸 / 配乐，逐层给具体内容。只写配乐不写环境层，等于没写。
9. **排除项**：按轨道取反方向 + 通用项，并声明投放面差异（H3 面无 negative 字段、整份丢弃；其余面可用哪些）。**归属**：这是文档层约定，逐镜正文一律不写。落地按平台分流——有 `negative_prompt` 字段（Kling 等）整份填入；无该字段（Seedance / 即梦 / 豆包）浓缩成 **Must not 一行**附于正文末。

**保真预算总纲（Step 2 附加项，对应锚文件 §五「材质与可见性预算」）**：`全片保真预算：主 = …；次 = …；省 = …`。身份保真 / 动作幅度 / 场景密度三者争同一份预算，**什么都想要 = 处处平庸**。

**容器参数（画幅比 / 分辨率 / 帧率 / 时长）不属于风格锚**：Step 2 不写它们，逐镜阶段统一进参数行（Step 3 第 11 项）。

**内容安全门**：真实人物肖像、名人、品牌商标、受版权角色一律改原创形象。敏感内容的处理原则是**给正向替代物，不是列禁令**——写清它是什么（旧绢质感、平铺塌瘪、无液体），而不是反复说它不是什么。

**I2V 参考图五分工**：每张图只分配一个主职责——身份 / 首帧 / 环境 / 风格 / 材质，并说明「该图仅用于 X，不继承 Y」。

**🔴 CHECKPOINT**：风格锚完成后暂停向用户确认（三锁 / 九段锚 / 保真预算）再进逐镜。用户说「继续」或「不用确认」时跳过。

### Step 2.5：资产层（A1 以上必做）

**🔴 出图前先过审美层（v5.5.0）**：顺序是**先设计定稿，再锁死出图**，倒过来会返工——剪影没定就出图，等于把一个平庸造型稳稳锁死。

**画风归属（v5.36.0 · 防误用）**：**资产图不带画风**（画风由当次出图的风格指令统一附加，写进每条只会打架、换风格还要逐条改）；**逐镜投喂词必带画风压句**（S7 门）。两者对象不同，别互相套——细则见 `场景资产与时间线光照.md` §一之二。建角色卡 / 生物卡 / 群像包时，一次过四项，全部落点为 `references/资产审美_设计原理.md`：

1. **三读法则**——剪影（32px）→ 色块（64px 眯眼）→ 细节，顺序不可倒；不过就改轮廓，别改颜色；
2. **形状语言与剪影**——主形状 + 破形状（圆/方/三角），2–3 处地标（地标要长在肩以上，否则近景投喂带不到），一处破对称元素；
3. **过设计审计**——色 ≤3 / 服装主元素 ≤3 / 配饰焦点 ≤3，并用递减法删一轮细节；
4. **配色**——HEX 三色必须标出底色 / 结构色 / 重音色（结构色由底色派生，重音色全片唯一，与注册表 `palette.usage` 同一件事），并查 AI 色彩稳定性：**白 / 雾 / 浅灰最不稳**，主要出没场景若属五类高危（沙漠 / 雪雾 / 夜店 / 森林 / 赛博雨夜）须配对策——但**用色不得越出本项目风格锚的色域**（多款风格锚禁用霓虹 / 荧光）。

群像包另过**视觉领地象限**（任意两个主要角色不在同一象限），再叠亲缘推导（先拉开该不像的，再拉近该像的）。**多集 / 系列项目另过「全片视觉统筹」**——视觉主题宣言 + 色彩哲学（主色 ≤3 + 情绪映射 + 禁忌色）+ 色彩叙事弧（全片往哪走）+ 参考图矩阵（含**反面参考**；注意矩阵是**项目级参考库**，单镜投喂仍受 Seedance 2.5 的图片 ≤8、推荐素材总量 4–5 份约束）。没有这一层，各集的色调光线各写各的，单看都对、连起来不像一部片。出图前清单见该文件第十五节。

**清单先过出现记录与身份判定**（v5.1.0，`资产层_锁定与一致性.md` 第五节，判定细节**以该文件 5.1—5.3.1 为准，本段只是摘要**）：先记出现（六问 + 四态）再判身份（复用 / 新变体 / 新资产 / 未决四选一，未决禁止带默认 ID 出图）；关键道具过准入门三问 + 数量上限（单镜 0-1 / 单集 1-3 / 系列 ≤8）；场景按去重键建卡（同地点同时段一张方位卡，光照变体不建新卡——时段变体走 `scenes.<slug>.variants.<时段>` 子键，不拆条目、不建新卡、不占新编号，方位卡跨变体共用）。单包出场角色超 5 个提示拆分或明确风险。

**判定结果必须落盘成 `identity_verdict`**，四桶（characters / props / creatures / scenes）都要填，`damage_states` 不填（它是状态容器不是身份）。
判为 `unresolved` 的条目额外写 `identity_unresolved` 四键（`candidates` / `missing_evidence` / `impact` / `unblock_when`）且**不得写 `outputs`**——
写了解除条件，后面拿到证据的人才知道要补什么。这三条由 `audit_project.py` F4/F5/F6 断言机械检查（**只查落盘与合法性，不查判得对不对**）。

### Step 3：逐镜提示词（严格按序）

**写镜前三查 + 第四查（v5.17.0 增补）**：一查 `镜头骨架库.md`——这一镜的叙事功能有没有现成骨架；二查 `任务模板路由.md`——是不是动作戏/连续长镜/口播对话；三查 `视听层_镜头文法与光色.md`——**这个镜头承担三任务里的哪一个**（改变情绪 / 推进动作 / 施加压力），**三项皆无的镜头一律剔除**；**四查·上下文隔离**——逐镜单独投喂，模型看不到上一镜，本镜用不到的信息一律清零：未出场角色 / 未使用的 @标签 / 场景编号 / 剧本标题 / 「同上·如前·继续自·上一场」类继承措辞（机检 `W-CONTEXT-LEAK`）——吸收 CINEDANCE D1 移除清单口径。视角度数按内容类型查 `references/光学与空间语言块.md` 表七。

**加一问·景别装得下吗（v5.35.0 增补）**：三查之后多问一句——**这一镜的景别，装得下我要它演的东西吗？**
判据在 `视听层_镜头文法与光色.md` §七之二：**表演是空间的函数，不是文字的函数**（实测：同一段表情描述一字不改，
景别从头占 1/7 改到 1/3，表情自己演出来了）。同时先确认**影像基底**（真人 / 2D / 水墨 / 3D）——
基底不同，脸部特写的角度规则不同（3D 禁「特写 × 平视正面」，真人守 1/3 配额）。**基底未锁定 = 停下询问，不得默认真人。**
**打斗镜加第四查**：`references/专项_打斗编排.md`——**先定档**（R0~R3，段头写 `【打戏声明】：R2 · 戏型`），再过五段结构（流派生物力学 / 连招链 / 接触点与轴线 / 武器锁 / 血腥尺度）+ IAU 负载上限 + 镜内速度四拍（起→爆→顿→收）+ 减速器配额。交付时 **W-COMBAT-* 八码 + E-COMBAT-TIER-UNDECLARED**机械兜底（前缀即级别，E- 阻断、W- 建议），跨镜两项（全身景别下限 / 贴脸档连排）在 `audit_project.py` 的 S23/S24（默认打戏包才跑，`--combat off` 可关）。**豁免表见该文件第九节**——群战 / 枪战 / 追车 / 术法对轰 / 大场面各有放行项，别拿一对一贴身互殴的量化线去套。

**写镜时加一查·局部入画归属**（v5.40.0 · `references/专项_局部入画归属.md`）：**身体部件进画面一律带归属**——
「一只靴抬起」→「**马六那只**深褐短打的靴抬起」；「落在一个跪着的人身上」→「落在**跪着的陈砚**身上」；
「另一只手横出来」→「**门房的手**横出来」。🔴 理由：**模型不会追问，只会填空**——缺的归属它按先验补一个最像的，
补得视觉上完全成立，所以不报错、只悄悄错，跨镜接戏时才暴露（同一只手在两段里换肤色与袖口）。
**改归属时六个位置全扫**：画面（事件序）/ 场景 / 站位 / 硬性约束 / Must not / 段名与接戏表——
**只改画面行必漏**（实战里第一轮改 43 处以为收工，后五个位置又补出 7 处）。
机检两码 `W-BODY-PART-NO-OWNER` / `W-ANON-FIGURE-NO-OWNER` 只兜得住前三个，后三个走该文件 §六自检清单第 4 问。
确为无人镜，段头写「【局部入画豁免】：<理由>」。

**写镜时加一查·空间方位参照系**（v5.41.0 · `references/专项_空间方位参照系.md`）：**左右前后一律挂「画面」**——
「停在他右前方一步」→「停在**画面右三分之一**、距他一步」；「机位在他的左后方」→「机位在陈砚身后、略偏**画面右**侧」；
「案面左后角」→「案面靠**画面左**的后角」。🔴 理由：**参照系从来没被显式声明**，写作者默认读者和他站在同一边，
而镜头恰恰把两边分开了——人物背对镜头时「他的左」＝画面右，跪姿/侧身朝向未写时**根本无法反解**。
典型故障：上一段马六绕到画面左，下一段起手却写「马六在画面右三分之一」，同一个人横跨半个画面。

⚠️ **压数字数时最先被删掉的就是「他」「画面」这类参照词**——本项目「停在他右前方一步」为省一字删成
「停在右前方一步」，归属与参照系同时丢失。机检 `W-SPATIAL-NO-FRAME-REF`（WARN，§22F；
判据看**整个小句**，因为「继续向左走出画面左缘」里「画面」在方位词之后）。
主观 POV 必须用角色自身左右时，段头写「【空间方位豁免】：<理由>」。

**交付前加第五查·全包配额**（v5.7.0）：逐镜写完后，按 `references/分镜配额与机检规范.md` 查**整包的镜头构成**——11 项区间配额（人物特写占比 25%~40% / 常规机位 ≤30% / 侧 45° 30%~40% / 侧面 ≤15% / 大仰角与大俯角各 ≤3 / 荷兰角 ≤1 / 焦段 ≥4 种 / 运镜 ≥8 种 / 连续禁第 3 镜同运镜 / 重技法全片上限 / 每组必有 1 大景别 + 1 特写 + 1 中景）。前四查管**单镜该不该这么写**（第四查管的是「别把上一镜的信息当已知传下去」），第五查管**连起来有没有失控**——全片 12 镜 10 个中景平视，每镜单独看都合规，连起来是同一个画面拍了十遍。

**markdown 零标记（强制）**：逐镜正文是可直接复制进生成工具的纯文本，禁止任何 markdown 标记——不用 `#`、不用 `**`/`*`、不用 `-`/`*` 列表符。文档层可保留结构。

**可复制正文里只写模型要执行的话**（v5.4.2，资产包实战踩到）：模板骨架与逐镜正文里
**不得出现给执行者看的元指令**——「（中英都要写，两句都要有）」「（零引线：服饰结构写进正文）」
「（并排展示）」「作人工核对依据」「`face_hd` 为身份锚」这类都是给人看的纪律或提醒，
它们不参与投喂，只会占字数，还有被模型当成画面内容读进去的风险。
判据一句话：**这句话是让模型画出来的，还是让你照着填的？** 后者一律放文档层
（字段注释表 / 骨架外的纪律段）。对模型确有约束的（如「物件数量不得增减」）
要写成正文里的正常句，不要藏在括号里。

   `认领：场次1 P01-P02, P05`）。清单每行一拍：`P01｜场次1｜画面事件｜动作`（台词拍写
   `P02｜场次1｜甲（对白）：台词原文｜台词`）。交付前跑 `check_prompt.mjs --beats <清单>` 对账：
   每拍恰好一镜认领、台词拍逐字进镜、认领拍预估时长（台词按 3.2 字/秒 + 0.4s 发酵、动作 2.5s/拍）不超镜长 15%
   ——违反报 `E-BEAT-*` / `W-BEAT-*`。**台词一致性由此从人工守门变成脚本断言；剧本改了重跑一次，失效镜头当场点名。**
   **钩子具象标记（v5.18.0，声明式 opt-in）**：兑现开场钩子的那一拍，行尾加第 5 段 `｜HOOK`：
   `P01｜场次1｜门在身后关上｜动作｜HOOK`。包首写 `【钩子门】查（窗口 3）` 才启用——启用后
   清单无 HOOK 标记报 `E-HOOK-UNDECLARED`、HOOK 落点超窗报 `E-HOOK-OUT-OF-WINDOW`（窗口可调）。
   🔴 **不无条件启用**：「黄金 3 秒」是信息流平台适配，**文艺短片可以慢开场**（叙事层既有裁决）——
   国内剧 / 海外剧默认应声明并查；解说叙事类与「其他」（文艺片 / 毕设 / 公益 / 纪录）不声明即不查，
   **不出声不代表通过，是「本门不适用」**。
2. **场景与人物**：一行，`场景：xxx（环境基调色）｜人物：xxx`。**人物须列全本镜所有出场对象**（含群像、动物、无生命主体）。
   **画内/画外清单**：入画者逐个具名（含只听不说的听话者）；画外者明写「×不入画」。道具支撑视线动作时必须锚定入画方式。
   **开场不在的人**（v5.36.0）：分清谁开场就在、谁后来才进来，**剧本没写某人进场，当他开场就在**；本场第一镜的站位行里不要写开场不在的人——否则模型会让他在第一镜就出现。细则见 `空间层_调度与轴线.md` §十七·4。
3. **站位与轴线（两层，不可合并）**：
   ```
   轴线：查验台—门框连线，旅客甲在画面左三分之一（西侧），查验员乙在右三分之一（东侧）
   站位：@旅客甲（查验台沿 · 画面左 · 侧身45°朝右 · 右手提箱 · 左手递票）；@查验员乙（门框内侧 · 画面右 · 正面朝左 · 单手扶框）
   位移：@旅客甲 案前→查验台西端半步（起身上前，终态面向乙）；@查验员乙 全员原位，无位移
   ```
   - **轴线行**（v5.27.0 起只写地理事实）：**正文只写「锚物连线 + 谁在左谁在右」**，按方位卡的屏幕方向映射写（`西侧` / `画面左三分之一`）。
     `建立 / 保持 / 跨越` 三态是**跨镜状态**，归**连续性台账**的场景账，**不进逐镜正文**——逐镜单独投喂，模型看不到上一镜，
     「保持」对它是个没有指向的词；「沿用镜 N」更是跨镜引用，会触发 `W-CONTEXT-LEAK`。
     - 正面：`轴线：查验台—门框连线，旅客甲在画面左三分之一（西侧），查验员乙在右三分之一（东侧）`
     - 反面：`轴线：保持，沿用镜 8 的柱—隔断墙连线…`（状态词 + 镜号引用，两样都是台账层的东西）
     - 换边（台账记「跨越」）时，**过渡方式写进转场注记表**，本镜正文仍只写新的左右归属。
     - 缺地理参照 → `W-AXIS-NO-GEO`；正文出现状态词 → `W-AXIS-STATE-IN-BODY`（移进台账）。
   - **站位行**（四要素，写成生层）：每人一段括号——**固定锚物（放第一位）+ 位置（画面左/右/中）+ 朝向 + 姿态**。
     **站位挂死物不挂活人**：锚物优先三级 = 固定锚物（柱/台/门/墙，默认）> 物理接触（手搭/背贴/脚踩）> 人物间距（距 X 三步，**只作补充，不许单独用**）。人的位置会变，物的位置不会 → 单独用间距触发 `W-STAGING-RELATIVE`。
   - **位移行**：本镜要发生的移动逐人写 `起点→终点`，每步有动作原因，**禁瞬移**；静态镜写「全员原位，无位移」。**起终点都要挂锚物**——终点挂在活人身上（`→僵侧后`）等于终点失守，写成 `→隔断墙西端两步（终态面向 X）`。
   - **持物分左右手**（v4.7.6）：站位行里一旦提到手上的东西，必须写死哪只手——`右手桃木剑 · 左手手电`；空手就明写「徒手 / 垂手 / 背手」。模型不看上一镜，「桃木剑在手」在它眼里等于每镜重掷一次骰子，第 2 镜换手就是穿帮 → `W-PROP-HAND`。被动接触（`被攥脚踝`）是打斗接触点，不算持物，不报。
   - **along 坐标**（v5.37.0 · 同侧多人时必写）：站位行里写 `along 0.25` 这样的归一化坐标（0 = 该锚物一侧的起点，1 = 终点），**同侧任意两人差值 ≥ 0.12** → `W-STAGING-ALONG-TOO-CLOSE`。单侧一人或两侧各一人不必写。理由：两人贴在同一个点上，模型会把他们**合成一个人**——「分身」的另一种成因。细则与示例见 `空间层_调度与轴线.md` §十七·3。
   - **空间分级**（决定写到哪一层）：S0 单人 → 只写位置+朝向+动作一行，免轴线免位移；S1 双人静态 → 站位行 + 轴线行；S2 多人静态 → 站位行全员具名 + 轴线行；S3 多人移动 → 加逐人位移因果链；S4 复杂战斗/多空间切换 → 加 CAM1~4 编号调度。
   - **不写 = 把左右交给模型随机决定，第一次反打就会崩。**
   - **原子镜头契约**（v5.35.0 新增 · 上游来源 zyz254009-crypto/script-to-shootable-storyboard）：一个镜号默认只装**一个连续时空 + 一个主导景别 + 一个主要视觉行动单元 + 一个主要摄影运动**，且动作/对白/反应/运镜必须在镜头时长内完成，上一镜的结束状态能承接下一镜的开始状态。**五条拆镜触发器**（任一命中就拆）：① 主导景别明显跨级；② 出现「切到 / 再切至 / 转到另一边」等隐含剪辑；③ 机位、方向、注意力中心、时空或独立信息结果改变；④ 反应或证据需要独立读取；⑤ 动作链、主体数、口型、手部、物理交互或运镜负载过高。机检 `W-SHOT-MULTI-SCALE` 兜底：一个镜号里出现 ≥3 个景别档位即报（阈值取 3 不取 2——两档如两极对冲 ECU↔EWS 仍可由一次运镜完成，三档以上必然要求镜头内部换构图）。**长镜头例外**：只有用户明确要连续长镜头且方案可执行时才设 `【长段声明】`，并写起止构图、摄影机路径、人物路径、失败点与拆镜备用方案（与既有 20–25s 三条件放行是同一机制的两半）。
4. **标题参数行**：`# title: 镜X｜标题`——**写在参数行区，不进正文**（与 `# duration` / `# ratio` 同栏）。
   这是给生成工具填「标题/项目名」用的**元信息**，不是画面描述；逐镜块里唯一该出现的位置是参数区。
   ⚠️ v5.28.0 前的写法是正文第 4 行 `生成视频：镜X｜标题`——它与第 1 小节「镜号与标题」逐字重复，
   且**带可读文字进正文**（撞「禁可读文字」的张力）、白占 12~16 字/镜额度。已并进参数行。
5. **出场人物**：`出场人物：甲——<身份描述>；乙——<身份描述>`。**把本镜在场角色逐一具名并给一句可复现的身份描述**，供模型识别「谁是谁」——**每个点名角色都要有自己的一段**，缺一个就 `E-IDENTITY-NOT-INLINE`。
   描述取**风格锚 ④ 角色锁定**的短版（能认出来就够，**不要抄全量**）：外形地标 + 服装主色与形制 + 一件随身物。例：`祝翁——枯瘦老者，靛灰长袍褐腰带，白发髻白山羊胡，红绳坠半枚铜钱`。
   🔴 **为什么单起一行，不塞进整体风格**：逐镜是**单独投喂**的，模型要在几百字里先认出「这个人是谁」再谈怎么拍；身份与画风混在一句里，两个任务互相稀释。**一行一个职责**：这行管身份，下一行管画风。
   ⚠️ 点名与不点名都要交代：**只要在本镜画面里出现就必须列**——包括不说话、只当背景的人（否则模型自己编一个）。
6. **整体风格**：**只管画风**（v5.15.3 起**人物外观已独立成上一行的「出场人物」**，本行不再混写）。

   ```
   整体风格：一幅当代中国城市的写实实拍电影画面，取的是老胶片志怪剧照那一路。
   ```

   逐字抄风格锚压句的**首句**（第一个句号前那段，一般 30–40 字）。为什么是首句不是全文：完整压句 150+ 字，逐镜全量内联会直接撑爆单镜 1000 字额度；而写压句时最关键的可辨识特征本来就放在第一句。卷首那一段完整压句是**给人读与对账的源文件**，不参与投喂。

   🔴 **为什么不能只写「承接风格锚 <id>」**：逐镜是**单独投喂**的（Step 6：可复制范围是「镜号标题 → 参数行」，卷首不在内），模型根本看不到卷首的风格锚段落；而 `<id>` 是给人看的注册表索引，模型不认识这个字符串。两件事叠加，结果是**模型一个字的画风都没收到**，只能自己发挥——风格漂移的根因。缺画风报 `S7-PRESS-NOT-IN-SHOT`（P0）。

   **② 人物外观** → **已移到第 5 条「出场人物」行**（v5.15.3）。该行的内联详略按图的有无决定：

   | 条件 | 出场人物行的写法 |
   |---|---|
   | 有干净参考主体图，且已声明 `@图片N作为首帧。` | 只写主体简称 + 本镜变化点 |
   | 有参考图但未声明为首帧 | 写颜色 + 轮廓 + 可辨识特征，禁写服装名词 |
   | 无参考图（T2V） | 全量内联外观，逐一识别不可漏 |
   | 整合镜拆出的子片段 | 【主体与关系】整段复制，出场对象逐一识别 |

   声明首帧后必须**另起一句补该帧的构图、主体位置与镜头方向**，只写「以参考图 X 为首帧参考」视为未锁定。若该图来自上一段，必须是**验收通过的实际尾帧**，并在界面 / API 将上传角色设为 `first_frame`；参数区留痕 `# 首帧来源：段N实际尾帧（验收通过）`、`# 首帧绑定：first_frame`。下一段首拍先保持首帧状态再进入新动作，普通参考图不等于硬绑定。
7. **本镜保真预算**：`本镜保真预算：主 = 材质与苍白皮肤；次 = 体积雾氛围；省 = 随从群像（仅剪影，不交代五官与服饰）`。一次只押一个主花费。
8. **本镜光色基调 + 色彩预算**：`本镜光色基调：冷青灰（死寂）；色彩预算：唯一重音色 = 随从所持火把（橙红团块），归属第五段`。**不声明色彩预算，模型会自发补饱和度，全片色调立刻散掉。**
9. **时间线分镜**：按投放面骨架逐段写。段头的**景别、透视、景深与空间位置一律查 `光学与空间语言块.md` 取句，不许现编形容词**。
   段内写清楚：画面主体与动作（可执行动词）；**只写本拍发生变化的站位 / 朝向及可见结果，初始站位不整组复抄**；镜头观察关系（过肩/低角度/隔前景遮挡）；人物表情姿态（**走 FACS，见下**）；景深**用视觉结果写不写 f 值**；**对白必须写入本段**；后期合成元素明确标注。
   **每段只锁一个主动作 + 一个主运镜**，同一段内不得混用不同原语群的运镜（推/拉＝位移；摇/俯仰＝旋转；变焦/拉焦＝镜头；环绕＝弧线；手持＝晃动感）。
   **镜行尾必须带行内 `声音：` 与 `台词：`**（无台词写「台词：无。」）——这让声音锚到具体拍上；完整的声音设计另见第 9 条。
   **可见终态（end state · v5.51.0 吸收 AtlasCloudAI/C14）**：一段里若有**多个事件阶段**（如「走近→立定→开口」），每个阶段结束都要写一句**看得见、可截图验证**的终态——谁在哪、手里有什么、朝向哪；**禁写内心感受**（「他愣住了」不是终态，「他停在原地，抬起的左手停在半空」才是）。位移行只管"位置怎么变"，end state 管"阶段结束时画面长什么样"——两者互补不重复；下一段的首拍从最近一个 end state 起画，接戏才有底本。
10. **声音设计（四层混音 + 行内三写）**：
   ```
   声音设计（四层混音）：
   环境层：xxx（空间底噪，极弱/持续）
   动作层：xxx（本镜物件与身体发出的具体声音，逐条）
   呼吸层：xxx（鼻息、喘息、气声，标出节奏）
   逼近层：xxx（由远及近的威胁性声音，标出渐强曲线）
   对白：0:0X 角色（语气/语速）：「原文」
   ```
   缺层写「无」，**不可省略层名**。非台词人声（哭/呻吟/惊叫）不用「」，归呼吸层或动作层。
   **混音电平**：对白 0 dB > 动作物理音效 −6 dB > 环境声景与 BGM −14 ~ −18 dB。动作音效不得遮盖人声，BGM 在对白爆发时自动避让。⚠️ **生成的音频为单声道**（官方明示 · v5.49.0 注记）——立体声声像与左右动态靠后期混音实现，四层混音的电平分层是给后期预留的结构，不是生成侧的声道布局。
   **台词写法按投放面取**：Seedance 面三写（时间线段内 + 镜行尾 + 本段「对白」行，三处逐字一致）；H3 面按总表降为一写。**对白文本一律置于「」内**（官方建议对话置于双引号内 · 建议级注记 v5.49.0——与 `{}` 官方字符体系兼容，不设门）。
   ⚠️ **MiniMax H3 面降为一写**——只在对应 Shot 的 `<d>` 里出现一次。重复写会被当成两次发声，口型与时长都乱。见 `references/MiniMaxH3适配.md` 第五节。
11. **刚性约束（正向锁定 + 可见性限定式）+ Must not 行**（⚠️ MiniMax H3 **没有 negative 字段**，Must not **不得进正文**，降级为参数行注释。见 `references/MiniMaxH3适配.md` 第六节）：
    ```
   刚性约束：
   必锁：关键道具 = 平铺塌瘪的褪色旧绢，轻薄半透，破损边缘，暗红粉调（锚「关键道具」图）
   可见性：随从 = 仅雾中剪影与背影；犬只 = 画面只含吻部与前爪，其余在雾外

   Must not：可读文字、字幕、水印、logo
   ```
    **两条铁律**：**必锁用正向定义**（它是什么），不写排除式——**Naming a flaw plants it**，每写一次「零 XX」就是在模型里种一次那个概念；**可见性用限定式**（仅/只 + 范围），不用否定式。唯一允许否定式的地方是 `Must not` 行，且 ≤1 行。
    **单实例铁律**：凡禁项必须含「每个点名角色全程只有一个身体，禁止同角色分身、复制人、同框重影」。人数锁定只防「多出陌生人」，防不了「点名人自己变两个」，两条都要写。
    **锁行（高漂移镜按需，不再默认每镜复写）**：多人冲突、打斗、遮挡、复杂运镜或历史易漂移镜，可在正文物理末尾（`Must not` 前）用一行收束最易漂移的一项或两项，如身份锚或关键站位；普通镜删除。禁止把光向、身份、站位、机位机械抄四遍，也不把锁行当合格证据。若锁行与轴线、站位或实际首帧冲突，以实际首帧和初始空间事实为准并删掉冲突句。

> （喻体名词被画出来、反光道具写光效出片"点火"、`不/禁` 后面的词根被当画面词）。
> **改法优先级已重排**：换具象动作 → **删**（画不出来就删，别硬翻） → 材质形状 → 对照基准 → 光效（末位）。
> **禁裸度量**：不写「距 X 一米」「三分之一虹膜」「瞳孔放大 3 毫米」；可写「光比 1:8」「主光 3200K」这类**带观感锚的分档量化**。
> **反光道具零光效描写**：只写材质本色，光源改在人物身上复述。

**默认档（简单文戏）**：用正常影视表演语言描述（动作 + 神态 + 可见生理反应），**不展开 AU 配方**。但**空泛结果词禁令全局有效**——禁「开心/难过/邪魅/愤怒」。

**全量触发条件**（满足其一）：① 特写 / 大特写；② 微表情、口是心非、隐忍克制类表演；③ 情绪转折关键拍（台词重音 / 金句发酵）；④ 该角色历史表情易崩。

触发后按四区拆解：**眉区 → 眼区 → 颧颊 → 嘴/下颌**，缺区会导致表情发空或模型自由发挥崩脸。

- **真笑**＝AU6（眼尾眯、眼下隆起）+ AU12（嘴角上提），**眼一定参与**；**假笑**只给 AU12。
- 惊讶＝AU1+2+5（抬眉+瞪眼）；再叠 AU4（眉心拧住）才是恐惧。
- AU10 提上唇＝轻蔑/嫌；AU15 降口角＝难过/委屈。**写反情绪就错。**
- **强度宁小勿大**，默认痕（10–25%）；强档只给爆点且不超 80%，满格易成鬼脸。
- **表情不能比台词先结束**，峰值对齐重音字，句尾留半拍余韵。
- 单侧动作（玩味笑、挑眉、wink）必须**指定左右且不中途换边**，与轴线一致。
- **遮挡就写看得见的部分**：戴墨镜/侧脸/背对时，眼区 AU 拍不出来，改写眉与下半张脸。

**🔴 分层铁律（违反即返工）**：**AU 编号、强度档、English kernel 一律不进投喂正文**。正文只写画面语言：哪块肌肉 + 什么可见动作 + 幅度 + 持续秒数。强度档翻译规则：痕→「轻微地／一丝／几乎看不出地」；显→「明显地／清晰地」；强→「大幅度／剧烈地」。
**为什么禁**：模型不识别 FACS 编码，`AU23` 会被当无意义 token 忽略，更糟的是被当字面字符串**渲染成画面上可读的文字**，与「禁可读文字」正面冲突；中文稿里插英文 kernel 还会造成中英各执行一半、动作加倍或打架。

**低细节清单（以下五类默认不写，写了就是稀释权重）**：泛泛的美感描写；非关键的服饰细节；背景群演的具体特征（只写数量与动态趋势）；非活跃道具；参考图里已经清晰可见的内容。

### Step 3.5：可生成性三查（v6.19.3 · 语义项，不做门，交付前人工过）

> **为什么不做成门**：这三类都能被机器扫到词，但判不了「对不对」——`像水一样糊` 是好提示词，
> `像被人碰了旧伤` 不是。做成门就是假绿门（见 §九「语义项一律不做成门」）。
> 但它们恰恰是机检全绿、出片全废的主因，所以立在细则里，逐条人工过。
> **来源**：EP20 三模型版实测，三版 check_prompt 全 0 error，而画面描述仍有六类不可生成表述。

**一查 · 景别容量**：景别决定信息容量，按叙事需要写内容必翻车。

| 景别 | 装得下 | 装不下（写了就是自相矛盾） |
|---|---|---|
| 远景 / 全景 | 空间关系、群体规模、光位对峙 | 微表情、眼神、手指动作、器物文字、「每张脸都是…」式的表情概括 |
| 中景 | 一个人的上半身 + 一个主动作 | 两个人的远距离对视（20m 外同框＝几何不成立）、全场人数 |
| 中近景 | 一个席位、一个人 + 近旁器物 | 「每张席面都…」式的全场扫描 |
| 特写 | 一个物件的材质、一处肌群 | 「一只只盘子」「一排排」——这是时间跨度，不是单帧内容 |

**判据一句话**：写之前问「这一帧的取景框里，这个东西有多大」——小于画面 1/20 的东西写进去等于没写。

**二查 · 比喻转译**：比喻是作者的话，不是模型的话。

- ❌「眼神晃了一晃，**像被人碰了旧伤**」→ ✅「上眼睑抬高一档，瞳孔向右下偏移一次，喉结动一下」
- ❌「咀嚼声停了，**像被掐掉的音轨**」→ ✅ 停就是停，写「集体咀嚼同时静止，只剩空旷回声」（听觉类比留给声音设计行，不进画面）
- ❌「名单**硌着心口**」（触觉）→ ✅「内袋透出纸张的方形轮廓，衣料被顶起一道折」
- ❌「冷蓝自四边**向中心吞没**」（剪辑效果）→ ✅ 若真要写，写成「冷蓝自画面四边向内推进，压到主体边缘」；否则交给后期

**唯一允许保留的比喻**：描述**视觉结果**且模型见过的大量样本——「面孔隔一层水般模糊」（＝失焦 + 液体折射）
可以；「像被人碰了旧伤」不行。分界线：比喻指向**画面里能看见的物理现象**，还是指向**心理与因果**。

**三查 · 跨段对象自洽**：六段是**六次独立生成**，模型看不到前后文。

- 同一物件在每段的口径必须一致：EP20 段 1「夹一筷菜」／段 3「盘中无菜、是影像碎片」＝同一个盘子两种内容，
  模型会一段给真菜、一段给碎片，跨段接缝必断。
- 解法二选一：① 统一口径（盘里从来是影像，她夹的就是影像）；② 在首段就埋可见证据（菜在减少的特写），
  让反转有视觉依据。
- 同理：同一个人物的伤口/持物/服装在每段都要重述一次（不写「同前」——那是跨镜指代，`W-CONTEXT-LEAK` 会抓）。

**四查（连带）· 场景行必须写注册表全名**

`场景：地下礼堂中庭（相片世界·冷蓝与烛光对峙）`——**用注册表 `display_name` 全名**，不要写「长宴席（同上）」。
实测 107 个存量包里 **69 个（64%）** 写的是简称或「同上」，导致 C2（场景时段）与 C3（场景开口）
两道场景门全部无法生效——**门在，但认不出场景，等于没查**。这一条不改，场景类判据永远是 36% 覆盖。

**五查 · 体态（v6.19.4 补）**：「出场人物」行只锁**外观**（外形地标 + 服装主色形制 + 一件随身物）会得到人形立牌。
外观之外必须给一句**体态**：重心落点 + 脊柱角度 + 双手当下在哪。

- ❌「沈照——18~20 岁男性……颈挂老式旁轴相机」（只有外观 → 笔直立正）
- ✅ 同上 + 「体态：重心压在右脚，上身微微前倾，右手悬在相机上方三指处」

生成模型对**姿态动词**的响应强于对「面朝画面左/右」这类朝向描述——朝向只决定转身角度，不决定他怎么站。

**六查 · 段缝方式要混用（v6.19.4 补）**：包首的【段缝声明】若只写「① 末帧定格承接」，六段全定格，
剪起来是**六次刹车**。真实短剧每 15s 不会停一次。

- 六段里至少 **2 段改用运动中截断**：镜头还在推、动作还在走时切断，下一段从同一运动相位接上；
- 定格只留给**情绪落点**（本集是段 4「妈给你留着」与段 6 收尾）；
- 包首声明里把两种方式都写出来，否则默认全定格。
