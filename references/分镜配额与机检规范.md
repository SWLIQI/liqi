# 分镜配额与机检规范（Shot Quota & Lint）

> 📐 **流程位置：Step 3 逐镜阶段的质量约束层**。
> 本规范把「镜头多样性」从原则变成**可统计的区间配额**，并定义 S10~S22 十三个机检码。
> 与 `视听层_镜头文法与光色.md` 的分工：那份管**这个镜头值不值得存在、承担哪个任务**（审美判断），
> 本规范管**整包的镜头构成有没有失控**（统计判断）。先用那份定单镜，再用本规范查全包。

---

## 〇、 为什么需要配额

`视听层` 已有两条硬规则：「严禁连续两个镜头使用相同景别 + 相同机位」「景别阶梯跃迁」。
这两条管的是**相邻关系**，管不了**全包构成**。

实测里最常见的失控不是单镜写错，是**全片节奏雷同**：

- 一集 12 镜，10 镜中景平视——每镜单独看都合规，连起来看全是同一个画面；
- 运镜全是「缓慢推近」——模型对推近的响应最稳，于是不自觉全写推近；
- 特写占比 8%——该给的情绪拐点全给了中景，情绪起不来。

**配额把审美偏好变成可检查的工程约束。** 关键在于本规范给的全是**区间**（如特写占比 25%~40% 而非固定值）——既划出失控边界，又保留创作空间。

## 二、 配额表（11 项区间配额，全区间制，每项都有例外通道）

> 十一项 = Q1~Q11。另有三条**构成要求** C1 / C2 / C2 附，不算占比、算必有项，见本节末。
> `check_skill.mjs` 的 **L3 契约**会核对「这里写的项数」与「下面实际 Q 行数」是否一致——调配额时两处一起改。

> **最小样本量（v5.37.3）**：Q1~Q4 是占比判据、Q8/Q9 是种数判据，全部按**每集分布**标定
> （原始标定口径是 57 单元一集）。镜块太少时它们不是「严格」，是**数学上不可满足**：
> n=2 时占比只有 0 / 50 / 100 三档，「25%~40%」要求命中 0.5~0.8 个镜；焦段凑不出 4 种、
> 运镜凑不出 8 种。结果是任何短包必挂 4~6 条**永远修不掉**的黄字，用户只能一律滑过，
> 连带 S16 / S19 / S22 三条真判据一起失效。
>
> 所以 `audit_project.py` 设了门槛：**Q1~Q4 需 ≥3 镜、Q8 需 ≥4 镜、Q9 需 ≥8 镜**。
> 不够门槛时报「本门未查（配额类 …：镜块 N 不够门槛）」并写明实际镜块数与粒度——
> **不报「不合格」（用户改不动），也绝不报通过（未查 ≠ 通过）**。
> 单场 / 单元 / 广告这类短包本来就不该按整集配额判。

| # | 配额项 | 区间 | 例外声明（段首显式写即豁免） |
|---|---|---|---|
| Q1 | 人物特写占比 | 25%~40% | 物件特写不计入；定场镜禁特写 |
| Q2 | 常规机位占比（平视 + 正面/过肩 + 平稳运镜） | ≤30% | 文戏重场可声明「常规机位主导」 |
| Q3 | 侧 45° 机位占比 | 30%~40% | — |
| Q4 | 侧面机位占比 | ≤15% | — |
| Q5 | 大仰角次数 | ≤3 次/集 | — |
| Q6 | 大俯角次数 | ≤3 次/集 | — |
| Q7 | 荷兰角次数 | ≤1 次/集，或不用 | — |
| Q8 | 全片焦段种数 | ≥4 种 | — |
| Q9 | 全片运镜种数 | ≥8 种 | 含「固定机位」为一种（v5.37.3）；Q10 的连续同运镜**不计**它 |
| Q10 | 连续同运镜 | 禁止第 3 镜（≤2 镜） | 剧烈晃动短链可连续 |
| Q11 | 重技法全片上限 | 滑动变焦 ≤1、环绕 ≤3、Snorricam ≤1、鱼眼 ≤2、升降 ≤2、摇臂 ≤2、POV ≤3 | 单场各 ≤1 |

另有一条**构成要求**（不算占比，算必有项）：

| # | 要求 | 说明 |
|---|---|---|
| C1 | 每组（段）至少 1 大景别 + 1 特写 + 1 中景 | 「大景别」= 档 1~3，「中景」= 档 5 |
| C2（跨段出口） | **v6.4.0 起废止「补 1 秒段末接戏全景」**（实测撤销） | 跨段出口 = 实际尾帧验收 ＋ 下一段 `first_frame` 硬绑定 ＋ 复核实际首帧，不强制全景拍；规格沿革见 `空间层_调度与轴线.md` §十三留档 |

## 三、 越界分级：只有三项报 ERROR

配额越界一律先报 WARN，**只有下列三项报 ERROR**——这三项是实测翻车最重、
且没有合法创作理由的：

| 项 | 为什么是 ERROR |
|---|---|
| Q10 连续同运镜 | 第三镜必然读成「同一个机位拍了三遍」，是节奏死直的直接成因 |
| Q11 重技法超上限 | 重技法是注意力税，全片超发等于没有重点 |
| Q7 荷兰角超配 | 荷兰角是风格化手段，一集超过 1 次就从手法变默认 |

其余八项（Q1~Q6、Q8、Q9）越界报 **WARN**，提示调整但不阻断。

## 四、 与既有裁决的兼容（倒车防护，必读）

本规范**不推翻** liqi 已裁过的任何结论，二者并存：

### 4.1 「跳级不非法，缺过渡素材才非法」

`资产审美_设计原理.md` §13.3 已裁定：相邻景别跨度大**本身不是错**，错在跳了却不给模型过渡素材。
因此本规范**不把「相邻景别差」设为 ERROR**：

- 「相邻两镜档位差 ≥3」只报 **WARN**（S21），提示补过渡素材；
- 段首显式写「本段采用极限景别跳跃」→ 该段整段豁免 S21。

### 4.2 「极限景别跳跃」与「开场 ECU 两极对冲」合法

`视听层` 保留的两种合法大跨度手法，本规范同样认：

| 手法 | 豁免内容 |
|---|---|
| 极限景别跳跃（ECU↔EWS 对跳） | 豁免 S21（相邻档位差 WARN） |
| 开场 ECU 两极对冲（首镜无上一镜） | 豁免 S21，且首镜不计入 Q1 特写占比分母 |

### 4.2.1 极限景别跳跃的两种声明粒度（v5.29.0）

S21「相邻景别跨度 ≥3 档」是 WARN，声明即豁免。**两种粒度，按项目体量选**：

| 粒度 | 写法 | 位置 | 适用 |
|---|---|---|---|
| **逐段** | `【配额声明】本段采用极限景别跳跃` | 该段段首 | 只有个别段是跳切 |
| **包级** | `【配额声明】全片采用极限景别跳跃` | **包首**（与【段缝声明】同级，**不进正文**） | 全片配额构成本身就需要跨档 |

**为什么要有包级**：Q1 特写 25%~40% + Q3 侧45° 30%~40% + C1 每组必有三种景别，三条叠加后
10 镜级的片子**几乎每块都要跨档**；逐段声明每条 14 字，9 块就是 126 字，直接吃穿单镜 800 字额度。
包级声明写在正文外，不占额度，一次豁免全片。

> 判定：`audit_project.py` 的 S 门先看包首有没有「全片采用极限景别跳跃」，再看逐块 `decl`。

### 4.3 配额与 800 字额度正交

配额是**结构约束**，字数是**长度约束**，两者不互相豁免。
不能因为某镜字数超额度就免它的配额，也不能因为配额合规就放宽字数。

## 五、 S 系列机检码

落在 `scripts/audit_project.py`，新增独立段 `S. 分镜配额构成`。
镜块切分复用 `split_shots`，不另建切分逻辑。

| 码 | 级别 | 配额项 | 判据 |
|---|---|---|---|
| S10 | WARN | Q1 | 人物特写占比越出 25%~40% |
| S11 | WARN | Q2 | 常规机位占比 > 30% |
| S12 | WARN | Q3 | 侧 45° 机位占比越出 30%~40% |
| S13 | WARN | Q4 | 侧面机位占比 > 15% |
| S14 | WARN | Q5 | 大仰角 > 3 次/集 |
| S15 | WARN | Q6 | 大俯角 > 3 次/集 |
| S16 | ERROR | Q7 | 荷兰角 > 1 次/集 |
| S17 | WARN | Q8 | 焦段种数 < 4 |
| S18 | WARN | Q9 | 运镜种数 < 8 |
| S19 | ERROR | Q10 | 连续第 3 镜同运镜（剧烈晃动短链豁免） |
| S20 | ERROR | Q11 | 重技法超全片上限 |
| S21 | WARN | — | 相邻两镜景别档位差 ≥3（段首声明「极限景别跳跃」即豁免；开场首镜不判） |
| **S22** | **ERROR** | — | **配额统计失效元检查**——统计不到镜块 / 有块但都不含 duration 行 / 过半镜块解析不出景别 / 所有镜块解析不出运镜词，报 FAIL 而非报 OK |

**只有 S16、S19、S20 三项报 ERROR**（荷兰角、连续同运镜、重技法超限），
其余 WARN；S22 是元检查，恒为 ERROR。

### 5.1 S22 为什么必须是 ERROR

配额机检最大的失败模式不是漏检，是**「没统计却报通过」**。
若 `split_shots` 返回 0 块（分块格式没被识别），或有块但都不含 duration 参数行
（容器段被当成镜头），或过半镜块解析不出景别，统计结果会退化成「0 越界」→ 看起来全绿。
S22 专治这个：**统计不到就报 FAIL，并明说「本门没有真正查过，不算通过」。**
这与 `check_style.mjs` 的 S0 假绿防线、`audit_project.py` 的 Z 门是同一条纪律。

⚠️ **但它有一个反向陷阱（v5.37.3 修）**：旧判据是「所有镜块都解析不出运镜词 ⇒ 统计失效」，
而运镜词表只收位移/变焦类动作，**「固定机位」不在表里**。于是一个**正确写满固定机位**的
静态包（静物镜、对话定场、空镜）解析出的运镜集合为空，直接撞 S22 报 ERROR，还附上一句
「本门没有真正查过」——用户被要求去「修格式」，可它格式完全正确。

病根是把两件不等价的事当成一件：**「没写运镜」与「运镜写得认不出」**。
固定是运镜的反面，但它是一个**明确的选择**。
修法两条必须一起动，否则按下葫芦浮起瓢：

1. 词表补「固定」（`固定机位 / 机位固定 / 机位静止 / 固定镜头 / 静态机位 / 固定`）；
2. **Q10 连续同运镜把「固定」排除**——三镜固定机位在对话戏与静物戏里极常见，
   它读不出「同一个机位拍了三遍」的问题，计进种数、不计进连续链。

### 5.2 只统计叶子块

S 系列**只统计含 duration 参数行的块**（真镜头）。容器段
（如 `## 段 1｜夜探（25s）`）本身不是镜头，计入分母会污染占比——
混合格式（容器段 + 镜块）下尤其明显。有块但都不含 duration 行时，
S22 报 FAIL 而不是拿容器段充数。

### 5.3 统计不到字段怎么办

单镜解析不出景别或运镜时，该镜**计入分母、不计入分子**，并在报告里给出
「未解析出景别的镜号列表」（挂在 S22 附行）。分母永不为 0（有叶子块就有分母），
所以占比永远可算，不会出现除零或空集假绿。

## 六、 声明式例外的写法

例外不是靠注释里写「这里我特殊处理」，而是**段首一行显式声明**，机检认字符串：

```
【配额声明】本段采用极限景别跳跃
```

认的声明词（段首 `【配额声明】` 行内出现即生效，只对所在段生效）：

| 声明词 | 豁免 |
|---|---|
| 极限景别跳跃 | S21 |
| 常规机位主导 | Q2（S11） |
| 重技法集中段 | 该段内重技法不计入全片上限（仍受单场 ≤1 约束） |

**纪律**：声明只能豁免统计，不能豁免内容质量。声明了「极限景别跳跃」的段，
仍受 `资产审美` §13.4 的过渡素材兜底约束——声明不等于免检，只是换一道检查。

## 八、 常见失败模式

| 现象 | 根因 | 处置 |
|---|---|---|
| 一集看下来全是同一个画面 | 常规机位超配（Q2） | 逐镜标机位角度，把平视正面降到 30% 以下，补侧 45° 与过肩变化 |
| 情绪起不来 | 特写占比不足（Q1） | 情绪拐点/关键道具/台词重音/反应镜四类必给特写 |
| 节奏死直 | 连续同运镜（Q10） | 第三镜必须换运镜或换景别；查 S16 |
| 画面发花 | 重技法超发（Q11） | 重技法是注意力税，全片总预算就那么多，集中给一个高潮段 |
| 机检全绿但明显漏查 | 统计失效 | 查 S22；确认分块格式是「镜 N｜标题（Ns）」且标题带秒数 |
| 荷兰角用得顺手就收不住 | 缺配额意识 | 一集 ≤1 次是硬线，超了报 ERROR 不报 WARN |
