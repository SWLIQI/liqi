## 〇、 立条目背景

### 现象

提示词正文混用两套坐标：

- **A 画面参照系（观众视角）**：「马六在**画面右三分之一**」「自**画面右缘**踱入」
- **B 人物参照系（角色自身左右）**：「停在**他右前方**一步」「机位在**他的左后方**」「两列灯在**他右后方**」

两套各写各的都不算错，**错在混用**。人物背对或侧对镜头时，B 会整体左右翻转——
读者（和模型）按 A 理解，写作者按 B 摆位，出来的站位正好镜像。

### 复现场景（最小复现）

```
段 1｜靴底碾下（15s）
站位：陈砚跪在画面正中偏下；马六自画面右缘踱入，停在他右前方一步。
        ↑ A：画面右缘                    ↑ B：陈砚的右前方

段 2｜人群散尽（15s）
站位：陈砚在画面左三分之一、跪着未起；马六在画面右三分之一，转身后走出画面右缘。
                                        ↑ A：画面右三分之一
```

陈砚跪着、**朝向未定义**，所以「他的右前方」在观众视角是画面左还是画面右根本无从判断。
马六还「绕走半圈」——绕完落到陈砚另一侧（画面左）。段 1 结束在画面左，段 2 起手就在画面右三分之一。
**同一个人两段之间横跨半个画面。**

### 出片症状（三条，按暴露顺序）

1. **跨段瞬移**——上一段人从画面左出画，下一段从画面右入画，剪在一起像闪现。
2. **视线对不上**——两人相对而立的位置被镜像，眼神交互的方向整体反过来。
3. **机位越轴**——「机位在他的左后方」被按画面左理解，实际该在画面右，越轴后人物朝向整段反了。

### 根本原因

| 层 | 原因 |
|---|---|
| 表层 | 写作者用人物左右描述空间——因为他脑子里是站在角色视角看场面 |
| 中层 | 🔴 **参照系从来没被显式声明**。作者默认读者和他站同一边，而镜头恰恰把两边分开了 |
| 深层 | 🔴 **人物朝向在正文里通常没写**（跪着、侧身、背对镜头各有各的翻法），于是 B 无法反解成 A |
| 机制层 | 这同样是**不可见缺陷**：单看一段完全成立，跨段才暴露；且压字数时最先被删掉的就是「他」「画面」这类参照词 |

一句话：**参照系是空间描述的坐标系，省掉坐标系，每个人算出来的位置都不一样。**

### 为什么既有五道门全没拦住（含 v5.40.0 新增的两码）

| 门 | 管什么 | 为什么拦不住 |
|---|---|---|
| `check_prompt.mjs` §22E | 局部入画**有没有归属** | 管的是「这只手是谁的」，不管「这个位置以谁为准」——「停在他右前方一步」**有归属（他＝陈砚），但参照系仍然是错的** |
| `check_prompt.mjs` 站位门 | 站位写没写、锚定给没给 | 「停在他右前方一步」是一条完整站位，格式上完全合法 |
| `audit_literal.py` | 抽象、不可演的表述 | 「右前方」**可演**，不是抽象表述 |
| `audit_risk.py` | 平台合规 | 与合规无关 |
| `check_style.mjs` | 风格串与色板 | 与风格无关 |

**真正的缺口是第二个维度：空间指代的参照系。**
v5.40.0 补的是「实体找不找得到主人」，本条补的是「位置找不找得到坐标系」。
两者是同一族（指代完整性）的两个面，缺一都会断在同一帧。

**实战代价**：人工扫一遍只找出 8 处；上新门当天**又抓出 6 处**（其中 4 处是人工连扫两轮都没看见的
「屋脊中段偏左」「炭堆在她脚前偏左」「案面右侧」「纸的左上角」——这四个都不是人物左右，
是**物体自身左右**，人工扫的时候根本不会往参照系上想）。

## 一、 定义

**空间方位**＝正文里描述「东西/人在画面的哪一边」的左右前后。四类高发位置：

| 类 | 例子 | 高发写法 |
|---|---|---|
| 站位 | 人在画面哪里 | 「马六在画面右三分之一」✅／「停在他右前方一步」❌ |
| 出入画 | 从哪进、从哪出 | 「自画面右缘踱入」✅／「从右侧走出」❌ |
| 机位 | 摄影机摆在哪 | 「机位在画面右后方」✅／「机位在他的左后方」❌ |
| 道具摆放 | 道具在场景哪里 | 「案面靠画面左的后角」✅／「案面左后角」❌ |

**画面参照系**＝观众视角。画面的左半边就是观众看到的左半边，与任何角色的朝向无关。
**这是本 skill 的唯一合法参照系。**

---

## 二、 两套坐标的翻转规则（背下来）

人物朝向决定 B 能不能反解成 A：

| 人物朝向 | 他的左手边在观众视角的 | 反解 |
|---|---|---|
| 面朝镜头 | 画面右 | 镜像 |
| 背对镜头 | 画面左 | 同向 |
| 面朝画面右 | 画面上方（更远处） | 旋转 90° |
| 面朝画面左 | 画面下方（更近处） | 旋转 90° |
| 侧身/跪姿朝向未写 | **无法反解** | 🔴 |

**最后一行是本条的立条理由**：只要正文没写朝向，B 就是一道无解方程，
而「跪着」「侧身」「背对镜头」在短剧里是常态，不是例外。

## 三、 写法三式（照抄即可）

### 式一：主位用画面坐标（必须）

```
站位：马六自画面右缘踱入，绕到陈砚面前、停在画面右三分之一、距他一步。
```

画面坐标给**精确位置**，人物关系（「陈砚面前」「距他一步」）给**相对关系**，两者并存不冲突——
画面坐标在前，相对关系在后。

### 式二：相对关系只作补充，不作定位

✅「停在画面右三分之一、距他一步」——位置由画面定死，距离是补充
❌「停在他右前方一步」——位置完全交给一个未定义朝向的人

### 式三：物体自身左右也要换成画面坐标

物体没有朝向，但读者会把「案面左后角」「纸的左上角」「屋脊中段偏左」理解成画面坐标——
**一旦物体中途被移动或旋转，这套坐标就跟着翻**。

```
❌ 纸的左上角与右上角各翘起一片……他把纸转过半圈，指腹抹平下边左角、再抹下边右角
✅ 纸靠画面左的上角与靠画面右的上角各翘起一片……他把纸转过半圈，指腹先抹平靠画面下的左角、再抹右角
```

「转过半圈」之后，纸自身的左上已经变成右下。**用画面坐标写，旋转多少次都不翻。**

### 身体部位是唯一例外

右眉尾缺一截／左手／右颊一颗痣／右拇指玉扳指——**保持人物参照系**。
这是资产特征，跟着人走，换了机位也还是那条右眉。机检白名单见第五节。

## 四、 六个漏点位置（★ 站位行只是第一个）

人工第一轮只扫了站位行，其余五行全漏。**改方位时六行一起扫**：

| # | 位置 | 实例（本项目实战） |
|---|---|---|
| 1 | **站位** | 「马六…停在他右前方一步」→「停在画面右三分之一」 |
| 2 | **时间线分镜（事件序）** | 「马六从画面右缘踱进来、绕走半圈」→ 绕完落哪边没说 |
| 3 | **场景** | 「两列灯在他右后方」→「在画面右侧、他身后」 |
| 4 | **镜头（机位）** | 「机位在他的左后方」→「机位在陈砚身后、略偏画面右侧」 |
| 5 | **硬性约束 / Must not** | 约束行里也会写方位，同样要挂画面 |
| 6 | **道具摆放（案面/纸/屋脊）** | 「案面左后角」「屋脊中段偏左」「纸的左上角」 |

⚠️ **压字数时别删参照词。** 本项目「停在他右前方一步」→「停在右前方一步」就是为了省一个字，
结果**归属和参照系同时丢失**——省一个字，断一场戏。

## 五、 机检（`W-SPATIAL-NO-FRAME-REF`，check_prompt.mjs §22F）

### 判据

方位词（左／右）所在的**整个小句**里，有没有出现「画面」二字。
有 → 放行；没有 → 报 `W-SPATIAL-NO-FRAME-REF`。

### 判据为什么是「整个小句」（🔴 第一轮写坏过）

第一版只看**方位词之前**的窗口，结果把「三个纸人的纸脚继续向左走出画面左缘」判成没挂参照系——
「画面」在方位词**之后**，已经把方向写清楚了，却被判违规。**把「写在后面」当成「没写」。**
改成看整个小句（用「，。；：」切，不用「、」切）后，这类后向承接写法全部正确放行。

用「，。；：」而不是「、」切小句，是因为实战里「人群自画面右缘进入、横过前景、距他约一臂后出左缘」
这种承接写法极多——用顿号切会整片刷屏。

### 三条设计限定（与 §22E 同一取舍）

1. **只查「挂没挂画面参照系」，不查方位写得对不对**——画面左三分之一到底该站谁，脚本量不出来，交 Step 4 人工。
2. **WARN 级**——主观 POV 镜头里用角色自身左右是有意为之，做成 ERROR 会逼出「为过门硬塞画面二字」的假合规。
3. **身体部位白名单**：右眉／左耳／右手／右颊／右颧／右掌／左腿……一律放行（资产特征）。

### 声明式豁免

段头写 `【空间方位豁免】：<理由>` 整段豁免。用于主观 POV、第一人称视角。

### 误报源四件套（已实测排除，各有自测用例）

| 源 | 处理 |
|---|---|
| 「左右分开」「左右两边」 | 双向词，不是方位歧义 → 跳过 |
| 「画左」「画右」简写 | 等同画面参照系 → 放行 |
| 「继续向左走出画面左缘」 | 方位词在后半截被接住 → 看整个小句 |
| 「右眉尾」「左手」「右颊」 | 身体部位 → 白名单放行 |

**已知漏网（WARN 级，不追求零漏）**：「他的左手边」「右手侧」这种「部位＋方位」会被当成部位放行。

## 六、 自检清单（交付前五问）

1. 本段每一个「左／右／前／后」，前面都挂了「画面」吗？（身体部位除外）
2. 用「他／她」的方位（他的右前方、他的左后方）全部改成画面坐标了吗？
3. 上一段人物结束在画面哪一侧，本段起手在同一侧吗？**跨段对照一遍。**
4. 机位写的是画面方位，还是人物方位？人物背对镜头时两者是反的。
5. 道具写的是画面方位，还是物体自身方位？**物体中途被旋转的话，自身方位会翻。**

## 七、 失败模式（现象 → 原因 → 第一改项）

| 现象 | 原因 | 第一改项 |
|---|---|---|
| 上一段从画面左出画，下一段从画面右入画 | 两段各写各的，人物朝向未定义 | 下一段入画侧改到与上一段出画侧一致 |
| 两人对视，眼神方向反了 | 站位被镜像（B 当 A 用） | 站位全部改画面坐标 |
| 越轴：人物朝向整段反了 | 机位用「他的左后方」 | 改「画面右后方」或「他身后、略偏画面右」 |
| 道具摆错边（牌位跑到另一头） | 用「案面左后角」这种物体方位 | 改「案面靠画面左的后角」 |
| 纸转了半圈后四个角描述全乱 | 用纸自身方位，旋转后翻转 | 全程用画面坐标描述四角 |
| 压完字数位置突然对不上 | 删掉了「他」「画面」这类参照词 | 回退该处压缩，保住参照词 |

## 八、 与既有规则的边界（不重叠）

| 规则 | 管什么 | 本条不管 |
|---|---|---|
| `专项_局部入画归属.md`（v5.40.0） | 实体**归谁**（这只手是谁的） | 位置**以谁为准** |

**一句话分工**：归属条目管「找不找得到主人」，本条管「找不找得到坐标系」。
