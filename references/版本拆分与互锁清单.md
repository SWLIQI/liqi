# 版本拆分与互锁清单（批量任务前必读）

## 一、何时需要拆分多版本

| 触发条件 | 判定标准 | 处理 |
|---|---|---|
| 服装阶段切换 | 设定/剧本中出现"换装、新裁、改穿"等时间节点 | 拆 A/B 两条目，各自独立出图 |
| 体态状态切换 | 同一角色出现"瘦脱形、衰老、状态恶化"等体态变化 | 拆两条目（正常版/状态版），同衣不同状态 |
| 道具阶段切换 | 道具出现"完好→烧焦/破损/使用后"等状态变化 | 拆两条目（如 8A 完好/8B 烧焦） |
| 单一版本 | 全片/全程一套服装、无状态变化 | 一条目即可，不拆 |

判断口诀：**有切换点（时间/剧情节点）→ 拆分；无切换点 → 单条目**。不确定时按拆分处理，多一张图比穿帮好。

## 二、条目编号规则

- 主编号连续：1, 2, 3, 4...
- 拆出的版本用字母后缀：`2` 与 `2B`、`18A` 与 `18B`
- **🔴 易错点**：条目拆分后，其他条目中引用该道具的编号会失效——批量生成后必须全包检索旧编号并改为当前包内实际编号（如旧包引用"条目8A"→新包实际为"条目18A"）。

## 三、版本互锁负面词对照表

| 版本 | 禁止内容必写（互锁词） |
|---|---|
| 角色A A（素白中衣） | 藕荷色系 |
| 角色A B（藕荷衣裙） | 素白中衣（本版禁用A版配色） |
| 角色B正常版 | 瘦脱形（正常版禁用四幕状态） |
| 角色B瘦脱形版 | 换脸、换服装颜色、骷髅化 |
| 藕荷小衣完好态（8A） | 焦黑痕迹、恢复完好 |
| 藕荷小衣烧焦态（8B） | 燃烧中的火焰、明火元素、恢复完好 |

原则：**每个版本的禁止内容里，必须有"禁另一版本特征"的词**——这是版本隔离的关键，防止生图工具串版。

## 四、使用纪律速查

1. **版本独立生成（硬规则）**：多版本每个单独出图，禁止合并进同一张设定图。
2. **图注文字一律中文**：道具/场景表引线注释中文；人物卡零引线零标注线（仅表情名/身高线/色板三处带字）；中文渲染崩了走 SKILL.md Step 3 的三级降级预案。
3. **身高线与头身档位都是硬约束**：所有站立角色条目必须带垂直身高参照线；头身比按**目标观感**档位表选（不默认 7 头身），同包禁止混档；孩童 vs 成人差是构图基础。
4. **无主图条目**：文字版角色收尾句"不篡改参考图人物面部五官结构"按"保持设定五官一致"理解即可。
5. **场景-资产联动**：资产绑定时间节点的（如某服装从中秋才启用），写入使用纪律防止穿帮。
6. **安全约束内嵌**：解剖类=无内脏无骨骼无鲜血；文书类=无可读文字；剪影=不露正脸；动物=不露全貌。
7. **注册表回写（硬规则）**：新增版本后，除了给新版本写 `lock_out`，**必须回头给旧版本的 `lock_out` 补上新版本特征**——单向加锁等于没加锁，这是串版最高频的漏项。同时更新 `asset-registry.json` 的 `lock_matrix`。
8. **色值取用纪律**：色值只从注册表取，禁止现场编造；**缺 HEX 视为不合格**（中文色名跨模型漂移极大）。
