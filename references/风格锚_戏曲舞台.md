# 戏曲舞台·浓彩程式 风格锚（写实轨 × 实拍 × 戏曲舞台专项）

本文件是 Step 2「全片统一风格锚（九段）」在**戏曲舞台实拍质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：戏曲舞台的真人实拍——检场空台与一桌二椅、浓彩脸谱与翎子行头、
程式化身段（亮相、圆场、水袖）、舞台顶光的正面照明、幕布与氍毹的红金配色。
用户给的是戏曲 / 舞台戏中戏 / 国粹题材参照时，锁③ 风格轨道选**写实轨**，风格 id 取 `opera-stage-live`。

**边界声明**：

- 与古装仙侠偶剧（`xianxia-idol-live`）：同为古装真人，**世界规则不同**——偶剧是实景山水叙事世界；
  戏曲是**检场空台**（台上什么都没有，一桌二椅即千军万马），脸谱与行头是程式不是写实。
- 与复古港风（`hk-retro-filmstill`）：同为浓彩实拍——港风是霓虹 grade 与胶片感；
  戏曲是舞台顶光正面照明的剧场感 + 行头彩绣的本体浓彩。
- 与民国月份牌（`republic-calendar-poster`）：月份牌是绘画海报程式；戏曲是真人舞台实拍。
- 与纪实实拍（`documentary-live-action`）：纪实的晃动与偷拍感反戏曲的舞台仪式感。

> **竖屏适配（C26）**：舞台以正面平观为主——竖屏写法：亮相式单人居中、水袖纵向抛出、
> 翎子纵向拉高画面。**竖屏友好，无需改写行**。

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 戏曲舞台实拍：检场空台（台上只有一桌二椅），氍毹红毯与幕布的金红配色；行头彩绣在舞台顶光下的丝缎反光；脸谱是画在脸上的浓彩程式（油彩的光泽感）；真人皮肤在浓妆下只见眼与手 |
| ② 配色与色域 | 舞台三主色：氍毹红、幕布金、行头彩（按行当分档：生净浓彩/旦角清彩）；**每镜只声明一个唯一重音色**；禁日常便服色、禁灰暗、禁霓虹 |
| ③ 运动签名 | 24fps 舞台观感：固定机位平观为主（观众席视角），程式身段是本体——亮相定格、圆场碎步、水袖翻飞；运镜极少（一场一推）；禁环绕、禁甩镜、禁手持 |

| ⑤ 场景锁定 | 走 `<Subject N>`：检场空台——一桌二椅的位置与围桌椅帔颜色写死；幕布与侧幕不入画或做暗部 |
| ⑥ 道具锁定 | 走 `<Subject N>`：马鞭、船桨、令旗、折扇，程式道具形制写死（一道具一世界） |
| ⑦ 光色基调 | 舞台顶光正面照：光从上前方打，人物面部明亮均匀，台面留出光区与暗区的舞台光池；**禁电影级侧逆光、禁自然光逻辑、禁景深虚化** |
| ⑧ 声音签名 | 环境层：剧场底噪、板鼓与檀板；动作层：水袖拂、厚底靴踏台、髯口抖；唱腔与锣鼓经是节奏本体；配乐：文武场（京胡、锣鼓），有板有眼 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A live-action Chinese opera stage frame: bare stage with one table and two chairs, red carpet and gold curtain world, stage-top front lighting with a bright pool on the floor. Opera faces are thick greasepaint formulas, costumes are embroidered silk robes with satin sheen, water sleeves and spear-props staged as pure convention. Frontal theatre view, proscenium grammar, no cinematic side lighting.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
red carpet and gold curtain base, costume colours by role type, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `realistic battlefield set` | `bare stage ... one table and two chairs` | 检场空台是本锚的世界规则 |
| `cinematic rim light` | `stage-top front lighting` | 电影布光反串舞台感 |
| `natural costume colours` | `greasepaint formulas ... embroidered silk` | 程式浓彩是本体 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 61 词，长档——预算紧先删第三句（Opera faces 一句，脸谱行头由正文逐镜写），删后约 47 词。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅戏曲舞台实拍画面：检场空台只有一桌二椅，氍毹红毯与金幕的舞台世界，舞台顶光从上前方正面照下，台面留出明亮的光池。脸谱是画在脸上的油彩浓彩程式，行头是彩绣丝缎带缎面反光，水袖与马鞭都是程式道具。正面的镜框舞台视角，不用电影侧逆光。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：氍毹红与幕金打底，行头彩按行当程式，每镜只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「真实古城战场」 | 删，写「检场空台一桌二椅」 | 空台程式是本锚世界规则 |
| 「电影感打光」 | 删，写「舞台顶光正面照」 | 反串电影感 |
| 「淡妆素雅」 | 删，写「油彩浓彩程式」 | 浓彩是行当本体 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（检场空台、舞台顶光、油彩浓彩、程式道具）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把舞台推成实景电影**，所以「检场空台」与「舞台顶光」在国内面**不许省略**。

| 分类 | 运镜 |
|---|---|
| 主力 | 固定平观（观众席视角）、一场一推 |

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 跑成古装实景剧 | 写了真实山水、布景 | 「检场空台」锁死；负面词带写实布景 |
| 跑成电影感 | 写了侧逆光、浅景深 | 舞台顶光正面照锁死；负面词带电影级布光 |
| 脸谱变淡妆 | 写了淡雅、清透 | 油彩浓彩程式锁死；负面词带素颜淡妆 |
| 卸妆穿帮 | 中途写卸妆换便服 | 行头跨镜不变，进连续性台账 |
| 道具变实物 | 写了真马真船 | 程式道具（马鞭即马）锁死 |
| 台下观众入画 | 视角写偏 | 镜框舞台正观，台下不入画 |
| H3 正文混中文 | 压句或行当段夹中文 | 压句纯英文；跑 `check_prompt_h3.mjs` |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「电影化」与「生活化」两侧的词**，保留检场空台与程式浓彩。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| realistic set / 真实布景 | bare stage, one table two chairs | 空台是世界规则 |
| cinematic lighting / 电影打光 | stage-top front lighting | 反串电影感 |
| soft natural makeup / 淡妆 | greasepaint formulas | 浓彩是行当本体 |
| real horse / 真马 | whip as the horse | 程式道具铁律 |
| casual clothes / 便服 | role-type costumes | 行头程式 |

### 9.2 互斥风格

`xianxia-idol-live`（实景叙事世界 vs 检场空台，世界规则互斥）、`hk-retro-filmstill`（霓虹 grade vs 舞台顶光）、
`sweet-romance-live`（生活化现代 vs 程式浓彩）、`documentary-live-action`（纪实偷拍感 vs 舞台仪式感）。
