# 质感与可见性预算清单

写作时直接查表套用，避免临场造词。

## 一、材质与质感清单：四类标准写法

写实轨按这四类逐条写，每条锚定一张资产图。写法 = **名词 + 可观测特征**，不写"高精度""细节丰富"。

| 类别 | 可观测特征维度 | 示例 |
|---|---|---|
| 布料 | 纤维粗细 / 织纹 / 起毛起球 / 磨损补丁 / 垂坠感 / 新旧 | 粗布补丁，经纬粗粝起毛，补丁针脚外露，几乎无垂坠 |
| 皮肤 | 蜡质/血色 / 干湿 / 皮下透色 / 纹理强度 / 温度暗示 | 蜡质苍白，无血色、皮下透青灰、干燥起皮 |
| 地面环境 | 潮湿 / 反光 / 颗粒 / 风化 / 植被状态 | 潮湿石土路面，碎石缝隙积水反光，枯草倒伏 |
| 道具 | 材质本体 / 反光率（哑光-镜面）/ 透光性 / 新旧 | 骨簪式惨白，哑光微透 |

**特殊材质单列**：当某物件承担核心叙事功能（如关键道具、信物、凶器），从四类中提出来单独写一条。
三件套为 **来源资产 + 色调转换 + 正向状态定义**——第三件是"它是什么状态"，
**不是排除式**（早期版本写"排除式定义"，与本文第十节的纯正向原则冲突，已废止）：
`关键道具：褪色旧绢、泡胀雨衣质感，轻薄半透，破损边缘起翘发脆，暗红粉调，表面干爽
（锚「关键道具」图与「空壳的藕荷色衣裙」；质感介于「修皮骨簪」的惨白与「瓷盒」的温润之间）`

正向状态写足了，画面就锁死了。补一句"零血污、零液体喷溅"不但冗余，
还是在模型里重新种一次那两个概念（Naming a flaw plants it）。

## 二、质感交叉引用句式库

遇到图集里没有的新材质，用已有资产夹逼定位。固定格式：**"X 的（属性）+ 与/但 + Y 的（属性）"**。

- 两资产插值：`质感介于「修皮骨簪」的惨白与「瓷盒」的温润之间`
- 借形态换色调：`如「空壳的藕荷色衣裙」的轻薄透明与破损边缘，但色调转为暗红粉`
- 借质感换载体：`参考「角色A」白衣的冷白皮肤质感，转为粉红肌理`
- 借氛围换对象：`如「客栈大堂」暗处悬挂肉干在暗光下的微弱暖色`
- 借生物细节换场景：`参考「主要角色」图中破旧环境的生物细节`

**禁止**：凭空造形容词（"诡异的质感""令人不适的材质""电影级细节"）——模型无法解码，只稀释权重。

## 三、可见性预算等级表（全部用**限定式**，不用否定式）

每个出镜对象都必须分配可见等级，漏写 = 模型默认给全貌/正脸，是穿帮高发区。

**写法铁律：用"仅/只 + 范围"告诉模型画什么，不用"零XX/不露"告诉它别画什么。**
说了"仅背影"就不需要再补一句"零正脸"——那句是冗余，且在模型里多种一次"正脸"这个概念。

| 等级 | 限定式写法 | 适用 |
|---|---|---|
| 局部 | `画面只含吻部与前爪，其余在浓雾与画框之外` | 动物、不愿定型的对象 |
| 剪影 | `仅现雾中剪影，面部与服饰细节隐没在雾里` | 群像、随从、未揭示身份者 |
| 背影 | `只呈现背影与后脑轮廓` | 需隐藏身份的角色 |
| 遮挡 | `隔着门框取景，面部被门框切在画外` | 窥视视角 |
| 虚化 | `景深外虚化，五官融进背景色块` | 背景人群 |
| 单部件 | `画面里只有火把与锣可辨，人物保持在轮廓状态` | 配角、执法者 |

写法模板：`可见性：<对象> = 仅/只<可见范围>（锚「资产图名」）`

**否定式（零/不/禁止）唯一允许的去处是 `Must not` 行，≤1 行，只放平台期望的类别：**
`Must not：可读文字、字幕、水印、logo`
有 `negative_prompt` 字段的平台（如 Kling）填入该字段；Seedance 类平台附于正文末一行。

## 四、色彩预算写法（正向表述）

**必须显式声明色彩预算**，两种形态二选一：

- **有重音色**：`色彩预算：唯一重音色 = 随从火把（橙红团块，如「客栈大堂」暗处悬挂肉干的微弱暖色），归属第五段`
- **单一色系**：`色彩预算：单一色系，全片落在冷青灰区间，饱和度压至最低`

> 不写"零跳色""禁止高饱和"——那是给模型种概念。改成正向的"单一色系 + 饱和度压至最低"。
> 不声明色彩预算，模型会自发补饱和度，全片色调立刻散掉。

## 五、运动签名句式库（分两层，写进风格锚第 3 条）

| 层 | 装什么 | 去向 |
|---|---|---|
| **生成期** | 节奏与质感词汇 | **进提示词正文** |
| **后期** | 抽帧、速度曲线、剪辑层操作 | **不进正文**，写 `# 后期` 行 |

生成期句式：

| 意图 | 句式 |
|---|---|
| 皮影/偶戏感 | 动作起落带轻微顿挫，关节转折处短暂停顿，模拟皮影关节感 |
| 纪实手持 | 轻微手持呼吸感，机身保持稳定 |
| 冷峻机械 | 全程匀速横移，机身稳定 |
| 古典舒缓 | 缓推缓拉为主，画面保持稳定 |
| 快切紧张 | 三段结构，切点干净利落 |

后期层句式（写进参数行）：
`# 后期：关键动作抽帧至 15fps 播放，速度曲线 0.5 拍滞后`

> ⚠️ 常见错误：把"抽帧""慢半拍""30fps"写进正文。模型按固定帧率输出，它不会抽帧——
> 抽帧是剪辑层操作。写进正文既无效又占权重，后期还拿不到可执行参数。

## 六、时长带宽与滑窗拆分

| 单条提示词时长 | 段数 | 处理 |
|---|---|---|
| 2-4s | 1 | 单一动作，不分段，不需要时间指示 |
| 5-9s | 2-3 | 一段内按顺序叙述 |
| 10-20s | 3-5 | 分镜 / 时间轴段，每段一个主动作 |
| 21-30s | 4-6 | 已越过 20s 方法论红线，Seedance 2.0 / 2.5 面均允许（30s 是模型硬上限），强烈建议拆；**H3 面不适用本行——H3 单条硬上限 15s** |
| **30s+** | — | **强制滑窗拆分**（30s→2 窗，45s→3 窗） |

（与 SKILL.md Step 1 第 3 条同表；改一处必须同步另一处。）

**两条线必须分清：20s 是方法论红线，30s 是模型硬上限。**
超过 20 秒不拆，模型只会稳定生成约 20 秒的内容，剩余靠循环播放凑——这是"后半段重复"事故的根因。
超过 30 秒接口根本不支持，必须拆。校验器对应两条：20-30s 报 W-OVER-20S（建议拆），>30s 报 E-OVER-30S（必须拆）。

**滑窗规则**：每窗写成独立自洽的提示词——角色重新用外观识别、禁止写"接上/继续/仍穿着"、
窗间靠视觉重叠衔接（上一窗末帧作下一窗首帧参考），不靠文字连续性。

## 七、投放面段头骨架（二选一，不可混用）

| 投放面 | 平台 | 骨架 |
|---|---|---|
| 国内面 | 即梦、豆包、Dreamina、Ark | `【时间轴】0-7s：画面…｜镜头：全景 固定机位 缓速右摇｜音效：…` |
| 国际面 | Sora、Veo 3、Runway、fal | `Shot 1 (0-7s): 全景，固定机位，缓速水平右摇。画面… Sound: …` |
| Seedance 2.5 面 | 火山方舟 Ark（doubao-seedance 2.5）、即梦 2.5、豆包 | liqi 镜块骨架 + 【时间轴】保留；另加【生成目标】【参考素材职责】【未采用素材】【主体与关系】【事件脚本】段；台词 `{}`、音乐 `()`、音效 `<>`。详见 `Seedance2.5适配.md` |

混用两套骨架会让模型失去切点，长提示词渲染成一镜到底。
**已废弃**：中文数字段号（`0:00-0:07 · 第一段 · …`）——它不属于任何一套骨架。

## 八、保真预算（每镜必写）

身份保真 / 动作幅度 / 场景密度三者争夺同一份预算，什么都想要 = 处处平庸。
一次只押一个主花费，并**主动写明节省什么**：

`本镜保真预算：主 = 主要角色面部的蜡质皮肤与微表情；次 = 火把的暖色团块；省 = 随从的五官、服饰纹样与个体区分（只给可数的深色轮廓）`

常见分配：

| 镜头类型 | 主花费 | 次花费 | 主动节省 |
|---|---|---|---|
| 产品/材质特写 | 材质与形态 | 一个材质动作 | 场景密度、人群、天气 |
| 动作/打斗 | 动作幅度 | 身份（靠参考图重锚） | 面部特写、陈设 |
| 环境建立 | 场景密度与氛围 | 运镜 | 人物身份（不出现近距离主体） |
| 对白特写 | 面部稳定（固定机位） | 台词 | 运动、背景活动 |

## 九、四层混音分层判据

| 层 | 装什么 | 判据 |
|---|---|---|
| 环境层 | 空间底噪（虫鸣、风、远处闷响、人声嗡鸣） | 持续、极弱、不推动剧情 |
| 动作层 | 物件与身体发出的声（布料闷响、脚步、黏腻挤压声） | 与画面动作逐条对应 |
| 呼吸层 | 鼻息、喘息、气声、吞咽 | 标出节奏（断断续续/压扁/渐促） |
| 逼近层 | 由远及近的威胁声（铜锣、警报、脚步逼近） | 标出渐强曲线与质感（如隔深水/低频震颤） |
| 对白 | 「」原文 + 语气语速 | 单独一行，不与四层混 |

- 缺层写"无"，**不可省略层名**（省略会被理解为未设计）。
- 非台词人声（哭声/呻吟/惊叫）归入呼吸层或动作层，用 `音效=（效果描述）`，**不用「」**。

## 十、正向表述句式（**已修正**：原"正向 + 排除式双写"是错的）

> **修正说明**：早期版本要求"正向定义 + 排除式定义双写"，这是错的。
> 业界共识（seedance-20 anti-slop 原文）：**Naming a flaw plants it** ——
> 每写一次"零XX"，就是在模型里种一次那个概念。正向替代物写足了，画面就锁死了，
> 不需要再补一句否定。

约束栏"必锁"**只写正向**：

```
必锁：<对象> = <它是什么：材质 + 形态 + 状态>（锚「资产图」）
```

改写对照（左为旧写法，右为现写法）：

| ❌ 旧（正向 + 排除式双写） | ✅ 现（纯正向） |
|---|---|
| `关键道具 = 旧绢质感，零剥皮血腥、零液体喷溅` | `关键道具 = 平铺塌瘪的褪色旧绢，轻薄半透，破损边缘起翘发脆，表面干爽` |
| `无皮人体 = 粉红肌肉纹理，无内脏、无骨骼外露` | `无皮人体 = 粉红肌肉纹理，表层完整，黏膜湿润` |
| `主要角色 = 枯瘦苍白，零哭泣、零喊叫，仅抿嘴与微颤` | `主要角色 = 枯瘦苍白，面部纹丝不动，双唇闭合，呼吸压在鼻腔里，下颌微颤随即被压住` |
| `屏幕 = 纯色块，无任何可读文字` | `屏幕 = 高亮浅绿纯色块，内部保持空白，只留发光质感` |

**唯一保留否定式的地方**：`Must not` 行，≤1 行，只放平台期望的类别
（可读文字、字幕、水印、logo）。内容安全类（血腥/暴力）**不再写"零血腥"**——
把正向替代物写足即可。
