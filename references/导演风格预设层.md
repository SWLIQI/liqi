# 导演风格预设层（L1.5 · 导演轴路由）

【参数】层级：风格路由表的导演轴扩展 ｜ 触发：用户给导演名 / 片名 / 「某某风」 ｜ 上游：锁③ 风格 id 选择 ｜ 下游：十节风格锚 + S1-S9 校验
【参数】数据来源：woodfantasy/Seedance-ShotDesign-Skills 的 director-styles.md（MIT，26 条 preset，2026-10-12 收编于 references/external/woodfantasy-director-styles.md）

## 零、文件头

一句话定位：本文件把「用户心里的导演与场景参照」降解为 liqi 可执行的风格路由——导演名不是风格 id，但用户会带着导演名来。

适用判定：用户说「我要诺兰风」「新海诚那种感觉」「韦斯安德森式构图」，或给了参考片名（「参考《沙丘》的质感」）时走本层。用户直接给风格 id 或参考图时不走。

边界声明：本层不做新风格落值——它把导演参照桥接到已落值的风格 id，或明确告知「哪条待建 / 哪个缺口」；降解产物仍走十节锚的全部纪律（压句逐字复用、色值单一事实源、S1-S9 门禁）。**桥接不等于混轨**：一个包最终只有一个 style_id，导演预设只决定「落到哪个 id」与「给该 id 的运动签名/光色增量」。

## 一、什么时候走这一层

三种触发，一次问清：

1. **导演名**：「诺兰风」「王家卫那种」——最常见
2. **片名 / IP 名**：「《沙丘》那种压迫感」「新海诚的天空」——需先降解再路由，片名本身禁进投喂词
3. **场景词**：「竖屏短剧感」「小红书种草风」——新媒体 preset，部分在 liqi 边界外（见映射表转交列）

判定后按第二节降解，查第四节映射表，按第五节结论执行。

## 二、四轴降解框架

任何导演参照都降解到四条物理轴，不带着名字往下走：

| 轴 | 含义 | 例 |
| --- | --- | --- |
| 色彩 | 色盘、饱和度、色温、对比 | 去饱和冷色 / pastel 马卡龙 / 霓虹高饱和 |
| 灯光 | 光源类型、光行为、氛围 | 单一实用光源 / 幕背光 / 体积雾 / 极端自然光 |
| 美术 | 建筑、材质、场景美学 | 粗野混凝土 / 微缩布景 / 国风青瓦 |
| 机位 | 焦段、运镜、稳定方式 | 冰川般缓推 / 机械 90 度横摇 / 手持呼吸感 |

降解纪律：**每轴必须落到可观测的物理参数**（「135mm 长焦极缓推轨」），不许停在「史诗感」「压迫感」这类评价词。四轴写全后才能进映射表——缺轴的参照（用户只说「高级感」）按 Ask 流程补问，不猜。

## 三、去名化三铁律（强制）

1. **投喂词禁用人名**：导演名、摄影师名、工作室名一律不进正文与参考图标注。外部库的做法是把名字降成四轴参数后用「安全提示词」行——本层沿用：映射表的「去名化锚句」列即安全提示词，逐字复用。
2. **投喂词禁用 IP 符号**：作品名与标志性情节符号（「时间穿越」「旋转走廊」「沙虫」「龙猫」）改用原创物理描述（「巨型生物体穿越沙暴」「毛茸茸的巨型森林守护灵」）。liqi 的 guofeng-cine-3d 与 documentary 锚早有 ip_note 同向纪律，本层把它扩展到全轨道。
3. **参照图也得去名**：用户拿电影截图当参考图时，图可以喂（锁身份/风格用），但标注与正文不写片名；图里出现字幕/水印按文字铁律处理。

## 五、两个真实缺口（本次评审发现）

1. **4:3 画幅（✅ v5.45.0 已进锁②）**：锁②现为六值 16:9 / 9:16 / 21:9 / 4:3 / 3:4 / 1:1（4:3、3:4、1:1 仅明确指定时用）。VHS、复古录像带、老式监视器媒介写 4:3 即可，与 1:1 同档；竖向传统媒介用 3:4。官方 `ratio` 可选值原文含这两个值（见 SKILL.md 锁②注）。
2. **写实轨缺「霓虹高饱和」档**：王家卫与赛博朋克两条 preset 落不进去——urban-folk-filmstill 明禁霓虹赛博（那是市井志怪的粗粝 requirement），photoreal-pbr 是影视级干净高光。这是风格覆盖的真实空洞，建议列为待建候选（如 neon-noir-live-action），落值前这两条预设一律按「缺口」处理，禁止硬塞。

## 六、与既有层的接口

降解产物不另起炉灶，全部汇入既有流程：

| 情况 | 取用 |
| --- | --- |
| 落点是已落值 id | 按 id 取风格锚十节；导演预设的四轴增量只写进「运动签名」与「光色基调」两段，压句仍逐字复用锚文件原句 |
| 落点是现场落值 | 按 `风格锚_模板.md` 十节落值，覆写项写进成因注记，回写项目级 style-registry.json |
| 落点是待建 / 缺口 | 告知用户排期或建议换最近邻；禁止引用待建 id（P0） |
| 降解后的镜头有打斗 / 冻结 | `references/专项_打斗编排.md` 五段结构 |
| 降解后的镜头是舞蹈 / 卡点 | 转交 generate-dance-video-prompts，接口纪律见同文件第五节 |
| 交付前校验 | S1-S9 风格门禁 + check_prompt.mjs（含新增 `W-DIRECTOR-NAME-IN-BODY` 去名化兜底） |

## 六之二、相邻易混与机械区分（v6.1.0 · C26）

「诺兰风」和「芬奇风」都能落到 photoreal-pbr——**同一个 id，不同的增量**。用户在易混对里选错的不是 id，是增量。下表七对是本层最易混的组合，每对给一条一眼判据（来源：DirectorSKILL MIT 版反例区分思想「What this lens is NOT」，2026-10-29 对拍吸收，落法本库自定）：

| 易混对 | 为什么会混 | 机械区分（一眼判据） |
|---|---|---|
| 诺兰 / 芬奇 | 同落 photoreal-pbr，同去饱和冷色 | 诺兰=自然光高对比＋大景深实景巨构；芬奇=低调单点光源雕刻面部＋精确框取 |
| 维伦纽瓦 / 诺兰 | 同巨物压迫、同缓推 | 维伦纽瓦=弥散体积雾＋粗野混凝土＋长焦压空间；诺兰=自然光＋实景大景深，无雾 |
| 新海诚 / 宫崎骏 | 同天空同自然同 2D | 新海诚=数码光彩＋极高饱和蓝紫＋逆光丁达尔＋天空占六成（anime-2d）；宫崎骏=手绘水彩＋云透光（ghibli-2d 干净映射） |
| 韦斯安德森 / 微缩定格 | 同微缩感 | 安德森=正交平面＋机械 90 度横摇＋pastel（现场落值）；gothic-puppet=定格顿挫＋手工痕迹（id 直落） |
| 黑泽明 / 张艺谋 | 同大色块同集团调度 | 黑泽明=天气即光源＋高对比黑白/土色＋长焦压缩；张艺谋=浓烈单色色块＋仪式感航拍 |
| 仙侠修真 / 古偶柔光 | 同 guofeng 同丁达尔 | 仙侠=金青暗紫＋云海＋航拍穿越（npr/guofeng 二选一）；古偶=柔粉暖金＋柔侧逆光＋花瓣 orbit |
| VHS 复古 / 都市情感 | 同 documentary 同手持 | VHS=扫描线＋4:3＋camcorder 缺陷（媒介缺陷即签名）；都市=35mm 颗粒＋实用光源，无媒介缺陷 |

判据落点纪律：区分写进「运动签名 / 光色基调」增量与覆写项，**不改写锚压句**（压句仍逐字复用锚文件原句）。
