# 粉笔粉彩·黑板肌理 风格锚（手绘轨 × 粉笔专项）

本文件是 Step 2「全片统一风格锚（九段）」在**粉笔与粉彩（chalk & pastel）黑板质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：粉笔画的黑板世界——深色板面底、粉尘质感的粉笔线条（擦一半留一半的涂抹感）、
粉彩的柔和厚涂色块、手指擦晕的渐变（是粉尘擦出来的不是数字渐变）、板擦痕迹与粉笔灰。
用户给的是黑板报 / 粉笔画 / 课堂叙事 / 回忆杀参照时，锁③ 风格轨道选**手绘轨**，风格 id 取 `chalk-pastel-2d`。

**边界声明**：

- 与极简几何扁平（`flat-minimal-2d`）：扁平是矢量零肌理；粉笔是**粉尘肌理本体**（每一笔都掉渣）。
- 与宋式美学（`song-aesthetic-2d`）：宋式是绢本工笔的雅；粉笔是黑板粉尘的拙朴。
- 与黑色电影插画（`noir-ink-2d`）：同为深底浅线，noir 是版画硬边两值；粉笔是**粉尘软边＋彩色粉彩**。
- 与水墨淡彩（`ink-wash-2d`）：水墨洇在宣纸；粉笔浮在板面，可擦可改（擦痕是叙事元素）。

> **竖屏适配（C26）**：黑板报版式天然竖向分栏（报头-正文-插画角）——竖屏写法：
> 报头在上、主体粉笔画居中、粉笔灰落款压底。**竖屏是主场**。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 黑板粉笔画：深绿或磨砂黑的板面底（带擦痕的云雾状残粉），粉笔线条粗粝带粉尘飞渣，粉彩色块是侧锋厚涂的颗粒堆叠，手指擦晕的渐变带明确的方向感；板面反光与粉笔灰是氛围 |
| ② 配色与色域 | 板面深底＋粉笔白＋粉彩色族（粉黄/粉蓝/粉红各一层不混）；**每镜只声明一个唯一重音色**；禁照片色、禁饱和荧光、禁金属光泽 |
| ③ 运动签名 | 24fps，**画的进行时**：粉笔线条一段段长出来（书写过程可见）、擦掉重画的痕迹保留、粉尘在光柱里飘；运镜静止与极缓推近为主；禁快切、禁环绕、禁甩镜 |
| ④ 角色锁定 | 走 `<Subject N>`：头身比 6-6.5（粉笔画的拙朴比例档）；人物是粉笔线条构成（线条重复描两三遍的手绘感），服装色用粉彩侧锋铺；跨镜线条粗细不变 |
| ⑤ 场景锁定 | 走 `<Subject N>`：整面黑板就是世界（板报分栏式构图），教室/窗/讲台画成板面边缘的粉笔框；同场景跨镜擦痕与分栏一致 |
| ⑥ 道具锁定 | 走 `<Subject N>`：板擦、粉笔盒、三角尺，形制写死；板擦擦痕是叙事道具（擦掉=遗忘/修改） |
| ⑦ 光色基调 | 教室顶光下的板面：板面有轻微反光（不是镜面），粉尘在光柱里可见；**禁强投影、禁金属反光、禁数字锐光** |
| ⑧ 声音签名 | 环境层：粉笔写字的哒哒声（签名主角）、板擦摩擦、教室远噪；动作层：翻书、椅腿、粉笔灰落下；呼吸层：情绪点才写；配乐：八音盒或简单钢琴，朴素温暖 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。其他面：照片质感、数字锐利线条、金属反光、饱和荧光、3D 渲染、可读文字（板书按铁律禁——本锚特例见下）、水印、多余人物、分身 |

> **⚠️ 本锚特例——板书文字铁律的局部放开（沿用「局部放开不全局放开」先例）**：黑板报语境下
> 板面上的文字**可以用「写了一半被擦掉的粉笔字迹」呈现**（不可读、只留笔画形状）——这是叙事元素
> 不是可读文字；完整可读的板书仍然禁止（可读文字铁律不全局放开）。声明方式：包首写
> `【粉笔字迹豁免】本包板面字迹均为不可读笔画形状`。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A chalk-and-pastel blackboard drawing: deep green board ground with cloudy eraser smudges, chunky chalk lines with dusty crumbly edges, pastel side-stroke colour blocks, finger-smudged gradients with visible smudge direction. Chalk dust drifting in classroom light, half-erased ghost strokes left visible. Naive and warm, never digital-sharp, never glossy.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
deep board ground, chalk white lines, soft pastel colour families, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `digital clean lines` | `chunky chalk lines with dusty edges` | 数字锐线是本锚反面 |
| `glossy render` | `chalk dust drifting` | 光泽渲染反面 |
| `vivid saturated` | `soft pastel colour families` | 荧光是反面 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 47 词，中等——预算紧先删末句（Naive and warm 一句）。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅粉笔黑板画的画面：深绿板面带云雾状擦痕残粉，粉笔线条粗粝带粉尘飞渣，粉彩色块是侧锋厚涂的颗粒堆叠，手指擦晕的渐变带明确方向感。粉笔灰在教室光柱里飘，擦掉重画的幽灵笔画留在板面上。拙朴温暖，不是数字锐线，不是光泽渲染。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：板面深底加粉笔白，粉彩色族各一层不混，每镜只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「清晰锐利」「数字感」 | 删，写「粉尘粗粝」 | 数字锐线是反面 |
| 「光鲜」「反光」 | 删，写「板面轻反光＋粉尘」 | 光泽渲染反面 |
| 「鲜艳」「荧光」 | 删，写「粉彩色族」 | 荧光是反面 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（板面擦痕、粉尘线条、粉彩颗粒、擦晕方向感）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把粉笔推成数字白板**，所以「粉尘肌理」与「擦痕残粉」在国内面**不许省略**。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 静止、极缓推近（线条生长过程可见） |
| 少量 | 缓慢横移（板报分栏扫读） |

| 项 | 落值 |

| 主 | 主体粉笔线条与粉彩色块的粉尘质感 |

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 跑成数字白板 | 线条锐利、色彩干净 | 「粉尘肌理」锁死；负面词带数字锐线 |
| 板书变可读文字 | 写了完整板书内容 | 不可读笔画形状＋【粉笔字迹豁免】声明（局部放开不全局放开） |
| 粉彩变荧光 | 写了鲜艳 | 粉彩色族（各一层不混）锁死 |
| 渐变变数字渐变 | 擦晕没写方向感 | 「手指擦晕带方向感」锁死——是粉尘擦出来的 |
| 擦痕消失 | 板面太干净 | 「云雾状擦痕残粉」不许省 |
| 线条变均匀 | 手绘感丢失 | 「线条重复描两三遍」的手绘感锁死 |
| H3 正文混中文 | 压句或线条段夹中文 | 压句纯英文；跑 `check_prompt_h3.mjs` |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「数字锐利化」与「光泽化」两侧的词**，保留粉尘肌理与拙朴手绘感。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| digital clean lines | chunky dusty chalk lines | 数字锐线是反面 |
| glossy / 反光渲染 | chalk dust drifting | 光泽反面 |
| vivid neon / 荧光 | soft pastel families | 荧光反面 |
| smooth gradient | finger-smudged with direction | 擦晕是有方向的粉尘 |
| photoreal classroom | board-ground drawing world | 照片反面 |

### 9.2 互斥风格

`flat-minimal-2d`（矢量零肌理 vs 粉尘肌理本体）、`noir-ink-2d`（版画硬边两值 vs 粉尘软边彩粉）、
`ink-wash-2d`（宣纸墨韵 vs 板面粉尘）、`gouache-2d`（水粉纸面 vs 黑板板面）。
