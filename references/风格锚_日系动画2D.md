# 日系动画 2D 风格锚（卡通轨 × 全投放面通用）

本文件是 Step 2「全片统一风格锚（九段）」在**日系动画 2D（anime，TV/剧场通用档）**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：细线勾边的赛璐璐上色，两段式阴影（一段底色 + 一段影色，分界相对清晰但不硬到刀切）；
角色比例走日系美型——眼大、鼻口简化、下颌收尖；头发画成体块加高光带（angel ring）；
背景多为绘制背景，允许写实度较高的美术背景配平面角色。有限动画（limited animation）的运动逻辑。
用户给的设定图是这类质感时，锁③ 风格轨道选**卡通轨**，风格 id 取 `anime-2d`。

**边界声明**：

- 与国漫赛璐璐（`celshade-guoman-2d`）：同为赛璐璐系，**区别在配色与线条气质**。
  国漫走干净厚亮的中高饱和色块与美型大眼，暗部固有色加深一档；日系 anime 走**更薄的色彩层 +
  更细的线 + 更大的眼部表现空间**，且背景允许写实美术背景。两者可互换，但**同包禁混**。
- 与三渲二 NPR（`npr-celshaded-3d`）：本风格是 2D 画，转面要重新画，**不允许环绕运镜**（会崩形）；
  三渲二的资产是模型，才敢环绕。写了环绕就说明选错轨。
- 与手绘轨（`ink-wash-2d`）：手绘轨要平面无体积、纸纹可见、禁赛璐璐粗描边；本风格要赛璐璐的干净分界。互斥。
- 与暗黑二次元（`dark-anime-2d`）：那是本风格的低明度变体，未落值，需要时按 `风格锚_模板.md` 现场落。

> **本风格的头号风险是「转面崩」与「背景写实度失控」**：2D 画绕不过去的物理限制，
> 所以运镜池里环绕与大幅度横移一律禁。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 日系 2D 动画赛璐璐上色：细线勾边，色块分两段（底色 + 影色），分界清晰；角色是平面的，不做体积渲染；背景允许绘制美术背景（可带写实度），但角色层与背景层保持不同的绘制密度 |
| ② 配色与色域 | 明度分层清晰的配色：亮部薄、暗部用带色相的影色（偏紫或偏蓝，不用灰）；**每镜只声明一个唯一重音色**；禁用脏灰、荧光、大面积渐变 |
| ③ 运动签名 | 24fps 的有限动画逻辑：角色动、背景多为静止或平移；口型只做三档简化；**禁止环绕、禁止大幅度横移视差、禁止运动模糊** |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 6.5–7（日系美型成人档，孩童取 4.5–5）**；眼型与瞳色必写（本风格的辨识核心在眼）、发型体块化并带高光带、服装形制与配色；跨镜不换装、不换瞳色 |
| ⑤ 场景锁定 | 走 `<Subject N>`：背景是绘制背景，写形制与配色；同场景跨镜地标与光位一致；背景与角色层分开描述 |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、入画方式必须写（手持 / 悬挂 / 置地）；小道具允许简化为一个色块加一条边 |
| ⑦ 光色基调 | 单一主光方向，影色随形走，分界清晰；**禁全局光照、禁软阴影、禁环境光遮蔽**；可以写逆光边缘光，画成一条明确亮边 |
| ⑧ 声音签名 | 环境层：轻薄，常留白；动作层：衣料摩擦、脚步、道具声，节拍干净；呼吸层：情绪点上才写；配乐：JPOP / 轻钢琴 / 弦乐，按题材定 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅其他有 negative 字段的面可用：3D 渲染、写实照片感、真人化、厚涂油画笔触、软过渡渐变、运动模糊、环绕视差、Q 版二头身、可读文字、水印 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Japanese 2D anime cel-shaded look: thin clean lineart, flat colour split into base tone and shadow tone with a crisp boundary, no volumetric shading, no gradient. Characters stay flat and graphic while the painted background may carry more detail. Limited-animation motion, no camera orbit, no motion blur.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
anime palette where shadow is a tinted hue rather than grey, with a single accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `anime` 单写 | `Japanese 2D anime cel-shaded look` | 只写 anime 会被当成泛二次元，容易滑向 3D 或厚涂 |
| `soft shadow` / `ambient occlusion` / `gradient` | `flat colour split into base tone and shadow tone` | 这三个词触发 3D 渲染管线，线条与色块一起塌 |
| `camera orbit` / `parallax pan` | 删除 | 2D 画做环绕必崩形，这是本风格最硬的物理限制 |

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅日系 2D 动画赛璐璐画面：细而干净的勾线，颜色分成底色与影色两层，分界清晰，不做体积渲染，没有渐变。角色保持平面化的绘画感，背景可以是绘制得更细的美术背景。有限动画的运动方式，镜头不环绕，无运动模糊。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
日系动画配色：暗部用带色相的影色而不是灰，每帧只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「二次元」「动漫风」 | 「日系 2D 动画赛璐璐」 | 「二次元」太泛，模型会自行决定是 3D 还是厚涂 |
| 「柔和阴影」「真实光影」 | 「底色与影色两层，分界清晰」 | 写实光影词会开全局光照，线条立刻变软 |
| 「不要 3D、不要写实」 | 删否定句，正面写「勾线干净、色块分层、平面化」 | 否定不生效 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次（细线勾边、两段式色块、不环绕）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台倾向给 2D 角色加体积渲染**，
所以「不做体积渲染，没有渐变」这句在国内面**不许省略**。

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 变 3D CG | 正文出现 render、volumetric、soft shadow | 压句首词 `2D anime cel-shaded`，全片禁 3D 词 |
| 环绕时角色崩形 | 运镜写了 orbit / 绕到侧面 | 运镜池里环绕是禁项，转面镜头改拆镜 |
| 线条变软变糊 | 出现 gradient、blur、soft lighting | 正面写「细而干净的勾线，分界清晰」 |
| 眼型漂移 | 角色条目没写死眼型与瞳色 | `<Subject N>` 里眼型、瞳色、睫毛三件必写 |
| 背景喧宾夺主 | 背景细节写太多，压过角色 | 预算纪律：主花费给角色头部，背景走「省」 |
| 暗部变灰 | 影色写成 grey / 灰 | 写「带色相的影色（偏紫或偏蓝）」 |
| 运镜加运动模糊 | 写了 motion blur | 明写 `no motion blur` |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删的是「立体化」与「厚涂化」两侧的词**；本风格要保留线条与两段式色块。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| render / volumetric / soft shadow / ambient occlusion | 删除，改写 flat colour in two tones | 触发 3D 管线 |
| thick paint / oil brush / painterly | 删除，改写 clean cel colour | 厚涂破坏赛璐璐的干净分界 |
| grey shadow / grey shading | shadow is a tinted hue | 影色一灰，日系配色立刻塌成廉价 CG |
| motion blur / camera orbit | 删除 | 2D 画面加运动模糊必糊，环绕必崩 |
| photorealistic background characters | 群演只写数量与趋势 | 写实群演会压过平面主角 |

### 9.2 互斥风格

与本风格互斥的 id（与 L0 `style-registry.json` 的 `excludes` 一致，**双向登记**；数值有出入时以 L0 为准）：

`npr-celshaded-3d`（三渲二，2D 与 3D 资产互斥）、`ink-wash-2d`（手绘平面，赛璐璐分界与水墨晕染互斥）、
`photoreal-pbr`（写实，平面绘画与真实材质互斥）、`celshade-guoman-2d`（国漫赛璐璐，配色与线条气质不同，同包禁混）、
`webtoon-2d`（韩漫条漫，竖屏专项与横屏动画演出互斥，分镜密度和留白规则都不一样，同包禁混）。
