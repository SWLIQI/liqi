# 水墨淡彩 东方手绘 2D 风格锚（手绘轨 × MiniMax H3）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**水墨淡彩东方手绘 2D**这套具体风格上的落值，
同时给出 H3 面的英文压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

适用判定：宣纸／熟宣底、淡彩水墨渲染、细匀墨线勾边、低饱和东方配色、大量留白当天空与地面、
静态的架上绘画构图。用户给的设定图是这类质感时，锁③ 风格轨道选**手绘轨**，风格锚取本文件。

> ⚠️ **2026-10-05 实测修订**：本文件原 §二 的英文压句含 `2D animation`、`illustrated storybook register`
> 与三处否定（`no gradients / no rendered volume / no specular highlights`）。
> 实测结果：**出片普遍呈 2.5D**。成因与替换方案见 §九，**§二的压句已换，旧句作废**。

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次，
漂三次这套风格就不叫水墨了。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A flat hand-painted Chinese ink-and-wash picture on xuan paper, held on one plane. Thin ink outlines with occasional dry-brush breaks; every area is one flat wash struck once. Light is not modelled, and the same flatness holds near and far. Large areas of bare paper read as sky and ground.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
muted desaturated palette of xuan-paper white, pale lilac grey, slate blue grey, ochre earth and pine green, with a single restrained cinnabar accent
```

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

**四个改动点，每个都在治 2.5D，一个字都不要改回去**：

| 旧写法 | 新写法 | 为什么 |
|---|---|---|
| `2D animation` | `picture` | `animation` 会把视频模型路由到日式三渲二通道，那是 2.5D 本身 |
| `in a quiet illustrated storybook register` | 删 | storybook illustration 的先验是厚涂半立体插画 |
| `no gradients, no rendered volume, no specular highlights` | `Light is not modelled, and the same flatness holds near and far.` | 扩散模型对否定基本不生效，`no rendered volume` 极易被读成「有 volume」 |
| （无） | `every area is one flat wash struck once` | 正面交代「一块颜色一次涂完」，比否定渐变强 |

**字面量必须与原句等长**（原 47 词，新 47 词）。这不是强迫症：正文有 350–500 词的区间门禁，
压句一涨就把原本贴着 500 上限的单元顶出去，一缩就把贴着 350 下限的单元挤下去。
改动前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅平面手绘的中国水墨淡彩画，画在宣纸上，整幅压在同一个平面内。细匀墨线勾边，偶有干笔断锋；每一块颜色都是一次平涂完成。光不做塑造，近处与远处保持同样的平面感。大面积留白即为天空与地面。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
低饱和配色：宣纸白、藕荷灰粉、灰青灰、赭石土黄与墨绿松针，朱红只作唯一重音色点缀。
```

**中文面三条额外纪律**（英文面没有，别漏）：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「水墨**动画**」「国风**动漫**」 | 「水墨淡彩**画**」「平面手绘**画**」 | 中文的「动画 / 动漫」与英文 `animation` 是同一个路由开关，命中即走日式三渲二通道，出片 2.5D |
| 「不要渐变」「不要体积感」 | 「光不做塑造」「近处与远处保持同样的平面感」 | 中文否定句同样是负向提示，扩散模型读成肯定 |
| 「暗部提亮一档、降饱和一档」 | 从正文删除，只留在 (A) 结构层与参数行 | 校色操作是给后期看的，进了正文模型会全局提亮 → 补光照 → 2.5D |

**两处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联里。
只写一句会导致色域漂移。刚性约束的「必锁」行再压一次风格特征（平涂、细墨线、留白），
三处互为兜底——2.5 面没有 negative 字段，正向句是唯一的钉子。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行，不滥加通用负向项。有该字段的面整份填入。

国内面最容易出问题的是**平台自带的美化倾向**会自动补饱和度与渐变。
所以 2.2 那句「每一块颜色都是一次平涂完成」在国内面**不许省略**——省了就散。

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **出片 2.5D（半立体）** | 风格压句里带 `animation` / `storybook` / 否定句；正文有横向位移产生视差；参考图本身半立体 | 见 §九，压句换新 + 位移改同速率 + 参考图重出 |
| 画面变 3D 渲染 / 塑料感 | 写了高光、渐变、体积光，或风格压句没写 | 压句逐字复用；禁写高光与渐变 |
| 变成赛璐璐卡通 | 误选卡通轨，写了粗黑轮廓线与硬边阴影 | 锁手绘轨；轮廓线写 thin even ink outlines |
| 饱和度失控、色散 | 没写色彩预算 | 每镜声明唯一重音色与色系 |
| 角色被画成设定表三宫格 | 把三视图 / 4 View 板当首帧 | 三视图只当 `<Subject N>` 定义，绝不当首帧 |
| 水印被画进画面 | 资产图带平台水印未裁 | 喂模型前裁掉或用修补盖掉 |
| 人物与场景质感打架 | 人物图是柔和水彩、场景图是平涂线描 | 场景图按本文件压句重出一版，只改质感不改构图 |
| 表情全部被抹平 | 一镜塞了太多表情节拍 | 一镜一个主节拍，拆成 2–3 秒短镜 |
| 动作像橡皮糖 | 写了碰撞、液体量、物体切半 | 不拍那一刻，改写为光一闪加物件离开 |

## 七、声音签名（中英双轨）

投中文面（Seedance 2.5 / 国内面）直接取中文版，不要拿英文版现场翻译——译一次音色就散一次。

**中文版（2.5 面 / 国内面用）**：

```text
整体声音签名：环境层——高处风声、脚下木板吱呀、远处一声不重复的钟响；
动作层——衣料摩擦、鞋底擦地；呼吸层——克制，可闻不可见；配乐层——无。
```

**英文版（H3 面用）**：

```text
overall_soundscape:
Thin high-altitude wind, the creak of a wooden board underfoot, and one distant bell that does not repeat.

non_diegetic_music:
N/A
```

需要配乐时写清乐器、速度、动态走向，例：
`A solo guqin at a slow tempo with long silences between phrases, no swell, no percussion.`

这套风格**默认无配乐**。加了配乐就要在整体声音签名里声明，否则不同镜会各自补出不同的音乐。

## 九、去立体化与串轨防护

本风格的第一崩点是出片 2.5D（半立体）。判据、污染词与验收全在本节。

### 9.1 污染词与替换对（2026-10-05 实测）

#### 判据

观感上「像日式动画 / 像半立体插画 / 有厚度但没细节」——就是 2.5D。它的内部分工是：
**造型是 2D 的，光影与空间是 3D 的**。所以光看轮廓找不出问题，要看**明度层次**和**位移时的视差**。

#### 五个来源（按影响排序）

| # | 来源 | 怎么认 | 反制 |
|---|---|---|---|
| 1 | **风格路由词**：`2D animation`、`illustrated storybook` | 全文搜这两个词，命中数 = 风格压句重复数（57 单元就是 57 次） | 换成 `picture` / `painting`；删 storybook |
| 2 | **否定句**：`no gradients`、`no rendered volume`、`no specular highlights` | 搜 `\bno (gradients\|rendered volume\|specular highlights)\b` | 全部改正面陈述；H3 无 negative 字段，否定句只会被读成肯定 |
| 3 | **微立体材质词**：`glow`、`shadow`、`光柱`、`透暖`、`磨得发亮`、`包浆` | 这些是 PBR 语义，模型会补高光与次表面散射 | `glow` → `flat warm wash`；材质词保留但补「不做反光」 |
| 4 | **横向位移产生视差**：`pans slowly to the right` | 2D 平面一旦平移，模型为了解释位移就会自建 3D 空间 | 改成「整幅作为一张平面同速率侧移」，明确不产生视差 |
| 5 | **参考图本身半立体** | 首帧图就带明暗层次 | 回资产板重出，图崩了视频必崩 |

#### 顺手要清的配套污染

- **校色操作规则混进 prompt**：`暗部提亮一档、降饱和一档` 是给人看的后期规则，
  进了正文就是让模型「提亮暗部」→ 全局光照 → 2.5D。它只能待在 (A) 结构层与参数行里。
- **分层合成说明混进 prompt**：`留白是一层独立的宣纸层`、`日光柱是一层独立的水墨光柱层`
  是后期分层的要求，进了正文会被理解成「画面里叠了一层半透明层」→ 分层立体感。
  正文改成「留白与日光柱都画在同一个平面上」。
- **光影范围声明写完不要压暗**：`光照范围之外保持纸白，不做压暗` 里的「不做压暗」是反转
  风险点，写成正面句「光照之外的部分保持纸白」。

#### 量化扫描

```bash
# 五个来源一次扫完（在包所在目录跑）
python scripts/dedupe_style.py <包.md> --style ink-wash-2d            # 只报数，不改
python scripts/dedupe_style.py <包.md> --style ink-wash-2d --aggressive  # 确认安全后再改
```

#### 验收

修完必须四项全过，缺一项都别发：

1. `check_prompt_h3.mjs` → **0 error / 0 warning**
   （压句字数必须与原句等长，否则 350–500 词的区间门禁会炸）
2. 全文 `animation` = 0、`illustrated|storybook` = 0、风格否定句 = 0、`glow` = 0
3. `audit_literal.py` 候选不增加；`audit_risk.py` 仍报「镜数 N / 触发 0」——**镜数不能为 0**，
   为 0 说明扫描器空转，不是通过
4. 台词条数与字数逐条比对**一字不差**，单元数、参数行数、总时长不变

#### 改完还 2.5D，说明问题在 prompt 之外

按顺序排查：① 参考图/首帧本身是否半立体 → 重出资产；② 是否用了纯文生视频（改走 I2V/Ref2VA）；
③ 镜头是否在动（把「移」改成「切」）；④ 模型对平面手绘的先验本就弱——这时唯一的杠杆是
**把平面特征写进画面内容本身**（龟裂、平涂色块、无明暗界线的场景），而不是继续加参数。

### 9.2 互斥风格

与本风格互斥的 id（与 L0 `excludes` 一致，**双向登记**）：

| 互斥 id | 混了会怎样 |
|---|---|
| `photoreal-pbr`（写实 PBR） | PBR 材质词自带高光与次表面散射，一进正文画面立刻有体积，直接变 2.5D |
| `celshade-guoman-2d`（国漫赛璐璐） | 粗黑轮廓 + 两段式硬边阴影会把细匀墨线顶掉，水墨变卡通 |
| `gothic-puppet`（哥特定格木偶） | 定格轨要体积要纵深——本文件 9.1 的删词表在它那儿是**反的**，照抄等于给自己下毒 |
| `npr-celshaded-3d`（三渲二） | 3D 模型套卡通着色，自带体积与纵深，与本轨的平面无体积直接冲突 |

**串轨怎么认**：看有没有出现对面的材质词。水墨正文里出现「高光 / 渐变 / 体积光 / 次表面散射」，
或赛璐璐正文里出现「厚涂 / 软过渡 / 水痕晕染」，就是串了，按 9.1 的替换对清。
