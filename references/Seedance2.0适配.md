# Seedance 2.0 适配规范（liqi 格式 × 2.0 官方指南对接）

本文件规定本 skill 的终稿格式投放到 **Seedance 2.0**（火山方舟 Ark 2.0 线 / 即梦、豆包的 2.0 档）
时的改写规则与**完整包结构模板**。依据 Seedance 2.0 官方提示词指南
（docs.volcengine.com/docs/82379/1587797，① 2026-10-28 实读，ark 镜像正文可读）
与《创建视频生成任务》API 文档（82379/1520757，① 同日核）整理；
16x9_15s_2x0 项目 24 包生产事故（v6.9.1 修复）的反哺条款已内化。

**总原则：liqi 的增值层全部保留（风格锚、预算体系、可见性限定式、连续性台账、转场注记、
参数行），只改与 2.0 冲突的部分——段头骨架、素材指代、时长切分、正文边界。**

> ⚠️ **本文件存在的理由**：v6.9.1 之前 2.0 面没有适配文件与黄金样例，生成时套用 2.5 模板
> 导致三类事故（元块进正文 / 即兴注记 / 台词声音被清空）。本文件与第四套黄金样例
> `examples/实战_圆桌2x0_EP01/`（2.0 面六段 15s 基准）共同封死这类模板漂移。

## 〇、投放面判定与轨道对照

| 投放面 | 代表平台 | 骨架 | 符号 |
|---|---|---|---|
| Seedance 2.0 面 | 即梦、豆包、Ark（2.0 线） | **镜头编号事件序**：`镜头1：…｜镜头2：…`（秒级时间轴禁用） | 台词 {} 音乐 () 音效 <> ——**四符号体系覆盖 2.0**（①） |

轨道规则与 Step 0 ① 完全一致，不因 2.0 换轨。**2.0 单条 4-15s 或 auto**；15s 以上内容
用 `镜头1:/镜头2:/镜头3:` 在**一次调用内**切分（每镜 4-6s），不走滑窗——2.0 面不存在
「15-30s 单条」这回事，滑窗是 2.5 面概念。

## 一、符号系统对齐（①官方核实 · v6.9.1 改口径）

官方「特殊字符规范」章明列，**四符号体系与 2.5 完全一致**：

| 内容 | 符号 | 示例 |
|---|---|---|
| 台词 | `{原文}` | 方姨（急切，压着）：{记者同志，我儿子没死，他一直跟我住} |
| 音效 | `<描述>` | <纸张摩擦、桌面轻响> |
| 音乐 | `(描述)` | (背景播放舒缓的钢琴乐) |
| 字幕 | `【内容】`（仍只用于"后期合成"声明场景） | 画面不显示字幕 |

**历史错误废止**：v6.9.1 前本面写「声音语法：无，音效走后期配音（待核实维持禁用）」——
待核实占位被当成定论，导致 24 包台词声音被清空（事故来源）。官方简介原文：
「模型原生支持**音频与视频联合生成**」——2.0 有同期声，台词与音效照写。

**台词三写铁律不变**：时间线段内 + 镜行尾 `台词：` + 声音设计对白行，三处逐字一致，
「」换 {}。对白文本建议置于「」内的建议级注记同 2.5。

## 二、素材引用与投喂图序（2.0 核心机制）

官方指代方式（①）：

- **基础指代**：`图片1`、`图片2`……按上传顺序编号指代。
- **主体绑定**：简单场景用 `<主体N>@<图片N>`（如 `沈照@图片2`）；复杂场景先
  「将…定义为<主体N>」定义标签后持续使用同一标签。
- **⚠️ 编辑/延长任务**用 `<视频N>` 指代，勿加「参考」二字（防误判为参考任务）。
- **素材库 ID 不能直接当指代**——仍须 `<图片/视频N>`。

**素材上限（model-limits.json 2.0 档，①分项已核）**：图 ≤9 / 视频 ≤3 / 音频 ≤3 /
**合计 ≤12**；音频**不可单独输入**（须至少配 1 图或 1 视频）。

**投喂图序（2.0 面的素材职责落法）**：2.0 面**不写**【参考素材职责】正文段（那是 2.5 面结构）。
挂图顺序落参数行——放「—— 以下不进正文 ——」之后：

```
# 投喂图序（按顺序挂 4 张）：图1=场景\S01_方姨家.png（客厅结构与方桌窗位）｜图2=角色\C01_沈照_4View资产板.png（沈照的五官、发型与灰绿工装）｜…
```

正文里对素材的引用写「图2 用于沈照的五官与灰绿工装」式一句话（跟在【参考素材】相关句里），
**不整块搬职责表**。

## 三、时长与切分（2.0 特判）

- 官方单条 **4-15s 或 auto**；`E-OVER-30S` 的阈值随锁①走——2.0 面 15s 即报。
- **不响应时间戳**（官方口径 82379/2222480；2.5 指南明列两线差异）：0-3 秒级精确范围
  支持不稳定、强制时长可能异常输出。**秒只作内部预算**，写进行为描述
  （「停一拍的工夫」「磨了两秒才收回」），不写「0-3s」。
- 每镜 4-6s 一动作一运镜；镜间是**事件先后**关系，模型按镜头编号顺序响应。
- Ark 另推荐 prompt 首尾可选回声「时长：X秒」（中文「秒」）作强化，非控制。
- 跨段衔接：2.0 面单条 15s 封顶，跨段通过 **I2V 首帧绑定**（取上一段实际尾帧作下一段 first_frame）实现——2.0 支持 I2V（投放面总表投放模式行）。滑窗拆分声明对 2.0 **不适用**（单条 15s 封顶无需拆分）；【段缝声明】在 2.0 面为**信息性声明**（机检 V 门 E-SEAM-UNDECLARED 只对 2.5/h3 生效），写了不碍事、不写也不报。

## 四、2.0 面单镜模板（可复制骨架 · v6.9.1 事故反哺）

> **【段声明】**是 2.0 面的段落声明标签（`15s · 节拍 N · 收束：…`），等价于 2.5 面的【长段声明】但因 15s 封顶**无需三条件放行**——声明节拍数与收束方式即可，无机检读取。

**正文边界四条**（详版见 `工作流_写镜细则.md` 2.0 特判段）：
① 【参考素材职责】不进正文（挂图走 `# 投喂图序` 参数行）；
② 段头只写「时间线分镜（镜头编号事件序）：」，禁把规则理由写成括号注记进正文；
③ 台词三写进正文（{} 符号），声音设计行音效用 `<>`——2.0 有同期声；
④ 交付指针只进包首**或附文区**，且必须指向真实存在的交付物。

```text
段 1｜段名（15s）
【段声明】15s · 节拍 N · 收束：末拍定格

场景：…（日，光源）｜人物：…
轴线：…站位：…位移：…视线：…
出场人物：…（外观识别写全，2.0 逐镜独立）
整体风格：（风格锚首句逐字内联）
本镜保真预算：主 = …；次 = …；省 = …
本镜光色：…

时间线分镜（镜头编号事件序）：
镜头1：全景，固定机位。画面动作描述（时长感写进行为描述）｜台词：方姨：{台词原文}
镜头2：中景，固定机位。…｜台词：无
镜头3：近景，固定机位。…｜台词：沈照（平）：{姓名，年龄}
声音设计：环境——…；动作——镜头1 <…>；镜头2 <…>；呼吸——…
台词：镜头1 方姨：{台词原文}
台词：镜头3 沈照（平）：{姓名，年龄}

刚性约束：必锁：…
Must not：…
锁行：光向；身份锚；站位铁律

—— 以下不进正文 ——
# title: 段名
# duration: 15s | # ratio: 16:9 | # 输出规格: 1920×1080 / 24fps
# 投喂图序（按顺序挂 N 张）：图1=路径（职责）｜图2=…（职责）
# style_id: xxx
# 首帧参考: 图1 场景基准图
```

## 五、台词与声音（联合生成口径）

1. **同期声存在**：台词 `{}` 与音效 `<>` 都进正文，模型联合生成音轨。
2. **台词语言**：模型按文本语言生成——中英混排需显式「用英语说道{…}」（官方示例同款）。
3. **音效纪律**：`<>` 只进声音设计行与时间轴镜头行，不混进画面描述（方言与旁白规程 §三）。
4. **配音对齐单仍产出**：同期声不豁免交付物——TTS 版本、纯音乐段、多语言版仍走
   《配音对齐单》（Step 6 附表）；包首指针只指它，不指不存在的《后期音效单》。

## 六、能力边界与 2.5 差异清单

| 维度 | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| 单条时长 | 4-15s 或 auto | 4-30s |
| 段头骨架 | 镜头编号事件序 | 【时间轴】整秒时间戳 |
| 素材上限 | 图9/视3/音3/合12 | 图30/视10/音10/合50 |
| 音频参考 | 不可单独输入 | 可仅传音频 |
| 符号体系 | `<>{}（）【】`（①同款） | 同 |
| 素材指代 | 图片N / `<主体N>@<图片N>` | 同 + 【参考素材职责】正文段 |

| 参考视频时长 | 每个 2-15s、合计 ≤15s | 合计 ≤30s |
