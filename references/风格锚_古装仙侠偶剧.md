# 古装仙侠·偶剧实拍 风格锚（写实轨 × 实拍 × 仙侠短剧专项）

本文件是 Step 2「全片统一风格锚（九段）」在**古装仙侠偶像剧实拍质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：真人古装剧的实拍质感——物理布景与实景山水、真人皮肤带剧级精修（柔肤但保留纹理）、
古装服饰织物清晰、仙侠元素只以「可见的实体件」出现（发光法器、纱雾、粒子光尘、剑气余辉），
调色走清透的青金月白档。用户给的是仙侠短剧 / 古装偶剧参照（剧照或成片截图）时，
锁③ 风格轨道选**写实轨**，风格 id 取 `xianxia-idol-live`。

**边界声明**：

- 与国风电影级 3D（`guofeng-cine-3d`）：那是**三维动画**（唐代院线动画渲染、非真实毛发与皮肤着色）；
  本锚是**实拍**——真人毛孔纹理、实物织物、物理布景。出现「渲染」「CG 角色」一类词即跑向对方。
- 与写实 PBR（`photoreal-pbr`）：photoreal 是现代题材的通用写实渲染；本锚限定古装形制 + 剧级精修
  + 仙侠元素层。现代物件（手机、马路、西装）入画即穿帮。
- 与市井写实志怪（`urban-folk-filmstill`）：志怪是低饱和粗粝老胶片 + 恐惧压抑；仙侠偶剧是清透高调
  + 柔光精修 + 意象唯美。两者的 grade 方向相反，负面词互斥。
- 与纪实实拍（`documentary-live-action`）：纪实禁精修禁摆拍感；偶剧档的精修与打光是本体不是缺陷。

> **竖屏适配（C26）**：本锚签名不依赖横幅构图——偶剧以中近景人物对话为主，竖屏天然适配。
> 竖幅写法：双人对话改高低位落差（站/坐或台阶差），大场面改纵向纵深（前景法器 → 中景人物 → 远景山门）。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A live-action Chinese xianxia idol-drama frame: real sets and scenic mountains, drama-grade retouching that keeps skin texture, crisp silk and embroidered robes, physically lit with a clean rim light. Ethereal elements appear only as visible props: a faintly glowing talisman, thin gauze mist, drifting light motes. Moon-white and pale cyan grade with gold accents.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
pale moon-white and cyan palette, gold and rouge accents, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `CG render` / `3D animation` | `live-action ... real sets` | 写 CG 词会跑向国风电影 3D 档 |
| `beautiful stunning gorgeous` | `drama-grade retouching that keeps skin texture` | 颜值词不落地，精修感靠质感词达成 |
| `dark grim moody horror` | `clean rim light` / `pale cyan` | 恐怖 grade 是志怪档的方向，反串 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 54 词，属于偏长档——H3 预算紧的项目可先删第三句（Ethereal elements 一句，仙气元素改由正文逐镜写），删后约 47 词。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅古装仙侠偶像剧的实拍画面：真实布景与实景山水，剧级精修的皮肤保留毛孔与绒毛纹理，纱缎与绣金织物质感清晰，物理布光带干净的轮廓光。仙侠元素只以可见的实体件出现：微微发光的法器、薄纱雾气、飘浮的光尘。月白淡青的清透调，金色与胭脂做重音。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：月白与淡青打底，金与胭脂只做每镜唯一重音。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「动漫感」「国漫」 | 「实拍画面」 | 会跑向 3D 动画档 |
| 「唯美的仙侠世界」「绝美」 | 删，写「清透调 + 精修质感」 | 形容词不落地，模型自由发挥 |
| 「恐怖」「阴森」「诡谲」 | 删，写「清透」「轮廓光」 | 反串到志怪 grade |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（实拍质感、保留皮肤纹理、仙气元素只作实体件、月白淡青调）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把精修推成磨皮瓷面**，所以「保留毛孔与绒毛纹理」这句在国内面**不许省略**。

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 跑成 3D 动画 | 出现「渲染」「CG」「动画」词或皮肤过度光滑 | 压句锁「实拍」，皮肤纹理词保留；跑第九节删词表 |
| 磨皮瓷面脸 | 精修写成「完美无瑕」 | 写「柔肤但保留毛孔与绒毛纹理」，负面词带磨皮瓷面 |
| 仙气失控变玄幻大片 | 光尘写满屏、法器高亮爆闪 | 实体件三件为限（法器/纱雾/光尘各一），辉光写「微光」 |
| 穿帮现代物件 | 场景段没锁死形制 | 场景锁定逐镜点名（布景、道具、服装形制） |
| 调色跑向恐怖志怪 | 写了阴森、惨白、冷灰 | 锁「清透月白淡青」，负面词带恐怖青绿 |
| 武打段运镜叠加 | 环绕+拉升+快切同段全上 | 运镜池「一段一主运镜」，冲突词对自查（光学块 §九） |
| H3 正文混中文 | 压句或角色段夹中文 | 压句纯英文；跑 `check_prompt_h3.mjs` 确认 0 warning |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「动画化」与「恐怖化」两侧的词**，保留剧级实拍精修与清透仙气。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| CG render / 3D animation / 动画质感 | live-action、实拍 | 跑向国风电影 3D 档 |
| porcelain skin / flawless / 磨皮瓷面 | 保留毛孔与绒毛纹理 | 精修不等于瓷面 |
| dark grim / 惨白 / 阴森 | clean rim light、清透 | 反串志怪 grade |
| glowing runes everywhere / 满屏符光 | 实体件三件为限 | 仙气失控主因 |
| modern objects / 现代物件 | 古装形制逐镜点名 | 穿帮主因 |

### 9.2 互斥风格

`guofeng-cine-3d`（3D 动画 vs 实拍，渲染方向相反）、`photoreal-pbr`（现代通用写实 vs 古装形制限定）、
`urban-folk-filmstill`（恐怖粗粝 vs 清透精修，grade 相反）、`documentary-live-action`（无修图纪实 vs 剧级精修）。
