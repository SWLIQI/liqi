# 方言与旁白规程

> 本文件管两件事，**性质完全不同，别混读**：
>
> | 部分 | 性质 | 是否设门禁 |
> |---|---|---|
> | 第二节 · 方言 AI 配音总控 12 条 + 第三节 · 方言标注法 | **外挂参考表**（按需查） | ❌ **不设门禁、不参机检** |
> | 第四节 · VO / OS 声画分离红线 | **规则**（交付前必过） | ✅ 人工 + 语义审（机检只兜底可机械判定的部分） |
>
> **方言部分为什么不设门禁**：方言听感是**音质维的形容词叠加**，没有可机械判定的对错——
> 做成一堆「必须出现粤语关键词」的断言，只会逼出「为过门而堆方言词」的假合规。
> 这是 liqi 与上游共同的克制处，**照抄不改成门**。

---

## 一、 定位

- **方言部分**：为台词「语气位」提供**地域口音的量化控制口径**；也用于 AI 配音
  （TTS / 音色克隆）执行前的地域听感校准。**只提供听感描述词，不改变任何既有规则。**
- **旁白部分**：管 liqi 的 **VO（画外旁白）/ OS（画外音）** 写法纪律——
  这不是可选项，是「写错就会穿帮」的硬规则。

**调用方式**：

1. 用户直接点名（「粤语口音的广东老伯」「带点东北味」）→ 查第二节 / 第三节口径，落进语气位；
2. liqi 按人物籍贯 / 场景地域自动查（**仅在用户明确要地域听感时**，不主动加）→ 同 ①；
3. **不需要地域听感时，不要主动加方言标注**——加了就是给模型多一个可以漂的维度。

## 二、 全国方言 AI 配音总控（12 条 · 先读）

> 使用原则：所有方言均以**当地年轻人真实日常口语**为基准。优先控制**地域听感、语调、节奏和语气**，
> 不追求夸张模仿。人物说话必须自然、连贯、清晰，**禁止播音腔、舞台腔、刻意学方言腔**。
> 根据具体城市和人物年龄进行轻重调整。

1. **优先保证地域听感，其次保证台词清晰度。**
2. **人物必须像当地年轻人真实聊天，不像演员表演方言。**
3. **方言不能为了突出地域感而故意拖音、夸张变调。**
4. **禁止普通话播音腔、新闻腔、广告腔、舞台腔。**
5. **禁止把相邻地区口音混合**——西安不能变成兰州，成都不能变成重庆，广州不能变成港台腔。
6. 同一地区不同人物允许存在轻微个体差异，但**核心地域听感必须稳定**。
7. 年轻人物优先采用现代城市年轻人口吻，避免老年人语气。
8. 对**完整方言语言**，保持真实方言音系；对**「本地普通话」类型**，
   则以普通话清晰度为基础叠加轻微地域特征。
9. **台词必须与人物口型严格同步**，发音、停顿、重音与动作自然对应。
10. **禁止 AI 合成音的机械感、字字分离、过度标准化和情绪断层。**
11. **旅游 / 地域类内容不能说成导游播报**，必须像当地人自己在生活中自然说出来。
12. 每个地区的**方言强度默认控制在「明显能听出地域，但不会影响理解」**的范围；
    如果用户指定「纯方言」，再提高方言强度。

### 2.1 分地区速查（听感要点 + 执行要求红线）

> 完整分区词典属**外挂数据表**，liqi **不内置**（v5.9.0 既定裁决：避免维护负担与重复造轮）。
> 需要具体某地口径时，向上游词典按地区条取用。**当前在用的两版外挂词典**（裁决记录见
> `外部Skill吸收裁决总表.md` C04 条）：
>
> - `dialect-voice-control-dictionary.md`（上游 50 套分区，本表速查的底稿）；

>   声调特征 / 语流节奏 / 语气表现 / 口语特征 / AI 执行要求）。
>
> 两版条目整包都是**否定式控制**（「禁止播音腔、小品腔」）——**只能进声音设计层与《配音对齐单》**，
> 照 §3.1 纪律 2 执行：不写进画面描述、不新立 `方言：` 字段。把否定式词条搬进画面正文会直接撞
> `W-NEGATION-IN-BODY`（v5.44.0 由 P0 降为建议级）与「Naming a flaw plants it」铁律（SKILL.md Step 3 第 11 条）。
>
> 下表是**分区分组的通用校准方向**，用于不查表就能给出合理口径。

| 大区 | 听感方向 | 执行要求红线（该区最易演错的方向） |
|---|---|---|
| **华北 / 东北** | 平翘舌区分自然，儿化适量不堆叠；语速中等偏快，语流连贯，爽利松弛 | 禁老北京腔、**禁相声腔**、禁播音腔；东北不演成小品腔 |
| **西北（陕甘宁青新）** | 音高起伏明显，重音突出，句尾收放灵活 | **禁把相邻地区混在一起**（西安 ≠ 兰州）；禁拖长腔调当「特色」 |
| **华东（沪苏浙皖赣）** | 语调平稳细腻，语速中等，咬字清晰，尾音轻收 | 禁止刻意的「软糯」表演感；禁港台腔混入吴语 |
| **华中 / 西南（湘鄂川渝云贵）** | 语速偏快，句尾上扬明显，重音前置 | **成都 ≠ 重庆**；禁把川渝演成一味「麻辣」的夸张腔 |
| **华南（粤桂闽琼）** | 音系独立，入声与鼻音保留，节奏顿挫分明 | **禁港台腔**（广州 ≠ 香港）；闽南 / 潮汕 / 海南各有独立音系，不得混用 |
| **本地普通话型** | 以普通话清晰度为基础，叠加**轻微**地域特征 | 不得为了「像本地人」而牺牲清晰度（总控第 1 条） |

## 三、 方言配音标注法

### 3.1 写在哪里（不新增字段、不新增段落）

方言听感作为**语气位里的「音质」维**叠加——liqi 的语气位本来就是多维描述
（`（扯着嗓子，不急不躁）`、`（气喘吁吁，自来熟）`），方言只是再叠一层：

```text
对白：0:12 王掌柜（重庆话口音，语速偏快，尾音上扬，急性子）：「哪个晓得嘛，账本我一早锁柜里了。」
```

**三条纪律**：

1. **不新增字段**：不得为方言另立一行 `方言：`。方言是语气的属性，不是台词的属性。
2. **不写进画面描述**：画面段写「说了句重庆话」是无效的——模型不据此调音色。
3. **同时写进声音设计段**：涉及配音交付时，在「动作层 / 呼吸层」旁注一行音色校准
   （音色克隆 / TTS 参考），便于后期配音对齐。

### 3.2 强度分级（对应总控第 12 条）

| 强度 | 写法 | 适用 |
|---|---|---|
| **轻**（默认） | `（带点XX味，语速语气不变）` | 只需地域标识、要保清晰度 |
| **中** | `（XX话口音，尾音上扬，语速偏快）` | 地域是剧情要素（如本地人 vs 外地人对照） |
| **纯方言** | `（XX话，纯方言发音，不作普通话收口）` | **用户明确指定**才用 |

### 3.3 与「台词一字不差」铁律的关系

🔴 **方言标注只改听感，不改一个字。** liqi 的台词铁律是**台词冻结后一字不差**——
方言标注是**语气位的附加描述**，不构成改台词。**不得因为「这样更像方言」而改台词用字**
（「那个」写成「那锅」是改台词，不是加标注）。要改写用字，属于 Step -1 剧本层，冻结后不许动。

### 3.4 与赛道的关系

- **赛道① 国内剧 / ② 海外剧**：方言标注照用（② 的目标语言另按语言合同走）。
- **赛道③ 解说叙事类**：**方言只用于「引述 / 采访」这类出现对白的地方**。
  解说主体是旁白，旁白用普通话（**地域听感可用于旁白的「讲述者人设」**，
  但要在声音设计段统一声明，不许逐句漂）。
- **总控第 11 条在赛道③ 尤其重要**：解说本身就是讲述，
  **最容易滑成导游播报 / 新闻腔**——这是解说类最常见的听感翻车。

## 四、 VO / OS 声画分离红线（规则 · 交付前必过）

### 4.1 三个概念的区分（先分清再写）

| 记号 | 是什么 | 说话者在画面里吗 | 锁口型吗 |
|---|---|---|---|
| **对白** | 角色当场开口说话 | 在 | **锁** |
| **VO**（画外旁白 / 心声） | 角色内心独白，或第三方讲述 | 可能在（心声） | **不锁** |
| **OS**（画外音） | 说话者在别处 / 未入画 | **不在** | **不锁** |

liqi 现有写法把它们都放在 `对白：` 行，靠**括注**区分。
**这一节就是规定括注必须写、且必须写对。**

### 4.2 容量红线（赛道① / ② / ④）

| 项 | 上限 | 为什么 |
|---|---|---|
| **VO + OS 镜数占比** | **≤30%** | 画外声是结构件——点缀、引爆画面对比。占比一高，观众会从「看」变成「听」 |
| **VO 口播量** | **60~80 字/分钟** | 超过这个量，画外声就从「点睛」变成「念稿」 |

⚠️ **赛道③ 解说叙事类豁免本节的容量口径**——解说类**全片 VO**，
套 ≤30% 会把稿子判死。赛道③ 改用 `赛道分流.md` 第五节的**解说语速档** +
本文件 §4.3 的**声画信息差纪律**。

### 4.3 OS 不复述画面（声画信息差 · 两条赛道都保留）

> **画外声负责「讲因果 / 讲规律 / 讲人物内心」；画面负责「给证据 / 给场景 / 给过程演示」。**

- **判据一句话**：**把画外声删掉，画面信息量不得减少；把画面删掉，画外声信息量不得减少。**
  两边都要能独立成立、且不互相复述。
- 赛道① / ②：画面与旁白是**并列关系**（旁白不解释画面正在做的事）。
- 赛道③：**允许画面配合旁白**（画面是注释，不是复述）——这是解说与剧情 VO 的唯一区别。
- **两条赛道共同禁止的**：画外声念出画面里已经大字写出的内容（**字幕与旁白不重复**）。

| 违规 | 例 |
|---|---|
| ❌ 复述字幕 | 画面打大字「康熙二十三年」，旁白也说「康熙二十三年……」 |
| ❌ 复述动作 | 画面正在演示篙点船帮，旁白说「他把篙点向船帮」 |
| ✅ 画面证据 + 旁白因果 | 画面给「磨白的黄铜扣」特写，旁白说「这箱子，她抱了十二年」 |

### 4.4 三条硬线（违反即阻断，不是建议）

| # | 硬线 | 为什么 |
|---|---|---|
| **1** | **标了「画外音 / 心声 / 旁白」的行，不得同时要求该角色口型动作** | 一边说不锁口型、一边写「嘴型与台词同步」= 自相矛盾，模型会二选一，出片必穿帮 |
| **2** | **画外声必须写进「对白：」行并带括注标记，不得塞进声音设计的四层混音里** | 四层混音（环境 / 动作 / 呼吸 / 逼近）是**氛围**层，不是台词层；塞进去等于这句台词丢了 |
| **3** | **四个官方声音标记 `<>`（音效）/ `{}`（台词）/ `()`（音乐）/ `【】`（字幕）只能出现在声音段与台词位，不得混进画面描述** | 混进画面描述会让模型把它当画面内容读，直接毁掉该镜 |

### 4.5 与既有结构的接口

| liqi 既有结构 | 本节怎么接 |
|---|---|
| `对白：0:10 老周（扯着嗓子）：「…」` | 对白**照原样**；VO/OS 在同一行加括注 `（内心独白，画外音）` |
| `声音设计（四层混音）` | 四层**照原样**（环境 / 动作 / 呼吸 / 逼近）；**台词不塞这里**（硬线 2） |
| `【时间轴】…｜镜头：…｜音效：…` | 音效照原样；**字幕另走官方 `【】` 或后期烧录**，不与旁白重复 |
| SKILL.md 台词密度红线 ≤4.0 / ≤5.0 / 物理 6.5 | 容量红线是**另一个维度**（**占比与字数**，不是**语速**）——赛道①②④两者同时适用。**赛道③ 容量口径整条豁免**（全片旁白，套 ≤30% 会把稿子判死，见 赛道分流.md 三维表）、**密度卡口 4.0/5.0 也豁免**，换轨为解说语速档 **3.8~5.0**（金句 3~3.6），仅保留 6.5 物理硬闸（v5.43.0 更正：本行旧文「赛道③ 只豁免密度口径」与 赛道分流.md 矛盾，以此为准） |

## 五、 交付前自检清单

**方言部分**（只在用了方言标注时过）：

- [ ] 方言只写在语气位（音质维），没新立 `方言：` 字段、没写进画面描述；
- [ ] 强度默认「轻」或「中」，「纯方言」是用户明确指定；
- [ ] 没为「更像方言」而改台词用字（台词一字不差）；
- [ ] 没混相邻地区口音（西安≠兰州、成都≠重庆、广州≠香港）；
- [ ] 没滑成播音腔 / 相声腔 / 导游播报腔。

**旁白部分**（每次交付都过）：

- [ ] 画外声都带括注标记（画外音 / 心声 / 旁白），没标的一律按对白处理过；
- [ ] 标了画外音的行没同时要求口型同步（硬线 1）；
- [ ] 台词都写在对白行，没塞进四层混音（硬线 2）；
- [ ] `<>` `{}` `()` `【】` 没混进画面描述（硬线 3）;
- [ ] VO + OS 镜数 ≤30%、VO 口播 ≤80 字/分钟（**赛道③ 跳过本条**）；
- [ ] 声画信息差成立：删旁白画面仍成立、删画面旁白仍成立；
- [ ] 赛道③：旁白语速按 **3.8~5.0 字/秒**（金句 3~3.6）、不越 6.5 硬闸。
