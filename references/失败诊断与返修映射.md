# 失败诊断与返修映射（v2.0 补）

生成结果不对时，用这份表定位。**返修纪律说"一次只改一个变量"，但没说改哪个**——
本表补的就是这一环。

---

## 〇、先分层，再定位

不要一上来就改形容词。九成的问题集中在锚定层与时序层，跟文笔无关。

| 层 | 症状特征 | 典型表现 |
|---|---|---|
| **锚定层** | 对象本身不对 | 脸变了、衣服变了、材质变了、色调变了 |
| **预算层** | 对象对，但精度不够或互相打架 | 动作做了但糊、两个主体都糊、细节糊成一团 |
| **时序层** | 单帧都对，连起来不对 | 动作丢了后半、后半段重复、切点错位 |
| **表述层** | 生成结果与描述南辕北辙 | 加了负面词反而出现、运镜反了、画风漂了 |

判据只有一句：**截图看单帧对不对**。单帧不对是锚定或预算问题，单帧对但连起来不对是时序问题。

---

## 〇之二、返修前置纪律：改景别之前，先 grep 整份提示词（v5.35.0 新增）

> 上游来源：phileiny/h3-storyboard-skill §五之二 及其续篇（2026-09-26 系列实测）。

**规则**：任何涉及景别、构图、尺寸的返修，**先 grep 整份提示词里所有提到物件 / 构图 / 尺寸的句子，再动手改。**

两条依据，第二条更阴：

1. **旧文字不会自己消失。** 改「宣告句」却留下照旧设计写的细节句，模型会忠实执行两段——两段互相矛盾，
   出片必然错。实测一天内六次因为这个返工。
2. **景别一变，原本无害的句子会「活过来」。** 「桌上放着杯子」在膝上景别里只是环境交代；
   把景别收紧到胸以上、桌面出画了，这句话就从无害的环境描写变成「模型要凭空画一个桌面+杯子」的指令。

**操作规则**：

```
改景别前：
1. grep 整份提示词里的物件名、构图词、尺寸词（杯 / 桌 / 窗 / 门 / 杖 / 占画面 / 齐 / 切在 / 三分之二 / 一臂……）
2. 逐句问：这一句在新的景别里还成立吗？
3. 不再成立的，要么删，要么显式写「画面外」——不要留着让它跟新景别打架
4. 改完再扫一遍 M 类（audit_literal.py）与 W-SHOT-MULTI-SCALE（check_prompt.mjs）
```

**反面**：直接改景别那句话就重跑。省两分钟，赔八分钟。

## 一、症状 → 原因 → 改什么

按概率排序。**只改第一列的第一项**，改完重 roll 验证，无效才往下走。

| 症状 | 可能原因（按概率） | 第一改什么 | 验证 |
|---|---|---|---|
| 人物脸变了 / 换了个人 | ① 内联外观不全 ② 参考图职责没写"不采用 Y" ③ 一张图同时承担身份与首帧 | 补全内联外观，逐一写五官与轮廓 | 单镜重 roll，只比脸 |
| 服装变了 | ① I2V 写了服装名词 ② 参考图被通用服装覆盖 ③ 内联写了与图冲突的款式 | 删掉全部服装名词，只留颜色+轮廓 | 比服装色块，不比款式 |
| 材质不对（该粗糙的光滑） | ① 只写了抽象词（"高精度"） ② 没锚资产图 ③ 材质与保真预算冲突 | 换成可观测特征（起毛/反光/起皮）+ 锚图 | 截帧放大看表面 |
| 全片色调散了 | ① 没声明色彩预算 ② 声明了但每段各写一套 ③ 参考图色调被继承 | 补齐每镜"色彩预算"行，全片统一 | 抽三镜并排比色 |
| 动作只做了一半 | ① 一拍塞了多个动作 ② 段太长 ③ 动作描述是状态不是动词 | 按 W-ACTION-DENSITY 拆拍，一拍一动作 | 逐拍核对动作数 |
| 后半段重复 / 循环感 | ① 节拍供给不足（段数 < 时长档下限）② 末拍无收束定格 ③ 单条 >20s 且三条件不齐 ④ 末拍 >8s | **先补节拍密度 → 再补末拍收束定格 → 最后才滑窗拆分**（v5.19.0 返修顺序；权威 `references/长段放行与段缝成本对账.md` §八） | 看后半是否与前半**同构**（同起止点/同路径且无新事件＝循环；减速收势、有新信息＝合格长段，别拆） |
| 一段里两个运镜打架 / 画面抖 | ① 混用运镜原语群 ② 段内景别变化（"中景转全景"） | 一段只留一个原语群，变化改写成运镜动词 | 看段内有没有二次运动 |
| 运镜方向反了 | ① 方向词含混（"摇"没写左右） ② 中文面对英文方向词响应不稳 | 写全"缓速水平右摇"，不用简写 | 逐段核对方向 |
| 台词口型对不上 | ① 台词密度 >5.0 字/秒 ② 一拍里既说话又给反应 ③ 没写三态 | 按密度红线精简台词或拆段 | 数段落字数 ÷ 秒数 |
| 两人站位每镜都在变 | ① 没写轴线声明 ② 写了但每镜各定一次 ③ 跨镜没比对 | 补轴线行，一场戏只建一次轴 | 台账逐镜比对轴线行 |
| 反打视线不匹配 | ① 只写了躯干朝向没写视线 ② 反打忘了反向 | 躯干朝向与视线分开写，反打反向 | 见轴线与反打规则第四节 |
| 画面出现可读文字 | ① 正文写了屏幕内容 ② 没声明"后期合成" | 屏幕一律写"纯色块，内部空白供后期合成" | 逐帧扫文字 |
| 主体被背景吃掉 | ① 没写色彩预算导致背景抢色 ② 保真预算主项押错 | 保真预算主项改押主体，背景写"熔成色块" | 看主体与背景明度差 |
| 过审被拦 | ① 写实血腥 ② 负面提示词里含高危词 ③ 描述过于直白 | 先换风格（皮影/剪纸/水墨/版画） | 跑 audit_risk.py 看分数 |
| 整体画风漂移 | ① 风格锚轨道与逐镜冲突 ② 参考图风格职责未声明 ③ 内联画风句不全 | 逐镜内联补"画风一句话" | 首尾镜并排比 |

## 二、返修决策树

```
结果不对
 ├─ 单帧就不对？
 │   ├─ 对象本身变了      → 锚定层：补内联 / 删服装名词 / 补"不采用 Y"
 │   └─ 对象对但精度差    → 预算层：重分保真预算，主项押回主体
 └─ 单帧对，连起来不对？
     ├─ 动作丢后半        → 时序层：拆拍 / 拆窗
     ├─ 后半段重复        → 时序层：先查密度 → 再查收束 → 最后才滑窗拆分（v5.19.0，见长段放行 §八）
     └─ 结果南辕北辙      → 表述层：查否定式、查运镜原语群、查骨架混用
```

改完必须重跑 `check_prompt.mjs`。连改 2 次仍失败，回到 Step 4 重新分层，不要继续加词。

---

## 三、禁止的返修动作

一、**加更多形容词**——稀释权重，越改越糊。
二、**加负面词**——Naming a flaw plants it，且平台审核同样扫负面词。
三、**一次改两个变量**——出了问题无法归因，下次照犯。
四、**反复重 roll 同一份提示词**——重 roll 是重采样，不是改提示词。
   同一份词重 roll 3 次都不对，说明词本身有问题，回去改词。
五、**靠堆质量词补救**（"4K""超清""杰作"）——不产生画面，只占预算。

## 四、与机械门禁的分工

| 工具 | 能查 | 查不了 |
|---|---|---|
| check_prompt.mjs（H3 面 check_prompt_h3.mjs） | 单镜格式、时长、站位、台词密度、参数污染 | 跨镜一致性、生成结果对不对 |
| audit_literal.py | 画面表述抽象九类、高敏感画面 | 除表述外的一切 |
| audit_project.py | 台词与剧本一致性、资产锚覆盖、角色漂移 | 画面质量问题 |
| audit_risk.py | 过审风险词 | 除审核外的一切 |
| check_style.mjs | 风格串轨、压句逐字复用、配色句、假绿防线 | 画面质量与跨镜一致性 |

生成结果类的问题机械门禁都查不了，只能走本表的分层诊断。
