## 〇、 v5.8.0 改了什么

旧版只有「五段结构 + 三码机检」——基础不差，但**没成体系**：同样的写法拿去拍文艺片的推搡和玄幻大招，
出来的东西都不对。本次补的是**分档 + 节奏负载 + 冲击分级 + 豁免表**。

| 新增 | 解决什么 |
|---|---|
| **R0~R3 四档定档** | 所有打戏共用一个高燃套路 → 文艺片被逼着拍爆炸 |
| **默认档按项目类型定**（不是 R2） | 倒车防护核心：liqi 用户做文艺片 / 毕设 / 公益片，默认商业高燃会反向伤害 |
| **IAU 渲染负载上限** | 一镜塞 4 个动作 → 模型只渲染第一个，其余丢失 |
| **镜内速度四拍** | 只有镜与镜之间的节奏维度 → 全片匀速位移，机检查不出 |
| **冲击帧三级 + 减速器配额** | 白闪/定格/慢镜滥用到处都是 → 节奏被自己的减速器拖垮 |
| **豁免表（一开始就建）** | 护栏原型取自「一对一贴身互殴」，外推到群战/追车/法术对轰会失真——**不要等撞了再补** |

**保留不动**：五段结构（生物力学 / 连招链 / 接触点 / 武器锁 / 血腥尺度）与三码机检口径全部保留，
本次是往上加，不是替换。

## 一、 四档定档（先定档，再动笔）

| 档 | 名称 | 适用 | 开局 | 近景机枪对招 | 气爆 / 特效 | 终结定格 |
|---|---|---|---|---|---|---|
| **R0** | 文戏 / 无打戏 | 文艺片、纪录、公益、毕设、纯文戏 | 不适用 | 不适用 | **禁** | 不适用 |
| **R1** | 写实克制 | 写实格斗、悬疑暗杀、追逐、喜剧打斗、儿童向 | 1.5s 内发生接触即可 | 可选 | 不强制，以真实受力反馈为主 | **允许收势 / 悬念收尾** |
| **R2** | 商业高燃 | 多数短剧 / 漫剧打戏 | **必选 0.5s 硬撞** | 必选 1 段 | 必选 | 必选高潮定格 |
| **R3** | 玄幻大招 | 仙侠 / 二次元 / 特效向 | 必选 | 必选 | 拉满 | 必选最高燃定格 |

**R0 是 liqi 特有新增**（上游三档体系没有）。它的作用不是"少做一件事"，而是**让「没打戏」成为一个显式声明**：
包里写了 R0，即使出现推搡、争执、拉扯这类词，也不跑打戏门。不写 R0 而正文里有打斗词，
机检按 TIER-UNDECLARED 报错——**这正是要逼出来的那句话：你到底要不要打。**

### 定档纪律（四条）

1. **未定档不得动笔写打戏。** 声明写在段头：`【打戏声明】：R2 · 一对一贴身`（档位 + 戏型，戏型可选）。
2. **默认档按项目类型定，不是 R2**：

   | 项目类型 | 默认档 |
   |---|---|
   | 文艺片 / 纪录 / 公益 / 毕设 / 广告产品片 | **R0 或 R1** |
   | 商业短剧 / 漫剧 / 竖屏爽剧 | **R2** |
   | 玄幻 / 仙侠 / 二次元特效向 | **R3** |

   **这一条是倒车防护的核心**：upstream 体系把 R2 设为默认，因为它的样本全是商业漫剧。
   liqi 的用户构成不同——默认 R2 会逼着毕设短片去拍气爆与终结定格，那是反向伤害。
3. **一集同一场战斗原则上单档**；混档须写明切换点（`切换点：8s 起升 R3`）。
4. **R1 档不套用高燃套路**（不硬塞气爆与终结定格）；**R3 档切换法术语言**
   （法宝媒介 + 五行术法 + 术法攻防 + 能量具象化），不硬套武侠物理打斗。

## 二、 打斗编排五段结构（保留，v4.4 立）

每段打斗镜按此五段写，顺序固定。写法全部落在「模型能演出来」的层，不写风格形容词。

### 第 1 段 生物力学与身体规格

指名流派和它的生物力学，不写 epic fight scene 这类空词。

```
生物力学：authentic Taekwondo biomechanics——真实解剖、体重约 70 公斤、重心落在后脚、
每一次出腿都带髋部转动与膝盖伸展的完整链条，落地有缓冲
```

流派词决定动作词汇：Taekwondo 的腿法链、boxing 的拳法链、剑戟的斩击线各不相同。
**不指名流派，模型会在它知道的一切武术之间取平均，还你一套广播体操。**

### 第 2 段 逐拍连招链

招式写成链，不写单摆姿势。链的要素：进攻 → 格挡 → 反击 → 重新占位，逐拍交替。

```
连招链：直拳接勾拳接低扫；对方滑步下潜封挡，随即反击体踢；
双方持续进攻——不待机、不摆架子、不重置、不瞬移、不跳位
```

**「双方持续进攻」这句必写**：不写，模型会让两人轮流站定亮相，打出来像慢动作回合制。

### 第 3 段 接触点与镜头轴线

接触点是打斗镜的生死线：**不写接触点，结果是两个人在彼此附近挥舞，永远打不到。**
每个接触点写清「谁身体的哪个部位 / 武器的哪个部位，击中 / 架住 / 磕开对方的哪个部位」。

镜头绕接触点转，并写明是镜头和背景在转，不是人物无意义自转。

轴线沿用 liqi 通用层三态（建立 / 保持 / 跨越），但打斗镜多一条硬要求：
**左右关系翻转一次，打斗就散了**——打斗镜默认全程保持，确需跨越时在转场注记表里写明过渡方式。

### 第 4 段 武器锁

武器数量、握持位置、部件连接三件事锁死：

```
武器锁：全场共两把刀；手只握在鍔之后的柄上；刀身、鍔、柄、鞘、房饰的连接在每个镜头里都不变
```

空手镜免此段。道具变体（断刀 / 脱手）按 liqi 道具状态变体处理，不算武器漂移。
（持物左右手另见 `空间层_调度与轴线.md` 与台账人物账「道具持拿」项——**哪只手持刀由台账管，
本段管的是刀本身长什么样**。）

### 第 5 段 特效与血腥尺度，以及负向

血腥尺度必须显式声明——**不声明，安全过滤会把整段削软**。尺度两档：

- 无血档：`No blood`，打击反馈用黑色数字粒子、故障碎片、尘土替代（赛博之刃案例写法）
- 有血档：限定部位与形态（伤口只在指定位置、不流成面），配 liqi 质控层的高敏感五手法兜底

负向必含布娃娃禁令：

```
Must not：ragdoll / limp / floppy——核心始终发力，每个动作都有肌肉意图
```

**禁布娃娃化是实测头号坑**：不写 NEVER ragdoll，被击退方会变成软体布偶，前半段的生物力学全部作废。

## 三、 渲染负载上限：IAU（Independent Action Unit）

### 3.1 定义

**IAU = 一次独立可命中的打击或位移动作。** 词表（机检 `COMBAT_IAU` 用**族**去重，
同一次接触的多写只算 1 个）：

| 族 | 词 |
|---|---|
| 斩击 | 撩斩 斩中 劈中 劈碎 劈开 竖劈 剪斩 砍中 |
| 突刺 | 刺中 捅入 挑刺 扎入 |
| 横扫 | 横扫 扫腿 扫堂 扫中 |
| 踢击 | 踢中 踹中 顶中 膝顶 点中 |
| 砸击 | 砸中 砸在 砸下 轰中 捶中 肘击 |
| 撞击 | 撞中 撞碎 撞在 撞穿 撞上 撞击 |
| 擒拿 | 抓住 揪住 扼住 勒住 擒住 攥住 掐住 制住 |
| 格挡 | 格挡 架住 架开 格开 磕开 硬接 硬扛 对撞 交击 兵器相击 |
| 投掷 | 扑击 震飞 甩出 摔倒 撂倒 掷中 拍飞 |

### 3.2 上限（上限型判据 = 不许过载）

| 镜长 | IAU 上限 | 依据 |
|---|---|---|
| ≤ 2s | 2 | 单秒绝不超过 3 的保守化 |
| 3s | **2** | 实测：3s 内塞 5 个 → 模型只渲染第一个 |
| 4s | 3 | |
| 5s | 3 | |
| ≥ 6s | 4（每 +3s 放宽 1） | |

**为什么 3s 只能是 2 而不是 3**：模型在 3 秒内可靠渲染 2~3 个 IAU，但超过 2 个之后
保质率骤降。留 1 个冗余 → 定 2。违反此条的症状**可辨识**：多动作稿出片必现
「贴脸互殴 + 后半段动作消失」。

### 3.3 一镜一主任务

每镜只能有 **1 个主任务**，六选一：`证规模 / 证力量 / 证速度 / 证招式 / 证招式轨迹 / 证情绪`。
判据：若某镜 IAU 跨 **≥3 个族**，即判一镜多任务。

## 四、 镜内速度四拍（起 → 爆 → 顿 → 收）

**每一镜内部**必须具备下列节拍，顺序不可颠倒。旧版只有「镜与镜之间」的节奏维度
（五维交替 / 每 5~8 镜一个节奏波），**全片四镜都写匀速位移它也查不出**——这是补的那一维。

| 拍 | 语义 | 时长占比 | 词 |
|---|---|---|---|
| **① 起（慢）** | 蓄力 / 预备 / 重心下沉 / 微调站位 | 15~30% | 沉肩 压低重心 绷紧 屏息 蓄 预备 屈膝 后仰 重心下压 拧腰 |
| **② 爆（快）** | 蹬地暴起 / 骤出 / 疾掠 | 极短 | 暴起 骤然 猛地 瞬间 陡然 疾掠 扑上 冲出 甩出 弹射 蹬地 |
| **③ 顿（停）** | 命中瞬间画面时停 | **2~3 帧** | 顿住 时停 顿帧 定格 凝固 压在 戛然 |
| **④ 收（慢）** | 卸力 / 稳住 / 滑步 / 落地缓冲 | 20~35% | 卸力 稳住 侧滑 滑退 收势 滑步 落地缓冲 后撤 站定 单膝 |

**顿拍是全片最关键的一拍**：命中瞬间画面定住 2~3 帧，是「打到了」的唯一视觉证据。
**缺顿拍 = 观众没看见击中 = 再多动作也读作在乱动。**

**逐镜判定，不用「全片总数 ≥ 镜数」口径**——后者下「镜头 1、4 全空 + 镜头 2、3 各塞两处」
总数照样够，一处写满、一处全空能蒙混过关。

⚠️ **统计要剔除纯结构标注**：`（起手拍，慢）`这类括号标签是给人看的结构说明，
计入命中 = **护栏被自己的标注喂饱**。只剥离 ≤6 字的纯结构标签，
含实写正文的括号块（如`（命中瞬间画面顿住两帧，命中点炸开一圈冲击波）`）必须保留。

## 五、 冲击帧三级 + 减速器配额

### 5.1 冲击帧三级

| 级 | 用在哪 | 写法 |
|---|---|---|
| **一级** | 关键瞬间 | 特写 + 冲击帧（命中点炸开一圈冲击波） |
| **二级** | 强力命中 | 命中定住 2~3 帧 + 位移结果（撞塌、嵌入、倒飞） |
| **三级** | 大招 / 终结技 | **3 帧白闪**，**同场仅 1 次** |

### 5.2 减速器配额（黑白闪 / 定格帧 / 慢镜）

**三者都是「减速器」——用一处就从快拍时间里扣一处。**

| 片长 | 黑白闪 | 定格帧 | 慢镜 |
|---|---|---|---|
| 15s 片 | ≤1 | ≤1 | ≤1 |
| 30s 片 | ≤2 | ≤2 | ≤2 |
| 短于 8s | 允许 1（招牌不省） | 建议全砍 | 建议全砍 |

**黑白闪写法硬条**：必须写成**自然画面句**，严禁术语标签 ⛔ `★插入黑白闪 #1`、`<黑白闪 2帧>`。

**上限（本节）与下限（激烈度护栏）成对使用**：只压下限 → 节奏失控；只压上限 → 打戏发闷。

## 六、 对抗激烈度六条硬护栏（治「站桩摆拍」）

> 实测病征：出片后逐帧看，**每 2~3 秒只有一个静态构图**——对峙 → 特效 → 对峙 → 特效，
> 全程零贴身对招，看着燃其实什么都没发生。根因：提示词给了时码分段，
> 但**没强制同一段内必须有位移与接触**，模型遂把每个时间区间理解成一张画。

| # | 护栏 | 判据 |
|---|---|---|
| ① | **每段必含位移 + 接触** | 每个时间区间内双方都必须发生身体位移（冲刺 / 滑退 / 翻滚 / 腾空 / 被击飞），且至少一次实体接触。⛔ 严禁某区间只有「站着 + 发光」 |
| ② | **相邻两段不许同构图** | 相邻时间区间的机位或双方相对位置必须变化。⛔ 严禁连续两段都是「两人隔着距离对视」 |
| ③ | **贴身对招占比下限** | 15s 片真正贴身缠斗 ≥5s；30s 片 ≥10s。**「隔空对波」不计入** |
| ④ | **禁止摆拍动词** | ⛔「兵器抵住对手面部」→ ✅「兵器捅入对手肋下，对手横飞撞塌半面墙」 |
| ⑤ | **自检判据：抽掉特效** | 抽掉所有特效后剩下的纯动作应能连成一段打得起来的武打；只剩俩人站着 → 不达标 |
| ⑥ | **隔空对波的定位** | 隔空对波 = 双方站立不动、各放能量光束在空中相撞。看着燃，实则零接触零位移。**仅允许两处**：㈠ 高潮大招释放瞬间（1~2s，作收束点）；㈡ 短暂反制（≤0.5s，且紧接着必须贴身） |

### 节奏零件库（六件，看清必选 / 可选）

| 零件 | 功能 | 取用 |
|---|---|---|
| **蓄** | 对峙蓄势（低机位暗部起画、气机锁死；**0.5s 内兵刃必须已破空逼近**） | ◇ 推荐起手；很短的片可直接用【快】起手 |
| **快** | 贴身交锋（近身攻防对拆、**双向受力**） | ★ **必选**，可重复取用 |
| **停** | 战局反转（变招破防 / 主角挂彩 / 底牌掀开） | ◇ 有反转才用 |
| **慢** | 情感升华（升格聚焦决然眼神） | ◇ 属减速器，15s 内建议不用 |
| **静** | 万籁俱寂（定格 + 黑白闪 + 声浪归零） | ◇ 大招前想造压强就用 |
| **爆** | 绝杀降临（全屏闪白 + 收束协议，定格最燃瞬间） | ★ **必选** |

**组合三铁律（唯一不可动的骨架，只管首中尾）**：
① 起手必须有形——开场 0.5~1.5s 内出现兵刃破空逼近或物理接触，禁全景无人风景慢热；
② 中段必须有来有回——至少 1 段【快】且双向受力，禁单向殴打沙包；
③ 结尾必须有落点——必须取用【爆】，**严禁平缓收尾帧**（收刀入鞘 / 微风吹发）。

**参考范式**（可拆可改，禁止当模板照套）：A 经典反杀 蓄→快→停→快→慢→静→爆；
B 快打碾压 快→快→停→爆；C 双强对攻 快→停→快→停→爆；D 蓄势一击 蓄→静→爆（5~8s 超短片）；
E 群战乱斗 快→快→快→停→爆。

## 七、 15s 打戏段自评（四维加权，**仅自评，不作交付门禁**）

    完播潜力 = 0.20×开局吸引力 + 0.30×节奏呼吸 + 0.25×运镜丰富度 + 0.25×情绪拐点

| 维度 | 权重 | 硬指标（R2 / R3 档） |
|---|---|---|
| 开局吸引力 | 20% | **0~1.5s 内必须发生攻防接触**（R2/R3：0.5s 内出现两种对立招式的正面硬撞 + 命中微停顿）。第一帧建议双人同框中近景，禁远景风景慢热 |
| 节奏呼吸 | 30% | 快慢交替，**同节奏连续 ≤5s**；用命中瞬间 1~2 帧微停顿制造反差，**禁用慢镜/升格** |
| 运镜丰富度 | 25% | **同运镜 ≤2s，同景别 ≤3s**；终结招式用三段式运镜（低仰蓄力 → 俯冲跟随 → 碰撞定格） |
| 情绪拐点 | 25% | **8~12s 区间必须出现一次**局势逆转、破防爆发或破绽抓取 |
| 以高潮收尾 | 核心 | R2/R3：**禁 0.5s 平缓收尾帧**；最后一帧停在终结技命中 / 重创失衡 / 冲击波炸裂 / 嵌墙的最高潮定格。**R1 允许克制收势或悬念收尾** |

> ⚠️ 这是创作者自检用的**加权启发式**，衡量完播潜力，不是真实完播率预测模型。
> **不做成门禁**：打分需要语义理解，做成门就是假绿门——与 liqi「身份判定不做成门」同一取舍。

**总纲铁律**：**AI 视频没有静止表演能力。** 任何「对峙 2 秒 / 蓄势待发 / 留白 / 悬停」
类静止段都会被渲染成角色呆立。**一切情绪与蓄力必须在运动中完成**——边打边蓄、上升途中蓄、
后撤中蓄；神态挂载在动作瞬间（甩剑转身时冷笑），不单独成段。
**唯一允许的「定格」是命中瞬间 1~2 帧微停顿。**

## 八、 终结技三幕 + 大招运镜 + 特效生长

### 8.1 三幕（破局 → 绽放 → 余震），禁止一击直接结束

| 幕 | 时长 | 内容 |
|---|---|---|
| **破局** | 0.5~1.0s | 化劲借力破防 / 重击破格 / 下盘破坏 / 入身绕背 / 时空截击——打破攻防平衡，制造绝对破绽 |
| **绽放** | 1.5~2.5s | 凌空下劈 / 贯穿式寸劲 / 多段旋风连斩 / 神兵神能绝杀——大招全力输出，视觉巅峰 |
| **余震** | 1.0~1.5s | 地面蛛网龟裂 / 环形冲击波 / 受击者形变嵌墙 / 终帧定格——**严禁加 0.5s 平静收势** |

**视觉巅峰五要素必须同时爆发**：大幅动作 + 快节奏 + 全景/中景空间 + 特效生长 + 三段运镜。
缺任何一条都会视觉降级（缺大幅动作 → 全景空洞；缺快节奏 → 拖沓；缺全景 → 看不到张力；
缺特效生长 → 没爆点；缺三段运镜 → 像舞台剧摆拍）。

### 8.2 大招运镜 11 模式（模式 A~K，按档取用不必全用）

| 模式 | 名称 | 镜头规格 |
|---|---|---|
| A | 低仰蓄力 | 全景/中景 · 正面 30° 仰视 · 慢推 · 跟随蓄力能量 |
| B | 轨迹拖尾 | 中景/全景 · 30-60° 斜侧平视 · 跟拍 · 跟随肢体/刃光末端（拖尾 ≥ 身高 1.5 倍） |
| C | 双色咬合穿透 | 特写/微距 · 急速推镜 · 推进至接触点定格 0.2s |
| D | 全景冲击波 | 全景 · 30-45° 斜拍 · 急速拉镜 · 以碰撞点为圆心 |
| E | 不对称压迫 | 中近景 · 跟拍 · 压制方能量铺满大半屏幕 |
| F | 翻摔全肢展开 | 全景 · 跟拍 · 跟随被摔者翻转弧线 |
| G | 元素对称对峙 | 中景 · 环绕（≤180°） · 以两人为圆心 |
| H | 角色签名地面 | 中景/全景 · 45-60° 斜俯 · 升降 · 跟随胜者能量向地面蔓延 |
| I | 攻击部位冲镜 | 极端特写 · 极速推镜 · 推进至拳面前 0.3 米骤停 |
| J | 三段打腹终结 | 中近景斜仰慢推蓄力 → 近景急速上跟拍发力 → 中景 45° 斜侧命中定格 |
| K | 力量交换链 | 中景双拳对撞 → 弧形重击跟拍 → 极端特写血沫 → 近景头部后仰 |

### 8.3 特效生长三段论（时间维度）

大招特效**绝不能「啪」地直接满屏**，必须由内而外生长：

1. **萌芽 0.3~0.5s**（攻击启动）：出招点泛起微弱但清晰的高亮星芒或气旋
2. **生长 0.5~1.0s**（位移蓄力）：能量沿轨迹膨胀，密度亮度梯度倍增，向核心收束
3. **绽放 0.2~0.5s**（命中瞬间）：接触点引爆，环形冲击波 / 满月光刃 / 地裂气浪
4. **余韵 0.3~0.5s**（环境留痕）：焦痕冒烟、冰晶飘散、热扭曲久久不散

**段落分配**：前段（0-3s）一招一炸、开局亮眼即收；中段（3-12s）连打零特效保持干净、
收尾重击带特效；后段（12-15s）特效生长全开。

### 8.4 呼吸帧与急停弹射

    急停弹射 = 前置高速密集对攻(≥1.5s) → 瞬间极慢/定格呼吸帧(0.3~0.5s) → 绝杀爆发

**没有高速铺垫的定格是无聊停顿**；只有在高速机枪对攻后突然插入 0.3s 极慢镜头
（汗珠滞空、眼神精光一闪、发丝悬停），速度差才形成「情绪弹簧」，把观众弹射进最终大招。

## 九、 豁免表（★ 一开始就建，不要等撞了再补）

> **为什么必须先建**：本文件 §三~§六 的量化口径——`3s 镜 ≤2 个 IAU` / `逐镜四拍` /
> `全身档 ≥ 半数镜` / `贴脸档连续 ≤2 镜`——**原型全部取自「一对一贴身互殴」**。
> 外推到群战 / 枪战 / 追车 / 法术对轰 / 大场面会**反向压制**：把本该连排的近景对招拉开成远景、
> 把连招拆成单招、给每镜硬塞慢动作 → 观众读到的就是「呆板」。
> 这不是护栏不够严，是**把单一戏型的量化线当成了全戏型的法规**。

**用法**：段头声明里写戏型，机检按本表放行：`【打戏声明】：R3 · 术法对轰`

| 戏型（先定档） | 豁免的码 | 放行口径 |
|---|---|---|
| **R0** 文戏 / 无打戏 | 全部九码 | 显式声明 R0 后不再跑打戏门 |
| **群战 / 混战 / 围杀 / 对军**（R2/R3） | IAU-OVER、FULLBODY（跨镜全身档） | 靠镜头快切与空间调度替代贴身，不按单镜 IAU 上限与全身档半数控 |
| **枪战 / 狙击 / 暗杀 / 追车 / 儿童向**（R1） | CONTACT-MISSING、FULLBODY、护栏①③⑥ | 交火本质是**中远距**：允许一方静止（据枪/瞄准/潜行），允许**零实体接触**；不得硬塞贴身 |
| **术法对轰 / 远程法术 / 法阵 / 对波 / 万剑归宗**（R3） | CONTACT-MISSING、FULLBODY、护栏③⑥ | 对波/对轰是玄幻档**合法主武器**，不按「用特效冒充激烈」处理 |
| **大场面**（法相 / 法天象地 / 巨兽 / 对军清场） | IAU-OVER、FULLBODY、BEAT-MISSING | 宏观调度：允许整段大远景/全景；「站定施展术法」是**施法**不是躺平 |
| **近景机枪对招 / 连招段**（R1/R2） | IAU-OVER、BEAT-MISSING（改段落级一次） | 连招本就是序列化招式链，按「每 2 秒主动作 ≤3」节点口径执行；贴脸档连续上限放宽至 ≤4 镜 |
| **【静】【慢】零件所在镜**（全档） | 护栏①「站着发光」 | 【静】＝完全静止定格、【慢】＝升格，**是设计**，不判躺平 |

### 保底（豁免之后仍然成立的三条，不放行）

1. **不得整场零接触、零位移、无收束**（「对峙 → 站着发光 → 对峙」的空转模板）；
2. **相邻区间的机位不得完全相同地连排 ≥3 段**；
3. **不得为消除告警而把打戏改呆**——⛔ 禁止拆掉招式序列、把连续近景对招拉开成远景、
   给每镜硬塞慢动作、把大场面写成一镜一动作。**那是把「呆板」当合规。**

**一句话：豁免的是「量化上限」与「几何模板」，不是「打得起来」本身。**

## 十、 时间冻结与物理奇观（五拍骨架）

这条是边界澄清，不是新规则：liqi 通用层禁「闪回 / 叠化 / 转场」这类**剪辑语**进正文
（audit_literal 的 F 类），因为那是后期工序、模型不认。时间冻结恰恰相反——
`time locks completely` 是**生成指令**，是画面里真实发生的物理状态，合法且必须写进正文。
判定口径：禁的是「告诉剪辑师怎么剪」，不禁止「告诉模型生成什么物理状态」。

五拍骨架，每拍一段，保留拍序、替换物理材质：

1. **年代与质感行**：时代、现场灯、颗粒、手持能量
2. **第一拍常态**：把那个豁免角色立成从容、略带无聊——这个态度是整套效果的叙事支点
3. **第二拍碰撞**：事故炸开，所有东西被抛起
4. **第三拍冻结**：`time locks completely`，所有人的脸定住，只有豁免角色还在动
5. **第四拍环绕**：慢慢绕冻结场景一整圈，把悬浮细节逐一点名（液体挂成玻璃质飘带、
   有真实表面张力的完美球体、单根头发悬空、托盘还在原地自转、面孔锁在惊愕表情上）
6. **第五拍倒放与消解**：一切精确倒回起始位置（受控而优雅，不是解到随机状态），
   用一个轻的随手动作收尾（抬两根手指随意招手、拆开一片口香糖嚼起来）

四条实测坑：

- **把冻结写成慢动作**，得到的是慢动作不是静止——写 `time locks completely`
- 环绕给的时间太短——餐厅案例用九秒走完一整圈，悬浮细节才看得清
- 拿重物或会碎裂的东西当冻结材质——液体和轻物件在冻结帧里比碎片扛得住得多
- 顺手把豁免角色也冻住了——每个冻结拍里都要重申这个人还在动

## 十一、 机检九码（W-COMBAT-*，check_prompt.mjs）

打斗镜识别：标题含 打斗 / 交手 / 缠斗 / 对决 / 混战 / 厮杀 / 格斗 / 大战 / 激战，
或正文出现流派词（taekwondo / boxing / 剑道 / 武术 / 格斗 / 搏击…）。

| 码 | 级别 | 判据 | 处置 |
|---|---|---|---|
| **E-COMBAT-TIER-UNDECLARED** | **ERROR** | 打斗镜段头无 `【打戏声明】：R0~R3` | 补声明。**不允许默认档**——定档是倒逼出来的那句话：你到底要不要打 |
| W-COMBAT-CONTACT-MISSING | WARN | 正文无任何接触点词 | 补接触点：谁哪个部位击中对方哪个部位 |
| W-COMBAT-RAGDOLL-GUARD | WARN | Must not 无布娃娃禁令（ragdoll / limp / floppy / 布娃娃 / 软绵绵） | 负向补「禁布娃娃、核心始终发力」 |
| W-COMBAT-CUTS-TOO-MANY | WARN | 段数 > 秒数 ÷ 2.5 | 并段：一次接触一个主动作 |
| **W-COMBAT-IAU-OVER** | WARN | 单镜 IAU 族数超 §3.2 上限 | 拆镜或删动作（3s 塞 5 个，模型只渲染第一个） |
| **W-COMBAT-BEAT-MISSING** | WARN | 镜内速度四拍缺拍（起/爆/顿/收） | 补拍；**顿拍最不能缺**——没有命中顿帧，观感必然糊 |
| **W-COMBAT-HITSTOP-EXCESS** | WARN | 黑白闪 / 定格 / 慢镜 超 §5.2 配额 | 减速器是扣快拍时间的，用一处扣一处 |
| **W-COMBAT-NO-FORCE-CHAIN** | WARN | 有重击词（劈中 / 砸中 / 轰中 / 撞穿）却无动力链推导（蹬地 / 转胯 / 拧腰 / 沉肩 / 髋部 / 重心） | 补发力链：力量从哪来、经哪传导、落在哪 |
| **W-COMBAT-BEAM-FILL** | WARN | 出现隔空对波类词（能量光束 / 对波 / 气功波 / 冲击波对撞 / 隔空）且无贴身接触词 | 对波只允许两处：高潮释放 1~2s、短暂反制 ≤0.5s 且紧接贴身 |

**跨镜两项在 `audit_project.py` 的 S 门**（打戏包才跑）：
**S23 全身景别不足**（每 2 镜至少 1 镜全身档，中全景/中景/全景/大远景）、
**S24 贴脸档连排 >2 镜**（特写 / 近景 / 中近景连续第三镜必须切回全身档）。
——打戏的说服力来自**身体力学**，全身档是唯一能同时看见「重心」与「位移量」的景别。

> **只有 TIER-UNDECLARED 是 ERROR**，其余八码是 W 级。编排深度是审美与连续性判断，
> 脚本只拦「明显没写」的；但**档位必须声明**，那是能不能开始写的前提。

## 十二、 自检清单（打戏镜交付前九问）

1. 声明档位了吗？（R0~R3 + 戏型）
2. 流派与生物力学写了吗？（不写 → 广播体操）
3. 每个接触点写清「谁哪个部位击中对方哪个部位」了吗？
4. 「双方持续进攻」写了吗？（不写 → 回合制亮相）
5. 单镜 IAU 族数超上限了吗？（3s 只能 2 个）
6. 这一镜有「起—爆—顿—收」吗？**命中顿住了吗？**
7. 减速器用超配额了吗？（15s 各 ≤1）
8. 抽掉全部特效，剩下的纯动作连得成一段打得起来的武打吗？
9. 全身档够吗？贴脸档连续超 2 镜了吗？

## 十三、 失败模式

| 症状 | 根因 | 处方 |
|---|---|---|
| 打戏像回合制亮相 | 没写「双方持续进攻」 | 连招链段补上，禁「不待机/不摆架子/不重置」 |
| 两人互相挥舞永远打不到 | 无接触点 | 补接触点（五段结构第 3 段） |
| 出片「贴脸互殴 + 后半段动作消失」 | IAU 超载 | 拆镜或删动作（§3.2） |
| 观感糊、看不出打到了 | 缺顿拍 | 命中瞬间定住 2~3 帧（§四） |
| 全片匀速位移、呆滞 | 只有镜间节奏，无镜内四拍 | 逐镜补起/爆/顿/收（§四） |
| 看着燃其实站着发光 | 隔空对波充数 | 按 §六·⑥ 只留两处，其余改贴身 |
| 节奏被自己的特效拖垮 | 减速器超额 | 按 §5.2 配额砍 |
| 被击退方变软体布偶 | Must not 无 ragdoll 禁令 | 补负向（五段结构第 5 段） |
| 文艺片被逼拍爆炸 | 默认档错配 | 按项目类型定档，改 R0/R1（§一·2） |
| 群战被拆成一招一镜、呆板 | 护栏外推失真 | 声明戏型走豁免表（§九） |

## 四、打戏 Clip 合同（v6.13.0 · C33-A4，来源 script-writing-studio-v2 04f 打戏导演——机制参考零拷贝）

**什么时候填**：R2（对抗）与 R3（大战）打戏，**每场一纸**；R0/R1 不用。填完回填分镜
（动作链拆进镜行），并把「段末状态」交给连续性台账与 06 硬锁——合同是分镜与提示词的中间凭据，
不是交付物本体。

**合同七栏（逐场填写，缺栏不算立约）**：

| 栏 | 填什么 | 反的什么事故 |
|---|---|---|
| ① 战斗目的 | 这场打戏在剧情上改变什么（夺物 / 逃脱 / 击溃 / 暴露）——写不出目的的打戏先砍 | 为打而打的模板化动作戏 |
| ② 双方战术差异 | 两边的打法与短板各一句（力量型 vs 灵巧型、持械 vs 徒手）——差异才有的打 | 双方动作同质化，模型演成互抡 |
| ③ 空间轴线 | 起始轴线与**允许的越轴点**（跨轴必须有动作理由）——挂场景方位卡锚物 | 打乱后观众失去方向感 |
| ④ 动作链 | 3-6 拍因果链（我方出招 → 对方受力/回应 → 战线变化），逐拍写接触点与受力方向 | 招式凭空出现、受力无来由 |
| ⑤ 镜头职责 | 每拍归哪类镜（主拍/反应/插入/空镜），与 IAU 上限对账 | 一镜塞太多动作（IAU 过载） |
| ⑥ 武器/道具/VFX 连续性 | 兵器离手落点、破损与血迹的持续区间、特效存续——进台账 | 武器瞬移、伤痕消失 |
| ⑦ 段末状态 | 胜负残局：谁倒谁立、场地新增破坏、下一场的钩子 | 打完即忘，下场满血重来 |

**与既有机制的分界**：R0~R3 定的是**档位与密度**（本文件第一、三节），合同管的是**这一场的
具体战术与连续性**——定档回答「打多大」，合同回答「这场怎么打、打完留下什么」。
逐拍连招链（第二节第 2 段）填进合同第④栏，两处同源不重复写。
