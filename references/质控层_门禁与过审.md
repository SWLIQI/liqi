# 质控层 · 门禁与过审

> 本文件合并两套体系：
> **liqi 的机械校验**（三个可执行脚本，32 个规则码）＋ **老李的语义门禁**（P0~P2 三级 + 改动后三步复验）。
> 本层由两套质检体系合并而成：P0~P2 三级门禁来自一方的分级实践，过审双向闭环（量化闸门 + 转译词典）来自另一方的合规实践，两者已在下文各节合并。
> 一句话原则：**脚本负责「查得出来」，门禁负责「拦得住」，复验负责「改完不漏」。**

---

## 一、三层质检架构

| 层 | 工具 | 答什么问题 | 什么时候跑 |
|---|---|---|---|
| **L1 机械层** | `check_prompt.mjs` | 单条提示词本身合不合规（时间轴、参数、台词双写、字符数、slop 词） | 每写完一条就跑 |
| **L2 项目层** | `audit_project.py` | 跨镜一致性（台词对齐、资产锚、角色漂移、时长、转场表） | 全片写完跑一次 |
| **L3 过审层** | `audit_risk.py` | 哪些镜会被审核拦、风险分多高 | 投喂前跑，被拦后复筛 |

三层都不是可选项。**只跑 L1 就交付 = 未完成质检。**

## 二、L1 · `check_prompt.mjs` 规则码全表（→ P0/P1/P2 映射）

运行：`node scripts/check_prompt.mjs <提示词包.md>`

规则码共 32 个，本 skill 把 liqi 原来的 error / warning 两档**重映射为老李的 P0/P1/P2 三级**：

- `E-*`（error） → **P0 阻断**，必须改完才能交付
- `W-*`（warning）且涉及结构缺失 → **P1 自动修复**
- 其余 `W-*`（审美 / 密度类） → **P2 优化建议**

### P0 级（E-*，阻断交付）

| 规则码 | 触发条件 | 处理 |
|---|---|---|
| `E-TIMELINE-START` | 时间轴首段起始 ≠ 0s | 归零重排 |
| `E-TIMELINE-END` | 末段结束 ≠ 声明镜长 | 核 `# duration` 与镜行 |
| `E-TIMELINE-GAP` | 相邻段之间时间轴断裂 | 补空档或合并 |
| `E-SKELETON-MIX` | 单条内段头骨架混用（国内面 / 国际面写法并存） | 统一为一种 |
| `E-MULTI-CAMERA` | 单段出现多个运镜原语群 | 拆段，一镜一运镜 |
| `E-OVER-30S` | 单条 > 30s（模型硬上限） | 强制滑窗拆分 |
| `E-PARAM-IN-BODY` | 正文出现容器参数（`ratio=`/`duration=`/`model=` 等） | 移入 `—— 以下不进正文 ——` 参数行 |
| `E-NEGATION-IN-BODY` | 正文出现否定式（「不要 X」「别 Y」） | 改写为正向描述 + 负面词块 |
| `E-DIALOGUE-MISSING-IN-SOUND` | 台词只在时间线，声音设计缺 | 补写，逐字一致 |
| `E-DIALOGUE-MISSING-IN-TIMELINE` | 台词只在声音设计，时间线缺 | 补写，逐字一致 |
| `E-SECTION-MISSING` | 有台词但缺「时间线分镜」或「声音设计」小节 | 补小节 |
| `E-IDENTITY-NOT-INLINE` | 人物未在「整体风格」小节内联锁定 | 逐镜会被单独复制，外观必须内联 |
| `E-SLOP-OVERLOAD` | slop 词 ≥5 | 重写（见 `去AI味对照清单.md`） |
| `E-INPUT` | 文件读不了 / >2MB | 拆文件 |

### P1 级（W-*，自动修复 — 结构缺失类）

| 规则码 | 触发条件 | 处理 |
|---|---|---|
| `W-BEAT-BUDGET` | 段数超/低于该时长的推荐区间 | 按推荐区间重切段 |
| `W-LENGTH-CAP` | 可复制正文超字符额度（见 C05） | 删冗余，先删形容词与重复空间描述 |
| `W-CONSTRAINT-SHAPE` | 刚性约束缺「必锁 / 可见性 / 禁现」三段式 | 补齐三段 |
| `W-ALLOCATION-MISSING` | 未声明保真预算（主/次/省） | 补写 |
| `W-COLOR-BUDGET` | 未声明色彩预算（唯一重音色 / 单一色系） | 补写，防模型自发补饱和度 |
| `W-FIRSTFRAME-SHAPE` | 声明了首帧但未补该帧构图 / 主体位置 / 镜头方向 | 补三要素 |
| `W-I2V-GARMENT` | 已声明首帧，正文仍出现未与参考图关联的服装名词 | 改「换成 X」写法（见 C18） |
| `W-SURFACE-MISMATCH` | 投放面与段头骨架语言不匹配 | 按投放面换骨架 |
| `W-CONTEXT-LEAK` | 正文出现跨镜指代（「上一镜的…」「如前」） | 每镜独立自足，删指代 |

### P2 级（W-*，优化建议 — 节奏 / 密度 / 审美类）

| 规则码 | 触发条件 | 处理 |
|---|---|---|
| `W-OVER-20S` | 越过 20s 滑窗红线 | 建议拆，不拆要写理由 |
| `W-BEAT-LENGTH` | 首拍 <3s 或末拍不在 3–8s | 调拍长 |
| `W-DIALOGUE-DENSITY` | 台词密度超物理可实现（>5.0 字/秒） | 减字或加时长 |
| `W-ACTION-DENSITY` | 动作密度过高（一镜多动作） | 拆动作或拆镜 |
| `W-SPATIAL-WEAK` | 出现站位弱词（附近 / 旁边 / 某处） | 换物理锚定（见 `空间层_调度与轴线.md`） |
| `W-SHOTSIZE-MISSING` | 未写景别 | 补 7 档视觉结果句 |
| `W-GAZE-MISSING` | 未写朝向或视线 | 补朝向视线分离写法 |
| `W-POSITION-MISSING` | 既无画面位置也无物理接触 / 距离锚定 | 补站位 |
| `W-AXIS-MISSING` | 未声明轴线 | 按 S0~S4 分级：S0 免，S1+ 必写（见 C09 附带修正） |
| `W-SLOP-COUNT` | slop 词 1–4 个 | 按档处理（1–2 收紧 / 3–5 重写） |

> ⚠️ **`W-AXIS-MISSING` 已被 C09 收窄**：接入老李 S0~S4 分级后，单人镜（S0）免轴线免位移，只写一行简版，原 liqi 对单人特写报无用警告的行为在本 skill 中取消。

## 三、L2 · `audit_project.py` 五类项目级检查

运行：`python scripts/audit_project.py <提示词包.md> [--script <剧本.docx>] [--assets <资产目录>] [--shots 1,2,5b]`

| 类 | 查什么 | 对应本 skill 的哪条铁律 |
|---|---|---|
| **A. 台词一致性** | 剧本原文台词 vs 提示词包是否逐字对齐 | 定稿后台词冻结（C06） |
| **B. 资产锚覆盖** | 每镜是否指定参考图；引用的图名是否真实存在 | 门禁③ 引用无图阻断（C12） |
| **C. 角色描述漂移** | 同一角色跨镜服装 / 外貌描述是否自相矛盾 | 文字锁 10+6 项（C12） |
| **D. 时长一致性** | 镜标题时长 vs 参数行 `duration`；是否超 15s 红线 | 时长红线（C04） |
| **E. 转场表完整** | 相邻镜对的转场注记是否缺漏 | 转场台账（C14 交付形态） |

**A 项是最不能省的一项**——用户铁律「台词一字不差」，返修时最容易顺手压缩长句，只有 A 项能抓出来。
（`--coverage` 可查反向覆盖：剧本里的台词有没有在提示词包里漏掉。）

## 四、L3 · `audit_risk.py` 过审风险分

运行：`python scripts/audit_risk.py <提示词包.md> [--shot 1,2,3,5b] [--detail]`

**评分模型**：`风险分 = Σ(词等级 × 出现次数)`，等级 3=极高（几乎必拦）/ 2=高（写实下必拦）/ 1=中。

**阈值**：

- 单镜 **≥20** ＝ 大概率被拦 → 必须替换后再投
- 单镜 **≥50** ＝ 几乎必拦 → 该镜重新设计
- 退出码：0 无触发 / 1 有极高词 / 2 只有中高危词

**只扫可复制正文**——自动排除 `>` 说明行与 `#` 参数行。因为只有正文会真正送进模型与审核。

**该脚本的词汇表是志怪 / 民俗 / 恐怖向**（人皮、验尸、停尸房、剥皮、声带、内膜），
**动作 / 暴力向的词汇表来自外部《平台安全合规转译指南》**（第三方资料，未随本仓库分发，见 §六）。两表题材互补，都要用。

⚠️ **它只查词，不查画面。** 拿到风险分之后必须走 §6.3 高敏感五手法给每一拍配镜头手法——
**换词不算完，画面不兜底等于没改。** 画面表述（剪影、伤情本体、儿童危险物口径）另跑
`scripts/audit_literal.py` 的 S 类。

## 五、P0 ~ P2 三级质量拦截门禁（老李语义 + 本 skill 补充）

> 补充两项老李原有、liqi 缺失的门禁（原属他的 P0，本 skill 保留）：
> 📐 **画幅一致性**：所有交付物顶部 `【画幅】` 声明必须等于锁② 的值；出现混用或回退（锁 16:9 却写出 9:16 构图词）→ P0 阻断。
> 🗂 **资产一致性**：分镜 / 投喂引用的 `@CHR/@SCN/@PRP` 必须指向已锁定的资产参考图；以文字替代资产、或成片形象与资产图不一致 → P0 阻断回补出图。

| 级别 | 拦截标准（未达标必须重构） | 常见违规 |
|---|---|---|
| **P0 致命（阻断交付）** | · 单条超 30s / 单镜越过红线且未拆<br>· 篡改 / 删减定稿台词<br>· 角色核心五官 / 服装跨镜漂移<br>· 严重跳轴或空间方位无故反转<br>· 正文混入容器参数、后台代码、乱码<br>· 引用未锁定资产图或以文字替代资产<br>· 画幅与锁② 不一致<br>· 段头骨架混用（国内面 / 国际面） | 镜头写成 90° 侧面中景；台词被压缩；引用 `@CHR` 却无对应资产图；正文出现 `ratio=9:16` |
| **P1 结构（自动修复）** | · 缺保真预算 / 色彩预算 / 刚性约束三段式<br>· 镜头时长全篇雷同无快慢节奏<br>· 光源无物理来源或在日景用冷蓝光<br>· 台词在时间线与声音设计只写一处<br>· 出现跨镜指代<br>· **高敏感拍只换词未配镜头手法**（见 §6.3）<br>· **人物以剪影为唯一呈现方式**（见 `视听层_镜头文法与光色.md`）<br>· **画面正文残留抽象表述**（跑 `audit_literal.py`） | 全片每镜都 5s；白天出现棚拍冷光；「同上一镜的光」；写「不拍伤口」却仍在特写里给伤处；写「角色E以剪影出现」而她这场有台词 |
| **P2 审美（优化建议）** | · 空镜过多或无戏剧任务<br>· 形容词空泛未转译为物理事实<br>· 声音层次不够分明<br>· 站位弱词（附近 / 旁边） | 「极具压迫感」；「站在旁边」 |

## 六、过审双向闭环（C16：查 → 改 → 复筛）

liqi 给的是**量化闸门**，老李给的是**修改手册**。两者是「查」与「改」的关系，合起来才是闭环：

```
① 查：跑 audit_risk.py，拿到单镜风险分与贡献词清单
        ↓
② 改：按题材选词表，逐词替换
        ↓
③ 复筛：再跑一次 audit_risk.py，确认风险分降下来（≥20 的镜降到 <20 才放行）
```

### 6.1 志怪 / 民俗 / 恐怖向词表（liqi 体系）

| 高危词 | 物理转译词 |
|---|---|
| 人皮 | 皮壳 / 蝉蜕 / 旧衣壳 |
| 验尸 | 验看 / 查验 |
| 停尸房 | 石室 / 静室 |
| 剥皮 / 剥 | 蜕下 / 脱下 / 褪去 |
| 血 | 赤红 / 暗红痕 |
| 尸体 | 无生命躯壳 / 空衣 |
| 器官 / 声带 / 内膜 | 不提，改外在表现（喉部起伏 / 呼吸声） |
| 肌肉 / 骨骼 | 赤红躯体 |

### 6.2 动作 / 暴力 / 战斗向词表（老李体系，四维度）

| 维度 | 高危拦截写法 | 转译方向 |
|---|---|---|
| **击打受力** | 骨裂、骨折、骨头碎裂 | 写受力后的**位移与形变**（身体后仰、手臂被带偏） |
| **面部创伤** | 鼻血、嘴角流血、面部变形 | 写**遮挡与角度**（背对镜头、发丝遮面） |
| **致命打击** | 致命、杀死、当场毙命 | 写**结果状态**（不再起身、镜头停在空位） |
| **环境破坏** | 血肉横飞、爆头、肢解 | 写**环境反应**（尘土扬起、物件散落） |

### 6.3 🔴 改的落地：高敏感五手法（换词不算完）

**这是过审闭环里最容易漏的一环。** 6.1 / 6.2 解决的是"词怎么换"，但没有解决"画面怎么办"——
词换掉了，画面还在拍同一个东西，审核照样拦，或者模型照样把它生成出来。

**纪律：每替换一个高危词，必须同时给这一拍指定一种镜头手法。** 只换词不给手法＝没改。

| 手法 | 怎么做 | 适用 |
|---|---|---|
| **画外（声音先入）** | 危险发生在画外，画面只给听者的反应；声音先到，画面后到或不给 | 伤害、事故、死亡 |
| **前景遮挡** | 用门框 / 碗沿 / 桌沿 / 器物挡住主体关键部位 | 利器、身体局部 |
| **局部特写** | 只给手、器物、衣料，不给全貌 | 伤口、形变、操作过程 |
| **逆光与暗部轮廓** | 主体压在暗部，只留边缘与轮廓，暗部有层次不死黑 | 暴力动作、垮塌、熔化 |
| **空镜承接** | 危险过后接一个环境空镜，用痕迹代替本体 | 结果、余波、现场 |

#### 两条反直觉纪律（踩过才知道）

**① 只给结果，不拍过程。**
要表现"他夜里抓过自己的脸"，**不能写抓挠动作**——写抓挠就必然要拍到皮肤接触与形变，高风险且模型做不好。
正解：只给结果。「左颊颧骨下方一道两指长的浅白印子，边缘不齐，颜色比周围皮肤浅一档，不红不肿」，
配合声音层的抓挠声。**观众看得懂，模型做得到，审核过得去。**

**② 儿童与危险物要分两层，不能写「全程不同框」。**
剧本若要求儿童接触危险物（端热汤、靠近灶火），不能写「孩子全程不与热源同框」——
这会与核心动作直接打架，投喂时两条指令互相抵消，模型随机二选一。
正解：写「**不与危险发生的瞬间同框**」，并把可见范围收窄——
`端汤过程只给碗身与双手，碗口不抬起，热气不扑面`。动作保住了，危险瞬间没拍到。

#### ⛔ 剪影不是规避手法

`audit_risk.py` 早期版本建议"配合雾 / 剪影 / 暗调降冲击"——**这条已修正**。
剪影降的是可见度，同时也**降掉了"人物在场"**（模型读不懂剪影，见
`视听层_镜头文法与光色.md` 剪影反向约束）。人物要出场就必须给光与朝向，
遮挡用前景与暗部，不用剪影。

### 6.4 不可合并的两句声明

- 本 skill 提供降低风险的方法，**不承诺任何 100% 通过**——最终以各平台实时审核政策为准。（老李）
- 人脸过滤在**模型层**，换 API 宿主无效；被拒时不要浪费时间换宿主，改**风格化画风**重试。（liqi）

## 七、改动后复验铁律（C13：liqi 完全缺失的一环）

> 改稿禁止只复验改动处。改动会与全档其他部分冲突——典型翻车：改一句台词剧透前文伏笔、改一个场景与资产锚冲突，而整档未重跑。

### 三步复验闭环（缺一不可）

1. **局部验证（改动处自检）**：改动内容本身达标（台词 / 画面 / 锚点 / 时长）
2. **联动冲突检查（七项交叉扫描）**：伏笔 → 角色（人设 / 脸模 / 服装）→ 信息量（剧透 / 节奏）→ 因果节拍 → 资产锚点 → 时长预算 → 画幅一致性
3. **全量审核**：整档重跑 L1 + L2 + P0~P2 门禁；**不允许以「已检查改动处」豁免**

### 《改动复验报告》交付要求

**修改类交付物文末必须附：改动清单 + 联动检查结论 + 全量审核结论。**
**未附报告 ＝ 视为未完成复验，禁止交付。**

这是本 skill 唯一强制附件。任何「改了三个字所以不用复验」的判断，一律驳回。

## 八、声音三段混音电平（制作纪律，写进参数行）

```
对白 0 dB  >  动作物理音效 SFX −6 dB  >  环境声景 / BGM −14 ~ −18 dB
```

- 对白永远处于最高清晰度优先级。
- 动作音效不得遮盖人声；激烈打斗或对白爆发时 BGM 自动避让（Ducking）。
- 与四层混音段（环境 / 动作 / 呼吸 / 逼近）是两回事：**四层定「有哪些声音」，电平定「谁听得清」**。

## 九、后期兜底层（生成完之后还有一道保险）

提示词与资产板能压住大部分漂移，但压不住全部。**已经生成的镜头里仍有一小部分脸会歪**——这时候不重抽，走后期兜底。

### 两道工序

| 工序 | 做法 | 适用 |
|---|---|---|
| **漂移镜头换脸修正** | InsightFace / FaceFusion 把漂掉的脸贴回参考脸 | **只处理脸清晰可见的镜头**。远景小脸、背影、侧后脑不做——贴上去反而更假 |
| **全片统一调色** | 所有片段进 DaVinci / CapCut 统一曝光与白平衡，再套一个 LUT | **全片必做** |

### 为什么调色比换脸更重要

**肤色统一对「感知一致性」的贡献大于任何单项技术。** 不同生成调用之间的色温差，会让同一个角色看起来像换了个人——脸明明是对的，观众还是觉得「不是他」。所以：

- 顺序上**先调色再看换脸**。很多「脸不对」的观感问题，调完色就消失了。
- 生成时**不要逐镜单独调色**，一律留到后期统一处理——生成期调色会引入不可逆的色偏。
- 基准调色板来自资产层注册表 `palette`，**与场景光照锚点是两回事**（光照管「光从哪来」，调色管「全片落在哪个色域」）。

### 与「回卡修」的分工

| 问题出在哪 | 用哪一招 |
|---|---|
| **卡本身错了**（设定图上的面板就有问题） | 回卡修（`失败诊断与返修映射.md`）——不重抽镜头，改卡后所有镜头继承修复 |
| **卡是对的，只是这一镜生成歪了** | 重抽这一镜；重抽仍不稳 → 后期换脸修正 |
| **卡对、单镜也对，但全片观感不统一** | 后期统一调色 |

**不要用后期兜底去掩盖卡的问题**——卡错了却一直靠换脸贴，成本会失控，而且每个镜头都要贴一次。
