# 写实 PBR 风格锚（写实轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**影视级写实 PBR**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

**适用判定**：真实皮肤与高精度材质、PBR 光照、体积雾、胶片颗粒；
有实拍对手戏素材时必须选本轨（其他轨会与实拍素材割裂）。
用户给的设定图是**照片或照片级渲染**时，锁③ 风格轨道选**写实轨**，风格 id 取 `photoreal-pbr`。

> 🔴 **稳定性 = 险（人脸）**。本轨是全套风格里翻车率最高的一档：
> 恐怖谷、塑料脸、美颜磨皮、手部崩形、换脸，五个坑全在人脸与手上。
> **短片（≤10 镜）可以用；长片多镜强烈建议换 `npr-celshaded-3d`**（同为 3D，但一致性是「稳」档）。
> 选本轨就要接受：必带资产图走 I2V/Ref2VA、必写不完美词、必做逐镜人脸核对。

**边界声明**：

- 与卡通轨（`celshade-guoman-2d`）和三渲二轨（`npr-celshaded-3d`）：**负面词方向完全相反**。
  写实轨禁的是「卡通感、塑料感、玩具感、平涂色块、描边、Q 版」；那两轨靠的正是这些。写反 = 全片污染。
- 与定格木偶轨（`gothic-puppet`）：定格轨要「假」——黏土、布偶、微缩模型的痕迹是风格本体；
  本轨要「真」。材质词汇互斥。
- 与手绘轨（`ink-wash-2d`）：平面 vs 体积，互斥。

## 一、九段锚（中文，给 liqi 上游用）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 影视级 3D 写实渲染（UE5 / PBR 精度）；皮肤有毛孔、细纹与轻微不对称，布料经纬粗粝可见，石土有颗粒与潮湿反光；体积散射雾；胶片颗粒极轻；**皮肤必须带不完美，禁止无瑕光滑** |
| ② 配色与色域 | 低饱和去色为主：青灰、土黄、暗褐；**每镜只声明一个唯一重音色**（通常是唯一暖光源：火把、灯）；禁用高饱和、荧光、干净鲜亮的调色 |
| ③ 运动签名 | 24fps 电影感，动作连续有重量，关节转折自然；允许轻微手持晃动与呼吸感运镜；可以有运动模糊（写实有）；不放动画式的夸张幅度 |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 7–7.5（真实人体比例；孩童取 5–5.5）**；脸型骨相、发型、眉眼、**皮肤不完美特征（痣、疤、细纹）**、服装形制与配色；跨镜不换脸、不换装、比例不漂移 |
| ⑤ 场景锁定 | 走 `<Subject N>`：建筑与地面材质、植被、天气与能见度；同场景跨镜地标与光位一致；雾与湿度要按场次写清 |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、做旧程度、持握方式；道具入画方式必须写（手持 / 悬挂 / 置地）；金属与木头按真实反射写，但要给明确光源 |
| ⑦ 光色基调 | 主光方向明确（侧逆 / 顶光 / 窗光），衰减真实；阴影柔和有层次，暗部不死黑；体积雾按能见度写（如「三步外轮廓消融」）；**必须写明光源，不写「昏暗」这种无方向的词** |
| ⑧ 声音签名 | 环境层：空间感与远近层次明确，环境细节丰富；动作层：脚步、衣料、材质接触声，按材质写实；呼吸层：真实可闻；配乐：克制，低频为主 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅生图模型与其他有 negative 字段的面可用：卡通感、塑料感、玩具感、平涂色块、描边、Q 版比例、美颜磨皮、无瑕光滑肌肤、贴图拉伸、多余手指、肢体畸形、可读文字、水印、比例漂移、换脸、服装变化 |

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A photoreal live-action film frame with PBR materials and real cinematic lighting. Skin shows pores, fine lines and slight asymmetry, never flawless or airbrushed. Cloth weave, damp stone and weathered wood all read at close range. One motivated light source with natural falloff, volumetric haze, very light film grain.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
desaturated palette of cold grey, earth ochre and deep brown, with a single warm accent hue carried by the only practical light source
```

**四条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `perfect skin` / `flawless complexion` | `Skin shows pores, fine lines and slight asymmetry` | **本轨第一崩点就是塑料脸**。模型与平台默认往光滑无瑕走，不写不完美必翻车 |
| `3D render` / `CGI` | `photoreal live-action film frame` | 写 render/CGI 会被路由到明显 CG 的通道，材质发假 |
| `beautiful` / `stunning` / `gorgeous` | 删除 | 这类评价词会触发平台的美化倾向，等于变相磨皮 |
| 不写光源 | `One motivated light source with natural falloff` | 不写光源方向，模型会补棚拍式均匀光，画面立刻发假 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅写实电影画面，PBR 真实材质与真实的电影布光。皮肤能看到毛孔、细纹与轻微不对称，绝不光滑无瑕、绝不磨皮。布料织纹、潮湿石面与风化木料在近距离都清晰可辨。单一有依据的光源，衰减自然，带体积雾，极轻的胶片颗粒。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
低饱和配色：冷灰、土黄与深褐，唯一暖色重音由画面里唯一的实用光源承担。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「完美肌肤」「精致五官」「高颜值」 | 「皮肤有毛孔与细纹，五官有轻微不对称」 | 中文面同样有美化路由，这三个词等于直接下令磨皮 |
| 「3D 渲染」「CG 动画」 | 「写实电影画面」 | 「渲染 / CG」在中文面会出明显假材质 |
| 「不要卡通、不要塑料」 | 删否定句，正面写「真实材质、毛孔可见、衰减自然」 | 否定不生效，反而容易被读成肯定 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（PBR 材质、光源有依据、皮肤不完美）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台自带的美颜与磨皮**，它是本轨的头号杀手。
所以 2.2 那句「绝不光滑无瑕、绝不磨皮」在国内面**不许省略**。

## 三、色值表（风格级起点，项目级以 asset-registry 为准）

| 用途 | 色值 | 说明 |
|---|---|---|
| 雾白 / 亮部 | #C8CBCA | 晨雾与受光面，不纯白 |
| 青灰主调 | #6E7773 | 环境与建筑主色 |
| 深阴影 | #2A2E2E | 暗部，不死黑 |
| 土黄 | #8A7550 | 土路、木料 |
| 暖光（重音色） | #C9743A | 全片唯一暖色：火把 / 灯 |
| 暗红 | #7A2E28 | 血与危险色，点缀级，不成块 |
| 皮肤亮部 | #D8C3B0 | 带血色，不做瓷白 |

**色彩预算纪律照旧**：每镜只声明一个唯一重音色（通常是唯一的实用光源），其余压成同色系低饱和。

**同步纪律**：本表与 L0 `style-registry.json` 的 `palette` 必须一致，改一处要同步另一处。

## 五、材质与可见性预算（写实版）

| 项 | 落值 |
|---|---|
| 主花费 | **皮肤与布料材质**——写实轨的辨识度全在材质，脸一假全片假 |
| 次花费 | 体积雾与氛围、环境光的层次 |
| 省 | 群像细节与远景陈设（压成雾中的剪影与色块） |
| 可见性 | 只写看得见的部分：侧脸时不写远侧眼珠细节，改写眉骨与颧骨的受光 |
| 禁 | 平涂色块、描边、卡通着色、无瑕光滑肌肤、磨皮、瓷娃娃质感、塑料反光 |

**不完美词清单（必带，至少带两项）**：毛孔、细纹、轻微不对称、皮肤瑕疵、干燥起皮、
布料的起毛与补丁针脚、木料的开裂与风化。
**不带不完美词 = 出塑料脸**，这条在本轨是硬性的，不是建议。

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **塑料脸 / 美颜磨皮（本轨头号崩点）** | 没写不完美词；写了 perfect / beautiful / 精致五官 | 压句逐字复用；不完美词至少带两项；删掉一切颜值评价词 |
| **恐怖谷** | 皮肤太光滑 + 眼睛太锐利 + 比例完美 | 皮肤加不完美；眼睛写「有血丝与轻微不对称」；比例按真实档 7–7.5 |
| **变卡通 / 变三渲二** | 压句没写 photoreal；正文出现平涂、色块、描边、硬边阴影 | 压句第一词就是 `photoreal`；卡通着色词全部删除 |
| **手部崩形（多指 / 少指 / 肢体畸形）** | 3D 生成常见问题，手部没给明确姿态 | 手部写清姿态与可见指节；负面词保留「多余手指、肢体畸形」 |
| **跨镜换脸 / 比例漂移** | 没走 `<Subject N>`；参考图不是同一套 | 每镜内联锁定；**必带资产图走 I2V/Ref2VA**；逐镜核对人脸 |
| **光线发假、棚拍感** | 没写光源方向与衰减；写了「昏暗」这种无方向的词 | 必须写明光源（侧逆 / 顶光 / 窗光）与衰减；写清阴影层次 |
| **画面发灰、像广告片** | 没写色彩预算 | 每镜声明唯一重音色与低饱和色系 |
| **噪点过多 / 画质糊** | 写了 heavy grain 或高 ISO | 只写「极轻的胶片颗粒」；画质词交给参数行 |
| **材质贴图拉伸 / 花纹穿帮** | 3D 生成贴图问题 | 服装写纯色或简单织纹，复杂花纹交给后期 |
| **过审被拦（真人感 + 血腥 / 恐怖）** | 写实血腥画面 | 伤口与血液一律正向定义 + 「影视特效化妆感、不是血腥恐怖画面」口径；投国内面必跑 `audit_risk.py` |

## 八、参考图集与角色锁定

本风格**无专属参考图集**。角色锁定走 `<Subject N>` 通用写法（见第一节第④段，头身比 7–7.5）。

**本轨的资产纪律（最严的一轨）**：

1. **必带资产图走 I2V / Ref2VA**。纯文生视频在写实轨的还原率最低，不带图基本必翻车。
2. 资产图本身必须是**照片级或写实渲染**，不能是画。参考图是画，出片就往画那边滑。
3. 角色锁定里**必须写一条不完美特征**（痣、疤、细纹、不对称）——它是跨镜防换脸的锚点，
   也是防磨皮的钉子。
4. 逐镜做人脸核对：出片后比对眉眼间距、鼻梁走向、那颗痣还在不在。

## 九、去立体化与串轨防护

**本轨不要跑 `scripts/dedupe_style.py --style ink-wash-2d`**。那份词表是「去立体」的，
而**本轨要的就是体积与纵深**——用它等于把写实删成平面。本轨只按 §9.1 的表手工清。

### 9.1 污染词与替换对（写实轨方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 完美肌肤、无瑕、精致五官、高颜值、瓷娃娃 | 皮肤有毛孔与细纹、五官轻微不对称 | **美颜类词是本轨头号杀手**，一律删除 |
| 平涂、色块、描边、卡通着色、toon、cel-shading | 删除 | 卡通类词，写反即全片污染 |
| Q 版、二头身、大头 | 删除 | 比例跨档 |
| 磨皮、柔光、美白 | 删除 | 直接触发平台美化 |
| beautiful / stunning / gorgeous（英文） | 删除 | 触发美化倾向，等于变相磨皮 |
| `3D render` / `CGI` 单写 | `photoreal live-action film frame` | 写 render/CGI 会路由到明显 CG 通道 |
| 昏暗、气氛感（无方向的光） | 侧逆光 / 顶光 / 窗光 + 衰减 | 无方向的光 ⇒ 模型补棚拍均匀光 ⇒ 发假 |
| 高 ISO、重噪点、heavy grain | 极轻的胶片颗粒 | 噪点过多会糊掉材质 |
| 血腥、伤口见骨、断肢 | 影视特效化妆感、不是血腥恐怖画面 | 过审口径，且写实画面最容易被拦 |

**必须主动加的词**（不是删，是加）：毛孔、细纹、轻微不对称、干燥起皮、
布料起毛、木料开裂风化、光源方向、自然衰减、体积雾。

### 9.2 互斥风格

| 互斥 id | 混了会怎样 |
|---|---|
| `celshade-guoman-2d`（国漫赛璐璐） | 负面词方向完全相反：本轨禁的「平涂 / 描边 / 色块」正是它靠的本体 |
| `npr-celshaded-3d`（三渲二） | 同为 3D 但着色逻辑相反：它要两段式硬边阴影与描边，本轨要真实光照与材质 |
| `ink-wash-2d`（水墨淡彩） | 平面 vs 体积，互斥 |
| `gothic-puppet`（哥特定格木偶） | 定格轨要「假」（黏土、布偶、微缩痕迹），本轨要「真」；材质词汇互斥 |

**串轨怎么认**：看材质词。本轨正文里出现「平涂 / 描边 / 色块 / 硬边阴影」，
或卡通轨正文里出现「毛孔 / PBR / 真实皮肤」，就是串了。
