# 风格锚 · 统一模板（L1 · 十节骨架）

> 用途：新增任何一套风格时，按本模板逐节填满，产出 `references/风格锚_<slug>.md`。
> 上游＝`风格注册表_style-registry.md`（L0 数值）；下游＝SKILL.md 路由（L2）与校验脚本（L3）。
>
> **硬规则**：L1 是 L0 的散文展开。L1 里出现的每一个色值、每一条负面词、每一个头身比，
> 必须能在 L0 找到同一个数值。L1 里禁止出现 L0 没有的数值——出现就是两套事实源。

---

## 零、文件头（必写）

三件事，缺一不可：

1. **一句话定位**：本文件是 liqi Step 2「全片统一风格锚（九段）」在 **XXX** 这套风格上的落值。
2. **适用判定**：什么样的画面特征 / 用户给了什么样的设定图时，该选本风格。写具体的可观测特征，不写「有质感」这种空词。
3. **边界声明**：与相邻轨道的界线在哪儿，混了会怎样。这是防串轨的第一道闸。

正例（哥特锚）：
```
适用判定：手作木偶质感、微缩布景实拍、大头细肢骨骼式解剖、尸感黏土皮肤、月光蓝低饱和。
与写实轨的边界：写实轨要 PBR 真实皮肤；定格木偶轨要「假」——黏土、布偶、微缩模型的痕迹本身就是风格本体。两者材质词汇互斥，禁止混轨。
```

反例：`适用：有质感、有氛围、高级感的画面。` —— 三个词全是 slop，判不出任何东西。

---

## 一、九段锚（中文，必写）

一张九行表，直接对应 Step 2 的九段。字段固定：

| 段 | 写什么 | 常见漏写 |
|---|---|---|
| ① 画风与材质质感 | 媒介声明放**第一句**（是画、是模型、是渲染、是实拍），再写材质 | 媒介声明挪到句子后半段，模型就按自己的先验猜 |
| ② 配色与色域 | 色名 + HEX 倾向 + 唯一重音色是谁 + 禁用哪些 | 只写「低饱和」，不点名唯一重音色 |
| ③ 运动签名 | 帧率、幅度、延迟、起收、该风格特有的运动特征 | 不写「禁什么」（定格要禁丝滑，手绘要禁视差） |
| ④ 角色锁定 | 走 `<Subject N>`：脸型骨相、发型发饰、眉眼、服装形制与配色、鞋袜；**头身比必写** | 漏头身比——跨镜身形立刻散 |
| ⑤ 场景锁定 | 建筑形制与配色、地面质地、植被、远山轮廓；同场景跨镜地标与光位一致 | 不写「跨镜一致」这条纪律 |
| ⑥ 道具锁定 | 形制、材质、**入画方式必须写**（手持 / 悬挂 / 置地） | 漏入画方式，道具会飘在半空 |
| ⑦ 光色基调 | 主光是什么、入射角、影子形态、禁哪种光 | 只写「昏暗」，不写光从哪来 |
| ⑧ 声音签名 | 四层：环境 / 动作 / 呼吸 / 配乐，逐层给具体内容 | 只写配乐，不写环境层 |
| ⑨ 排除项 | 声明「H3 面丢弃（无 negative 字段）」，其余面可用哪些 | 不声明投放面差异，国内面会多出一行 Must not |

## 二、多面压句（必写，改版重点）

**这一节是本次改造的核心**：旧版只有 H3 英文压句，投国内面与 Seedance 面要临场翻译，一翻译就漂。

三小节，按投放面分别给，都要求逐字复用：

```
### 2.1 H3 英文压句（写在 [Shot 1] 之前）
[英文压句原文]
配色补充句（写进风格 <Subject N> 定义里）：
[英文配色句]

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）
[中文压句，与英文压句语义等价]

### 2.3 国内面中文压句（写在整体风格段）
[中文压句]
```

**措辞纪律表（必附）**：三到五行，每行是「旧写法 → 本锚定稿 → 为什么」。
这张表是防回退的——后来的人看到某个词想改回去时，先读为什么。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。
改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。只写一句会导致色域漂移。

## 三、色值表（必写）

用途列 + HEX + 说明列。至少覆盖：底色 / 亮部 / 主要衣物 / 肤色 / 重音色 / 勾边色。

表尾必须带**色彩预算纪律**：每镜只声明一个唯一重音色，其余压成同色系灰调。不声明色彩预算，模型会自发补饱和度。

**同步纪律**：本表与 L0 的 `palette` 必须一致，改一处要同步另一处。

---

## 四、运镜池（必写）

三分类表：主力 / 少量 / 避免。

- 主力：与该风格气质一致的常规运镜
- 少量：段落转折用，一部片两三次
- 避免：会破坏本风格本体感的运镜（手绘禁环绕与横移视差；定格禁甩镜；皮影禁横移）

**每段只锁一个主运镜**，与 liqi 的原语群纪律一致。

---

## 五、材质与可见性预算（必写）

主 / 次 / 省 / 可见性 / 禁 五项。

- 主花费：这套风格的辨识度在哪儿，就押在哪儿
- 禁：哪些材质词会把画面推向错误方向（手绘禁高光渐变；定格禁次表面散射）

---

## 六、崩点清单与反制（必写，最有用的一节）

三列表：崩点 / 成因 / 反制。至少 6 条，上不封顶。

**禁止照抄别家的崩点表**。水墨的头号崩点是出片 2.5D，定格木偶的头号崩点是变光滑 CGI，
两者方向相反——抄过来就是给自己的风格埋雷。

写的时候按这个顺序想：① 这套风格最容易变成什么（变成隔壁某个风格）；② 什么词会触发它；③ 怎么用正面陈述钉死。

---

## 七、声音签名（必写，中英双轨）

旧版只有英文。新版要求中英各一套，因为国内面投喂是中文。

```
整体声音签名（中文）：环境层…；动作层…；呼吸层…；配乐…
overall_soundscape: [英文]
non_diegetic_music: [英文或 N/A]
```

需要配乐时写清乐器、速度、动态走向。**默认无配乐的风格要明写「默认无配乐」**——
不写，不同镜会各自补出不同的音乐。

---

## 八、参考图集与角色锁定（可选）

有专属参考图集时才写。没有就写一行「本风格无专属参考图集，角色锁定走 `<Subject N>` 通用写法」。

写了就包含：图集名、每个角色的可复现锁定句（含头身比）、投喂纪律（左区头部近景当身份锚）。

---

## 九、去立体化与串轨防护（必写）

两小节：

### 9.1 本风格的污染词与替换对

对应 L0 的 `dedupe_pairs`。给一张表：污染词 → 替换词 → 为什么。

**按风格差异极大**：
- 手绘平面轨：删 `animation` / `storybook` / `glow` / 否定句（这些会触发 2.5D）
- 定格木偶轨：**反向**，删的是「丝滑 / 流畅 / 运动模糊 / 真实人体解剖」（这些会触发 CGI 化）
- 赛璐璐轨：不删 `glow` 类词，但要删「厚涂 / 软过渡 / 油画笔触」（这些会破坏硬边阴影）

抄错方向等于给自己的风格下毒。

### 9.2 互斥风格

列出与本风格互斥的 id（与 L0 `excludes` 一致），并写一句「混了会怎样」。

## 十、与 liqi 既有 references 的对接（必写，可照抄骨架）

一张表，每行「情况 → 取用哪个文件」，并按本风格做差异化说明（比如光色基调按本文件第七段，不按通用光照锚点）。

骨架行（每行都要按本风格改括号里的差异化说明）：

| 情况 | 取用 |
|---|---|
| 定光照锚点、场景跨镜一致 | `场景资产与时间线光照.md`，但光色基调按本文件第一节第⑦段（**填本风格的光**） |
| 写材质描述 | `质感与可见性预算清单.md`，主次省按本文件第五节 |
| 微表情 | `表演层_FACS微表情.md`；AU 编号与强度档一律不进正文（**填本风格的幅度处理**） |
| 抽象表述自查 | `抽象表述判定口径.md`，英文正文同样适用 |
| 站位与轴线 | `空间层_调度与轴线.md`，写法不变，只翻译成投喂语言 |
| 投 H3 | `MiniMaxH3适配.md` |
| 投 Seedance 2.5 | `Seedance2.5适配.md` |
| 投国内面 | 负面词压成 `Must not` 一行附正文末 |
| 出资产图 | `Seedream5适配.md`；出图提示词里压句同样逐字复用 |
| 具名运镜拼装 | `h3-camera-shots` skill |
| 出片不对 | `失败诊断与返修映射.md` + `h3-shot-iteration` skill |
