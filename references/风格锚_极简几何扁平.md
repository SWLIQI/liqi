# 极简几何扁平 风格锚（卡通轨 × 扁平图形专项）

本文件是 Step 2「全片统一风格锚（九段）」在**极简几何扁平（flat minimal）设计感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：现代扁平设计语言的动画——大色块几何形状、有限色板、无描边或极细描边、
负空间构图、人物是几何化的简约形（圆头方身）。用户给的是扁平风 / MG 动画 / 极简品牌片参照时，
锁③ 风格轨道选**卡通轨**，风格 id 取 `flat-minimal-2d`。

**边界声明**：

- 与合成器波（`synthwave-retro-2d`）：合成器波是**霓虹发光渐变**的八十年代语汇；扁平是**哑光大色块**
  的现代设计语汇。发光与否是分界。
- 与美式漫画硬线（`us-comic-ink-2d`）：美漫有排线与印刷肌理；扁平是**零肌理纯色块**。
- 与国潮新中式（`guochao-2d`）：国潮有东方纹样装饰；扁平是几何抽象，无纹样。
- 与 Low-poly（`lowpoly-iso-3d`）：lowpoly 是 3D 体块；扁平是 2D 平面图形。维度互斥。

> **竖屏适配（C26）**：扁平构图靠负空间与几何分割，画幅无关——竖屏写法：
> 主体几何形占中段、负空间上下留白。**竖屏友好，无需改写行**。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 现代扁平设计：大色块几何形状（圆、方、三角构成人与物），无描边或统一极细描边，零肌理零渐变（或仅两阶同色系明度阶），负空间大量留白；一切像矢量图形放大后的干净边缘 |
| ② 配色与色域 | 有限色板（全片 4-6 色）：低饱和主色＋一个饱和重音色；**每镜只声明一个唯一重音色**；禁渐变滥用、禁纹理、禁照片色 |
| ③ 运动签名 | 24fps，**图形的节奏**：位移用缓入缓出（ease 曲线感），形状变换（圆变方）是转场语言；运镜只许固定与极缓推近；禁甩镜、禁写实跟拍 |
| ④ 角色锁定 | 走 `<Subject N>`：头身比不适用（几何化人物 2.5-4 头身的简约形）；人物由几何件构成（圆头、方身、线状四肢），主色写死；跨镜构成不变 |
| ⑤ 场景锁定 | 走 `<Subject N>`：场景是几何件的组合（矩形楼、圆日、三角山），每镜场景元素 ≤5 件；同场景跨镜构图一致 |
| ⑥ 道具锁定 | 走 `<Subject N>`：道具几何化到剪影级，形制写死 |
| ⑦ 光色基调 | 无光影：扁平没有光源与阴影（或只有同色系深一阶的投影形状）；**禁投影渐变、禁体积光、禁写实光照** |
| ⑧ 声音签名 | 环境层：干净底噪或全静；动作层：UI 音效化的点触声、几何移动的滑音；呼吸层：情绪点才写；配乐：轻电子或钢琴单音，极简 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。其他面：照片质感、渐变滥用、肌理纹理、写实解剖、3D 渲染、可读文字、水印、多余人物、分身 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A flat minimal design frame: large geometric colour shapes composing figures and scenes, circle heads, rectangular bodies, triangular mountains, unified thin or no outlines, generous negative space, a limited palette of muted primaries with one saturated accent. Crisp vector edges, zero texture, flat shading with at most one darker tone step. Modern motion-design cleanliness, never photoreal, never textured.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
limited palette of four to six muted colours, one saturated accent, flat two-step shading only
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `neon glow / 发光` | `flat shading with one darker tone step` | 发光是合成器波档的本体 |
| `detailed realistic` | `geometric simplified` | 细节是本锚反面 |
| `textured grain` | `crisp vector edges` | 肌理是本锚反面 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 58 词，长档——预算紧先删末句（Modern motion-design 一句），删后约 50 词。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅极简几何扁平风格的画面：大色块几何形状构成人物与场景——圆头方身的人物、三角的山、矩形的楼，统一细描边或无描边，大量负空间留白，低饱和有限色板加一个饱和重音色。矢量级的干净边缘，零肌理，扁平两阶明度，没有渐变滥用。是现代动效设计的干净感，不是照片，不带肌理。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：全片四到六色的有限色板，一个饱和重音色，扁平两阶明度。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「发光」「霓虹」 | 删，写「扁平哑光」 | 反串合成器波档 |
| 「细节丰富」「真实」 | 删，写「几何简化」 | 细节是反面 |
| 「渐变过渡」 | 删，写「两阶明度」 | 渐变滥用是反面 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（大色块几何、有限色板、负空间、两阶明度）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台往色块里加渐变和光效**，所以「扁平两阶明度」与「零肌理」在国内面**不许省略**。

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 渐变混入 | 写了光效、过渡色 | 两阶明度锁死；负面词带渐变滥用 |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「发光化」与「写实化」两侧的词**，保留哑光色块与几何简化。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| neon glow / 发光 | flat matte colour blocks | 反串合成器波档 |
| detailed / realistic | geometric simplified | 细节是反面 |
| gradient transition | two-step flat shading | 渐变滥用反面 |
| textured grain / 纸纹 | crisp vector edges | 肌理反面 |
| real anatomy / 写实解剖 | geometric figure forms | 解剖是反面 |

### 9.2 互斥风格

`synthwave-retro-2d`（霓虹发光 vs 哑光色块）、`us-comic-ink-2d`（印刷肌理排线 vs 零肌理纯色）、
`lowpoly-iso-3d`（3D 体块 vs 2D 平面）、`chibi-qban-2d`（Q 版五官程式 vs 几何无脸形）。
