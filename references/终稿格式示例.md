## 〇、全片统一风格锚（总纲，供逐镜对齐）

```
统一风格：2D 手绘卡通动画，粗黑轮廓线（描边稳定 3-4px），平涂色块填充，柔和单色阴影，
简洁几何化背景，Q 版三头身人物比例，卡通角色表情夸张化。
材质与质感清单（卡通轨：无材质，只锁色块规则）：平涂色块，单一色阶填充，硬边单色阴影；
金属与布料以明度差区分，画面保持干净色块，不引入纹理与渐变。
运动签名：
生成期（进正文）：动作起落干净，节奏匀速，画面保持稳定
后期（不进正文）：三段快切在剪辑层完成硬切，速度线为后期叠加
角色与场景画风锁定：
- 角色A：黑色短发带闪电形灰色高光，深灰色西装、白衬衫、黑鞋；
- 角色B：寸头，深蓝色制服，神情沉稳；
- 角色C：束发低马尾，深蓝色制服，神情温和。
场景锁定：
- 场景1：米色墙壁、灰色条纹地毯、银灰色金属桌、弧形天花板嵌入式白色灯带；
- 场景2：深蓝色块背景、昏黄楼道灯光斑、散落卡通空啤酒瓶；
- 场景3：土黄与棕褐色块、破窗斜射黄色几何光柱、铁笼黑色剪影；
- 场景4：高明亮浅蓝白色块、玻璃顶网格线条。
关键道具锁定（承担叙事功能的贯穿物件，与各镜道具铁律一致）：
- 银灰色手铐为全片唯一一副（镜1/镜10a）；
- 白色塑料束带为藏匿工具（镜5/镜6/镜9）；
- 毛巾包裹轮廓为动物象征物，不露全貌（镜5/镜9）；
- 黑色行李箱为色块轮廓、无文字（镜6b/镜7）。
保真预算总纲：主 = 人物表情与肢体可读性；次 = 场景色块的干净度；省 = 背景陈设与群像个体。

参数行（不进正文）：
# ratio: 16:9 | # 输出规格: 4K/30fps

负面提示词（全片通用）：写实照片感、3D 渲染、真人化、复杂纹理背景、多余手指、肢体畸形、
可读文字、字幕、水印、logo、血腥暴力、动物虐待、比例漂移、非三头身比例、身体比例失调、
换脸、服装变化、风格滑向写实。
```

## 转场注记总表

```
镜1（讯问室）→ 镜2（楼梯间）：全片唯一倒叙闪回。镜1落幅静帧保持 0.5s，黑场 0.3s
（低频嗡鸣骤停），楼梯间环境声渐入、画面自下而上渐亮。
镜3b（街景）→ 镜4（仓库）：时间转场（深夜 → 次日白天）。黑场 0.5s + 环境音淡出，
次日白天黄色光效自下而上渐入，避免时空误判。
镜5（仓库门口）→ 镜5b（仓库内）：同空间硬切，光位延续暖黄侧光，阴影渐浓。
镜6（仓库内剪影）→ 镜6b（仓库门口）：旅客甲从逆光剪影中走出，面部与服装细节在侧光中逐层显现。
镜6b（邮轮港外）→ 镜7（旅检大厅）：环境声硬切，切至港口嘈杂人声与广播声由远及近渐入。
```

## 单镜提示词完整示例（镜 8｜欲逃被控 · 三段快切 · 国际面）

```
镜 8｜欲逃被控（10s）
场景：海关查验台旁（浅蓝白）｜人物：旅客甲、查验员乙、值守员
生成视频：镜8｜欲逃被控
整体风格：2D 手绘卡通动画，粗黑轮廓线，平涂色块，卡通着色，Q 版三头身。本镜材质继承风格锚：
平涂色块，硬边单色阴影，画面保持干净色块。出场对象逐一识别：旅客甲（黑色短发带闪电形灰色高光、
深灰西装、白衬衫、黑鞋）；查验员乙（寸头、深蓝制服、神情沉稳）；值守员（深蓝制服、身形敦实）。
场景为海关查验台旁，高亮光线，浅蓝白色调，弧形天花板嵌白色灯带。三段快切结构，切点干净利落。
本镜保真预算：主 = 查验员乙的眼神与旅客甲的微表情；次 = 动作的干净收束；省 = 背景陈设与大厅群像。
本镜光色基调：浅蓝白（暴露）——高亮、空旷、无处可藏。色彩预算：单一色系，全片落在浅蓝白
区间，饱和度压至最低。

时间线分镜：
Shot 1 (0-2s): 特写，固定机位。X 光机屏幕占满画面，屏幕是一块高亮浅绿纯色块，内部保持空白，
只留屏幕自身的发光质感，供后期合成 X 光图像。背景虚成一片浅蓝白色块。
Sound: 查验大厅远距离人声嗡鸣，广播底噪。
Shot 2 (2-6s): 特写，固定机位，随视线轻微横移。查验员乙，寸头，深蓝色制服。他眯起眼睛，目光缓缓
扫向画面外的旅客甲，镜头跟着他的视线轻微横移，落在旅客甲僵硬的步伐与微隆的腰腹上。此时查验员乙心声起
（内心独白，画外音，音色压轻、带轻微混响）：「箱子没问题，动作不太对劲。」
Sound: 心跳从微弱起步，衣料摩擦声。
Shot 3 (6-10s): 中景，固定机位。旅客甲察觉查验员乙的视线停在自己微隆的腰腹上，神色骤紧；趁查验员乙
视线稍移，他猛然转身欲跑，身后带卡通速度线；值守员快步上前将他稳稳按住，动作干净利落，
画面在按住的瞬间定格。查验员乙开口对白（平稳专业）：「请配合前往人身查验室。」
Sound: 布料闷响，急促鼻息在按住的瞬间戛然而止。

声音设计（四层混音）：
环境层：查验大厅远距离人声嗡鸣、广播底噪（极弱）
动作层：衣料摩擦声与脚步声贯穿；0:08 按住瞬间的布料闷响
呼吸层：旅客甲急促短鼻息，0:08 后戛然而止
逼近层：心跳声从 0:00 至 0:08 渐强，0:08 骤然停止
对白：0:02 查验员乙心声（内心独白，画外音，音色压轻、带轻微混响）：「箱子没问题，动作不太对劲。」；
0:08 查验员乙开口对白（平稳专业）：「请配合前往人身查验室。」

刚性约束：
必锁：卡通速度线为唯一表现逃跑的符号化元素；屏幕保持浅绿纯色块，内部空白，发光质感保留，
X 光图像由后期合成
可见性：屏幕内容停留在不可辨的色块状态，画面只呈现其发光质感
```

## 附：全局制作纪律（整片必出）

```
1. 风格铁律：全部镜头保持 2D 手绘卡通（粗黑轮廓线、平涂色块、Q 版三头身）；滑向写实/3D/真人化即失败，重出。
2. 投放面铁律：全片统一国际面 Shot N 骨架（或统一国内面【时间轴】骨架）；两套骨架禁止混用，禁止使用中文数字段号。
3. 参数卫生铁律：16:9、4K、30fps、时长一律写入 # 参数行，不进提示词正文；景深用视觉结果描述（"背景熔成色块"），f 值只在参数行注记。
4. 运动签名铁律：生成期只用节奏词汇进正文；抽帧、速度曲线、硬切一律在剪辑层执行，写入 # 后期行。
5. 正向表述铁律：正文只写"是什么"（必锁正向定义 + 可见性限定式），否定式只留在 Must not 行（≤1 行，仅文字/水印/字幕/logo）。
6. 保真预算铁律：每镜声明主/次/省三项；身份保真、动作幅度、场景密度三者不可同时要满。
7. 时长带宽铁律：单条提示词不超过 20s；超长按滑窗拆分，每窗独立自洽、角色重新用外观识别。
8. I2V 优先：项目素材库中的场景参考图与角色参考图直接作为首批 I2V 首帧/风格参考，逐镜以参考图为首帧，锁定主体身份与卡通风格；仅加入[动作/光线/镜头]描述。I2V 时只写颜色+轮廓，禁止重复服装名词。
9. 文字铁律：短信、X 光屏幕、报告正文、法条字幕一律后期合成。
10. 台词铁律：旁白与对白以剧本原文为准、一字不差（含引号内文字与法条），一律后期配音/合成，禁止缩写、改写或让 AI 自发生成台词文本；每镜声音设计中的「」引号内即锁定文案。
11. 出镜限制：动物只以局部色块（鳞片、六边形纹样）出现；某角色只以语音波形 + 手机屏幕存在——均用限定式表述（"画面只含…"），不用"零全貌/不露脸"。
12. 连续性铁律：逐镜记录 9 锚点台账（角色/道具/空间/屏幕方向/视线/光位/机位/动作态/声音态），转场注记写明状态交接。
13. 返修纪律：一次只改一个变量（运镜/色块基调/动作幅度）；每镜最多重 roll 3 次；细节丢失时降级为静帧 + 呼吸感。
14. 交付校验：交付前必跑 node scripts/check_prompt.mjs <file> --surface intl|cn，error 清零后方可交付。
```
