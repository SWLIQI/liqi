# 抽象表述判定口径

> 适用：所有画面正文（时间线段、镜正文、整合段正文）。台词、参数行、文档层说明不在此列。
> 配套脚本：`scripts/audit_literal.py`（机械扫描 + 分级报告）。
> 上位规则：`视听层_镜头文法与光色.md` 第四节「反形容词转译表」是本文件的速查版，冲突时以本文件为准。

## 一、两条判据（v5.21.0 由一条扩为两条）

### 判据一 · 演不出来（原有）

**模型能不能用身体、光、物演出来。**

能演出来＝具体，留。演不出来＝抽象，改。
判的时候把自己当成模型：只拿到这一句话，手上没有任何上下文，能不能把它画/演成一帧？

反面自测：如果一句话需要观众「读懂」才算成立（要体会、要联想、要共情），它就不是画面指令。

### 判据二 · 会被字面画出来（v5.21.0 新增，吸收老李漫剧实测）

🔴 **只过判据一不够。** 有一类写法**完全可执行**，模型也真的执行了——**只是执行的不是你想要的东西**。

三条实测病根（老李 `short-drama-director/references/model-adapters.md` §5.0.3 / `sd-combat-engine/references/combat-iron-laws.md` 铁律24）：

| 写法 | 模型实际做了什么 |
|---|---|
| 「剑海如**星河**倒泻」「如**深海鱼群**」 | 把比喻名词**真的画进画面**——画出一群鱼、一条河 |
| 「玉佩受油灯照射处有一片暖黄**光斑**」 | 出片**玉佩像打火机点了一簇火**（道具只要与光产生描写关联就被点火） |
| 「**禁**空镜开场」「玉佩**不**发光」 | 两条否定式全部被无视——**模型对否定不敏感、对词根敏感** |

**判据二的一句话**：**这句话里的名词，会被模型当成一个要画出来的东西吗？**

- 比喻的喻体（鱼群 / 星河 / 蜡 / 丝绸）→ 会被画出来 → 按 C 类删或改；
- 反光道具身边的光效词（光斑 / 受光 / 照射 / 映出 / 泛光 / 亮起）→ 会点火 → 走**零光效描写**（见 §二·K）；
- `不 / 禁 / 零` 后面挂的词根 → 会被当画面词 → 走**换词**而不是加否定（见 §二之五）。

> 判据一管「写不写得清」，判据二管「写清了会不会长歪」。**两条都过才算合格。**

## 二、必改九类（命中即改，无一例外）

### 1. 「X 得＋评价」程度结构

中文最隐蔽的一类，因为它看起来在写物理属性，实际在写评价。

| ❌ 原句 | 问题 | ✅ 改法（v5.21.0 修订） |
|---|---|---|
| 白得发光 | **最危险**——模型会真加辉光/泛光 | 面色白，两颊不见血色（**不许**写成"带蜡质光泽"，见下） |
| 黑得过分 | 过分是评价 | 发黑，几乎看不见眼白 |
| 细得过分 | 同上 | 腰身细，束腰处衣料收得极紧 |
| 瘦得脱了形 | 脱了形是评价 | 颧骨凸出，眼窝深陷，肩背撑不满衣袍 |
| 憔悴松弛 | 状态评价 | 眼窝深陷、两颊塌陷 |
| 安静得不像话 | 比喻式评价 | 删，或换成可观测（呼吸起伏幅度、无位移） |

**改法通则**：把「X 得」拆成**可观测特征 + 可对照的基准物**（几乎看不见眼白／撑不满衣袍／收得极紧——都是能构图能渲染的）。

> 🔴 **v5.21.0 修正——旧改法「肤色白、带蜡质光泽」是错的，两处违规**：
> ① **「蜡质」是喻体**（用蜡比皮肤），按**判据二**模型可能把蜡的质感画出来，且它本身是 C 类比喻，改了 A 犯 C；
> ② **「光泽」是光效词**，与"白得发光"同一个病根——换了个说法但没换掉辉光。
> **A 类的改法只许落到三类词上**：颜色（面色白 / 发黑）· 可见状态（两颊不见血色 / 渗出薄汗）· 对照基准（撑不满衣袍 / 几乎看不见眼白）。
> 皮肤可以写颜色与状态，**不写光泽**；光泽与光效一律按 §二·K 处理。

### 2. 孤句判断句（没有位置、光照、颜色）

| ❌ | ✅（v5.21.0 修订） |
|---|---|
| 月亮圆而惨白。 | 满月悬在檐角上方，月面惨白，边缘过亮，青白月光自上而下铺满院子。 |
| 屋里很暗。 | 烛火只照亮两人之间的一小片地面，砖墙与梁架隐进暗部（**不写"半尺"**，见 §二之二） |
| 她很美。 | **删**，或挂角色资产锚（`@CHR-xx 同一张脸`）——**不许**翻成"五官比例精确、左右对称"（见下） |

**惨白/发暗这类颜色词可留**，孤句判断不可留。补三件套：**位置（在哪）+ 光照（怎么亮）+ 颜色（什么色）**。

> 🔴 **v5.21.0 修正**：旧改法「五官的位置比例间距精确、左右完全对称」是**几何 / 数学属性**，模型做不到；
> 老李 C20m 实测这类"毫米级构图补偿"式写法塞进 2~4 秒镜行会**稀释人物动作权重并诱发画面无故晃动**。
> **"她很美"的正解是删或挂资产锚**——美是纯评价，没有单一可执行对应，硬翻只会翻出废话。
>
> **光照补强（吸收老李 `lighting-and-antifake.md` §四/§五）**：只写"暗 / 亮"仍缺落点，补两个**带观感锚的分档量化**——
> `光比 1:8`（观感表：1:2 平 / 1:4 立体 / 1:8 压得住 / 1:16 强反差）、`主光 3200K 暖 + 轮廓 6500K 冷`。
> 这两档**允许写**（见 §二之二：带观感锚 ≠ 裸度量）；禁的是"强反差""冷暖对比"这类**无锚形容词**。

### 3. 画面正文里的比喻

| ❌ | ✅ |
|---|---|
| 像旧绢的经纬 | 纹路横竖交错成织纹状 |
| 像画上去的一笔 | 边缘齐整、粗细均匀，末端比正常嘴角高一线 |
| 像一条黑色的带子拖在身后 | 斜影与他等长，影头伸到画面左下角 |
| 像蛇蜕的一角 | 半透明薄片，边缘由厚到透明，表面细密网格纹 |

**改法**：比喻拆成**形状 + 材质 + 度量**。
⚠️ **台词里的比喻一字不动**（台词铁律）。只动画面正文。

> 🔴 **v5.21.0 补强——C 类的真实危害不是"不可执行"，是"会被字面画出来"（判据二）**。
> 老李 `combat-iron-laws.md` 铁律24 实测：写「剑海如**星河**倒泻」「如**深海鱼群**」，
> 模型会把**喻体名词直接画进画面**（真的画出一群鱼、一条河）。老李已据此**废止一切文学比喻**，改纯几何形态 + 物理运动轨迹。
> ⇒ **改法收紧一层**：拆完之后还要回读一遍——**喻体名词有没有残留？**（"蜡质""丝绸般""瓷器一样"都算残留）
> 有残留就按 §五 的**删**处理，不要硬翻。

### 4. 摄影/后期术语（模型会按字面执行）

| ❌ | 为什么危险 | ✅ |
|---|---|---|
| 瞳孔空焦 / 焦点不在任何东西上 | **模型会真把眼睛生成失焦** | 瞳孔不收不放，视线不落在（某人/任何一张脸/任何物体）上 |
| 焦点虚化背景 | 需要景深参数 | 背景虚化不抢主体（景深用视觉结果写） |
| 面部肌肉不动 | 生理不可能，模型会僵脸 | 只写需要的那一处（下颌绷紧／咬肌隆起） |
| 空镜、留白、意境 | 无画面内容 | 换成具体空镜内容（门槛外青石板、湿了一小片） |

> 🔴 **v5.21.0 补强（吸收老李 C20m「摄影机理论废话拦截」+ 防补丁打补丁铁律）**：
> 本类还有一类**以前没管住的写法**——**摄影机理论废话**。
> 老李实测：把 `85mm F1.4 极浅景深（焦平面全程死锁面部无漂移）`、`保持极细微规律呼吸式微动`、`毫米级构图补偿`、
> `画面线条笔直构图平整` 塞进 2~4 秒镜行，会**严重稀释人物动作 Token 权重并诱发画面无故晃动**。
> **处置不是"写得更精确"，而是分流**：焦段 / 光比 / 色温收敛进段首风格栏，
> **镜行正文只留「景别 · 角度 · 运镜 + 纯物理动作 + 句尾一句光影锚」**。
> 判据一句话：**这句话是在让画面动起来，还是在描述画面有多讲究？后者一律移出正文或删。**

### 5. 不可控时长

| ❌ | ✅ |
|---|---|
| 许久、良久、半天、一会儿 | 停两息 / 约两秒 / 三次呼吸 |

时间轴上的拍长是硬约束，模糊时长会让模型自行决定节奏，与后续拍对不上。

> 🔴 **v5.21.0 补强（吸收老李时码制）**：**能落进时码的就不要留在正文里当状语**。
> 老李镜行头是 `00:05-00:08 [镜头3] 特写 · 微仰 · 固定`，时长由**段头时码**承载，正文不写"停顿了一会儿"。
> ⇒ 优先序：**段头时码（首选） > 可数拍（停两息 / 三次呼吸） > 秒数状语（约两秒，末位）**。

### 6. 剪辑语进正文

闪回 / 叠化 / 转场 / 切 / 蒙太奇 / 时间跳 / 定格 / 慢放。

| ❌ | ✅（v5.21.0 修订） |
|---|---|
| 闪回三连 | 特写三格短切 各一拍（素材复用，见可见性） |
| 叠化转场 | **剥离进转场注记表**（见下）——正文只写"本段末帧停在…" |
| 画面定格 | 末拍静止，画面停在这一帧上收束 |

🔴 **v5.21.0 修正——旧改法「分两次生成，后期硬切」是错的**：那是**制作注记**，不是画面描述。
老李 `engineering-language-cleanup.md` §十一 判据：**凡是"描述镜头之间关系"或"给创作者看的标注"，一律不是画面事实**——
要么转成"画面里看得见的东西"，要么**直接剥离**。老李机检 C12 同样拦截「末态继承 / 拼接节点 / 换机位」等工作流规则名词进正文。

⇒ **F 类的正解是"剥离"不是"翻译"**：转场方式、生成批次、后期工序一律写进
**Step 5 转场注记总表 / 段缝声明**（liqi 已有这个归宿），**镜行正文只留这一段的最后一帧停在哪**。

**例外**：**素材复用型**「闪回」不算剪辑语——必锁／可见性里写「复用已有成片素材」是可以的，但**镜头字段与正文里不能出现「闪回」二字**。

### 7. 模糊指代

| ❌ | ✅ |
|---|---|
| 某种东西 / 某个物件 / 一团什么 | 给出材质与轮廓：一块对折的皮料片，边缘刻刀弧线清楚 |
| 他做了个动作 | 写出动作本身 |

> 🔴 **v5.21.0 补强（吸收老李 C20b 悬空指示代词 + 道具单实例锁）**：模糊指代不止"某种东西"一种形态。
> ① **悬空指示代词**——「这只手」「那张脸」无归属定语，模型会自己补一个头 / 补一只手；
> ② **物件只给材质不给数量与绑定**——必须写清**数量限制 + 绑定位置 + 移动后原位变化**，
> 否则出片"桌上一个、手里一个、背景又一个"。
> ⇒ 完整写法 `一件（数量）对折的皮料片（材质轮廓），攥在他右手（绑定），离手后桌面空出一块（原位变化）`。

**例外**：高敏感规避场景里**刻意**的模糊是允许的（「一块看不出是什么的软物件」），但必须**同时给材质与形状兜底**，让它模糊得可控。

### 8. 画面行里的听觉词

| ❌ | ✅ |
|---|---|
| 死寂中，他抬起头 | 他抬起头（声音归声音设计层） |
| 一片寂静里 | 删 |

画面行只管看得见的。听觉进四层混音，不进画面正文。

> 🔴 **v5.21.0 补——H 类只管"画面行"，声音层是豁免区（吸收老李听觉层豁免）**：
> 老李 `cinematic-dramaturgy-rules.md` §四注与 `model-adapters.md` §5.2.4 明写：
> **反形容词规则只约束画面段**——语气位、`声音：` 段、【音效】段**不受约束**，可以用质地与力度词
> （`嘶哑` / `低语` / `气音` / `冷笑`，官方对白范例即 `warm, low voice`），**因为声音没有"肌肉动作"可写**。
> 但声音层**同样禁空泛结果词**：`难过` / `生气` / `开心` 既非音质也非力度，是结果，一律禁。
> ⇒ 判据一句话：**画面段按 H 类删听觉词；声音段按"禁结果词"管，不禁质地词。**

### 9. 神情/内心的评价词

松、稳、沉、空、茫然、若有所思、心事重重、眼里没有光。

| ❌ | ✅（v5.21.0 修订） |
|---|---|
| 眼神空洞 | 瞳孔不收不放，目光不落在任何一张脸上 |
| 神情复杂 | 眉毛先扬后蹙，视线撞上她又弹开 |
| 眼里没有光 | 上眼睑压下来遮住瞳孔上缘，眼神发直（**不许**写"遮住三分之一虹膜"，见下） |

> 🔴 **v5.21.0 修正**：旧改法「上眼睑下垂遮住**三分之一虹膜**」是**微观解剖度量**——模型量不出虹膜被遮了几分之几。
> 见 §二之二：**裸度量禁输出**。改成可命名的形态变化：「压下来遮住瞳孔上缘」。
> 同类禁写：`瞳孔放大 3 毫米`、`嘴角上提 15°`、`露出八颗牙`。
>
> 🔴 **补一条老李实测陷阱（模型默认加甜笑）**：冷硬 / 宣判 / 质问类台词的角色，**画面段必须显式写反向肌肉动作**
> （双唇抿紧、嘴角向下压、下颌绷紧、眉梢下压），不写则模型对年轻女性角色**默认渲染露齿甜笑**，成片情绪直接反掉。

## 二之二、数值二分法：裸度量禁输出，带观感锚的分档量化可写（v5.21.0 新增）

> 来源：老李 `sd-combat-engine/references/combat-iron-laws.md` 铁律19。
> 这条解决一个 liqi 一直没判准的问题：**"写具体"和"写精确"是两回事，精确过头一样不可执行。**

| | 内容 | 处置 |
|---|---|---|
| **A. 裸度量（禁输出）** | 厘米 / mm、**距主体 X 米**、m·s⁻¹ 速度、Bloom 值、径向形变 %、鱼眼 %、震屏 %、f 值光圈、**微观解剖度量**（遮住三分之一虹膜 / 瞳孔放大 3 毫米 / 嘴角上提 15°） | **删或降级**——模型在画面里找不到落点，写了也不执行 |
| **B. 带观感锚的分档量化（可写）** | `光比 1:8`（配观感表）、`主光 3200K / 轮廓 6500K`（配冷暖观感）、档位枚举 | **保留**——每一档都挂了可辨认的观感，模型能照着摆 |
| **C. 宏观叙事尺度四件套（必写）** | ① 画框分数占比（占画面 1/2 / 七成）② 宏观物理量级（宽达上百米，**约数不用精确小数**）③ 参照物（比人 → 比建筑 → 比山 → 比天地）④ 人物在画框中的位置与占比 | **补上**——大场面 / 大特写的规模靠这四件落定 |

**判据一句话**：**这个数字，模型能在画面里找到落点吗？** 有观感锚或参照物＝能，裸工程单位＝不能。

> 🔴 **由此修正本库一处硬伤**：`光学与空间语言块.md` §四 空间弱词替换表教写「距 X 一米以内」「距查验台一米」，
> 属 A 类裸度量，**与本条冲突**。v5.21.0 起改为**画框分数 + 接触动词 + 固定锚物**（见该文件 §四）。
> **做对的一条保留**：本库「景深写视觉结果不写 f 值」与老李同向（f 值在 A 类），不动。

## 二之三、J 类：动作可生成度（v5.18.0 · 独立轴，**不计入九类**）

> 来源：船长套件 `script-pass.md` 硬规则 4。**与九类是两条不同的轴，别混**：
> **九类**管「**抽象 → 具体**」的转译（「他很愤怒」→ 咬肌隆起）；**J 类**管「**具体但做不到**」的降级
> （「伸篙一挡」有动作有物理，但三物交互必崩）。**九类计数不变**——把 J 并进九类会让「九类」这个
> 口径在全库六处文件的表述全部失准，且语义错位。

**一句话判据**：**这个动作在生活视频里常见吗？** 模型只会演它见过千万次的动作。

| | 例 | 处置 |
|---|---|---|
| ✅ 放心写 | 上船、坐下、递东西、点头、回头、抱紧、站起来——常见动作的**组合与时机**给戏 | — |
| ❌ 改写或删 | 用工具挡住某物（篙/担/船帮三物交互）；文学化微动作（睫毛颤）；以寸计的位移（退了半寸）；比喻性画面（像被雾攥住的茧） | 换成常见动作，或删；比喻性画面同时命中 C 类 |

**写法定则**：**戏剧信息靠常见动作的组合与时机给，不靠动作本身的精巧。**

**机检**：`audit_literal.py` 的 **J 类**（词表命中报候选，走「只报候选不判真伪」同口径）。已收录：
`睫毛/眼睫/睫羽 + 颤/抖动`、`以寸计 / 寸许 / 半寸 / 挪了半寸 / 收了半寸 / 退了半寸`、`指尖 + 颤/抖/蜷缩`。

### 🔴 与 FACS 的边界（必读，否则两套规则互殴）

船长禁「睫毛颤」，liqi 的 `表演层_FACS微表情.md` 却要求写「眼睑撑开」——**表面冲突，实质不冲突**：

| 判据 | FACS 允许（保留） | J 类禁（改写） |
|---|---|---|
| 结构化 | 具名肌肉 + 可见动作 + 强度档 + 持续秒数 | 无量无幅度的文学化微描写 |
| 模型能否当动作执行 | 眼睑撑开 / 眼尾眯 / 嘴角上提 / 眉心拧住——见过千万次 | 睫毛颤 / 眼神一黯 / 退了半寸——没见过或量级太小 |

**裁决**：FACS 的肌肉动作**全部保留**（它是「常见动作」的面部变体，只是限定在面部）；J 类只收外层微描写。
⇒ **J 类词表严禁收录「眼睑 / 嘴角 / 眉心 / 眉头上扬 / 眼尾」等 FACS 结构词**（脚本内有同款注记，
改词表前先读本节）。覆盖面部的写作仍走 FACS 四区 + 分层铁律，不走 J 类。

## 二之四、K 类：道具光效 —— 零光效描写（v5.21.0 新增 · 第二个独立轴，**不计入九类**）

> 来源：老李 `model-adapters.md` §5.0.3 / `h3-adapter.md` 法则23 / 机检 **C20d · C18e**。
> 与 J 类同例：**独立轴，不计入九类**——九类管「抽象 → 具体」，本类管「**写具体了反而长歪**」（判据二的典型）。

**一句话**：反光道具**只写材质本色**，光效从句一律不写。

**实测病根（老李「重生70」EP01 拉片）**：

| 写法 | 出片 |
|---|---|
| 玉佩受油灯照射处只有指甲盖大的一片暖黄光斑 | **玉佩像打火机点了一簇火** |
| 玉面映出 / 倒映火苗 | 玉面画出小火苗、整体泛光 |
| 举向油灯冲光 | 透光自发光 |
| 改写成"侧受光" | ⚠️ 老李实测**仍点火**，旧建议已废止 |

**两条硬规则**：

1. **零光效描写**——`光斑 / 受光 / 照射 / 照在 / 映出 / 倒映 / 泛光 / 亮起` 类从句**一律不写**。
   正解只留材质本色：`玉体呈深青色实心石质、哑光质感，玉面呈青玉原色`。
2. **触发器移除**——诱发被禁效果的**动作本身**换掉：道具与灯火**彻底解耦**，
   动作只留「把玩 / 随身佩戴」，不靠近任何光源。

**主光源另找承接者**：油灯 / 火把 / 窗光要在镜行里**复述在人物身上**（`油灯暖光照着她的下颌`），
但**不得与反光道具同句共现**。

**适用对象**：玉佩 / 银镯 / 宝石 / 镜面 / 金属 / 瓷 / 漆 / 玻璃 / 水面等**反光物**。
（人物皮肤不在此列——皮肤写颜色与可见状态，见 A 类。）

**机检**：`audit_literal.py` 的 **K 类**（报候选不判真伪，与 J 类同口径）。

## 二补、S 类：高敏感画面表述（高危，命中即退 exit 2）

`audit_literal.py` 在九类之外另设 S 类（高危，与 A/D/F 同类）。这类不是「表述抽象」，是**平台口径与画面安全**——命中的候选没有「误报源四件套」可剔除，只有改法：

| 子类 | 命中示例 | 改法 |
|---|---|---|
| 伤情本体入画 | 伤口 / 渗液 / 渗血 / 血迹 / 流血 / 红肿 / 破皮 / 溃烂 / 结痂渗 | 五手法兜底：**画外 / 前景遮挡 / 局部特写 / 逆光暗部轮廓 / 空镜承接**——只给结果不拍过程 |
| 剪影当唯一呈现 | 「剪影站着」「暗部中的人影立在……」 | 模型读不懂「剪影」二字；改给正面/侧面，并写明光怎么落在脸上 |
| 儿童与危险物口径过严 | 「全程不与火同框」「始终不与危险同框」 | 会与核心动作打架；改「不与危险**发生的瞬间**同框」 |

英文面（MiniMax H3）有对应规则，见 `audit_literal.py` 的英文规则段。S 类与九类一样**报候选不判真伪**，但 S 类没有「可留」情形——看见就按上表改。

## 三、必留类（扫描时先剔除，别误删）

以下看着像抽象，实际可执行，**一律保留**：

| 类别 | 实例 | 为什么留 |
|---|---|---|
| 段末收束体例 | 画面渐黑收束 / 黑场 / 画面停在…上收束 | 全片统一体例，不是文学描写 |
| 视线落点 | 目光从 X 移到 Y、视线停两息、眼神躲闪 | 身体动作 + 落点，模型可执行 |
| 极细/极轻/极缓 | 极细的暗线、极轻的一响 | 修饰的是已给的动作，有参照 |
| 生理极限描述 | 几乎看不见眼白、脸色惨白 | 可渲染 |
| 尺寸与比例 | 腰身细、肩宽腰细、腰身窄得古怪 | 有对照基准，可构图 |
| 台词内容概括 | 心虚 / 醒悟 / 魂散了一半 | 属剧本语义，台词铁律管，画面层不动 |
| 高敏感的刻意留白 | 看不出是什么、字朝里看不见 | 过审策略，已配材质兜底 |

## 四、误报源四件套（扫「像」字必先剔除）

扫描命中「像」时，先剔除这四类再判断是否比喻：

- **群像**（群像戏、众生相——"像"多为"图像/影像"义或"好像"的比较）
- **画像**（寻人画像、肖像画——是实体物件）
- **镜像**（镜中构图、镜像关系——是空间关系）
- **影像**（影像资料、成像——是名词）

同理，扫「空」要剔除：空间、空气、空隙、天空、空镜（空镜是合法镜头类型）。
扫「松」要剔除：松散的动作描写里的"松开手"（松开是具体动作，松弛才是评价）。

## 五、改法优先级

命中后按这个顺序挑改法，别硬套：

1. **换成具象动作**（首选）——两三个连续的身体动作，或一个**可命名的形态变化**
2. **删**（v5.21.0 由末位提到次位）——**画不出来就删，不要硬翻**
3. **换成材质与形状**（物件适用）——名词 + 可观测特征
4. **换成可对照的基准**（程度类适用）——「几乎看不见眼白」这种拿身体部位当尺子
5. **换成光效**（**末位**）——亮度/方向/颜色/范围的变化，**且必须先过 §二·K 类**（反光道具禁光效）

> 🔴 **v5.21.0 重排——为什么"删"从最后手段提到第二位**（吸收老李 C20c 与用户实测）：
> 老李判据一句话：**这句里每个词都能画出来吗？画不出来的就是形容词——删掉，或换成具象动作。**
> 实测两处：「漏雨**成线**砸在手背上」→ 写「**雨滴**砸在手背上溅开」就够；「手指**轻蜷**」→ AI 理解不了，**直接删**。
> 硬翻的代价是**翻出一条新的抽象**（旧版"她很美"→"五官比例精确"就是典型），删掉反而更干净。
> 光效降到末位同理：它在反光道具上是**病根不是解法**（见 K 类实测"玉佩点火"）。

⚠️ **改完必须回读三遍**（v5.21.0 由一遍扩为三遍）：

1. 有没有改出**新的抽象**？（最常见：换成动作序列时又写进评价词）
2. **喻体名词有没有残留？**（判据二——蜡质 / 丝绸般 / 瓷器一样都算残留）
3. 有没有引入**裸度量或几何属性**？（§二之二——三分之一虹膜 / 距 X 一米 / 85mm）

### 五之补、词根敏感三改法 + 高低关联分界（v5.21.0 新增）

> 来源：老李 `model-adapters.md` §5.0.4。**模型对否定不敏感、对词根敏感**——
> 被禁概念的词根留在提示词里（哪怕前面挂着"不/禁"），就成了喂给模型的画面词。
> 实测三条否定式（禁空镜开场 / 玉佩不发光 / 面无笑意）**全部被无视**。

| 改法 | 做什么 | 例 |
|---|---|---|
| **一 · 换词** | 被禁词根**零出现于提示词任何位置**（含 Must not 行） | `不发光` → `玉面呈青玉原色`；`面无笑意` → `双唇抿紧、嘴角向下压、下颌绷紧`；`禁空镜开场` → 镜 1 首分句直接写主体 |
| **二 · 主体优先句式** | 每段镜 1 第一个分句即画面主体（人名开头或"画面主体：<人名>"） | 环境前置词开头（"土炕上…""房梁下…"）会诱导模型渲染**空场景开场**（实测两轮出空房间） |
| **三 · 触发器移除** | 换掉**诱发被禁效果的动作/构图本身** | 「举向油灯冲光」是透光自发光的构图触发器 → 道具与灯火彻底解耦 |

**高低关联分界（liqi 此前完全没有的一条）**：

| 类型 | 例 | 处置 |
|---|---|---|
| **低关联瑕疵**（模型本就不倾向生成） | 水印 / 变形 / 字幕 / 现代元素 / logo | **否定式兜底够用**，走 Must not 行 |
| **高关联倾向项**（模型有强默认倾向） | 表情（默认甜笑）/ 开场（默认加建立镜头或空镜）/ 道具光效（默认点火）/ 视线（默认盯道具） | **否定式是废纸**，必须走镜行内正向描写或**触发器移除** |

### 五之补二、正向描写的密度纪律（v5.21.0 新增）

> 来源：老李 `model-adapters.md` §5.0.4「镜行少形容词」。

**正向描写每镜只留必要项**——主体、动作、材质 / 光**各写一处即可**。
修饰词堆叠（「深青色实心哑光石质原色＋暖黄反光＋冷硬下颌」连排）会**稀释关键信息、拉低模型对每条指令的服从率**。

写完扫一遍：**与本镜主体无关的形容词一律删掉。** liqi 既有的「低细节清单」管的是"哪五类不该写"，
本条管的是"**该写的也别写多了**"——两条互补。

## 六、模型默认倾向陷阱（v5.21.0 新增 · liqi 此前完全缺失的一层）

> 来源：老李 `model-adapters.md` §5.0.2–§5.0.3、`prompt-feeding-checklist.md` 第 12 项、机检 C16d / C18c / C20g。
> **九类管的是"你写错了什么"，本节管的是"你没写，模型自己会加什么"。**
> 这一类**不做机检**（语义项，做成门就是假绿门），但写镜时必须逐条自查。

| 默认倾向 | 触发条件 | 必写的反向锚 |
|---|---|---|
| **默认甜笑** | 年轻女性角色 + 冷硬 / 宣判 / 质问类台词 | 画面段显式写肌肉动作：双唇抿紧、嘴角向下压、下颌绷紧、眉梢下压 |
| **默认加建立镜头 / 空镜** | 生成时长富余时 | 镜 1 首分句直接写主体（改法二），空镜要显式声明且每段至多 1 镜 |
| **默认盯道具** | 手持 / 把玩道具说话 | 补「目光落在 XX 脸上，视线不落在道具上」；盯道具是戏时则明写「盯住 XX」 |
| **一镜多视线** | 「先看 A 再转回 B / 依次扫过 A、B、C」 | 每镜只锁 **1 个**视线落点（短镜内连转必崩） |
| **多张参考图 = 多个人** | 4 View 四张裁片齐投 | 补「以上素材描述的是同一个人物，不出现重复、分裂或镜像身影」 |
| **并列句式出两张脸** | 「X 与 Y 同框」「首帧即这只手与脸同框」 | 改成单主体句式（老李 C20a 实测：并列句式渲染出两张脸） |

## 六之二、M 类：模型行为禁用字（v5.35.0 新增 · 治「门禁全绿但片子坏了」）

> 来源：phileiny/h3-storyboard-skill §五之三（2026-09 系列实测）。与 §六「模型默认倾向」是同一枚硬币的两面：
> §六 管「你不写它也会加」，本节管「**你写了，它反而照着字面做错**」。
>
> **为什么单独立一类**：下面每一条都不触发本脚本其他任何规则，也不触发 check_prompt 的格式检查、
> audit_risk 的敏感词检查——**门禁全绿，但出片必坏**。这是最危险的一类缺陷。

### 8.1 六类禁用写法

| 序号 | 不要这样写 | 模型实际会怎么做 | 改成 |
|---|---|---|---|
| M1 | `nothing about her changes`／「她什么都没变」／「什么都不变」 | **整颗冻结**——连底噪的呼吸、眨眼、衣料微动全部消失 | 正面陈述 + 明写底噪：「只有右手在动，其余保持」，并补一句底噪动作（呼吸起伏／眨眼一次／衣料微动） |
| M2 | `no push in, no zoom, no dissolve`／「不要推轨、不要变焦」 | **剪点反而漂到 3.5 秒后**——否定句被模型当成「这里有剪辑点」的信号 | 改正面陈述；确需固定机位时写「机位固定，画面静止」 |
| M3 | `widening`／`spreading`／「画面扩大」「向外蔓延」 | **无终点地扩大**，停不下来 | 给终点：「扩大到容纳三人即停」 |
| M4 | `about two thirds as tall as the frame`／「占画面三分之二」 | **被忽略**（实测只到 45–52%，且不稳定） | 讲**裁切关系**：「头顶齐画框上沿，脚底切在膝下」 |
| M5 | 「距桌子 80 厘米」「距离镜头两米」 | **带单位的距离被忽略** | 用参照物比例：「一臂之差」「一步之遥」 |
| M6 | 提示词里出现**不该入镜**的物件名 | **模型会把它画进来** | 只写画面里要有的（详见 8.2） |

### 8.2 M6 为什么最难防

M1–M5 是「写法问题」，改句子就行。**M6 是「射程问题」**：

- 你以为在共用段写「她戴着母亲的银镯」只是身份交代，模型会当成「这一镜必须出现银镯」；
- 你在光的描述里写「烛火」，模型就在没有烛火的场景里点一支；
- **规则本身的射程比你想的宽**——同一份提示词内部，A 段的约束会溢到 B 段。

判据一句话：**这句话是让模型画出来的，还是让你照着填的？** 后者一律放文档层，不要进正文。

（这与 v5.4.2「可复制正文里只写模型要执行的话」是同一条纪律的两个方向：那条管「别把元指令写进正文」，这条管「别把不需要的物件名写进正文」。）

### 8.3 机检边界

| 条目 | 谁来查 |
|---|---|
| M1–M5 | **脚本**（`audit_literal.py` 的 M 类规则，**高危，命中退 exit 2**） |
| M6 | **人**（需要知道「这一镜不该出现什么」，是语义判断，脚本抓不到） |

## 七、与脚本的分工

| 环节 | 谁做 |
|---|---|
| 机械扫描（九类 + J / K / S 独立轴 + 误报剔除） | `scripts/audit_literal.py` |
| 判定"是不是真抽象" | 人（脚本只报候选，带上下文） |
| 判据二"会不会被字面画出来" | **人**（语义判断，脚本不判） |
| 改法选择 | 人（按第五节优先级） |
| 默认倾向自查（§六） | **人**（不做机检，语义项） |
| 改后复扫 | 脚本 |

脚本的定位是**不漏**，不是**不误报**。它的输出全是候选，命中率高但必然有误报；价值在于人工扫会漏，脚本不会。

```bash
python scripts/audit_literal.py <提示词包.md> [--detail]
```

退出码：0 干净 / 1 有候选待判 / 2 有高危候选（白得发光类、摄影术语类、剪辑语类）。
