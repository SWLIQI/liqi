# 抽象表述判定口径

> 适用：所有画面正文（时间线段、镜正文、整合段正文）。台词、参数行、文档层说明不在此列。
> 配套脚本：`scripts/audit_literal.py`（机械扫描 + 分级报告）。
> 上位规则：`视听层_镜头文法与光色.md` 第四节「反形容词转译表」是本文件的速查版，冲突时以本文件为准。

---

## 一、唯一判据

**模型能不能用身体、光、物演出来。**

能演出来＝具体，留。演不出来＝抽象，改。
判的时候把自己当成模型：只拿到这一句话，手上没有任何上下文，能不能把它画/演成一帧？

反面自测：如果一句话需要观众「读懂」才算成立（要体会、要联想、要共情），它就不是画面指令。

---

## 二、必改九类（命中即改，无一例外）

### 1. 「X 得＋评价」程度结构

中文最隐蔽的一类，因为它看起来在写物理属性，实际在写评价。

| ❌ 原句 | 问题 | ✅ 改法 |
|---|---|---|
| 白得发光 | **最危险**——模型会真加辉光/泛光 | 肤色白、带蜡质光泽 |
| 黑得过分 | 过分是评价 | 发黑，几乎看不见眼白 |
| 细得过分 | 同上 | 腰身细，束腰处衣料收得极紧 |
| 瘦得脱了形 | 脱了形是评价 | 颧骨凸出，眼窝深陷，肩背撑不满衣袍 |
| 憔悴松弛 | 状态评价 | 眼窝深陷、两颊塌陷 |
| 安静得不像话 | 比喻式评价 | 删，或换成可观测（呼吸起伏幅度、无位移） |

**改法通则**：把「X 得」拆成**可观测特征 + 可对照的基准物**（几乎看不见眼白／撑不满衣袍／收得极紧——都是能构图能渲染的）。

### 2. 孤句判断句（没有位置、光照、颜色）

| ❌ | ✅ |
|---|---|
| 月亮圆而惨白。 | 满月悬在檐角上方，月面惨白，边缘过亮，青白月光自上而下铺满院子。 |
| 屋里很暗。 | 烛火只照亮两人之间半尺范围，暗部保留砖缝。 |
| 她很美。 | 五官的位置比例间距精确，左右完全对称。 |

**惨白/发暗这类颜色词可留**，孤句判断不可留。补三件套：**位置（在哪）+ 光照（怎么亮）+ 颜色（什么色）**。

### 3. 画面正文里的比喻

| ❌ | ✅ |
|---|---|
| 像旧绢的经纬 | 纹路横竖交错成织纹状 |
| 像画上去的一笔 | 边缘齐整、粗细均匀，末端比正常嘴角高一线 |
| 像一条黑色的带子拖在身后 | 斜影与他等长，影头伸到画面左下角 |
| 像蛇蜕的一角 | 半透明薄片，边缘由厚到透明，表面细密网格纹 |

**改法**：比喻拆成**形状 + 材质 + 度量**。
⚠️ **台词里的比喻一字不动**（台词铁律）。只动画面正文。

### 4. 摄影/后期术语（模型会按字面执行）

| ❌ | 为什么危险 | ✅ |
|---|---|---|
| 瞳孔空焦 / 焦点不在任何东西上 | **模型会真把眼睛生成失焦** | 瞳孔不收不放，视线不落在（某人/任何一张脸/任何物体）上 |
| 焦点虚化背景 | 需要景深参数 | 背景虚化不抢主体（景深用视觉结果写） |
| 面部肌肉不动 | 生理不可能，模型会僵脸 | 只写需要的那一处（下颌绷紧／咬肌隆起） |
| 空镜、留白、意境 | 无画面内容 | 换成具体空镜内容（门槛外青石板、湿了一小片） |

### 5. 不可控时长

| ❌ | ✅ |
|---|---|
| 许久、良久、半天、一会儿 | 停两息 / 约两秒 / 三次呼吸 |

时间轴上的拍长是硬约束，模糊时长会让模型自行决定节奏，与后续拍对不上。

### 6. 剪辑语进正文

闪回 / 叠化 / 转场 / 切 / 蒙太奇 / 时间跳 / 定格 / 慢放。

| ❌ | ✅ |
|---|---|
| 闪回三连 | 特写三格短切 各一拍（素材复用，见可见性） |
| 叠化转场 | 分两次生成，后期硬切 |
| 画面定格 | 末拍静止，画面停在这一帧上收束 |

**例外**：**素材复用型**「闪回」不算剪辑语——必锁／可见性里写「复用已有成片素材」是可以的，但**镜头字段与正文里不能出现「闪回」二字**。

### 7. 模糊指代

| ❌ | ✅ |
|---|---|
| 某种东西 / 某个物件 / 一团什么 | 给出材质与轮廓：一块对折的皮料片，边缘刻刀弧线清楚 |
| 他做了个动作 | 写出动作本身 |

**例外**：高敏感规避场景里**刻意**的模糊是允许的（「一块看不出是什么的软物件」），但必须**同时给材质与形状兜底**，让它模糊得可控。

### 8. 画面行里的听觉词

| ❌ | ✅ |
|---|---|
| 死寂中，他抬起头 | 他抬起头（声音归声音设计层） |
| 一片寂静里 | 删 |

画面行只管看得见的。听觉进四层混音，不进画面正文。

### 9. 神情/内心的评价词

松、稳、沉、空、茫然、若有所思、心事重重、眼里没有光。

| ❌ | ✅ |
|---|---|
| 眼神空洞 | 瞳孔不收不放，视线不落在任何一张脸上 |
| 神情复杂 | 眉毛先扬后蹙，视线撞上她又弹开 |
| 眼里没有光 | 瞳孔反光减弱，上眼睑下垂遮住三分之一虹膜 |

## 三、必留类（扫描时先剔除，别误删）

以下看着像抽象，实际可执行，**一律保留**：

| 类别 | 实例 | 为什么留 |
|---|---|---|
| 段末收束体例 | 画面渐黑收束 / 黑场 / 画面停在…上收束 | 全片统一体例，不是文学描写 |
| 视线落点 | 目光从 X 移到 Y、视线停两息、眼神躲闪 | 身体动作 + 落点，模型可执行 |
| 极细/极轻/极缓 | 极细的暗线、极轻的一响 | 修饰的是已给的动作，有参照 |
| 生理极限描述 | 几乎看不见眼白、脸色惨白 | 可渲染 |
| 尺寸与比例 | 腰身细、肩宽腰细、腰身窄得古怪 | 有对照基准，可构图 |
| 台词内容概括 | 心虚 / 醒悟 / 魂散了一半 | 属剧本语义，台词铁律管，画面层不动 |
| 高敏感的刻意留白 | 看不出是什么、字朝里看不见 | 过审策略，已配材质兜底 |

## 四、误报源四件套（扫「像」字必先剔除）

扫描命中「像」时，先剔除这四类再判断是否比喻：

- **群像**（群像戏、众生相——"像"多为"图像/影像"义或"好像"的比较）
- **画像**（寻人画像、肖像画——是实体物件）
- **镜像**（镜中构图、镜像关系——是空间关系）
- **影像**（影像资料、成像——是名词）

同理，扫「空」要剔除：空间、空气、空隙、天空、空镜（空镜是合法镜头类型）。
扫「松」要剔除：松散的动作描写里的"松开手"（松开是具体动作，松弛才是评价）。

## 五、改法优先级

命中后按这个顺序挑改法，别硬套：

1. **换成动作序列**（最稳）——给两三个连续的身体动作
2. **换成光效**（次稳）——亮度/方向/颜色/范围的变化
3. **换成材质与形状**（物件适用）——名词 + 可观测特征
4. **换成可对照的基准**（程度类适用）——「几乎看不见眼白」这种拿身体部位当尺子
5. **删**（最后手段）——确认删掉不影响叙事才删

⚠️ 改完必须回读一遍：有没有改出新的抽象？常见是「换成动作序列」时又写进了评价词。

## 六、与脚本的分工

| 环节 | 谁做 |
|---|---|
| 机械扫描（九类 + 误报剔除） | `scripts/audit_literal.py` |
| 判定"是不是真抽象" | 人（脚本只报候选，带上下文） |
| 改法选择 | 人（按第五节优先级） |
| 改后复扫 | 脚本 |

脚本的定位是**不漏**，不是**不误报**。它的输出全是候选，命中率高但必然有误报；价值在于人工扫会漏，脚本不会。

```bash
python scripts/audit_literal.py <提示词包.md> [--detail]
```

退出码：0 干净 / 1 有候选待判 / 2 有高危候选（白得发光类、摄影术语类、剪辑语类）。
