# 视听层：镜头文法与光色

> 🔗 流程位置：**Step 3 写镜头之前（三任务判定）与写光色之时**。
>
> 本层补的是 liqi 最大的空白：**liqi 有「怎么写」（光学语言块、去 AI 味），但没有「该写什么」**——它不会告诉你这个镜头值不值得存在、为什么这场戏看不下去。老李的 上游短剧工程体系的镜头文法模块（未随本仓库分发） / 其 15 条机位规格（未随本仓库分发） / 其光物理与防冷光规则（未随本仓库分发） 补的正是这一层。

## 一、 镜头三任务法则（写镜前第一问）

**在生成任何镜头前，强制该镜头必须承担以下至少一个明确任务。三项皆无的镜头一律剔除。**

| 任务 | 含义 | 例 |
|---|---|---|
| **改变人物情绪** | 从自信到慌乱、从伪装到破防、从冷酷到动容 | 听到名字的瞬间，握杯的手停住 |
| **实质推进动作** | 完成物理位移、攻防碰撞、破坏场景或传递道具 | 他把刀放下，推过桌面 |
| **施加戏剧压力** | 缩短距离、缩紧时间、逼入死角 | 门在身后关上，脚步声从走廊尽头逼近 |

**这一条是砍水最有效的工具。** 写完一镜自问：删掉它，观众会漏掉什么？答不上来就删。

## 二、 三大调度法则

1. **芬奇法则**：摄影机默认**静止沉稳**，只有画面主体发生状态改变（发现破绽、开始冲锋、重创倒地）时才跟随运镜，**运镜速度与主体运动 1:1 同步**。
   → 反过来说：**无状态改变的镜头不要运镜**。大量短片「镜头一直在飘」正是违反这条。

2. **斯皮尔伯格空间法则**：无论打斗或调度多激烈，**观众在任何一秒都必须清晰知道「主角在哪、威胁在哪、出口在哪」**。
   → 这是「激烈但不混乱」的标准。氛围镜头也得保留一个空间参照物。

3. **黑泽明环境压力法则**：全场必须由**一种主导的物理环境压力**贯穿（暴雨 / 狂风 / 水雾 / 碎石 / 频闪日光）。
   → 一种，不是五种。环境压力是把分散的镜头缝成一个世界的胶水。

## 三、 剪辑六律与 Eye-Trace

### 切镜优先级矩阵

```
情感真实 (51%) > 剧情推进 (23%) > 节奏节拍 (10%) > 视线引导 (7%) > 二维构图 (5%) > 三维空间 (4%)
```

**情感真实占一半以上**——这是为什么「构图完美但情绪没接上」的剪辑比「构图糙但情绪对了」的差得多。

### Eye-Trace 视线落点连续性

**上一镜观众视线落在画面哪个位置，下一镜切入瞬间的核心信息点必须精准承接在同一位置或顺势滑动。**

- 例：上一镜刀光从画面右侧出鞘 → 下一镜自右向左冲刺的流光核心
- **严禁让观众满屏寻找焦点**

**景别阶梯跃迁（防平铺）**：

- **严禁连续两个镜头使用相同景别 + 相同机位**
- 动作高潮前插入**极微距特写**（指尖发力 / 剑身微颤 / 眼眸神纹），浅景深虚化背景
- 大招释放用**宏观全景**展示环境破坏
- 绝杀收尾用**鸟瞰或过肩定格**，配合满天飞叶 / 烟尘扑镜实现自然遮挡转场

**极限景别跳跃**（长段高燃专属）：在**极微距特写 ECU** 与**极宏观大远景 EWS** 之间对跳，制造两极反差。与阶梯跃迁互补——阶梯管顺序推进，跳跃管两极反差。

### 四阶动静呼吸律

长段战斗（≥15s 或拆段成片）的节奏骨架：**静 → 极动 → 慢/滞 → 绝杀**

1. **静**：眼眸特写、平心擦剑、蓄势凝神，节奏压到最低
2. **极动**：空斩、贯穿、对冲、多段拆招
3. **慢 / 滞**：短蓄力——用 **1~2 个紧凑镜头快速带过**（⚠️ **升格慢镜默认禁用**，实测破坏节奏）
4. **绝杀定格**：最高情绪与视觉爽点释放，定格终帧

## 四、 反形容词转译表

**严禁空洞形容词，强制 100% 转译为摄影机可捕捉的物理事实。**

| ❌ 空洞形容词 | ✅ 摄影机可记录的物理事实 |
|---|---|
| 「他很愤怒」 | 咬紧后槽牙，咬肌剧烈隆起，下颌骨紧绷，指节捏得发白泛青 |
| 「激烈的打斗」 | 后脚蹬碎青砖，腰胯猛拧，拳峰重击下颚，断齿伴随血沫飞溅 |
| 「极具压迫感的光线」 | 左上方窗棂透入窄条天光，阴影深沉，半边脸颊隐入青灰暗部 |
| 「速度极快」 | 身形化作一道撕裂空气的残影，出招瞬间空气被击穿出细长气穴 |
| 「剑法高超」 | 剑尖沿极小侧弧绕开对手中线，寸劲直刺手腕，剑格碰撞爆出冷白星芒 |
| 「氛围感布光」 | 45° 主光从机位左打来，右侧柔光补面，顶部逆光勾出发丝轮廓（Level 3） |

**精度梯度**（同一概念从弱到强）：

```
Level 0 空泛（「氛围感布光」）
Level 1 类型（「戏剧肖像光」）
Level 2 布光（「三点布光」）
Level 3 角度（「45°主光，右侧柔补，顶逆发丝光」）  ← 至少做到这一级
Level 4 数值（「主光 45° 机位左，3200K」）          ← 只有极高一致性要求才上，且数值不进正文
```

> 上表是**速查版**——只覆盖"形容词→物理事实"这一类。
> 抽象表述的**完整判定口径**（九类必改 ＋ 三类必留 ＋ 误报源四件套 ＋ 改法优先级）见
> `抽象表述判定口径.md`，机械扫描用 `scripts/audit_literal.py`。
> 冲突时以那份为准。

## 五、 美学构图四件套（让画面「帅」起来）

先保动作清晰，再上这一层。**锦上添花层，不是基础层。**

### 1. 开场 ECU 两极对冲

第一镜不用双人全景对撞，改用**极微距双眼特写**（左右对称构图），双眼各带一道属性光。

```
极微距特写 (ECU) · 正面水平机位 · 左右对称构图。双目怒睁，左目赤红血芒+暗黑魔纹，右目金黄雷霆+裂空电弧，两极分立。
```

作用：一帧立住「这是什么级别的对决」。

### 2. 中心对称 · 天地立极

单人蓄力 / 对峙用**中心对称构图 + 极低角度仰拍**，人物立于画面正中。

⚠️ **蓄力 / 对峙不得静止**：必须**边动边蓄**——人物在上升中 / 踏步中 / 旋腕中完成蓄力。禁止「悬空静止蓄力」。

⚠️ **严禁裸写「能量光柱 / 光柱直插云霄」**——模型理解不了抽象光柱质感，会渲染成两根呆板的简笔柱子，整段崩坏。

**天地异象必须具象化**（长什么样 / 什么质感 / 从哪来 / 怎么动）：

- ✅ **天幕分野版（推荐）**：不写柱体，写「左右半边天被两色能量染透」——左半边天际被银白剑气辉光染亮，右半边被黑红火光映透，云层沿两色分界滚动翻涌
- ✅ 光粒子洪流版：亿万细碎光粒子自脚下法阵螺旋上升，汇聚成旋转的星尘漩涡
- ❌ 禁写：光柱直插云霄、通天光柱、能量巨柱

### 3. 剪影 / 轮廓光 / 负空间

⚠️ **剪影定格 = 呆立**。只用于**动作瞬间**（转身甩剑 / 跃起滞空 / 挥斩中）的轮廓光抓拍，**不用于静止特写**。

```
人物跃起滞空瞬间背对光源成纯黑剪影，边缘勾一圈银白/金红轮廓光，衣袂与发丝在风中狂舞。
```

背景负空间可以留，但**人物必须处于运动帧**。

#### 🔴 剪影反向约束：不得当人物的唯一呈现方式

上面讲的是"剪影怎么用才帅"，这一条讲的是"什么时候根本不能用"——**两者不冲突，但这条优先级更高**。

**视频模型读不懂「剪影」这个指令。** 实测：让一个角色以剪影出现，模型有两条失败路径——要么把人渲染成一团没有结构的黑块（看不出是谁、看不出在做什么），要么干脆理解成"画面里没有这个人"，人物直接不出场。而这两种失败在生成结果里还都"看起来完成了"。

**判定规则**：

| 情况 | 处理 |
|---|---|
| 人物在场且承担表演（有台词、有反应、有动作） | **禁用剪影**。给正面或侧面，写明光怎么落在脸上 |
| 人物只是**环境元素**（远景路人、雾中随从、门口等的人） | 可用剪影，且必须写明"仅剪影级、静止、仅一人" |
| 动作瞬间抓拍（本节前述） | 可用，且必须处于运动帧 |
| 高敏感规避需要遮挡 | **不能靠剪影规避**，改五手法（见 `质控层_门禁与过审.md` 高敏感镜头手法章） |

**反面案例**（实测被打回）：某场写「角色E以剪影出现在门口」——角色E在该场有台词与情绪反应，剪影让表演全部丢失。改为「两人同在一盏油灯的光里面对面，相距一臂半」后成立。

**替代写法三选一**：

1. **给光**：`烛火只照亮两人之间半尺范围，暗部保留砖缝`——用光域限定可见范围，人是实的不是黑的
2. **给朝向与距离**：`角色E坐画面右小凳上正面朝向她，两人隔灯对坐，中间那段空地在画面下方清楚可见`
3. **沿用已成镜构图作 I2V 首帧**：窗纸人影、门缝窥视这类间接呈现，不要写「剪影」，改成复用已有成镜的画面构图

⚠️ 这条与 `质控层_门禁与过审.md` 的高敏感五手法里"剪影"的用法是同一条纪律的两个面：**剪影可以降风险，但降不了"人物得出场"这个需求**。人物要出场就得给光和朝向。

### 4. 极端体量对比

大招 / 法相镜用**体量对比**制造奇观：渺小人物 vs 通天巨物，人物置于画面一角或底部，巨物占据主画幅。

**不需要任何特效，体量差本身就是奇观。**

```
极宏观大远景 (EWS) · 从地表极低视角仰望。巍峨如高山的神魔巨躯拔地而起，下方山脉与人物如蝼蚁微尘。
```

### 组合法则

- **开场**：ECU 双眼对峙 → 紧接中心对称天地立极（人物运动中）→ 才进入动作
- **蓄力 / 大招**：剪影轮廓光（动作瞬间）→ 极端体量对比
- **收尾**：命中瞬间定格抓剪影，呼应开场——**禁静止收尾**
- **节奏优先**：美学镜头每个 ≤1~2s，不拖节奏

## 六、 受击镜头工具箱（挨打方怎么拍）

受击不是「被打飞」三个字了事：

- **短促径向震动**：命中瞬间镜头沿受力方向短促震一下（1~2 帧），模拟冲击波击中摄影机
- **轻微轴向受力**：镜头随受击方向小幅偏转 / 倾斜，传递「摄影机也被波及」的重量感
- **瞬时焦点变化**：受击瞬间焦点从攻方急切到受击方面部，或焦点随击飞目标快速转移
- **动态模糊与速度匹配**：击飞 / 震退段加径向动态模糊，**模糊方向与位移方向严格匹配**，禁全屏均匀模糊
- **Time Ramp 变速**：仅限极短受击瞬间（命中帧前后 0.2s 内的加速/减速切换），**禁整段升格慢镜**

## 七、 光色体系

### 真实光线物理来源铁律

**严禁无来源的情绪假光与廉价棚拍白光。** 光线必须具备明确的物理发光源：

- **日景白天**：侧面窗棂天光、林间丁达尔斑驳阳光、天空自然散射光
- **夜景室内**：暖黄钨丝灯、破败日光灯管频闪、蜡烛烛火微光、霓虹灯管反射
- **阴影要求**：阴影必须呈现自然的青灰 / 暗棕环境漫反射色阶，**严禁死黑或全脸漂浮发白**

### 🔴 日景防冷光防御机制

**在日景 / 白天场景中，严禁直接使用「冷白光、冰冷蓝光、刺眼冷光」。**

需要表达白天肃杀、凄清、冷酷氛围时，**必须转译**为：

```
低饱和度影调，青灰色自然漫射阴影，背光面与高光处形成自然明暗阶梯，逆光边缘光勾勒轮廓
```

**为什么**：冷蓝光是棚拍打光的特征。「白天 + 冷蓝光」是「假」的第一识别信号——观众说不出哪里不对，但会觉得「这段像在摄影棚里拍的」。

### 与其他层的关系

- **场景光照锚点**（`lighting_anchors`）管**跨镜一致性**——色温、入射角、影子形态、人工光，四值从锚点表取，见 `资产层_锁定与一致性.md` 第八节
- **本层管真实性**——光源必须有物理来源、阴影必须有环境漫反射色阶、日景禁冷光

两者不冲突：锚点表给数值范围，本层给物理约束。**锚点表说「黄昏 2000–3500K」，本层说「必须有明确方向、投长影、不能是无方向性的点光源」。**
