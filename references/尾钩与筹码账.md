# 尾钩与筹码账：分集结构表规程（v5.20.0 新建 · 多集项目的集间纪律）

> **本文件是两套集间纪律的唯一权威**：① **尾钩链**（每集结尾钓住什么、下集怎么还）② **筹码变化账**（每集主角得失什么）。两者共用同一份 opt-in 输入《分集结构表》，由 `audit_project.py --epstruct` 驱动 N5/N6 两门。
> **触发条件**：多集项目（A3 且 ≥2 集）。单集短片不适用——单集没有「下集」，**不适用不是通过，是本门不跑**。（门槛与 `连载记忆与多集一致性.md` 的 ≥3 集不同：尾钩只需有「下集」；记忆四件套需 ≥3 集才启用。）
> **来源**：外部爆款管线《单王》的「分集结构表 + 付费卡点表 + 反转登记簿」吸收改造（2026-10-17 检索）。对方全集 12 集尾钩 100% 携带新信息、卡点全部精确到下集回收秒位——这是 liqi 此前的单点缺口：**钩子门（v5.18.0）管开场 3 秒，没有人管第 89 秒**。

## 〇、两个既有概念的分层（先读，防止和旧规打架）

| 概念 | 管什么 | 在哪 |
|---|---|---|
| 钩子门（E-HOOK-*） | **开场 3 秒**的钩子落点 | SKILL.md Step 3 节拍认领行 |
| **尾钩链（本文件）** | **集尾 15 秒**钓什么 + **下集前 30 秒**怎么还 | 本文件 |
| 台词章的「筹码」 | **句间**博弈：每句对话有一方施压一方掩饰 | `叙事层_剧本门控与台词.md` §三 |
| **筹码变化账（本文件）** | **集间**得失：每集至少一类筹码发生增减 | 本文件 |
| 伏笔表（N4） | 物/信息的埋设—回收生命周期 | `连载记忆与多集一致性.md` |

四条互不替代：开场钩子是「让人点进来」，尾钩是「让人点下一集」，伏笔是「让人记得住」，筹码账是「让人知道主角这集没白忙」。

## 一、尾钩链

### 1.1 尾钩四型（枚举，写进分集结构表）

| 型 | 定义 | 判据 | 《单王》范本 |
|---|---|---|---|
| **信息钩** | 抛出一条新信息（真相/身份/线索） | 观众收到一个此前不知道的事实 | 「0713，你弟弟的单子，不是意外」 |
| **危机钩** | 把主角架到新的危险/压迫上 | 下一集开头主角处境更差或被追击 | 「同一张重单，砸给全站」 |
| **选择钩** | 把一道两难摆到主角（或观众）面前 | 下一集必须回应「选哪边」 | 「U 盘悬在两人之间——拿，还是不拿？」 |
| **态度钩** | 主角对世界亮出一个态度宣言 | 下一集围绕这个态度付出或收获代价 | 「明天发布会，我自己说」 |

### 1.2 三条铁律

1. **每集必须有尾钩**（多集项目无例外；季终集除外——季终钩是第二季钩，见 `连载记忆与多集一致性.md`）。
2. **尾钩必须携带新信息**：判定式——尾钩内容与已登记伏笔/反转（N4 表）不重复、且含一个此前未揭示的事实/危机/选择/态度。**重复利用旧钩 = 观众第三集就疲劳**（机检查非空与类型，「新不新」是语义项，人工核）。
3. **下集前 30 秒必须回收**：尾钩抛出的信息/危机/选择，在下一集 B1/B2（00:00-00:30）内必须有点名回应——回收方式写进《分集结构表》「下集回收」列，格式 `E5 0:10 接 28 斤单全景`（集号 + 秒位 + 一句话）。**钓了不还 = 观众被吊两次就弃剧**；机检只查「回收列非空且含集号」，还得好不好是语义项。

### 1.3 与付费卡点的关系（边界说明）

商业卡点（IAA 广告位/IAP 解锁位）**不归 liqi 管**（超出提示词 skill 边界）。但卡点的机制本质 = 「把峰值故意欠着，下集还」——已被本节的铁律 3 覆盖。做商业规划时，卡点表直接复用《分集结构表》的「尾钩内容 + 下集回收」两列，**不另立格式**。

## 二、筹码变化账

### 2.1 四类筹码（枚举）

| 类 | 定义 | 记什么 |
|---|---|---|
| **信息** | 主角知道了/握有了此前不知道的事实、证据、方法论 | 例：获得跨系统申诉方法论；掌握证据三件套打法 |
| **关系** | 人物关系发生变化（结盟/反水/疏远/调离） | 例：苏芮入盟；赵德柱调离 |
| **资源** | 可调用的物力/权限/组织 | 例：骑手数据组成立；委员会权限（受限） |
| **力量** | 改变规则/舆论/格局的能力 | 新规生效；平台撤罚道歉 |

### 2.2 三条纪律

1. **每集至少一类非空**：一集下来主角的信息/关系/资源/力量一条都没变 = 这集是水集（机检 N5：筹码内容空 = WARN）。
2. **筹码类型必须在四类枚举内**（机检 N5：枚举外 = ERROR——类型写飞了，账就记不住）。
3. **「只压必给」配对**：憋屈集（主角净失去）的下一集必须给痛快/暖的回报（语义项，人工核）。连压三集不给，是弃剧点，不是张力。

### 2.3 与伏笔表的分工

筹码账记**主角状态的增减**（这集他多了什么少了什么）；伏笔表记**具体物/信息的生命周期**（哪集埋、哪集收）。一件软肋物（如裂头盔）的「裂口又大一寸」同时是筹码（资源受损）和伏笔（物证线推进）——**两表都记，各记各的字段**，不互相替代。

## 三、《分集结构表》格式（opt-in 输入 · 唯一格式）

```markdown
| 集 | 核心事件 | 筹码类型 | 筹码内容 | 尾钩类型 | 尾钩内容 | 下集回收 |
|---|---|---|---|---|---|---|
| 1 | 地铁送单被系统判「超速」，当众反杀 | 信息 | 申诉方法论＋「弟弟的单不是意外」线索 | 信息钩 | 匿名短信「你弟弟的单子，不是意外」 | E2 0:08 回拨顾客电话 |
| 2 | 哑叔被恶意仅退款，证据链翻案 | 信息 | 证据三件套打法；白嫖是组织行为 | 危机钩 | 电话那头传来话术培训班的背书声 | E3 0:05 周野提「话术团伙」 |
```

**七列列序固定**。写法四条：
1. 集号阿拉伯数字；筹码类型/尾钩类型必须落在枚举内（机检 ERROR 级）。
2. 筹码内容/尾钩内容/下集回收不许空（机检 WARN 级）。
3. 下集回收格式 = `E<集号> <秒位> <一句话>`（机检只认含 `E` + 数字；秒位写 `0:10`）。
4. **本表是 liqi 自己的格式**，不是外部剧本的分集结构表全列复制——对方表里的「反转级别/峰值情绪/五段覆盖」归 N4 伏笔表与（后续批次的）峰值管理，不进本表。**一张表一个职责，别贪多**。

## 四、机检落点（v5.20.0）

| 门 | 码 | 判据 | 严重度 |
|---|---|---|---|
| N5 筹码账 | `E-EPSTRUCT-TYPE` | 筹码类型 ∉ {信息,关系,资源,力量} | ERROR |
| N5 | `W-EPSTRUCT-STAKES-EMPTY` | 某集筹码内容为空 | WARN |
| N6 尾钩链 | `E-EPSTRUCT-HOOKTYPE` | 尾钩类型 ∉ {信息钩,危机钩,选择钩,态度钩} | ERROR |
| N6 | `W-EPSTRUCT-HOOK-EMPTY` | 某集尾钩内容为空 | WARN |
| N6 | `W-EPSTRUCT-RECALL-EMPTY` | 某集下集回收为空或不含集号 | WARN |
| 元检查 | `E-EPSTRUCT-EMPTY` | 传了 `--epstruct` 但解析出 0 行 | ERROR（空表不是已登记） |
| 元检查 | — | 未传 `--epstruct`：本门跳过——**跳过不是通过** | — |

**严重度裁决**：类型枚举两码 ERROR（写飞了账就废）；内容为空三码 WARN（可能是季中过渡集的有意取舍，阻断不合理）。全部门在 `audit_project.py`，与 `--foreshadow`/`--ledger`/`--decisions` 同族 opt-in。

## 五、返修顺序（账不平的时候）

```
某集读着「水」/ 尾钩没咬住
 ├─ ① 筹码账空了？        → 补这集的得失（信息/关系/资源/力量四选一以上）
 ├─ ② 尾钩没新信息？      → 换一个未揭示的事实/危机/选择/态度（禁复用旧钩）
 ├─ ③ 下集没回收？        → 在下集 B1/B2 补点名回应（30 秒内）
 └─ ④ 三样都齐还是水？    → 回 Gate 3 查这场戏的因果链（删场标准见叙事层）
```
