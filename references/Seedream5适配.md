# Seedream 5.0 Pro 适配

> ⚠️ 版式更新（2026-09-15）：本 skill 的角色资产版式已统一为 4 View 资产板，不再以 liqi 的三卡体系为主导。
> 本文件内出现的「双视图人设卡 / 九视图人设卡 / 侧背补锚卡」一律按按需补出的单卡理解；凡与本 skill 主文件冲突的生成顺序，以 资产层_锁定与一致性.md 第二节为准。

目标模型从关键词型（Midjourney / SD 系）切到 Seedream 5.0 Pro 时的转写规则。
本 skill 的默认模板按关键词型模型优化过，**直接喂给 Seedream 会退化**，必须转写。

来源标注：**【官方】** = 火山引擎官方文档（docs.volcengine.com/docs/6464/1829186，Seedream 4.0–5.0 提示词指南）；
**【实测】** = 第三方平台与创作者的实测聚合（Atlas Cloud、GPTProto 等）；
**【本 skill】** = 本项目实践中归纳，非模型文档。

## 一、模型特性（影响写法的六条）

| 特性 | 说明 | 对本 skill 的影响 | 来源 |
|---|---|---|---|
| **无独立 negative_prompt 字段** | 多个平台确认未暴露该参数 | 所有"禁止内容"必须内嵌进 prompt | **【实测】** |
| **Chain-of-thought 推理** | 先规划构图/光照/配色再生成，理解自然语言 | **句子优于关键词词袋** | **【实测】** |
| **简洁精确优于堆砌** | 官方原文："采用简洁精确的提示通常优于重复堆叠华丽复杂的词汇" | 删堆叠形容词，本 skill 大量"超细节/极致细节"要删 | **【官方】** |
| **原生三种比例** | 1:1 (3840×3840)、16:9 (3840×2160)、9:16 (2160×3840) | 比例在**参数**里选；prompt 里写 8k/4K **不提升上限** | **【实测】** |
| **文字渲染是短板** | 官方承认"精细化文字渲染仍有提升空间" | 中文引线降级预案照常执行，不要跳过 | **【官方】** |
| **多参考图** | 支持 10–14 张，可分工（identity/服装/姿势/光照） | 角色卡定稿后作参考图传入，锁身份 | **【实测】** |

## 二、逐项转写对照表

### A. 句式

| 本 skill 默认写法 | Seedream 转写 |
|---|---|
| `写实PBR材质渲染，细节锐利清晰，整张画面光照统一，无透视畸变，全部视图采用严格正交相机，不篡改参考图人物面部五官结构，16:9` | `用写实 PBR 材质渲染，细节锐利清晰，整张画面光照统一。所有视图使用严格正交相机，没有透视畸变，不要改变参考图人物的五官结构。画幅 16:9。` |
| `画面中心排布3个站立角色视图：正面、侧面、背面。` | `画面中央并排站着同一个角色的三个视图：正面、侧面、背面。` |
| `禁止内容：出现任何角色或人物、画面上出现任何可读文字、日光、天光、均匀照明、暖黄烛光晕。` | `Negative Prompt: 任何人物或角色，可读文字，日光，天光，均匀照明，暖黄烛光晕。` |

**转写原则**：把顿号分隔的名词短语，补上主谓宾变成完整句子。模型要理解"谁对谁做了什么"，不是匹配关键词。

### B. 负面词

| 项数 | 写法 | 位置 |
|---|---|---|
| 1–3 项 | 内联 `no X, no Y` | 就近放在被约束的描述后面 |
| 4–16 项 | `Negative Prompt: ...` 块 | **prompt 最末尾** |
| > 16 项 | 砍到 16 项以内 | 超出的移到落盘 `.md`，不进 prompt |

⚠️ 长排除列表更难与正向描述调和——列表越长，模型越容易"为了避开负面词"而偏离正面目标。宁可留 10 项最关键的。

### C. 质量词（全部删除）

`8K`、`8k`、`4K`、`超清`、`极致细节`、`超细节`、`高清`、`大师级`、`最佳质量`、`杰作`

理由：分辨率由生成参数决定，prompt 里的关键词不提升上限；且属官方点名的"堆叠华丽词"。
**保留**的材质/光照词（`PBR 材质`、`体积光`、`次表面散射`、`各向异性高光`）有实际渲染指向，不是空词。

### D. 解剖与手部

| 否定式（本 skill 默认） | 正向式（Seedream 推荐） |
|---|---|
| `no distorted hands` | `双手自然垂放在身体两侧，五指分明，指节结构清楚` |
| `手脚畸形，多指缺指` | `手部和脚部结构完整，五指分明，比例正常` |

否定只点名了故障，没给目标。正面描述给模型一个可达的落点。
**保留的否定**：`多指或少指`、`额外肢体`——这类"多出来"的故障正向描述无法表达，只能否定。

### E. 皮肤质感

Seedream 5 系列有皮肤过度平滑/塑料化的倾向。加不完美词：

```
皮肤有细微毛孔与自然肤质不均，保留真实肤质纹理。
Negative Prompt: 塑料感皮肤，美颜磨皮，过度平滑，橡皮质感，无毛孔。
```

### F. 动作

**一个主体一个动作**。同一句里塞多个动作会触发动作过度（物体飞散、姿态夸张）。

- 差：`他一边转身一边举起手中的剑，同时衣袂飞扬`
- 好：`他正面站立，右手握剑自然垂于身侧，衣摆静止下垂`

设定表本就是静态站姿，这条基本自动满足；**持物设定图（Step 2.5）最容易踩**。

## 三、完整转换示例

### 转换前（本 skill 默认 · 关键词型）

```
生成图片：专业3D角色转面设定表，16:9画幅，浅灰白色影棚背景，画面填满无大面积空白，蓝图辅助网格，整卡无任何标注线、引线与箭头，图注文字仅限中文。
参考角色：青年书生，严格沿用参考图片全部五官样貌，乌黑长发束成儒生发髻，面部白净。
画面中心排布3个站立角色视图：正面、侧面、背面。
核心强制约束：正面、侧面、背面三套视图使用完全一致的6头身人体比例，肩宽、躯干长度、四肢长度、袍摆长度全部统一；三个角色的脚底严格贴合同一条水平地面基准线。
三视图左侧放置垂直身高参照线，零刻度精准对齐脚底地面基准线，旁标文字"172 cm"。
画面角落放置色板，圆形色票，每项色票旁标注中文色名与十六进制色值：浅蓝色 #A8C4DC（长袍）、皂色 #2B2B2B（长靴）、浅米色 #E8D5B7（肤色）。
禁止内容：手持或佩戴任何道具，服装跨视图不一致，英文文字，乱码字符，水印。
写实PBR材质渲染，细节锐利清晰，整张画面光照统一，无透视畸变，全部视图采用严格正交相机，不篡改参考图人物面部五官结构，16:9
```

### 转换后（Seedream 5.0 Pro）

```
生成一张专业 3D 角色转面设定表，画幅 16:9，浅灰白色影棚背景，画面填满没有大面积空白，带极淡蓝图辅助网格，整卡没有任何标注线、引线与箭头，图注文字全部用中文书写。

画面主体是一位青年书生，严格沿用参考图片的全部五官样貌，乌黑长发束成儒生发髻，面部白净。画面中央并排站着同一个角色的三个视图：正面、侧面、背面。

三个视图必须使用完全一致的 6 头身人体比例，肩宽、躯干长度、四肢长度和袍摆长度全部统一，三个角色的脚底严格贴合同一条水平地面基准线。三视图左侧放置一条垂直身高参照线，零刻度精准对齐脚底基准线，线旁标注文字「172 cm」，身高线与身体保持空隙，不遮挡也不穿插人物躯体。

画面角落放置色板，圆形色票，每项色票旁标注中文色名与十六进制色值：浅蓝色 #A8C4DC（长袍）、皂色 #2B2B2B（长靴）、浅米色 #E8D5B7（肤色）。

用写实 PBR 材质渲染，皮肤有细微毛孔与自然肤质不均，整张画面光照统一。所有视图使用严格正交相机，没有透视畸变，不要改变参考图人物的五官结构。

Negative Prompt: 角色手持或佩戴任何道具，服装跨视图不一致，发型跨视图不一致，身高线遮挡躯体，英文文字，乱码字符，塑料感皮肤，美颜磨皮，水印，logo。
```

**改了什么**：

| 改动 | 处数 |
|---|---|
| 顿号堆砌 → 完整句子，并按语义分段（空行隔开） | 全文 |
| 独立"禁止内容"段 → 末尾 `Negative Prompt:` 块 | 1 |
| 删除 `16:9画幅` 里的画幅声明重复（保留一处）、删除隐含的 8k 类词 | 2 |
| 补皮肤不完美描述（Seedream 塑料感倾向） | 1 |
| 负面块砍到 10 项，超出部分移 `.md` | — |

## 四、Seedream 专属故障表

| 症状 | 原因 | 修法 | 来源 |
|---|---|---|---|
| prompt 里写了 8K，出图仍是默认尺寸 | 关键词不提升上限 | 在生成**参数**里设分辨率 | **【实测】** |
| 画面文字扭曲、缺笔、错字 | 文字渲染短板 | 文字放双引号、尽量短、指明位置；仍不稳走中文引线降级预案 | **【官方】** |
| 皮肤塑料感、过度平滑 | 5 系列默认倾向 | 加不完美词 + `no beauty filter, no airbrushed skin` | **【实测】** |
| 物体飞散、姿态过度夸张 | 一句多动作 | 一个主体一个动作，降低动作强度词 | **【实测】** |
| 无害 prompt 被拒 | 触发词敏感 | 改写触发词，换干净的端点试 | **【实测】** |
| 长负面列表导致主体偏离 | 负面与正面打架 | 砍到 16 项以内 | **【实测】** |
| 风格串中译后泛化 | 中文风格词触发泛化 | 风格锚保留英文原文 | **【本 skill】** |
| 多参考图时身份串味 | 未给参考图分工 | 传图时指定每张的角色（identity/服装/姿势/光照） | **【实测】** |

## 五、参数建议

| 参数 | 建议 | 说明 |
|---|---|---|
| 分辨率 | 角色卡 / 4 View 资产板用 **16:9 (3840×2160)** | 原生比例，无缩放损失 |
| 参考图 | 角色卡定稿后，后续分镜**必传** 4 View 板裁片（`face_hd` 为身份锚） | 锁身份最有效手段 |
| seed | 定稿后记录 seed | 便于微调重出时保持构图 |
| 编辑模式 | 改一处用编辑，不要整张重生成 | 编辑保留未修改区域，一致性更强 |

## 六、与其他模板的协作

- **4 View 角色资产板（Step 2.5）**：本就是 Seedream 适配结构（四段式 + 内嵌负面 + 数值化排版），**无需再转写**，直接用。
- **场景环境设定表（Step 2.5）**：需要转写——原模板的"1pt 白色网格线"三个限定词要改成句子，`{项目风格锚}，体积光，超细节材质，大气粒子，冷暖对比，8k，无logo` 收尾里的 `8k`、`超细节`、`大气粒子` 要删。
- **持物设定图（Step 2.5）**：转写时**重点改手部**——否定式改正向式，且动作只留一个。
