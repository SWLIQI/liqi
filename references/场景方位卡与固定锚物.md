# 场景方位卡与固定锚物

> 🔗 流程位置：**Step 2.5 场景资产（定一次）→ Step 3 站位与轴线（每镜对照）**。
>
> 来源：2026-10-12 外部站位图专项调研（评审底稿不随包分发）。drama-skills 用 `screen_direction: entrance east, kitchen north` 与 `fixed_anchors` 把空间钉在场景地理上，liqi 原写法缺这一层。

---

## 一、为什么需要：相对参照系会漂

liqi 原来的站位写法是**相对参照系**——相对人、相对上一镜：

```
站位：@道士乙（画面中右 · 距道士甲三步 · 双手举罗盘）
轴线：承重柱—石膏隔断墙连线，长风画面左（西侧），白毛邪物画面右（东侧）
```

两个毛病：

1. **「距道士甲三步」的基准是人**。长风一动，清羽的位置就跟着失守；模型不知道"三步"到底在哪，只知道两个人挨着。
2. **「保持」是状态词，不是地理**。多镜同场时每镜各自解释"保持什么"，到第 3 镜左右关系就开始漂。

对照 drama-skills 的写法：

```
blocking.axis: counter-to-entrance working side
blocking.screen_direction: entrance east, kitchen north
blocking.fixed_anchors: counter / shutter / service hatch
```

它的基准是**场景地理**——入口在东、厨房在北，一次定死，不随人动。这才是站位的正确参照系。

**一句话原则：站位要挂死物，不要挂活人。**

---

## 二、方位卡四要素

一个场景定一次，写进场景资产（或包内的「〇 场景方位卡」段），全场景所有镜共用。

| 要素 | 写什么 | 例（废弃工地顶层） |
|---|---|---|
| **① 罗盘方位** | 出入口与主陈设的朝向，**用东南西北，不用左右** | 楼梯口在南，承重柱居中偏北，石膏隔断墙在西，窗洞在东 |
| **② 固定锚物清单** | 3~5 个不动、可见、可跨镜复用的物体 | 承重柱 / 石膏隔断墙 / 楼梯口 / 窗洞 / 水泥梁 |
| **③ 屏幕方向映射** | 本场景"画面左/右"对应哪个方位，**定一次不再改** | 画面左 = 西侧（石膏隔断墙），画面右 = 东侧（窗洞） |
| **④ 禁变约定** | 哪些关系全场景不许变 | 柱与隔断墙的相对位置三镜一致；楼梯口始终在画面下方 |

**为什么①必须用东南西北**：左右是相对镜头的，换个机位就翻；东南西北是相对场景的，换机位不变。方位卡存在的前提就是有一套不随镜头变化的坐标。

**为什么③要显式写**：不写，每镜的"画面左"就是各镜自己解释，③的作用就是把画面坐标和场景坐标锁死一次。

## 三、模板

```
〇 场景方位卡（废弃工地顶层 · 夜）

罗盘方位：楼梯口在南，承重柱居中偏北，石膏隔断墙在西，窗洞在东
固定锚物：承重柱 / 石膏隔断墙 / 楼梯口 / 窗洞 / 水泥梁
屏幕方向：画面左 = 西侧（石膏隔断墙），画面右 = 东侧（窗洞），画面下方 = 南侧（楼梯口）
禁变约定：柱与隔断墙的相对位置三镜不变；楼梯口恒在画面下方
场型：V2（厅堂）——景别上限中景至全景；禁大俯（会拍出天花板空面），环绕须贴墙走
```

> **「场型」是附加行，不是第五要素**（v5.13.0）：四要素仍是罗盘方位 / 固定锚物 /
> 屏幕方向 / 禁变约定四项不变。场型回答的是「这个空间长什么样」，决定景别上限与运镜禁令，
> 分型表见 `空间层_调度与轴线.md` §九（**V1~V4 室内 / W1~W2 室外 / X 特殊**）。
> ⚠️ **别写成 S1~S4**——liqi 的 S0~S4 已被「空间风险分级」占用，两套编号互不相干。

多场景就多张卡，每卡标场景名。卡的粒度 = 一个物理空间一张，换空间换卡。

### 时段变体共用同一张卡（v5.6.2 明确）

**方位卡只有空间信息，没有光照信息——所以同一场景的晨/午/昏/夜各变体共用一张卡，不随变体重出。**

理由：方位卡四要素里没有一条会随时段变——罗盘方位是建筑结构，固定锚物是「不动、可见、可跨镜复用」的物，屏幕方向映射由机位与锚物决定，禁变约定管的是空间关系。**变的只有太阳角度**（光斑落哪、影子多长），那是 `lighting_anchors` 与场景 `variants` 的事，不是方位卡的事。

落地：

- 注册表里方位卡挂在**场景条目层**（`scenes.<slug>`），不挂 `variants.<时段>` 下；
- 卡上标场景名时**不带时段后缀**（写「废弃工地顶层」，不写「废弃工地顶层·夜」）；
- 若某个时段变体真的改了固定锚物（如「火灾后」承重柱倒塌），那**不再是时段变体，是陈设阶段变化**——按去重键另建场景条目，那时才出第二张卡。

（判据来自 `资产层_锁定与一致性.md` 5.5 去重键：时段变化只改光照变体、不建新卡；不同地理、不同入口或**不同固定锚点**才建新卡。）

## 四、固定锚物选品三条

不是什么都能当锚物。三条全中才算：

1. **不动**：墙、柱、门框、供台、柜台、楼梯、窗洞、栏杆、树、石。人不算，道具不算（会被拿走）。
2. **可见**：在本场多数镜的取景半径内。全景才看得见的远处山头，不能用来给近景定位。
3. **可跨镜复用**：至少在两镜里出现。只用一次的物，跨镜对不上账。

**可画、可认、可核对（v5.2.0 补，判据三问）**：锚物不仅要满足上面三条，还要过三问——
**可画**：能生成出来且稳定（飘动的雾、复杂花纹不行）；**可认**：观众一眼能把它从画面里认出来；
**可核对**：QC 能拿它对生成镜头（有明确形状/位置/颜色，不是氛围）。正反对照：
「补丁船篷」是锚物（可画可认可核对），「陈旧的氛围」是形容词（三问全不过）。
锚物数量按四要素②取 3~5 个，不堆数量——每个都要过三问。

**优先级**：柱 / 台 / 门 / 墙 > 窗 / 阶 / 栏 > 家具 / 陈设 > 植物 / 地形。

**反面**：`距道士甲三步`、`在他旁边`、`两人之间` —— 全是相对人的，不算锚物，只能作补充。

## 五、站位写法：锚物优先三级

站位四要素（位置 / 依托物 / 朝向 / 姿态）里的**依托物**升级为**固定锚物**，并按三级优先取用：

| 级 | 锚定方式 | 例 | 何时用 |
|---|---|---|---|
| **① 固定锚物** | 人物与不动物的空间关系 | 承重柱侧后 / 背靠石膏隔断墙 / 立在楼梯口 | **默认，优先用** |
| **② 物理接触** | 手、背、脚与物的接触 | 手搭水泥梁 / 背贴柱面 / 脚踩断裂沿 | ① 不够精确时补 |
| **③ 人物间距** | 与另一角色的距离 | 距长风三步 | **只作补充，不许单独用** |

**写法**：先锚物，后位置，间距放最后。

```
站位：@道士甲（承重柱侧后 · 画面左 · 侧身朝右 · 桃木剑在手）；@道士乙（石膏隔断墙前 · 画面中右 · 距长风三步 · 双手举罗盘）
```

对照原写法「@道士乙（画面中右 · 距道士甲三步 · 双手举罗盘）」——前者清羽的位置由墙定死，长风走了她也不动；后者长风一动她就漂。

## 六、位移写法：起终点都挂锚物

原写法 `@道士甲 承重柱后→僵侧后两步（潜行）` —— 起点是锚物（承重柱后），**终点是活人（僵侧后）**。终点失守。

改为起终点各挂一个锚物，人物只作为"最终面向谁"的补充：

```
位移：@道士甲 承重柱后→石膏隔断墙西端两步（潜行，终态面向白毛邪物）
```

静态镜照旧写 `全员原位，无位移`。

## 六之二、持物写法：分左右手（v4.7.6）

站位挂死物解决了"人在哪"，还差一件事：**东西在哪只手**。

模型不看上一镜。「桃木剑在手」在它眼里不是"沿用上一镜的持剑手"，而是"随便挑一只手"——
第 1 镜右手、第 2 镜左手，剪出来就是穿帮，而且这种穿帮**人眼一扫容易漏，观众一眼就看出**。

写法：提到手上的东西就写死哪只手；空手也要明写，别留空。

```
站位：@道士甲（承重柱侧后 · 画面左 · 侧身朝右 · 右手桃木剑 · 左手手电）
站位：@道士丙（殿门口 · 画面右 · 跪坐蒲团 · 双手抖开绢布）
站位：@道士乙（隔断墙前 · 画面中右 · 徒手 · 侧身朝左）
```

三条判定口径：

| 情形 | 算不算持物 | 例 |
|---|---|---|
| 主动持/握/举/拿/托/端 + 物件 | 算，必须分左右 | 右手桃木剑 · 左手手电 · 双手举罗盘 |
| 空手状态词 | 不算，本身就是明确态 | 徒手 / 空手 / 垂手 / 背手 / 负手 / 插兜 / 抱臂 |
| **被动接触**（被攥/被抓/被扶） | 不算——那是打斗接触点，不是持物 | 被攥脚踝侧倾 · 双脚离地 |

第三条是实测踩出来的：打斗镜里 `@道士甲（画面中 · 被攥脚踝侧倾 · 双脚离地）` 一度被误报成"持物未分左右手"。
接触点声明是打斗专项要求的好东西，不能被持物码反过来打。

与方位卡的关系：持物是**跨镜恒定项**，写进站位行后同时进台账的「道具」行——
`道具：桃木剑（镜1 抽出、镜2 仍在右手）`，两边口径一致才对得上账。

## 七、轴线行：状态词 + 地理参照

原格式只有三态状态机（建立 / 保持 / 跨越），加一个**地理参照**——说明这条轴线挂在场景的哪两个锚物之间：

```
轴线：承重柱—石膏隔断墙连线，长风在画面左（西侧），白毛邪物在画面右后（东侧）
轴线：保持（同镜1：承重柱—隔断墙连线），长风画面中偏左，黑毛邪物画面右
```

**跨越**时更要写清：从哪条线跨到哪条线，用哪种合法手段。

对照：原「轴线：保持，长风画面中偏左，黑毛邪物画面右」——「保持」什么？两个问题：状态词该进台账、且没挂锚物。改成「锚物连线 + 左右」后，跨镜对账才有据可依。

---

## 八、与连续性台账的衔接

台账九锚点里的**空间**与**屏幕方向**两行，改用方位卡的坐标写：

```
空间：承重柱、石膏隔断墙、楼梯口三点位置三镜一致（按方位卡：南楼梯口 / 中北柱 / 西隔断）
屏幕方向：镜1 画面左=西（隔断）、右=东（窗洞）；镜2 同；镜3 换场重建
```

这样跨镜比对的是**同一套坐标**，不是各镜的左右描述。

## 九、自检六问

1. 本场景有没有方位卡？罗盘方位、锚物清单、屏幕方向映射、禁变约定四要素齐了吗？
2. 站位行的依托物是不是固定锚物？有没有只写"距某人 N 步"的？
3. 位移的**终点**有没有挂锚物，还是挂在活人身上了？
4. 轴线行除了状态词，有没有写明挂在哪些锚物之间？
5. 站到镜前的人物，手上的东西**分没分左右手**？空手的是不是明写了"徒手"？
6. 台账的空间、屏幕方向、道具三行，用的是不是方位卡的同一套坐标与左右？

## 十、机械门禁

`check_prompt.mjs` 三码（v4.7.5 / v4.7.6 新增，口径见脚本注释）：

| 码 | 级别 | 触发 | 修法 |
|---|---|---|---|
| `W-STAGING-RELATIVE` | WARN | 站位/位移用「距某人 N 步/米」且同段没有固定锚物 | 补锚物：距 X 三步 → 隔断墙前 · 距 X 三步 |
| `W-AXIS-NO-GEO` | WARN | 轴线行没有地理参照（缺方位词或锚物连线） | 补连线：`轴线：柱—隔断墙连线，谁在画面左、谁在画面右` |
| `W-AXIS-STATE-IN-BODY` | WARN | 逐镜正文出现 `建立/保持/跨越` 状态词（v5.27.0 起） | 状态词移进连续性台账场景账；正文只留锚物连线 + 左右 |
| `W-PROP-HAND` | WARN | 站位/位移提到持物（持/握/举/拿/托 · 在手/手中）却没写左手/右手/双手/徒手 | 写死：右手桃木剑 · 左手手电；空手写徒手 |

三码都只警告不阻断——方位卡是**场景级**资产，脚本按镜扫描看不到包级卡，所以只能抓"本镜有没有挂地理 / 分没分左右"，抓不到"挂得对不对"。后者靠台账按方位卡逐镜比对。

> 与既有码的关系：`W-POSITION-MISSING` 管"完全没写站位"，`W-SPATIAL-WEAK` 管"写了弱词"，`W-STAGING-RELATIVE` 管"写了但基准是活人"，`W-AXIS-MISSING` 管"没写轴线"，`W-AXIS-NO-GEO` 管"写了轴线但没地理"，`W-PROP-HAND` 管"写了持物但没分左右"。六级递进，不重叠。
