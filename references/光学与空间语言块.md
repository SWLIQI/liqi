# 光学与空间语言块（v2.0 新增）

写时间轴前取句用。**原则不变：写可见结果，不写镜头参数**——不写 f 值、不写焦段毫米数、
不写 ISO、不写镜头型号。模型对参数的响应不稳定，对「背景熔成什么色块」稳定。

不引入视场角度数体系（如 47°/84°）。那类度数指令在 Seedance 国内面与火山方舟的响应未经验证，
沿用视觉结果写法更安全。若后续实测证明度数有效，再单独立表。

---

## 一、景别视觉结果句（7 档）

| 档 | 画面占比 | 环境可见度 | 可复制句 |
|---|---|---|---|
| 大远景 | 主体占画面高度 1/8 以下 | 环境完全主导 | 主体仅为比例参照，环境占满画面，可辨认的是体积与位置，不是细节 |
| 远景 | 1/8 - 1/4 | 环境主导 | 主体全身可见但小，姿态与动势可辨认，五官不可辨 |
| 全景 | 全身入画，占 1/2 - 3/4 | 环境提供空间语境 | 主体全身入画，头顶与脚下留有余量，环境交代所处空间 |
| 中景 | 腰腹以上，占约 1/2 | 背景退为色块但仍可读 | 取景到腰腹，背景保留形状与色块关系，细节纹理让位给主体 |
| 近景 | 胸部以上，面部占 1/4 以上 | 背景开始虚化 | 取景到胸部，面部占画面四分之一以上，背景化开但能读出明暗结构 |
| 特写 | 面部或物件占 6 成以上 | 背景退出叙事 | 主体占画面六成以上，背景只剩色块与光斑，不参与叙事 |
| 大特写 | 单一五官或局部占满 | 全部融化 | 只有局部占满画面，其余全部融化，可辨的只有材质与微动 |

档位必须在时间轴段头写清（如「中景」「特写」），不许只写「镜头对准 XX」。

## 二、透视行为句（3 类）

每类**至少选 3 条**叠加进该段描述，不要整段照抄。

**广角空间扩张**（机位物理贴近，距离一米上下）
- 前景身体存在感明显大于自然比例
- 环境在主体周围仍然可见，一直延伸到画面边缘
- 边缘到边缘保持清晰
- 直线保持平直，没有弯曲
- 机位物理贴近主体
- 无长焦压缩，无奶油状肖像散景

**标准自然人眼**（机位距主体三到五米）
- 透视接近人眼所见，面部与身体比例自然
- 无可见畸变，无夸张的前大后小
- 景深舒适，背景可读但不抢戏
- 画面沉稳中性，不做情绪化变形

**长焦压缩**（机位距主体六到八米或更远）
- 背景在主体身后被压缩成平面，紧贴其后
- 只有主体锐利，其余全部融化为柔和色块
- 近景靠焦段拉近实现，不是机位物理靠近
- 前景遮挡以柔和暗散景框住主体
- 主体在融化的背景前锐利跳出
- 镜头与主体之间悬浮着大气薄雾

同一段内不得同时出现广角与长焦的行为句——它们互斥，混写会让模型随机选一个。

## 三、景深视觉结果句（3 档）

| 档 | 可复制句 |
|---|---|
| 浅 | 只有主体与关键物件在焦点内，背景熔成 X 色块，前景边缘同样化开 |
| 中 | 主体清晰，背景保留形状与色块关系，失去细节纹理 |
| 深 | 从前景到远景全程清晰，纹理可读，空间纵深靠线条与明暗交代 |

景深写视觉结果，**不写 f 值**。f 值属于文档层注记，写进参数行，不进正文。

## 四、空间调度弱词替换表

弱词会让模型自由发挥位置关系，是空间穿帮的主要来源。**一律替换成物理锚定**。

| 禁用 | 替换为 |
|---|---|
| 附近 / 不远处 / 周围 | 距 X 一米以内 / 紧贴 X |
| 旁边 / 一侧 | 在 X 的画面左侧 / 位于画面左三分之一 |
| 某处 / 在该区域内 | 正站在 X 正下方 / 在 X 门前 |
| 靠着 | 背靠 X / 手搭在 X 上 |
| 大概在 / 差不多 | 与 X 齐平 / 高出 X 半个头 |

物理锚定句式：`主体 + 距离/接触动词 + 参照物 + 画面位置`。
例：旅客甲站在距查验台一米以内，双手搭在台沿，位于画面右三分之一。

## 五、身体朝向与视线分离规则

朝向与视线是两件事，合并写会丢一半信息。三个变量分别写：

- 躯干朝向：躯干正对 X / 侧身朝向画面左 / 背对镜头
- 视线目标：视线锁定 Y / 目光越过镜头看向 Y / 眼睑下垂不看任何目标
- 头部动作：头转向 Z / 保持不动 / 微微低头

例：查验员乙躯干正对查验台，视线锁定旅客甲的腰腹，头部不动。

对白场景额外规则：说话者的嘴唇只为当段台词而动；其他角色保持静默聆听；
不说话时嘴唇静止；无明确要求时不出现画外音。

---

## 六、防漂移句

凡用长焦或广角的镜，正文末尾加一句防漂移，否则模型会在镜头中途换透视。

| 类型 | 防漂移句 |
|---|---|
| 长焦 | 本镜任何部分都不变为广角覆盖，背景全程保持压缩与融化，更宽的取景靠机位拉远实现而不是换透视 |
| 广角 | 本镜任何部分都不变成长焦肖像，环境在主体周围保持可见，机位保持物理贴近 |
| 标准 | 无极端广角畸变，无长焦压缩，画面保持自然中性 |

---

## 七、接入位置

Step 3 第 7 条（时间线分镜）写段头时：
景别查表一取句，透视查表二至少取 3 条，景深查表三取句，
空间位置一律走表四的物理锚定，朝向与视线走表五拆分，
用了长焦或广角就在段末加表六的防漂移句。

不许自己现编形容词描述光学效果——现编的词（如「柔和的电影虚化」）不产生画面，只占权重。
