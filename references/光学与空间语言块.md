# 光学与空间语言块（v2.0 新增）

写时间轴前取句用。**原则不变：写可见结果，不写镜头参数**——不写 f 值、不写焦段毫米数、
不写 ISO、不写镜头型号。模型对参数的响应不稳定，对「背景熔成什么色块」稳定。

不引入视场角度数体系（如 47°/84°）。那类度数指令在 Seedance 国内面与火山方舟的响应未经验证，
沿用视觉结果写法更安全。若后续实测证明度数有效，再单独立表。

## 一、景别视觉结果句（9 档 · v5.22.0 补齐中全景 / 中近景）

| 档 | 画面占比 | 环境可见度 | 可复制句 |
|---|---|---|---|
| 大远景 | 主体占画面高度 1/8 以下 | 环境完全主导 | 主体仅为比例参照，环境占满画面，可辨认的是体积与位置，不是细节 |
| 远景 | 1/8 - 1/4 | 环境主导 | 主体全身可见但小，姿态与动势可辨认，五官不可辨 |
| 全景 | 全身入画，占 1/2 - 3/4 | 环境提供空间语境 | 主体全身入画，头顶与脚下留有余量，环境交代所处空间 |
| 中全景 | 膝盖以上，占 1/2 - 3/4 | 环境仍交代所处空间 | 取景到膝盖，人物全身入画但下缘切在膝上，环境仍在交代所处空间 |
| 中景 | 腰腹以上，占约 1/2 | 背景退为色块但仍可读 | 取景到腰腹，背景保留形状与色块关系，细节纹理让位给主体 |
| 中近景 | 胸口以上，面部占 1/6 以上 | 背景开始化开 | 取景到胸口，面部占画面六分之一以上，背景化开但能读出明暗结构 |
| 近景 | 肩部以上，面部占 1/4 以上 | 背景开始虚化 | 取景到肩部，面部占画面四分之一以上，背景化开但能读出明暗结构 |
| 特写 | 面部或物件占 6 成以上 | 背景退出叙事 | 主体占画面六成以上，背景只剩色块与光斑，不参与叙事 |
| 大特写 | 单一五官或局部占满 | 全部融化 | 只有局部占满画面，其余全部融化，可辨的只有材质与微动 |

档位必须在时间轴段头写清（如「中景」「特写」），不许只写「镜头对准 XX」。

## 二、透视行为句（3 类）

每类**至少选 3 条**叠加进该段描述，不要整段照抄。

**广角空间扩张**（机位物理贴近，距离一米上下）
- 前景身体存在感明显大于自然比例
- 环境在主体周围仍然可见，一直延伸到画面边缘
- 边缘到边缘保持清晰
- 直线保持平直，没有弯曲
- 机位物理贴近主体
- 无长焦压缩，无奶油状肖像散景

**标准自然人眼**（机位距主体三到五米）
- 透视接近人眼所见，面部与身体比例自然
- 无可见畸变，无夸张的前大后小
- 景深舒适，背景可读但不抢戏
- 画面沉稳中性，不做情绪化变形

**长焦压缩**（机位距主体六到八米或更远）
- 背景在主体身后被压缩成平面，紧贴其后
- 只有主体锐利，其余全部融化为柔和色块
- 近景靠焦段拉近实现，不是机位物理靠近
- 前景遮挡以柔和暗散景框住主体
- 主体在融化的背景前锐利跳出
- 镜头与主体之间悬浮着大气薄雾

同一段内不得同时出现广角与长焦的行为句——它们互斥，混写会让模型随机选一个。

## 三、景深视觉结果句（3 档）

| 档 | 可复制句 |
|---|---|
| 浅 | 只有主体与关键物件在焦点内，背景熔成 X 色块，前景边缘同样化开 |
| 中 | 主体清晰，背景保留形状与色块关系，失去细节纹理 |
| 深 | 从前景到远景全程清晰，纹理可读，空间纵深靠线条与明暗交代 |

景深写视觉结果，**不写 f 值**。f 值属于文档层注记，写进参数行，不进正文。

## 四、空间调度弱词替换表

弱词会让模型自由发挥位置关系，是空间穿帮的主要来源。**一律替换成物理锚定**。

| 禁用 | 替换为 |
|---|---|
| 附近 / 不远处 / 周围 | **紧贴 X** / 手搭在 X 上（**不写"距 X 一米"**，见下） |
| 旁边 / 一侧 | 在 X 的画面左侧 / 位于画面左三分之一 |
| 某处 / 在该区域内 | 正站在 X 正下方 / 在 X 门前 |
| 靠着 | 背靠 X / 手搭在 X 上 |
| 大概在 / 差不多 | 与 X 齐平 / 高出 X 半个头 |

物理锚定句式：`主体 + 接触动词 + 参照物 + 画面位置`。
例：旅客甲紧贴查验台站定，双手搭在台沿，位于画面右三分之一。

> 🔴 **v5.21.0 修正——"距 X 一米"是裸度量，禁输出**（`抽象表述判定口径.md` §二之二 数值二分法）：
> 米 / 厘米是**模型在画面里找不到落点**的工程单位，写了也不执行，与"附近"同属无效。
> 老李 `combat-iron-laws.md` 铁律19 明令禁止输出"距主体 X 米"。
> ⇒ **距离改用三类可执行写法**：① **接触**（紧贴 / 手搭 / 背靠 / 脚踩）② **画框分数**（画面左三分之一）
> ③ **已知尺寸的参照物**（高出 X 半个头 / 与 X 齐平）。
> 需要"远"的感觉时写**观感与结果**（隔着一整间屋子，彼此只剩轮廓），不写米数。

## 五、身体朝向与视线分离规则

朝向与视线是两件事，合并写会丢一半信息。三个变量分别写：

- 躯干朝向：躯干正对 X / 侧身朝向画面左 / 背对镜头
- 视线目标：视线锁定 Y / 目光越过镜头看向 Y / 眼睑下垂不看任何目标
- 头部动作：头转向 Z / 保持不动 / 微微低头

例：查验员乙躯干正对查验台，视线锁定旅客甲的腰腹，头部不动。

对白场景额外规则：说话者的嘴唇只为当段台词而动；其他角色保持静默聆听；
不说话时嘴唇静止；无明确要求时不出现画外音。

## 六、防漂移句

凡用长焦或广角的镜，正文末尾加一句防漂移，否则模型会在镜头中途换透视。

| 类型 | 防漂移句 |
|---|---|
| 长焦 | 本镜任何部分都不变为广角覆盖，背景全程保持压缩与融化，更宽的取景靠机位拉远实现而不是换透视 |
| 广角 | 本镜任何部分都不变成长焦肖像，环境在主体周围保持可见，机位保持物理贴近 |
| 标准 | 无极端广角畸变，无长焦压缩，画面保持自然中性 |

## 七、光学视角度数速查表（v5.17.0 新增）

**口径**：社区实测（来源 CINEDANCE V4 内容-FOV 对齐法则，本地整理；非官方文档口径）。
度数是对角线视野（diagonal FOV）。**核心法则一句话：内容决定度数**——环境的、空间的、物理的、
身体贴近镜头的内容用广角；肖像、观察、孤立、压缩、远距离注视的内容用长焦；微距/细节自成插入拍；
**一个节拍内禁混两类内容**（面部肖像 + 环境地理 + 微距细节同拍 = 镜头漂移），需要就做受控内切、每拍一个镜特性。

| 内容类型 | 度数 | 对应写法 |
|---|---|---|
| 面部肖像 · 带环境的亲密特写 | 84° | 阿方索·卡隆式亲密广角 |
| 面部肖像 · 中景肖像 | 29° | 短焦长焦肖像 |
| 面部肖像 · 紧凑情感特写 | 18° | 经典长焦 |
| 面部肖像 · 远距隐藏观察 | 8° | 超长焦观察 + 前景遮挡 |
| 环境动作 · 纪录片式 | 47° | 标准镜头 |
| 环境动作 · 宽广 | 84° | 经典广角 |
| 环境动作 · 大尺度地理 | 107° | 广角直线镜头 |
| 环境动作 · 极端沉浸 | 135° | 广角环境图案（仅整拍都是环境动作时） |
| 细节/微距 · 标准 | 29° 或 18° | — |
| 细节/微距 · 广阔环境内 | 蛇眼镜头 | 仅明确需要时 |
| 远距观察 · 体育/野生动物 | 8° | 超长焦观察 |
| 远距观察 · 压缩监视肖像 | 18° 或 8° | 长焦 + 前景遮挡 + 大气雾霾 |

**与表六的关系**：选了 84°/107°/135°（广角）或 18°/8°（长焦），段末照加表六对应防漂移句；
**避免作为主要控制**：mm 焦段数值、f 值、ISO、镜头品牌——按 Level 4 纪律，数值类不进正文（见 `视听层_镜头文法与光色.md` 反形容词转译表）。

## 八、接入位置

Step 3 第 8 条（时间线分镜）写段头时：
景别查表一取句，透视查表二至少取 3 条，景深查表三取句，
空间位置一律走表四的物理锚定，朝向与视线走表五拆分，
视角度数按需查表七（内容类型定度数），用了长焦或广角就在段末加表六的防漂移句。
写任何「推近 / 拉远 / 靠近」前，先过第九节真假运镜口径——机位因果写错，视觉结果句再对也是「把画面放大」而不是「走近了」。

不许自己现编形容词描述光学效果——现编的词（如「柔和的电影虚化」）不产生画面，只占权重。

## 九、真假运镜口径（v5.38.0 吸收运镜三变量资料 · 只收因果不收数值）

上文各表只写视觉结果，前提是「机位做了什么」写对。这一节补最常写错的因果：**推近是机位真的靠近，放大不等于靠近。**

| 类型 | 机位与画面事实 | 视觉结果句（照这个写） |
|---|---|---|
| 真推进（Dolly In） | 摄影机真实向主体移动，透视关系随之改变 | 机位向主体持续靠近，主体逐渐变大，前景与背景的相对位置与遮挡关系同步改变 |
| 假推进（Zoom In） | 摄影机不动，只放大画面 | 机位固定不动，画面仅作放大，前景与背景的相对关系不变，无透视变化 |
| 真后退（Dolly Out） | 摄影机真实远离，空间被打开 | 机位持续后退，主体逐渐变小，周围环境逐步入画，纵深关系展开 |
| Dolly Zoom（希区柯克式） | 机位靠近的同时取景收窄，背景伸缩而主体比例大致不变 | 机位向主体靠近的同时取景逐渐收窄，背景产生不自然的伸缩，主体大小保持稳定 |

三条纪律：

一、**「摄影机真实移动」必须显式写。**只写「镜头推近」时模型按数字放大执行，透视不变——观众看到的是画面被放大，不是有人走近了。

二、**同一镜内不得先写真推进又写只放大。**两类因果混在一镜，模型随机选一个，段落前后空间关系自相矛盾。

三、**外部资料的 mm、T 值、F 值矩阵不收进本文件。**数值属 Level 4（不进正文，见 `视听层_镜头文法与光色.md` 反形容词转译表精度梯度）；本表只收「机位做了什么、画面怎么变」的因果层。T 值与 F 值换算见 `术语对照表_glossary.md` 第十六节。

另收一条外部经验（③ 社区实测）：**运镜变化排进时间**，不要起始即终点——一段 8 秒运镜，变化发生在第 2 到 5 秒、5 秒之后才落定，时间轴上把「起始状态、中间变化、最终状态」分开写，与 Step 1 时长带宽同源。来源：W4《AI 电影运镜三变量》（v5.38.0 吸收；裁决记录《外部Skill吸收裁决总表》W4 行 / C03 节）。

再收一条外部经验（③ 社区实测；来源：Rylaispirit/cinematic-video-prompt-skill §8.11，MIT，2026-10-29 对拍吸收）：**长镜走路线化描写，单向不回头**——穿越、飞行、追行长镜按「A→B→C」逐段给动词（掠过 → 绕过 → 钻入），路线只进不退；单向约束比「流畅运镜」更能压住模型的往返漂移。与上条同源：变化排进时间轴，路线本身就是时间轴。

**冲突词对人工自查表（v6.6.0 · C30 附带；③ 来源：Rylaispirit/cinematic-video-prompt-skill 冲突对示例，MIT，2026-10-28 实勘）**：光与天气/时段的组合存在物理互斥——外部原例「golden hour × heavy downpour（日落暖光 × 暴雨）不可同用」：太阳贴近地平线才有金色低角度光，暴雨云遮天时它不存在，模型随机选一个或画出两头都不像的中间态。写完光色段自查三问：① 这两个词能否同时为真（光源方向 × 天气遮蔽）？② 时段是否打架（正午顶光 × 黄昏长影）？③ 光源句是否互相作废（前句「唯一实用光源」后句又「霓虹满街」）？撞了任一条：保叙事需要的那半边，删另半边。**不设机检**（加门三问：互斥是语义判断，词表覆盖不全反而造成漏检假绿；W-SHOT-MULTI-SCALE ×2303 噪声的教训——没有事故数据的门不立），与第九节三条纪律同层。
