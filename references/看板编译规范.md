# 看板编译规范（md → 单文件离线 HTML）

> **交付形态**：本 skill 统一按锁③ 的三选一交付（① 离线看板 HTML / ② markdown / ③ 两者都交付，默认③）。
> liqi 只给 `.md`，在 20+ 镜的项目里读不动——几万字纯文本，核对转场 / 台账 / 轴线一致性时没法对比。
> 本 skill 的交付默认是**③ 两者都交付**：md 是唯一真相，看板由 md 编译生成。

---

## 一、铁律四条（编译前必读）

| 编号 | 规则 |
|---|---|
| **K-1** | **md 是唯一真相，看板只读不回写。**不允许「跳过 md 直接写看板」；改稿改 md，改完重编译 |
| **K-2** | **缺字段降级不中断。**缺什么显示「未解析到」并记 WARN，看板永远出得来 |
| **K-3** | **拆解视图与原文并存。**逐镜表 / 镜头卡用于定位问题，围栏原文可整段复制投喂 |
| **K-4** | **⑤ 资产出图提示词与 ③ 分镜投喂提示词必须同板呈现**（缺 P2.5 → WARN） |

**看板不产生新内容。**它只是把 md 里已经写好的东西换一种排版。任何「看板上比 md 多出来的文字」都是 bug。

---

## 二、运行

```
python scripts/build_board_lite.py <项目.md> [--out <看板.html>]
```

- 不指定 `--out` 时，输出到同目录 `<项目名>_分镜看板.html`
- 产出**单文件离线 HTML**：CSS / JS 全内嵌，双击浏览器即开，零依赖 / 零数据库 / 零端口
- 运行后会打印：段落数 · 镜头数 · 资产数 · 出图提示词数 · 总时长 · WARN 列表 · 输出路径

### 3.1 章节识别（关键词归区，不必照抄标题）

| 归区 | 命中关键词 |
|---|---|
| 发布文案（P6） | `发布文案` / `P6`（且不含「投喂」） |
| 资产出图（P2.5） | `出图提示词` / `P2.5` / `资产出图` |
| 分镜投喂（P4） | `投喂提示词` / `P4` / `分镜提示词` |
| 视听圣经 | `视听圣经` / `风格圣经` |
| 剧本 | `剧本` / `故事` / `梗概` |
| 资产清单（P2） | `资产清单` / `资产表` / `P2` |
| 创作基准（P0A） | `创作基准` / `P0A` |

**未归区的章节进「⑦ 其他章节」，原文照录，信息零丢失。**这是 K-2 的兜底。

### 3.2 段标题宽容写法

`### 段1` / `### U01 · …` / `### 第1段` 都认。

### 3.3 逐镜行的三种写法都认

```
00:00-00:05 [镜头1] 中景 · 缓推 · …
[00:00-00:05] 中景 · 缓推 · …
[0-3秒] 中景 · 缓推 · …
```

`[镜头N] ` 前缀会被剥掉，卡片上只留景别 · 运镜 · 动作。

### 3.4 资产表表头别名

表头按**标准字段 × 别名优先级**扫描（不是按列顺序），所以「类 | 编码 | 类型 | 出图 | 复用单元」这类自定义列序也能正确识别：

| 标准字段 | 认得的别名 |
|---|---|
| code | 编码 / code / 资产编码 / id / 资产id |
| name | 名字 / 名称 / 角色 / 人物 / 资产 / name / 资产名 |
| view | 视图 / **出图** / 出图类型 / 规格 / 类型 / view |
| img | @图片n / 图号 / 图片 / 参考图 / img / 绑定图 |

（「出图」优先于「类型」命中 view，防列序歧义。）

## 四、看板七个区块

**创作蓝图层**（先看这里：故事 / 基准 / 风格）

- Ⅰ · 创作基准（P0A 表格项 → 看板行）
- Ⅱ · 剧本层（P1 正文照录）
- Ⅲ · 视听圣经（P1 一次锁定 · 全片继承）

**分镜生产层**（拿去干活的那一份：资产 / 分镜 / 投喂 / 文案）

- ① 时间轴泳道 — 段内独立计时 → 按累计偏移铺成整片时间轴，读得出成片节奏
- ② 镜头卡矩阵 — 拆解视图，逐镜栏位
- ③ 投喂提示词原文 — 成品视图，**照录未改写，可整段复制直接投喂**
- ④ 资产总表 — 编码 / 名字 / 视图 / @图片N / 附加信息 / 引用段（用编码在段原文里回查）
- ⑤ 资产出图提示词 — 与 ③ 必同板；同一场景资产的连排条目（①②③）聚合成一张卡，支持「复制全部」
- ⑥ 发布文案（可选）
- ⑦ 其他章节（未归区原文照录）

**交互**：顶部告警条显示 WARN 数（轻量校验）；「只看告警」可筛出有问题的段；段筛选按钮；每个提示词框带「复制投喂原文 / 复制出图提示词」按钮。

## 五、常见 WARN 与处理

| WARN | 含义 | 处理 |
|---|---|---|
| 未找到 ```text 围栏投喂原文 | 段下有内容但没有围栏 | 补围栏，否则无法一键复制 |
| 未解析到 [起-止秒] 逐镜时间戳行 | 段内无时间戳 | 补时间戳行 |
| 镜头时间码回跳：Xs 早于上镜结束 | 时间轴断裂 | 修时间码 |
| 资产出图提示词 X 未找到围栏原文 | P2.5 缺围栏 | 补围栏 |
| 全档未解析到「### 段N」分镜段 | 段标题契约不对 | 按 §3.2 改标题 |
| 未解析到「## P2.5 · 资产出图提示词」 | 缺 P2.5 章节 | 补齐（K-4） |
| 未声明【画幅】——B 锁未锁定 | 锁② 缺失 | **用户未指定 ≠ 默认 9:16**，回去问 |
| 未声明【模型版本】——A 锁未锁定 | 锁① 缺失 | **用户未指定 ≠ 默认 2.5**，回去问 |

> 最后两条是关键：**看板把「没锁」当错误报，不替用户默认。**锁①锁②是硬前置，看板是最后一道提醒。

## 六、与 11 节镜块格式的关系

看板**不解析 11 节镜块的内容结构**——它只认「围栏原文」和「时间戳行」两样东西：

- ③ 区放的是围栏原文，**一个字都不改**
- ② 区从时间戳行提取景别 / 运镜 / 动作做卡片

所以 **11 节镜块的内部写法与看板无关**，UI 上一律零标记（不出现 `#` `**`）。镜块的完整规范见 `SKILL.md` 第 3 步。

### 6.1 MiniMax H3 面必须走后处理再编译

H3 面的包结构是「〇 风格锚 → 〇.5 资产层 → 一 转场注记 → 二 连续性台账 → 三 逐镜 U01…」，
与上面第 36 行的骨架不同。**直接把包喂给 `build_board_lite.py`，57 个单元会全部报
「未找到围栏投喂原文」「未解析到 [起-止秒] 逐镜时间戳行」**——
看板照 K-2 降级出得来，但 ② 镜头卡空、③ 无法复制投喂，等于废板。

必须两步走：

```bash
python scripts/h3pkg_to_board_src.py <包.md> --script <剧本.txt> \
    --assets <资产条目.md> --out <看板源.md>
python scripts/build_board_lite.py <看板源.md> --out <看板.html>
```

映射口径（脚本已内化，不必每次重推）：

| 看板区 | H3 面来源 |
|---|---|
| Ⅰ P0A 创作基准 | 包头的三锁 / 全片规格 / 台词铁律 / 参数行说明 +「四 全局制作纪律」 |
| Ⅱ P1 剧本 | 源剧本 txt（脚本 `--script`） |
| Ⅲ P1 视听圣经 | 「〇 风格锚（九段）」+ 〇.5 的第 1–4 小节 |
| Ⅳ P2 资产清单 | 资产条目 md（`--assets`） |
| ⑤ P2.5 出图提示词 | 资产条目 md 的围栏正文 |
| ③ P4 投喂提示词 | 单元标题到「以下不进正文」分隔线之间的**六段**，逐字 |
| ② 镜头卡 / ① 泳道 | `detailed_description` 里的 `[Shot N]` 与 `At MM:SS.mmm` 推出来的 `[起-止秒]` 行 |

三个易踩点：

1. **画幅与模型版本要写在看板源文件头一次**，写在单元里会被吞进看板的 A/B 双锁，
   不显示成卡片标签；单元里只用 `【时长】【场景】【参考素材】【交接】`。
2. **「附一 / 附二」（改动复验报告、校验结果）不进看板**——那是关于包的交付记录，
   不是制作内容；「四 全局制作纪律」要进（那是投喂铁律）。
3. 资产条目的出图 prompt 若只有 (B) 层、没有 (A) 六层结构（见 `资产结构层模板.md`），
   照发，但要在条目文件与看板源里注明「尚未补 A 层」，免得出图崩了无从定位。

## 七、交付清单（默认③）

一次完整交付应产出三个文件：

| 文件 | 说明 |
|---|---|
| `<项目名>.md` | 唯一真相，逐镜提示词包 |
| `<项目名>_分镜看板.html` | 由 md 编译，双击即开 |
| 《改动复验报告》 | **仅修改类交付物需要**，见 `质控层_门禁与过审.md` §七 |

H3 面另加两个中间件（供可复现编译）：`<项目名>_看板源.md` 与资产条目 md
（后者按 `SKILL.md` 第 6 步用**小写连字符 slug** 命名，禁止中文文件名与空格）。

三项缺一不算交付完成。用户选①或②时，按锁定项③的选择裁剪。
