# 哥特定格木偶 风格锚（定格木偶轨 × MiniMax H3 / Seedance 通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**哥特维多利亚定格木偶（Gothic Victorian stop-motion puppet）**这套具体风格上的落值，
同时给出 H3 面的英文压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

适用判定：手作木偶质感、微缩布景实拍、大头细肢骨骼式解剖、尸感黏土皮肤、月光蓝低饱和、
德国表现主义布景、暗黑童话气质。用户给的设定图是这类质感（参考「生成图片去水印」图集：
提灯少女 / 捧馍老妇 / 行旅青年 / 枯槁老翁四张双视图）时，锁③ 风格轨道选**定格木偶轨**，风格锚取本文件。

> **与写实轨的边界**：写实轨要 PBR 真实皮肤与高精度材质；定格木偶轨要「假」——黏土、布偶、
> 微缩模型的痕迹本身就是风格本体。两者的材质词汇互斥，**禁止混轨**。
> **与手绘轨的边界**：本轨是三维实体拍摄（有真实光影与景深），不是平面画。水墨锚的
> 「平面化、无体积、去 2.5D」纪律在本轨**全部不适用**，反着来——这里要体积、要纵深、要布景层次。

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Gothic Victorian stop-motion puppet film, a handcrafted dark fairytale shot as real miniature set photography with visible handmade textures. Burton-esque puppets with oversized heads, thin elongated limbs, crooked skeletal anatomy, corpse-like faces and matte clay skin; subtle stop-motion imperfections stay in every movement. Moonlit blue lighting, deep shadows, a desaturated blue-grey palette, German expressionist sets, and every surface matte and non-glossy.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
desaturated blue-grey palette of moonlit cold blue, deep night-blue shadow, pale clay skin and weathered cloth, with a single warm lantern-orange accent
```

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

**三条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 用户原文写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `Avoid Pixar, Disney, photorealism...` | 不进正文，只进有 negative 字段平台的排除项 | H3 无 negative 字段，否定句只会被读成肯定；「每处都哑光」的正面陈述比一串 Avoid 强 |
| `matte non-glossy surfaces` | `every surface matte and non-glossy` + 材质词一律配「不做反光」 | 光滑高光是本风格变 CGI 的头一崩点，必须正面钉死 |
| `subtle stop-motion imperfections` | `subtle stop-motion imperfections stay in every movement` | 只写静态 imperfection 没用，模型会把动作渲染成丝滑 CGI；必须写进运动里 |

压句 62 词、配色句 22 词。改压句前先算 Δ：正文有 350–500 词的区间门禁，压句一涨就把贴上限的单元顶出去。
改完跑 `check_prompt_h3.mjs` 确认 0 warning。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一部哥特维多利亚定格木偶电影，手作暗黑童话，按真实微缩布景实拍方式呈现，手工痕迹清晰可见。伯顿式木偶：头大、四肢细长、骨骼解剖歪扭、尸感面孔、哑光黏土皮肤；每一处动作都保留轻微的定格动画不完美。月光蓝照明、深长阴影、去饱和蓝灰色调、德国表现主义布景，每一处表面都哑光不反光。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
去饱和蓝灰色调：月光冷蓝、深夜蓝阴影、苍白黏土肤色与做旧粗布，灯笼暖橙作唯一重音色。
```

**中文面四条额外纪律**（英文面没有，别漏）：

| 用户原文写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 「丝滑流畅的动作」 | 「二拍一顿挫，动作起收各留半拍静止」 | 中文面的模型同样会补流畅动作，一补就是 CGI 观感 |
| 「高清细腻的皮肤」 | 「哑光黏土皮肤，保留指痕与接缝」 | 「细腻」在中文面直接路由到写实/CGI 皮肤 |
| 「真实人体比例」 | 「头身比约 1:4，木偶比例，四肢细长歪扭」 | 写实化的头号入口 |
| 「皮克斯风、迪士尼风、动漫风」 | 不进正文，只进有 `negative_prompt` 字段的面 | 否定句不生效，正面钉「哑光黏土 + 微缩实拍」比一串禁止强 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次媒介特征（定格木偶、微缩布景、哑光不反光）。
2.5 面没有 negative 字段，正向句是唯一的钉子。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台自带美化倾向会自动磨平手工痕迹**。
所以 2.2 那句「每一处动作都保留轻微的定格动画不完美」在国内面**不许省略**——省了就变 CGI。

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **变光滑 CGI / 皮克斯感** | 材质词没配「哑光」；正文出现高光、辉光、次表面散射类词；运动写成丝滑 | 压句逐字复用；每个材质词后面跟 matte / non-glossy；动作写 stagger 与 imperfect |
| **变写实真人** | 写了真实解剖词（肌肉、皮肤纹理、真实五官比例）；参考图是真人照片 | 钉死木偶比例与尸感面孔；参考图必须本身就是木偶质感，真人照当参考直接报废 |
| **运动太顺滑，丢失定格感** | 写了流畅连续动作长拍 | 一段只写一个主动作，动作间留静止半拍；长动作拆成 2–3 秒短镜 |
| **动漫化 / 三渲二** | 风格压句缺位或被稀释；参考图带动漫风 | 压句第一句就是媒介声明（stop-motion puppet film），不许挪到句子后半段 |
| **色彩饱和度漂移变鲜艳** | 没写色彩预算 | 每镜声明唯一重音色与蓝灰色系；配色句必须与压句同时出现 |
| **角色被画成设定表三宫格** | 把双视图 / 4 View 板当首帧 | 双视图只当 `<Subject N>` 定义（左脸特写裁身份锚），绝不当首帧 |
| **布景变真实大小空间** | 场景词写了真实世界尺度参照 | 写微缩模型痕迹（接缝、板材、手工做旧），场景「是搭的」可以被看见 |
| **表情过度灵活变脸** | 一镜塞了太多表情节拍 | 木偶的表情幅度天生受限：一镜一个主节拍，微表情写可见的黏土形变（眉位移、嘴角位移），不写细腻皮肤动态 |
| **暖光源扩散污染全片** | 写了「温暖的光照亮房间」 | 暖光只照亮相邻一小圈、衰减快；画面主体始终是冷蓝调 |

## 七、声音签名（中英双轨）

投中文面（Seedance 2.5 / 国内面）直接取中文版，不要拿英文版现场翻译——译一次音色就散一次。

**中文版（2.5 面 / 国内面用）**：

```text
整体声音签名：环境层——微缩屋顶上的夜风，木偶关节随动作细响，脚步落在模型地面上的闷响，
远处一声不重复的犬吠；动作层——关节吱嘎、布料摩擦；呼吸层——克制；配乐层——极简。
```

**英文版（H3 面用）**：

```text
overall_soundscape:
Night wind over a miniature rooftop, wooden joints creaking faintly with each puppet movement, muffled footsteps on model ground, and one distant dog bark that does not repeat.

non_diegetic_music:
A sparse solo cello or music box at a slow tempo, long silences between phrases, no swell, no percussion.
```

配乐中文写法（需要时）：`一段极简的大提琴独奏或八音盒，速度缓慢，乐句之间留长静默，无渐强，无打击乐。`

这套风格**默认配乐极简**（弦乐独奏或八音盒）。加了配乐就要在整体声音签名里声明，
否则不同镜会各自补出不同的音乐。禁史诗感管弦轰炸——它会把微缩布景撑成大片实景。

## 九、去立体化与串轨防护

本轨的污染方向与水墨锚**完全相反**，这是全套风格里最容易抄错的一节。

- 水墨（手绘平面轨）要「**去**立体」：删 `animation`、`storybook`、`glow`、否定句，防出片 2.5D。
- 本轨要「**保**立体」：微缩布景实拍本身就有真实光影与景深，**体积与纵深是风格本体，不是缺陷**。
  要防的是另一端——**CGI 化与写实化**。

把水墨那张删词表套过来，等于把本风格的实体感亲手删掉。

### 9.1 污染词与替换对（定格轨·反向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 丝滑、流畅、连续动作、一气呵成 | 二拍一顿挫，动作起收各留半拍静止 | 丝滑是 CGI 观感的头号来源，进了正文模型必补运动模糊 |
| 运动模糊 | 删除，不写 | 定格动画没有运动模糊，写了即 CGI |
| 高光、镜面反射、次表面散射、辉光 | 每个材质词后跟「哑光不反光」 | 光滑高光是本风格变 CGI 的第一崩点 |
| 真实人体解剖、肌肉、真实五官比例 | 木偶比例（头身比 1:3.5–1:4.5）、骨骼解剖歪扭、四肢细长 | 写实化的头号入口 |
| 皮克斯风、迪士尼风、动漫风 | 不进正文；媒介声明放首句（stop-motion puppet film） | 否定不生效，正面钉媒介比一串禁止强 |
| 辽阔、实景、真实世界尺度 | 微缩模型痕迹（接缝、板材、手工做旧） | 布景一变大就丢掉「搭出来的」这件事 |
| 温暖的光照亮房间 | 暖光只照亮相邻一小圈、衰减快；主体始终是冷蓝调 | 暖光扩散会污染全片色彩预算 |
| 细腻皮肤动态、丰富微表情 | 眉、嘴角、眼睑的大位移 | 黏土面孔做不出细腻皮肤动态，表情一灵活就变真人 |

**正面句优先原则**：本风格的钉子全是正面陈述。凡是要「禁止 X」的地方，
先问「X 的反面怎么用正面句写」——写不出来，说明这条约束本来就不该进正文。

### 9.2 互斥风格

与本风格互斥的 id（与 L0 `style-registry.json` 的 `excludes` 一致，**双向登记**；数值有出入时以 L0 为准）：

| 互斥 id | 混了会怎样 |
|---|---|
| `photoreal-pbr`（写实 PBR） | 写实轨要真实皮肤解剖，本轨要「假」——黏土、布偶、微缩模型的痕迹本身就是风格本体，材质词汇完全互斥 |
| `ink-wash-2d`（水墨淡彩） | 手绘轨要平面化无体积，本轨要体积要纵深，两张删词表方向相反，混用必崩 |
| `celshade-guoman-2d`（国漫赛璐璐） | 赛璐璐会把木偶压成平涂色块，丢掉实体质感与布景纵深 |
| `npr-celshaded-3d`（三渲二） | 干净 CG 与手作痕迹互斥，三渲二的均匀描边会抹掉木偶的手工不完美 |
| `stylized-pixar-3d`（风格化 3D） | 皮克斯式的光滑 CG 与丝滑运动正是本轨负面词点名的对象，混进来就没有「搭出来的」布景感了 |

**串轨怎么认**：看有没有出现对面的材质词。本轨正文里出现「平面化 / 无体积 / 留白」，
或水墨正文里出现「高光 / 渐变 / 体积光」，就是串了。
