# 脚本用法速查

> 流程位置：SKILL.md「References › scripts」的展开版。
> **SKILL.md 里只留「什么时候跑哪个」；本文件给全量参数、退出码与踩坑注记。**
> 需要拼命令行时才加载本文件，不要预先读。

---

## 一、四个交付门禁（必跑，按投放面选）

### `scripts/check_prompt.mjs` — Seedance 面单镜格式机械校验（36 规则码）

```bash
node scripts/check_prompt.mjs <file> [--surface intl|cn|auto] [--strict] [--all] [--official] [--target <面>]
```

- `--surface` 是历史参数名（语言面），`--lang` 是同一个开关的新名字，两者等价，`--surface` 优先。
- `--strict` 把 warning 也当失败（退出码 1）。
- `--all` 把整包当一个镜块校，不按镜切分。
- `--official` 额外查官方 API 门禁：中文 ≤500 字（`W-OFFICIAL-500`）/ 英文 ≤1000 词（`W-OFFICIAL-1000W`），默认关闭。
- **拿错脚本会假报错**：检测到 H3 六段式包就直接早退（`E-WRONG-SCRIPT`，退出码 2）并提示改跑
  `check_prompt_h3.mjs`。确实要强行按 Seedance 面校验时追加 `--target seedance-off`。
- 退出码：有 error 1 / 全过 0 / 用法或输入问题 2。
- 规则码全表见 `质控层_门禁与过审.md` 第二节。

### `scripts/check_prompt_h3.mjs` — MiniMax H3 面专用机械校验

```bash
node scripts/check_prompt_h3.mjs <file> [--strict] [--all]
```

查：六段齐全与顺序、`<Subject N>` / `<Picture N>` 标签是否定义过、`<d>` 成对与语言标记、
`[Shot N] At MM:SS.mmm` 切点、单条 4–15 秒、`Must not` 是否误入正文、否定式频率、
`detailed_description` 350–500 英文词、英文正文混中文。
**与 `check_prompt.mjs` 不可混跑**；检测到 Seedance 面的中文【时间轴】或对应段头会明确提示改跑哪个。

### `scripts/check_style.mjs` — 风格一致性门禁（P0），交付前必跑

```bash
node scripts/check_style.mjs <包.md> [--surface auto|h3|seedance|cn] [--registry <path>]
```

查 9 项：style_id 未声明 / 未注册 / 引用待建 / 同包多 id / **互斥风格特征词串轨** /
头身档混用 / **压句未逐字复用（逐词定位第一个改动点）** / 配色句缺失 / 压句语言串面。
- 注册表查找顺序：`--registry` > 当前目录 `style-registry.json` > 包同目录 > `references/style-registry.seed.json`。
- 退出码：有 ERROR 1（**不许交付**）/ 全过 0 / 用法错误或找不到注册表 2。
- 串轨检测会**跳过负面词上下文里的点名**——负面词里必须写「禁赛璐璐」，那是合法的，不算串轨。

### `scripts/audit_literal.py` — 抽象表述与高敏感画面表述扫描（九类 + S 类，带误报剔除）

```bash
python scripts/audit_literal.py <提示词包.md> [--detail] [--seg 段1,段2]
```

- `--detail` 打印逐条命中的上下文；`--seg` 只扫指定段 / 镜标题（逗号分隔，改完复验单镜时用）。
- 中文规则外另含**英文对应规则**（H3 面正文为英文，只查中文会全部漏掉）。
- 命中文末附文（全局制作纪律 / 改动复验报告 / 校验结果）即停扫，不当正文处理。
- 依据 `references/抽象表述判定口径.md`。**多镜 / 整合镜交付前强制跑。**
- 退出码 0 / 1 / 2 与 `SKILL.md` Step 4 声明一致。

## 二、项目级与过审（有条件必跑）

### `scripts/audit_project.py` — 项目级审计

```bash
python scripts/audit_project.py <包.md> [--script <剧本.txt>] [--assets <资产图目录>] [--cast 甲,乙] [--coverage] [--limit N]
```

查台词一致性 / 资产锚覆盖 / 角色漂移 / 时长 / 转场。
- `--cast` 不传时自动从包里「人物：」行与 @锚点收集；**收集不准再显式传入**。
- `--coverage` 额外统计剧本台词被包采用的比率。这一路必然带噪声（实测会把动作描写当台词，
  覆盖率数字不可信），**默认不跑**，只想粗看漏拍情况时才打开。
- `--limit` 单镜时长红线；不传则自动判定——整合段格式（`段 N｜标题`）取 30，
  分镜格式（`镜 N｜标题`）取 15。

### `scripts/audit_risk.py` — 国内平台内容审核风险预检

```bash
python scripts/audit_risk.py <包.md> [--shot N] [--detail]
```

**只查词**——拿到结果后必须按 `质控层_门禁与过审.md` §6.3 给每拍配镜头手法，
光看风险分不等于过了审。

> 三个审计脚本（`audit_literal` / `audit_project` / `audit_risk`）都识别 `镜 N` / `段 N` / `U01` 三种编号。

### `scripts/extract_script_docx.py` — 剧本 .docx → 标准 txt

```bash
python scripts/extract_script_docx.py <剧本.docx> [-o 输出.txt]
```

产物喂给 `audit_project.py --script`。不依赖 python-docx（走 zipfile + ElementTree）。

## 三、资产出图与看板（按需）

### `scripts/slice_reference.py` — 设定卡裁切（需 Pillow）

```bash
python scripts/slice_reference.py <图.png> [-o 输出目录] [-l 4view|9view|dualview|sideback] [--full front,side,back] [--heads 6.5] [--expr 表情名,逗号分隔] [--ratio 0.25] [--margin 12] [--gap 4] [--no-manifest]
```

- **默认版式 `--layout 4view`**（左头部近景 + 右无头三联）；`dualview` / `sideback` / `9view`
  三种是按需补卡，本 skill 默认不出，触发条件见 `资产层_锁定与一致性.md` 第二节。
- `-l` 与 `--layout` 等价。
- 输出 `manifest.txt` 投喂清单，并给出每格头部像素评估——**用来判断这张裁片能不能当身份锚**。
- `--expr` 只在 `9view` 用，默认是占位表情名；正式项目要从剧本场记提取真实表情名后传入。

### `scripts/build_board_lite.py` — md → 单文件离线分镜看板

```bash
python scripts/build_board_lite.py <看板源.md> [--out <看板.html>]
```

锁③ 交付形态选 ① 或 ③ 时用。输入契约见 `看板编译规范.md`。

### `scripts/h3pkg_to_board_src.py` — H3 面提示词包 → 看板源 md

```bash
python scripts/h3pkg_to_board_src.py <包.md> --script <剧本.txt> --assets <资产条目.md> --out <看板源.md> [--title <看板标题>]
python scripts/build_board_lite.py <看板源.md> --out <看板.html>
```

**为什么需要这一层**：H3 面的包结构（〇 风格锚 / 〇.5 资产层 / 一 转场注记 / 二 台账 / 三 逐镜 U01…）
与 `build_board_lite.py` 的输入契约不同，**直接拿包去编译会让 57 个单元全部报
「未找到围栏投喂原文」「未解析到 [起-止秒] 行」**——看板出得来但不可用。
本脚本把六段正文压成 ```` ```text ```` 围栏、把 `[Shot N]` 与时间码推成 `[起-止秒]` 行、
把风格锚与资产层归到 P1 视听圣经 / P2 资产清单 / P2.5 出图提示词。**逐镜正文一个字不改。**

### `scripts/dedupe_style.py` — 按风格清污染词（泛化版，新包一律用这个）

```bash
python scripts/dedupe_style.py <包.md> [--style <id>] [--registry <path>] [--fix] [--aggressive] [--no-backup]
```

- 词表从 `style-registry.json` 的 `dedupe_pairs` 读，另叠一份内置长句精调表（目前只有 `ink-wash-2d` 有）。
- `--fix` 才真写文件（默认只报告不改）；写文件前默认留 `.bak`，`--no-backup` 关掉备份。
- `--registry` 指定注册表，不给则按 `--registry` > 当前目录 > 包同目录 > skill 种子文件 依次找。
- `--style` 不给时从包里的 `【风格】<id>` 或 `# style_id: <id>` 推断；**推断不出就报错列可用 id，不猜**。
- 词级「删除型」替换默认只报不删（容易把句子删残），确认安全再加 `--aggressive`。
- 🔴 **作用区间非空是硬断言**：区间为空直接退出（退出码 2），不做任何替换——
  曾经按围栏切分而文件里围栏已丢，替换全部作用在空集合上，报「替换 0 处」却看着像成功，白跑两轮。

### `scripts/generate_emotion_curve.py` — 情绪张力曲线 + 三条可机械判定的法则自检

```bash
python scripts/generate_emotion_curve.py --beats "6,8,4,9,7" [--beats-file 节拍.txt] [--out 曲线.png] [--no-plot]
```

- 自检三条：波峰（≥9.0）不少于 2 次 / 相邻波峰之间必须回落 ≥1.0 / 极差 <2.0 判为全片平铺。
- 第四条「开局 3 秒内必须伴随即时冲突」要看节拍里有没有事件，**脚本判不了，留人工复核**。
- 刻意不内置老李面向抖音的 12 节拍命名与分值（C15 已判不吸收），默认示例用题材无关的五幕结构。
- 需 matplotlib；未安装会打印安装提示而不是崩栈。`--no-plot` 只跑法则自检不出图。

## 四、通用注意事项

- **Python 侧**：全部只用标准库 + `matplotlib` / `pillow` 两个可选包（见 `requirements.txt`）；
  Python ≥ 3.8。所有文本读写都显式 `encoding='utf-8'`，9 个脚本都设了 `sys.stdout.reconfigure`。
- **Node 侧**：零 npm 依赖，只用 `node:fs` / `node:path` / `node:url`；Node ≥ 16。
- **退出码约定**：三个 `.mjs` 校验脚本统一 **有 error 1 / 全过 0 / 用法或输入问题 2**。
  CI 里务必按退出码判定，不要只看有没有打印文字——用法错误也会打印一段好看的说明。
- 校验脚本只做机械判定，**审美与叙事逻辑仍按 SKILL.md Step 4 人工复核**。
