# 纪实实拍风格锚（写实轨 × 全投放面通用）

本文件是 Step 2「全片统一风格锚（九段）」在**纪实 / 纪录片式实拍**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：画面看起来是被一台摄影机在真实环境里拍到的——手持的自然微晃、现场光不作修饰、
景别由物理距离决定、人物不摆拍、允许穿帮级的生活细节（杂物、路人、反光的窗）。
素材可以是真实拍摄的参考片段，也可以是**模拟实拍观感**的 AI 生成画面。
用户给的素材是实拍片段、或要求「纪录片质感 / 新闻纪实 / 街头跟拍」时，锁③ 风格轨道选**写实轨**，
风格 id 取 `documentary-live-action`。

**边界声明**：

- 与写实 PBR（`photoreal-pbr`）：**这是最容易混的一对**。photoreal-pbr 是「影视级 CGI」——
  追求的是完美渲染，光源是设计的、皮肤是干净的、构图是控制的；
  本风格是「被拍到的」——**追求的是可信的不完美**：手持晃、曝光不匀、构图偶尔失衡、人物有瑕疵。
  判断标准只有一句：**画面里有没有「摄影师在场」的痕迹**。有，就是本风格；没有，就是 PBR。
- 与写实 PBR 的另一处差异：PBR 必带「不完美词」是为了防塑料脸；
  本风格的不完美是**风格本体**，不是补丁。
- 与卡通 / 手绘 / 三渲二轨：材质与光照逻辑完全不同，互斥。

> **本风格的风险点不在画质，在「过度整洁」**：模型默认输出的是精修画面，
> 越好看越假。所以本锚的第六节崩点表里，「变精修」「变广告片」排在最前面。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 真实摄影机在真实环境里拍到的画面：现场光、自然微晃、不做修饰；人物不摆拍，有生活化的瑕疵；材质是真实材质——皮肤有毛孔与细纹，布料有褶皱与磨损，地面有灰尘与反光 |
| ② 配色与色域 | 现场光的自然色偏：日景偏冷、室内白炽偏暖、荧光偏绿；整体中低饱和；**每镜只声明一个唯一重音色**（常是现场光源本身：一盏灯、一块招牌）；禁用调色预设感（禁 teal-orange、禁电影感分级） |
| ③ 运动签名 | 25fps 或 30fps（按地区制式），**手持微晃 + 呼吸感**，允许追焦、允许构图临时失衡；**禁止丝滑稳定器长镜、禁止无人机式完美弧线** |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比写实 7–7.5（真人比例，不做美型简化）**；脸型骨相、发型发色、眉眼特征、服装形制与配色；允许写不对称、细纹、斑点这类真实特征 |
| ⑤ 场景锁定 | 走 `<Subject N>`：真实场所，写清地点类型与陈设密度；同场景跨镜地标与光位一致；**允许生活杂物入画**（这是本风格的真实感来源） |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、入画方式必须写；道具可以是有使用痕迹的日常物件 |
| ⑦ 光色基调 | 只写现场光源：窗光、顶灯、街灯、屏幕光；入射角与影子形态写实；**禁止补光灯式的均匀布光、禁止轮廓光设计感** |
| ⑧ 声音签名 | 环境层：真实环境底噪，是主体之一；动作层：脚步、器物、衣物，实录感；呼吸层：保留，不修饰；配乐：**默认无配乐**，需要时写清乐器与速度 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅其他有 negative 字段的面可用：CGI、3D 渲染、塑料皮肤、完美对称脸、电影级调色、稳定器丝滑运镜、广告片质感、动漫化、可读文字、水印 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
Footage shot by a real camera in a real location: available light only, natural handheld micro-shake, unposed subjects with everyday imperfections. Real skin texture with pores and fine lines, real cloth with creases and wear. Documentary framing chosen by physical distance, not by design. No colour grading, no stabilised glide.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
natural available-light colour with a single practical accent source per frame, mid-to-low saturation, no graded look
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `cinematic` / `film still` / `movie scene` | `footage shot by a real camera in a real location` | cinematic 会触发电影级调色与广告片质感，是本风格头号崩点 |
| `perfect lighting` / `studio lighting` | `available light only` | 布光一出现，现场感立刻消失 |
| `smooth camera` / `gimbal` / `drone shot` | `natural handheld micro-shake` | 稳定器与无人机弧线会把画面推向广告片 |

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一段由真实摄影机在真实环境里拍到的素材：只用现场光，带手持的自然微晃，人物不摆拍且有日常的不完美。皮肤有毛孔与细纹，布料有褶皱与磨损。纪实式的取景，由物理距离决定景别，不是设计出来的构图。不做调色，不用稳定器式的平滑运镜。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
现场光的自然色偏，每帧只有一个实用光源作为重音色，中低饱和，不做调色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「电影感」「大片质感」「电影级」 | 「真实摄影机拍到的素材」 | 电影感三件套直接触发调色与布光，是本风格最大敌人 |
| 「完美的光线」「柔和的布光」 | 「只用现场光」 | 布光一写就假 |
| 「不要 CGI、不要太精致」 | 删否定句，正面写「手持微晃、现场光、生活杂物入画」 | 否定不生效 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次（现场光、手持微晃、不摆拍、无调色）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台默认输出偏精修、偏广告**，
所以「不做调色，不用稳定器式的平滑运镜」这句在国内面**不许省略**。

## 三、色值表

| 用途 | 色值 | 说明 |
|---|---|---|
| 日景亮部 / 天空 | #D8DCE0 | 现场光偏冷的受光面 |
| 室内暖白（白炽） | #E8D6B8 | 室内现场光 |
| 荧光偏绿 | #CFD8C8 | 办公室 / 走廊荧光灯 |
| 阴影 | #4A4E52 | 带环境色，不用纯黑 |
| 钠灯橙（重音色） | #E08A3C | 全片唯一的实用光源重音色：街灯、台灯 |
| 肤色亮部 | #E8C4A8 | 真实肤色，无磨皮 |
| 肤色暗部 | #A87F68 | 同色系加深 |
| 衣物常用（灰蓝） | #5A6470 | 日常服装主色 |
| 木与土 | #8A7256 | 陈设与地面 |

**色彩预算纪律**：每镜只声明一个唯一重音色，其余压成同色系。本风格的重音色**必须是一个现场光源**，
不能是「角色衣服的颜色」——那样就变成调色了。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 手持跟拍、肩扛式跟随、固定机位守候、轻微推拉找焦点、追焦 |
| 少量 | 快速转向（突发事件）、上车式的进退、隔着前景遮挡拍 |
| 避免 | **稳定器长镜、无人机弧线、完美对称构图、轨道横移、慢动作升格** |

**每段只锁一个主运镜**。景别由物理距离决定，不靠变焦凑。

## 五、材质与可见性预算

| 项 | 落值 |
|---|---|
| 主 | 皮肤与布料的真实质感（毛孔、细纹、褶皱、磨损） |
| 次 | 环境材质（灰尘、水渍、反光、风化） |
| 省 | 远景细节、背景人群 |
| 可见性 | 路人只写数量与动态趋势，不写五官 |
| 禁 | 塑料皮肤、完美对称脸、磨皮、镜面高光（会把画面推向 CGI 与广告） |

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 变精修广告片 | 出现 cinematic、film still、movie scene、perfect lighting | 压句首词 `footage shot by a real camera in a real location`，全片禁「电影感」类词 |
| 变电影级 CGI | 出现 render、CGI、3D、subsurface scattering | 删掉；皮肤只写「毛孔与细纹」 |
| 皮肤变塑料 / 磨皮 | 出现 flawless skin、smooth skin、perfect face | 必带不完美词：毛孔、细纹、轻微不对称、汗 |
| 运镜变丝滑 | 出现 gimbal、smooth camera move、drone | 写「手持微晃 + 呼吸感」 |
| 构图变设计感 | 写了三分线、对称、精美前景框 | 写「由物理距离决定景别」并允许构图临时失衡 |
| 调色味出现 | 写了 teal orange、电影调色、氛围光 | 明写 `no colour grading`，重音色只给现场光源 |
| 人物摆拍感 | 人物朝向与姿态写成展示式 | 写「不摆拍」，动作给日常目的（找东西、等人、整理衣物） |

## 七、声音签名（中英双轨）

```
整体声音签名（中文）：环境层——真实环境底噪，是本风格的主体之一（街道、房间、空调、远处人声）；动作层——脚步、器物碰撞、衣物摩擦，实录感不加修饰；呼吸层——保留，不修饰；配乐——默认无配乐，需要时写明乐器、速度与动态。
```

```text
overall_soundscape: a documentary mix where the ambient bed is a lead element — street, room tone, HVAC and distant voices stay present and unpolished; foley is dry and unshaped for footsteps, objects and cloth; breathing is left in and untreated; no score by default.
non_diegetic_music: N/A by default — add only if specified, then name instruments, tempo and dynamics.
```

**默认无配乐必须明写**——不写，不同镜会各自补出不同的音乐。

## 八、参考图集与角色锁定

本风格无专属参考图集，角色锁定走 `<Subject N>` 通用写法。角色条目必须写头身比（7–7.5），
并写**至少两项真实特征**（细纹、斑点、轻微不对称、疤痕、晒痕）——不写就一定出塑料脸。

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删的是「精致化」一侧的词**；本风格要保留不完美，不做去立体化。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| cinematic / film still / movie scene / 电影感 | footage shot by a real camera in a real location | 触发调色与广告片质感 |
| flawless skin / smooth skin / perfect face | skin with pores, fine lines and slight asymmetry | 磨皮是本风格头号崩点 |
| gimbal / stabilised / drone / smooth camera | natural handheld micro-shake | 稳定器弧线推向广告 |
| studio lighting / soft box / rim light | available light only | 布光一出现就假 |
| teal and orange / colour graded | natural available-light colour | 调色味 |
| subsurface scattering / render / CGI | 删除 | 拉向影视级 CGI |

### 9.2 互斥风格

`photoreal-pbr`（影视级 CGI，设计与纪实互斥）、`npr-celshaded-3d`（三渲二，卡通着色互斥）、
`stylized-pixar-3d`（风格化 3D，夸张比例互斥）、`celshade-guoman-2d`（赛璐璐，绘画与实拍互斥）、
`ink-wash-2d`（手绘平面，互斥）。
