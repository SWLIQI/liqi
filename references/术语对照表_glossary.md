# 术语对照表 Glossary（中文 ↔ English）

用途：给非中文读者（与非中文代码）一张查词表，也供本机脚本做国际化映射时参考。
本表**不定义规则**，只做译名对照；规则以各自文件为准。

---

## 一、三锁（Three Locks）

| 中文 | English | 说明 |
|---|---|---|
| 前置锁（第零道锁 + 三锁） | preamble locks (lock 0 + three locks) | 任何任务第一步，缺一项就停下问用户。v5.9.0 起在 ①模型版本 / ②画幅 / ③投放面+风格轨道+交付形态 之前加**第零道锁〇赛道分流** |
| 〇 赛道分流 | Lock 0 — track routing | **第零道锁**，强制四选一：①国内剧 / ②海外剧 / ③解说叙事类 / ④其他。决定「这一类内容该怎么写」，是语速 / VO 容量 / 资产口径 / 字幕的**上位口径**。**正交于投放面**（内容类型 vs 段头骨架族）。① 最常见但**不是默认值**，仍须必问；**改赛道 = 重开任务**。见 `赛道分流.md` |
| 锁① 模型版本 | Lock 1 — model target | Seedance 2.0 / Seedance 2.5 / MiniMax H3 |
| 锁② 画幅 | Lock 2 — aspect ratio | **六值**：16:9 / 9:16 / 21:9 / 4:3 / 3:4 / 1:1（4:3、3:4、1:1 仅明确指定时用）；`ratio` 另接受 `adaptive`。白名单唯一事实源 `references/model-limits.json` 的 `ratio_whitelist`（**H3 面维持四值** 16:9 / 9:16 / 21:9 / 1:1） |
| 锁③ 投放面 + 风格轨道 + 交付形态 | Lock 3 — surface + style track + delivery form | 三项同锁 |

> **编号防混（v4.8.3 B2）**：圈号 ①②③ 在全库有三套独立编号，互不相干——
> 三锁固定写「**锁**①/②/③」；九段锚写裸 ①~⑨（见 §四）；看板区块写裸 ①~⑦（见 `看板编译规范.md` §四）。
> 看到裸圈号时按所在章节判归属，不要跨体系对数。
| 投放面 | delivery surface | **段头骨架族**，由「投放平台 + 模型版本」共同决定。共 5 个：国内面 / 国际面 / Seedance 2.5 面 / **Seedance 2.0 面** / MiniMax H3 面 |
| 国内面 | CN surface | 即梦、豆包、Dreamina、火山方舟 Ark；**模型须为 Seedance 2.5** |
| 国际面 | international surface | Sora、Veo、Runway、Kling 国际版 |
| Seedance 2.0 面 | Seedance 2.0 surface | 镜头编号事件序骨架（`镜头1：…｜镜头2：…`）；2.0 不响应时间戳，秒级时间轴禁用 |
| 段头骨架 | segment-header skeleton | 由投放面决定，**各面骨架绝不可混用**（共 5 套，不是两套） |

> **投放面 vs 模型版本（v5.6.5）**：二者是**决定关系**而非完全正交。锁① 选定模型版本后，投放面基本就定了——
> 2.5→2.5 面（或国内面）、2.0→2.0 面（或国际面）、H3→H3 面（唯一）。之所以投放面里会出现模型名，
> 是因为三家的段头语法差异大到一套骨架兼容不了。中文里「2.0 面」既指投放面也常被用来指模型线，
> 读文档时按上下文判维度。
| 全能参考模式 | all-reference mode | Seedance 2.5 的两种任务模式之一 |
| 首尾帧模式 | first/last-frame mode | 只有 `first_frame` + `last_frame` 双图 |

## 二、六条风格轨道（Six Style Tracks）

| 中文 | English | 判断要点 |
|---|---|---|
| 卡通轨 | Cartoon track | 赛璐璐上色、色块干净、硬边阴影 |
| 写实轨 | Realistic track | PBR 材质；含影视级 CGI 与纪实实拍两个分支 |
| 手绘轨 | Hand-painted track | 水墨 / 水彩 / 绘本 / 版画，平面无体积 |
| 定格木偶轨 | Stop-motion puppet track | 黏土、微缩布景、手工痕迹本身就是风格本体 |
| 三渲二轨 | NPR cel-shaded 3D track | 3D 模型 + 卡通着色；含三渲二与风格化 3D 两个分支 |
| 平面工艺轨 | Flat craft track | 皮影 / 剪纸 / 折纸，单层平面 |

相关：风格锚 = style anchor；风格 id = `style_id`；已落值 = ready；待建 = draft；
条件准入 = conditional；不入 = rejected；稳定性 = stability（稳 stable / 中 medium / 险 risky）。

## 八、资产与一致性（Assets）

| 中文 | English |
|---|---|
| 4 View 角色资产板 | 4-View character asset board |
| 左区头部近景 | left panel — head close-up（身份锚） |
| 右区保头无脸三联 | right panel — featureless-face front/side/rear |
| 图底音纹条 | bottom voiceprint strip | **4 View 卡最下方的通宽细节条**（v5.10.0 起）。只装两样：**声纹波形图形 + ≤8 词英文音色速览标签**。**通宽、不计入格数、不占主视图区**；裁切时由 `slice_reference.py --band` 预留（默认 12%）不裁入任何裁片 |
| 音色速览标签 | voice description label | **图底条右侧那行 ≤8 词英文**（如 `deep, gravelly, feigned-weak voice`），**全卡唯一允许出现的英文**。**属音色（听起来什么样）不属声纹** |
| 音色交接文本 | Voice Description (timbre) | **英文 2–4 句**（音色特质 / 语速语调 / 情绪层次 / 适用场景），**不进图**，写进《素材接线单》与提示词文档供配音 / TTS / 下游读取。**旧称「音色锁」已废止** |
| 声纹锚 / 声纹波形 | voiceprint anchor / waveform | 图底条左侧的**抽象波形图形**。**属图案不属文字**、不占「入图文字」名额。🔴 **不宣称能锁声线**——声线锁定走音频侧 TTS 音色 ID / 参考音 |
| 声纹 ≠ 音色（术语正名） | voiceprint vs timbre | **声纹 = 「这个人是谁」的生物特征**（本 skill 不做）；**音色 = 「听起来什么样」**（这才是图底那行英文交接的东西）。两者混用是旧称「音色锁」的病根（把「听起来什么样」说成了「是谁」）。v5.10.0 吸收漫剧老李口径 |
| 文字锁（16 项） | 16-point verbal lock | **外观锁**（五官 10 + 服装 6）。**音色不在这 16 项里**，也**不改 CT3 硬指纹**——音色锁不住外观，是另一条正交的交接链 |
| 光照锚点 | lighting anchors |
| 互锁词 | interlock words |
| 亲缘推导 | kinship derivation |
| 版本拆分 | version splitting |

### 身份判定四值（v5.1.0 立 / v5.6.8 落盘为字段）

| 中文 | 落盘值 | 含义与下游动作 |
|---|---|---|
| 复用 | `reuse` | 已有条目覆盖本次事实，沿用编号、身高、色值与互锁词 |
| 新变体 | `new_variant` | 同一身份的可复用新状态，基础身份不变只写差异 |
| 新资产 | `new_asset` | 持续身份不同，新建条目 |
| 未决 | `unresolved` | 证据不足：列候选 / 缺失证据 / 影响 / 解除条件，**禁写 `outputs`、禁带默认 ID 进 4 View** |

- **身份判定** identity verdict —— 5.3 的四选一，**不许模糊**（A0-A3 分级可以模糊升级，身份不行）
- **身份判定字段** `identity_verdict` —— 四桶每个条目必填，`damage_states` 不填；F4/F5 断言
- **未决容器** `identity_unresolved` —— 四键 `candidates` / `missing_evidence` / `impact` / `unblock_when`
- **出场人物行** cast line（v5.15.3）—— Step 3 第 5 小节，`出场人物：甲——<外形地标 + 服装主色形制 + 一件随身物>；乙——…`，位置在站位三行之后、`整体风格：` 之前。**把身份与画风拆成两行**（一行一个职责），供模型在几百字里先认出「谁是谁」。缺则 `E-IDENTITY-NOT-INLINE`
- **出现四态** four appearance modes —— 出镜 / 画外音 / 影像出现 / 只被提及（5.2）

## 十一、项目级门禁与工程词

| 中文 | English | 说明 |
|---|---|---|
| 四阶出图链 | four-stage image chain | 场景资产出图流程：一阶单视图基准图（文生图）→ 二阶俯视空间结构图（图生图，喂一阶）→ 三阶多视角图（2×2 四视角，图生图，喂一阶＋二阶）→ 四阶不同时段的多视角图（图生图，喂一阶＋二阶）。**前三阶各 1 张**；四阶每个时段变体各 1 张。出哪些时段**按全文判读**（v5.20.1，见 2.4.0），不按 `variants` 字段。见 `场景资产与时间线光照.md` |
| C 门 | C-gate (version drift — character / prop) | 项目级门禁之一。判据：同一镜同时出现**两个版本名** → 判串版。**适用角色 / 道具**。实现在 `audit_project.py` |
| C2 门 | C2-gate (scene time-period drift) | 项目级门禁之一。判据：同一镜**声明了时段 T，又命中 T.lock_out 里的禁写词** → 判串版。**适用场景**。实现在 `audit_project.py` |
| 时段漂移 | time-period drift | **C2 门的判定对象**：同一场景跨时段版本之间的特征串版（日景特征混进夜景版）。防它靠每个变体的 `lock_out` 互锁词，完备性直接决定 C2 召回 |
| **状态漂移 / 破坏态** | **state drift / damage state** | **第三类漂移**：事件造成的物理改变（墙被撞穿、血迹、灰烬、撕裂、烧毁）。登记处 `scenes.*.damage_states`，与 `variants` 并列。此前无任何门禁覆盖，漏登记＝下一镜画面凭空复原。由 F 门双向 `lock_out` ＋ 人工核对承接 |
| 三类漂移 | three drift classes | ① 版本漂移（C 门）② 时段漂移（C2 门）③ 状态漂移（F 门＋人工） |
| 节拍认领 | beat claiming | 写镜时逐拍认领时长与内容的机制（「认领：场次1 P01-P03」行）；挂 7 个 `E/W-BEAT-*` 专项规则码，`--beats` 给节拍清单时启用 |
| slug | slug | 文件命名规则：小写连字符（`images/<slug>-sheet.png`），**禁止中文文件名与空格** |
| 六轨道 | six style tracks | 六条风格轨道的简称：卡通轨 / 写实轨 / 手绘轨 / 定格木偶轨 / 三渲二轨 / 平面工艺轨。逐条见 §二 |
| 场景方位卡 | scene orientation card | A1 以上必做的场景产物；四要素（罗盘方位 / 固定锚物清单 / 屏幕方向映射 / 禁变约定）**一次定死**，时段变体共用同一张卡。见 `场景方位卡与固定锚物.md` |
| 高敏感画面 | high-sensitivity imagery | 过审预检里的敏感画面分级概念；`audit_literal.py` 的 **S 类**规则扫这一类，命中后按 `质控层_门禁与过审.md` §6.3 五手法规避（是规避，不是换词了事） |
| 镜头骨架 | shot skeleton | 可复用的镜头结构模板（8 类 24 条），按叙事功能检索，写时间轴前先查。见 `镜头骨架库.md` |
| 负形 | negative shape (cut-out) | 平面工艺轨（皮影 / 剪纸）的核心视觉特征词：镂空掉的那一块本身成形（红纸负形 / 刀刻硬边）；与「立体纸雕 / 纸艺」互斥，后者归定格轨 |
| 12 小节 | twelve sub-sections | Step 3 逐镜提示词的十二个固定小节（v5.15.3 加「出场人物」行）；轻量项目也照跑不减 |
| 标题参数行 | title param line | v5.28.0 起第 4 小节：`# title: 镜X｜标题`，**写在参数行区不进正文**（旧写法 `生成视频：镜X｜标题` 与镜号标题重复且占正文额度） |
| **连续性台账** | continuity ledger | v5.7.2 新增产物。**写一段登一段**的三本账：人物账（站位/朝向/服装/道具持拿/姿态/声音身份）+ 场景账（陈设状态/时段/空气介质/光源/方位卡版本/尺度参照）+ 时间轴账（入口/出口/推进）。落盘 `continuity-ledger.md`。**方位卡管不变的空间基准，台账管会变的状态**，两者不重叠。见 `连续性台账.md` |
| 人物账 | character ledger | 台账三本账之一，六项一项都不能缺。**道具持拿必须写左右手**（模型不区分左右），服装项只记当前处于哪个版本、不判断该判哪个版本（那是 C 门的事） |
| 场景账 | scene ledger | 台账三本账之一。**陈设状态**是最容易漏的一项，也是打戏之后最高频的穿帮源（墙被撞穿了，下一段回全景墙又好了）。时段只从 `lighting_anchors` 引用，不现场编 |
| 时间轴账 | timeline ledger | 台账三本账之一：入口/出口时间 + 推进方式（连续/跳跃/平行）。平行蒙太奇的两条线必须标**同一时刻锚**，否则剪辑时天光对不上 |
| 变更行 | ledger change entry | 台账里每处状态变化的一行：`触发节拍 ｜ @对象 字段：旧值 → 新值（落点或方式）`。**没有触发节拍的变化＝凭空变化**；**道具离手必有落点**，「没了」不是落点。落点允许发生在画外，但必须写明 |
| **递进收窄** | progressive narrowing | 选风格的四步交互规程（v5.8.2）：影像基底 → 3 个候选锚 → 收敛 1 个 → 可选辅助质感。**每一步都在排除，不平铺**——把 20 个已落值锚一次甩给用户等于没做筛选 |
| 影像基底 | image substrate | 2D / 3D / 实拍 / 平面工艺四选一。**必须由用户明确确认，不得由执行者自动判定**——基底判错则全片画质词 / 形体骨相 / 候选池 / 打戏档位全错在源头，下游无从纠正 |
| **选定即冻结** | lock-on-selection | v5.8.2。全包只允许该锚的**色域 / 材质口径 / 禁用项 / heads_range**；**改风格 = 重开任务，不得中途换锚**（中途换，前面所有镜的色域与负面词全部作废）。机检 S10-STYLE-GAMUT-OUT（WARN，越出 palette）+ S11-STYLE-BANNED-HIT（ERROR，出现 negative_direction）。改色域要改项目级 `style-registry.json` 并回写，**别只在提示词里换色** |
| S10 / S11 | style gamut / banned item | `check_style.mjs` 的冻结守门码。**S10** 正文用色越出该锚 palette → WARN（项目级重音色要补进 palette.extended）；**S11** 正文出现该锚 negative_direction → ERROR。**两条都在剥掉压句与配色句之后扫**，否则锚自己的压句（含「无噪点颗粒」这类否定式）会被判成串轨 |
| **情节点** | plot beat | 一次**意图变化 / 关系变化 / 信息翻转**，任一即算。不是「发生了一件事」——没改变任何人意图 / 关系 / 信息量的事不算。门槛：**单集 ≥5、15s 投喂段 ≥1**，相邻情节点不得跨过一场戏。机检只数显式标注（`情节点：`），**不标注报「无法核对」，不是通过**（N2） |
| 事实权威链 | fact authority chain | 改编项目必做。五级：`FACT`（原作明文）/ `INFERENCE`（两条以上事实推得）/ `ASSUMPTION`（无据为连贯而设，须过用户确认）/ `USER_OVERRIDE`（用户要求改写）/ `OPEN_ITEM`（未定，挂起）。权威顺序：用户提供的小说事实 > 锁定剧本 > 分集规划 > 当前稿 > 审稿意见。不分级 → 模型推断会被当成原作事实写进正文（N3） |
| 三视角审稿 | three-lens review | v5.8.1 轻量版（**不搬上游五席圆桌 full 版**——那是长剧多批次用的）。观众视角 / 类型视角 / **类型反例视角**，每视角 ≥2 个**真实问题**（空话不算，写不出＝没审）。两条反捧杀：自评不满意点 ≥1 条；**三视角全好评 → 判可疑，强制回类型反例视角再审** |
| 实体编号唯一性 | entity ID uniqueness | 同一实体不得两个编号（`@长风` 与 `@长风道长` 会被资产层当两个人建两套）；跨集项目编号连续，不每集从 1 重排——重排等于每集一套实体，台账与注册表会在集边界整片失效。机检 N1 |
| **打戏声明** | combat tier declaration | v5.8.0 新增。打戏镜段头的定档行：`【打戏声明】：R2 · 群战乱斗`（档位必写，戏型可选）。**未声明档位 = ERROR**（E-COMBAT-TIER-UNDECLARED）——定档是倒逼出来的那句话：你到底要不要打。戏型决定豁免表里哪些配额不适用 |
| 打戏四档 | combat tiers R0-R3 | **R0** 文戏 / 无打戏（liqi 特有新增，让「没打戏」成为显式声明）；**R1** 写实克制（1.5s 内接触即可，允许收势悬念收尾）；**R2** 商业高燃（必选 0.5s 硬撞 + 近景机枪对招 + 气爆 + 高潮定格）；**R3** 玄幻大招（拉满 + 最高燃定格）。**默认档按项目类型定，不是 R2** |
| IAU（独立动作单元） | Independent Action Unit | 一次独立可命中的打击或位移动作。机检按**族**去重计数（「格挡 + 硬接」算一次）。上限：≤3s → 2 类，4~5s → 3 类，≥6s → 4 类（每 +3s 放宽 1）。违反症状可辨识：出片必现「贴脸互殴 + 后半段动作消失」 |
| 镜内速度四拍 | four in-shot beats | 起（15~30%）→ 爆（极短）→ **顿（命中定住 2~3 帧）** → 收（20~35%）。**顿拍是全片最关键的一拍**，缺顿拍 = 观众没看见击中 = 再多动作也读作在乱动。补的是旧版缺失的「镜内」节奏维度（旧版只有镜与镜之间） |
| 减速器 | decelerator | 黑白闪 / 定格帧 / 慢镜三者统称——**用一处就从快拍时间里扣一处**。配额：15s 片各 ≤1，30s 片各 ≤2，短于 8s 建议全砍 |
| 冲击帧三级 | impact frame tiers | 一级 = 关键瞬间（特写 + 冲击帧）；二级 = 强力命中；三级 = 大招 / 终结技（3 帧白闪，**同场仅 1 次**） |
| 终结技三幕 | finisher three acts | 破局（0.5~1.0s，制造绝对破绽）→ 绽放（1.5~2.5s，视觉巅峰）→ 余震（1.0~1.5s，冲击扩散与形变）。**禁止一击直接结束**，终帧严禁加 0.5s 平静收势 |
| 隔空对波 | beam struggle | 双方站立不动、各放能量光束在空中相撞。**看着燃，实则零接触零位移**——属「用特效冒充激烈」。仅允许两处：㈠ 高潮大招释放 1~2s；㈡ 短暂反制 ≤0.5s 且紧接贴身 |
| 打戏豁免表 | combat exemption table | v5.8.0 **一开始就建**（不等撞了再补）。九码的量化口径原型取自「一对一贴身互殴」，外推到群战 / 枪战 / 追车 / 术法对轰 / 大场面会反向压制。**保底三条不放行**：不得整场零接触零位移无收束、相邻机位不得相同连排 ≥3 段、**不得为消除告警而把打戏改呆** |
| G 门 | G-gate (continuity ledger reconciliation) | 项目级门禁之一（v5.7.2）。**拿外部事实源（台账）去核提示词**——与 C/C2 门「只在提示词内部找矛盾」互补。G1 持物矛盾（ERROR）／G2 持物漏写（WARN）／G3 离手无落点（ERROR）／G4 角色漏登（WARN）／G5 时段对账（ERROR）／G6 段号对不上（WARN）／G7 空账元检查（ERROR）。需 `--ledger` |
| 交付契约核销 | contract checkout | L4 契约层（v5.8.3）。`check_prompt` 报全绿只代表**投喂块语法合格**，不代表全流程交付完成——它不知道上游有没有真做资产层、有没有选风格锚、有没有跑过项目级审计。核销把「阶段产物完整性」从交付人的记忆变成可核销清单：每项＝硬产出 + 唯一权威源路径 + 必现结构指纹。与 L2 `audit_project` 的分工：**L2 查内容一致性（稿内矛不矛盾），L4 查阶段产物完整性（该做的阶段做没做）**，串行跑不重叠 |
| CT1~CT8 | contract items | 八项契约：CT1 剧本门控通过记录／CT2 风格锚声明+冻结／CT3 角色资产板（4 View + 五官 10 项 + 服装 6 项）／CT4 场景方位卡+时段锚点表／CT5 道具持物设定／CT6 逐镜提示词+配额自检／CT7 投喂稿过机检／CT8 质检结论与改动复验报告 |
| 契约四态 | four states (PASS/WARN/FAIL/N-A) | `PASS` 硬产出在场且指纹齐／`WARN` 在场但指纹不全／`FAIL` 缺失或**在场但关键指纹 0 命中（＝简笔糊弄版）**／`N/A` 不适用或显式跳过。🔴 **`N/A` 不是通过，是「没查」**——报告单列、不计入核销率（延续 Z 门 / G7 / N2 的同一条口径）。核销率 = `PASS / (PASS+WARN+FAIL)` |
| 硬项（不可豁免） | sealed items | `CT2`（风格锚）/ `CT6`（逐镜块）/ `CT7`（机检）——任何形态的交付都必须做，`【契约豁免】` 声明无效并额外报提示。其余五项（CT1/CT3/CT4/CT5/CT8）依赖项目档位或交付类型，可声明豁免。**豁免一个已 FAIL 的硬项不会让它变 PASS，只会让它变 N/A**——豁免是「本项不适用」，不是「本项通过」 |
| 简笔糊弄版 | sketchy-summary version | 契约核销 FAIL 的典型形态：资产层写成「沈知微：22 岁，穿靛蓝布衫。」一行（没按 4 View 模板展开）；风格锚写成「2D 赛璐珞，冷色调。」两句（九段锚只剩两段）。判据不是「写得短」而是**关键结构指纹 0 命中** |
| 赛道分流 | track routing | **第零道锁（v5.9.0）**，先于三锁。四路：**① 国内剧 / ② 海外剧 / ③ 解说叙事类 / ④ 其他**。管**内容类型**（这一类该怎么写），与「投放面」管的**段头骨架族**（怎么排版给模型读）是**两条正交轴**。**赛道未确认 = 不开始；改赛道 = 重开任务**。权威：`赛道分流.md`。⚠️ **与「六条风格轨道 / Style Tracks」（管画风，落 style_id）是两条正交轴**——查画风、选 style_id 不进本表，进 `风格路由表.md`（v5.43.0 补辨析，外部审计指 track 一词两用易混） |
| 解说叙事类 | explainer / narration track | 赛道③。「台词」不是对白而是**旁白**——信息载体是旁白 + 画面注释 + 字幕，**旁白即主体（80~100%）**。人物可无固定角色、不做跨镜连续表演；分镜单位 = 旁白句 → 1~2 个画面。子类型三选一：历史人物志 / 历史事件战役 / 科普知识解说 |
| 解说语速档 | explainer pacing | 赛道③ 专用语速（v5.9.0）。上游理论档 4.5~6.5 字/秒；**liqi 排期取 3.8~5.0**（金句 3~3.6）、硬闸 6.5。**不盲抄上游**的理由：liqi 本地实测显示 AI 配音落点比理论档慢 20~30%（对白理论 3.5~5 → 实测 2.6~3.6），且要与既有「说书人 / 旁白 3.6~3.8」档衔接 |
| 声画信息差 | audio-visual information gap | 旁白负责「讲因果 / 讲规律 / 讲人物内心」，画面负责「给证据 / 给场景 / 给过程演示」。**判据一句话**：把旁白删掉画面信息量不得减少；把画面删掉旁白信息量不得减少。剧情赛道下画面与旁白是**并列**关系；**解说赛道允许画面配合旁白**（画面是注释不是复述），但两条赛道都禁「旁白念出画面已大字写出的内容」 |
| VO / OS | voice-over / off-screen voice | **VO** = 画外旁白 / 心声（说话者可能在画面里）；**OS** = 画外音（说话者在别处、未入画）。**两者都不锁口型**。liqi 里都写在 `对白：` 行靠**括注**区分——必须标（画外音 / 心声 / 旁白），不标就等同对白处理，模型会按口型同步演，出片必穿帮 |
| VO 容量红线 | VO/OS volume cap | 赛道① / ② / ④：**VO + OS 镜数 ≤30%**、**VO 口播 60~80 字/分钟**。这是**容量**口径（占比与字数），与台词**密度**口径（≤4.0 / ≤5.0 / 物理 6.5 字/秒）是**两个维度**，同时适用。**赛道③ 解说类豁免容量口径**（全片 VO，套 ≤30% 会把稿子判死）。**换算式（v5.43.0 补）**：60~80 字/分钟 ≈ 1.0~1.3 字/秒，是**口播总量预算**口径；旁白语速 3.6~3.8 字/秒 ≈ 216~228 字/分钟，是**单句念速**口径——两者相差约 3 倍且各管一段预算，不互相换算、不混用 |
| 素材形态 M0 / M1 / M2 | asset delivery modes | liqi 的 **M 轴（v5.9.0）**：图在不在你手里。**M0 纯提示词**（不出现任何图号，一致性靠文字锁）/ **M1 编号占位（默认）**（`@图片N` + 必附《素材接线单》）/ **M2 已入库**（用户交回图，可图像级核验）。**与 A 轴（依赖分级 A0~A3）正交**：A 轴决定要不要建资产链，M 轴决定门禁怎么判、一致性靠什么。**四铁律：不索要 / 不阻塞 / 不假装 / 要声明**；**形态切换必须显式，首行必写声明** |
| 素材接线单 | wiring sheet | M1 / M2 必附的「**平台侧挂图说明书**」——用户不需要把图交回来，只需按单子把图挂上。列：图号 / 类型 / 用途（只控制什么）/ 你该挂哪张 / 不控制什么。**图号只能有两个来源**（用户提供或本单显式定义）；**双向一致**（提示词出现过的图号本单必有行）；**不写内部 ID**。⚠️ **M1 交付 = 接线单 + 全套出图提示词**，缺任一类 = 交付不全 |
| 方言标注法 | dialect voice annotation | 把地域听感作为**语气位里的「音质」维**叠加（`（重庆话口音，语速偏快，尾音上扬）`）。**不新增字段、不写进画面描述**；强度三级（轻 / 中 / 纯方言，纯方言须用户明确指定）。🔴 **只改听感不改台词用字**——台词冻结后一字不差，方言是语气的附加描述不是改台词。**外挂参考表性质，不设门禁不参机检** |
| 语言合同 | language contract | 赛道② 海外剧必建（写在交付物顶部，**第一句对白之前**，不许写完后倒填）。六件套：目标语言 / 地区 / 语速（按目标语言，英文 ≈2.2~3.0 词/秒，**禁用字/秒**）/ 字幕（逐字锁定）/ 校准状态 / 换语纪律。🔴 **不得自称已完成本土化**——模型判断与双模型一致都不能升级校准状态 |

> **C 门与 C2 门是两套语义，不可混**：C 门判「同一镜同时出现两个版本名」，管**角色 / 道具**的
> 版本漂移；C2 门判「声明了时段 T 却写了 T.lock_out 的禁写词」，管**场景**的时段漂移。
> 判定对象、判据、适用资产类型三项都不同——拆两套的原因与 C2 的召回边界见

| 空间风险分级 S0~S4 | spatial risk grading | **决定"写多细"**（S0 单人免轴线 → S4 全量）。**与场型 V/W/X 是两套编号**，不跨体系对数 |
| 相邻镜机位角差 ≤30° | camera angle delta | 同段相邻两镜机位相对轴线的夹角差上限，超过必须用四种过渡手段之一。⚠️ **与「30°~60° 斜角」（单镜取景角）是两回事**——前者管机位变化量，后者管这一镜怎么摆 |
| 过肩退距 | over-shoulder setback | CAM3 过肩反打须写「机位自对话轴线后退 **1.5~2 米**」并给数值。**「稍退后 / 保持距离」不算写了距离**——不写会拍成贴背特写，后脑勺占画面三四成 |
| 权力几何五维 | five power axes | 高低 / 前后 / 远近 / 左右 / 视线。🔴 **场末必须 ≠ 场初**（至少变一维）；**过场须显式声明重置了哪几维** |
| 节拍五段闭环 | five-beat loop | 起势 → 路径 → 接触/阻挡 → 落点 → **接收者反应**。🔴 **第 5 段是最高频漏项**——不给反应，观众不知道打没打中 |
| 动作重合 60~80% | action overlap band | **同段内**相邻两镜表现同一连续动作时的重合区间：<60% 动作断、>80% 显得重复。**跨段不要求**（蒙太奇直切，跨段切同段连） |
| **段末接戏全景（v5.14.0 立 · v6.4.0 废止留档）** | handoff anchor wide | 🔴 **v6.4.0 起废止**（实测撤销，机检催报码移除；跨段衔接走跨段继承＋实际尾帧硬绑定）。原文：**末拍不是档 1~3 的段**（单人 / 双人 / 多人一视同仁），**末拍前给 1 秒的档 1~3 全景**，**首选「缓拉」承前式**（从上一拍机位后拉、站位承前不重新设计）、备选固定机位，框住全部在场角色（画面左右 / 朝向 / 持物左右手 / 与锚物关系四件事可见）。🔴 **投喂要投、成片要剪**：占时长与字数额度、真的渲出来给下一段当 `first_frame` 与站位底本，**剪辑时整拍剪掉**，「剪辑时剪掉…」**写在施工行、不进正文**。**CAM1 给入口，接戏全景给出口**。豁免：X 型 / 长镜 / 片终最后一段 + 声明式「【接戏全景豁免】：理由」（**单人已不豁免**，v5.15.6）。**末拍本身就是档 1~3 的不另加**（排除项）。**那 1 秒优先从前段/中段扣，不从戏剧高点扣**（v5.15.4）。**景别按跨度选**：3 人及以上→远景、2 人相邻→全景；**拉程 ≥6 档（大特写起）改明写「快速后拉」**（v5.15.7） |
| 决策证据 / 被否决方案 | decision evidence / rejected alternative | **S3 / S4 必写两行**：为什么这么摆 + 考虑过但不用（及否决原因）。改稿时可复核，防在几种摆法之间来回横跳 |
