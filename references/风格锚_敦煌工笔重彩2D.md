# 敦煌 / 工笔重彩 2D 风格锚（手绘轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**敦煌壁画传统 / 工笔重彩**这套具体风格上的落值
（v5.42.0 批 3 第三个），同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——
改一个词，不同镜头质感就会漂移。

**适用判定**：铁线描细匀轮廓、满构图矿物色（石青、石绿、朱砂）、沥粉描金、
土黄壁底、平面装饰性透视（散点、无灭点）、人物带飞帛与飘带节奏。敦煌题材活化、
盛唐气象、佛本生与飞天、文物活化纪录片、国风史诗段落都吃这套。
用户给的设定图是这类矿物重彩质感时，锁③ 选**手绘轨**，风格 id 取 `dunhuang-gongbi-2d`。

**边界声明**：

- 与水墨淡彩（`ink-wash-2d`）：同是手绘轨，方向相反——水墨要留白与晕染、一淡到底；
  工笔重彩要**满构图、矿物色、层层罩染的实色**。判据是「空与满」：大量留白 = 水墨，
  画面铺满色 = 本风格。两者已在 L0 登记互斥。
- 与国潮新中式（`guochao-2d`）：国潮是现代设计语言借传统纹样，色块平涂带当代构图；
  本风格是**壁画传统的材料感**——壁底、矿物色、沥粉贴金是有材料出处的，不是设计元素。
- 与三渲二/3D 轨：本风格是 2D 手绘平面；3D 化的「洞窟漫游」另走 `guofeng-cine-3d`。

> ⚠️ **版权与文物规避**：投喂词内**不点名具体洞窟编号、不点名当代修复机构与摄影师**。
> 写「敦煌壁画传统」「盛唐风格」这类断代与地域描述；具体纹样写到「联珠纹」「卷草纹」这类
> 公有形制名为止。作品名只出现在本文档的说明层与对话里。

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Chinese Gongbi heavy-colour painting in the Dunhuang mural tradition, fine even iron-wire outlines, densely packed flat mineral pigment areas of azurite blue and malachite green, gold-leaf accent lines, aged earthen plaster background, flat decorative perspective without western vanishing points, no gradient, no grain.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
mineral palette of earthen ochre ground with azurite blue and malachite green filling the frame, vermilion accents and gold-leaf outlines as the single accent per frame
```

**三条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `Japanese anime` / `manga style` | `Chinese Gongbi heavy-colour painting` | 语种风格路由：anime 词把飞天龙女画成日漫 cosplay，是本锚头号事故 |
| `soft watercolour wash` / `gradient` | `flat mineral pigment areas` | 晕染词把矿物实色变水彩，壁画感全失 |
| `realistic perspective` / `depth of field` | `flat decorative perspective` | 西画透视与景深是壁画本体之外的东西，一加就出 3D 场景图 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。
改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 44 词（按校验器空白分词口径实测），在二十个锚里居中，仍留加词空间，但别堆否定串。

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅中国工笔重彩绘画，敦煌壁画传统：铁线描细匀勾勒，石青石绿等矿物色平涂铺满画面，沥粉贴金的金线勾勒轮廓，土黄壁底带轻微壁面肌理。平面装饰性透视，无西画灭点，无渐变，无噪点颗粒。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
矿物重彩配色：土黄壁底铺底，石青与石绿铺满画面，朱砂为辅，每帧只保留一处沥金重音。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「日系和风」「浮世绘」 | 「敦煌壁画传统」「盛唐风格」 | 语种风格路由，和风词把飞天与服化道整套带偏 |
| 「立体感」「光影层次」 | 「平涂矿物色」「平面装饰性透视」 | 立体词把壁画推向 3D 场景渲染 |
| 「不要太满」 | 删否定句，正面写「满构图、色块铺陈」 | 本风格的本体就是满构图，否定句反而引入留白倾向 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（铁线描、矿物色平涂、沥粉贴金）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成

## 三、色值表（风格级起点，项目级以 asset-registry 为准）

| 用途 | 色值 | 说明 |
|---|---|---|
| 土黄壁底 | #E8D8B8 | 全画面基调底色，带壁面肌理 |
| 石青（主色） | #2E4E7E | 衣袂、天穹、飘带的主色域 |
| 沥粉金（重音色） | #C9A227 | 全片唯一重音色：金线、璎珞、冠饰、背光 |
| 石绿 | #3D7A5E | 与石青配对的主色域，山石与衣饰 |
| 朱砂 | #9E3B2F | 辅助色：唇色、花瓣、点缀 |
| 铅白 | #EFE6D8 | 高光面与人物肤色亮部 |
| 赭石 | #8C5B3F | 壁面深部与线描棕调 |
| 青金石深 | #1F3A5F | 石青的深部层次，罩染用 |

**色彩预算纪律照旧**：每镜只声明一个唯一重音色（默认沥粉金），其余按石青石绿主域压平。
矿物色的辨识度在「色域窄而稳」——重音一多，壁画变年画。

**暗部纪律**：暗部 = 同色系矿物色加深一档罩染（石青加深是青金石深），**不是灰、不是黑**。
这是工笔「三矾九染」的逻辑：层次靠罩染次数，不靠黑白。

**同步纪律**：本表与 L0 注册表的 `palette` 必须一致，改一处要同步另一处。
项目级具体角色的色值另存 `asset-registry.json`，不抄进本文件。

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **飞天龙女变日漫 cosplay** | 压句混入 anime 词、眼型写大 | 压句钉死 `Chinese Gongbi`；眼型按「细长上挑」写死 |
| **矿物色变水彩淡彩** | 写了晕染、水痕、透亮 | 钉死 `flat mineral pigment areas`；色块是实色不是透的 |
| **壁画变 3D 洞窟场景** | 写了立体、纵深、光影 | 平面装饰性透视写死；要 3D 漫游换 `guofeng-cine-3d` |
| **金线变黄色渐变** | 沥粉贴金写成「金色光效」 | 金是「线」不是「光」——写 `gold-leaf accent lines`，不写 glow |
| **色域漂向年画** | 朱砂面积失控、重音过多 | 每镜一个沥金重音；朱砂只做辅 |
| **满构图变拥挤** | 元素堆叠没有主次 | 满构图≠均质：主像占画面主导面积，配景按法式铺 |
| **角色跨镜换形制** | 发髻与帔帛没写死 | `<Subject N>` 内锁定形制名，跨镜逐字复用 |

## 九、去立体化与串轨防护

本风格是手绘平面轨，**去立体化方向与水墨一致但词表不同**：不要直接跑
`dedupe_style.py --style ink-wash-2d`（水墨词表会删「描金」类结构词），按 §9.1 手工清。

### 9.1 污染词与替换对（工笔重彩方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 日系和风、浮世绘、anime | 敦煌壁画传统、盛唐风格 | 语种风格路由，头号事故源 |
| 水彩晕染、水墨氤氲、透亮 | 矿物色平涂、层层罩染 | 晕染把实色矿物变水彩 |
| 立体感、光影纵深、体积光 | 平面装饰性透视、平涂色块 | 立体词把壁画推向 3D 场景 |
| 金色光效、金光普照 | 沥粉贴金金线 | 金是「线与面」不是「光」 |
| 留白、极简、空灵 | 满构图、色块铺陈 | 留白是水墨的本体词，写进来就变水墨 |
| 写实肌肤、毛孔 | 平涂肤色（铅白基调） | 写实皮肤词是滑向 3D 的入口 |
| 噪点、颗粒、胶片感 | 删除，壁面肌理除外 | 颗粒与肌理是两回事：肌理是壁面，颗粒是摄影 |

**保留不动的词**（这些在别的轨要删，在本轨是本体）：`flat`、`outline`（铁线描）、`gold`、`mineral`、`mural`。
