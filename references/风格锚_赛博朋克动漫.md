# 赛博朋克动漫·霓虹义体 风格锚（卡通轨 × 赛博动画专项）

本文件是 Step 2「全片统一风格锚（九段）」在**日系赛博朋克动画（cyberpunk anime）质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：攻壳/Akira 一脉的赛博动画——霓虹雨夜都市、义体与 HUD 界面、高对比霓虹色块、
赛璐璐上色的动画人物、中文/日文霓虹招牌的失焦色块。用户给的是赛博朋克 / 义体改造 /
近未来都市动画参照时，锁③ 风格轨道选**卡通轨**，风格 id 取 `cyberpunk-anime-2d`。

**边界声明**：

- 与暗黑二次元（`dark-anime-2d`）：暗黑是低照度悬疑（哥特阴郁、无科技元素）；赛博是**霓虹高饱和**
  （义体、HUD、全息）。科技层是分界。
- 与新海诚系（`shinkai-2d`）：诚系是清新光晕与自然风景；赛博是工业霓虹与都市峡谷。光色相反。
- 与热血少年漫（`shonen-hotblood-2d`）：热血是高调爆发平涂；赛博是霓虹环境光的低照度高对比。
- 与复古港风（`hk-retro-filmstill`）：港风是**实拍胶片**霓虹；赛博是**动画赛璐璐**霓虹。维度互斥。

> **竖屏适配（C26）**：都市峡谷的纵深天然纵向——竖屏写法：霓虹招牌纵向层叠（上段全息广告、
> 中段人物、下段湿街反光），义体 HUD 界面沿竖边排布。**竖屏友好，无需改写行**。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A cyberpunk anime frame: clean cel shading with cool-shifted tones, magenta-cyan-violet neon ambient light wrapping the character rims and faces, cybernetic seams and hairline HUD graphics glowing thin, rain-slick streets mirroring neon signs as defocused colour blocks. High-contrast low-key city night, details kept in shadows. Never daylight, never warm sun.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
magenta-cyan-violet neon ambient scheme, dark character base tones, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `sunny daylight / 清新` | `low-key city night` | 反串清新档 |
| `readable neon signs` | `defocused colour blocks` | 可读文字铁律 |
| `grim gothic dark` | `high-contrast ... details kept in shadows` | 暗黑悬疑档无科技霓虹 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 50 词，偏长档——预算紧先删末句（Never daylight 一句，由负面词锁）。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅日系赛博朋克动画的画面：干净的赛璐璐上色带冷色调偏移，品红青紫三路霓虹环境光勾出人物轮廓与受光面，义体接缝与发丝般的 HUD 细线在发光，雨夜湿街镜像着失焦成色块的霓虹招牌。高对比低照度的都市夜，暗部保留细节。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：品红青紫三路霓虹环境光，人物本体色压暗，每镜只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「白天」「阳光」「清新」 | 删，写「低照度都市夜」 | 反串清新档 |
| 「招牌上写着…」 | 「招牌失焦成色块」 | 可读文字铁律 |
| 「阴森恐怖」 | 删，写「霓虹高对比」 | 反串暗黑档（无科技） |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（赛璐璐冷调、三路霓虹环境光、义体接缝发光、招牌失焦）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把霓虹推成荧光辣眼或招牌变可读字**，所以「冷调赛璐璐」与「招牌失焦」在国内面**不许省略**。

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 跑成实拍港风 | 写了胶片颗粒、真人质感 | 锁「赛璐璐动画」「动画人物」；维度互斥 |
| 跑成暗黑悬疑 | 霓虹全灭只剩黑暗 | 三路霓虹环境光不许省；负面词带无光源纯暗 |
| 招牌变可读字 | 写了招牌内容 | 「失焦色块」锁死；可读文字铁律 |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「实拍化」与「清新化」两侧的词**，保留动画赛璐璐与霓虹环境光。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| film grain / 胶片 | clean cel shading | 反串实拍港风 |
| daylight / 阳光 | low-key city night | 世界规则 |
| gothic grim / 哥特阴森 | neon high-contrast | 反串暗黑档 |
| photoreal cyborg / 写真机械 | glowing seam graphics | 义体是动画图形 |
| readable signs | defocused colour blocks | 可读文字铁律 |

### 9.2 互斥风格

`dark-anime-2d`（哥特阴郁无科技 vs 霓虹义体）、`shinkai-2d`（清新光晕自然 vs 工业霓虹都市）、
`hk-retro-filmstill`（实拍胶片 vs 动画赛璐璐，维度互斥）、`synthwave-retro-2d`（图形海报 vs 叙事动画）。
