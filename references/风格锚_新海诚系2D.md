# 新海诚 / 京都动画系 2D 风格锚（卡通轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**日系光色背景绘抒情动画**这套具体风格上的落值
（v5.42.0 备选批首个），同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——
改一个词，不同镜头质感就会漂移。

**适用判定**：手绘感极强的写实度背景（城市、天空、云海、雨景）、魔幻时刻的饱和光色、
逆光与镜头光斑、背景精细而人物上色干净简练的质感对比、青春都市或小镇风景抒情。
都市青春、恋爱物语、风景治愈、雨夜与黄昏情绪戏都吃这套。
用户给的设定图是这类「背景插画级、人物动画级」质感时，锁③ 选**卡通轨**，风格 id 取 `shinkai-2d`。

**边界声明**：

- 与日系动画（`anime-2d`）：同一赛璐璐人物体系，但背景精度与光色戏剧性是分水岭——
  anime 通用档背景服务叙事、干净简洁；本风格**背景本身是主角**，光色时刻决定情绪。
  判据：把人物遮住，背景还像一张画 = 本风格。
- 与吉卜力系（`ghibli-2d`）：吉卜力是柔和自然光下的透明水彩乡村世界；本风格是饱和的
  都市/天空光色、锐利的逆光与光斑。判据是光：柔光 = 吉卜力，魔幻时刻强光 = 本风格。
- 与写实轨：本风格背景虽然写实度高，但**仍是画的**——天空有笔触式的云层堆叠，
  不是照片。镜头光斑是画出来的装饰，不是光学实录。

> ⚠️ **版权规避**：投喂词内**不点名任何导演或工作室名**（哪怕用户明说想要某导演的味道）。
> 只写风格特征——光色背景绘、魔幻时刻、积雨云天穹。导演与作品名只出现在本文档的
> 说明层与对话里；机检 `W-DIRECTOR-NAME-IN-BODY` 守正文。

## 一、九段锚（中文，给 liqi 上游用）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 日式 2D 动画，光色背景绘传统：背景是插画级手绘（笔触可见的云层、砖瓦、光影渐变），人物是干净赛璐璐上色；两者质感对比是本体；无噪点颗粒 |
| ② 配色与色域 | 饱和的光色系：晴空蓝与黄昏暖白为基调，晚霞橙做全片唯一重音色；随叙事时刻整体偏移（清晨冷蓝 → 黄昏金橙 → 夜晚青蓝），但每镜内部色域统一；禁灰调大底、禁脏色 |
| ③ 运动签名 | 24fps；人物动作干净克制（日常幅度），环境动效是主角——云层缓移、雨丝斜落、光线缓变、风摇树梢；无运动模糊（光斑是静态装饰）；无镜头抖动 |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 6.5–7（偏写实的日系档）**；自然系五官、发型有空气感碎发、服装日常形制与配色写死；转面不换形，跨镜不换装 |
| ⑤ 场景锁定 | 走 `<Subject N>`：建筑与街景按真实城市形制刻画（**背景精度是本风格主花费**）；电线杆、护栏、站牌等城市元素按几何形制写；**同场景跨镜地标、光位与云层状态必须一致** |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、入画方式必须写（手持 / 悬挂 / 置地）；手机、车票、饮料罐等现代道具按真实形制但干净上色 |
| ⑦ 光色基调 | 魔幻时刻体系：低角度暖主光 + 天空冷补光，逆光合法且高频（人物边缘光 + 镜头光斑）；影子长而柔和（一个方向、边缘略柔）；禁平光、禁顶光大白脸 |
| ⑧ 声音签名 | 环境层：城市底噪与自然声分层（电车、蝉鸣、雨、风）；动作层：轻而清晰的生活音（脚步、书包扣、易拉罐）；呼吸层：自然的、克制的；配乐：钢琴弦乐为主的抒情配乐，情绪段落才进 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅生图模型与其他有 negative 字段的面可用：3D 渲染、厚涂油画笔触、噪点颗粒、暗调悬疑、灰雾天空、Q 版二头身、可读文字、水印 logo |

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Japanese animated frame in the luminous painted-background tradition, towering detailed cumulus skies, saturated magic-hour light with warm dusk tones, gentle lens sparkle and rim-lit characters, finely painted backgrounds against cleanly shaded characters, no grain.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
saturated light-driven palette of dusk warm white and clear sky blue with sunset orange as the single accent per frame, colours shifting with the story hour but unified within each frame
```

**三条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 导演名 / 工作室名进正文 | `luminous painted-background tradition` | 版权规避铁律（F-4）：参考只作内部解析，转译为可见参数 |
| `realistic sky photo` / `photoreal background` | `towering detailed cumulus skies`（画出来的） | 背景是画不是照片——photoreal 词把整包推向实拍轨 |
| `moody dark sky` / 灰雾天 | `saturated magic-hour light` | 灰雾是阴天语法，本风格的天空永远有光色戏 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。
改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 35 词（按校验器空白分词口径实测），偏短，加词空间充足，但别堆否定串。

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅日式 2D 动画画面，光色背景绘传统：背景是插画级手绘精度，积雨云堆叠的天穹占画面主导，魔幻时刻的饱和光色带暖调黄昏倾向，人物带边缘逆光与轻微镜头光斑。背景精细、人物上色干净，两者质感对比分明。无噪点颗粒。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
饱和的光色配色：黄昏暖白与晴空蓝为基调，晚霞橙作每帧唯一重音；色随叙事时刻整体偏移，但每帧内部色域统一。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 导演名 / 作品名（「像某导演那种」） | 「光色背景绘传统」「魔幻时刻」 | 版权规避铁律；中文名同样会被平台过滤 |
| 「阴天灰蒙蒙」 | 「透亮的天空」「云层有光色层次」 | 灰天词瓦解光色戏剧性 |
| 「背景随便一点」 | 删——背景精度是本体 | 本风格背景就是主花费，降低背景=变成 anime 通用档 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（插画级背景、魔幻时刻、边缘逆光）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台自带美化倾向会把背景糊成景深虚化**（把插画级背景当照片虚化掉）——
所以 2.2 那句「背景是插画级手绘精度」「背景精细」在国内面**不许省略**。

## 三、色值表（风格级起点，项目级以 asset-registry 为准）

| 用途 | 色值 | 说明 |
|---|---|---|
| 黄昏暖白（底色） | #F5E6D0 | 天空亮部与暖调基底 |
| 晴空蓝（主色） | #4A7BA6 | 天空主体与冷调区域 |
| 晚霞橙（重音色） | #FF8C5A | 全片唯一重音色：霞光、逆光边缘、光斑 |
| 云海亮白 | #FDFBF7 | 云层受光面，接近纯白 |
| 暮紫 | #6B5B95 | 黄昏远天与阴影偏色 |
| 线杆灰 | #8A8E94 | 电线杆、护栏等城市元素 |
| 草坡绿 | #7BA05B | 植被与地面暖调 |
| 暮云金 | #E8B87A | 云层被霞光染色的过渡层 |

**色彩预算纪律照旧**：每镜只声明一个唯一重音色（默认晚霞橙）。
本风格的特殊点：**色域随叙事时刻整体偏移**（晨蓝 / 昼青 / 暮金 / 夜蓝），
偏移要按场景组整体声明——同一场景组内偏移量必须一致，否则跨镜跳色。

**暗部纪律**：暗部 = 暮紫 / 晴空蓝加深，带环境色倾向，**不是灰黑**。
阴影边缘略柔（与赛璐璐硬边不同档），但不做渐变涂抹。

**同步纪律**：本表与 L0 注册表的 `palette` 必须一致，改一处要同步另一处。
项目级具体角色的色值另存 `asset-registry.json`，不抄进本文件。

## 四、运镜池

| 类别 | 镜头 | 用法 |
|---|---|---|
| 主力 | 缓慢横移（城市扫街）、固定长镜（让云与光自己动）、缓推入人、仰拍天空、雨窗内望 | 运镜给背景让戏——天空与光才是情绪主角 |

| 项 | 落值 |
|---|---|

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **背景被虚化成景深** | 写了浅景深 / 背景虚化 | 压句钉死 `finely painted backgrounds`；全画面清晰是本风格铁律 |
| **背景变照片质感** | photoreal 词混入 | 「画出来的」写死——天空有笔触式云层；负面词带照片质感 |
| **光色戏丢失，变普通日漫** | 光位没写、时刻没定 | 每镜声明叙事时刻（晨 / 昼 / 暮 / 夜）与光源方向；同场景组时刻锁定 |
| **逆光死黑，人物成剪影** | 逆光写了但补光没写 | 边缘逆光 + 一档冷补光同时写；人物暗部保留细节 |
| **跨镜跳色** | 时刻偏移没按场景组锁定 | 同场景组内时刻偏移量一致；切换时刻 = 显式转场镜 |
| **导演名进正文触发过滤** | 用户给了导演参照，执行者照抄 | 只写特征参数；机检 `W-DIRECTOR-NAME-IN-BODY` 兜底 |
| **角色跨镜换脸** | 没走 `<Subject N>` | 每镜内联锁定；首帧必带身份锚图 |

## 九、去立体化与串轨防护

本风格是 2D 赛璐璐系，**不要跑手绘轨或定格轨的 `dedupe_style.py` 词表**，按 §9.1 手工清。

### 9.1 污染词与替换对（光色背景绘方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 导演名、工作室名、作品名 | 光色背景绘传统、魔幻时刻 | 版权规避铁律（F-4），机检兜底 |
| 背景虚化、浅景深、bokeh | 全画面清晰、背景插画级 | 虚化把插画背景变照片语法 |
| 照片感、实拍质感 | 画出来的云层、手绘光色 | 实拍词把整包推向写实轨 |
| 阴天、灰雾、压抑低沉 | 透亮天空、云层光色层次 | 灰天词瓦解光色戏剧性 |
| 立体渲染、3D 感 | 手绘背景、赛璐璐人物 | 立体词把画面推向 3D |
| 噪点、颗粒、胶片感 | 删除 | 本风格要干净的数字赛璐璐 |

**保留不动的词**（这些在别的轨要删，在本轨是本体）：`lens sparkle`（画出来的光斑）、`rim-light`、`saturated`、`sky`、`cloud`。

### 9.2 互斥风格

重点对子（写具体因）：

| 互斥 id | 混了会怎样 |
|---|---|
| `anime-2d`（日系动画 2D） | 同母系但背景精度与光色戏不同档：通用档背景服务叙事，本风格背景是主角，混写两头不靠 |
| `ghibli-2d`（吉卜力系） | 柔和自然光乡村 vs 饱和魔幻时刻都市，光色体系相反 |
| `dark-anime-2d`（暗黑二次元） | 透亮光色 vs 低照度悬疑，明暗逻辑相反 |
| `documentary-live-action`（纪实实拍） | 画的光色 vs 摄影机实录，媒介声明互斥 |

**以下补登自 L0 excludes 全量对齐（v5.42.0）**——其余互斥 id 保证锚文件与 L0 无漏：

| 互斥 id | 混了会怎样 |
|---|---|
| `celshade-guoman-2d`（国漫赛璐璐 2D） | 光色抒情 vs 明快美型色块，色域与叙事气质不同 |
| `webtoon-2d`（韩漫条漫） | 横屏光色抒情 vs 竖屏条漫分格，构图与精度互斥 |
| `thickpaint-2d`（厚涂二次元） | 干净赛璐璐 vs 厚涂软过渡，笔触逻辑相反 |
| `comic-popart-2d`（美漫波普） | 光色渐层 vs 波普平涂撞色，色域互斥 |
| `gouache-2d`（绘本水粉） | 都市光色 vs 童书纸面，受众与质感双反 |
| `chibi-qban-2d`（Q 版超变形） | 写实头身档 vs 超变形档，头身档互斥 |
| `dunhuang-gongbi-2d`（敦煌工笔重彩） | 天空光色 vs 壁画平光，光色体系互斥 |
| `ink-wash-2d`（水墨淡彩） | 饱和光色 vs 淡彩留白，色域相反 |
