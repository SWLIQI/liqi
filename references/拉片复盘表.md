## 零、与台账的分工（谁记什么）

| 工具 | 粒度 | 记什么 | 不记什么 |
|---|---|---|---|
| `render_ledger.py`（C18） | 段级 | attempt / outcome / 成本 / 实际尾帧 / learned_rule 一句话 | 节拍级偏差分析 |

## 一、泳道时间轴表（镜级，主表）

每段一行，计划与实画并排：

| 段/镜 | 计划节拍（Step 1 带宽） | 计划运镜 | 实画面（拉片描述） | 偏差类型 | 喂下一包的改法 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

偏差类型六选一：**节拍缺**（计划三拍实出两拍）／**运镜假**（写推进实放大）／**表演过**（情绪链跳级）／**收束散**（末拍无定格感）／**一致性漂**（脸/服/光与锚不符）／**时长越**（超出 ±15% 带）。节奏类偏差（节拍缺/时长越）归因时**挂包首【节奏档位】**（v6.14.0 · C33-B）——同是「节拍缺」，高密度档是密度预算超支、电影感档是节拍供给不足，改法不同；未声明档位的包先补声明再复盘。

## 二、结构树（段-镜-节拍层级）

把交付包的结构树对照成片重画一遍，节点标三类：`✓` 如期 / `△` 偏差（挂泳道表行号）/ `✗` 废镜（与镜头裁定表联动——废镜禁入 canon）。成片结构与计划结构的**分叉点**，就是下一包 Step 1 分段要改的地方。

## 三、实测情绪曲线表（0–10 分）

| 节拍 | 计划分值 | 实测分值 | 差因 |
|---|---|---|---|
|  |  |  |  |

**分值口径唯一锚 = 《叙事层_剧本门控与台词.md》§五 情绪张力曲线**——开局冲突首拍 ≥3.0、波峰不少于 2 次、高潮间必须回落、防全片平铺，四条法则同尺。实测分是拉片时对着成片的人工打分，不是机检；打分纪律：同一个人打完整片，中途不换人。

**判据要带实证对照（v6.5.0 · C31，来源 Leonxlnx/taste-skill ③ MIT——判据实证化格式）**：凡立「好/坏」判据（锚像不像、节奏拖不拖），写判据时附**自己拉片数据的高分/低分对照**（如「高分段 X 特征出现率 vs 低分段 Y%」）——没有对照数据的阈值是感觉，搬外部领域的数值是假实证（网页审美阈值不适用于视频帧，同 C31 风险注记）。首个项目拉完片前，判据一律标「未定阈值 · 先记现象」。
