# 韩漫条漫 2D 风格锚（卡通轨 × 竖屏专项）

本文件是 Step 2「全片统一风格锚（九段）」在**韩漫条漫（webtoon）**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：数字绘制的彩色条漫质感——干净的数码勾线、柔边过渡的赛璐璐上色、皮肤带轻微柔光与渐变、
人物比例修长偏成人向（8 头身常见）、画面以竖构图组织、镜头靠「分格感」推进而不是连续运镜。
叙事单元短、一屏一格、靠上下滚动的节奏感。用户给的设定图是这类质感时，锁③ 风格轨道选**卡通轨**，
风格 id 取 `webtoon-2d`。

**边界声明**：

- 与日系 anime（`anime-2d`）：两者都用赛璐璐上色，**区别在上色厚度与比例**。anime 是薄色 + 两段式硬分界 + 6.5–7 头身；
  条漫是**柔边过渡 + 皮肤带轻微渐变 + 7.5–8 头身**，且允许更多的数码柔光。
- 与国漫赛璐璐（`celshade-guoman-2d`）：国漫走美型大眼与干净厚亮色块、头身 6–6.5；条漫走修长成人比例与柔光皮肤。
- 与写实 PBR（`photoreal-pbr`）：条漫的皮肤有柔光但仍是画，不是照片；写了真实毛孔与摄影镜头发就跑偏。
- 与韩系插画（`korean-illust-2d`）：那是单张插画质感，无分格与叙事节奏；本 id 是条漫叙事档。

> **本风格是竖屏 9:16 的专项档**：它解决的是「9:16 只有画幅语法、没有内容模板」这个缺口。
> 横屏项目不要用本 id——横屏用 `celshade-guoman-2d` 或 `anime-2d`。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 数字绘制的彩色条漫：干净数码勾线，上色是柔边过渡的赛璐璐（不是两段式硬边），皮肤带轻微柔光与渐变，人物是平面绘画不做体积渲染；整体有屏幕显示的发光感 |
| ② 配色与色域 | 明快偏冷的都市色：低饱和背景 + 高饱和人物；**每镜只声明一个唯一重音色**；禁用脏灰、大面积荧光、粗颗粒噪点 |
| ③ 运动签名 | 24fps，**分格式推进**：一个叙事单元一屏，靠上下位移与轻微缩放推进，**禁止连续长镜跟拍、禁止环绕、禁止甩镜** |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 7.5–8（修长成人档，少年取 7）**；脸型偏瓜子、眼型细长、发型是明确的体块与流向；服装走现代都市形制；跨镜不换装、不换瞳色 |
| ⑤ 场景锁定 | 走 `<Subject N>`：都市室内外景，背景绘制密度低于人物；同场景跨镜地标与光位一致；竖构图时场景要写「上中下三段各有什么」 |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、入画方式必须写（手持 / 悬挂 / 置地）；手机、杯具、文件这类现代小道具是本风格的常见道具 |
| ⑦ 光色基调 | 柔和的屏幕光：主光方向明确但边缘柔；允许皮肤高光与轻微辉光；**禁硬边两段式阴影、禁全局光照、禁写实景深虚化** |
| ⑧ 声音签名 | 环境层：都市底噪（车流、空调、人声远处）；动作层：衣物、手机提示音、开关门，节拍干净；呼吸层：情绪点才写；配乐：轻电子 / 都市 R&B，低速 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅其他有 negative 字段的面可用：3D 渲染、写实照片感、两段式硬边赛璐璐阴影、厚涂油画、Q 版二头身、粗颗粒噪点、可读文字、水印 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Korean webtoon illustration look: clean digital lineart, soft-edged cel shading with slight skin glow and gentle gradients, elongated eight-head adult proportions, flat graphic characters with a screen-lit finish. Vertical panel composition, no camera orbit, no continuous tracking shot.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
webtoon palette with desaturated backgrounds and saturated characters, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 头身写成数字加中文（如 `8头身`） | `eight-head adult proportions` | H3 正文必须纯英文，混中文会触发 `check_prompt_h3.mjs` 的英文纯度检查 |
| `two-tone cel shading` / `hard edge shadow` | `soft-edged cel shading` | 硬边两段式是 anime 轨的本体，写了就变日系 |
| `realistic photo` / `skin pores` | `flat graphic characters` | 写实词会把条漫拉向照片 |

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅韩漫条漫质感的画面：干净的数码勾线，上色是柔边过渡的赛璐璐，皮肤带轻微柔光与渐变，人物是修长的成人比例，整体是平面绘画的数码质感并带屏幕亮感。竖屏分格构图，镜头不环绕，不做连续长镜跟拍。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
条漫配色：背景低饱和、人物高饱和，每帧只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「漫画风」「条漫」单写 | 「韩漫条漫质感的数字绘制」 | 「漫画风」会被引向黑白线稿或美漫 |
| 「硬边阴影」「两段式」 | 「柔边过渡的赛璐璐」 | 硬边是日系 anime 的词 |
| 「不要写实照片」 | 删否定句，正面写「平面绘画的数码质感」 | 否定不生效 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次（数码勾线、柔边赛璐璐、竖屏分格、不环绕）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台会把柔边赛璐璐渲染成硬边两段式**，
所以「柔边过渡的赛璐璐」这句在国内面**不许省略**。

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 变日系 anime | 写了硬边两段式、头身掉到 6.5 | 压句写 `soft-edged cel shading`，头身写死 7.5–8 |
| 变写实照片 | 出现 photorealistic、skin pores、摄影镜头词 | 删掉，写 `flat graphic characters` |
| 皮肤变塑料 | 柔光写成 glossy / plastic | 写「轻微柔光与渐变」而非「高光」 |
| H3 正文混中文 | 压句里夹中文词 | 压句纯英文，跑 `check_prompt_h3.mjs` 确认 0 warning |
| 竖屏构图崩（人物贴边 / 上下留黑） | 没按上中下三段写 | 每镜场景段写「上段 / 中段 / 下段各有什么」 |
| 背景抢戏 | 背景饱和度高过人物 | 写「背景低饱和、人物高饱和」 |
| 连续运镜导致形崩 | 写了长镜跟拍 | 运镜池里连续跟拍是禁项 |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「硬边化」与「写实化」两侧的词**，保留柔边过渡与数码平面感。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| two-tone / hard edge / crisp shadow | soft-edged cel shading | 硬边是 anime 轨本体 |
| photorealistic / skin pores / DSLR | flat graphic characters | 写实词拉向照片 |
| glossy / plastic highlight | slight skin glow | 塑料感是柔光皮肤最常见的崩法 |
| 中文词混入英文压句 | 全部改英文 | H3 面英文纯度门禁 |
| thick paint / oil brush | clean digital painting | 厚涂破坏数码质感 |

### 9.2 互斥风格

`anime-2d`（日系，硬边两段式与柔边互斥）、`celshade-guoman-2d`（国漫，头身与配色气质互斥）、
`photoreal-pbr`（写实，平面绘画与真实材质互斥）、`ink-wash-2d`（手绘平面，数码与水墨互斥）。
