# 黏土定格 3D 风格锚（定格木偶轨 × 通用暖调档）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**通用黏土定格（claymation）**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

**适用判定**：手作黏土偶质感——大头细肢、表面留着指痕与工具刮痕、接缝可见、一律哑光不反光；
布景是**真实搭出来的微缩模型**（板材接缝、干苔藓、植绒、手工做旧都看得见）；
暖主光加柔和补光，投影柔和而短；动作带定格的顿挫。用户给的设定图是这类质感时，
锁③ 风格轨道选**定格木偶轨**，风格 id 取 `claymation-3d`。

**边界声明**：

- 与哥特定格木偶（`gothic-puppet`）：**边界在题材与光色，不在材质**。两者都是黏土偶 + 微缩布景实拍，
  手工痕迹的语法完全一样；分家的是——本锚是**通用暖调**（暖米亮部、暖褐本体、陶土红重音、柔和短投影），
  哥特是**暗黑月光蓝**（去饱和蓝灰、低平入射角、深长硬影、灯笼橙作唯一暖色）。
  **要暗黑童话就换 `gothic-puppet`，不要在本锚里把光调冷**——调冷就是在通用暖调里塞哥特，出来四不像。
- 与写实轨（`photoreal-pbr` / `documentary-live-action` / `urban-folk-filmstill`）：写实轨要真实皮肤解剖与高精度材质；
  本轨要「假」——黏土、指痕、微缩模型的痕迹本身就是风格本体。材质词汇互斥，**禁止混轨**。
- 与手绘轨（`ink-wash-2d`）：本轨是三维实体拍摄（有真实光影与景深），不是平面画。
  手绘轨「平面化、无体积、去 2.5D」的纪律在本轨**全部不适用**，反着来——这里要体积、要纵深、要布景层次。
- 与三渲二 / 风格化 3D（`npr-celshaded-3d` / `stylized-pixar-3d`）：干净 CG 与均匀描边会抹掉手作不完美痕迹。

> **羊毛毡的处理（v4.9.1 定）**：**并入本锚，不单开 id**。
> 羊毛毡与黏土的差别是**表面**（绒毛与缝线 vs 指痕与压光），不是本体——两者的本体都是
> 「手作实体 + 微缩布景实拍 + 逐格顿挫」，换表面不改变任何一条材质纪律、运镜纪律或崩点。
> 用法：**一具偶只许一种材质**，不要在同一个 `<Subject N>` 里既写指痕又写绒毛（见第五节）。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A claymation stop-motion film, handcrafted and shot as real miniature set photography. Characters are hand-modelled clay puppets with oversized heads, thin limbs and surfaces that keep fingerprint dents, tool marks and seam lines, all matte and non-glossy. The set is a real built miniature with visible board seams, dried moss, flocking and hand-weathered surfaces. One warm key light with soft fill casts soft short shadows, not CG lighting. Movement carries stop-motion step timing with no motion blur. It is handmade practical stop-motion, not a 3D render.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
warm clay palette of cream highlights, warm brown clay body and a single terracotta accent, shadows never black
```

**五条措辞纪律**：

| 写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `smooth` / `fluid motion` / `seamless` | `stop-motion step timing with no motion blur` | 丝滑是 CGI 观感的头号来源，写了模型必补运动模糊 |
| `glossy` / `shiny` / `subsurface scattering` | `matte and non-glossy` | 光滑高光是本轨变 CGI 的第一崩点，每个材质词后面都要跟 |
| `realistic human anatomy` / `realistic proportions` | `oversized heads, thin limbs` | 写实化的头号入口 |
| `moonlit blue` / `desaturated blue-grey` | `one warm key light with soft fill` | 冷蓝是 `gothic-puppet` 的光色，写了就串到哥特 |
| `Avoid Pixar, Disney, photorealism...` | 不进正文，只进有 negative 字段的面 | H3 无 negative 字段，否定句只会被读成肯定 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头，配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移——本锚尤其明显，暖褐本体与「不死黑」的投影全靠配色句钉住。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，
改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 86 词（按校验器空白分词口径实测），在全库锚中排第 5（按词数降序），偏长——**加词前必须先想清楚删哪一句**。真要压减，先砍布景那一句（第三句），
**但 `matte and non-glossy` 与 `no motion blur` 两处不许删**——那是本轨仅有的两道防 CGI 声明。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一部黏土定格动画电影，手作微缩布景实拍。角色是手工捏出的黏土偶：头大、四肢细，表面留着指痕、工具刮痕与接缝，一律哑光不反光。布景是真实搭出来的微缩模型，板材接缝、干苔藓、植绒与手工做旧的痕迹都看得见。单一暖主光加柔和补光，投影柔和而短，不是 CG 打光。动作带定格的顿挫，不用运动模糊。整体是手作实拍的定格片，不是 3D 渲染。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
暖调黏土配色：暖米亮部、暖褐本体与暗部、陶土红唯一重音色，投影偏暖紫灰不死黑。
```

**中文面四条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「丝滑流畅的动作」 | 「二拍一顿挫，动作起收各留半拍静止，不用运动模糊」 | 中文面的模型同样会补流畅动作，一补就是 CGI |
| 「高清细腻的黏土」 | 「表面留着指痕、工具刮痕与接缝，哑光不反光」 | 「细腻」在中文面直接路由到写实 / CGI 皮肤 |
| 「真实人体比例」 | 「头身比 1:3–1:4，大头细肢，木偶比例」 | 写实化的头号入口 |
| 「皮克斯风、迪士尼风、动漫风」 | 不进正文，只进有 `negative_prompt` 字段的面 | 否定句不生效，正面钉「哑光黏土 + 微缩实拍」比一串禁止强 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次媒介特征（黏土定格、微缩布景、哑光不反光、不用运动模糊）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台自带美化倾向会自动磨平手工痕迹**，
所以 2.2 里「表面留着指痕、工具刮痕与接缝」这句在国内面**不许省略**——省了就变 CGI。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定中景、缓慢推近、逐格跳切、正反打、低角度仰拍 |
| 少量 | 轻微横移、摇臂微升、局部特写（手 / 道具）、过肩带前景遮挡 |
| 避免 | **丝滑跟拍、360 环绕、甩镜、快速变焦、连续长镜跟拍** |

**每段只锁一个主运镜**。低角度仰拍是微缩布景的本命机位（能把小布景拍出体量），主力用；
环绕与连续跟拍会诱发模型补运动模糊，是本轨的禁区。

## 五、材质与可见性预算

| 项 | 落值 |
|---|---|
| 主 | 黏土表面痕迹（指痕、工具刮痕、接缝、不对称）与微缩布景的手工材质 |
| 次 | 布光层次（单一暖主光 + 柔和补光）与投影 |
| 省 | 远景群像与天空 |
| 可见性 | 只写看得见的部分：侧脸时不写眼珠细节，改写眉骨与下半张脸的黏土起伏 |
| 禁 | 次表面散射、CGI 光滑表面、塑料反光、镜面高光、真实皮肤毛孔、运动模糊 |

**羊毛毡子档（并入本锚，不单开 id）**：把「指痕、工具刮痕、压光接缝」换成
「**表面细绒毛、缝线针脚、边缘略起毛**」，其余全部照抄——同样的哑光、同样的微缩布景、同样的定格顿挫。
纪律只有一条：**一具偶只许一种材质**。同一个 `<Subject N>` 里既写指痕又写绒毛，模型会给同一个人形
同时长出压光平面和绒毛边缘，那是本轨最难修的一种夹生。

## 六、崩点清单与反制（9 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| **变光滑 CGI（本轨头号崩点）** | 材质词没配哑光；正文出现高光、辉光、次表面散射 | 每个材质词后跟 `matte and non-glossy`；动作写 `step timing` |
| 运动被补成流畅动画，丢定格感 | 写了流畅连续长拍，或没写无运动模糊 | 明写 `no motion blur`；动作起收各留半拍静止 |
| **跑成哥特暗黑** | 写了冷蓝月光、去饱和、深长硬影 | 通用黏土是暖调：写单一暖主光加柔和短投影；要暗黑童话就换 `gothic-puppet`，别在本锚里调冷 |
| 布景变真实大小空间 | 场景词写了真实世界尺度参照 | 写微缩模型痕迹（板材接缝、干苔藓、手工做旧），场景「是搭的」可以被看见 |
| 脸部跨镜漂移 | 没走 `<Subject N>`；参考图不是同一套 | 每镜内联锁定；左区头部近景当身份锚；必带资产图走 I2V/Ref2VA |
| 手指出错与肢体畸形 | 黏土偶的手是团块，没写姿态 | 手部写清姿态与团块手指；负面词保留多余手指与肢体畸形 |
| 黏土与羊毛毡混在一具偶上 | 同一 Subject 既写指痕压光又写绒毛缝线 | 一具偶只许一种材质（见第五节） |
| 塑料反光 | 写了 glossy / shiny | 材质词一律配哑光不反光 |
| 色彩溢出，暖调跑成塑料玩具 | 没写色彩预算 | 每镜声明唯一重音色（陶土红）与暖调色系 |

## 七、声音签名（中英双轨）

```
整体声音签名（中文）：环境层——室内低频，布料与木材的细响；动作层——黏土偶落在微缩地面上的闷响、关节轻响、道具磕碰，节拍干净不密集；呼吸层——克制；配乐——木琴或拨弦小品，中低速、暖调、留白多，抒情段落才进，不是每镜都进。
```

```text
overall_soundscape: a warm interior low bed with faint cloth and timber detail; clean foley of clay feet meeting model ground, joint creaks and small prop knocks, unhurried and never crowded; breathing kept restrained.
non_diegetic_music: xylophone or plucked-string piece, mid-slow tempo, warm tonality, sparse arrangement, entering only on lyrical beats.
```

配乐中文写法（需要时）：`一段木琴或拨弦小品，中低速、暖调、配器稀疏，只在抒情段落进。`

禁史诗感管弦轰炸——它会把微缩布景撑成大片实景。

## 八、参考图集与角色锁定

本风格无专属参考图集，角色锁定走 `<Subject N>` 通用写法。角色条目必须写头身比（1:3–1:4 内取一个值并全片写死），
并写死**脸型团块、眼型与眼位、服装形制与配色**——黏土偶的辨识度集中在这三处。
投喂纪律照旧：**任何镜头都带一张左区头部近景当身份锚**；双视图只当定义，绝不当首帧。

## 九、去立体化与串轨防护

本轨的污染方向与水墨锚**完全相反**，这是全套风格里最容易抄错的一节。

- 水墨（手绘平面轨）要「**去**立体」：删 `animation`、`storybook`、`glow`、否定句，防出片 2.5D。
- 本轨要「**保**立体」：微缩布景实拍本身就有真实光影与景深，**体积与纵深是风格本体，不是缺陷**。
  要防的是另一端——**CGI 化与写实化**。

把水墨那张删词表套过来，等于把本风格的实体感亲手删掉。

### 9.1 污染词与替换对（定格轨·反向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 丝滑、流畅、连续动作、一气呵成 | 二拍一顿挫，动作起收各留半拍静止 | 丝滑是 CGI 观感的头号来源 |
| 运动模糊 | 删除，不写 | 定格动画没有运动模糊，写了即 CGI |
| 高光、镜面反射、次表面散射、辉光 | 每个材质词后跟「哑光不反光」 | 光滑高光是本轨变 CGI 的第一崩点 |
| 真实人体解剖、肌肉、真实五官比例 | 木偶比例（头身比 1:3–1:4）、四肢细长 | 写实化的头号入口 |
| 皮克斯风、迪士尼风、动漫风 | 不进正文；媒介声明放首句（claymation stop-motion film） | 否定不生效，正面钉媒介比一串禁止强 |
| 辽阔、实景、真实世界尺度 | 微缩模型痕迹（板材接缝、干苔藓、手工做旧） | 布景一变大就丢掉「搭出来的」这件事 |
| 冷蓝月光、去饱和蓝灰、深长硬影 | 单一暖主光加柔和补光，投影柔和而短 | 那是 `gothic-puppet` 的光色，写了就串轨 |
| 细腻皮肤动态、丰富微表情 | 眉、嘴角、眼睑的大位移 | 黏土面孔做不出细腻皮肤动态，表情一灵活就变真人 |

**正面句优先原则**：本轨的钉子全是正面陈述。凡是要「禁止 X」的地方，
先问「X 的反面怎么用正面句写」——写不出来，说明这条约束本来就不该进正文。
