# 赛道分流（第零道锁）

> **本文件是 liqi「〇 赛道分流」的唯一权威定义。** SKILL.md 的「前置锁（第零道锁 + 三锁）」只写路由入口；
> 四路赛道的定义、判定信号、规则集映射、下游影响、扩展方法一律以本文件为准。
>
> **与「投放面」是两个维度，别混**：投放面管**段头骨架族**（怎么排版给模型读），
> 赛道管**内容类型**（这一类内容该怎么写、语速怎么算、VO 能不能是全片）。
> 两者正交可组合，冲突时以本文件的下游影响表为准。

---

## 一、 为什么要有这一层

### 1.1 缺口

liqi 原来的「投放面」只有**五族骨架**（国内面 / 国际面 / Seedance 2.5 面 / 2.0 面 / H3 面），
它解决的是**格式**问题——同一段内容该用 `【时间轴】` 还是 `Shot N` 还是英文六段式。
但 liqi 的规则集**默认「这是中文剧情短剧」**：语速按对白口径算、VO 是点缀、
人物要跨镜连续表演、台词要锁口型。

一旦用户要做**解说叙事类**或**海外剧**，这套默认值会**系统性出错**：

- 解说类的「台词」不是对白，是**旁白**。按对白口径排语速 → 全片语速排慢一半，
  信息密度这个卖点直接丢掉；
- 解说类**全片都是旁白**，而 liqi 的 VO 容量口径是「点缀级」——套上去会把稿子判死；
- 解说类的人物是**插画形象、可单镜出现**，不需要跨镜连续表演，硬套 4 View + FACS 是浪费预算；
- 海外剧的正文不是中文，语速按**中文字/秒**算就是错的（英文要按词算），
  且字幕从「一般不需要」变成「必须逐字锁定」。

### 1.2 解法

把「做哪一类」升格为**先于三锁的第零道锁**，让各赛道挂自己的适配口径，互不污染。
**liqi 的四路不是四套流程**——流程只有一条（Step -1 → 0 → 1 → 2 → 2.5 → 3 → 4 → 5 → 6），
赛道只决定**这条流程里哪些参数该换成另一套值**。

## 二、 〇 赛道分流锁（第零道锁 · 先于锁①②③）

```text
请先确认本次做哪一类（〇 赛道分流 · 第零道锁）：

1. 国内剧     —— 中文剧情短剧 / 漫剧 / 番剧短片 / 动画短片（liqi 最常见的赛道，但仍是必问项）
2. 海外剧     —— 非中文正文 / 海外投放 / 多语或方言项目
3. 解说叙事类 —— 解说 / 拉片 / 盘点 / 历史人物 / 历史事件 / 科普（旁白即主体）
4. 其他       —— 广告片 / 宣传片 / PREVIS / MV / 纪录短片等非剧集形态

回复示例：1    或    3（历史人物志）
```

**分流时机**：在**最开始、任何创作之前**，与三锁同批完成（可分批弹出，但未锁完不进 Step 1）。
赛道结论写入交付物顶部（与 `【三锁】` 同级），全流程不再更改；**确需改赛道 = 重开任务**。

**未指定 = 停下询问**，禁止默认按① 走——这与三锁同规格，是硬门不是建议。

## 三、 四路定义与判定信号

### ① 国内剧（liqi 最常见的赛道）

| 项 | 内容 |
|---|---|
| **判定信号** | 短剧 / 漫剧 / 番剧短片 / 动画短片 / 毕设 / 公益短片；中文正文 |
| **正文语言** | 中文 |
| **语言合同** | 不建立 |
| **语速口径** | 对白走 `叙事层_剧本门控与台词.md` 第四节语速三档 + **实测校准表**（排期区间 2.6~3.6 字/秒） |
| **VO 容量** | **点缀级**：VO + OS 镜数 ≤30%，VO 口播 60~80 字/分钟封顶（见 `方言与旁白规程.md` §四） |
| **资产口径** | 角色跨镜一致是硬约束（4 View + 文字锁 16 项 + FACS） |
| **平台合规** | `audit_risk.py` 过审风险预检 + `质控层_门禁与过审.md` §6.3 高敏感五手法 |

### ② 海外剧

| 项 | 内容 |
|---|---|
| **判定信号** | 英文 / 非中文正文；海外平台投放；多语混说、移民社群、地域口音 |
| **正文语言** | **目标语言**（可能完全非中文） |
| **语言合同** | **必须建立**（第一句对白之前，不许写完后倒填） |
| **语速口径** | **按目标语言重算**——英文约 **2.2~3.0 词/秒**（≈130~180 wpm），**禁用中文字/秒口径** |
| **字幕** | **必须有**：外语正文 + 中文字幕（或目标观众语言字幕）**逐字锁定**，制作阶段不得自行改写 |
| **资产口径** | 同①，另加：**族裔 / 地域形象不得刻板化** |
| **模型适配** | 投放面优先 **国际面**（`Shot N` 骨架）或 **H3 面**；见 SKILL.md 锁③ 决定关系表 |

**语言合同六件套**（写在交付物顶部，不塞进正文）：

```text
【语言合同】目标语言=（如 北美英语）｜地区=｜语速=（词/秒，禁用字/秒）｜
            字幕=（逐字稿 + 观众语言）｜校准状态=（machine_drafted / human_reviewed）｜
            换语纪律=（哪个角色在什么时点换语，谁被排除）
```

🔴 **不得自称已完成本土化**：模型判断、网页检索、双模型一致，**都不能**把校准状态
升级到 `human_reviewed`——只有真人核定过才算。这条是海外赛道的假绿防线。

**跨阶段守恒铁律**：换语、字幕或地方说法变化时，**同步**角色与单语听者「知道什么、
是否被排除、何时获得共同语言信息」以及关系 / 行动后果。制作阶段**不得**因为「排了字幕」
或「模型读起来顺」就自行升级本土化状态。

### ③ 解说叙事类（旁白即主体）

| 项 | 内容 |
|---|---|
| **判定信号** | 解说、拉片、盘点、逐帧拆解、口播影评、历史人物志、历史事件、科普、冷知识、知识区、「一口气看懂」、纪录片式旁白 |
| **子类型** | 历史人物志 / 历史事件战役 / 科普知识解说（**三选一，进入前必须确认**） |
| **正文语言** | 中文（历史 / 科普题材可中英混排） |
| **语言合同** | 不建立；但**历史 / 科普题材须信源分级（T1 一手史料 / T2 讨论）** |
| **语速口径** | **解说专用档**，见第五节 —— **不套对白语速档** |
| **VO 容量** | **全片 VO**：VO + OS ≤30% 的容量口径**对本赛道豁免**，改用解说语速 + 声画信息差纪律 |
| **分镜单位** | **旁白句 → 画面**：一句旁白配 1~2 个画面 |
| **资产口径** | **场景风格一致 > 人物一致**；人物做插画形象、**不做跨镜连续表演**；同一人物 ≤2 个形象版本（正面像 + 全身像） |
| **平台合规** | 解说类字幕 / 封面规范 + **史料引用来源标注** |

#### 解说类的本质差异（照对白口径建模会系统性写错）

| 维度 | ① 国内剧 | ③ 解说叙事类 |
|---|---|---|
| **信息载体** | 对白 + 表演 + 情节 | **旁白 / 解说词 + 画面注释 + 字幕** |
| **声音结构** | 台词为主（≥70%），VO/OS ≤30% | **旁白即主体（80~100%）**，对白可为零 |
| **人物** | 角色连续表演、跨镜一致、FACS | **可无固定角色**；人物以插画 / 影像素材出现，无需连续表演 |
| **分镜逻辑** | 剧情节拍 → 镜长 | **旁白句 → 画面** |
| **台词字段** | 对白锁口型 | 解说词走**画外旁白**，**不锁口型**；出现对白时（采访 / 史料引述）才用对白位 |
| **质量门** | 首镜锚定、摆位必入画、人物账 | **声画信息差检查、旁白句-画面映射、史实 / 科普正确性、金句结尾** |

**三大子类型的情绪动线**（与 liqi 叙事层第五节「只吸收四条法则」不冲突——那是**张力曲线**，
这是**素材排布动线**，两者叠加使用）：

| 子类型 | 动线模型 | 钩子写法（≤15 字，落 0~3s） |
|---|---|---|
| **历史人物志** | 反差人设钩子（0~10%）→ 出身与困顿（10~30%）→ 关键转折 / 高光（30~65%）→ 跌落 / 结局（65~85%）→ 历史评价与金句（85~100%） | 结果前置 / 人物反差式 |
| **历史事件战役** | 悬念结果前置（0~10%）→ 背景与起因（10~35%）→ 过程层层拆解（35~70%）→ 关键决策点（70~85%）→ 影响与遗产（85~100%） | 悬念式 / 结果前置 |
| **科普知识解说** | 反常识 / 痛点钩子（0~10%）→ 生活场景切入（10~25%）→ 知识拆解 3~5 步（25~70%）→ Wow Moment（70~85%）→ 价值升华（85~100%） | 反常识式 / 冲突式 |

### ④ 其他（按需扩展）

| 项 | 内容 |
|---|---|
| **判定信号** | AI 广告片 / 宣传片 / 分镜预演 PREVIS / MV / 武打动作设计 / 纪录短片 |
| **规则集** | 复用现有全流程，**不套用剧集专属的集数 / 卡点 / 追看约定** |
| **VO 容量** | 按① 的点缀级口径（宣传片解说可放宽，但须显式声明理由） |

## 四、 赛道 × 投放面（两条正交轴）

投放面回答「**怎么排版给模型读**」，赛道回答「**这一类内容该怎么写**」。**互不覆盖**。

| 赛道 ↓ ／ 投放面 → | 国内面 | 国际面 | 2.5 面 | 2.0 面 | H3 面 |
|---|---|---|---|---|---|
| ① 国内剧 | ✅ 主 | ⛔ 不自然 | ✅ 主 | ⛔ 见下 | ⛔ 见下 |
| ② 海外剧 | ⛔ | ✅ 主 | ⚠️ 可行（中文提示词 + 目标语言台词） | ⚠️ 可行（禁用秒级时间轴） | ✅ 主（英文正文六段式） |
| ③ 解说叙事类 | ✅ 主 | ✅ 可行 | ✅ 主 | ✅ 可行 | ✅ 可行 |
| ④ 其他 | ✅ | ✅ | ✅ | ✅ | ✅ |

⚠️ **两条必须同时看的两处冲突**：

1. **赛道②（海外剧）× 2.0 面**：2.0 不响应时间戳，秒级时间轴禁用——
   但外语台词的语速时长预算**只能靠秒算**。**解法**：秒数只作内部预算写进行为描述
   （「停一拍的工夫」），不写进段头。见 SKILL.md Step 1 的 2.0 特判句。
2. **赛道③（解说）× 任意面**：旁白不锁口型，故 2.5 面的台词语法（`{}`）**不适用于解说词**——
   解说词走**声音设计段**，不写进对白位。见 `方言与旁白规程.md` §四。

**赛道③ 在 H3 面**：正文仍须英文六段式，旁白写进 English 的 `audio/dialogue` 描述里；
但**中文对照版必须出**（用户要能审）——见 `MiniMaxH3适配.md` 「中文对照版体例」。

## 五、 各赛道下游影响（唯一权威）

> 这张表是本文件落地的地方。**改任何一行的值，必须同步改对应权威文件**，否则分流不可见。

| 维度 | ① 国内剧 | ② 海外剧 | ③ 解说叙事类 |
|---|---|---|---|
| **台词语言** | 中文 | **目标语言逐字稿** | 中文（解说词 = 旁白，非对白） |
| **语速基准** | 对白 `3.5~5 字/秒`（理论）／**排期用实测 2.6~3.6** | **按目标语言重算**：英文 ≈ `2.2~3.0 词/秒`，**禁用字/秒** | 见下方「解说语速档」 |
| **VO / OS 容量** | `≤30%` 镜数；VO 口播 `60~80 字/分钟` | 同左（另核对单语听者是否被排除） | **豁免容量口径**，改用解说语速 + 声画信息差 |
| **旁白 / 心声写法** | 写进对白行并标「画外音 / 心声」 | 同左（内容为目标语言） | 走**声音设计段**，不写进对白位；不锁口型 |
| **字幕** | 一般不需要 | **需要，逐字锁定** | **需要**：解说类逐词烧录是标配（与旁白不重复） |
| **分镜单位** | 剧情节拍 → 镜长 | 同左 | **旁白句 → 画面**（一句 → 1~2 画面） |
| **密度红线** | `≤4.0`（慢板 · 旁白）／`≤5.0`（对白）；物理红线 `>6.5` | 按目标语言重算 | **豁免 4.0/5.0 卡口**，**保留 6.5 物理红线** |
| **资产口径** | 4 View + 文字锁 16 项 + FACS | 同左 + 族裔 / 地域形象不得刻板化 | **场景风格一致 > 人物一致**；插画形象，不做连续表演，不写 FACS |
| **素材形态** | M0/M1/M2 照常（`资产层_锁定与一致性.md` 第十五节） | 同左 | 同左 |
| **信源纪律** | — | 证据与权限边界（不得自称已本土化） | **历史 / 科普强制 T1/T2 分级** |
| **机检** | 全套 L1~L4 | 全套 + 语言校准状态一致性 | 全套；**VO 容量码按赛道③ 改判** |

### 解说语速档（liqi 版 · 不盲抄上游）

上游给的解说语速是 **4.5~6.5 字/秒**（金句 3~4）。**liqi 不直接采用这个数**，理由两条：

1. **liqi 有本地实测**：`叙事层_剧本门控与台词.md` 第四节记录——对白按理论档 3.5~5 排完，
   实测 32 句超标、9 句 >6 字/秒，实际落点集中在 **2.6~3.6**。即 **AI 配音落点比理论档慢约 20~30%**。
   旁白同理，不折减就是重复踩同一个坑。
2. **要与既有档位衔接**：liqi 实测校准表里「说书人 / 旁白」是 **3.6~3.8 字/秒**，
   解说旁白突然跳到 4.5~6.5 会出现同片两套旁白口径。

| 口径 | 值 | 用途 |
|---|---|---|
| **排期档（推荐）** | **3.8~5.0 字/秒** | 排镜长预算就用这一档 |
| **金句 / 爆点句** | **3~3.6 字/秒** | 降到这一档留发酵空间，配画面留白 |
| **上限硬闸** | **6.5 字/秒** | = liqi 物理红线（与上游上限一致，不冲突） |
| **镜长公式** | `旁白字数 ÷ 语速 + 画面缓冲 0.3~0.8s` | 每句独立算，全片求和 = 总时长 |

**总时长由内容倒推、不凑满**（承接 SKILL.md 法则 17）。
**如果你的配音实测能做到 4.5~6.5，就用上游档**——那一档是理论上限，不是错的，
只是 liqi 没有本地样本支撑，所以排期按折减后的数走。

## 六、 跨赛道铁律与禁止项

1. **赛道未确认 = 不开始**：与三锁同规格，禁止默认按① 走；用户说了但没说清（如「做个英语的」）
   时，追问一句确认赛道与目标语言。
2. **赛道决定规则，不决定质量下限**：各赛道质量底线相同（能看懂、有因果、台词属于此人此境）；
   差别在**节奏预设、语速口径、VO 容量、语言纪律、资产口径**。
3. **禁止跨赛道搬运约定**：
   - 不得把国内剧的**对白语速档**套到解说旁白上（会把信息密度丢掉）；
   - 不得把解说的**「全片 VO」口径**回写污染剧情赛道——① 的 VO/OS ≤30% 卡口**不动**；
   - 不得把海外剧的「不预设中文短剧节奏」当作可以省掉①的分场要求；
   - 不得把某个赛道的**平台规则**外推到另一赛道。
4. **不越界**：剧情剧任务不套解说口径；解说任务不套 FACS 与跨镜连续表演要求。
5. **分流的痕迹要留**：交付物顶部必须写明赛道编号（③ 还须写子类型），
   后续阶段只在此基础上**新增证据**，不另建互相冲突的口径。

## 七、 新赛道扩展四步法

用户后续要加「互动剧」「知识付费」「人物纪录」「MV」等新品类时，照这四步走，**不用动主流程**。

1. **定赛道**：在 §三 加一节「定义与判定信号」（表：判定信号 / 正文语言 / 合同要求 / 语速口径 /
   VO 容量 / 资产口径 / 平台合规）。
2. **挂规则集**：在 §五 映射表加一列；规则集写成**总控 references 文件**（轻量、差异少）
   或**独立文件**（差异大、需独立分发）。
3. **开分流口**：在 SKILL.md「前置锁（第零道锁 + 三锁）」加一项；同步 §二 的选项列表与 §四 正交表。
4. **接校验**（可选）：机检**默认不新增码**——先看能不能靠现有门改判；确需新码时，
   写进 `质控层_门禁与过审.md` 的码表并同步 SKILL.md 的计数。

**扩展纪律**：新赛道的规则**不得回写污染①**（做成独立文件，不要就地改国内剧规则）；
新赛道的体量、卡点、追看约定**不得默认继承**①。

**liqi 的克制**：与上游相比，liqi **不新开赛道专属机检码**。
解说类的语速、金句、声画信息差、子类型动线**全是语义项**——做成门就是假绿门
（同一取舍见 v5.8.0「完播自评只作自评不作门禁」）。机检只兜底**可机械判定**的部分。
