## 二、行业共识工作流（六步）

**1. Character Sheet 先行，锁定为唯一事实源**  
出片前先出多角度设定卡（行业通用：4 角度 turnaround + 脸部特写 + 中景特写，4K），多代几版选优后**锁定**。此后每个镜头的 prompt 都带它——invideo 复盘的 164 个镜头**无一例外**全部携带角色参考。行业一句话："AI 必须始终看到角色确切长什么样，否则它会自己脑补。"

**2. Hero Image 锁定，中途不换**  
从卡中选定一张最优图做**全项目主参考**。已结算制作的原话级纪律：**中途更换参考集是重新引入漂移最快的路**。参考集存进固定目录、命名标明每张的角色，全程不换。

**3. 分层投喂（省钱且防漂）**

- **特写 / 近景**（脸是重点）→ I2V + 参考图，prompt 只写动作和运镜，**不重复描述长相**（参考图已锁）
- **远景 / 切出镜头**（脸小）→ **文生视频 + 提示词锚**，不投参考图。观众对小脸不敏感，服装+体型描述足够维持错觉，还省参考额度
- 群戏从已确立的角色图 I2V 出，不从文本直出（多主体是重灾区）

**4. Per-Beat Sheet（外观变化就出新卡）**  
角色每经历一次外观变化（换装、加饰物、受伤）→ **出一张新卡**，不拉伸旧卡硬扛。invideo 复盘：角色每到一城加一件饰物，剧组就为每一段出一张新 sheet。这与本 skill 的版本拆分表 / 图生图换装编辑（Step 2.5 · 版本拆分）完全同构。

**5. Fix at the sheet, not the shot（在卡上修，不在镜头上修）**  
某镜头角色细节错了，**不要重抽那个镜头**——回设定卡找到错误面板（invideo 案例里 AI 自己定位到卡上一格多余的耳机），修正卡片，之后所有镜头继承修复。只重抽受影响的镜头。**这是行业与本 skill 最大的互补点**：我们的故障表全部是"镜头层修法"，缺"回卡修正"的原则。

**6. 后期兜底层（我们完全缺失的一环）**

- **漂移镜头换脸修正**：InsightFace / FaceFusion 把漂了的脸贴回参考脸，只处理脸清晰可见的镜头
- **全片统一调色**：所有片段进 DaVinci/CapCut 统一曝光、白平衡，再套一个 LUT。**肤色统一比任何单项技术都对"感知一致性"贡献大**——不同生成调用的色温差会让同一个角色看起来像换了人
- 行业成本预期：平均 3 次生成出 1 条可用镜头，这是正常损耗不是失败

## 三、转身 60° 禁区（跨模型共性弱点）

Kling 3.0 实测 20 次仅 3 次失败，**全部是超过约 60° 的极端转头**。这不是 Kling 一家的问题——侧脸超出模型从参考集学到角度分布时，五官只能靠先验编。

分镜设计约束：**侧脸镜头角度尽量 ≤60°；必须大转头的戏，用首尾帧法（`资产层_锁定与一致性.md` 第二节 · 转身镜头技巧）拆解**——首帧背身尾帧正脸，让动作本身扛身份。这与本 skill 已有的转身首尾帧法互为印证：行业实测确认它是当前最稳的转身方案。

## 四、Seedance 人脸过滤（对选用 Seedance 的项目必须知道）

**过滤在模型层，不在平台层**——换 API 宿主没用，规则跟着模型走。

|            | 内容                                                 |
| ---------- | -------------------------------------------------- |
| **触发**     | 参考图中"清晰居中的可识别真人面孔"为主体；prompt 点名真实人物                |
| **不触发**    | 大远景、后脑勺/侧脸为主体的图、**风格化/插画/卡通面部**、**从零描述的原创角色**、动物风景 |
| **无效做法**   | 模糊脸、裁到只剩下巴、不点名地影射名人                                |
| **官方恢复路径** | **用图像模型预生成角色参考图再喂 I2V——分类器把合成面孔读作非真人**             |

三个对本项目的直接结论：

1. **本 skill 的资产板流程本身就是官方推荐路径**——先出 AI 角色卡、再喂 I2V，恰好落在"原创角色 + 风格化画风"双保险区。
2. Dreamina（字节自有平台）过滤最严，第三方宿主配置普遍更宽；被拒可以换宿主试，**同一 prompt 不同平台结果不同**。
3. 网格覆盖类对抗过滤的 hack 面向的是真人面孔场景，**原创角色不需要也不应该用**。

### Seedance 2.5 专项（2026-06 预告 → 07-31 上线即梦/豆包 → API 火山方舟）

来源：字节官方博客 + 多方报道交叉印证。

**四项升级，逐条对照我们的工作流：**

| 升级       | 内容                                                    | 对资产板工作流的影响                                                                                |
| -------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **时长**   | 单次 30s（2.0 为 15s）+ **多轮延长**至数分钟，延长时保持主体/场景/风格/音画一致    | **镜头拆分策略要变**：连贯动作优先合并进一段 30s，而非每个镜头单独生成；一镜到底式长叙事可行。但单镜头 ≤10s 的铁律依然成立（注意力稀释问题不变）          |
| **参考扩容** | **50 参考位**：30 图 + 10 视频 + 10 音频 + 3D 白模（2.0 为 12 位）   | "每镜头 2–3 张"的建议**不变**（稀释的是模型注意力不是额度）；真正的变化是**多角色同框时全员参考可同时上场**（官方音乐会案例 18 图分饰主唱/乐队/合唱/观众） |
| **编辑**   | 时间戳级定向编辑（改某段的角色/动作/声音/剧情）、局部编辑（换背景/道具不整段重渲）、绿幕编辑、视角编辑 | "重抽整段"的成本大降，但 **Fix at the sheet 原则不变**——源头错（卡错了）依然回卡修，编辑只解决"卡对但镜头生成歪了"                  |
| **画质**   | 系统性去"油腻感"（材质/肤质/眼神/光影/饱和度），减少字幕与 BGM 失控               | 对 3D 动漫风直接利好——2.0 的塑料感/油腻感是动漫风最高频投诉                                                      |

**白模参考是给专业管线留的接口**：无纹理 3D 模型定空间结构、机位、运动轨迹，模型据此渲染并推算光照物理（光源方向/色温/阴影）。与资产板的结合：**白模管运镜与调度，角色卡管身份**——复杂调度镜头（环绕、跟拍、多人走位）可以先搭白模再生成，比纯文字描述运镜稳。

**新增的视频参考（10 段）**：可投动作/运动参考片段指定步态与微表情；绿幕实拍可做场景合成参考。

**官方自认仍弱**（写进提示词预期管理）：复杂运动的物理合理性、极多主体交互的稳定性。多人同框时按 `空间层_调度与轴线.md` 第四节的**同框动作分配三档**（单主体聚焦动作 / 其余持续微动 / 配角禁默认大动作）处理。

## 六、成本与预期管理（行业实测）

- 平均 **3 次生成出 1 条可用镜头**（cherry-pick 是流程的一部分，不是失败）
- invideo 三个已结算案例：70s 双角色短片 2 天 $750；3 分钟 2 人动画剧集约 $950（164 镜头）；锁一个角色平均 5 次生成约 $9.78
- 选型结论（行业共识）：**一致性差是后期修不回来的，画质糊反而可以**——叙事项目宁可要一致性高的模型
