# 美式漫画·硬线印刷 风格锚（卡通轨 × 美漫叙事专项）

本文件是 Step 2「全片统一风格锚（九段）」在**美式漫画（superhero comic book）硬线印刷质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：美式超级英雄漫画的叙事档——粗细变化的钢笔墨线、交叉排线阴影（cross-hatching）、
戏剧化的肌肉解剖与仰角透视、四色印刷的 CMYK 质感、分格感与爆发性构图。
用户给的是美漫 / 超英 / 硬朗动作漫画参照时，锁③ 风格轨道选**卡通轨**，风格 id 取 `us-comic-ink-2d`。

**边界声明**：

- 与美漫波普（`comic-popart-2d`）：波普是 **Lichtenstein 式大众图像**——印刷网点（Ben-Day dots）、
  平涂色块、冷幽默构图；本锚是**叙事动作漫画**——排线阴影、连续分格叙事、戏剧透视。同族不同档。
- 与热血少年漫（`shonen-hotblood-2d`）：同为动作向，**线条语言不同**——热血是赛璐璐动画色块＋速度线；
  美漫是钢笔排线＋印刷网点底。着色逻辑互斥。
- 与暗黑哥特 2D（`gothic-2d`）：哥特是墨线平涂剪影的暗黑装饰；美漫是排线塑形的立体印刷感。
- 与黑色电影插画（`noir-ink-2d`）：noir 是黑白高对比剪影光影；美漫是四色彩印。色彩体系互斥。

> **竖屏适配（C26）**：美漫封面构图天然竖向（人物大半身仰角 + 标题位）——竖屏写法：
> 仰角透视拉纵向、排线沿肢体方向走。**竖屏友好，无需改写行**。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
An American superhero comic-book panel: variable-width pen-and-ink linework, cross-hatching shadows, dramatic heroic anatomy with low-angle perspective, four-color CMYK print feel with slight misregistration on comic paper. Bold outer contours, fine interior lines, flat print colours with dot-textured skin tones. Graphic and punchy, never soft-gradient or photoreal.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
four-colour print palette with slight offset, dot-textured tones, one accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `Ben-Day dots / pop art` | `cross-hatching shadows` | 网点平涂是波普档的本体 |
| `anime cel shading` | `pen-and-ink linework` | 反串日系档 |
| `soft lighting / gradient` | `flat print colours` | 渐变破坏印刷感 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 46 词，中等——动作段的招式与分格描述耗词快，预算紧先删末句（Graphic and punchy 一句）。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅美式超级英雄漫画的画面：粗细变化的钢笔墨线勾勒，阴影用交叉排线塑形，人物解剖戏剧化夸张带低角度仰视透视，四色 CMYK 印刷质感带轻微套印偏移与纸点。外轮廓墨线粗、内部线条细，平涂印刷色带网点叠色。硬朗有力，不是柔光渐变，不是照片。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：四色印刷色域微偏，肤色网点叠色，每镜只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「波普」「网点平涂」 | 删，写「排线阴影」「钢笔墨线」 | 反串波普档 |
| 「日系」「赛璐璐」 | 删，写「美漫硬线」 | 反串热血档 |
| 「柔光」「唯美」 | 删，写「硬朗」「印刷感」 | 渐变是反面 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（钢笔墨线、交叉排线、四色印刷、戏剧透视）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台把排线推成潦草乱线**，所以「外轮廓粗内部细」的墨线分档在国内面**不许省略**。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 急推急拉（分格爆点）、Dutch angle（戏剧失衡）、固定封面帧 |
| 少量 | 低角度仰拍（英雄气场）、甩镜转场（分格切换，每段 ≤1 处） |
| 避免 | 柔和横移、写实跟拍、缓慢环绕、手持晃动 |

**每段只锁一个主运镜**；分格感是帧内构图（漫画框线感），不是运镜。

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「波普化」与「日系化」两侧的词**，保留排线塑形与印刷质感。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| Ben-Day dots / pop art flat | cross-hatching shadows | 反串波普档 |
| cel shading / anime colours | pen-and-ink linework | 反串日系档 |
| soft gradient glow | flat print colours | 渐变是印刷反面 |
| photoreal skin | dot-textured skin tones | 照片反面 |
| 3D render | graphic print feel | 立体渲染反面 |

### 9.2 互斥风格

`comic-popart-2d`（网点平涂 vs 排线塑形，同族不同档）、`shonen-hotblood-2d`（赛璐璐色块 vs 钢笔排线）、
`noir-ink-2d`（黑白高对比 vs 四色彩印）、`gothic-2d`（剪影装饰 vs 立体排线）。
