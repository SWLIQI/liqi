# 资产审美：设计原理

## 〇、 这份文件管什么

`资产层_锁定与一致性.md` 管的是**锁得住**：16 项文字锁、4 View 像素账、投喂铁律、版本互锁。
本文件管的是**好不好看**：剪影认不认得出、主角配角会不会撞型、这个配色进 AI 会不会糊、造型有没有记忆点。

两者分工，不互相覆盖：

| | 资产层_锁定与一致性 | 资产审美_设计原理（本文件） |
|---|---|---|
| 回答 | 怎么锁住不出漂移 | 锁住的东西值不值得锁 |
| 落点 | 出图后（裁切、投喂、诊断、回写） | 出图前（设计与定稿） |
| 判据 | 像素账、门禁、**七项**漂移检查（v5.10.0 起） | 剪影测试、3-3-3、色彩稳定性 |
| 触发 | Step 2.5 必做 | 建角色卡 / 生物卡 / 群像包时做 |

**用法**：Step 2.5 里先过本文件（设计定稿），再进资产层（锁死并出图）。顺序反了会返工——剪影没定就出图，锁得再稳也只是把一个平庸造型锁死。

**来源说明**：第一至四、七、十二节的方法论收编自 `references/external/` 的 Apache-2.0 / MIT 文件（原样未改，见 `THIRD-PARTY-NOTICES.md` 第一节）；第五、六、八、九、十、十一、十三节借鉴自一个**无许可证**的上游项目，按「不复制文字、只重写思想」处理（见该文件第二节），措辞与判据均为 liqi 侧独立得出。

## 一、 三读法则（设计顺序的铁律）

一个角色要在**三个观察距离**上都成立，且顺序不可颠倒。

| 读序 | 观察条件 | 必须回答的问题 |
|---|---|---|
| 第一读 | 缩略成 32×32 纯黑剪影 | 只看轮廓认得出是谁吗？姿态是这个角色独有的吗？会和同片的另一个角色混淆吗？ |
| 第二读 | 缩略成 64×64 并眯眼 | 还剩 2–3 个主导色吗？有明确的底色 / 结构色 / 重音色层级吗（见第七节）？颜色本身传达性格吗？ |
| 第三读 | 全分辨率看细节 | 加上腰带、纽扣、纹理之后，**有没有反过来伤害前两读**？ |

**铁律**：顺序不能倒。先堆细节再回头改剪影，是这一类工作里最贵的错误——细节越好，越舍不得删，最后只能把一堆精致噪声锁进资产库。

**判据（写在角色卡定稿前）**：

- 第一读不过 → 改轮廓，不是改颜色。改颜色的收益上限很低。
- 第二读不过 → 检查是不是用了三个以上同权重色。
- 第三读反而是唯一能删的一读——删细节只损失这一读。

**与资产层的衔接**：第一读对应资产层的右区三格（`front` / `side` / `back` 给的就是廓形），出图后可直接拿三格缩到拇指大小自检。

## 二、 形状语言（几何先于细节）

在加任何细节之前，先用几何图元把性格交代掉。

| 形状 | 传达 | 体型落地 | 典型 |
|---|---|---|---|
| 圆 / 弧 | 友好、可亲近、无威胁 | 圆头、软肩、弧线肢体 | 卡比、大白、龙猫 |
| 方 / 矩 | 稳定、强壮、可靠 | 方正躯干、平肩、扎实站姿 | 破坏王、多数坦克位 |
| 三角 / 尖 | 动态、危险、侵略性 | 尖角特征、棱角肢体、锐利剪影 | 玛琳菲森、多数反派 |

**组合是常态，不是例外**：

- 圆身 + 方肩 → 骇人但可爱（表里不一的「凶脸好心」）
- 三角头 + 瘦身 → 聪明但不构成物理威胁（智力型反派）
- 圆身 + 三角刺 → 有威胁但带喜剧感

**落地规则（写进角色卡的「体型」栏）**：

1. 先给这个角色定**一个主形状**，写进卡片；
2. 再定**一个破形状**（用来制造内在矛盾）；
3. 同一个阵营 / 家族的角色共享主形状，靠破形状区分个体——这是「一眼看出是一伙的、又一眼分得清是谁」的解法。

**与非写实风格的衔接**：本节的形状语言与 `风格锚_*` 系列不冲突——风格锚定的是**画法**（平涂 / 渐变 / 笔触），本节定的是**几何骨架**。皮影、剪纸、水墨这三种平面工艺风格里，形状语言的作用反而更大，因为细节被工艺天然削掉了，只剩轮廓和色块可读。

**与头身比的接口**：形状语言落在具体体型上时会受 `heads_range` 约束。极端头身比会改变落地方式——定格木偶 `1:3.5–1:4.5`、剪纸 `4–4.5` 的「方肩」是拉长变形后的方，不是写实篮球运动员的方；写实档 `7–7.5` 的「圆头」是可辨识的成熟骨相，Q 版「圆头」直接是一个球。**先读风格锚的 `heads_range`，再决定这个形状语言画到几分。**

## 三、 剪影设计（不对称法则与地标技术）

### 3.1 不对称法则

完全对称的剪影是无聊、泛用、记不住的。好剪影都有一处**破对称**：

- 只有一侧有道具（武器、挎包、单肩披挂）
- 发型破对称（偏分、呆毛、单侧发饰）
- 站姿偏重一侧
- 服装元素只出现在单侧（单侧肩甲、单侧下摆）

**注意区分两件事**：资产的 4 View 板**本身**必须是左右对称的正面像（否则裁切和投喂会乱），不对称体现在**角色设定**上，不是画板排版上。

### 3.2 地标技术

每个角色给 2–3 处「地标」——在任何尺度都看得见的突起：

- 尖耳 / 兽角 / 发冠
- 背后的武器、法器的外露部分
- 独特的发型外轮廓
- 明显的肩部或头部结构差异

**判据**：把角色剪影缩到拇指大小交给没见过的人看，认不出 → 剪影失败；认得出但说不出地标 → 地标不够突出。

**与资产层的衔接**：地标优先放进右区三格能拍到的位置。左区只取头部近景，肩以下的剪影信息全在右区——**地标如果长在腰以下，等于没做**，因为投喂时近景镜头带的是左区脸片。

### 3.3 剪影检查表

- [ ] 缩到 32px 还认得出？
- [ ] 有破对称元素（不是镜像的）？
- [ ] 有清晰负空间（不是一团）？
- [ ] 有 2–3 处地标（不是泛用的人形）？
- [ ] 和同片其他角色摆在一起时互不混淆？

## 四、 过设计审计（3-3-3 与递减法）

角色看起来「忙」而不是「细」，是新手最常犯的错误——把复杂度当成了质量。

### 4.1 3-3-3 规则

- 主导色最多 **3** 个
- 主要服装元素最多 **3** 个
- 配饰焦点最多 **3** 个

经典角色的配置都很克制：马里奥 = 红帽 + 蓝背带裤 + 胡子；林克 = 绿袍 + 尖帽 + 剑。仅此而已。

### 4.2 焦点层级

| 层级 | 职责 |
|---|---|
| 主焦点 | 第一个抓住眼睛的元素（通常是脸） |
| 次焦点 | 第二个（武器、手部、胸前物） |
| 其余 | 只做支撑，不参与竞争 |

### 4.3 递减法（比加法可靠）

1. 从当前设计删掉 30% 的细节；
2. 缩到 32px 测一次——**变好还是变差**；
3. 变好，再删 20%；
4. 删到会变差为止，停。

### 4.4 单个元素的三问

对每个设计元素问：

1. 删了它，剪影会受损吗？（会 → 留）
2. 删了它，这个角色还是这个角色吗？（是 → 留）
3. 删了它，有人会注意到吗？（不会 → 删）

「拿不准就删掉。」——这是原则，不是建议。

**与 liqi 的衔接**：本节的产出直接进角色卡的「服装 6 项」栏。16 项文字锁要求把服装写细，但**写细的前提是元素本身够少**——元素多还写细，等于给模型喂噪声。

## 五、 群像差异化（视觉领地象限）

### 5.1 先群像，后个体

正确顺序是**先出群像，再从中提取个体**。角色 A 的「善良」要靠角色 B 的「邪恶」衬托；只给主角做设计、配角随便混，结果是配角之间撞脸、配角与主角撞色，观众看完全片分不清谁是谁。

**这是设计阶段的病，出了图就救不回来**——因为四个维度（色彩 / 体型 / 服装 / 姿态）在出图后都锁死了，改任何一项都等于重做整个资产链。

### 5.2 视觉领地象限

用「色彩冷暖」×「视觉复杂度」画四象限，**任何两个主要角色不能占据同一象限**。

| 象限 | 特征 | 视觉传达 |
|---|---|---|
| I | 复杂 + 暖调 | 充满细节、热血、处于冲突中心 |
| II | 简单 + 暖调 | 沉稳、父性 / 母性、力量感、可信任 |
| III | 简单 + 冷调 | 疏离、神秘、局外人、干练 |
| IV | 复杂 + 冷调 | 机械压迫、非人化、精密而致命 |

### 5.3 四维差异化（防 AI 融合）

AI 生成多人同框时会把人物互相渗透，设计阶段就要拉开四个维度：

| 维度 | 拉开方式 |
|---|---|
| 色彩 | 每个主要角色分配专属色彩标识，远看可区分 |
| 体型 | 高矮胖瘦、轮廓形状要有明显差别 |
| 服装 | 材质感、复杂度、风格标签各不相同 |
| 姿态 | 驼背对挺拔、展开对收缩 |

**判据**：把全片主要角色的剪影并排摆一张，缩到拇指大小 —— 分不清谁是谁，就是没拉开。

**与资产层的衔接**：原 liqi 有「亲缘推导」（家族 / 师徒），管的是**该像的地方要像**；本节管的是**该不像的地方必须不像**。两件事同做，先做本节（拉开），再做亲缘推导（拉近该像的）。

## 六、 原型混搭

### 6.1 八个原型

| 原型 | 核心功能 | 设计优先级 |
|---|---|---|
| Hero 英雄 | 推动叙事弧线 | 成长弧线 |
| Shadow 阴影 | 制造最大冲突 | 威胁感 |
| Mentor 导师 | 给予智慧或道具 | 标志性细节 |
| Trickster 诡计者 | 打破规则、制造意外 | 姿态反差 |
| Threshold Guardian 阈限守卫 | 测试英雄 | 弱点设计 |
| Herald 信使 | 宣告或召唤 | 视觉信号 |
| Shapeshifter 变形者 | 制造悬念 | 身份锚点 |
| Ally 伙伴 | 提供支持 | 独立性 |

### 6.2 叠加是默认，不是加分项

每个主要角色**至少叠加两个原型**。单原型角色是扁平的：观众能提前猜到他的所有反应，也就记不住他。

| 叠加 | 结果 |
|---|---|
| Hero + Shadow | 被使命撕裂的悲剧英雄 |
| Hero + Mentor | 用死亡教育后辈的牺牲者 |
| Shadow + Ally | 表面敌人、实际帮助主角 |
| Mentor + Shadow | 反差型导师（平日是普通老头） |

叠加的落点是**视觉**，不是人设文档：每个原型在画面上都要有一处对应的**可见物**，两个原型就是两处该互相打架的视觉元素（例如「导师的朴素外袍」对「阴影的凶戾配饰」）。

### 6.3 姿态弧线

主角的姿态**在片内要变**，这是最省成本的角色成长可视化：

```
阶段一：驼背、重心不稳  →  阶段二：挺直、找到方向  →  阶段三：僵硬（异化 / 走向反面）
```

姿态弧线一旦定了，要写进注册表的 `characters.durable`，并作为**版本拆分的触发条件**之一（姿态跨阶段变化 = 新版本）。

### 6.4 可用检查

- [ ] 每个主要角色至少两个原型？
- [ ] 每个原型有对应的可见物？
- [ ] 主角有姿态弧线吗？跨阶段是否建了新版本？

## 七、 配色角色分配（60/30/10）

### 7.1 先分配角色，再谈颜色

配色不是「挑三个好看的色」，是**给每个色安排一份工作**：

| 角色 | 占比 | 职责 | 落地 |
|---|---|---|---|
| **底色** | 约 60% | 定情绪基调，退到背景里 | 通常是中性色（近黑、灰白、暖灰、冷灰） |
| **结构色** | 约 30% | 造结构、造纵深 | 从底色**派生**，不是独立选色 |
| **重音色** | 约 10% | 唯一的「有性格」的颜色 | 用一次就够，用多了就失效 |

**为什么用「底色 / 结构色 / 重音色」这三个名字**：本文件别处已在用「**主导色**」指「画面主色的总数」（第一节第二读的「还剩 2–3 个主导色」、第四节 3-3-3 的「主导色最多 3 个」）。若 60/30/10 也把占 60% 的那个色叫「主导」，同一个词在同一份文件里就有了两个含义。三个名字各管一件事，不再撞词。

**最容易搞错的是底色**：想让底色「有意思」是错的，它就该退下去。饱和的底色会和你的主体抢注意力，还会让眼睛疲劳。

**结构色必须从底色派生**：底色小幅提亮（暗场）或压暗偏灰（亮场）。底色与结构色的差值决定画面层级——差值太小分不开，太大显得碎。

### 7.1.1 例外：平面工艺风格不走「底色退到背景」

上一条是**通用规律，不是铁律**。以下风格的 primary 恰恰是高饱和的**风格本体色**，且正因此才成立：

| 风格 | 其 primary | 占比 |
|---|---|---|
| 剪纸 2D | 中国红 `#C0362C` | 占画面**七成** |
| 皮影 2D | 牛皮透光暖黄 `#E8C97A` | 主色 |
| 民俗年画 2D | 年画红 `#D33A2C` / 槐黄 `#E8B04B` | 大面积衣饰与主体 |
| 国潮新中式 2D | 靛青 `#2B4C7E`（中高饱和） | 为底 |
| 水墨淡彩 2D | 墨色 / 宣纸底 | 为底 |

**这些风格报的是「本体色 ≈70% / 结构色 ≈20% / 重音 10%」**。60/30/10 里真正不可让渡的是两条：**角色要分配**（每个色有职责）与**重音唯一**（`W-COLOR-BUDGET` 查的就是这一条）；比例本身按风格锚的 `palette.usage` 走。

### 7.2 与 liqi 色值双轨的衔接

资产层的「色值双轨」给的是 HEX 三色。本节补的是**这三色的角色**：定完 HEX 后必须再标一句谁是底色谁是结构色谁是重音色。

**⚠️ 这套角色不是本节新立的——liqi 已在 `风格注册表_style-registry.md` 的 `palette` 字段里定义过**（`usage` 字段写明「primary 为底色/留白，accent 为全片唯一重音色」）。本节是它的**设计依据**，注册表是它的**落盘字段**，两者是同一件事：

| 本节的名字 | 注册表字段 | 注册表 usage 的说法 | 门禁 |
|---|---|---|---|
| 底色 | `palette.primary` | 底色 / 留白 | — |
| 结构色 | `palette.secondary` | — | — |
| 重音色 | `palette.accent` | **全片唯一重音色** | `W-COLOR-BUDGET` 查「唯一重音色」 |
| （超三色的补充） | `palette.extended` | 无则 `null` | — |

**冲突时的取舍**：注册表已有 `palette.usage` 的，以注册表为准，本节不得另立一套；注册表没写的，用本节补。

由此推出一条**出图前检查**：三个 HEX 如果饱和度接近、明度接近，等于没分角色，要重配。

### 7.3 色彩人格映射（选色时的参考，不是教条）

| 色 | 主要联想 | 常见用法 |
|---|---|---|
| 红 | 热情、危险、侵略、重要性 | 主角能量感；反派的威胁感 |
| 蓝 | 信任、冷静、智慧、忧郁 | 可靠型角色；困境中的角色 |
| 黄 | 乐观、能量、警示、怯懦 | 活力角色；喜剧调剂 |
| 绿 | 自然、生长、嫉妒、病态 | 自然系角色；病态反派 |
| 紫 | 王权、神秘、魔法、堕落 | 法师、神秘者、道德暧昧者 |
| 橙 | 热忱、创造力、温暖 | 活力配角 |

**饱和度的三条体感**：高饱和给卡通 / 风格化 / 活力；低饱和给写实 / 落地 / 成熟；去饱和给道德灰、神秘、异界。

**阵营配色**：给每个阵营一个清晰的颜色身份（正派蓝金 / 反派紫黑 / 中立绿棕），阵营内共享调色板但**改变用量与位置**——这是「看得出是一伙，又分得清谁是谁」的配色版解法。

## 八、 AI 色彩稳定性光谱

**本节是本文件里最能直接减少废图的一节。**

颜色在 AI 生成里的稳定程度差异极大。同样是「一个红衣服的人」，纯红能稳稳出，雾白会糊掉。选色时要把这一层算进去。

### 8.1 稳定性分级

| 色彩类型 | 稳定性 | 说明 |
|---|---|---|
| 纯红 / 纯黄 / 霓虹蓝 | 最高 | 红黄是视觉极点，AI 优先响应 |
| 深红 / 橙 / 电紫 | 高 | 饱和但有深色压底 |
| 正蓝 / 绿 | 中 | 蓝偏冷，绿在自然中太常见 |
| 深灰 | 低 | 低饱和，必须靠强光影辅助 |
| 肤色 / 浅灰 | 低 | 中间调，最易被模糊处理 |
| 白 / 雾效 | 最低 | 无饱和度，完全依赖光影 |

**机理**：高饱和像素的方差大，边缘检测与注意力机制都优先响应它；低饱和区域（灰褐、雾、阴影）在训练数据里被当作可压缩内容，容易被平滑掉。

**⚠️ 边界：本节的分级只在项目风格锚允许的色域内适用。** 「霓虹蓝 / 电紫最稳」说的是**模型渲染得稳**，不是说**该用**——色域由 `风格锚_*` 的「② 配色与色域」与「⑨ 排除项」定死，本节不得用来推翻风格锚的禁用项。liqi 多款风格锚明令禁用霓虹 / 荧光：

| 风格锚 | 原文禁用项 |
|---|---|
| 国漫赛璐璐 2D | 禁用荧光、霓虹、脏灰混色、胶片颗粒感 |
| 国潮新中式 2D | 禁用高饱和荧光、禁用一切渐变色（霓虹撞色须「三主色受控」） |
| 哥特定格木偶 | 禁用高饱和、荧光、干净鲜亮的色彩 |
| 暗黑哥特 2D / 美漫波普 2D | 同向 |

**正确读法**：先在风格锚色域内选出**该色域里最稳的那个色**（例如低饱和灰蓝域里，深蓝比雾灰稳），而不是把域外的霓虹搬进来。

### 8.2 五类高危场景与对策

| 高危场景 | 失败表现 | 对策 |
|---|---|---|
| 沙漠 / 沙尘 | 肤色融进沙地 | 加红或蓝的围巾 / 配饰，加轮廓光 |
| 雪景 / 雾景 | 浅色服装消失 | 改深色或饱和色，或加高饱和配饰 |
| 夜店 / 昏暗室内 | 面部糊成一团 | 霓虹打脸、反光材质、边缘光【注 1】 |
| 森林草木 | 绿棕角色像长在树上 | 换红橙服装或加红橙配饰 |
| 赛博雨夜 | 边缘崩塌 | 霓虹服装 + 局部打光【注 1】 |

【注 1】**后两行的对策与 liqi 多数东方题材风格锚不兼容**（它们禁用霓虹 / 荧光，见 8.1 边界段）。四、二两行只在这两类场景确实是项目设定、且风格锚未禁霓虹时才用；志怪 / 武侠 / 古装题材走「反光材质 + 边缘光 + 高饱和配饰」这三条替代。

【注 2】表里的「围巾 / 配饰」属**服装范畴**，写进角色卡「服装 6 项」，**不是道具**——不要写成手持物件，那里受第十节「角色卡零道具」约束。

**判定顺序**：先问「这个角色主要出现在哪类场景」，再定服装色。**先定色再看场景的顺序会直接导致废图**——尤其是雪景、雾景、沙漠这三类，在 liqi 的志怪 / 武侠题材里出现频率很高。

### 8.3 五种稳定色彩结构

按可靠性排序：

1. 主体高饱和 + 背景中性灰 —— 最安全的基础结构
2. 主体高饱和 + 背景互补色 —— 视觉冲击最强
3. 主体深色 + 背景高亮度 —— 靠明度差而非饱和度
4. 主体低饱和 + 背景高饱和 —— 反向结构
5. 主体单色 + 配饰高饱和锚点 —— **最实用**（灰褐角色 + 一条黄色围巾）

### 8.4 最大误区

**色彩暴力不等于全画面高饱和。**

正确的做法是**结构化对比**：主体饱和 + 环境低饱和（或互补）。
全身高饱和 + 背景也高饱和 = AI 不知道该突出谁，结果主体和背景一起糊。

### 8.5 与 liqi 的衔接

本节与第七章的 60/30/10 配合使用：先按 7.1 分配角色，再按本节查稳定性。

- 底色若是「白 / 雾 / 浅灰」，必须补一条强光影或高饱和重音色兜底；
- 场景卡（`场景资产与时间线光照.md`）定光照时，把本节 8.2 的高危组合当作硬约束检查一遍；
- 检查结果写进角色卡的备注，供逐镜阶段复用。

## 九、 姿态叙事

### 9.1 姿态公式

```
姿态 = 重心位置 × 四肢角度 × 脊椎曲直 × 头部位置
```

四个变量，每个都有明确的两极：

| 变量 | 一极 | 另一极 |
|---|---|---|
| 重心 | 高（自信，直立） | 低（压抑，下沉） |
| 四肢 | 张开（开放） | 紧缩（封闭） |
| 脊椎 | 直（力量） | 弯（谦卑 / 疲惫） |
| 头部 | 抬起（对抗） | 低下（顺从） |

### 9.2 性格到姿态

| 性格 / 阶段 | 姿态特征 |
|---|---|
| 自信放松 | 慵懒开放，重心随意 |
| 亲密信任 | 身体靠近，动作收缩 |
| 战斗对抗 | 挺拔张扬，占据空间 |
| 老年 / 疲惫 | 重心前倾，背部弓形 |
| 反派压迫 | 俯视、收缩、侵占空间 |

### 9.3 与 FACS 表演层的分工

`表演层_FACS微表情.md` 管的是**脸上的肌肉**（AU 级）；本节管的是**脸以下**。两者不重叠也不互相替代。

**联动的必要**：情绪不能只写在脸上。同一个「怒」，脸上给眉心皱缩、嘴角下压，身体却站得笔直双手垂放，模型会读出矛盾，成片容易出来一个「表情滑稽的木头人」。

**落地**：写逐镜提示词时，情绪词必须同时落到两处——面部（走 FACS 口径）+ 姿态（走本节口径）。

## 十、 极端对比与矛盾性

### 10.1 七种对比

对立统一的点要出现在**同一场景**里，角色才会难忘。

1. 外表对真实（普通人外表 / 绝世高手内心）
2. 色彩对内容（可爱画风 / 黑暗故事）
3. 姿态对身份（杀手用侍弄花草的姿态）
4. 场景对角色（童话世界里塞一个黑暗角色）
5. 色彩对情绪（用暖色表达悲伤、冷色表达愤怒）
6. 服装对角色（正装在垃圾场，流浪汉在宫殿）
7. 比例对真实（超大头 / 超小身，制造不安）

### 10.2 矛盾性三问

- 这个角色的 A 面和 B 面分别是什么？
- 这两面在**同一个画面里**出现过吗？
- 这个矛盾让他更真实、更难忘记吗？

### 10.3 与「零道具」等硬约束的关系

本节是**设计思路**，不是要突破资产层的硬约束。极端对比通过**造型与光影**实现（例如「威严法器配破旧草鞋」），不通过往角色卡里塞道具实现——角色卡仍是零道具，法器另建道具卡，靠持物设定图组合。

## 十一、 记忆钩子与服装叙事

### 11.1 服装的四个功能

| 功能 | 说明 |
|---|---|
| 造型 | 人为制造尖锐 / 圆润边缘，改变剪影 |
| 叙事 | 承载角色的成长弧线 |
| 身份 | 纹样代表门派 / 阵营 / 文化 |
| 锚定 | 固定元素让模型记住这个角色 |

### 11.2 记忆钩子

给每个主要角色一个**独特的、可拆卸的**视觉标志——一件亮色外物、一个标志性配饰、一处显眼的结构。它的作用是在剪影之外再给 AI 一个抓手。

**可拆卸是关键**：不能拆的标志（比如角色的脸型）无法参与服装状态变化，也无法在换装版本里保留。

### 11.3 材质叙事

材质本身就是叙事装置：

- 厚重挺括的料子（厚呢、硬缎、挺括羊毛）→ 权力、不必劳作、情感设防
- 起球发软的料子（棉、麻、薄化纤）→ 日常、脆弱、可接近
- 破损、磨损、缝补 → 经历过什么，且**磨损位置本身在讲信息**（单侧袖口的油渍 = 惯用手 + 工种）

### 11.4 做旧纪律

干净的服装在成片里会「出戏」。设计阶段就要定：这件衣服**脏在哪、破在哪、旧到什么程度**，并写进服装 6 项栏。

**与资产层的衔接**：做旧细节属于 `durable`（恒存）还是 `transient`（临时），要在注册表里分清。恒存的（如固定的补丁位置）必须每镜都在；临时的（本场新增的泥污）按状态弧管理，别混。

## 十二、 生物设计八原则

适用于白毛僵、鬼物、灵兽一类生物资产。

1. **进化逻辑** —— 每个生物看起来都该像能进化出来的
2. **剪影优先** —— 独特性先于细节
3. **解剖服务功能** —— 形态跟随它在故事里的功能（捕食者要有明确的攻击方式）
4. **眯眼测试** —— 威胁等级在任何尺寸都该读得出
5. **运动反推设计** —— 想象不出它怎么动的，就重新设计
6. **声音塑造形态** —— 好生物能暗示它的叫声
7. **一个核心概念** —— 每个生物只需要一个清晰的点子，多了就散
8. **尺度决定一切** —— 尺寸变化会改变设计的全部（同一造型放大三倍，压迫感完全不同）

**现实锚定**（让奇幻生物可信的常用手法）：给每个生物找现实参照并做组合，而不是凭空捏。参照组合要保证**骨架逻辑成立**——关节能朝需要的方向弯，腿能支撑体重，头的大小配得上脖子。

**几个必须自查的失败**：

- 腿撑不起体重的（大型生物最常见的错）
- 捕食者没有明确攻击方式
- 「恐怖」设计其实只是「忙」（细节多 ≠ 可怕）
- 拼贴感重，像各种动物硬拼而非演化出来的

## 十三、 景别跳跃规则

### 13.1 档位先对齐

本节沿用 liqi 的 **9 档景别**（v5.7.0 由 7 档扩为 9 档：`光学与空间语言块.md` 表一、
`质控层_门禁与过审.md` 的 `W-SHOTSIZE-MISSING` 均按 9 档查），不自立档位名：

```
大远景 → 远景 → 全景 → 中全景 → 中景 → 中近景 → 近景 → 特写 → 大特写
   1       2      3       4       5       6       7      8       9
```

**为什么从 7 档扩到 9 档**：原 7 档在「中景」与「近景」之间缺一级，
「膝盖以上」（中全景）与「胸口以上」（中近景）被迫挤在同一档，
统计时分不开——而这两个取景范围对参考素材的依赖程度不同，混在一档等于让配额失去精度。
补齐后，`分镜配额与机检规范.md` 的特写占比、景别构成等统计才有意义。

### 13.2 风险：跨度越大，角色被重构的概率越高

**这一步管的是「角色会不会被重画」，不是「镜头能不能这么切」。**

| 相邻两镜的档位差 | 风险 | 说明 |
|---|---|---|
| 相邻一档（全景→中景） | 低 | 参考素材够用 |
| 隔一档（远景→中景） | 中 | 补一张过渡参考即可 |
| 隔两档以上（大远景→特写） | 高 | 模型对小脸素材的依赖最强，等于从一张小脸图里重造五官 |

**原理**：模型在生成特写时对参考素材的依赖最强。上一镜是大远景全身、下一镜直接切特写，等于让模型从一张小脸图里重造五官，出来的人像另一个人。

### 13.3 🔴 但「跳级」在叙事上不一定非法——区分两件事

`视听层_镜头文法与光色.md` 明确保留两种**合法**的大跨度手法，本节不推翻它们：

| 手法 | 出处 | 说明 |
|---|---|---|
| **极限景别跳跃** | 视听层「景别阶梯跃迁」段 | 在**极微距特写 ECU** 与**极宏观大远景 EWS** 之间对跳，制造两极反差，**长段高燃专属** |
| **开场 ECU 两极对冲** | 视听层「美学构图四件套」第 1 条 | 第一镜直接用极微距双眼特写立住量级——**开场首镜没有上一镜，不受本节约束** |

所以本节的正确读法是：

> **叙事上允许跳，技术上必须兜底。** 跳级本身不是错，错在跳了却不给模型过渡素材。

### 13.4 两种技术兜底

| 方案 | 做法 | 适用 |
|---|---|---|
| 加过渡镜头 | 大远景 → 中景（膝盖以上）→ 近景（胸口以上）→ 特写 | 段落推进，有镜头预算 |
| 传前一镜输出图 | 大远景 → 传远景图 + 特写 prompt → 特写 | 必须硬跳（极限景别跳跃、开场对冲） |

**与 liqi 的衔接**：这条与资产层「三条投喂铁律」是同一条链上的两环——铁律解决「带哪张图」，本节解决「跨度大了要补什么图」。**两者必须同时满足**：带了 `face_hd` 但跨度大又没补过渡素材，仍会漂移。

**落点提示**：本节的机械判据（相邻镜景别档位差 → 是否带过渡素材）已在 **v5.7.0 落地**——
`scripts/audit_project.py` 的 `S. 分镜配额构成` 段，机检码 **S18**（相邻档位差 ≥3 报 WARN，
段首 `【配额声明】本段采用极限景别跳跃` 即整段豁免，开场首镜不判）。
档位差判据只是配额机检的一环，全包配额表（特写占比、机位配比、焦段与运镜种数等 11 项）
见 `references/分镜配额与机检规范.md`。

## 十四、 全片视觉统筹

前十三节管的是**单个资产 / 单个场景**好不好看。本节管更高一层的问：**这部作品为什么是这个视觉**。

### 14.1 什么时候需要

不写这一层就直接进资产层，会出现「每个资产单看都对、连起来不像一部片」——色调、光线、构图的规则散落在各张卡里，没有共同的上游。

| 项目形态 | 是否需要 |
|---|---|
| 单集 / 单条短视频（≤5 分钟） | 可省 |
| 多集连续剧、系列短片、有明确作者意图的项目 | **必做** |

### 14.2 五个产出

**其一，视觉主题宣言。** 一段话回答：这部作品的视觉语言是什么、要让观众感受到什么。

先定**核心情感主题（一到两个词）**，由主题反推视觉。反过来（先想好看再找主题）得到的只是随机美化——这是本节第一条反模式。

**其二，色彩哲学。**

| 项 | 要求 |
|---|---|
| 主色调 | 最多 3 色 + 1–2 点缀色（与第七节 60/30/10 配合） |
| 情绪色彩映射 | 不同故事情绪对应不同色彩，写成表 |
| 禁忌色 | 哪些颜色会破坏这个世界观——写出来就等于给负面词一份依据 |

**其三，色温情感带与光线情感表。** liqi 的光照锚点纪律是「四值只从 `lighting_anchors` 取，禁止现场编」，但没规定这些值**一开始怎么定**——本节补的就是这一步。

⚠️ **先分清两条轴，不要把本节当第二张锚点表。** 本节与 `场景资产与时间线光照.md` 的时段表是**两个维度**：

| | `场景资产与时间线光照.md` 时段表 | 本节 色温情感带 |
|---|---|---|
| 划分依据 | **时间**（拂晓 / 晨 / 正午 / 午后 / 黄昏 / 入夜 / 深夜） | **情绪**（极暖 / 暖 / 中性 / 冷 / 极冷） |
| 粒度 | 7 个时段，各自一个 K 区间 | 5 个情绪带 |
| 身份 | **数值来源**（`lighting_anchors` 是唯一事实源） | **设计参考**（第一次定锚点时的依据） |

两条轴**不是一一对应**——同一个情绪带可以对上多个时段，同一个时段的 K 值也可能跨两个情绪带（如拂晓 6500–8000K 横跨「冷」与「极冷」；黄昏 2000–3500K 横跨「极暖」与「暖」）。**取值永远回 `lighting_anchors`，本节只用来在定锚点前想清楚「这场戏该给我什么感觉」。**

| 情绪带 | 色温区间 | 典型光源 |
|---|---|---|
| 极暖 | 1800–2500K | 烛光、火堆、油灯、炭火 |
| 暖 | 3000–3500K | 室内暖灯、黄昏低角度日光 |
| 中性 | 4500–5000K | 阴天天光 |
| 冷 | 5500–6500K | 蓝天直射日光 |
| 极冷 | 7000K+ | 阴影、雪天、冷白灯 |

（注：黄昏低角度日光是**一个**现象，落在 `lighting_anchors` 的 2000–3500K 区间内，横跨「极暖」与「暖」两带。上表只把它写在「暖」一行，不在「极暖」另举「日落」——同一个现象写进两个带，就是本节的内部矛盾。）

光线与情绪的对应（选时段与光位时的参考）：

| 光线状态 | 情感含义 | 常用场景 |
|---|---|---|
| 黄金时刻 | 温暖、怀旧 | 浪漫场景、收尾 |
| 蓝调时刻 | 忧郁、梦幻 | 告别、回忆 |
| 正午硬光 | 冲突、严酷 | 对峙、审判 |
| 低调单光源 | 神秘、危险、内心挣扎 | 秘密、转折 |
| 漫射柔光 | 平静、安全 | 日常 |
| 逆光剪影 | 命运感、史诗 | 出场、决战 |
| 烛光 / 火光 | 温情与危险双义 | 古装、密会 |

**其四，色彩叙事弧。** 全片的色彩走向要事先定，不能每集独立配色。三种常见走法：

- 开场冷 → 高潮暖 → 悲剧消色
- 反派场景引入对比色（主角暖、反派冷），对峙时双色同框
- 同一角色随处境变化其所属色域，但**专属色不变**（专属色是身份锚，不参与叙事变化）

⚠️ 这与 `场景资产与时间线光照.md` 的「色彩节奏设计（什么时候该破一致性）」是同一件事的两个角度：那份讲**何时破**，本节讲**往哪走**。

**其五，参考图矩阵。** liqi 有「主动检索参考图」，但没规定参考包该长什么样。按用途分五类：

| 类别 | 张数 | 用途 |
|---|---|---|
| 氛围参考 | 4–5 | 代表整体视觉感 |
| 色彩参考 | 2–3 | 承载目标色彩哲学 |
| 光线参考 | 2–3 | 代表目标光线状态 |
| 质感参考 | 1–2 | 材质样本 |
| **反面参考** | 1–2 | **明确标注「不要这种」** |

⚠️ **🔴 上表的刻度是「项目级参考库」，不是「单镜投喂包」——两者必须分开，否则直接撞 Seedance 2.5 的素材上限。**

| | 项目级参考库 | 单镜投喂包 |
|---|---|---|
| 规模 | 上表合计 10–15 张，跨集累积 | **图片 1–8 张**（`Seedance2.5适配.md`），推荐**素材总量 4–5 份** |
| 存放 | 项目 `reference/` 目录，人工查阅与挑选 | 每镜按用途挑，写进【参考素材职责】 |
| 用法 | 定视觉时的比对集 | 挑完就投，**不要按库的规模塞满** |

**挑法**：单镜按「这一镜最缺什么」从库里挑 2–4 类，合计不超过 8 张、推荐 4–5 份。具体上限与取舍纪律（先减素材，再减描述）见 `Seedance2.5适配.md`。

**反面参考是本节的独有抓手**：正面参考告诉模型「往哪去」，反面参考告诉它「别往哪偏」。在跨集项目里，反面样本抑制风格漂移的作用往往比正面样本更直接。

**⚠️ 反面参考是图片模态，不替代文字模态的负面词。** 项目既有的 `风格锚_*` 「⑨ 排除项」 / `negative_direction` / 国内面压成的 `Must not` 一行，**照旧照写**——两者并用，不是二选一。反面参考补的是「文字说不清的那种偏」，文字负面词管的是「能说清的禁用项」。

### 14.3 跨集一致性审核

多集项目在**每集进资产层之前**过一遍：

- [ ] 本集色调符合该集情绪对应的色彩吗？
- [ ] 同一场景的光线方向与本剧此前一致吗？
- [ ] 色温落在规定的时段区间内吗？
- [ ] 主角是否处在自己的专属色域里？
- [ ] 有没有引入与色彩哲学冲突的风格词？（**最常见的一类漂移**）

### 14.4 反模式

| 反模式 | 后果 | 修法 |
|---|---|---|
| 无主题视觉，只追求「好看」 | 随机美化，拼不成一部片 | 先定情感主题再反推视觉 |
| 主色超过 3 个 | 画面失去焦点 | 收到 3 主色 + 1–2 点缀 |
| 定了视觉规则却不执行 | 等于没定 | 每集进资产层前用 14.3 清单过一遍 |
| 情绪与色彩不对应 | 观众读不懂情绪转向 | 建情绪-色彩映射表并严格执行 |
| 参考图风格分散 | 模型收到互相矛盾的信号 | 参考包内所有图须在同一视觉频率上 |

## 十五、 出图前审美自检清单

建角色卡 / 生物卡 / 群像包，出图**之前**过一遍。

### 全片（多集项目）

- [ ] 视觉主题宣言写了吗（一到两个词的情感主题）？
- [ ] 色彩哲学定了吗（主色 ≤3 + 情绪映射 + 禁忌色）？
- [ ] 色彩叙事弧定了吗（全片往哪走）？
- [ ] 参考包里有没有「反面参考」？

### 单角色

- [ ] 三读顺序对吗（先剪影后细节）？
- [ ] 缩到 32px 认得出吗？有 2–3 处地标吗？
- [ ] 有破对称元素吗？
- [ ] 主形状 + 破形状都定了吗？
- [ ] 色数 ≤ 3、服装主元素 ≤ 3、配饰焦点 ≤ 3 吗？
- [ ] 删过一轮细节吗（递减法）？

### 群像

- [ ] 先出群像再提个体吗？
- [ ] 任意两个主要角色不在同一象限吗？
- [ ] 色彩 / 体型 / 服装 / 姿态四个维度都拉开了吗？
- [ ] 缩到拇指大小并排看分得清吗？
- [ ] 每个主要角色 ≥ 2 个原型吗？

### 配色

- [ ] HEX 三色标了底色 / 结构色 / 重音色吗（与注册表 `palette.usage` 一致）？
- [ ] 结构色是从底色派生的吗？
- [ ] 重音色是全片唯一那一个吗（`W-COLOR-BUDGET`）？
- [ ] 用的色落在本项目风格锚的色域内吗（没有踩风格锚的禁用项）？
- [ ] 查过第八节的稳定性分级吗（有没有踩白 / 雾 / 浅灰）？
- [ ] 角色主要出没的场景属于五类高危之一吗？对策写了吗？
- [ ] 配色结构属于五种稳定结构里的哪一种？

### 生物

- [ ] 骨架逻辑成立吗（关节、承重、头颈比）？
- [ ] 有明确的攻击 / 行动方式吗？
- [ ] 眯眼能读出威胁等级吗？
- [ ] 只有一个核心概念吗？
- [ ] 现实参照是谁？（说不出参照就是凭空捏的）
