# 风格路由表（L2 · 风格 id 速查与选型决策）

> 用途：锁③ 选定轨道后，用本表把轨道落到**具体风格 id**，再由 id 取风格锚文件。
> 替代 SKILL.md Load Map 里「风格名 → 文件名」的硬映射——风格会越加越多，硬映射表会爆炸，路由表不会。
>
> 上游＝锁③ 轨道选择；下游＝`references/风格锚_<slug>.md`。
> 数值事实源＝`style-registry.json`（ schema 见 `风格注册表_style-registry.md`）。

**「条件准入」的含义**：默认不用，但不再是禁区。像素一类的「动态必闪」是**参数层**问题
（固定帧数 + 网格对齐 + 禁中间帧插值即可缓解），不是风格层缺陷，因此从「不入」改为条件准入；
用到时按 `风格锚_模板.md` 现场落值并把 status 改成「已落值」。

**稳定性分级判据**：
稳 = 数据集重 tag、跨镜一致��好、长片可直接用；
中 = 需要额外约束词才稳（如限色、限运镜、加材质锚）；
险 = 高翻车率，需专门手法或干脆避让（水墨易变灰水彩、写实人脸恐怖谷、像素动态闪烁）。

## 三、选型决策器

按顺序答三个问题，答案直接指向 id。

### 问题 1 · 题材
| 题材 | 候选 |
|---|---|
| 古代 / 古风 / 非遗 | ink-wash-2d、dunhuang-gongbi-2d、qinglv-shanshui-2d、papercut-2d、shadow-puppet-2d、nianhua-2d |
| 现代都市 / 职场 / 校园 | celshade-guoman-2d、shinkai-2d、photoreal-pbr、npr-celshaded-3d |
| 奇幻 / 仙侠 / 神话 | celshade-guoman-2d、npr-celshaded-3d、gothic-puppet、dark-anime-2d |
| 科幻 / 未来 | npr-celshaded-3d、techwear-cyber-2d、lowpoly-iso-3d |
| 童书 / 温情 | gouache-2d、claymation-3d、ghibli-2d、stylized-pixar-3d |
| 恐怖 / 志怪 | dark-anime-2d、gothic-puppet（需配过审口径） |

### 问题 2 · 载体（这一问决定稳定性权重）
| 载体 | 要求 | 首选 |
|---|---|---|
| 长片 / 多镜（跨镜一致性刚需） | 稳定性必须是「稳」 | celshade-guoman-2d、npr-celshaded-3d、lowpoly-iso-3d、claymation-3d |
| 单帧海报 / 立绘 | 可以不稳，要好看 | thickpaint-2d、korean-illust-2d、dunhuang-gongbi-2d |
| 短视频单镜（≤10 秒） | 中等即可，但要避开动态闪 | 除 pixel-2d 外基本都行 |

### 问题 3 · 素材
| 素材情况 | 影响 |
|---|---|
| 有实拍对手戏素材 | 只能选 photoreal-pbr 或 npr-celshaded-3d，其余会割裂 |
| 有参考图集 | 优先选与图集同轨道的风格，图崩了视频必崩 |
| 纯文生（无图） | 「稳」档优先；手绘轨与定格轨纯文生风险高，建议先出资产图再走 I2V |

### 稳定性优先排序（长片项目按此选，拿不定就用排最前的）

celshade-guoman-2d ≈ npr-celshaded-3d > lowpoly-iso-3d ≈ stylized-pixar-3d ≈ claymation-3d > gothic-puppet > thickpaint-2d > ink-wash-2d > photoreal-pbr（人脸）

## 四、互斥矩阵（驱动串轨检测）

互斥 = 混写必崩。登记必须双向，单向会让检测漏一半。

| A | B | 混了会怎样 |
|---|---|---|
| celshade-guoman-2d | thickpaint-2d | 明暗逻辑相反（硬边界 vs 软过渡），出杂烩 |
| ink-wash-2d / papercut-2d / shadow-puppet-2d | photoreal-pbr | 平面化 vs 体积感，典型崩法是出片变 2.5D 半立体 |
| gothic-puppet / claymation-3d | photoreal-pbr | 材质词汇互斥（黏土假人 vs 真实皮肤） |
| 卡通轨任一 | 写实轨任一 | 负面词方向完全相反，写反全片污染 |
| npr-celshaded-3d | celshade-guoman-2d | 决定资产是 3D 还是 2D，进而决定投喂方式；选定后中途不得换 |
| gothic-puppet | ink-wash-2d | 一个要体积与纵深，一个要平面无体积，方向相反 |

**当前已落值的九条风格中，有 27 对是互斥的**（九条：ink-wash-2d / gothic-puppet / photoreal-pbr /
celshade-guoman-2d / npr-celshaded-3d / stylized-pixar-3d / anime-2d / webtoon-2d / documentary-live-action；
互斥关系全部登记在 L0 `style-registry.json` 的 `excludes`，且已**双向对称**）。它们分属六个方向：
平面手绘 / 实体定格 / 写实体 / 2D 赛璐璐 / 3D 卡通着色 / 实拍。
任意两条混写都会崩。**互斥关系不是全对称的**——例如 `gothic-puppet` 只与 5 条互斥（不与 anime-2d / webtoon-2d /
documentary-live-action 互斥），`webtoon-2d` 只与 4 条互斥；**逐条以 L0 `excludes` 为准，不要按「九条两两全互斥」理解**。
上表与本段列的是跨轨典型崩法对，不是完整互斥矩阵。

**通用串轨红线（不分风格）**：
- 同一包里出现两套风格压句 → P0
- 同一包里头身比跨档（有人 7 有人 5.5） → P0
- 引用了 status 为「待建」的风格 id → P0
- 负面词方向与轨道相反（卡通轨里写着「禁卡通感」） → P0

## 五、路由使用方式

```
锁③ 定轨道
  → 本表第一节确认轨道方向
  → 本表第三节决策器拿候选
  → 本表第二节查 id 与状态（待建的先按 `风格锚_模板.md` 落值再进交付；不想落值就退回上一档稳定性）
  → 按 id 取 references/风格锚_<slug>.md
  → 该锚第一节第九条写入交付物的风格声明
  → 交付前跑 check_style.mjs（阶段 3 上线）确认无串轨

**落值即回写**：现场落完十节锚后，把项目级 `style-registry.json` 里该 id 的 `status` 改成「已落值」并补 `ref_file`，否则下一轮还是会当成没锚文件重落一遍。
```

旧包兼容：历史包只写了轨道（如「写实志怪轨」）没写 id 的，按轨道默认风格处理（写实轨 → photoreal-pbr，手绘轨 → ink-wash-2d，定格木偶轨 → gothic-puppet，卡通轨 → celshade-guoman-2d），并在交付时提示补全 id。
