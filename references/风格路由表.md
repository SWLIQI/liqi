**「条件准入」的含义**：默认不用，但不再是禁区。像素一类的「动态必闪」是**参数层**问题
（固定帧数 + 网格对齐 + 禁中间帧插值即可缓解），不是风格层缺陷，因此从「不入」改为条件准入；
用到时按 `风格锚_模板.md` 现场落值并把 status 改成「已落值」。

**「不入」的判据（v4.9.1 补，来自外部风格趋势调研（评审底稿不随包分发））**：不入不等于不好，等于**它不走 liqi 的提示词生成链**。

| 不入项 | 不入的真实理由 |
|---|---|
| 沙画 | 低频，且固体材质极易被画成半立体 |
| Y2K 拼贴 | 自带大量文字，与禁可读文字铁律冲突 |
| 有机生物 CGI | 崩形且无稳定解法 |
| **沙雕表情包漫 / 火柴人 / 简笔画**（v4.9.1 补登） | **它的生产方式是素材库 + 剪辑 + 配音，不是提示词生成**——画面主体是贴图与微动作，给它写十节锚毫无意义。市场侧它是漫剧 1.0 形态、成本最低、完播率最高，所以**不入的理由不是它不好，是它不归本表管**。若确需在 liqi 里做：按 `pixel-2d` 同类的「条件准入」处理，**并在该包显式放开文字铁律**（局部放开，不全局放开） |

**Q 版口径（v4.9.1 补）**：**「Q 版」不是污染词，是风格 id 的选择问题。**
多个锚把「Q 版比例」写进负面词，那挡的是「**已选非 Q 版风格却写了 Q 版比例词**」这种混档，不是 Q 版本身——
Q 版 / 超变形是独立画风，2–3 头身是它的**定义**不是它的缺陷。
各锚负面词**保持不变**（它们挡混档是对的）；要用 Q 版就走 `chibi-qban-2d`（待建，批 3），不要指望从别的锚里「去掉负面词」得到 Q 版。

**稳定性分级判据**：
稳 = 数据集重 tag、跨镜一致��好、长片可直接用；
中 = 需要额外约束词才稳（如限色、限运镜、加材质锚）；
险 = 高翻车率，需专门手法或干脆避让（水墨易变灰水彩、写实人脸恐怖谷、像素动态闪烁）。

两者可以叠着描述同一张参考图，但**同一包里只取一个 id**；边界没被真实项目验证过之前，韩系插画维持待建，不现场落值。

**通用串轨红线（不分风格）**：
- 同一包里出现两套风格压句 → P0
- 同一包里头身比跨档（有人 7 有人 5.5）→ 机械层报 `S6-HEAD-MIX` WARN（全包级计数，做不到逐角色判定）+ 人工确认同一角色不跨档
- 引用了 status 为「待建」的风格 id → P0
- 负面词方向与轨道相反（卡通轨里写着「禁卡通感」） → P0

## 六、 递进收窄四步（v5.8.2 新增 · 选风格的交互规程）

> 上游是「影像基底 → 技法家族 → 导演卡 → 辅助质感」四步递进：74 组按技法收窄，
> 每一步都在排除，**每次只给 3~4 张候选卡**，不平铺。
> liqi 的候选池是 50 个锚而不是 74 组，所以**收窄的层数一样，每层的宽度按 liqi 的池子定**。

### Step 1 · 影像基底（**必问，不得自动带出**）

四选一：**2D / 3D / 实拍 / 平面工艺**（对应第二节的「维度」列）。

**为什么必须明确确认、不能自动判定**：基底一旦被自动判走，**全片画质词、形体骨相、
候选池、打戏档位全部跟着错，且错在源头、下游无从纠正**。典型事故：真人项目被判成
动漫基底，出片后所有人物都是动画脸，改都没法改——只能重做。
本步的判定表只用于**给建议**，不作为结论；**用户未表态 = 停下询问**。

| 基底 | 判定依据（只用于给建议） | 默认落点 |
|---|---|---|
| **实拍** | 有实拍对手戏素材、都市悬疑、年代怀旧、纪实 | photoreal-pbr / documentary-live-action / urban-folk-filmstill / xianxia-idol-live / sweet-romance-live / hk-retro-filmstill / urban-suspense-live / opera-stage-live |
| **2D** | 童话、青春、古风抒情、平面装饰向 | celshade-guoman-2d / anime-2d / gothic-2d / thickpaint-2d / webtoon-2d / ghibli-2d / shinkai-2d / dark-anime-2d / comic-popart-2d / chibi-qban-2d / shonen-hotblood-2d / us-comic-ink-2d / cyberpunk-anime-2d / synthwave-retro-2d / noir-ink-2d / flat-minimal-2d / pixel-2d |
| **3D** | 玄幻仙侠、机甲、高燃打斗、要环绕运镜 | npr-celshaded-3d / guofeng-cine-3d / stylized-pixar-3d |
| **平面工艺** | 非遗、民俗、装饰性题材 | papercut-2d / shadow-puppet-2d / guochao-2d / nianhua-2d / qinghua-porcelain-2d / han-relief-rubbing / bronze-motif-2d / miao-batik-indigo |

基底不匹配的风格**整体不出候选卡**（例：实拍基底却推 celshade-guoman-2d → 不出卡，并说明原因）。

### Step 2 · 每族给 3 个候选锚

按 Step 1 的基底 + 第三节的题材 / 载体 / 素材三问，给 **3 个候选 id**，
**不是把 50 个已落值的平铺给用户**。每张候选卡固定四行：

```
A【默认推荐】<id> · <轨道> · <一句话看得见>
   看得见：<可辨识的视觉特征，不写风格形容词>
   易跑偏：<选了它最可能出什么错——这是用户最需要的信息>
   适合：<题材 / 载体 / 稳定性代价>
B …
C …
不想挑就回「按你的推荐走」（= 沿用 A 卡）
```

**排序键 = 题材亲和度，不是稳定性、也不是能力**。稳定性是门槛（用于排除），
亲和度才是排序键——否则童书题材会把稳定性最高的 celshade-guoman-2d 顶上 A 卡。

### Step 3 · 收敛到 1 个（每族 ≤2 → 1）

- 同一轨道 / 同族**不得超过 2 个进终选**（3 个候选里同族占 2 个以上等于没给选择）；
- 最终只留 **1 个 style_id**（`S4-MULTI-STYLE` 守着）；
- 拿不定就按第三节「稳定性优先排序」取最前者，并明说「选它是要付什么代价」。

### Step 4 · 可选辅助质感（可跳过）

- 只给能与主锚叠加的，**必须不在第四节互斥矩阵里**；
- **未指定 = 不叠加**，按主锚执行，**不追问、不阻塞**。

## 七、 选定即冻结（v5.8.2 新增 · 四条硬规则）

- **F-1 一个主 style_id**：一包只能一个（`S4-MULTI-STYLE` 守着）。
- **F-2 至多一个辅助质感**，且须承担明确独立功能（如「主体水墨 + 特效手绘化」），
  并与主锚不互斥（按第四节矩阵核）。
- **F-3 选定即冻结**：全包只允许该锚的**色域 / 材质口径 / 禁用项 / heads_range**。
  **改风格 = 重开任务，不得中途换锚**——中途换，前面所有镜的色域与负面词全部作废。
- **F-4 第三方作品名禁入最终提示词**：参考只作内部解析，须转译为可见参数
  （机检 `W-DIRECTOR-NAME-IN-BODY`；各锚 `ip_note` 同口径）。

### 冻结四项分别由谁守

| 冻结项 | 守门 | 级别 |
|---|---|---|
| **色域** | **S10-STYLE-GAMUT-OUT**（正文用色越出 `palette`） | WARN |
| **禁用项** | **S11-STYLE-BANNED-HIT**（正文出现 `negative_direction`） | **ERROR** |
| heads_range | `S6-HEAD-MIX`（全包多档计数）+ 人工确认同角色不跨档 | WARN |
| 串轨 | `S5-CROSS-STYLE` + 第四节互斥矩阵（`excludes` 双向登记） | ERROR |

**S10 为什么是 WARN 不是 ERROR**：项目级重音色（如「全片唯一重音色 = 朱砂红」）
可能本来就不在该锚默认色域里。正确的处理是**补进项目级 `style-registry.json` 的
`palette.extended`**，而不是改提示词——所以报 WARN 并指明改哪里。
**S11 是 ERROR**：`negative_direction` 是轨道反向词，出现在正文就是串轨，没有合理解释。

⚠️ **两条都在剥掉压句与配色句之后扫**——压句里常带「无噪点颗粒」「无渐变」这类否定式写法，
不剥就会把锚自己的压句判成串轨（S5 已有同类豁免，S10/S11 沿用同一口径）。
S11 另有一条专用豁免：**否定语境只往前看 20 字且限定同一行**（用 S5 的 ±40 字窗口时，
「…画面带噪点颗粒」会被下一行的 `Must not` 无端豁免，实测漏报）。

**改色域的正确姿势**：改项目级 `style-registry.json` 的 `palette`，**改完回写注册表**。
只在提示词里换色不回写，下一轮还是按旧色域判——那是把冻结当摆设。

## 八、 明确不做：不把 21 锚扩成 74 组

上游有 74 组导演风格库，其中 14 组完整参数化。liqi 不跟进这个数量。

**理由**：liqi 单锚是 13~22 KB 的全量展开（专属禁用项、透光性口径、`heads_range`、
材质工艺、稳定性评级、崩点表、删词对、三面压句、运镜池、保真预算），
**深度换数量是倒退**。21 个锚里 20 个已落值，缺的不是数量，是**锁定规程**——
本次补的就是规程（第六、七节）。

要新风格时按 `风格锚_模板.md` 十节现场落值并回写 `status`，**不为凑数而落值**。
