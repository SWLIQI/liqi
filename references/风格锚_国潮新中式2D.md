# 风格锚 · 国潮新中式 2D（L1 · 十节）

风格 id：guochao-2d　｜　轨道：平面工艺轨　｜　维度：2D　｜　status：已落值

## 零、文件头

一句话定位：本文件是 liqi Step 2「全片统一风格锚（九段）」在**现代平面插画语言加东方纹样**这套风格上的落值。数值事实源是项目级 style-registry.json 的同名条目，本文件不另立数值。

适用判定：画面是干净的现代平面插画（平涂色块加金线勾边），纹样是东方母题的几何化再设计（云纹、回纹、瑞兽的简化形），构图讲留白与装饰带分区，主体美型但不写实。用户给了国潮风设定图、或明确要求国潮 / 新中式 / 东方潮玩风格时选本风格。

边界声明：与写实轨的边界在「笔触与体积」——写实轨要皮肤与光，本风格是无影平涂加金线，出现体积词即串轨。与三渲二轨的边界在「维度」——三渲二有 3D 体积与转面，本风格是 2D 平面，禁环绕运镜。与国漫赛璐璐的边界在「装饰语法」——赛璐璐是动画着色逻辑（固有色加暗部），本风格是插画装饰逻辑（纹样带、金线、留白），出现赛璐璐阴影术语即串轨。与民俗年画的边界在「色数控制」——年画是多色套印，本风格是受控的三主色加金。

### 措辞纪律表

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| 华丽的丝绸质感 | 几何化云纹装饰带，平涂 | 真实材质与光泽是写实词汇，把插画变成织物摄影 |
| 金光璀璨 | 细金线勾边，哑光金 | 辉光词把金线变廉价高光 |
| 灵动的飘带飞舞 | 一拍一有限动画，装饰带缓慢漂移 | 连续飞舞触发插值与运动模糊 |
| 精致立体的五官 | 美型插画脸，下颌干净 | 立体与毛孔是真人轨词汇 |
| 笔触 / 晕染 / 宣纸纹理 | 平涂色块，无笔触无纸纹 | 笔触与晕染是手绘水墨轨的入口词，一旦出现就被路由去水墨或工笔 |
| 霓虹撞色 / 赛博高饱和 | 三主色受控（靛青 / 朱砂 / 云白），其余压灰 | 「国潮」在模型先验里极易被做成霓虹赛博，色域一放开就变成另一个风格 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。只写一句会导致色域漂移——尤其朱砂那一处重音色，漏写配色句时「一镜一个主体」的约束就丢了，模型会把红撒满全画面。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 81 词（按校验器空白分词口径实测），在全库锚中排第 8（按词数降序），中等，留有两三个词的余量。

## 三、色值表

| 用途 | HEX | 说明 |
|---|---|---|
| 主色 / 底 | #2B4C7E | 靛青，大面积为底 |
| 辅色 / 重音 | #C0362C | 朱砂，一镜只许一个主体物件 |
| 留白底 | #F6F1E7 | 云白，负空间 |
| 勾边与纹样 | #D4A94E | 哑光金，只用于线与纹样 |
| 深部 / 剪影群 | #1F3350 | 深靛青，群像与远景压影 |

色彩预算纪律：每镜只声明一个唯一重音色（朱砂 #C0362C 的一个主体），其余压进靛青阶级（#2B4C7E 与 #1F3350）与云白留白。不声明色彩预算，模型会自发补饱和度，国潮立刻变廉价年货风。

**本表无「肤色」项（不是漏项）**：国潮人物的面部是靛青阶级里的一个平涂色块，不画肤色层次也不画红晕。`#F6F1E7` 的云白承担亮部与留白，肤色若单列一格，面部就从「色块构成」变成「皮肤塑造」，直接串去厚涂插画轨。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定正面、缓慢推近（保持平面不变形）、垂直升降取景、切换机位重取景 |
| 少量 | 缓慢横移（仅沿装饰带走，全片不超过两次） |
| 避免 | 环绕（平面无转面，环绕必崩）、荷兰角、甩镜、任何透视变形强烈的运镜 |

每段只锁一个主运镜。2D 平面没有第三维，环绕与斜对会让插画暴露成贴片——运镜语法同剪纸与皮影：摄影机正对画面或等比推近。

## 五、材质与可见性预算

| 项 | 落值 |
|---|---|
| 主花费 | 纹样装饰带的精确度与金线勾边的干净度 |
| 次花费 | 留白的形状控制（负空间本身是构图） |
| 省 | 群像（压成深靛青剪影群，只以冠饰轮廓区分）、远景建筑细节 |
| 可见性 | 群像只写数量与动态趋势；一镜纹样母题不超过三种 |
| 禁 | 体积光、渐变、3D、景深、真实皮肤、笔触纹理、投影、辉光 |

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| 纹样糊成噪点或麻点 | 纹样太密太小；一镜堆了三种以上母题 | 单个纹样不小于画布的百分之三；母题一镜不超过三种 |
| 金线变廉价高光 | 写了璀璨、闪耀、发光 | 金线一律哑光，写进压句 |
| 沦为通用国风 CGI | 纹样缺失，只剩立领盘扣标签；或混入 3D 渲染词 | 压句第一句钉死 flat illustration；每镜至少一处可见纹样带 |
| 留白被填满变拥挤 | 每个区域都加了装饰 | 云白负空间至少占画面三成；装饰带集中在上下边缘 |
| 出现赛璐璐阴影（串国漫） | 写了暗部、固有色加影、两段式阴影 | 本风格是无影平光，明暗只存在于固有色深浅 |
| 动效滑行丢失平面感 | 写了流畅飞舞 | 一拍一有限动画写进压句；确需漂移只给装饰带 |
| 朱砂重音滥用 | 每个主体都是红的 | 重音色一镜只许一个主体物件，写进本镜色彩预算 |
| 纹样跨镜对不上 | 每镜现编纹样；资产图里没锁纹样分布 | 纹样分布图随资产图一并锁定；跨镜只引用不改画，三视图（正 / 侧 / 背）的纹样必须能对上 |
| 靛青漂成藏蓝 / 宝蓝 / 黑蓝 | 只写「深蓝」不钉 HEX | 底色钉死 #2B4C7E、深部钉死 #1F3350，压句与配色句两处都带 HEX |
| 串去水墨或工笔手绘轨 | 写了笔触、晕染、宣纸、墨色浓淡 | 平涂无笔触、无纸纹；装饰是**几何化的纹样带**，不是画出来的笔法 |

## 七、声音签名（中英双轨）

投中文面（Seedance 2.5 / 国内面）直接取中文版，不要拿英文版现场翻译。

**中文版（2.5 面 / 国内面用）**：

```text
整体声音签名：环境层——市井的远闹与风吹织物的轻响；
动作层——器物碰撞的清响、金线摩擦的锐声、衣料走动的窸窣；
呼吸层——默认无（平面人物无胸腔起伏，不许补呼吸）；
配乐层——默认无配乐；需要时写一件民乐主奏加速度，全片不换编制。
```

**英文版（H3 面用）**：

```text
overall_soundscape:
Distant market murmur and the soft rustle of ornamented fabric in the ambient bed; clear ceramic knocks, the thin rasp of gold line-work and cloth whispers on every movement. No breathing layer — flat illustrated figures have no chest rise.

non_diegetic_music:
N/A by default. When scoring is needed, declare one folk instrument and a fixed tempo, unchanged for the whole film.
```

配乐中文写法（需要时）：`一段民乐，笛或古筝主奏，速度中缓，全片不换编制。`

**呼吸层纪律**：平面插画人物没有胸腔起伏，**呼吸层默认写「无」，不是留空**——留空会被补呼吸，呼吸会诱导模型给平涂人物加体积。

**动作层的取舍**：金线摩擦的锐声是本风格的辨识度，但只在**有金线装饰的物件入镜**时写；纯对话镜与空镜不要堆，堆了会像金属首饰广告而不是国潮插画。器物清响同理——一镜只留一个主导的动作声。

## 八、参考图集与角色锁定

本风格无专属参考图集，角色锁定走 `<Subject N>` 通用写法。出角色资产图时的版式按 liqi 非写实适配：视图用正面 / 侧面 / 背面三视图（纹样服装必须三面都能对上），材质写平涂不透光，相机写平面化，头身比落 6 到 6.5，身高线改工艺尺寸线。投喂铁律照旧：任何镜头带一张头部裁片作身份锚；纹样分布图随资产图一并锁定。
