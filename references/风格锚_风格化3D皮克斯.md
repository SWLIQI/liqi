# 风格化 3D（皮克斯式）风格锚（三渲二轨 × 全投放面通用）

本文件是 Step 2「全片统一风格锚（九段）」在**风格化 3D（皮克斯 / 迪士尼式 CG 动画电影）**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——改一个词，不同镜头质感就会漂移。

**适用判定**：角色是三维实体但造型经过夸张简化——头偏大、四肢偏圆、比例不写实；皮肤有柔和的次表面透光感；
布光是明亮的三点式，暗部带环境色反射而不是死黑；材质表面能看到手绘笔触与轻微不完美（指印、磨损、布纹）。
镜头敢做大范围推拉、环绕、挤压拉伸。用户给的设定图是这类质感时，锁③ 风格轨道选**三渲二轨**，
风格 id 取 `stylized-pixar-3d`。

**边界声明**：

- 与三渲二 NPR（`npr-celshaded-3d`）：同属 3D 轨，**区别在着色方式**。三渲二是两段式硬边阴影 + 均匀描边 + 平涂色块；
  本风格是**多层软过渡着色 + 体积光 + 无描边**。写了描边或「两段式硬边」就变成三渲二，写了三段色阶就不是本风格。
- 与写实 PBR（`photoreal-pbr`）：同属 3D 但目标相反。写实轨追求真实材质与真人相似度，人脸有恐怖谷风险；
  本风格明确**不追求真实**——比例夸张、皮肤简化、材质带手绘感，人脸走的是「可信但不真实」。
- 与定格木偶（`gothic-puppet`）：定格要的是手工痕迹与微缩布景的「假」；本风格要的是 CG 的顺滑与体积感。材质词汇互斥。

> **本风格的核心优势是表情与表演**：造型夸张意味着表情可做大，情绪传达效率高于写实轨。
> 代价是纯文生视频容易滑向写实 CG 或三渲二，**有资产图、走 I2V/Ref2VA 时最稳**。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 风格化 3D CG 动画电影（非写实）：三维实体带夸张简化比例，头偏大、四肢圆润；皮肤有柔和次表面透光，不做真实毛孔；材质带手绘纹理与轻微不完美；全局有体积感与景深层次，但明暗是多层软过渡，不是两段式硬边 |
| ② 配色与色域 | 明亮饱和的中高彩度：暗部吃环境反射色（偏冷紫或偏暖橙，不写死黑）；**每镜只声明一个唯一重音色**；禁用荧光、脏灰、低饱和灰蒙、胶片颗粒 |
| ③ 运动签名 | 24fps，运动连续可带挤压拉伸（squash & stretch）；允许适度运动模糊（本风格允许，与三渲二轨不同）；**禁止定格顿挫、禁止抽帧** |
| ④ 角色锁定 | 走 `<Subject N>`：**头身比 6–6.5（风格化成人档，孩童取 4–4.5）**；脸型骨相走简化几何（圆颅、下颌收），发型体块化；服装形制与配色；同一角色跨镜不换装、不换形、不换比例档 |
| ⑤ 场景锁定 | 走 `<Subject N>`：场景是三维布景，有纵深、层次与大气透视；同场景跨镜地标、比例与光位一致；允许写「远景层 / 中景层 / 前景层」三层结构 |
| ⑥ 道具锁定 | 走 `<Subject N>`：形制、材质、入画方式必须写（手持 / 悬挂 / 置地）；道具表面允许写磨损、指印、漆面掉角这类手绘细节 |
| ⑦ 光色基调 | 三点式布光：主光 + 补光 + 轮廓光；暗部有环境反射色，不是灰也不是黑；**禁用纯黑阴影、禁平面化平涂明暗**；允许写体积光与光晕 |
| ⑧ 声音签名 | 环境层：有空间感与远近层次；动作层：脚步、衣料、道具碰撞，节拍清晰带轻微夸张；呼吸层：克制但可闻；配乐：明亮管弦或轻爵士，按题材定 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。仅其他有 negative 字段的面可用：照片写实、真人皮肤毛孔、恐怖谷人脸、两段式赛璐璐阴影、均匀描边、平涂色块、塑料高光、定格顿挫、可读文字、水印 |

## 二、多面压句（逐字复用，按投放面取用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A stylized 3D animated feature look: rounded, simplified characters with slightly oversized heads, soft subsurface skin, multi-tone soft shading with no outline, volumetric three-point lighting where shadow takes the ambient colour rather than grey or black. Hand-painted surface texture, gentle imperfections, mild motion blur allowed.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
bright saturated palette where shadow carries the ambient bounce colour, never grey or black, with a single accent hue per frame
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `3D render` / `CGI` 单写 | `stylized 3D animated feature look` | 只写 3D render 会被路由到写实 PBR 通道，材质整套走偏 |
| `cel-shaded` / `two flat tones` / `outline` | 删除 | 这三个词是三渲二轨的本体，写了就变三渲二 |
| `photorealistic` / `skin pores` / `realistic face` | 删除 | 写实人脸词会把风格化脸顶掉，并触发恐怖谷 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅风格化 3D 动画电影画面：角色造型圆润简化、头略偏大，皮肤有柔和的次表面透光，明暗是多层软过渡，不描边。三点式布光带体积感，暗部吃环境反射色而不是灰或黑。材质表面有手绘纹理与轻微不完美，允许轻微运动模糊。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
明亮饱和的配色：暗部带环境反射色，不是灰也不是黑，每帧只保留一个重音色。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「3D 渲染」「CG 动画」 | 「风格化 3D 动画电影」 | 中文面「3D 渲染」直连写实 PBR，不写「风格化」必滑走 |
| 「赛璐璐」「描边」「平涂」 | 删除，正面写「多层软过渡、无描边」 | 这三个词是三渲二轨的词，写了就变三渲二 |
| 「不要写实、不要真人感」 | 删否定句，正面写「造型圆润简化、皮肤柔和透光」 | 否定不生效，反而容易被读成「有写实」 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（风格化三维、软过渡无描边、暗部带环境色）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节）。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台默认渲染管线会把暗部压成灰**，
所以 2.2 那句「暗部吃环境反射色而不是灰或黑」在国内面**不许省略**。

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 变写实 CG / 电影级渲染 | 压句只写 `3D render`，正文出现 PBR、photorealistic、skin pores | 压句第一词必须是 `stylized 3D animated feature look` |
| 变三渲二（描边 + 两段式） | 正文出现 cel-shaded、outline、two tones、平涂 | 删掉这三个词，正面写「多层软过渡、无描边」 |
| 人脸恐怖谷 | 写真实皮肤细节、真人脸比例 | 头身比按 6–6.5 写死，皮肤只写「柔和透光」 |
| 暗部变灰变脏 | 平台默认管线把阴影压成中灰 | 每镜光色基调都写「暗部吃环境反射色，不是灰也不是黑」 |
| 变定格动画 | 出现 stop-motion、顿挫、抽帧 | 写「运动连续，允许轻微运动模糊」 |
| 体块变平 | 光写成单一平光、无轮廓光 | 三点式布光三件都写：主光方向、补光、轮廓光 |
| 材质变塑料 | 出现 glossy、plastic、镜面高光 | 写「哑光手绘纹理 + 轻微不完美」 |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删的是「三渲二化」与「写实化」两侧的词**，本风格要保留体积与软过渡。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| cel-shaded / outline / two flat tones | 删除，改写 soft multi-tone shading with no outline | 触发三渲二通道 |
| photorealistic / skin pores / realistic face | 删除，改写 soft subsurface skin | 触发写实与恐怖谷 |
| glossy / plastic / mirror reflection | matte hand-painted surface | 塑料感是风格化 3D 最常见的崩法 |
| stop-motion / stutter | continuous motion | 掉进定格轨 |
| grey shadow / black shadow | shadow takes the ambient bounce colour | 暗部一灰，体积感全丢 |
| 厚涂 / 油画笔触 | 手绘纹理 / 表面轻微不完美 | 厚涂会拉进手绘轨 |

### 9.2 互斥风格

与本风格互斥的 id（与 L0 `style-registry.json` 的 `excludes` 一致，**双向登记**；数值有出入时以 L0 为准）：

`npr-celshaded-3d`（三渲二，着色方式互斥，混了会同时出现描边与软过渡）、
`photoreal-pbr`（写实，材质与比例互斥，混了会出恐怖谷脸）、
`gothic-puppet`（定格木偶，手工痕迹与 CG 顺滑互斥）、
`ink-wash-2d`（手绘平面轨，平面与体积互斥）、
`documentary-live-action`（纪实实拍，实拍无美术指导式的理想化比例与打光，方向相反）。
