# 黑色电影插画·黑白硬光 风格锚（卡通轨 × 黑白插画专项）

本文件是 Step 2「全片统一风格锚（九段）」在**黑色电影（film noir）黑白插画质感**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：四十年代黑色电影的插画化世界——纯黑白高对比、大面积实黑剪影、
百叶窗光与霓虹点光、雨夜街道、风衣礼帽的侦探剪影、版画式的干笔肌理。
用户给的是侦探 / 悬疑黑白 / 反讽犯罪插画参照时，锁③ 风格轨道选**卡通轨**，风格 id 取 `noir-ink-2d`。

**边界声明**：

- 与都市悬疑冷青（`urban-suspense-live`）：悬疑是**当代实拍冷青 grade**；noir 是**黑白插画**
  （两值系统、版画肌理）。维度与色彩体系互斥。
- 与复古港风（`hk-retro-filmstill`）：港风是实拍彩色霓虹；noir 是黑白插画。同题材（犯罪）不同维度。
- 与美式漫画硬线（`us-comic-ink-2d`）：同是墨线，美漫是**四色彩印**带排线塑形；noir 是**纯黑白**
  大面积实黑剪影＋干笔肌理。色彩体系互斥。
- 与水墨淡彩（`ink-wash-2d`）：水墨有浓淡干湿的墨韵；noir 是印刷感的硬边两值。

> **竖屏适配（C26）**：noir 签名（百叶窗光、雨夜、剪影）不依赖横幅——竖屏写法：
> 百叶窗光条纹纵向切割人物、雨丝纵落、剪影居中留白大面积实黑。**竖屏友好，无需改写行**。

## 一、九段锚（中文）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 黑色电影插画：纯黑白两值系统，大面积实黑剪影与刺目的白光区对撞，光影边缘是干净的硬边（不是渐变），干笔肌理与版画网点做中间灰的过渡，像老报纸连环画的精装版 |
| ② 配色与色域 | 纯黑白两值＋一个灰阶层：墨黑、纸白、半色调灰；**重音就是那道光**（百叶窗光/霓虹点光），每镜只声明一处；禁任何彩色、禁棕褐做旧、禁蓝调 |
| ③ 运动签名 | 24fps，**光影的戏**：人物在光带间穿行（明灭交替）、雨丝斜切光柱、烟雾缭绕；运镜以固定机位与极缓推近为主；禁环绕、禁手持晃动、禁快切 |
| ④ 角色锁定 | 走 `<Subject N>`：头身比 7-7.5（插画成人档）；人物半剪影或强侧光切割，风衣礼帽形制写死；面部只留最少的白（眼白、烟头红点除外——烟头是唯一彩点但按灰阶处理）；跨镜形制不变 |
| ⑤ 场景锁定 | 走 `<Subject N>`：雨夜街道、办公室（百叶窗）、码头、小巷四类；光源（路灯/霓虹/台灯）位置写死，光带形状逐镜一致 |
| ⑥ 道具锁定 | 走 `<Subject N>`：左轮、酒瓶、报纸、电话，形制写死；反光只给一刀白 |
| ⑦ 光色基调 | 硬边点光：光源小而锐（路灯/霓虹/百叶窗切光），实黑大面积压场，白光区刺目；**禁柔和渐变光、禁彩色光、禁均匀照明** |
| ⑧ 声音签名 | 环境层：雨声、远处爵士俱乐部含混乐声、街道脚步回声；动作层：打字机、电话铃、风衣摩擦、左轮转轮；呼吸层：低沉克制；配乐：爵士小号与低音提琴，慢板冷调 |
| ⑨ 排除项 | **H3 面丢弃**（无 negative 字段）。其他面：任何彩色、柔光渐变、日系赛璐璐、厚涂、照片质感、3D 渲染、可读文字、水印、多余人物、分身 |

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A film-noir black-and-white illustration: pure two-value world of solid ink blacks against stark white light, hard-edged light shapes, venetian-blind slats slicing a face, a lone streetlamp cutting rain-slick streets. Dry-brush and halftone greys for transitions, trench-coat and fedora silhouettes half-swallowed by shadow. No colour at all, no soft gradients, the light itself is the drama.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
strict black-and-white with one halftone grey step, the light shape as the single accent
```

**三条措辞纪律**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `moody blue-grey grade` | `no colour at all` | 蓝调是悬疑实拍档的方向 |
| `soft ambient shading` | `hard-edged light shapes` | 渐变光反 noir 本体 |
| `colorful neon` | 删，光带即重音 | 彩色破坏两值系统 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁。本锚英文压句现长 55 词，长档——预算紧先删末句（the light itself 一句），删后约 55 词。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅黑色电影风格的黑白插画：纯两值世界——大面积实黑剪影对撞刺目白光，光影边缘是干净硬边，百叶窗光条切开人脸，一盏路灯切亮雨夜街道。干笔肌理与版画网点做过渡灰。风衣礼帽的剪影半没入阴影。全片没有任何彩色，没有柔光渐变——光本身就是戏剧。
```

配色补充句（写进【主体与关系】的风格内联）：

```text
配色：墨黑与纸白两值加一档半调灰，每镜唯一重音是那道光的形状。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「蓝色忧郁」「冷青」 | 删，写「纯黑白」 | 反串悬疑实拍档 |
| 「彩色霓虹」 | 删，写「白光带」 | 两值系统铁律 |
| 「柔和明暗过渡」 | 删，写「硬边光形」 | 渐变光反 noir |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，刚性约束的「必锁」行再压一次（两值系统、硬边光形、干笔肌理、大面积实黑）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。
2. **负面词**：无 `negative_prompt` 字段时压成 `Must not：` 一行附正文末，≤1 行。

国内面最需要盯的是**平台自动上色或加蓝调**，所以「纯黑白两值」在国内面**不许省略**，且 Must not 必须带「彩色」。

## 三、色值表

| 用途 | 色值 | 说明 |
|---|---|---|
| 墨黑（实黑剪影） | #16141A | 大面积压场，不是纯 #000（留一点墨感） |
| 纸白（光区） | #F2EEE6 | 刺目白光的亮部 |
| 半调灰 | #7A7670 | 唯一过渡层，干笔与网点 |
| 干笔深灰 | #4A4640 | 中间调的暗侧 |
| 湿街反光灰 | #5A5850 | 雨夜地面反光 |
| 烟雾灰 | #8A867E | 烟雾的透光 |
| 皮肤亮部 | #D8D0C4 | 光带下的脸 |
| 皮肤暗面 | #2A2824 | 剪影化暗面 |
| 唯一彩点（限额） | #B03828 | 烟头红点——按灰阶处理，全片限一处 |

**色彩预算纪律**：全片两值＋一灰层；朱红烟头是唯一彩点，按灰阶明度处理（不作为颜色读出），全片限一处。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定机位、极缓推近（光形缓慢吞没人物） |
| 少量 | 缓慢横移（光带间穿行） |
| 避免 | 环绕、手持晃动、快切、无人机拉升、俯仰 |

**每段只锁一个主运镜**；光影明灭是画面内动效。

## 五、材质与可见性预算

| 项 | 落值 |
|---|---|
| 主 | 光形的形状与人物的剪影切割关系 |

## 六、崩点清单与反制（≥6 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| 彩色混入 | 写了霓虹彩色、肤色暖调 | 「纯黑白两值」锁死；Must not 必带彩色 |
| 跑成蓝调悬疑 | 写了冷青、蓝色 grade | 反串实拍悬疑档；负面词带蓝调 |
| 光变柔光 | 写了朦胧、渐变过渡 | 「硬边光形」锁死；负面词带柔光 |
| 实黑变死黑 | 压成纯 #000 | 保留墨感的 #16141A；干笔肌理过渡 |
| 人物全黑看不清 | 剪影写过头 | 「半剪影」——面部留最少的白（眼与轮廓线） |
| 烟头红点抢戏 | 彩点写多 | 全片限一处；按灰阶明度处理 |
| H3 正文混中文 | 压句或光影段夹中文 | 压句纯英文；跑 `check_prompt_h3.mjs` |

## 九、去立体化与串轨防护

### 9.1 本风格的污染词与替换对

方向：**删「彩色化」与「柔光化」两侧的词**，保留两值硬边与版画肌理。

| 污染词 | 替换 | 为什么 |
|---|---|---|
| blue grade / 冷青调 | pure black-and-white | 反串实拍悬疑档 |
| colorful neon / 彩色 | white light shapes | 两值铁律 |
| soft gradient light | hard-edged light shapes | 渐变光反 noir |
| cel shading / 赛璐璐 | dry-brush and halftone | 反串动画档 |
| photoreal rain | graphic rain streaks | 照片反面 |

### 9.2 互斥风格

`urban-suspense-live`（实拍冷青 vs 黑白插画，维度与色彩互斥）、`us-comic-ink-2d`（四色彩印 vs 纯黑白）、
`hk-retro-filmstill`（彩色霓虹 vs 两值硬光）、`ink-wash-2d`（墨韵浓淡 vs 印刷硬边两值）。
