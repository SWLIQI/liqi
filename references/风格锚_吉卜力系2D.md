# 吉卜力系 2D 风格锚（卡通轨 × 手绘水彩档）

本文件是 Step 2「全片统一风格锚（九段）」在**吉卜力系（Ghibli-inspired hand-drawn）**这套具体风格上的落值，
同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**。

**适用判定**：手绘动画质感——**背景是手绘水彩**，绿植、天空与云一层层叠出厚度，笔触与纸纹看得见；
人物是细笔勾线的手绘上色，**明暗有边界但边缘柔化**（不是硬边两段式）；
光是自然光——日光、树影与室内暖光，方向明确而柔和。用户给的设定图是这类质感时，
锁③ 风格轨道选**卡通轨**，风格 id 取 `ghibli-2d`。

**边界声明**：

- 与日系 anime（`anime-2d`）：两者都是手绘上色，**分家在明暗与光**。anime 是硬边两段式 + 高对比打光；
  本风格是「有边界但边缘柔化」+ **只用自然光**。写了硬边两段式就变日系。
- 与厚涂（`thickpaint-2d`）：厚涂是多层罩染的**软过渡无硬边**；本风格的明暗**有边界**，只是边缘柔化。
  两侧都禁——本锚既禁硬边两段式，也禁厚涂笔触。
- 与东方水墨（`ink-wash-2d`）：本风格是**西式透明水彩**（层层叠色、笔触与纸纹可见），
  不是墨色浓淡与皴法渗化。两者登记互斥，写了水墨词就串轨。
- 与新海诚 / 京都系（`shinkai-2d`，待建备选）：那一档是**强光晕、强对比光斑与高饱和反射**；
  本风格禁光晕特效，光只走自然光。要那一档就走 `shinkai-2d`，别在本锚里加 glow。
- 与写实轨任一：手绘水彩 vs 真实材质，负面词方向完全相反。

## 二、多面压句（逐字复用）

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A Ghibli-inspired hand-drawn animation frame: watercolour backgrounds with layered greens, skies and clouds that keep visible brushwork and paper grain; characters drawn with fine ink lines and painted shading that has a boundary but a softened edge, never hard two-step cel shading. Natural light only, soft daylight, tree shadow and warm interior light with a clear direction, no dramatic key lighting and no glow effects. It is a hand-drawn animation frame, not a 3D render and not a photograph.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
natural-light palette of sky blue and layered foliage green with a single warm sunlight-gold accent over warm paper tone
```

**五条措辞纪律**：

| 写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `hard two-step cel shading` | `shading with a boundary but a softened edge` | 硬边两段式是 anime 本体，写了就变日系 |
| `soft blended` / `painterly` / `thick paint` | `fine ink lines`、`hand-painted watercolour` | 厚涂是软过渡无硬边，与本锚的「有边界」相反 |
| `glow` / `lens flare` / `volumetric light` | `natural soft daylight, tree shadow, warm interior light` | 光晕是 shinkai-2d 那一档的词，这里只走自然光 |
| `3D render` / `ray tracing` / `CGI` | `hand-drawn animation frame` | 渲染词会把水彩背景顶成 CG 场景 |
| `ink wash` / `皴法` / `留白` | `hand-painted watercolour with paper grain` | 水墨是另一条轨，与 `ink-wash-2d` 互斥 |

**两处必须同时出现**：风格压句放在 `detailed_description` 开头，配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移——本锚的暖阳重音与「纸纹暖底」全靠配色句钉住。

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。改压句前先算 Δ，
改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 79 词（按校验器空白分词口径实测），在全库锚中排第 9（按词数降序），中上，留有两三个词的余量。真要压减，先砍第三句的自然光举例（tree shadow / warm interior light 保留其一），
**但 `hand-painted watercolour` 与 `natural light only` 两处不许删**——前者是背景本体，后者是与日系、新海诚分家的界线。

```text
一幅吉卜力系的手绘动画画面：背景是手绘水彩，绿植、天空与云一层层叠出厚度，笔触与纸纹看得见；人物是细笔勾线的手绘上色，明暗有边界但边缘柔化，不是硬边两段式。光是自然光——日光、树影与室内暖光，方向明确而柔和，不做戏剧性打光也不加光晕特效。整体是手绘的动画画面，不是 3D 渲染，也不是照片。
```

**中文面四条额外纪律**：

| 「动漫风」「二次元」单写 | 「吉卜力系的手绘动画画面」 | 单写会被引向电视动画或日系薄色 |

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段。

## 四、运镜池

| 分类 | 运镜 |
|---|---|
| 主力 | 固定全景、缓慢横移（背景卷动）、缓慢推近、正反打、静态长镜 |
| 少量 | 轻微俯仰、跟随移动、航拍式拉远 |
| 避免 | **360 环绕、甩镜、快速变焦、手持晃动** |

**每段只锁一个主运镜**。缓慢横移是手绘背景卷动的本命运镜（能展示水彩层次），主力用；
环绕与快速变焦会让水彩背景出现透视不一致。

## 六、崩点清单与反制（8 条）

| 崩点 | 成因 | 反制 |
|---|---|---|
| **变 3D / 半立体（本风格头号崩点）** | 背景写了 realistic / 3D / 体积光，或参考图是 CG 场景 | 媒介声明放首句；背景写 `hand-painted watercolour` 与 `visible brushwork`；删一切渲染词 |
| 背景被压成简化平涂，丢水彩层次 | 没写背景层次，只给了一个天空色 | 背景必须写「绿植、天空、云一层层叠出厚度」，并写可见笔触与纸纹 |
| 变日系电视动画 | 写了硬边两段式与高对比打光 | 明暗写「有边界但边缘柔化」；光只写自然光 |
| 跑到新海诚 / 京都系那一档 | 写了强光晕、强对比光斑、高饱和反射 | 禁光晕特效与高饱和反射；要那一档就走 `shinkai-2d`（待建） |
| 变东方水墨手绘 | 写了墨色浓淡、皴法、留白 | 与 `ink-wash-2d` 互斥，删水墨词；本锚是西式透明水彩 |

| 跨镜背景笔触与光位不一致 | 没走 `<Subject N>`，光位每镜重编 | 每镜内联锁定；光位与时段写死；必带资产图走 I2V/Ref2VA |
| 国内面把水彩压成塑料渐变 | 国内平台默认加渐变与磨皮 | 国内面「手绘水彩、笔触与纸纹可见」一句不许省 |

## 九、去立体化与串轨防护

本锚的污染方向是**两侧都删**：既要删「立体化」（3D 渲染与体积光会把水彩顶成 CG 场景），
也要删「另一侧的手绘化」（硬边两段式与厚涂软过渡都不是本锚的明暗逻辑）。
这与水墨锚的删词表**不是同一张**——水墨要的是平面无体积，本锚要的是手绘但有层次。

### 9.1 污染词与替换对

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 3D render / CGI / ray tracing / 体积光 | hand-drawn animation frame、hand-painted watercolour | 渲染词把水彩背景顶成 CG 场景 |
| hard two-step cel shading / 硬边两段式 | shading with a boundary but a softened edge | 硬边是 anime 本体 |
| soft blended / painterly / thick paint / 厚涂 | fine ink lines、hand-painted watercolour | 厚涂是软过渡无硬边，与本锚「有边界」相反 |
| glow / lens flare / 光晕 / 光束 | natural soft daylight, tree shadow, warm interior light | 光晕是 shinkai-2d 那一档的词 |
| 墨色浓淡 / 皴法 / 留白 / ink wash | hand-painted watercolour with paper grain | 水墨是另一条轨，与 `ink-wash-2d` 互斥 |
| photorealistic / skin pores / 磨皮 | hand-drawn animation frame | 写实与美化词把手绘拉向照片 |
| 霓虹 / 赛博 / 高饱和反射 | 自然光色系 + 唯一重音色 | 撞上就跑到科幻档，与本风格最远 |

### 9.2 互斥风格（重点对因）

| 互斥 id | 混了会怎样 |
|---|---|
| `ink-wash-2d`（水墨淡彩） | **同为手绘但水彩系统不同**：西式透明水彩层层叠色 vs 墨色浓淡与皴法渗化，两者登记互斥 |
| `anime-2d`（日系动画 2D） | 硬边两段式与高对比打光 vs 有边界但边缘柔化 + 只用自然光，明暗与光都相反 |
