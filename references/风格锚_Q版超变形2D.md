# Q 版 / 超变形 2D 风格锚（卡通轨 × 全投放面通用）

本文件是 liqi Step 2「全片统一风格锚（九段）」在**Q 版 / 超变形（chibi / SD）**这套具体风格上的落值
（v5.42.0 批 3 第四个），同时给出三个投放面各自的压句。**压句逐字复用，一个字都不要改**——
改一个词，不同镜头质感就会漂移。

**适用判定**：二到三头身的超变形比例、超大圆头、小而紧实的身体、粗而均匀的轮廓线、
大而圆的高光眼、明快的平涂色块、夸张的 Q 弹动作（挤压拉伸）。萌系日常、表情包式短剧、
儿童向内容、品牌吉祥物、轻科普都吃这套。用户给的设定图是这类超变形质感时，锁③ 选**卡通轨**，
风格 id 取 `chibi-qban-2d`。

**边界声明**：

- **与其他全部锚的头身档关系**：2–3 头身是本风格的**定义**，不是缺陷。
  其他锚的负面词里出现「Q 版二头身」挡的是「已选非 Q 版风格却写了 Q 版比例词」的混档；
  本风格恰恰相反——**写「写实比例 / 6–8 头身 / 真人化」才是崩**。头身档跨档 = 换风格。
- 与黏土定格（`claymation-3d`）：「3D 化的 Q 版」是常见滑轨——黏土偶是实体材质，
  本风格是 2D 平涂。判据是媒介：出现实体材质与布景纵深就是串到定格轨。
- 与国漫赛璐璐（`celshade-guoman-2d`）：同是赛璐璐上色逻辑，但头身档、五官密度、
  动作幅度全部不同档。同一包里 Q 版与美型档并存 = 头身档跨档（S6 拦）。

> ⚠️ **版权规避**：投喂词内不点名任何具体作品或 IP 名（哪怕用户拿某表情包系列当参照系）。
> 只写风格特征——Q 版、超变形、大头小身。作品名只出现在本文档的说明层与对话里。

## 一、九段锚（中文，给 liqi 上游用）

| 段 | 落值 |
|---|---|
| ① 画风与材质质感 | 2D 卡通超变形风格：二到三头身，超大圆头占全身一半以上，小而紧实的身体；粗而均匀的轮廓线，平涂色块配简单两段式阴影；大而圆的眼睛带一处大高光；无噪点颗粒 |

## 二、多面压句（逐字复用，按投放面取用）

三小节分别对应三个投放面。**同一套语义，三面各备一份句子，禁止临场翻译**——翻译一次漂一次。

### 2.1 H3 英文压句（写在 `[Shot 1]` 之前）

```text
A chibi super-deformed 2D cartoon with a two-to-three-heads-tall proportion, oversized round head on a tiny compact body, thick even outlines, flat bright colour areas with simple two-tone shading, large glossy eyes with one catchlight each, no gradient, no grain.
```

配色补充句（写进风格 `<Subject N>` 定义里）：

```text
bright clean palette of milk white and sky blue with one vivid orange accent per frame, colour blocks kept pure and clearly separated
```

**三条措辞纪律（每条都在治一个崩点，不要改回去）**：

| 旧写法 | 本锚定稿 | 为什么 |
|---|---|---|
| `cute anime character`（单独用） | `chibi super-deformed 2D cartoon` + 头身比写死 | 只写 cute 会路由到正常头身的美型档；头身比才是本风格的第一判据 |
| `realistic proportions` / `tall figure` | 删除，负面词方向改为「写实比例、六到八头身」 | 本风格的定义就是超变形——比例词写反就是换风格 |
| `soft painterly shading` | `flat bright colour areas with simple two-tone shading` | 软过渡把 Q 版推向黏土或厚涂，明快色块变糊 |

**压句字数纪律（H3 面）**：正文有 350–500 词区间门禁，压句一涨就把贴上限的单元顶出去。
改压句前先算 Δ，改完跑 `check_prompt_h3.mjs` 确认仍是 0 warning。本锚英文压句现长 39 词（按校验器空白分词口径实测），偏短，加词空间充足，但别堆否定串。

**两处必须同时出现**：风格压句放在 `detailed_description` 开头；配色句放在 `<Subject N>` 的风格条目里。
只写一句会导致色域漂移。

### 2.2 Seedance 2.5 中文压句（写在【生成目标】段首）

```text
一幅 2D 卡通 Q 版超变形画面：二到三头身，超大圆头配小而紧实的身体，粗而均匀的轮廓线，明快的平涂色块配简单的两段式阴影，大而圆的眼睛各带一处大高光。无渐变，无噪点颗粒。
```

配色补充句（写进【主体与关系】的风格内联，与【生成目标】的压句同时出现）：

```text
明快干净的配色：奶白与天蓝为主，每帧只保留一个活力橙重音，色块纯净、分界清楚。
```

**中文面三条额外纪律**：

| 写法 | 定稿 | 为什么 |
|---|---|---|
| 「写实一点的比例」「精致美型」 | 「二到三头身」「大头小身」 | 比例词写反就是换风格，是本锚第一崩点 |
| 「柔和的立体感」 | 「平涂色块」「两段式阴影」 | 立体感词把 Q 版推向 3D 黏土 |
| 「不要画得太幼」 | 删否定句，正面写「二到三头身、大圆眼」 | 否定句无效且引歧义 |

**三处必须同时出现**：压句在【生成目标】段首，配色句在【主体与关系】的风格内联，
刚性约束的「必锁」行再压一次风格特征（二到三头身、粗轮廓线、大圆眼大高光）。

### 2.3 国内面中文压句（写在「整体风格」段）

逐字复用 2.2 的两句中文，**一个字都不要改写**。差异只在两处：

1. **位置**：国内面单镜模板的「整体风格」段（SKILL.md Step 3 第 5 小节），不是【生成目标】。
2. **负面词**：国内面若平台无 `negative_prompt` 字段，把第一节第⑨段的排除项压成
   `Must not：` 一行附正文末，≤1 行。有该字段的面整份填入。

国内面最需要盯的是**平台自带美颜与美化倾向会把头身比悄悄拉高**（Q 版被「画精致」）——
所以 2.2 那句「二到三头身」「超大圆头」在国内面**不许省略**，且每镜的头身档必锁行都要带。

## 三、色值表（风格级起点，项目级以 asset-registry 为准）

| 用途 | 色值 | 说明 |
|---|---|---|
| 奶白（底色） | #FFF6E8 | 皮肤亮部与背景基色，不纯白 |
| 天蓝（主色） | #5CB8D4 | 服装主色与大型色块 |
| 活力橙（重音色） | #FF7B54 | 全片唯一重音色：关键道具、腮红、标识 |
| 草绿 | #7BC47F | 植被与辅助色块 |
| 樱粉 | #F7A8C4 | 腮红、点缀与暖色衣物 |
| 淡黄 | #FFE08A | 高光面与暖色块 |
| 深咖 | #6B4A38 | 轮廓线与最深的固有色，不是纯黑 |
| 天空白 | #EAF6FB | 天空与冷色背景块 |

**色彩预算纪律照旧**：每镜只声明一个唯一重音色，其余压成同色系。
Q 版的辨识度靠「少而正的颜色」——色一多，小小的人身上就花了。

**暗部纪律**：阴影 = 固有色加深一档的两段式，分界干净，**不是灰、不是黑**。
轮廓线用深咖而不是纯黑——纯黑线在明快色域里会发凶。

**同步纪律**：本表与 L0 注册表的 `palette` 必须一致，改一处要同步另一处。
项目级具体角色的色值另存 `asset-registry.json`，不抄进本文件。

## 六、崩点清单与反制

| 崩点 | 成因 | 反制 |
|---|---|---|
| **头身比漂到 4–5（半 Q 不 Q）** | 精致词、美型词混入；没逐镜锁头身档 | 每镜头身档必锁行带「二到三头身」；负面词带「写实比例、六到八头身」 |
| **变 3D 黏土质感** | 写了立体、圆润材质、软表面 | 压句钉死 `2D cartoon` 与 `flat bright colour areas`；负面词带黏土材质 |
| **变日系美型 Q 版（眼睛过精）** | 眼型写了过多层次、睫毛高光堆叠 | 大圆眼 + 单一大高光写死；不写睫毛细节 |
| **变美式卡通（嘴大身细）** | 用了美式 cartoon 词汇习惯 | 头身比与「小而紧实的身体」写死；嘴部做小 |
| **表情渐变失弹** | 表情按真实面部逻辑写 | 表情切换是跳变；动作写挤压拉伸，不写肌肉 |
| **色彩变脏变灰** | 重音过多、加了颗粒 | 每镜一个活力橙重音；负面词带噪点颗粒 |
| **道具与身体比例失调** | 道具按真实比例写 | 道具放大或简化到与身体协调，比例关系写进锁定行 |

## 九、去立体化与串轨防护

本风格是 2D 平涂轨，**不要跑手绘轨或定格轨的 `dedupe_style.py` 词表**，按 §9.1 手工清。

### 9.1 污染词与替换对（Q 版方向）

| 污染词 | 替换 | 为什么 |
|---|---|---|
| 写实比例、正常人体、修长 | 二到三头身、大头小身 | 比例词是本风格的第一判据，写反即换风格 |
| 精致、美型、高细节 | 简洁、圆润、大色块 | 精致词把 Q 版拉向美型档 |
| 立体感、黏土质感、软表面 | 平涂色块、两段式阴影 | 立体词把 Q 版推向 3D 黏土 |
| 真实肌肉、骨骼结构 | 挤压拉伸、Q 弹形变 | 解剖词与超变形逻辑相反 |
| 厚重笔触、油画感 | 平涂 + 粗轮廓线 | 笔触词破坏干净的卡通面 |
| 噪点、颗粒、暗调 | 删除，明快色域 | 本风格是高明度色域 |

**保留不动的词**（这些在别的轨要删，在本轨是本体）：`chibi`、`super-deformed`、`Q 版`、`大头`、`夸张`、`Q 弹`。
**特别注意**：本锚负面词**不含**「Q 版、二头身、大头」——那是本风格的本体词（v5.2.0 反向自打脸防线），
其他锚负面词里的「Q 版二头身」挡的是混档，不影响本锚。
